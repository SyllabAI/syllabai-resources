# Worksheet 4CH1-S2-h — Chemical tests
SME group `2-8-chemical-tests` · notes: 5 · spec points: 7

## Spec points in this subsection

- **4CH1-2.44** (2.44): describe tests for these gases: · hydrogen · oxygen · carbon dioxide · ammonia · chlorine.
- **4CH1-2.45** (2.45): describe how to carry out a flame test
- **4CH1-2.46** (2.46) · DAMAGE: know the colours formed in flame tests for these cations: · Li$^{+}$ is red · Na$^{+}$ is yellow · K$^{+}$ is lilac · Ca$^{2+}$ is orange-red · Cu$^{2+}$ is blue-green.
- **4CH1-2.47** (2.47) · DAMAGE: describe tests for these cations: · NH$_{4}^{+}$ using sodium hydroxide solution and identifying the gas evolved · Cu$^{2+}$, Fe$^{2+}$ and Fe$^{3+}$ using sodium hydroxide solution.
- **4CH1-2.48** (2.48) · DAMAGE: describe tests for these anions: · Cl$^{-}$, Br$^{-}$ and I$^{-}$ using acidified silver nitrate solution · SO$_{4}^{2-}$ using acidified barium chloride solution · CO$_{3}^{2-}$ using hydrochloric acid and identifying the gas evolved.
- **4CH1-2.49** (2.49): describe a test for the presence of water using anhydrous copper(II) sulfate
- **4CH1-2.50** (2.50): describe a physical test to show whether a sample of water is pure
