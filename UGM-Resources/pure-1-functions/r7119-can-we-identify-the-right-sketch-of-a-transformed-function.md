# Can we identify the right sketch of a transformed function?

## Question

The diagram below shows the graph of the function \(y = f(x)\).

> [figure: Graph of f, an increasing function with increasing gradient, passing through the origin — `https://undergroundmathematics.org/combining-functions/r7119/images/function.png`] (image not included in the text import; path of record).

The graph of the function \(y = -f(x+1)\) is drawn in which of the following diagrams?

| > [figure: Decreasing function with decreasing gradient and x-intercept at -1 — `https://undergroundmathematics.org/combining-functions/r7119/images/diagrama.png`] (image not included in the text import; path of record). | > [figure: Decreasing function with increasing gradient and x-intercept at -1 — `https://undergroundmathematics.org/combining-functions/r7119/images/diagramb.png`] (image not included in the text import; path of record). |
| --- | --- |
| > [figure: Decreasing function with decreasing gradient and x-intercept at 1 — `https://undergroundmathematics.org/combining-functions/r7119/images/diagramc.png`] (image not included in the text import; path of record). | > [figure: Decreasing functioin with increasing gradient and x-intercept at 1 — `https://undergroundmathematics.org/combining-functions/r7119/images/diagramd.png`] (image not included in the text import; path of record). |

## Solution

The graph \(y = f(x+1)\) is a translation of the original graph by one unit to the left.

This is followed by a reflection in the \(x\)-axis to get \(y = -f(x+1)\), and so the answer is (a).

(Doing the reflection followed by the translation gives the same answer.)
