## Solution

In how many ways can you identify the equation of this parabola?

> [figure: Upward facing parabola passing through the points (0,4.5), (1.5,1.5), and (2,4.5) — `https://undergroundmathematics.org/combining-functions/name-that-graph-again/images/parabola-1.png`] (image not included in the text import; path of record).

In [Name that graph](https://undergroundmathematics.org/quadratics/name-that-graph) we thought about the three formats in which we can write a quadratic equation. We explored some of the ways in which the equation of a parabola could be determined in each of these three forms and the relative efficiency of each.

Here we have three coordinates specified on the parabola, but because the graph is not plotted accurately with a background grid, we cannot read any additional points from the diagram.

We could of course go through the laborious process of forming three equations, one from each of the specified points on the parabola, in \(a,b, c\) and solve them simultaneously. This will give an equation in the form \(y=ax^2+bx+c\).

We can eliminate \(b\) by doing \(1.5 \times\)\(\eqref{eq:5}\) - \(2\times\)\(\eqref{eq:4}\) so that we have, \[6 = 1.5a\] giving \[a = 4.\]

Substituting the value of \(a\) back into equation \(\eqref{eq:5}\) we have \[0 = 16 + 2b\] and so \[b = -8.\]

The equation of the parabola is therefore \[y = 4x^2 - 8x + 4.5.\]

 Using each of the three specified coordinates in turn we obtain three equations:

\[\begin{align} 4.5 = c\label{eq:1} \\ 1.5 = 2.25a + 1.5b + c\label{eq:2}\\ 4.5 = 4a + 2b + c\label{eq:3} \end{align}\]

 Substituting the value of

\(c\)

 from equation

\(\eqref{eq:1}\)

 into equations

\(\eqref{eq:2}\)

 and

\(\eqref{eq:3}\)

 and simplifying we have

\[\begin{align} -3 = 2.25a + 1.5b\label{eq:4} \\ 0 = 4a + 2b\label{eq:5} \end{align}\]

**Approach 1**

We could instead locate the line of symmetry and use this to find the equation of the parabola in completed square form.

We are given two horizontally aligned points on the parabola, \((0, 4.5)\) and \((2, 4.5)\). The line of symmetry will therefore be a vertical line located midway between these two points, i.e. the line \(x = 1\).

This means that the parabola can be written in the form \[y=a(x-1)^2 + e.\]

Solving simultaneously, by first eliminating \(e\) from equation \(\eqref{eq:7}\), we have \[3 = 0.75a = \frac{3}{4} a\] and so \[a = 4.\]

Notice that converting the decimal into a fraction makes it easier to see the solution.

Substituting the value of \(a\) back into equation \(\eqref{eq:7}\) we find that \(e=0.5\).

So we now know that the equation of the parabola is \[y = 4(x-1)^2 + 0.5.\]

It is sensible to check that this agrees with the equation obtained from approach \(1\).

Expanding we have \[y = 4x^2 - 8x + 4 + 0.5\] which simplifies to \[y=4x^2 - 8x + 4.5\] as expected.

 Substituting the points

\((0, 4.5)\)

 and

\((1.5, 1.5)\)

 into this equation we have the two equations:

\[\begin{align} 4.5 = a + e\label{eq:7} \\ 1.5 = 0.25a + e\label{eq:8} \end{align}\]

**Approach 2**

Making use of the diagram in “Have you thought about…” we could find the equation by considering a translation of the original parabola.

> [figure: Shows the previous parabola translated down by 4.5 so that it now passes through the points (0,0), (1.5,-3) and (2,0) — `https://undergroundmathematics.org/combining-functions/name-that-graph-again/images/parabola-1a.png`] (image not included in the text import; path of record).

We can find the equation of the red parabola in factorised form because we can see the location of the two \(x\)-intercepts: \[y=ax(x-2).\]

Substituting the third point on this translated parabola, \((1.5, -3)\) into the equation we can find the value of \(a\): \[-3 = 0.75a = \frac{3}{4} a\] and so \[a = 4.\]

So the equation of the red, translated parabola is \[y=4x(x-2).\] If we call the original blue parabola \(f(x)\) then the red parabola is \(f(x) - 4.5\).

We now have that \[f(x) - 4.5 = 4x(x-2).\] Rearranging we have that \[f(x) = 4x(x-2) + 4.5\] and then expanding we get \[f(x) = 4x^2 - 8x + 4.5.\] So the equation of the blue parabola is \[y = 4x^2 - 8x + 4.5\] as before.
