## What estimating means

![Flowchart of estimating steps: round to 1 significant figure, rewrite the calculation, use BIDMAS, apply quick facts, and check whether a calculator answer is sensible](../assets/001-9bc7329c-8e97-480b-ba91-8f4d30fc5124.jpeg)
An estimate is close to the exact answer, but not exact, and an approximation is the rounded or simplified value you use. In GCSE questions, you usually round each number to 1 significant figure unless another easy value is clearly better.

To round to 1 significant figure, find the first non-zero digit and look at the next digit to decide whether to round up or down. So $47.6$ rounds to $50$, $0.52$ rounds to $0.5$, $12.4$ rounds to $10$ and $0.184$ rounds to $0.2$.

A zero can be a placeholder, so small decimals do not round to zero just because they start with $0$. For example, $0.52$ to 1 significant figure is $0.5$, not $0$.

## Estimate first, then calculate

When estimating, round first and then rewrite the whole calculation with the easy numbers. Do not work out the exact answer before you estimate, because the aim is speed and sense-checking.

Estimate $\frac{47.8 \times 61.6}{12.1}$ by rounding first: $47.8 \to 50$, $61.6 \to 60$, and $12.1 \to 10$. The rounded calculation is shown below.

$$$\frac{50 \times 60}{10}$$ Now multiply the numerator and divide by the denominator: $50 \times 60 = 3000$ and $3000 \div 10 = 300$. So the estimate is $300$.

If the numerator contains addition, use BIDMAS and add before you divide. For example, $\frac{18.7 + 62.4}{0.19}$ becomes $\frac{20 + 60}{0.2}$, and dividing by $0.2$ is the same as multiplying by $5$, so the estimate is $400$.

## Roots, powers and calculator checks

When a calculation includes a square root, round to a nearby perfect square so the root is easy to evaluate. Perfect squares include $25$, $49$, $64$ and $100$.

Estimate $\frac{22.4 + \sqrt{101.2}}{0.48}$ by using $20$, $100$ and $0.5$. The rounded calculation is shown below:
$$\frac{20 + \sqrt{100}}{0.5} = \frac{20 + 10}{0.5} = 60$$
So the final estimate is $60$.

Powers are estimated in the same spirit, so $3.9^2$ can be treated as $4^2 = 16$. For example, $\frac{426.5}{14.8 + 3.9^2}$ is about $\frac{400}{10 + 16} = \frac{400}{26}$. Since $26$ is close to $30$, a calculator answer near $14$ is sensible, while $1.4$ is not.

## Underestimates and overestimates

![Comparison of fractions 50 over 8, 50 over 10 and 50 over 12 showing that a smaller denominator gives a larger value](../assets/002-0e13f001-3f3f-4da1-a201-d9f315e06ec3.jpeg)

An underestimate is too small and an overestimate is too large. In a positive multiplication, rounding every factor down gives an underestimate and rounding every factor up gives an overestimate.

Fractions need extra care because the denominator works in the opposite direction. If the denominator is rounded down, the whole fraction gets larger, so the estimate can become an overestimate.

For example, Maya's weekly pay can be estimated by $8 \times 40 = 320$, so about £320. Because £8.32 and 41 were both rounded down, this estimate is an underestimate.

## Estimating area

Area is measured in square units, so remember to finish with units such as m² or cm². For a circle, use $A = πr^2$ and replace π with 3 when you estimate.

A circle with radius 11.6 m can be estimated using $r ≈ 10$ m. The estimate is shown below:

$$A ≈ 3 × 10^2 = 300$ m²

This is an underestimate because both π and the radius were rounded down. If a shape has a cut-out, estimate each part and then subtract. For a 5.26 m by 3.18 m rectangle with a square of side 1.94 m removed, use $5 × 3 - 2^2 = 15 - 4 = 11$ m².

## Estimating rates and large totals

Rates often involve awkward units, so estimate each part with easy numbers and keep the structure of the calculation clear. This helps you see the scale of a very large answer before you reach for a calculator.

If a machine records one event every $58$ seconds, estimate with $60$ seconds per event, $400$ days per year and $20$ hours per day. One factor of $60$ cancels with the $60$ seconds per event, so the estimate is shown below.

$$$\frac{400 \times 20 \times 60 \times 60}{60} = 400 \times 20 \times 60 = 480000$$

So the machine records about $480000$ events in a year.

This answer is rough, but it is good enough to spot nonsense. If a calculator later gave $4800$ or $48$ million, your estimate would show that something had gone wrong.

## Check yourself

1. Round $0.52$ to 1 significant figure.

   - $$0.5$ ✔

   - $$0$

   - $$0.05$

   - $$0.6$

   _Explanation:_ $$0.52$ has first significant figure $5$, and the next digit is $2$ so it rounds down to $0.5$. The common wrong answer is $0$ because the zero before the decimal point is only a placeholder, not a significant figure.

2. A student gets two possible answers for $\frac{426.5}{14.8 + 3.9^2}$: $1.4$ or $14$. Which answer is sensible?

   - $$1.4$

   - $$14$ ✔

   - $$140$

   - $$26$

   _Explanation:_ Rounding gives about $\frac{400}{10 + 4^2} = \frac{400}{26}$, and this is roughly $\frac{400}{30} \approx 13$, so $14$ is the sensible answer. The common wrong answer is $1.4$, which is ten times too small and would usually come from a decimal point error or an incorrect calculator entry.

3. To estimate $\frac{80}{19.6}$, Ben uses $\frac{80}{20} = 4$. Compared with the exact answer, $4$ is an

   - underestimate ✔

   - overestimate

   - exact answer

   - impossible to tell

   _Explanation:_ The numerator stayed the same but the denominator was rounded up from $19.6$ to $20$, and a larger denominator makes the whole fraction smaller, so $4$ is an underestimate. The common wrong answer is overestimate because students notice the denominator got bigger but forget that bigger denominators make fractions smaller.
