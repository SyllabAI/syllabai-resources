## Three forms, one value

![Hundred square with 40 shaded and labels 40/100, 2/5, 0.4 and 40% showing equivalent amounts](../assets/001-dd5686e3-7f83-46ed-b724-0faf36874f7e.jpeg)

Fractions, decimals and percentages are three ways to describe the same part of a whole. The whole can be one complete shape, one full amount, or $100\%$.

A fraction uses a numerator and denominator, a decimal uses place value, and a percentage means out of 100. For example, $\frac{2}{5}$, $0.4$, and $40\%$ all represent the same amount.

When you need to compare values, convert them into the same form first. Decimals are often the quickest form for ordering or deciding which is larger.

## Decimals and percentages

To change a decimal to a percentage, multiply by $100$ and add the percent sign. To change a percentage to a decimal, divide by $100$.

Start with $0.37$. Multiply by $100$:
$$0.37 \times 100 = 37$$
so $0.37 = 37\%$.

Start with $7\%$. Divide by $100$:
$$7 \div 100 = 0.07$$
so $7\% = 0.07$.

Watch place value carefully. $0.3 = 30\%$, not $3\%$, because the decimal point moves two places.

## Fractions and decimals

A fraction bar means divide. If the denominator can be changed to $10$, $100$, or $1000$, that is often the quickest route to a decimal.

Start with $\frac{4}{5}$. Make tenths first:
$$\frac{4}{5} = \frac{8}{10} = 0.8$$
We multiplied numerator and denominator by $2$, so the value stayed the same.

For a decimal to a fraction, use place value. Since $0.025$ has three digits after the decimal point, it is thousandths:
$$0.025 = \frac{25}{1000} = \frac{1}{40}$$
after simplifying by $25$.

## Fractions to percentages

Because percentage means out of $100$, try to rewrite the fraction with a denominator of $100$. If that is awkward, convert the fraction to a decimal first and then multiply by $100$.

Start with the fraction $\frac{11}{20}$. We can make the denominator $100$ by multiplying both the numerator and the denominator by $5$: $$\frac{11}{20} = \frac{55}{100} = 55\%$$

You must change both parts of the fraction by the same factor. If you only change the denominator, you have changed the actual value of the fraction rather than finding an equivalent form.

## Comparing and ordering mixed forms

When forms are mixed, decimals are usually easiest to compare. Convert first, compare second, and then write the original values in order.

Start with $42\%$, $\frac{1}{2}$, $0.47$, $\frac{2}{5}$, and $0.405$. Convert the percentage and fractions: $$42\% = 0.42 \quad \frac{1}{2} = 0.5 \quad \frac{2}{5} = 0.4$$

Now compare using the same number of decimal places: $$0.400 < 0.405 < 0.420 < 0.470 < 0.500$$ So the original values in order are $\frac{2}{5}$, $0.405$, $42\%$, $0.47$, $\frac{1}{2}$.

## Exam technique and pitfalls

In a 2-mark comparison question, show one clean conversion line before you compare, such as $16\% = 0.16$. This makes your method easy to follow and can help you earn method marks.

Check place value carefully: $4\% = 0.04$, not $0.4$. If someone spends part and saves the rest, remember the whole is $1$ or $100\%$, so saved amount = whole - spent amount.

## Check yourself

1. Which value is equal to $0.08$?

   - 8% ✔

   - 0.8%

   - 80%

   - $$\frac{8}{10}$

   _Explanation:_ $$0.08$ is eight hundredths, so it is $\frac{8}{100}$, which is 8%. The common wrong answer 80% comes from moving the decimal point the wrong way; 80% is $0.8$, not $0.08$. Hint: Think about hundredths.

2. What is $0.025$ as a simplified fraction?

   - $$\frac{25}{100}$

   - $$\frac{1}{40}$ ✔

   - $$\frac{25}{1000}$

   - $$\frac{1}{25}$

   _Explanation:_ $$0.025$ has three decimal places, so it is $\frac{25}{1000}$, which simplifies to $\frac{1}{40}$. The common wrong answer $\frac{25}{100}$ treats $0.025$ as 25 hundredths, but it is 25 thousandths.

3. Maya saves 38% of her money. Leo spends $\frac{3}{5}$ of his money and saves the rest. Who saves more?

   - Maya

   - Leo ✔

   - They save the same amount

   - It cannot be decided

   _Explanation:_ Leo saves the rest, so he saves $1 - \frac{3}{5} = \frac{2}{5} = 40\%$. The common wrong answer Maya comes from comparing 38% with $\frac{3}{5}$ instead of first finding Leo's saved part.
