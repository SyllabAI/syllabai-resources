## Slopes and line equations

![Side-by-side coordinate graphs showing parallel lines with matching rise-run triangles and perpendicular lines meeting at a right angle](../assets/001-d8deba64-4b77-4509-9229-e4a81feba28d.jpeg)

Straight lines are easiest to compare when written in the form $y=mx+c$. In this form, $m$ represents the gradient and $c$ represents the y-intercept.

If the equation is not already in this form, you must make $y$ the subject first. For example, $6y=3x-12$ becomes $y=\frac{1}{2}x-2$, so the gradient is $\frac{1}{2}$.

Parallel lines have the same gradient, while perpendicular lines meet at a $90^{\circ}$ angle. In most coordinate geometry questions, your first goal is to determine the gradient correctly.

## Parallel lines keep the same gradient

Parallel lines are lines in a coordinate plane that never meet. In the standard $y=mx+c$ form, they always possess the exact same gradient.

Suppose a line is parallel to $y=-3x+8$ and passes through $(2,1)$. To find the equation, we start with $y=-3x+c$ and substitute the point: $1=-3(2)+c$, which simplifies to $c=7$.

The final equation is $y=-3x+7$. If no specific coordinate point is given, there are infinitely many parallel lines because any value of $c$ will produce a valid result.

## Perpendicular lines use the negative reciprocal

Perpendicular lines meet at a right angle. For ordinary straight lines written as $y=mx+c$, their gradients are negative reciprocals.

Negative reciprocal means flip the fraction and change the sign. So $4$ becomes $-\frac{1}{4}$, and $-\frac{2}{3}$ becomes $\frac{3}{2}$.

There is one special case to remember. A horizontal line like $y=4$ is perpendicular to a vertical line like $x=-1$, and a vertical line does not have a defined gradient.

## Worked example: rearrange, then find a perpendicular line

Start with the line $3x+6y=12$ and rearrange it before doing anything else. Subtract $3x$ to get $6y=-3x+12$, then divide by $6$ to get $y=-\frac{1}{2}x+2$.

Now the gradient is easy to read: $m=-\frac{1}{2}$. A perpendicular line must have a gradient of $2$, so if it passes through $(0,7)$, we begin with $y=2x+c$.

Substitute the point $(0,7)$: $7=2(0)+c$, so $c=7$. The required equation is $y=2x+7$.

## Using two points to find the gradient

If a line is given by two points, calculate the gradient first using $m=\frac{y_2-y_1}{x_2-x_1}$. Keep the order of the two points the same in the top and bottom of the fraction.

For points $(0,4)$ and $(6,7)$, the gradient is $m=\frac{7-4}{6-0}=\frac{1}{2}$. A perpendicular line therefore has gradient $-2$.

If that perpendicular line passes through $(1,5)$, use $y=-2x+c$. Substituting gives $5=-2(1)+c$, so $c=7$ and the equation is $y=-2x+7$.

## Stretch: solving for an unknown k

Sometimes a point includes an unknown like $k$. Write the gradient using $k$ first. Then set it equal to the gradient you need to find the value of that variable.

Suppose Line A passes through $(-1,2)$ and $(3,4)$. Its gradient is $m_A=\frac{4-2}{3-(-1)}=\frac{1}{2}$, so a perpendicular line must have gradient $-2$.

Now let Line B pass through $(2,5)$ and $(k,-1)$. We can express its gradient using the unknown variable $k$ as $m_B=\frac{-1-5}{k-2}=\frac{-6}{k-2}$.

By setting the two expressions equal, we get $\frac{-6}{k-2}=-2$. Solving the equation $-6=-2(k-2)$ gives $-6=-2k+4$, which results in $k=5$.

## Check yourself

1. What is the gradient of $2x+5y=10$?

   - $$-\frac{2}{5}$ ✔

   - $$2$

   - $$5$

   - $$10$

   _Explanation:_ Rearranging gives $5y=-2x+10$, then $y=-\frac{2}{5}x+2$, so the gradient is $-\frac{2}{5}$. The common wrong answer is $2$ because students sometimes read the coefficient of $x$ before making $y$ the subject. Hint: Get the equation into $y=mx+c$ form.

2. A line is perpendicular to $y=-\frac{2}{3}x+1$. What is its gradient?

   - $$\frac{2}{3}$

   - $$-\frac{3}{2}$

   - $$\frac{3}{2}$ ✔

   - $$-\frac{2}{3}$

   _Explanation:_ Perpendicular gradients are negative reciprocals, so $-\frac{2}{3}$ flips to $\frac{3}{2}$ and changes sign to positive. The common wrong answer is $-\frac{3}{2}$ because it flips the fraction but forgets to change the sign.

3. Line A passes through $(1,2)$ and $(3,8)$. Line B passes through $(-2,1)$ and $(0,7)$. What is their relationship?

   - Parallel ✔

   - Perpendicular

   - They are the same line

   - Neither parallel nor perpendicular

   _Explanation:_ Line A has gradient $\frac{8-2}{3-1}=3$ and Line B has gradient $\frac{7-1}{0-(-2)}=3$, so the gradients are equal and the lines are parallel. The common wrong answer is perpendicular, but perpendicular lines need negative reciprocal gradients, not equal ones.

4. Line A passes through $(-1,2)$ and $(3,4)$. Line B passes through $(2,5)$ and $(k,-1)$. If the lines are perpendicular, what is $k$?

   - $$5$ ✔

   - $$-1$

   - $$2$

   - $$8$

   _Explanation:_ Line A has gradient $\frac{4-2}{3-(-1)}=\frac{1}{2}$, so the perpendicular gradient is $-2$. For Line B, $\frac{-1-5}{k-2}=\frac{-6}{k-2}$, and solving $\frac{-6}{k-2}=-2$ gives $k=5$; the common wrong answer is $-1$ because it comes from using gradient $2$ instead of $-2$.
