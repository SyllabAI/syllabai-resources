## What a graphical solution means

On a graph, the x-axis is horizontal and the y-axis is vertical. The axes cross at the origin, and a point is written as $(x, y)$ so you always read the x-coordinate first and the y-coordinate second.

Each straight-line graph shows all the points that satisfy one equation. When two lines cross, that point satisfies both equations at the same time.

That is why the intersection gives the solution to simultaneous equations. If the crossing point is $(2, 3)$, you write the answer as $x = 2$ and $y = 3$.

## Drawing a line when y is already isolated

If an equation already has $y$ on its own, choose some $x$-values and work out the matching $y$-values. Two points are enough for a line, but three points help you spot mistakes.

For $y = 2x - 1$, choose $x = 0$, $x = 1$, and $x = 2$. The matching values are:

$$$\begin{aligned} x = 0 &\Rightarrow y = -1 \\ x = 1 &\Rightarrow y = 1 \\ x = 2 &\Rightarrow y = 3 \end{aligned}$$

Plot the points $(0, -1)$, $(1, 1)$, and $(2, 3)$. Then join them with a ruler to make the straight-line graph.

## Rearranging before you plot

Some equations are not ready to draw because $y$ is not isolated. Rearrange them so $y$ is on its own before choosing points.

For $2y - x = 6$, add $x$ to both sides and then divide by 2. This gives:

$$$2y - x = 6 \Rightarrow 2y = x + 6 \Rightarrow y = \frac{1}{2}x + 3$$

Now choose friendly $x$-values such as $0$, $2$, and $4$, because they give whole-number $y$-values. That produces the points $(0, 3)$, $(2, 4)$, and $(4, 5)$.

## Worked example: solve by drawing both lines

![Graph of y = -x + 4 and y = 1/2 x + 1 crossing at (2, 2) on labelled axes](../assets/001-02b8f365-e0d9-4739-a2f3-bf8050953f9e.jpeg)
To solve $y = -x + 4$ and $2y - x = 2$ graphically, draw both lines on the same axes and then read where they meet. The graph shows the intersection clearly, but it helps to see how each line was built.

For the first line, $y = -x + 4$, easy points are $(0, 4)$ and $(4, 0)$. Plot those points and join them with a straight line.

For the second equation, first rearrange it. This gives:
$$
2y - x = 2 \Rightarrow 2y = x + 2 \Rightarrow y = \frac{1}{2}x + 1
$$

Now use points such as $(0, 1)$, $(2, 2)$, and $(4, 3)$ and draw the second line. The lines intersect at $(2, 2)$, so the solution is $x = 2$ and $y = 2$, and a quick check gives $2 = -2 + 4$ and $2 \times 2 - 2 = 2$.

## Negative coordinates and no solution

Sometimes the intersection is left of the $y$-axis or below the $x$-axis, so one or both coordinates are negative. You still read the coordinate in the same order: $x$ first, then $y$.

If two lines are parallel, they never meet, so the simultaneous equations have no solution. This happens when the lines have the same slope but different intercepts.

Graphical answers depend on accuracy. Use a ruler, label the lines clearly, and if the crossing is between grid lines, give the best estimate you can.

## Check yourself

1. Two drawn lines intersect at $(2, 3)$. What is the solution of the simultaneous equations?

   - $$x = 2$, $y = 3$ ✔

   - $$x = 3$, $y = 2$

   - $$x = 2$, $y = 1$

   - $$x = 3$, $y = 5$

   _Explanation:_ Coordinates are written in the order $(x, y)$, so $(2, 3)$ means $x = 2$ and $y = 3$. The most common wrong answer is B because it swaps the coordinates. Read across for $x$, then up or down for $y$.

2. Which is the correct rearrangement of $2y - x = 2$?

   - $$y = x + 2$

   - $$y = \frac{1}{2}x + 1$ ✔

   - $$y = 2x + 1$

   - $$y = \frac{1}{2}x - 1$

   _Explanation:_ Add $x$ to both sides to get $2y = x + 2$, then divide every term by 2 to get $y = \frac{1}{2}x + 1$. A common wrong answer is A because it forgets to divide the x-term by 2 as well as the constant.

3. Stretch: Without drawing, which pair of equations has no solution?

   - $$y = x + 2$ and $y = -x + 2$

   - $$y = 2x - 1$ and $2y = 4x + 6$ ✔

   - $$y = \frac{1}{2}x + 3$ and $x + 2y = 6$

   - $$y = -x + 4$ and $y = x - 2$

   _Explanation:_ Parallel lines never intersect. In B, $2y = 4x + 6$ rearranges to $y = 2x + 3$, so both lines have the same slope 2 but different intercepts. A common wrong answer is A, but those lines have opposite slopes and actually meet at $(0, 2)$.
