## What is a surd?

A surd is an irrational root left in exact form, such as $\sqrt{2}$ or $\sqrt{5}$. A square root like $\sqrt{36}$ is not a surd because it simplifies exactly to $6$.

When simplifying, look for the largest square number factor inside the root. You may split multiplication, so $\sqrt{ab} = \sqrt{a}\sqrt{b}$ for positive numbers, but you must not split addition, so $\sqrt{9+16} \ne \sqrt{9}+\sqrt{16}$.

## Simplifying square roots

To simplify a square root, factor out the largest square number inside it. This keeps the answer in exact form and gets to the simplest surd quickly.

For $\sqrt{72}$, use $72 = 36 \times 2$, so $\sqrt{72} = \sqrt{36}\sqrt{2} = 6\sqrt{2}$. If there is a coefficient, simplify the root first, so $5\sqrt{45} = 5\sqrt{9 \times 5} = 5 \times 3\sqrt{5} = 15\sqrt{5}$.

You may split multiplication inside a root, but not addition. That is why $\sqrt{9+16} \ne \sqrt{9}+\sqrt{16}$.

## Expanding and squaring

When expanding brackets with surds, treat them like algebra terms, and remember that $\sqrt{a}\times\sqrt{a} = a$. Like surds can be added or subtracted only when the root part is the same.

For $(3+\sqrt{2})(2-\sqrt{2})$, write all four products: $6 - 3\sqrt{2} + 2\sqrt{2} - 2$. Then collect the integers and the like surds to get $4 - \sqrt{2}$.

For a squared bracket, write it as two identical brackets before expanding. So $(5-\sqrt{3})^2 = (5-\sqrt{3})(5-\sqrt{3}) = 25 - 5\sqrt{3} - 5\sqrt{3} + 3 = 28 - 10\sqrt{3}$.

## Rationalising denominators

![Flowchart showing 72 split into 36 times 2 to simplify square root 72 to 6 square root 2, and showing rationalising 1 over 2 plus square root 3 with the conjugate 2 minus square root 3](../assets/001-4780670d-c68f-4151-a162-7ec34695fbb5.jpeg)

Rationalising the denominator means rewriting a fraction so that no surd is left on the bottom. This process removes irrational values from the denominator to simplify the expression.

If the denominator is a single surd, multiply the top and bottom of the fraction by that same surd. For example: $$\frac{4+\sqrt{8}}{\sqrt{2}} \times \frac{\sqrt{2}}{\sqrt{2}} = \frac{4\sqrt{2}+\sqrt{16}}{2} = 2\sqrt{2}+2$$ The denominator becomes rational because $\sqrt{2} \times \sqrt{2} = 2$.

If the denominator has two terms, multiply by its conjugate, changing only the sign in the middle. This uses the difference of two squares to eliminate surds: $$\frac{4+\sqrt{3}}{2+\sqrt{3}} \times \frac{2-\sqrt{3}}{2-\sqrt{3}} = \frac{8-4\sqrt{3}+2\sqrt{3}-3}{1} = 5-2\sqrt{3}$$ This works because the denominator calculation is $(2+\sqrt{3})(2-\sqrt{3}) = 4-3 = 1$.

## Algebraic surds

The same rules work with letters, as long as the expressions under the square roots are non-negative in GCSE real-number questions. Conjugates still cancel the surd part because $(\sqrt{m}+\sqrt{n})(\sqrt{m}-\sqrt{n}) = m-n$.

Squared brackets still need the middle term, as shown in the expansion of this algebraic expression:

$$$(3p+\sqrt{q})^2 = (3p+\sqrt{q})(3p+\sqrt{q}) = 9p^2 + 3p\sqrt{q} + 3p\sqrt{q} + q = 9p^2 + 6p\sqrt{q} + q$$

Always keep answers exact, and only collect surd terms when the root part matches.

## Check yourself

1. Which expression is not a surd?

   - $$\sqrt{2}$

   - $$\sqrt{45}$

   - $$\sqrt{36}$ ✔

   - $$\sqrt{7}$

   _Explanation:_ $$\sqrt{36} = 6$, so it is rational and not a surd. A common wrong choice is $\sqrt{45}$, but although it is not in simplest form, it is still a surd because it simplifies to $3\sqrt{5}$, which is irrational.

2. Which expression is equal to $(5-\sqrt{3})^2$?

   - $$28-10\sqrt{3}$ ✔

   - $$25+3$

   - $$28+10\sqrt{3}$

   - $$22-5\sqrt{3}$

   _Explanation:_ The correct expansion is $25 - 5\sqrt{3} - 5\sqrt{3} + 3 = 28 - 10\sqrt{3}$. The most common wrong answer is $25+3$ because it squares the two terms separately and forgets the two middle terms.

3. Which expression is equal to $\frac{1}{\sqrt{5}-1}$ after rationalising the denominator?

   - $$\sqrt{5}+1$

   - $$\frac{\sqrt{5}+1}{4}$ ✔

   - $$\frac{\sqrt{5}-1}{4}$

   - $$\frac{1}{4}$

   _Explanation:_ Multiply by the conjugate: $\frac{1}{\sqrt{5}-1} \times \frac{\sqrt{5}+1}{\sqrt{5}+1} = \frac{\sqrt{5}+1}{5-1} = \frac{\sqrt{5}+1}{4}$. A common wrong answer is $\sqrt{5}+1$ because it forgets that the new denominator is $4$, not $1$.
