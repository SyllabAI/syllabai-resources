## What proportion means

The symbol $y \propto x$ means $y$ is proportional to $x$. In GCSE questions, you usually replace $\propto$ with an equation using a constant $k$.

For direct proportion, $y = kx$, so both variables scale by the same factor. For inverse proportion, $y = \frac{k}{x}$, so when one variable gets bigger, the other gets smaller.

Watch the wording carefully. If $A$ is directly proportional to the square of $B$, write $A = kB^2$, but if $P$ is inversely proportional to the cube of $Q$, write $P = \frac{k}{Q^3}$.

## The main method

Most proportion questions follow the same routine. First write the formula with $k$, then use the known pair of values to find $k$, then substitute the new value.

Keep the first variable named in the question on the left side of the equation. If the question says "$p$ is directly proportional to $q$", start with $p = kq$, not $q = kp$.

A quick check can save marks. In direct proportion, the answer should move in the same direction as the input, while in inverse proportion it should usually move in the opposite direction.

## Worked example: direct proportion

Example: $p$ is directly proportional to $q$. When $p=8$ and $q=20$, find $q$ when $p=14$. Start with $p = kq$.

Substitute $p=8$ and $q=20$. This gives $$8 = 20k$$ so $$k = \frac{8}{20} = \frac{2}{5}$$

Now use $p=14$ in the same formula. Then $$14 = \frac{2}{5}q$$ so $$q = 14 \div \frac{2}{5} = 35$$

The answer is $q=35$. That makes sense because in direct proportion, increasing $p$ from 8 to 14 should also increase $q$ from 20 to a larger value.

## Inverse proportion

If $m$ is inversely proportional to $n$, we write the relationship as $m = \frac{k}{n}$. As $n$ gets larger, $m$ gets smaller, and the product $mn$ always remains constant.

For example, if $m=18$ when $n=5$, find $m$ when $n=15$. We start by substituting the known values to find the constant $k$: $$18 = \frac{k}{5}$$ which gives $$k = 18 \times 5 = 90$$

Now substitute $n=15$ back into the formula: $$m = \frac{90}{15} = 6$$ This result is sensible because $n$ increased from 5 to 15, and in an inverse proportion, $m$ must decrease accordingly.

## Squares, cubes and square roots

The wording can add powers or roots, but the method stays the same. "$y$ directly proportional to $x^2$" means $y = kx^2$, while "$y$ inversely proportional to $x^3$" means $y = \frac{k}{x^3}$.

Square roots work in the same way. "$r$ directly proportional to the square root of $s$" becomes $r = k\sqrt{s}$, and "$p$ inversely proportional to the square root of $q$" becomes $p = \frac{k}{\sqrt{q}}$.

Example: if $r=10$ when $s=25$, then $$10 = k\sqrt{25} = 5k$$ so $k=2$.

If $r=6$, then $$6 = 2\sqrt{s}$$ so $\sqrt{s}=3$ and $s=9$. Remember that $\sqrt{s}$ means the positive square root in these questions.

## Recognising graphs and tables

![Four labelled graph shapes for proportional relationships: straight line through origin, parabola at origin, reciprocal curve, and reciprocal squared curve](../assets/001-8ddc41c1-8d27-4a8e-8a2e-e792ca4afe3b.jpeg)
Graph shapes help you recognise the formula before you calculate anything. A direct proportion $y \propto x$ is a straight line through the origin, while $y \propto x^2$ is a U-shaped curve with its vertex at the origin.

Inverse graphs are curved rather than straight. For positive $k$, $y \propto \frac{1}{x}$ has one branch in the first quadrant and one in the third, while $y \propto \frac{1}{x^2}$ has two branches above the x-axis, one on each side of the y-axis.

For tables, test which quotient stays constant. For example, if $x=2$ gives $y=24$ and $x=3$ gives $y=81$, only $y \div x^3$ stays equal to 3, so $y = 3x^3$.

## Check yourself

1. Which equation matches the statement "$P$ is inversely proportional to the cube of $Q$"?

   - $$P = kQ^3$

   - $$P = \frac{k}{Q^3}$ ✔

   - $$Q = \frac{k}{P^3}$

   - $$P = \frac{k}{3Q}$

   _Explanation:_ $$P = \frac{k}{Q^3}$ is correct because inverse proportion puts the expression involving $Q$ in the denominator, and "cube of $Q$" means $Q^3$. The common wrong answer A treats the relationship as direct proportion instead of inverse proportion.

2. $$y$ is inversely proportional to $x$. When $y=12$ and $x=4$, what is the value of $y$ when $x=6$?

   - 8 ✔

   - 18

   - 2

   - 72

   _Explanation:_ For inverse proportion, $y = \frac{k}{x}$. Using $12 = \frac{k}{4}$ gives $k=48$, so when $x=6$, $y = \frac{48}{6} = 8$. The common wrong answer B comes from treating the relationship as direct proportion, but if $x$ increases in an inverse proportion, $y$ should decrease.

3. A graph is a straight line but it crosses the y-axis at 4, not at the origin. What does this tell you?

   - It shows direct proportion because all straight lines are direct proportion.

   - It is not direct proportion because a direct proportion line must pass through the origin. ✔

   - It must show inverse proportion.

   - It must show $y \propto x^2$.

   _Explanation:_ Direct proportion graphs have the form $y = kx$, so when $x=0$, $y=0$ and the line must pass through $(0,0)$. The common wrong answer A forgets that being straight is not enough; missing the origin means it is not direct proportion.
