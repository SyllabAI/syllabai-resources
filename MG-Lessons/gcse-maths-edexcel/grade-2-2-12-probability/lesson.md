## Chance and the probability scale

![Probability scale from 0 to 1 with impossible, even chance and certain labelled, plus a fair spinner with sections P, Q, R, R](../assets/001-ac9ef164-9bbe-4e16-8f08-6b6c9d03451e.jpeg)

Probability measures how likely an event is, using a number from 0 to 1. A probability of $0$ means impossible, $1$ means certain, and $\frac{1}{2}$ means an even chance.

An outcome is one possible result, like rolling a 5, and an event is the outcome or group of outcomes you care about. If something happens at random, the result is not chosen on purpose.

If outcomes are equally likely, use the following formula to calculate probability:

$$$P(\text{event}) = \frac{\text{wanted outcomes}}{\text{total outcomes}}$$

Your answer should always be a value between $0$ and $1$.

## Counting equally likely outcomes

For simple GCSE questions, the skill is careful counting. Count the total number of equally likely outcomes first, then count how many match the event.

If a label repeats, each copy still counts as a separate outcome. For the cards $2, 4, 4, 5, 7, 8, 9$, there are $7$ cards altogether.

The number $4$ appears on $2$ cards, so $P(4) = \frac{2}{7}$. The odd cards are $5, 7, 9$, so $P(\text{odd}) = \frac{3}{7}$.

## Impossible, certain and strict inequalities

A fair six-sided die has outcomes $1, 2, 3, 4, 5, 6$. Some events are impossible, some are certain, and some sit between these on the probability scale.

Rolling an $8$ is impossible, so the probability is $0$. Rolling a number less than $7$ is certain, so the probability is $1$.

For a number greater than $3$, the wanted outcomes are $4, 5, 6$. That gives $3$ outcomes out of $6$, so $P(\text{number} > 3) = \frac{3}{6} = \frac{1}{2}$.

Be careful with inequality words. "Less than 3" means $1$ and $2$ only, so the value $3$ is not included in the event.

## Bags, boxes and "the rest"

In bags and boxes, each item counts as one outcome. Do not count colours, count the actual counters. A box contains $25$ counters, with $9$ red and $6$ blue, and the rest are green.

Start by finding how many counters are already known. First add the known counters: $9 + 6 = 15$. Then subtract from the total: $25 - 15 = 10$, so there are $10$ green counters.

Now use the rule $P(\text{green}) = \frac{10}{25} = \frac{2}{5}$. If there are no yellow counters at all, then $P(\text{yellow}) = 0$.

## Complements and tables

Sometimes you need the probability that something does not happen. This is known as the complement, and it is calculated using the formula $P(\text{not }A) = 1 - P(A)$.

In a raffle of $300$ tickets, Aisha owns $12$. The probability that she does not win is calculated by subtracting her tickets from the total: $\frac{300 - 12}{300} = \frac{288}{300} = \frac{24}{25}$.

Tables can show either counts or probabilities, so check which type you have first. If the table shows counts, you must add them all together to get the total denominator before creating a fraction.

If the table shows probabilities, the sum of all outcomes must add up to $1$. For example, if the probabilities for red, blue, and yellow are $0.25$, $0.15$, and $0.40$, then the probability for green is $1 - 0.80 = 0.20$.

## Check yourself

1. A fair spinner has 4 equal sections labelled P, Q, R and R. What is the probability of landing on R?

   - $$\frac{1}{4}$

   - $$\frac{1}{2}$ ✔

   - $$\frac{1}{3}$

   - $$\frac{2}{3}$

   _Explanation:_ There are 4 equal sections in total and 2 of them are labelled R, so the probability is $\frac{2}{4} = \frac{1}{2}$. The common wrong answer $\frac{1}{3}$ counts different letters instead of sections, but repeated labels still count as separate outcomes.

2. A fair die is rolled once. What is the probability of rolling a number less than 3?

   - $$\frac{1}{6}$

   - $$\frac{2}{6}$ ✔

   - $$\frac{3}{6}$

   - $$\frac{4}{6}$

   _Explanation:_ The numbers less than 3 are 1 and 2, so there are 2 wanted outcomes out of 6 in total. The common wrong answer $\frac{3}{6}$ includes 3, but "less than 3" does not include 3.

3. A bag contains 6 red, 4 blue, 5 yellow and 3 green counters. What is the probability of not picking blue?

   - $$\frac{14}{18}$ ✔

   - $$\frac{4}{18}$

   - $$\frac{3}{4}$

   - $$\frac{14}{4}$

   _Explanation:_ There are $18$ counters in total and $18 - 4 = 14$ of them are not blue, so the probability is $\frac{14}{18}$, which simplifies to $\frac{7}{9}$. The common wrong answer $\frac{4}{18}$ is the probability of blue, not not blue, and $\frac{3}{4}$ counts colours instead of counters.
