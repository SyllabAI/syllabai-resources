## Reading a function machine

![Function machine with input 6 passing through a multiply by 4 box and a subtract 2 box to give output 22, with 24 shown as the intermediate value](../assets/001-7fca96e2-658d-480d-872e-59418218aa03.jpeg)

A function machine is a quick way to show a rule. The input goes in on the left, each box tells you an operation, and the output comes out on the right.

Follow the arrows in order from left to right. If you change the order, you can get a different answer. In the example shown, input 6 becomes $24$ after multiplying by 4, and then $22$ after subtracting 2. So the machine turns 6 into 22.

## Finding an output from a rule

If the input is called $x$, the machine "multiply by 4, then subtract 2" has output $4x - 2$. This allows you to write the whole machine as one algebraic rule.

Worked example: when the input is $x = 6$, we first multiply by 4 to find the intermediate result:
$$6 \times 4 = 24$$

Next, we subtract 2 from that result to calculate the final value:
$$24 - 2 = 22$$

So the output is 22. Negative inputs use the same method, but you must watch the signs. For example, with "multiply by 4, then add 7", an input of $-2$ gives $-8$ and then a final output of $-1$.

## Working backwards to find the input

![Function machine with an unknown input passing through multiply by 6 then add 4 to give output 46, and reverse arrows showing subtract 4 then divide by 6 to find input 7](../assets/002-c5515383-f02e-4cce-84fb-9d32c4235c6d.jpeg)

When the output is known but the input is missing, work backwards through the machine. Undo the last box first, then undo the earlier boxes.

Example: the machine is "multiply by 6, then add 4" and the output is 46. Start at 46, subtract 4 to undo the addition, then divide by 6 to undo the multiplication. The calculations are shown below.

$$$46 - 4 = 42$$
$$42 \div 6 = 7$$

So the input was 7, and checking forwards confirms it by calculating $7 \times 6 + 4$.

## Division machines

A division box works like any other operation when you go forwards. For example, with "divide by 5, then add 3", an input of 40 gives $40 \div 5 = 8$ and then $8 + 3 = 11$.

To work backwards, undo add 3 first, then undo divide by 5 by multiplying by 5. If the output is 12, then $12 - 3 = 9$ and $9 \times 5 = 45$, so the input is 45.

This is a common exam trap. Division forwards means multiplication backwards.

## Finding a missing box

If one operation is missing, use the boxes you do know first. Do not compare the input straight to the output until those known boxes have been used.

Example: input 5 → add 10 → missing box → output 4. First use the known box: $5 + 10 = 15$.

Now ask, "What changes 15 into 4?" Since $15 - 11 = 4$, the missing box is "subtract 11".

## Worded rules as function machines

A worded rule can be turned into a function machine by spotting the starting amount and the repeated change. For a taxi fare of £3 plus £2 per mile, the boxes are "multiply miles by 2" and then "add 3".

For a 7-mile journey, $7 \times 2 = 14$ and $14 + 3 = 17$, so the fare is £17. If the fare is £19, work backwards: $19 - 3 = 16$ and $16 \div 2 = 8$, so the journey was 8 miles.

Temperature rules work the same way. For Celsius to Fahrenheit, the machine is "multiply by 1.8, then add 32".

## Check yourself

1. A machine says input $\rightarrow$ add 3 $\rightarrow$ multiply by 2 $\rightarrow$ output. What is the output when the input is 5?

   - 16 ✔

   - 13

   - 10

   - 8

   _Explanation:_ Correct because $5 + 3 = 8$ and $8 \times 2 = 16$. The common wrong answer B comes from multiplying first and then adding 3, but the arrows show add 3 happens before multiply by 2. Hint: Follow the arrows one box at a time.

2. A machine says input $\rightarrow$ multiply by 4 $\rightarrow$ add 8 $\rightarrow$ output. The output is 32. What was the input?

   - 0

   - 6 ✔

   - 8

   - 10

   _Explanation:_ Hint: Start at the output, not the input. Correct because you undo $+8$ first: $32 - 8 = 24$, then undo $\times 4$: $24 \div 4 = 6$. The common wrong answer 0 comes from dividing first and then subtracting, but when you work backwards you must reverse the order as well as the operation.

3. A machine says input $\to$ multiply by 2 $\to$ missing box $\to$ output. When the input is 7, the output is 9. What is the missing box?

   - add 2

   - subtract 5 ✔

   - divide by 2

   - subtract 2

   _Explanation:_ Correct because the known box changes 7 into 14, and $14 - 5 = 9$. The common wrong answer A compares 7 directly with 9, but you must use the known box before finding the missing one.

4. A machine says input → multiply by 4 → subtract 9 → output. Which input gives the same value for input and output?

   - 0

   - 3 ✔

   - 4

   - 9

   _Explanation:_ Correct because input 3 gives $3 \times 4 - 9 = 12 - 9 = 3$, so the output matches the input. The common wrong answer A comes from noticing that 0 stays 0 when multiplied, but the machine still subtracts 9, so the output would be $-9$.
