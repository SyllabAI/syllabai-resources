## What substitution means

![Annotated substitution example showing 2a + 5b with a = 6 and b = 4, arrows to 2(6) + 5(4), then to 12 + 20 = 32](../assets/001-e1597101-fb53-4ab3-afdc-8464501a7b80.jpeg)

Algebra uses letters to stand for numbers. Substitution means replacing each letter with its given number and then working out the value.

This is not the same as solving an equation. The values of the letters are already known, so your job is to substitute carefully and calculate accurately.

An expression is something like $4x + 5y$, and a formula is something like $A = lw$. When a number or letter touches another letter, it means multiply, so $7m$ means $7 \times m$ and $ab$ means $a \times b$.

## A first worked example

Suppose $a = 6$ and $b = 4$. To find $2a + 5b$, read it as $2 \times a + 5 \times b$.

Replace the letters first, and keep the structure of the expression the same. Writing this substitution line helps you avoid skipped steps.

$$2a + 5b = 2(6) + 5(4)$$

Now multiply, then add. Do not add 6 and 4 first because they are in different terms.

$$2(6) + 5(4) = 12 + 20 = 32$$

## Substitute, then use BIDMAS

Once the numbers are in place, calculate in the correct order. Use BIDMAS: brackets, indices, division and multiplication, then addition and subtraction.

Take $T = 4(k + 3) - 5$ when $k = 6$. Substitute first, before doing any arithmetic.

$$$T = 4(6 + 3) - 5$$

Work inside the bracket first, then multiply, then subtract. Notice that the 4 multiplies the whole bracket, not just the 6. $$T = 4(9) - 5 = 36 - 5 = 31$$

## Negative numbers and powers

If a substituted value is negative, put it in brackets so the minus sign stays attached to the number. This is the safest way to avoid sign mistakes.

For $p = -5$ and $r = -4$, substitute like this. The brackets show that each whole value is negative.

$$3p - 2r = 3(-5) - 2(-4)$$

Now calculate each part carefully. Since subtracting a negative is the same as adding, you get

$$3(-5) - 2(-4) = -15 - (-8) = -7$$

Powers need brackets too. Without them, $-5^2 = -25$ because the square happens before the minus sign.

$$(-5)^2 = 25$$

## Fractions and longer formulae

Some formulae include fractions, and the fraction bar means divide. After substituting, work out the top and the bottom separately before you divide.

Find $R$ when $R = \frac{p^2 - q^2}{2r}$, $p = 9$, $q = 3$ and $r = 4$. Substitute first and keep the whole fraction structure. $$R = \frac{9^2 - 3^2}{2(4)} = \frac{81 - 9}{8}$$

Now simplify the numerator, then divide. So the final value is $9$. $$R = \frac{72}{8} = 9$$ This kind of question mixes powers, subtraction and division, so neat working really matters.

## Check yourself

1. What does substitution mean in algebra?

   - Replace the letters with their given values and calculate ✔

   - Find the value of the letter that makes an equation true

   - Put the letters into alphabetical order

   - Collect like terms to simplify the expression

   _Explanation:_ Substitution starts with values that are already given, so you replace each variable and work out the result. Option B is the most common wrong answer because it describes solving an equation, which is a different skill.

2. Given $k = 6$, what is the value of $4(k + 3) - 5$?

   - 31 ✔

   - 22

   - 19

   - 11

   _Explanation:_ Substituting gives $4(6 + 3) - 5 = 4(9) - 5 = 31$. Option B is the most common wrong answer because it ignores the bracket and does $4 \times 6 + 3 - 5$ instead of multiplying the whole $(6 + 3)$ by 4. Hint: Evaluate the bracket before multiplying.

3. If $p = 6$, $q = 2$ and $r = -1$, what is the value of $\frac{p^2 - q^2}{2r}$?

   - -16 ✔

   - 16

   - -8

   - 8

   _Explanation:_ Substitute first: $\frac{6^2 - 2^2}{2(-1)} = \frac{36 - 4}{-2} = \frac{32}{-2} = -16$. Option B is the most common wrong answer because it forgets that $2r = 2(-1)$ is negative, so the final answer must be negative.
