## Original value and percentage change

![Bar models showing original value £80, increase to £100 and decrease to £60, with the £20 change highlighted and the formula percentage change = change/original × 100](../assets/001-fd5bf944-d416-4df8-84b5-d00c2a68f26d.jpeg)

A percentage change measures how much something goes up or down compared with the amount you started with. That starting amount is called the original value.

First find the change, then compare it with the original amount. Use this formula:

$$\text{percentage change} = \frac{\text{change}}{\text{original value}} \times 100$$

If the new value is bigger, it is an increase. If the new value is smaller, it is a decrease.

## Worked example: percentage increase

To find a percentage increase, work out how much larger the new amount is. Then divide by the original amount, not the new one.

A bill changes from $£1680$ to $£1764$. So the change is $£84$, because:
$$1764 - 1680 = 84$$

Now compare that $£84$ with the original $£1680$:
$$\frac{84}{1680} \times 100 = 5$$
To 1 decimal place, the answer is $5.0\%$ increase.

## Worked example: decrease and rounding

A decrease is found in the same way, but the new value is smaller than the original. Keep the full calculator answer until the very end, then round once to maintain precision.

An insurance cost falls from £386 to £354. The decrease is £32, because:
$$386 - 354 = 32$$

Now compare that £32 with the original £386:
$$\frac{32}{386} \times 100 \approx 8.290$$
To 1 decimal place, that is an 8.3% decrease.

For example, if sales fall from 14.8 million to 13.9 million, then:
$$\frac{0.9}{14.8} \times 100 \approx 6.081$$
To 3 significant figures, that is a 6.08% decrease.

## Profit and loss

Profit and loss questions use exactly the same method as percentage change. The original amount is the cost price, because that is what you paid at the start.

Aisha buys a flat for £185,000 and later sells it for £199,800. Her profit is:
$$199800 - 185000 = 14800$$

Now compare the profit with the cost price:
$$\frac{14800}{185000} \times 100 = 8$$
So Aisha makes an 8% profit.

If the selling price is smaller than the cost price, you have a loss instead. You still divide by the cost price, not the selling price.

## Multi-step selling question

Some questions hide the profit inside unit conversions and repeated sales. Convert units first so that everything matches before you calculate the percentage. Maya buys 1.2 kg of sweets for £2.40. First convert the mass:
$$1.2 \times 1000 = 1200 \, \text{g}$$

Each bag holds 200 g, so the number of bags is determined by dividing the total mass by the mass per bag:
$$1200 \div 200 = 6$$
Each bag sells for 50p, which is £0.50.

So the total selling money is calculated as follows:
$$6 \times 0.50 = 3.00$$
The profit is the difference between revenue and cost:
$$3.00 - 2.40 = 0.60$$

Finally compare the profit with the cost price to find the percentage increase:
$$\frac{0.60}{2.40} \times 100 = 25$$
So Maya makes a 25% profit.

## Check yourself

1. A price rises from $£240$ to $£300$. Which value is the original amount?

   - $$£240$ ✔

   - $$£300$

   - $$£60$

   - $$25\%$

   _Explanation:_ $$£240$ is the starting price, so it is the original amount. The most common wrong answer is $£300$, but that is the new value after the increase.

2. A yearly cost falls from £386 to £354. What is the percentage change to 1 decimal place?

   - 8.3% decrease ✔

   - 9.0% decrease

   - 8.3% increase

   - 32% decrease

   _Explanation:_ The change is £32 and the calculation is $\frac{32}{386} \times 100 \approx 8.290$, which rounds to 8.3% decrease. The most common wrong answer is 9.0% decrease, which comes from dividing by the new amount £354 instead of the original £386.

3. Maya buys 1.2 kg of sweets for £2.40, makes 6 bags, and sells each bag for 50p. What percentage profit does she make?

   - 20% profit

   - 25% profit ✔

   - 25% loss

   - 60% profit

   _Explanation:_ The total selling money is $6 \times 0.50 = 3.00$, so the profit is £0.60. Then $\frac{0.60}{2.40} \times 100 = 25$, and the most common wrong answer is 20% profit from dividing by £3.00 instead of the original cost price.
