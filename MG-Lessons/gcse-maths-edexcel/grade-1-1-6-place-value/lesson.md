## Digits, columns and value

![Place value chart showing 3,058.42 with columns from thousands to hundredths and labels 3000, 50 and 0.4](../assets/001-1dee1bff-9950-4f6e-a9f5-11bf8f1cece9.jpeg)

A number is made from digits, but each digit's value depends on its column. In $642$, the $6$ is worth $600$, the $4$ is worth $40$, and the $2$ is worth $2$.

Place value means reading columns such as thousands, hundreds, tens and ones. After the decimal point, the columns are tenths, hundredths, thousandths, and so on.

The same digit can have different values in different numbers. A $5$ in $50$ is worth $50$, but a $5$ in $500$ is worth $500$.

## Zeros as placeholders

A zero can hold an empty column so the other digits stay in the correct places. In $3,058$, the $0$ shows there are no hundreds, but it still matters.

To find a digit's value, count columns from the right: ones, tens, hundreds, thousands. In $5,096$, the $9$ is in the tens column, so its value is $90$.

If the question asks for the value, write the full amount, not just the digit. So the value of the $9$ is $90$, not $9$.

## Decimals and the decimal point

A decimal point separates the whole-number part from the part smaller than 1. The first place to the right is tenths, then hundredths, then thousandths.

In 42.6, the 6 is not in the ones column. It is in the tenths column, so its value is 0.6.

Adding zeros at the end of a decimal does not change its value. For example, $0.4 = 0.40 = 0.400$.

## Writing numbers from clues

A 5-digit number has the columns ten-thousands, thousands, hundreds, tens and ones. If 4 must be the thousands digit, it goes in the second column from the left.

One possible 5-digit number with 4 as the thousands digit, using 4 only once, is 24,056. The comma helps you read the number, but it is not a digit.

Figures means writing with digits instead of words. So 6.4 million is $6{,}000{,}000 + 400{,}000 = 6{,}400{,}000$.

## Ordering whole numbers and decimals

![Aligned decimal comparison showing 0.42 as 0.420, 0.402, 0.24 as 0.240, 0.024 and 0.204 with decimal points lined up](../assets/002-1e80faf5-19a8-4932-8e6b-6e61b33dcd45.jpeg)

To order whole numbers, compare from left to right, starting with the largest place value. For 128, 139, 170, 172 and 205, the 2 in the hundreds column makes 205 the largest.

Decimals work the same way, but it helps to make the decimal lengths match first. A longer decimal is not always larger, because $0.42 = 0.420$ and $0.24 = 0.240$.

For 0.42, 0.402, 0.24, 0.024 and 0.204, write them as $0.420, 0.402, 0.240, 0.024$ and $0.204$. The order from smallest to largest is $0.024, 0.204, 0.24, 0.402, 0.42$.

## Using number cards

When making the largest number from cards, put the biggest digits in the biggest place-value columns. Using 8, 1, 6 and 4 to make a 3-digit number, choose 8, 6 and 4 and place them as 864.

For the smallest two-digit plus two-digit sum, the tens digits matter most. With 9, 5, 2 and 1, put 1 and 2 in the tens columns, then 5 and 9 in the ones columns.

That gives a smallest sum of $15 + 29 = 44$, although $19 + 25 = 44$ also works. Decide first whether you need the largest or smallest answer, then fill the highest-value columns first.

## Check yourself

1. What is the value of the $7$ in $274$?

   - $$7$

   - $$70$ ✔

   - $$700$

   - $$27$

   _Explanation:_ The $7$ is in the tens column, so it is worth $7$ tens, which is $70$. The most common wrong answer is $7$, but that is the digit itself, not its value. Hint: Name the column first, then write what the digit is worth.

2. What is the value of the $6$ in $42.6$?

   - $$6$

   - $$0.6$ ✔

   - $$0.06$

   - $$60$

   _Explanation:_ The $6$ is the first digit to the right of the decimal point, so it is in the tenths column and is worth $0.6$. The most common wrong answer is $6$, but that treats the digit as if it were still in the ones column.

3. Which list is in order from smallest to largest?

   - 0.07, 0.7, 0.707, 0.77 ✔

   - 0.07, 0.707, 0.7, 0.77

   - 0.7, 0.07, 0.707, 0.77

   - 0.07, 0.7, 0.77, 0.707

   _Explanation:_ Hint: Add zeros at the end to make the decimal places match. Write them as $0.070$, $0.700$, $0.707$ and $0.770$, then compare from left to right. The most common wrong answer is B, but $0.700$ is smaller than $0.707$, so $0.7$ must come before $0.707$.

4. Using the cards 9, 5, 2 and 1 once each, what is the smallest possible value of a two-digit plus two-digit sum?

   - 44 ✔

   - 71

   - 80

   - 116

   _Explanation:_ To make the total as small as possible, put the smallest digits, 1 and 2, in the tens columns because tens are worth more than ones. A common wrong answer is 71, which can come from arrangements like $12 + 59$, but that wastes a 5 in a tens column and makes the total larger. Hint: Choose the tens digits before you choose the ones digits.
