## What inequalities mean

An inequality compares two values, and a variable such as $x$ or $n$ stands for a number. A solution is any value that makes the inequality true.

Read the sign from left to right. For example, $x < 4$ means less than 4, $x > 4$ means greater than 4, $x \le 4$ means less than or equal to 4, and $x \ge 4$ means greater than or equal to 4.

The extra line in $\le$ or $\ge$ means the end value is included. Without that line, the end value is not included.

## Listing integer values between limits

If a question says "integer", you can only use numbers with no decimal or fractional part, including negatives, zero, and positives.

For $-4 < n \le 2$, $n$ must be greater than $-4$ but less than or equal to $2$. That means $-4$ is not included, but $2$ is.

So the possible integer values are: -3, -2, -1, 0, 1, 2.

Writing them in order helps you avoid missing one.

## Reading and drawing number lines

A number line helps you show exactly which values are allowed. Open circles mean 'not included', and solid circles mean 'included'.

An arrow to the right means greater than, and an arrow to the left means less than. A thick line between two endpoints means every value between them works.

For $-2 \le x < 3$, put a solid circle at $-2$ and an open circle at $3$, then join them. For $x < 1$, use an open circle at $1$ and shade the line to the left.

## Solving simple inequalities

Solving an inequality is very similar to solving an equation. Do the same operation to both sides, and the sign stays the same while you add, subtract, multiply, or divide by a positive number. If there are brackets, expand them first.

Example: solve $3t + 5 \le 17$. Subtract 5 from both sides:

$$3t \le 12$$

Now divide both sides by 3:

$$t \le 4$$

So any value of $t$ up to 4 is a solution.

## Letters on both sides

When the variable appears on both sides, collect the variable terms on one side and the numbers on the other. It is usually best to keep the variable positive if you can.

Solve $5x + 1 \le 2x + 13$ by subtracting $2x$ from both sides:

$$3x + 1 \le 13$$

Then subtract 1:

$$3x \le 12$$

Now divide by 3 to get $x \le 4$. On a number line, this is represented by a solid circle at 4 with an arrow pointing to the left.

## When the sign reverses

The inequality sign only flips when you multiply or divide both sides by a negative number. It does not change when you just add or subtract.

Solve $5 > 17 - 3x$ by subtracting 17 from both sides:

$$-12 > -3x$$

Now you need to divide by -3.

Dividing by -3 reverses the sign, so:

$$4 < x$$

This is usually written as $x > 4$.

## Compound inequalities

A compound inequality has two signs, so the variable must fit between two end values. To solve it, do the same operation to all three parts.

For $3 \le 2y - 1 < 11$, add 1 to every part:
$$
4 \le 2y < 12
$$

Then divide every part by 2. This gives:
$$
2 \le y < 6
$$

If $y$ is an integer, the possible values are 2, 3, 4 and 5. The 2 is included, but 6 is not.

## Check yourself

1. Which statement correctly describes $x \ge -2$?

   - $$x$ is greater than or equal to -2 ✔

   - $$x$ is greater than -2 only

   - $$x$ is less than or equal to -2

   - $$x$ is less than -2 only

   _Explanation:_ $$\ge$ means "greater than or equal to", so -2 itself is included. The common wrong answer is B, which forgets that the extra line means the endpoint is allowed.

2. A number line has an open circle at 1 and an arrow pointing left. Which inequality does it represent?

   - $$x < 1$ ✔

   - $$x \le 1$

   - $$x > 1$

   - $$x \ge 1$

   _Explanation:_ The arrow points left, so the values are less than 1, and the open circle shows 1 is not included. The common wrong answer is B, which would need a solid circle at 1.

3. Solve the inequality: $4x - 3$ is greater than $x + 6$.

   - x is greater than 3 ✔

   - x is greater than 9

   - x is less than 3

   - x is less than 9

   _Explanation:_ Subtract x from both sides to get 3x minus 3 is greater than 6. Add 3 to both sides to get 3x is greater than 9. Divide both sides by 3. So the solution is all numbers greater than 3.

4. Why does the inequality sign change when solving $-12 > -3x$ for x?

   - Because 12 is larger than 3

   - Because you divided both sides by a negative number ✔

   - Because the variable starts on the right side

   - Because you subtracted the same amount from both sides

   _Explanation:_ An inequality changes direction only when you multiply or divide both sides by a negative number. Here, dividing by $-3$ reverses the inequality sign. Adding or subtracting the same number on both sides does not change its direction.
