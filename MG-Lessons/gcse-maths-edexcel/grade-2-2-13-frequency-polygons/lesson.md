# grade-2-2-13-frequency-polygons — lesson

_Lane: `gcse-maths-edexcel` · grade 2 · 4 content steps · 3 check questions (source: MathsGenie lessons)_

## Core idea

A frequency polygon is a graph for grouped data. The table usually uses a variable such as $t$, $w$ or $h$ to stand for time, weight or height.

Each class interval becomes one point. Plot the class midpoint on the x-axis and the frequency on the y-axis.

Find the midpoint with $\text{midpoint}=\frac{\text{lower end}+\text{upper end}}{2}$. For $20 < t \leq 30$, the midpoint is $25$. After plotting all the points, join neighbouring points with straight lines.

## Worked example: travel times

![Frequency polygon for travel times with Time on the horizontal axis and Frequency on the vertical axis showing six plotted points joined by straight lines](../assets/001-e4eb3fd0-11e6-4337-9825-b644c2de14f2.jpeg)

A travel-time table has intervals $0 < t \leq 10$, $10 < t \leq 20$, $20 < t \leq 30$, $30 < t \leq 40$, $40 < t \leq 50$ and $50 < t \leq 60$, with frequencies $12, 16, 23, 28, 13$ and $8$. The graph shows the finished frequency polygon for that table.

First find the midpoints: $\frac{0+10}{2}=5$, $\frac{10+20}{2}=15$, $\frac{20+30}{2}=25$, $\frac{30+40}{2}=35$, $\frac{40+50}{2}=45$ and $\frac{50+60}{2}=55$. Then pair midpoint with frequency to get $(5,12)$, $(15,16)$, $(25,23)$, $(35,28)$, $(45,13)$ and $(55,8)$.

Plot the six points carefully on axes labelled Time (minutes) and Frequency. Then join each point to the next with straight line segments, not bars or separate lines to the origin.

## Choosing scales on blank axes

Sometimes the grid is blank, so you must choose the scale yourself. Label the x-axis with the variable and units, and label the y-axis Frequency.

The y-axis should usually start at $0$ and extend beyond the largest frequency. The x-axis must use equal steps and include all the midpoints you need to plot.

If all the data values are much larger than $0$, the x-axis does not have to start at $0$. Use sensible jumps such as 5s, 10s or 20s so the graph is easy to read.

## Worked example: blank axes

Suppose plant heights are grouped as $140 < h \leq 150$ with frequency $6$, $150 < h \leq 160$ with frequency $21$, $160 < h \leq 170$ with frequency $32$, $170 < h \leq 180$ with frequency $27$ and $180 < h \leq 190$ with frequency $14$. First find the midpoints: $\frac{140+150}{2}=145$, $\frac{150+160}{2}=155$, $\frac{160+170}{2}=165$, $\frac{170+180}{2}=175$ and $\frac{180+190}{2}=185$.

Label the axes Height (cm) and Frequency. Because the largest frequency is $32$, a y-axis from $0$ to $35$ in 5s works well.

The class values run from $140$ to $190$, so an x-axis from $140$ to $190$ in 10s is sensible. Now plot $(145,6)$, $(155,21)$, $(165,32)$, $(175,27)$ and $(185,14)$, then join neighbouring points with a ruler.

## Check yourself

1. For the class interval $20 < t \leq 30$ with frequency $18$, which point should be plotted on a frequency polygon?

   - $$(20,18)$

   - $$(25,18)$ ✔

   - $$(30,18)$

   - $$(25,30)$

   _Explanation:_ The x-coordinate must be the class midpoint, so you average $20$ and $30$ to get $25$, then use the frequency $18$ as the y-coordinate. A common mistake is A, which uses the lower class end instead of the midpoint.

2. A table has midpoints from $145$ to $185$ and the largest frequency is $32$. Which axes are the best choice for a frequency polygon?

   - x-axis 140 to 190 in 10s, y-axis 0 to 35 in 5s ✔

   - x-axis 0 to 500 in 100s, y-axis 0 to 100 in 20s

   - x-axis 150 to 180 in 10s, y-axis 0 to 30 in 5s

   - x-axis 140 to 190 in 3s, y-axis 5 to 35 in 5s

   _Explanation:_ A includes every midpoint, starts frequency at 0, and uses simple equal steps that fit the data well. A common mistake is C, but it misses some x-values and the frequency 32 would not fit.

3. A grouped height table only uses values from $140$ cm to $190$ cm. Which statement about the axes is correct?

   - Both axes must start at 0.

   - The x-axis can start at 140, but the y-axis should usually start at 0. ✔

   - The y-axis can start at 10 if the x-axis starts at 0.

   - Neither axis needs labels if the points are correct.

   _Explanation:_ The frequency axis should usually start at 0 because frequency counts from zero upward, but the variable axis can start nearer the data if the scale is clear and evenly spaced. A common mistake is A, which wastes space and is not required for the x-axis.
