## Calculator rules that prevent easy errors

A calculator is fast, but it only follows what you type. Most mistakes come from missing brackets, typing a fraction badly, or rounding before the end.

An expression is a calculation such as $1.3^2 + 1.4^2$. Scientific calculators usually follow BIDMAS, which means brackets, indices, division and multiplication, then addition and subtraction.

If a question says "write down all the figures on the display", copy every digit your screen shows on your own calculator. If your calculator shows a fraction or root form first, switch to decimal display with a key such as S⇔D, F⇔D or ≈.

## Squares and square roots

A square means multiply a number by itself, so $1.25^2 = 1.25 \times 1.25$. A square root reverses this and asks for the positive number whose square gives the value.

For example, $\sqrt{2.89} = 1.7$ because $1.7^2 = 2.89$. Also, $1.15^2 = 1.15 \times 1.15 = 1.3225$.

Use the square root key for roots and the $x^2$ key for squares. Always check whether the square should apply to one number or to a whole bracket.

## Brackets first, then powers

Brackets tell the calculator which part of the expression should be done first. If you typed $4.25 - 0.36^2 - 8.104$, only $0.36$ would be squared, which changes the result significantly.

Work out $(4.25 - 0.36)^2 - 8.104$ by typing the bracketed part first. Inside the brackets, $4.25 - 0.36 = 3.89$, so the squared part becomes $3.89^2 = 15.1321$.

Now subtract $8.104$ from the squared result: $15.1321 - 8.104 = 7.0281$. The final figures displayed on the calculator should be $7.0281$.

## Fractions and roots in one expression

![A labelled diagram of a square root sign enclosing a fraction with numerator 21.8 minus 4.28 and denominator 6.10 plus 1.20](../assets/001-090fc23e-1f1d-4597-ac27-287cbe14b379.jpeg)

For a fraction, use the fraction template if your calculator has one. If you use the division key instead, bracket the whole denominator so the whole bottom line stays together.

In $\sqrt{\frac{21.8 - 4.28}{6.10 + 1.20}}$, the numerator is $21.8 - 4.28 = 17.52$ and the denominator is $6.10 + 1.20 = 7.30$. So the value inside the root is $17.52 \div 7.30 = 2.4$.

Now find $\sqrt{2.4}$, which gives a typical display of $1.549193338$. Write all the digits shown on your own display, and switch to decimal mode first if the calculator shows an exact form.

## Round only at the end

Do not round halfway through a calculation, because a small error can grow in the later steps. Keep the full calculator value until the final answer, then round only if the question asks you to.

For $\frac{\sqrt{11.56 - 5.31}}{2.6^2}$, the display is about $0.3698224852$. To 2 decimal places, keep $0.36$ for now and look at the next digit, which is $9$, so the answer is $0.37$.

For $\frac{12.34 + \sqrt{8.41}}{5.2 \times 3.7}$, the display is about $0.7920997921$. To 2 significant figures, keep $7$ and $9$; the next digit is $2$, so the rounded answer is $0.79$.

## Trig keys: check DEG first

Before using $\sin$, $\cos$ or $\tan$, check that your calculator is in degree mode. In IGCSE questions the screen should usually show DEG.

For $\frac{\sin 30^\circ + \cos 60^\circ}{\cos 45^\circ - \sin 30^\circ}$, the numerator is $0.5 + 0.5 = 1$. The denominator is about $0.7071067812 - 0.5 = 0.2071067812$.

So the value is about $1 \div 0.2071067812 = 4.828427125$, which rounds to $4.83$ to 2 decimal places. If the calculator is in radians, the answer will be wrong even if every bracket is correct.

## Check yourself

1. A question says "write down all the figures on your calculator display" and your screen shows 4.282258065. What should you write?

   - 4.28

   - 4.282258065 ✔

   - 4.2823

   - 4.2822581

   _Explanation:_ You should copy exactly what the display shows, so $4.282258065$ is correct. The common wrong answer $4.28$ rounds to 2 decimal places, but the question did not ask for rounding.

2. Which calculator entry matches $(4.25 - 0.36)^2 - 8.104$?

   - $$4.25 - 0.36^2 - 8.104$

   - $$(4.25 - 0.36)^2 - 8.104$ ✔

   - $$(4.25 - 0.36 - 8.104)^2$

   - $$4.25 - (0.36^2 - 8.104)$

   _Explanation:_ The square must apply to the whole bracket, so option B is the only correct entry. The common wrong choice A squares only $0.36$, which changes the expression completely.

3. Stretch: A calculator display shows $0.046718293$. Rounded to 2 significant figures, what is the answer?

   - 0.05

   - 0.047 ✔

   - 0.046

   - 0.0467

   _Explanation:_ The first two significant figures are 4 and 6, and the next digit is 7, so $0.046718293$ rounds to $0.047$. The common wrong answer $0.05$ ignores that the leading zeros are not significant and rounds too far.
