## What inequalities tell us

An equation gives one exact answer, such as $x = 4$. An inequality compares values and usually gives a range of answers, such as $x < 4$.

The symbols mean: $<$ less than, $>$ greater than, $\le$ less than or equal to, and $\ge$ greater than or equal to. A number is a solution if it makes the inequality true.

The signs $<$ and $>$ are strict, so the endpoint is not included. The signs $\le$ and $\ge$ are inclusive, so the endpoint is included.

## Listing integer solutions

An integer is a whole number, including negative numbers and zero. If a question says the variable is an integer, you only list whole-number values that satisfy the inequality.

Example: if $-3 \le n < 2$, start at -3 because $\le$ includes it. Stop before 2 because $<$ is strict.

So the possible values are $n = -3, -2, -1, 0, 1$. Checking both endpoints first helps you avoid missing or adding a value.

## Solving linear inequalities

You solve most linear inequalities just like equations: use inverse operations and keep both sides balanced. If there are brackets, expand them first, and if the variable is on both sides, collect the variable terms onto one side.

Example: solve $5x - 6 \le 2x + 9$. Subtract $2x$ from both sides to get $3x - 6 \le 9$, then add 6 to get $3x \le 15$.

Now divide by 3 to get $x \le 5$. On a number line, this means a filled circle at 5 and shading to the left.

## The sign changes with negatives

There is one extra rule for inequalities: if you multiply or divide both sides by a negative number, reverse the inequality sign. This is the step students forget most often.

Example: solve $5 > 17 - 3x$. Subtract 17 from both sides to get $-12 > -3x$.

Now divide by -3 and reverse the sign to get $4 < x$. This is usually written as $x > 4$.

## Solving double inequalities

A double inequality has the variable between two bounds, such as $-2 < x \le 5$. Both parts must be true at the same time.

When solving, do the same operation to all three parts. For $3 \le 2y - 1 < 11$, add 1 everywhere to get $4 \le 2y < 12$.

Now divide all three parts by 2 to get $2 \le y < 6$. If $y$ is an integer, the possible values are $2, 3, 4, 5$.

## Check yourself

1. Which inequality represents all numbers up to and including 3?

   - $$x < 3$

   - $$x \le 3$ ✔

   - $$x > 3$

   - $$x \ge 3$

   _Explanation:_ $$x \le 3$ includes 3 itself and every smaller number. The common wrong answer is $x < 3$, but that is a strict inequality, meaning 3 is not included. Hint: Inclusive inequalities include the endpoint.

2. $$n$ is an integer and $-2 < n \le 2$. Which list gives all possible values of $n$?

   - $$-2, -1, 0, 1, 2$

   - $$-1, 0, 1, 2$ ✔

   - $$-1, 0, 1$

   - $$-2, -1, 0, 1$

   _Explanation:_ $$-2 < n$ means -2 is not allowed, while $n \le 2$ means 2 is allowed, so the full list is $-1, 0, 1, 2$. The common wrong answer is A, which incorrectly includes -2.

3. Which is the correct solution to $7 - 2(x - 1) \ge 3x + 5$?

   - $$x \le \frac{4}{5}$ ✔

   - $$x \ge \frac{4}{5}$

   - $$x \le -\frac{4}{5}$

   - $$x \ge -\frac{4}{5}$

   _Explanation:_ Expand first: $7 - 2(x - 1) = 9 - 2x$, so $9 - 2x \ge 3x + 5$. Rearranging gives $4 \ge 5x$, so $x \le \frac{4}{5}$. The common wrong answer is B, which comes from rewriting $4 \ge 5x$ the wrong way round; dividing by positive 5 does not flip the sign. Hint: Expand the bracket before collecting the $x$ terms.
