## Reading straight lines

![Coordinate grid with two parallel lines of gradient 2 and a perpendicular line of gradient minus one half, with a right angle marked](../assets/001-bc18b5a5-7380-4ae2-bc8c-e024006c74fa.jpeg)

Most straight-line questions become easier when the equation is written as $y = mx + c$. Here, $m$ is the gradient, which tells you how steep the line is, and $c$ is the $y$-intercept, so the line crosses the $y$-axis at $(0, c)$.

Parallel lines have the same gradient, so they run in the same direction and never meet. Perpendicular lines meet at $90^\circ$, and for non-horizontal lines their gradients are negative reciprocals: if one line has gradient $m$, the perpendicular line has gradient $-\frac{1}{m}$.

In the diagram, lines A and B both have gradient $2$, so they are parallel. Line C has gradient $-\frac{1}{2}$, and since $2 \times \left(-\frac{1}{2}\right) = -1$, it is perpendicular to them.

## Writing parallel lines

Parallel lines always keep the same gradient. If a line is parallel to $y=\frac{1}{2}x+6$, start by writing $y=\frac{1}{2}x+c$.

If the new line passes through $(0,-3)$, you can read off the intercept immediately because points on the y-axis have $x=0$. So the equation becomes $y=\frac{1}{2}x-3$.

If the given point is not on the y-axis, keep the same gradient and then substitute the point to find $c$. A common mistake is changing the gradient, but that would make the new line point in a different direction.

## Writing perpendicular lines

Perpendicular lines meet at a right angle. For non-horizontal lines, their gradients are negative reciprocals, which is the same as saying $m_1m_2=-1$. A horizontal line such as $y=4$ is perpendicular to a vertical line such as $x=2$.

Example: find the line perpendicular to $y=\frac{1}{4}x-5$ through $(0,6)$. The original gradient is $\frac{1}{4}$, so the perpendicular gradient is $-4$.

Write the new equation as $y=-4x+c$. Because the point provided is $(0,6)$, the y-intercept $c$ must be $6$, resulting in the final equation $y=-4x+6$.

## Rearranging before comparing

Some equations do not show the gradient straight away. Before comparing lines, rearrange until the equation is in the form $y=mx+c$.

For $2x+5y=10$, move $2x$ first and then divide every term by 5. This shows the gradient without guessing.

$$$2x+5y=10 \Rightarrow 5y=-2x+10 \Rightarrow y=-\frac{2}{5}x+2$$

Now you can see that the gradient is $-\frac{2}{5}$. A line parallel to this one keeps that gradient, while a perpendicular line would have gradient $\frac{5}{2}$.

## Using two points to find the line

If you are given two points instead of an equation, first find the gradient using $m=\frac{y_2-y_1}{x_2-x_1}$. This tells you the gradient a parallel line must keep.

Example: Line A passes through $(2,1)$ and $(6,13)$.
$$m=\frac{13-1}{6-2}=\frac{12}{4}=3$$
So a parallel line has the form $y=3x+c$.

If the new line passes through $(3,4)$, substitute that point into the equation.
$$4=3(3)+c \Rightarrow c=-5$$
Because the point is not on the y-axis, you must calculate $c$ rather than read it off. So the equation is $y=3x-5$.

## Missing values and proof questions

In missing-value questions, write the gradient using the unknown coordinate and then use the rule for parallel or perpendicular lines. In show that questions, calculate both gradients and then finish with a sentence saying why the lines are parallel or perpendicular.

Example: Line A passes through $(2,7)$ and $(5,1)$.
$$m_A=\frac{1-7}{5-2}=\frac{-6}{3}=-2$$
So a perpendicular line must have gradient $\frac{1}{2}$.

If Line B passes through $(-1,3)$ and $(k,5)$, then
$$m_B=\frac{5-3}{k-(-1)}=\frac{2}{k+1}$$
and $\frac{2}{k+1}=\frac{1}{2}$. Solving gives $4=k+1$, so $k=3$.

## Check yourself

1. For the line $y=4x-7$, which statement is correct?

   - Gradient 4 and y-intercept -7 ✔

   - Gradient -7 and y-intercept 4

   - Gradient 4 and y-intercept 7

   - Gradient -4 and y-intercept -7

   _Explanation:_ Compare $y=4x-7$ with $y=mx+c$. The number multiplying $x$ is 4, so the gradient is 4, and the constant term is -7, so the y-intercept is -7. The most common wrong answer is C, which ignores the negative sign on the intercept.

2. A line is perpendicular to $y=-3x+2$. What is its gradient?

   - 3

   - $$-\frac{1}{3}$

   - $$\frac{1}{3}$ ✔

   - -3

   _Explanation:_ The gradient of the given line is $-3$. Its reciprocal is $-\frac{1}{3}$, and changing the sign gives the negative reciprocal $\frac{1}{3}$. The most common wrong answer is B, which flips the number but forgets to change the sign.

3. Line A passes through $(1,4)$ and $(5,6)$. Line B passes through $(-2,3)$ and $(0,-1)$. How are the lines related?

   - Parallel

   - Perpendicular ✔

   - The same line

   - Neither parallel nor perpendicular

   _Explanation:_ Line A has gradient $\frac{6-4}{5-1}=\frac{1}{2}$. Line B has gradient $\frac{-1-3}{0-(-2)}=\frac{-4}{2}=-2$, and $\frac{1}{2}\times(-2)=-1$, so the lines are perpendicular. The most common wrong answer is D, which happens when you find both gradients but forget to check the negative reciprocal rule.
