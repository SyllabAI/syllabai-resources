## Place value and column methods

Addition combines amounts, and subtraction takes one amount away from another. In a column method, matching place values must line up, so ones go under ones, tens under tens, and so on.

In $58.26$, the 5 is worth 50, the 2 is worth 2 tenths, and the 6 is worth 6 hundredths. The answer to an addition is the sum or total, and the answer to a subtraction is the difference.

If a column totals 10 or more, write the digit for that column and carry the extra tens into the next column. If the top digit is too small in subtraction, exchange 1 from the next column so it becomes 10 of the smaller place value.

## Adding whole numbers

To add whole numbers, start at the ones column and work right to left. It is sensible to estimate first: $370 + 70 \approx 440$, so the final answer should be close to 440.

For $368 + 74$, add the ones first: $8 + 4 = 12$. Write 2 in the ones column and carry 1 ten, then add the tens: $6 + 7 + 1 = 14$. Write 4 in the tens column and carry 1 hundred.

Now add the hundreds: $3 + 1 = 4$, so
$$368 + 74 = 442$$
The estimate shows 442 is reasonable.

## Subtracting whole numbers

To subtract in columns, line up place values and start with the ones. For $3740 - 526$, it helps to think of 526 as 0526 so every column is present.

In the ones column, $0 - 6$ cannot be done, so exchange 1 ten from the 4 tens. The 4 tens becomes 3 tens and the 0 ones becomes 10 ones, so $10 - 6 = 4$.

Now subtract the tens and hundreds: $3 - 2 = 1$ and $7 - 5 = 2$. Then $3 - 0 = 3$, which completes the process.

$$$3740 - 526 = 3214$$
After an exchange, remember the original column is 1 smaller.

## Decimals and money

![Place value chart with 58.26 and 4.87 lined up by decimal point and matching columns labelled](../assets/001-a01b4c7f-38be-4017-8aee-297d53e72b7b.jpeg)
When adding or subtracting decimals, line up the decimal points, not the right-hand ends. Placeholder zeros do not change value, so $62 = 62.0 = 62.00$.

For $58.26 + 4.87$, start at the hundredths where $6 + 7 = 13$. Write 3 in the hundredths and carry 1 tenth, then add the tenths: $2 + 8 + 1 = 11$. Then add the ones and tens: $8 + 4 + 1 = 13$ and $5 + 1 = 6$.

$$$58.26 + 4.87 = 63.13$$
The decimal point stays in line throughout the calculation. Money works in the same way as decimals, but final answers are usually written to two decimal places. For example, £6.5 is usually written as £6.50.

## Longer calculations with addition and subtraction

In a longer calculation with only addition and subtraction, keep the sign with each number. It is often helpful to write every number to the same number of decimal places first: $64.50 - 18.23 - 7.40 + 25.00$. Now group the amounts being added and the amounts being subtracted.

Here, $64.50$ and $25.00$ are positive, while $18.23$ and $7.40$ are being taken away. Add the positive numbers and the negative numbers separately to make the final step clearer. $$64.50 + 25.00 = 89.50$$ $$18.23 + 7.40 = 25.63$$

Finally, subtract the total taken away from the total added: $$89.50 - 25.63 = 63.87$$ A common mistake is to lose a minus sign, but the sign belongs with the number next to it.

## Check yourself

1. When setting out $58.26 + 4.87$ in columns, what must be in the same vertical line?

   - The decimal points ✔

   - The last digits

   - The first digits

   - Only the tens digits

   _Explanation:_ Decimal points must line up so ones, tenths, and hundredths match correctly. A common wrong choice is B, but lining up the last digits can shift place values and give a wrong answer.

2. In $3740 - 526$, after you exchange to do $0 - 6$, what should the tens column become?

   - 4 tens

   - 3 tens ✔

   - 14 tens

   - 40 tens

   _Explanation:_ Exchanging 1 ten gives 10 ones, so the tens column loses 1 and becomes 3 tens. A common wrong choice is A, but that forgets to reduce the tens after the exchange. If one ten is moved to the ones column, there are $4 - 1 = 3$ tens left.

3. Which expression is equivalent to $64.5 - 18.23 - 7.4 + 25$?

   - $$(64.5 + 25) - (18.23 + 7.4)$ ✔

   - $$(64.5 - 25) - (18.23 + 7.4)$

   - $$(64.5 + 18.23) - (7.4 + 25)$

   - $$(64.5 + 25 + 18.23) - 7.4$

   _Explanation:_ A is correct because the positive numbers are $64.5$ and $25$, and the negative numbers are $18.23$ and $7.4$. A common wrong choice is B, but that changes $+25$ into $-25$, which changes the calculation.
