## Why graphs solve simultaneous equations

![Graph of the lines $y = x + 1$ and $x + 2y = 8$ crossing at the point $(2, 3)$](../assets/001-b12d134e-2b34-4c3f-a707-08763f8386d2.jpeg)

Each straight-line equation represents a line on a graph. The solution to two simultaneous equations is the point that lies on both lines.

When the lines intersect, that ordered pair satisfies both equations at the same time. Write the answer as $(x, y)$, or as separate values of $x$ and $y$.

## Read coordinates in the right order

A point is written as $(x, y)$. Read across for $x$ first, then up or down for $y$.

If a crossing is at $(2, 3)$, then $x = 2$ and $y = 3$, not the other way round. Every point on a line makes that equation true, so the intersection makes both equations true.

## From equation to plotted points

To draw a straight line from an equation, rearrange it so $y$ is the subject if that makes plotting easier. For $3y - x = 6$, this becomes:

$$$3y - x = 6,\quad 3y = x + 6,\quad y = \frac{x}{3} + 2$$

Choose friendly x-values that make the arithmetic easy. Using $x = -3, 0, 3, 6$ gives $y = 1, 2, 3, 4$, so you can plot $(-3, 1)$, $(0, 2)$, $(3, 3)$ and $(6, 4)$.

## Worked example: draw both lines

![Graph of the lines 3y - x = 6 and y = -x + 4 crossing at the point (1.5, 2.5)](../assets/002-ca1a2b2a-d63d-42a5-a776-ad523fc4ac77.jpeg)

Now solve $3y - x = 6$ and $y = -x + 4$ on the same grid. The first line is $y = \frac{x}{3} + 2$, so one good set of points is $(-3, 1)$, $(0, 2)$, $(3, 3)$ and $(6, 4)$.

For the second line, use easy points from $y = -x + 4$: $(0, 4)$, $(2, 2)$ and $(4, 0)$. Plot both sets on the same axes, draw straight lines with a ruler, and label each line clearly.

## Read carefully and check

Read the intersection carefully. Here the lines cross halfway between $x = 1$ and $x = 2$, and halfway between $y = 2$ and $y = 3$, so the graphical solution is $(1.5, 2.5)$.

You can check it by substitution: $y = -1.5 + 4 = 2.5$ and $3(2.5) - 1.5 = 6$. Both lines must be on the same grid, and parallel lines give no solution because they never meet.

## When the graph is already drawn

Sometimes the graph is already drawn for you. Drop vertically from the crossing to read $x$, then move horizontally to the y-axis to read $y$.

If $y = 3x - 2$ and $y = x + 4$ meet at $(3, 7)$, a quick check is $3(3) - 2 = 7$ and $3 + 4 = 7$. Substituting the x-value into both equations confirms that your graph reading is sensible.

## Check yourself

1. The lines $y = x + 1$ and $x + 2y = 8$ cross at $(2, 3)$. What is the solution of the simultaneous equations?

   - $$x = 2,\ y = 3$ ✔

   - $$x = 3,\ y = 2$

   - $$(1, 4)$

   - $$y = x + 1$

   _Explanation:_ The intersection gives the values that satisfy both equations, so the answer is $x = 2,\ y = 3$. The most common mistake is B, which swaps the coordinate order; in $(2, 3)$, the first number is $x$ and the second is $y$.

2. Which set of x-values is most convenient for plotting $y = \frac{x}{3} + 2$?

   - $$-3, 0, 3, 6$ ✔

   - $$1, 2, 4, 5$

   - $$-1, 1, 2, 5$

   - $$0, 1, 2, 3$

   _Explanation:_ Multiples of 3 make $\frac{x}{3}$ an integer, so the y-values are quick to calculate. A common wrong answer is D because it looks simple, but it gives awkward fractions such as $y = \frac{7}{3}$ when $x = 1$.

3. After drawing $3y - x = 6$ and $y = -x + 4$, what is the graphical solution?

   - $$(1.5, 2.5)$ ✔

   - $$(2.5, 1.5)$

   - $$(2, 2)$

   - $$(1, 3)$

   _Explanation:_ The lines cross halfway between $x = 1$ and $x = 2$, and halfway between $y = 2$ and $y = 3$, so the solution is $(1.5, 2.5)$. The common wrong answer is B, which swaps the coordinates; C is a point on $y = -x + 4$ but not on $3y - x = 6$.

4. Which pair of equations has no graphical solution?

   - $$y = 2x + 1$ and $y = 2x - 3$ ✔

   - $$y = x + 2$ and $y = -x + 2$

   - $$y = 3x$ and $y = 3x$

   - $$y = x - 1$ and $y = 2x - 1$

   _Explanation:_ A has the same gradient but different y-intercepts, so the lines are parallel and never meet. The common wrong answer is C, but those equations describe the same line, so they have infinitely many shared points rather than no solution.
