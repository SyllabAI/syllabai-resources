## Three forms, one value

![Number line from 0 to 1 labelled with equivalent values 1/4, 0.25, 25%, 1/2, 0.5, 50%, 3/4, 0.75, 75%, and 1, 100%](../assets/001-0f235a8e-b7e5-492e-8e60-ba07cef0c7ad.jpeg)

A fraction, decimal and percentage can represent the same part of a whole. They are equivalent if they have the same value, even when they look different.

On the number line, $\frac{1}{2}$, 0.5 and 50% all land at the same point. In a fraction, the top number is the numerator and the bottom number is the denominator.

A percentage means "out of 100", so 23% is the same as $\frac{23}{100}$. When you convert between forms, the amount stays the same and only the writing changes.

## Decimal place value and fractions

Decimals use place value, so $0.6$ is $6$ tenths but $0.06$ is $6$ hundredths. That extra zero matters because hundredths are ten times smaller than tenths.

To write $0.06$ as a fraction, use its place value first.
$$0.06 = \frac{6}{100}$$
Then simplify by dividing the numerator and denominator by $2$.
$$\frac{6}{100} = \frac{3}{50}$$

Always simplify a fraction unless the question says not to. A common mistake is writing $0.06$ as $\frac{6}{10}$, but $\frac{6}{10}$ equals $0.6$.

## Percentages and decimals

Percentage means "out of 100", so dividing by 100 changes a percentage into a decimal. Here is a direct example: $$18\% = \frac{18}{100} = 0.18$$

To change a decimal to a percentage, multiply by 100 and add the percent sign. For example, $$0.79 \times 100 = 79$$ so $0.79 = 79\% $.

Move the decimal point two places, not one. For example, $4\%$ is $0.04$, while $40\%$ is $0.4$.

## Fractions to decimals and percentages

A fraction bar means divide, so $\frac{7}{10}$ becomes 0.7. Sometimes it is quicker to make an equivalent fraction with denominator 10 or 100 first.

Worked example: convert $\frac{2}{5}$ to a decimal by making tenths. Multiply numerator and denominator by 2. $$\frac{2}{5} = \frac{4}{10} = 0.4$$

To convert a fraction to a percentage, make the denominator 100 if possible or go through a decimal. This tells you the percentage immediately. $$\frac{9}{20} = \frac{45}{100} = 45\%$$

## Comparing and ordering mixed forms

When numbers are written in different forms, do not compare them by how they look. Convert them first so every value is in the same format. Decimals are often the easiest choice because place value makes the order clear.

Example: order $80\%$, $\frac{3}{4}$, $0.77$, $0.9$ and $\frac{7}{10}$ from smallest to largest. First convert the percentage and fractions to decimals.

$$$80\% = 0.8,\quad \frac{3}{4} = 0.75,\quad \frac{7}{10} = 0.7$$

Now compare $0.7$, $0.75$, $0.77$, $0.8$ and $0.9$. The final order is: $$\frac{7}{10},\ \frac{3}{4},\ 0.77,\ 80\%,\ 0.9$$

## Check yourself

1. Which value is equivalent to 0.6?

   - 6%

   - 60% ✔

   - $$\frac{6}{100}$

   - 0.06

   _Explanation:_ 0.6 means 6 tenths, and 6 tenths is 60 hundredths, so it is 60%. The common wrong answer 6% means 6 out of 100, which is 0.06, not 0.6.

2. What is 4% as a decimal?

   - 0.4

   - 0.04 ✔

   - 4.0

   - 0.004

   _Explanation:_ 4% means 4 out of 100, so it is $\frac{4}{100} = 0.04$. The common wrong answer 0.4 is 40%, which comes from moving the decimal point only one place instead of two.

3. Two people earn the same monthly salary. Alex saves 40% of it. Sam spends $\frac{3}{5}$ of it and saves the rest. Who saves more?

   - Alex

   - Sam

   - They save the same amount ✔

   - Sam saves nothing

   _Explanation:_ If Sam spends $\frac{3}{5}$, then Sam saves $\frac{2}{5}$. Since $\frac{2}{5} = 0.4 = 40\%$, both people save 40% of the same salary. The common wrong answer is Alex, but it forgets to convert Sam's remaining fraction before comparing.
