## What is a histogram?

![Comparison of a bar chart with gaps and a histogram with touching bars, showing height equals frequency for the bar chart and area equals frequency for the histogram](../assets/001-3fed07e4-e53b-4695-87f8-ded86b707880.jpeg)

A histogram is used for grouped continuous data such as time, length, or mass. The bars touch because values can occur anywhere within the intervals. In a histogram, the area of each bar represents frequency.

This is different from a bar chart, where bar height shows frequency directly. For a histogram, both the width and the height of each bar matter.

## Class width and frequency density

A class interval like $4 \le t < 10$ starts at 4 and ends just before 10. That means 10 belongs to the next class, and the class width is calculated as $10 - 4 = 6$.

The height of a histogram bar is called frequency density. It tells you how much frequency there is per unit of class width.

$$\text{frequency density}=\frac{\text{frequency}}{\text{class width}}$$

You can rearrange this to get frequency from a bar. Always work out each class width separately because intervals can be unequal.

$$\text{frequency}=\text{class width}\times\text{frequency density}$$

## Worked example: frequency from a bar

Suppose a bar covers $5 \le t < 13$ and has frequency density 2.5. First find the class width by calculating the difference between boundaries: $13 - 5 = 8$.

Every histogram bar is a rectangle, so its area gives the frequency. Now use the standard histogram rule to find the result:

$$$\text{frequency}=\text{class width}\times\text{frequency density}=8\times 2.5=20$$

So the frequency is 20, not 2.5. The 2.5 is only the height of the bar, and the width of 8 turns height into area.

## Worked example: drawing a histogram

To draw a histogram, first complete the frequency density column. Then put class intervals on the horizontal axis and frequency density on the vertical axis.

Use this completed table. The largest frequency density is 3.6, so the vertical scale must go a little higher than 3.6.

| 10 up to 15 | 8 | 5 | 1.6 |
| 15 up to 20 | 18 | 5 | 3.6 |

Draw bars from 0 to 4, 4 to 10, 10 to 15, and 15 to 20 with heights 2.5, 3, 1.6, and 3.6. Check one bar by area, for example the interval $4 \le t < 10$ has width 6 and height 3, so its frequency is $6 \times 3 = 18$.

## Reading part of a bar

Sometimes a question asks for the frequency in only part of a class interval. Since the bar has a constant height across that interval, you can use the area of just that part of the rectangle.

Example: a bar runs from 20 to 35 minutes with frequency density 2. To estimate the number between 25 and 35 minutes, use width $35 - 25 = 10$ and calculate $10 \times 2 = 20$.

This answer is an estimate, not an exact count. It assumes the data is spread evenly within the class interval.

## Check yourself

1. Which statement about a histogram is correct?

   - The bars should have gaps between them

   - The height of each bar is always the frequency

   - The area of each bar represents the frequency ✔

   - Histograms are used for categorical data

   _Explanation:_ C is correct because a histogram uses bar area to show frequency. The most common wrong answer is B because the height is frequency density, not frequency, when class widths are not all $1$.

2. One histogram bar covers $10 \le x < 20$ and has frequency density 3. Another covers $20 \le x < 25$ and has frequency density 4. Which interval has the greater frequency?

   - $$10 \le x < 20$ ✔

   - $$20 \le x < 25$

   - They have the same frequency

   - It cannot be worked out

   _Explanation:_ The first bar has area $10 \times 3 = 30$, so it has the greater frequency. The most common wrong answer is B because it chooses the taller bar but ignores that the second bar is only 5 units wide, so its area is $5 \times 4 = 20$. Hint: Compare areas, not heights.

3. A histogram bar covers $30 \le t < 50$ and has frequency density 1.8. Estimate the frequency for $35 \le t < 45$.

   - 18 ✔

   - 36

   - 9

   - 1.8

   _Explanation:_ The selected part has width $45 - 35 = 10$, so the frequency is $10 \times 1.8 = 18$. The most common wrong answer is B, which uses the whole width 20 instead of only the requested section.
