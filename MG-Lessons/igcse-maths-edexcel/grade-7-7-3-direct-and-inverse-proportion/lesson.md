## What proportion means

In proportion questions, two variables are linked by a fixed number called the constant of proportionality, usually $k$. Your first job is to turn the words into an equation.

If $y$ is directly proportional to $x$, write $y = kx$. If $y$ is inversely proportional to $x$, write $y = \frac{k}{x}$, which is equivalent to $xy = k$.

Most questions then follow the same routine. Write the equation with $k$, use the known pair of values to find $k$, and substitute the new value carefully.

## Worked example: direct proportion

Suppose $p$ is directly proportional to $q$, and $p=9$ when $q=36$. Start with $p = kq$ because $p$ is the quantity described in the sentence.

Use the known pair to find the constant: $9 = 36k$, so $k = \frac{9}{36} = \frac{1}{4}$. The model is now $p = \frac{1}{4}q$.

Now substitute $p=4$: $4 = \frac{1}{4}q$, so $q=16$. The answer is sensible because both variables became smaller together.

## Worked example: inverse proportion

In inverse proportion, one variable increases while the other decreases. The equation is $m = \frac{k}{n}$, and the product $mn$ stays constant.

If $m=6$ when $n=10$, then $6 = \frac{k}{10}$, so $k=60$. You can also check this quickly because $6 \times 10 = 60$.

When $n=4$, substitute into the formula: $m = \frac{60}{4} = 15$. Since $n$ got smaller, $m$ got larger, which fits inverse proportion.

## Powers and roots

Some questions involve powers or roots instead of plain $x$. For example, $y \propto x^2$ means $y = kx^2$, and $y \propto \frac{1}{x^3}$ means $y = \frac{k}{x^3}$.

If $r$ is directly proportional to $\sqrt{s}$, we use the equation $r = k\sqrt{s}$. When $r=20$ and $s=25$, we substitute them to get $20 = k\sqrt{25} = 5k$, which gives $k=4$.

To find $s$ when $r=8$, solve $8 = 4\sqrt{s}$, resulting in $\sqrt{s} = 2$ and $s = 4$. A common trap is stopping at $\sqrt{s} = 2$ instead of squaring to find the final value.

## Recognising graphs and tables

![Four coordinate graphs showing a straight line through the origin for y proportional to x, a parabola for y proportional to x squared, a reciprocal curve for y proportional to one over x, and two positive branches for y proportional to one over x squared.](../assets/001-31fd4826-f3b8-46b9-89f6-7696070eefdb.jpeg)

Graphs often show the type of proportion immediately. A straight line through the origin means $y \propto x$, while a reciprocal curve suggests an inverse relationship.

A straight line is not enough on its own. For example, $y = 2x + 3$ is linear, but it is not direct proportion because it does not pass through the origin.

Tables can be tested systematically. Check whether $\frac{y}{x}$, $\frac{y}{x^2}$, or $\frac{y}{x^3}$ stays constant to decide which model fits.

## When the unknown is inside a power

Sometimes the final missing value is the variable inside the power. If $a$ is directly proportional to $b^3$, start with $a = kb^3$ before substituting any numbers.

When $a=54$ and $b=3$, we get $54 = k \times 3^3 = 27k$, so $k=2$. The formula becomes $a = 2b^3$.

If $a=16$, solve $16 = 2b^3$, so $b^3 = 8$ and $b=2$. Divide by the constant factor first, then take the cube root to find the value.

## Check yourself

1. If $p$ is directly proportional to $q$, which equation should you write first?

   - $$p = kq$ ✔

   - $$q = kp$

   - $$p = \frac{k}{q}$

   - $$pq = k$

   _Explanation:_ $$p = kq$ is correct because direct proportion uses multiplication by a constant and the wording says $p$ depends on $q$. The common wrong answer is B, which swaps the variables and often leads to substitution mistakes later.

2. If $y$ is inversely proportional to $x$ and $x$ doubles, what happens to $y$?

   - $$y$ halves ✔

   - $$y$ doubles

   - $$y$ stays the same

   - $$y$ quarters

   _Explanation:_ In inverse proportion, $xy = k$ stays constant, so doubling $x$ means $y$ must be divided by 2. The common wrong answer is B, which would be true for direct proportion, not inverse.

3. When $x=2$, $y=24$, and when $x=3$, $y=81$. Which statement is correct?

   - $$y \propto x$

   - $$y \propto x^2$

   - $$y \propto x^3$ ✔

   - $$y \propto \frac{1}{x}$

   _Explanation:_ $$\frac{24}{2^3} = 3$ and $\frac{81}{3^3} = 3$, so $y$ is proportional to $x^3$. The common wrong answer is B, but $\frac{24}{2^2} = 6$ and $\frac{81}{3^2} = 9$, so the ratio is not constant. Hint: Test a constant ratio.
