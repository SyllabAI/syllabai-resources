## What substitution means

![Flowchart showing substitution steps: replace variables with values, put negative values in brackets, work out brackets and powers, then multiplication and division, then addition and subtraction, with examples of hidden multiplication.](../assets/001-c55b3981-1139-4e18-97f7-0b07a2428c6e.jpeg)

A variable is a letter that stands for a number. Substitution means replacing the letter with its given value, then working out the result.

In algebra, multiplication signs are often hidden: $3f$ means $3 \times f$, $bc$ means $b \times c$, and $m(n-2)$ means $m \times (n-2)$. After you substitute, use BIDMAS so you calculate in the right order.

## Worked example: a simple expression

Suppose $f=6$ and $g=4$. Replace each letter first and show the hidden multiplication with brackets.

$$3f + 2g = 3(6) + 2(4)$$

Now do the multiplications before the addition. This follows BIDMAS.

$$3(6) + 2(4) = 18 + 8$$

Finally add the two terms. Writing the substituted line first can earn method marks even if the arithmetic later slips.

$$18 + 8 = 26$$

## Negative numbers and powers

If a variable has a negative value, put it in brackets straight away. This keeps the sign clear, because $4(-3)$ is different from $4-3$.

For $Q = 6p + 4r$ with $p=5$ and $r=-3$, substitute first and keep the negative value in brackets. Then multiply before you add.

$$$Q = 6(5) + 4(-3) = 30 + (-12) = 18$$

Brackets matter even more with powers. If $x=-3$, then $x^2 = (-3)^2 = 9$, not $-9$.

## Brackets and fractions in formulas

Some formulas already contain brackets, so that part must be done first after substitution. For $L = m(n-4)$ with $m=8$ and $n=9$, the bracket comes before the multiplication.

$$$L = 8(9-4) = 8(5) = 40$$

A fraction bar means divide, so it helps to work out the top and bottom separately. For $s = \frac{v^2-u^2}{2a}$ with $v=8$, $u=4$, and $a=2$, do the powers first.

$$$s = \frac{8^2 - 4^2}{2(2)} = \frac{64 - 16}{4} = \frac{48}{4} = 12$$

## Longer formulas without panic

Longer formulas are not harder if you stay organised. Write the full substituted line first, then simplify one part at a time.

$$s = ut + \frac{1}{2}at^2$$

If $u=-4$, $a=6$, and $t=3$, substitute everything before calculating. Keep the negative number in brackets.

$$s = (-4)(3) + \frac{1}{2}(6)(3)^2$$

Now work out the power, then the multiplications. This keeps the order of operations clear.

$$s = (-4)(3) + \frac{1}{2}(6)(9) = -12 + 27$$

Finally add the two terms. A neat line of working is exactly what examiners want to see.

$$s = 15$$

## Check yourself

1. If $d=7$, which line correctly rewrites $4d$ after substitution?

   - $$4(7)$ ✔

   - $$47$

   - $$4+7$

   - $$7-4$

   _Explanation:_ A is correct because $4d$ means $4 \times d$, so when $d=7$ it becomes $4(7)$. The most common wrong answer is B, but that wrongly joins the digits together instead of using the hidden multiplication.

2. If $x=-4$, what is the value of $2x^2$?

   - 32 ✔

   - -32

   - 8

   - -8

   _Explanation:_ A is correct because you square the whole value first: $2(-4)^2 = 2(16) = 32$. The most common wrong answer is B, which comes from forgetting that the negative number must be squared as a whole.

3. When $a=2$, $b=-5$, and $c=3$, what is the value of $b^2 - 4ac$?

   - 1 ✔

   - -1

   - 49

   - 24

   _Explanation:_ A is correct because $(-5)^2 = 25$ and $4ac = 4(2)(3) = 24$, so $25 - 24 = 1$. The most common wrong answer is B, which happens when a student treats $(-5)^2$ as $-25$ instead of squaring the whole negative number. Hint: Square $b$ before subtracting the product $4ac$.
