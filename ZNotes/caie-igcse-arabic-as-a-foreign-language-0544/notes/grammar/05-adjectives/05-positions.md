## Positional Adjectives - ظروف المكان

Positional Adjectives describe where an object is relative to another subject.

Examples include in front of, next to, behind, and so on

| English | Arabic - ظرف مكان |
|----|----|
| In front of | أمام |
| Behind | وراء \ خلف |
| To the right of | يمين |
| To the left of | يسار \ شمال |
| Above | فوق \ أعلى |
| Under | تحت \ أسفل |
| Beside / Next to | بجنب |
| Inside | داخل \ في |
| Outside | خارج |
| In the middle of / Between | في الوسط \ بين |
| Around | حول |
| North, South, East, West | شمال، جنوب، شرق، غرب |
| Towards | إتجاه |
