## Demonstratives - أسماء الإشارة
- Used when indicating or talking about someone or a group of people
- Examples of such are: These, Those, That, etc.

The Arabic Demonstratives are:

| English | Arabic |
| -------- | -------- |
| This (Male) | هذا |
| This (Female) | هذه |
| That (Male) | ذَلِكَ |
| That (Female) | تِلكَ |
| These (Male) | هؤلاء \ هذه |
| These (Female) | هؤلاء \ هذه |
| Those (Male) | أولئك \ تِلكَ |
| Those (Female) | أولئك \ تلك |

*'هذه' and 'تلك' are also used for plural non-human objects

Examples:
 - That girl wants to borrow this book
 - تلك الفتاة تريد إستعارة هذا الكتاب
 - Those guys were helping us out
 - أولئك الشباب كانوا يساعدوننا
 - Those books were on top of these shelves when I went to that cafe
 - تلك الكتب كانت فوق هذه الرفوف عندما ذهبت الى ذلك المقهى
