## Colors - الألوان

Colors are an adjective used to describe how you see an object. In Arabic, there are male and female terms, depending on the subject (plurals are the same as singular feminine, although some colors have other forms too for plural)

To make a color feminine, simply add a ‘ء’ at the end and remove the ‘أ’ from the beginning (if there was one)




Examples:

| Color (English) | Color (Arabic) | Plural(s) |
|----|----|----|
| Red | أحمر \ حمراء | حمراء \ حُمُر |
| Green | أخضر \ خضراء | خضراء \ خُضُر |
| Blue | أزرق \ زرقاء | زرقاء \ زُرق |
| Yellow | أصفر \ صفراء | صفراء \ صُفر |
| Black | أسود \ سوداء | سوداء \ سود |
| White | أبيض \ بيضاء | بيضاء \ بيض |
| Orange | برتقالي \ برتقالية | برتقالية |
| Pink | وردي \ وردية | وردية |
| Brown | بني \ بنية | بنية |
| Silver | فضي \ فضية | فضية |
| Gold | ذهبي \ ذهبية | ذهبية |
| Purple | بنفسجي \ بنفسجية | بنفسجية |
| Gray | رصاصي \ رصاصية | رصاصية |
