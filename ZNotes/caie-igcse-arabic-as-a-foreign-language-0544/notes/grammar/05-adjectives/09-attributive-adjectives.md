## Nisba Adjectives (Attributive Adjectives)
 - We use this when trying to attribute something to someone (or something else)
 - For a male, we add a 'يّ' at the end
 - For a female, a 'يّة' is added at the end of the object being attributed to
 

### Examples:

| English | Male Nisba | Female Nisba |
| -------- | -------- | -------- |
| Arab | عربيّ | عربيّة |
| Foreigner | أجنبي | أجنبية |
| Musician | موسيقيّ | موسيقيّة |
| Northener | شمالي | شمالية |
| Southener | جنوبي | جنوبية |

*Note that nisba adjectives are adjectives used on living beings (usually humans)
