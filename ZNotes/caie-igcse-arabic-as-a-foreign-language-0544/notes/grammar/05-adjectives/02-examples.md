$^1$ Usually means ‘the former/predecessors’ when used to describe humans

$^2$ Most objects just use ‘جافة’ as you dont really call a human dry

$^3$ The word ‘حديث’ is usually for non-human objects

$^4$ ‘سهلة’ is usually for non-human objects (sometimes both male and female)

$^5$ the word ‘ضِخام’ is used for both male and female plural

$^6$ ‘عامّة’ is used for female and both plural terms

$^7$ You use ‘على اتم وجه’ when youre saying something has been accomplished, or done well, regardless of what it is

$^8$ ‘بدون فائدة’ can be used for all forms, and it means ‘without use’; while ‘غير مفيد’ means ‘not useful’

$^9$ you only use ‘مشمس’ to describe the weather; which can work by using the following terms:

* ‘الطقس’(the weather) or ‘الجو’ (technically atmosphere) are male terms, as well as ‘اليوم’ (today).
* ‘السماء’ (the sky) is a female term.

These terms are considered singular terms (a plural would still use ‘مشمسة’)
