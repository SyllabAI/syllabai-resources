## Useful Phrases

* وهكذا - and so on / and like this

  * Prompts to the examiner that you're done with your sentence

* عفوا؟ / هل من الممكن أن تعيد(ي) السؤال؟ - Excuse me? / Can you repeat the question

  * To inform the examiner that the question wasn't fully comprehended

* هل من الممكن أن تتكلم(ي) بشكل أسرع / بشكل أبطأ / بصوت أعلى - Can you speaker faster / slower / louder

  * To prompt to the examiner to adjust the way they speak

* لم أفهم السؤال (هل من الممكن أن تغيّر(ي) صيغة السؤال) - I do not understand the question (Can you rephrase the question?)

  * The examiner will either repeat the question, give an alternative form, or proceed to the next question

* أريد أن أضيف شيئا / معلومة لو سمحت - Id like to add something / more information if you allow so

  * If the examiner interrupts you when you're saying something

* حّسّنًا - Well then

* بِرَأيِي / شَخصِيًّا - In my opinion / Personally

* صَرَاحَةً - Actually / Admittedly

* هَذَا كُلُّ شّيء - This is everything / Thats it

* كَمَا قُلتُ سَابِقًا / مِن قَبل - Like I said earlier / before
