## Ionic Equations

**Key points:**

* Solids don’t split into ions, so they stay as they are in the original equation.

* If a substance is an ionic compound in the aqueous state, it splits into its ions.

* If it’s a strong acid or alkali, split it into ions.

* Don’t make changes to other substances if not needed.

* **Spectator ions** are ions that appear unchanged on both sides of the equation. They are removed to give the net ionic equation.

**Worked example:**

* **Original equation**:

  $Ca(s) + Cu(NO_3)_2(aq) \rightarrow Ca(NO_3)_2(aq) + Cu(s)$

* **Split the compounds into ions**:

  $Ca(s) + Cu^{2+}(aq) + 2NO_3^{-}(aq) \rightarrow Ca^{2+}(aq) + 2NO_3^{-}(aq) + Cu(s)$

* **Remove the spectator ions**: $2NO_3^{-}(aq)$ appears on both sides, so it is removed.

* **Final net ionic equation** (doesn’t include spectator ions):

  $Ca(s) + Cu^{2+}(aq) \rightarrow Ca^{2+}(aq) + Cu(s)$

**Worked example (halogen displacement):**

* $Cl_2(aq) + 2KBr(aq) \rightarrow 2KCl(aq) + Br_2(aq)$

* Split into ions: $Cl_2(aq) + 2K^{+}(aq) + 2Br^{-}(aq) \rightarrow 2K^{+}(aq) + 2Cl^{-}(aq) + Br_2(aq)$

* $K^{+}$ is a spectator ion, so the net ionic equation is:

  $Cl_2(aq) + 2Br^{-}(aq) \rightarrow 2Cl^{-}(aq) + Br_2(aq)$
