# Common Errors and Improvements

## Errors and Improvements

| **Errors** | **Improvements** |
|----|----|
| No Repeats | Repeat Three Times |
| Different Colour Changes | Use a colorimeter |
| The measuring cylinder is inaccurate | Use a burette because it is more accurate |
| Adding past endpoint | Add volume in smaller quantities |
| Temperature/Heat Loss | Use a thermostatically controlled water bath |
| The same measuring cylinder used in multiple investigations | Use different measuring cylinders |
