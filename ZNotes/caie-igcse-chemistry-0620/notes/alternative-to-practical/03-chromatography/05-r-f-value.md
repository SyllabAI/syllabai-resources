## $R_f$ value

### Definition

* ratio of the distance moved by solute to the distance moved by solvent

$R_f\ Value = \ \frac{\text{Distance moved by solute}}{\text{Distance moved by solvent}}$

**Key Points:**

* $R_f$​ is always **less than 1**

* $R_f$​ has **no units**

* $R_f$​ is **constant** for a substance under the **same conditions**

Worked example

**Question:** A spot of substance travels 4.50 cm from the baseline. The solvent front travels 9.00 cm from the baseline. Calculate the $R_f$ value.

**Solution:**

$R_f\ Value = \ \frac{\text{Distance moved by solute}}{\text{Distance moved by solvent}}$

$R_f\ Value = \ \frac{\\4.50
}{\\{9.00}}$

$R_f$ = 0.50

### Using $R_f$ to Identify Substances

* Calculate $R_f$ of the **unknown** spot

* Compare with $R_f$ values of **known** substances

* If $R_f$ values **match**, the substances are the **same**

**Key Point:** $R_f$ values are **constant** for a substance under the **same conditions** (same solvent, same paper, same temperature).
