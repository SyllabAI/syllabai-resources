# Question 4

**Step in both methods**
- Crush the ore into a powder using mortar and pestle
- add water, stir and filter

**Method 1. Displacement in a solid state**
- then add a suitable reducing agent (carbon, iron, zinc, aluminium, magnesium) to the residue
- heat the ore to form bismuth
- bismuth is formed by getting displaced by reducing agent

**Method 2. using electrolysis**
- add strong acid to to the filtrate
- electrolysis of the solution
- using inert carbon or platinum electrodes
- bismuth is formed at the cathode
