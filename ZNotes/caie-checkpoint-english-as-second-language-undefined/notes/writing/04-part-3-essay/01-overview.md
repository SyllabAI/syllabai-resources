# Essay

## **Part 3**

(Question **7**)

* In this final part of the paper, you will be asked to write a **story** **OR** an **essay** on a given topic.
* Ideally, you should write **100-120 words** for this task, and it is essential not to write more than that.
* You should spend **about 30 minutes** in this section, which includes planning time.
* The total mark for this task is **20**, which consists of:
  * up to **5** marks for Content
  * up to **5** marks for Communicative Achievement
  * up to **5** marks for Organisation
  * up to **5** marks for Language

$ \quad $

When marking your response, an examiner will refer to a table like the one in the next card to find out how well you did.
