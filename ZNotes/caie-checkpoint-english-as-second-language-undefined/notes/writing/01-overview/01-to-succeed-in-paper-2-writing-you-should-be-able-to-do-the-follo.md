# **Overview**

### To succeed in Paper 2 (Writing), you should be able to do the following on a range of topics:

* Plan and write written work efficiently
* Write an email/essay with accurate grammar and vocabulary
* Use the correct style and register (text type) when writing
* Develop arguments that make sense, supported by examples and evidence where necessary
* Use appropriate layout (correct format) and punctuation when writing

### Information on the Writing test:

* This time given to complete this paper is **50 minutes**
* Recommendations on how much time to spend on each part is included.
* The total mark for this paper is **35**.
* You *may not* use dictionaries.
