## Integration

**Introduction**

Integration is the reverse (or inverse) process of differentiation.

If
$$
\frac{d}{dx} \left( F(x) \right) = f(x),
$$
then
$$
\int f(x) dx = F(x) + c,
$$
where $ c $ is the constant of integration.

---

For any real number $n\neq -1$:
$$
\int a x^{n} dx = a \frac{x^{n+1}}{n+1} + c
$$

**Example:**
$
\int 3x^2 dx = 3 \cdot \frac{x^3}{3} + c = x^3 + c
$

For $ n \neq -1 $:
$$
\int (a x + b)^{n} dx = \frac{(a x + b)^{n+1}}{a(n+1)} + c
$$

**Example:**
$
\int (2x + 1)^3 dx = \frac{(2x + 1)^4}{2 \cdot 4} + c = \frac{(2x + 1)^4}{8} + c
$
