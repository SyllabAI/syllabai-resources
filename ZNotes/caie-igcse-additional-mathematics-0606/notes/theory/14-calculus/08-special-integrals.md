## Special Integrals

$$

\int {\sin\left( \text{ax} + b \right)} = - \frac{1}{a}\cos\left( \text{ax} + b \right) + c

$$

$$

\int {\cos\left( \text{ax} + b \right)} = \frac{1}{a}\sin\left( \text{ax} + b \right) + c

$$

$$

\int {\sec^{2}\left( \text{ax} + b \right)} = \frac{1}{a}\tan\left( \text{ax} + b \right) + c

$$

$$
\int\frac{1}{x} = \ln \left\| x \right\| + c
$$

$$

\int \frac{1}{\text{ax} + b} = \frac{1}{a}\ln \left\| \text{ax} + b \right\|+ c

$$

$$

\int e^{\text{ax} + b} = \frac{1}{a}e^{\text{ax} + b} + c

$$
