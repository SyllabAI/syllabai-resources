## Straight Line Form

### **Power Laws:**

**Original**: $y = Ax^n$

**Take logs:**

$\log y = \log A + n \log x$

When plotting $\log y$ against $\log x$

**Gradient** = $n$

**y-intercept** = $\log A$

### **Exponential Form:**

**Original**: $y = Ab^x$

**Take logs:**

$\log y = \log A + x\log b$

When plotting $\log y$ against $x$,

**Gradient** = $\log b$

**y-intercept** = $\log A$

### **From Straight-Line graphs to original equations:**

**Examples:**

1. If graph of $y^2$ vs $x^3$ is a straight line
   $y^2 = Ax^3 + B$

2. If graph of $e^2y$ vs $x^2$ is a straight line
   $e^2y = Ax^2 + B$

3. If graph of $y^3$ vs $\ln x$ is a straight line
   $y^3 = A\ln x + B$

   In these cases, gradient $m=A$ and intercept $c=B$
