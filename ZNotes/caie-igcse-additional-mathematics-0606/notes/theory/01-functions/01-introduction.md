# Functions

## Introduction

### **Functions**

A function is a relation where each input (domain) has exactly one output (range).

e.g. $f(x) = 2x$

$\text{Input: } x = 3 \Rightarrow \text{Output: } f(3) = 6$

* ### Domain:

  All possible input (x) values a function can take

  e.g. $f(x) = \sqrt{x} \Rightarrow \text{Domain: } x \geq 0 \ (\text{can’t square root negatives})$

  $f(x) = \frac{1}{x} \Rightarrow \text{Domain: } x \ne 0 \ (\text{can’t divide by zero})$

* ### Range:

  All possible output (y) values a function can produce.

  e.g.
  $f(x) = x^2$
  $\text{Range: } y \geq 0 \text{ (squares are never negative).}$

  $f(x) = \sin x$
  $\text{Range: } -1 \leq y \leq 1.$

**Example 1:**

Let $f(x) = \frac{1}{x - 3}$

To find the domain, set the denominator $x - 3 \neq 0 \Rightarrow x \neq 3$\
So, the domain is $x \in \mathbb{R},\ x \ne 3$

**Example 2:**

Let $f(x) = \sqrt{x + 2}$

The expression inside the square root must be non-negative:\
$x + 2 \geq 0 \Rightarrow x \geq -2$\
So, the domain is $x \geq -2$

**Example 3:**

Let $f(x) = \sqrt{x - 1}$

Domain: $x \geq 1$

Let $y = \sqrt{x - 1} \Rightarrow x = y^2 + 1$

Since square roots are always non-negative, we have $y \geq 0$\
So, the range is $y \geq 0$
