## Special Functions

### **Composite Functions**:

Applying one function after another, such as:

e.g. $f(x) = x^2, g(x) = x+1 \rightarrow f(g(x)) = (x+1)^2.$

**In composite functions, the order matters!**

e.g. $f(g(x)) \neq g(f(x)).$

**Validity of Composite Functions:**

e.g. For the function fg(x)

The input x must satisfy two conditions

1. x must be in the domain of g (i.e, g(x) is defined)

2. The output g(x) must be in the domain of f.

### **Modulus Functions**:

Makes all outputs non-negative

e.g.

$f(x)=x-2 \rightarrow \|f(x)\| \text{ reflects negative parts above the x-axis.}$
$\|\sin x\| \rightarrow \text{Always between 0 and 1.}$

**Example 1:**

Let $f(x) = \sqrt{x}$ and $g(x) = x - 2$

The composite function is:\
$f(g(x)) = \sqrt{x - 2}$

To find the domain of $f(g(x))$:

1. Find the domain of $g(x)$, which is all real numbers:\
   $x \in \mathbb{R}$.

2. Find the domain of $f(x) = \sqrt{x}$, which requires the input to be non-negative:\
   $x \geq 0$

3. Since the input to $f$ is $g(x) = x - 2$, we require:\
   $x - 2 \geq 0 \Rightarrow x \geq 2$

Therefore, the domain of the composite function $f(g(x))$ is:\
$x \geq 2$
