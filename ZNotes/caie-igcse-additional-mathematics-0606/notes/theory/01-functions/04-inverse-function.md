## Inverse Function

Reverses the original function (swaps x and y)

**Condition**: Only exists if the function is one-one

**Test**: No vertical line touches the graph twice.

e.g.

$1. \text{ Write } y = f(x).$

$2. \text{ Swap } x \text{ and } y.$

$3. \text{ Solve for } y.$

Example     $ \rightarrow f(x) = 3x + 5$

Step 1: Write y = f(x)

$y = 3x + 5$

Step 2: Swap x and y

$x = 3y + 5$

Step 3: Solve for y

$y = \frac{x-5}{3}$

Final Result:

$f^{-1}(x) = \frac{x-5}{3}$

**Relation between function and its inverse is always a reflection in the line y=x**

Example:

Let $ f(x) = \sqrt{x - 2} $

Domain of $ f(x) $:

Since the expression under the square root must be $ \geq 0 $,

$
x - 2 \geq 0 \Rightarrow x \geq 2
$

So the domain is:

$
x \geq 2
$

Range of $ f(x) $:\
Square roots give only non-negative values,

$
y \geq 0
$

Find the inverse:

Step 1: Replace $ f(x) $ with $ y $

$
y = \sqrt{x - 2}
$

Step 2: Swap $ x $ and $ y $

$
x = \sqrt{y - 2}
$

Step 3: Solve for $ y $:

$
x^2 = y - 2 \Rightarrow y = x^2 + 2
$

So the inverse function is:\
$
f^{-1}(x) = x^2 + 2
$

* The **domain of the original function becomes the range** of the inverse.

* The **range of the original function becomes the domain** of the inverse.

Therefore,

Domain of $ f^{-1}(x) : x \geq 0 $

Range of $ f^{-1}(x): y \geq 2 $
