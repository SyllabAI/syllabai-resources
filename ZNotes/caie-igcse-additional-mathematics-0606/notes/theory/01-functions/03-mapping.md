## Mapping

### **One-to-one functions**

* Every output (y) comes from only one input (x)

* Test: Passes the horizontal line test (no horizontal line touches the graph twice)

  e.g. $f(x) = 2x + 3$
  $\text{straight line } \rightarrow \text{one-one.}$

  $\text{Not one-one:} f(x) = x^2$
  $\text{both 2 and -2 give 4.}$

### **Many-One Function**:

* At least two inputs (x) give the same output (y).

  e.g. $f(x) = x^2 \rightarrow f(2) = 4 \text{ and } f(-2) = 4.$
