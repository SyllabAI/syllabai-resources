## Notations

#### Basic Function Notation

A function is often written as:
$
f(x) = \text{expression in } x
$

Example:
$
f(x) = 2e^x
$
This means: input $ x $, output is $ 2e^x $

#### Arrow Notation

Alternate way of writing a function:
$
f : x \mapsto \lg x \quad \text{for } x > 0
$

This means: “$ f $ maps $ x $ to $ \lg x $”

#### Inverse Functions

The inverse of $ f(x) $ is written as $ f^{-1}(x) $

Reverses the effect of ( f ):\
$
f(f^{-1}(x)) = x \quad \text{and} \quad f^{-1}(f(x)) = x
$

**Only one-to-one functions** have inverses

**Example:**\
If $ f(x) = 2x + 3 $, then\
$
f^{-1}(x) = \frac{x - 3}{2}
$

#### Composite Functions

The composition $fg(x) $ means:
$
fg(x) = f(g(x))
$

**Example:**\
Let $ f(x) = x^2 $, $ g(x) = x + 1 $. Then:
$
fg(x) = f(g(x)) = f(x + 1) = (x + 1)^2
$

#### Repeated Function Application

The notation $ f^2(x) $ means:
$
f^2(x) = f(f(x))
$

**Example:**\
If $ f(x) = 3x $, then:
$
f^2(x) = f(f(x)) = f(3x) = 3(3x) = 9x
$

Note: This notation is **not used with trigonometric functions**
