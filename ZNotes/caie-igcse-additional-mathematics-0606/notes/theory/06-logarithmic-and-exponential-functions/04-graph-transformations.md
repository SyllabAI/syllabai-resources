## Graph Transformations

For functions like $y=ke^nx +a$ and $y=k\ln (ax+b)$

**$k$**: Vertical stretch ($k>1$) or compression ($0<k<1$)

$n$: Horizontal stretch ($0<n<1$) or compression ($n>1$)

$a$: Horizontal stretch ($0<a<1$) or compression ($a>1$)

$b$: Horizontal shift. If $b>0$, the graph shifts left by $\frac{b}{a}$ units. If $b<0$, the graph shifts by $\frac{\|b\|}{a}$ units.

$+a$: Vertical shift. If $a>0$, the graph moves up by a units. If $a<0$, the graph moves down by $\|a\|$ units.
