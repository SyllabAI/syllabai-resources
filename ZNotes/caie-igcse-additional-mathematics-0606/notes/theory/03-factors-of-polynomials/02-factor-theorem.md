## Factor Theorem

* If plugging in $x=a$ into the polynomial $f(x)$ gives zero - that is, if $f(a)=0$, then $(x−a)$ is a factor of the polynomial $f(x)$

### **Steps**

To factor a cubic polynomial like $f(x)=x^3+2x^2-5x-6$

1. Try rational roots, like $ x = \pm1, \pm2, \pm3, \pm6 $, and use the Remainder Theorem to check if $ f(x) = 0 $.

2. If $f(a)=0$ then $(x-a)$ is a factor.

3. Use division (long division) to divide $f(x)$ by $(x-a)$

4. You now have $f(x)=(x-a)(quadratic)$

5. Factor the quadratic (if possible!)

6. To solve the equation $f(x)=0$, set each factor to 0

**Note**:

* $x-a=0 \rightarrow x=a$

* $x+b=0 \rightarrow x=-b$

* $x-c=0 \rightarrow x=c$

These are the roots/solutions of the cubic polynomial!

### **Example**

Factor the cubic polynomial $ f(x) = x^3-4x^2+x+6$

**Step 1:** Try rational roots

* $f(-2)= (-2)^3-4(-2)^2+(-2)+6=-20$

* $f(2)=(2)^3-4(2)^2+(2)+6= 0

* Do note, there are more than one factor you can find when you try, use any one:

  * $f(-1)=(-1)^3-4(-1)^2+(-1)+6= 0

**Step 2:** Write in factor form for f(a)

* $f(2)=0$, by the **Factor Theorem,** $(x-2)$ is a factor of $f(x)$

**Step 3:** Use division (long division to divide $f(x)$ by $(x-2)$

* $(x^3 - 4x^2 + x + 6) \div (x - 2) = x^2 - 2x - 3$

**Step 4**: Factored form for f(x)

* $(x-2)(x^2-2x-3)$

**Step 5**: Factor the quadratic (if possible)

* $x^2 - 2x - 3 = (x - 3)(x + 1)$

**Step 6**: Solve the equation

* $f(x) = (x - 2)(x - 3)(x + 1)$

* $(x - 2)(x - 3)(x + 1)=0$

* $x=2, x=3, x=-1$
