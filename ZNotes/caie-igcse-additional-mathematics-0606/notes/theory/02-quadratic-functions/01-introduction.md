# Quadratic Functions

## Introduction

Given:

$
y = ax^2 + bx + c \quad (a \ne 0)
$

Step 1: Factor out $ a $ from the first two terms

$
y = a(x^2 + \frac{b}{a}x) + c
$

Step 2: Complete the square inside the bracket

$
= a\left(x + \frac{b}{2a}\right)^2 - a\left(\frac{b}{2a}\right)^2 + c
$

Step 3: Simplify the constants

$
= a\left(x + \frac{b}{2a}\right)^2 + \left(c - \frac{b^2}{4a}\right)
$

Final form:

$
y = a(x - h)^2 + k
\quad \text{where } h = -\frac{b}{2a},\quad k = c - \frac{b^2}{4a}
$

Vertex at $x=h$, value $f(h)=k$

If $a > 0$: Minimum at vertex

If $a < 0$: Maximum at vertex
