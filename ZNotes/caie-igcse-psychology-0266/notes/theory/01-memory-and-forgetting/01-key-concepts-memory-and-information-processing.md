# Memory And Forgetting

## Key Concepts

### Memory and Information Processing

Memory is the process of **encoding**, **storage** and **retrieval** of information.

* **Encoding**: Changing information into a form that can be stored.

* **Storage**: Maintaining encoded information over time.

* **Retrieval**: Accessing stored information from memory.

### Types of Memory

**Declarative Memory**

* Information about facts and events.

* Can be consciously remembered and recalled.

Examples:

* Facts

* Personal experiences

**Procedural Memory**

* Information about how to perform tasks.

* Involves skills and actions.

Examples:

• Riding a bicycle
• Playing an instrument

### Forgetting

Forgetting is the inability to remember information learned previously.

**Retrograde Amnesia**

* Loss of memories from before injury, disease or trauma.

* Affects previously stored memories.

**Anterograde Amnesia**

* Inability to form new memories after injury, disease or trauma.

* Prevents formation of new long-term memories.
