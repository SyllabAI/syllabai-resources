## Non-experimental Method: Case Studies

### Case study

* A case study is an in-depth investigation of a single individual, group or event.

* A case study uses triangulation by collecting information about the same case using different methods or sources of data.

These may include:

* Tests or tasks

* Observations

* Questionnaires

* Interviews

**Example:**

* A researcher investigates one child's psychological development using tests, observations and interviews with the child's parents.

* This is a case study because it is an in-depth investigation of one individual, with triangulation through different methods.

### Triangulation

* Triangulation is the use of different methods or sources of data to investigate the same individual, group or event in a case study.

* It allows the researcher to compare findings from different sources.

* If different methods produce similar findings, confidence in the validity of the conclusion can increase.

Example:

* A researcher investigates one student's anxiety using a questionnaire, observation and interview.

* The use of these different methods to investigate the same student is triangulation.

### Features of a case study

* In-depth investigation

* Single individual, group or event

* Uses triangulation

* Uses different methods or sources of data

* May involve tests, tasks, observations, questionnaires or interviews

**Application tip:**

One case \+ in-depth investigation \+ different methods/sources → case study with triangulation
