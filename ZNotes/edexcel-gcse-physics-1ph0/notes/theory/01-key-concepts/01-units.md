# **Key concepts of physics**

## **Units**

**SI Base Units:**

* There are hundreds of units in physics, these units can be derived into six base units from which every other unit can be found.
* These six units are called the SI Base Units.


|Quantity|SI Base Unit|Symbol|
|:---:|:---:|:---:|
|Mass|Kilograms|Kg|
|Distance|Meters|m|
|Time|Seconds|s|
|Temperature|Kelvin|K|
|Current|Amperes|A|
|Amount of Substance|Moles|mol|
|Luminous Intensity|Candela|cd|

* These are the SI Base Units in physics which can be used to find other common units in physics.
* Some of these common units include:


|Quantity|Unit|Symbol|
|:---|:---|:---|
|Force|Newtons|N|
|Potential Difference|Volts|V|
|Energy|Joules|J|
|Power|Watts|W|
|Magnetic Flux Density|Tesla|T|
