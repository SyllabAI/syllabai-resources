## **Newton’s First Law**

### What is Newton’s First Law:

* Newton’s first law states that "An object at rest stays at rest, and an object in motion stays in motion with the same speed and in the same direction unless acted upon by an unbalanced external force."
* This means that if an object has no external forces acting upon it, the object will remain at rest or travel at a constant speed.

### **Circular Motion:**

* To keep an object moving in a circular path, a force directed towards the center of the circle is required. This force is called centripetal force.
* When an object moves at constant speed in a circular orbit it has a changing velocity.
* One example of an object moving in a circular path is a stone tied to a string and whirled in a circle.
