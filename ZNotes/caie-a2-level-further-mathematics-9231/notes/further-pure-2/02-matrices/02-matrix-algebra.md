## ~~Matrix Algebra~~ 

* Given that $Ae = λ𝑒$ and $Be = μ𝑒$ where 𝑒 is a common eigenvector for both $A$ and $B$
  * The matrix $A + B$ has eigenvalue $λ + μ$ 
  * The matrix $AB$ has eigenvalue $λμ$ 
  * The matrix $A + 𝑘𝐈$ has eigenvalue $λ + 𝑘$ 
  * The matrix $A^𝑝 + A^𝑞 + ⋯ $ has eigenvalue $λ^𝑝 + λ^𝑞 + ⋯$
