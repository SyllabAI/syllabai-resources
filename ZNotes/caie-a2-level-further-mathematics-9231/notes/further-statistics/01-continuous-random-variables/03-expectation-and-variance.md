## **Expectation and Variance**

  - To calculate the expectation

$$E\left( X \right) = \int_{- \infty}^{\infty}{\text{xf}\left( x \right)}\text{\ dx}$$

In general: 

$$E\left( g\left( X \right) \right) = \int_{\forall x}^{}{g\left( x \right)f\left( x \right)}\text{ dx\ }$$

  - To calculate variance:
    
      - First calculate $E(X)$ using the formula given above
    
      - The calculate $E(X^{2})$ by

$$E\left( X^{2} \right) = \int_{- \infty}^{\infty}{x^{2}f\left( x \right)}\text{\ dx}$$

  - Substitute information and calculate using

$$\text{Var}\left( X \right) = E\left( X^{2} \right) - (E{\left( X \right))}^{2}$$
