# Chi-Squared Tests

## $\mathbf{\chi}^{\mathbf{2}}$ Test

* Used to test whether a particular type of distribution is
  appropriate for the data given
* Test statistic involves squares – only interested in upper limit
  critical values
* The $\chi^{2}$ test can only be used to test two lists of
  frequencies – the observed and the expected frequencies calculated
  from the hypothesis.

$$\chi^{2} = \sum_{}^{}\frac{\left( O_{i} - E_{i} \right)^{2}}{E_{i}}$$

where $O_{i}$ and $E_{i}$ are the observed and expected frequencies

* Another way to calculate $\chi^{2}$ is:

$$\sum_{}^{}\left( \frac{O_{i}^{2}}{E_{i}} \right) - N$$

* When calculating, set up a table as follows

| **Variable** | **Probability** | $\mathbf{O}_{\mathbf{i}}$ | $\mathbf{E}_{\mathbf{i}}$ | $\frac{\left( \mathbf{O}*{\mathbf{i}}\mathbf{-}\mathbf{E}*{\mathbf{i}} \right)^{\mathbf{2}}}{\mathbf{E}_{\mathbf{i}}}$ |
|----|----|----|----|----|
| $\vdots$ | $\vdots$ | $\vdots$ | $\vdots$ | $\vdots$ |
| **Total** | 1 | $N$ | $N$ | $\ldots$ |

* If the expected frequency for a class is less than 5, then you must
  group this class with the next class (or two …)
* Hypothesis when testing:
  * $H_{0}:$ the … distribution is a suitable model
  * $H_{1}:$ the … distribution is not a suitable model
