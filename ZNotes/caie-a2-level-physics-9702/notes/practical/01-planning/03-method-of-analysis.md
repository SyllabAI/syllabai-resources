## Method of Analysis (2 Marks)

* Conduct the experiment for 5-6 values of the independent variable.
  * Repeat the experiment 3 times for each value of the independent variable.
  * Calculate the average for each set of three repetitions to minimize uncertainty (1 mark).
* Formulate a linear relationship algebraically.
  * Select appropriate quantities for each axis to create a linear graph (1 Mark).

| **Relationship** | **Graph** | **Gradient** | $\mathbf{y}$**-intercept** |
|----|----|----|----|
| $y = mx + c$ | $y$ against $x$ | $m$ | $c$ |
| $y = ax^{n}$ | $\lg y$ against $\lg x$ | $n$ | $\lg a$ |
| $y = ae^{\text{kx}}$ | $\ln y$ against $\ x$ | $k$ | $\ln a$ |

* The graph should depict a straight line if the given relationship is true (1 Mark).
  * The line should pass through the origin if the linear equation lacks a constant term (c).
  * The line shouldn't pass through the origin if the linear equation includes a constant term (c).
* To calculate the variables given in the equation:
  * Utilize the linear equation formed.
  * Use the equation ( y = mx + c ) as a template to equate the values in the equation to the slope (m) and y-intercept (c).
  * Formulate equations to find the variable(s), ensuring the variable to be found in the subject (1 Mark).
