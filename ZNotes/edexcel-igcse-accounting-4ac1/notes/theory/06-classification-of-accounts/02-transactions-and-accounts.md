## Transactions and Accounts

### Transactions

A transaction is identified by any **business event which has a value measurable in terms of money**.

* So, if a business buys a laptop for £1200 in cash, it is a transaction because there is an exchange of an asset (the laptop) and cash (£1200).

* However, if a business interviews a candidate and decides to hire them for the position of manager, it is not considered a transaction because there is no exchange of assets or any monetary value changed.

### Accounts

Every transaction has two aspects (Debit and Credit) and each aspect has an account, it is stated that “an account is a summary of relevant transactions at one place relating to a particular head.”

* This relates to the accounting principle of duality.

* An transaction can only be considered an account if it has both aspects, and only when it does can it be recorded in the ledger accounts.
