## Computer Hardware and Software

### Computer Hardware

The physical aspects of the computer are called hardware, most of the time these are password protected to prevent access. Usually the component hardware used are as follows:

* Monitor

* Keyboard

* Mouse

* Data storage area (such as hard drives.)

* Graphics card

* Sound card

* Mother board

### Computer Software

The data and instructions that are sent to the hardware are called software, it allows the computer to act in the specific purpose it is programmed to. Usually the component software used are as follows:

* Operating system

* Computer programs (such as Adobe, Sage, QuickBooks, etc.)

These can be password protected in order to restrict access to only certain members of staff.
