## Spreadsheets

To provide financial budgets or cash flow budgets, and non current asset registers, businesses use online spreadsheets as convenient data storage units, also used to calculate loan interest payments, and many other sums.

* Computer software spreadsheets allows data to be presented in a tabular format, in which the electronic document can be saved and updated when necessary.

* A spreadsheet is a series of cells presented in rows and columns in which numerical data or words are entered into the sheet.

* When data has been input into the spreadsheet, the user can use preexisting programmed calculations, this speeds up the process of inputting data into the spreadsheets.

* Because of the set formulae, spreadsheets are able to automatically total columns and rows as needed.

* It can also be used as a planning tool for  different scenarios such as increases and decreases in revenue and how this impacts profit.
