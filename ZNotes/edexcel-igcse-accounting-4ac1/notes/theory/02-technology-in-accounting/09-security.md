## Security

All organizations consider their financial information as sensitive and therefore take measures to protect it’s confidentiality. The only exception to this is if a legislation demands that certain information is made available to external bodies and released to the public.

* Preventing unauthorized access to sensitive financial information and electronic accounting data is extremely important for a business.

All computerised accounting systems in a company typically have allocated passwords that are put to restrict access to the employees specific area of work.

* Passwords should be changed regularly to prevent non-authorised personnel from accessing the system.

* Computer systems have packages to resist viruses and attacks by hacking, such systems need to be constantly reviewed and updated.

* Most medium-sized or large organizations typically prefer computer networks over standalone computers, and this requires extra security measures (such as making sure the network is private).

### Prevention Measures

In order to protect an operating systems hardware and software, measures such as the following can be taken to ensure no malicious person can access confidential information:

* Install a firewall

  * Controls the information coming in and going out the computer and blocks internet traffic based on security features implemented

* Install antivirus software

  * Detects and removes and potential viruses on the computer and prevents new viruses from damaging stored files.

* Install anti-spyware software

  * Stops malware from being installed on the computer, preventing other users from looking at any work or taking control of the computer.

* Use complex and secure passwords

  * Strong passwords usually contain upper and lowercase letters, numbers and symbols. Passwords must be changed regularly.

* Check your security settings on your internet browsers

  * It is possible to set the internet zone security to high on a browser in order to not enter any malicious websites.
