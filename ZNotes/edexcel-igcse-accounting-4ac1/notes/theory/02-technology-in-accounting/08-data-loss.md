## Data Loss

* Data protection is essential for any business for a multitude of reasons such as record maintenance, access and security. It is extremely important that the data held on a computer is regularly saved and protected against data loss.

* There are different methods of storing electronic data, such as hard drives or memory sticks, both of which can be encrypted and password protected, restricting access to stolen data in the case that the disk is lost.

* Operating systems often have an option to automatically back-up data, meaning a temporary copy of the own document is created in the case in which it is lost or not saved.

* If data is lost, backed-up data can recover the original information, allowing to restore the accounts back, some operating systems can restore data to a specific back-up version, or to the last saved version.

* If the data is not backed-up, it’s necessary to activate ‘restore’ functionality, otherwise, it may risk all of the accounts being deleted and the accountant may have to start from scratch all over again.
