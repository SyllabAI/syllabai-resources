## Reciprocal Functions

The graph of $\frac{1}{f(x)}$ can be deduced from the graph of $f(x)$ using the following relation:

| Points/lines on $f(x)$ | Corresponding points/lines on $\frac{1}{f(x)}$ |
|----|----|
| $x$ intercept at $(a, 0)$ | Vertical asymptote $\ x = a$ |
| Vertical asymptote $\ x = a$ | $x$ intercept at $(a, 0)$ |
| Horizontal asymptote $\ y = b, \ b \ \cancel{=} \ 0$ | Horizontal asymptote $\ y = \frac{1}{b}$ |
| If Horizontal asymptote $\rightarrow \ y = 0$ | No horizontal asymptote formed |
| Oblique asymptote $\ y = mx + c$ | Horizontal asymptote $\ y = 0$ |
| Maximum point $(a, b)$, $\ b \ \cancel{=} \ 0$ | Minimum point $(a, \frac{1}{b}), \ b \ \cancel{=} \ 0$ |
| Minimum point $(a, b), \ b \ \cancel{=} \ 0$ | Maximum point $(a, \frac{1}{b}), \ b \ \cancel{=} \ 0$ |
| As $\ f(x) \rightarrow \pm \ \infty$ | $\ \frac{1}{f(x)} \rightarrow 0$ |
| As $\ f(x) \rightarrow 0$ | $\frac{1}{f(x)} \rightarrow \pm \ \infty$ |
| $f(x)$ is increasing | $\frac{1}{f(x)}$ is decreasing |
| $f(x)$ is decreasing | $\frac{1}{f(x)}$ is increasing |

* The curves $f(x)$ and $\frac{1}{f(x)}$ intersect at $y = 1$ and $y = -1$


---

Let us use the sketch of the rational function

$$

f(x) = \frac{x^2 - 1}{x^2 - 2}
$$

 ![Graph of f(x)](../../../assets/ed18a91f6374-668ae902a4169d60c5b16c423b75e9430903238d881b84f3.26)

* The red curve represents the function $f(x)$
  * The green line represents the horizontal asymptote $\ y = 1$
  * The purple line represents the vertical asymptote $\ x = \sqrt{2}$
  * The black line represents the vertical asymptote $\ x = -\sqrt{2}$

To draw the function, $f(x)$ , we first note that both the $x$-intercepts turn into vertical asymptotes. The vertical asymptotes on turn into $x$-intercepts for $\frac{1}{f(x)}$ . The horizontal asymptote stays the same. The minimum point on $f(x)$ turns into a maximum point on $\frac{1}{f(x)}$. It is also good to observe that wherever $f(x)$ is decreasing, $\frac{1}{f(x)}$ is increasing.

$$

\frac{1}{f(x)} = \frac{x^2 - 2}{x^2 - 1}

$$
