## Sensational Expressions

* Avoir is used to describe sensations as well as other feelings
* **Note:** Être cannot be used in place of Avoir in the following expressions

| Expression | Meaning |
|----|----|
| Avoir faim | To be hungry |
| Avoir soif | To be thirsty |
| Avoir sommeil | To be sleepy |
| Avoir peur (de) | To be scared (of) |
| Avoir honte (de) | To be ashamed (of) |
| Avoir mal (à) | To be hurt (To hurt a body part) |
| Avoir chaud | To be warm |
| Avoir froid | To be cold |
| Avoir raison | To be right (correct) |
| Avoir tort | To be wrong |
| Avoir de la chance | To be lucky |

### Age

* The expression “avoir (number) ans” is used to say the age of someone or something
* **Note:** Être cannot be used in place of Avoir
* **Example:** J’ai 21 ans. (I am 21 years old.)
