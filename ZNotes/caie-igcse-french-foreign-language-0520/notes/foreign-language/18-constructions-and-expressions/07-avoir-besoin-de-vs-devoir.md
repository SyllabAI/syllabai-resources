## Avoir besoin de vs. Devoir

* *Avoir besoin de* is used to describe a need or necessity or a necessity to live/exist
* *Devoir* is used to describe an obligation
* **Note:** Nouns can be used with *Avoir besoin de* when it is needed (Ex. an ingredient in a recipe)

**Examples:**

Je dois travailler. (I have to work.) *I have to work because I’m obliged to*

J’ai besoin de travailler. (I need to work.) *I need to work because I’ll die if I don’t*
