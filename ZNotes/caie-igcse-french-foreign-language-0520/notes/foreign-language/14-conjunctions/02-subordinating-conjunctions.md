## Subordinating Conjunctions

* They link a dependent clause with an independent clause
* **Example**: *Il a réussi parce qu’il a beaucoup travaillé*. (He
  succeeded because he worked a lot.)

|    |    |
|----|----|
| Comme | As, since |
| Puisque | As, since |
| Lorsque | When |
| Si | If |
| Parce que | Because |
| Pourquoi | Why |
| Quand | When |
