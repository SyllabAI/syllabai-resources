## Future Tense

* Used to express actions that will happen sometime in the future or actions that will undoubtedly happen

**Formation:**

$$
\text{Subject} + \text{Future}\ \text{stem} + \text{Suffix}
$$

* To form the future stem, use -ir and -er verb infinitives
* For –re verbs, remove the -e

| Subject | **Suffix** |
|----|----|
| **Je** | -ai |
| **Tu** | -as |
| **Il/Elle/On** | -a |
| **Nous** | -ons |
| **Vous** | -ez |
| **Ils/Elles** | -ont |

**Example:** descendre → descendr (future stem)= Nous descendrons (We will go down)

* There are also irregular stems in the future that must be remembered. Common ones include:

| Infinitive | Meaning | Irregular Stem |
|----|----|----|
| Être | To be | ser- |
| Avoir | To have | aur- |
| Aller | To go | ir- |
| Faire | To do; To make | fer- |
| Savoir | To know | saur- |
| Vouloir | To want | voudr- |
| Pouvoir | To be able to (can) | pourr- |
| Voir; Envoyer | To see; To send | verr- ; enverr- |
| Recevoir; Décevoir; Devoir; (and other verbs that end in *-evoir*) | To receive; To disappoint; To have to (must) | recevr- ; décevr- ; devr |
| Mourir | To die | mourr- |
| Venir; Tenir (and other verbs that end in *-enir*) | To come; To hold | viendr- ; tiendr- |
