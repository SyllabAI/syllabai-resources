# Tenses

## Present Tense

* Both present and present continuous tenses in English are conveyed in one single tense in French.
* Remove -er/-ir/-re from the ending of the verb to form the present
  stem
* Add the ending from the table below.

|    | **-er** | **-ir** | **-re** |
|----|----|----|----|
| **Je** | -e | -is | -s |
| **Tu** | -es | -is | -s |
| **Il/Elle/On** | -e | -it |    |
| **Nous** | -ons | -issons | -ons |
| **Vous** | -ez | -issez | -ez |
| **Ils/Elles** | -ent | -issent | -ent |

* **Example:** regarder → regard (present stem)Tu (regard + es) = Tu regardes (You are watching *or* You watch)
* **Note:** irregular verbs do not follow this pattern
