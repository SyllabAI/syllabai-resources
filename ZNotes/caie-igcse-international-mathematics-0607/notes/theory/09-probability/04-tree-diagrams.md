## Tree diagrams

Tree diagrams are a visual representation used in probability to map out all possible outcomes of a sequence of events

### **How to draw**

1. **Identify the Events**: Determine the sequence of events you are analyzing.

2. **Draw the First Event**: Start with a node and draw branches for each possible

   outcome of the first event

3. **Draw Subsequent Events**: From each branch of the first event, draw branches for the

   next event's possible outcomes

4. **Assign Probabilities**: Write the probability of each outcome on the corresponding

   branch

5. **Calculate Combined Probabilities**: Multiply the probabilities along each path to find

   the probability of the sequence of events

Example :

1. Flipping a coin twice:

   ![](https://images.znotes.org/allimages/95c6ad77455a1730b91c9c5a.webp =650x)

   * Probabilities for 2 heads $= 0.5 \times 0.5 = 0.25$

   * Probabilities for a head then a tail $= 0.5 \times 0.5 = 0.25$

2. Drawing Two Balls Without Replacement, A bag contains 3 red balls and 2 blue balls. We draw two balls without replacement

   ![](https://images.znotes.org/allimages/95c6ad77455a1730b91c9c5a.webp =650x)

   * Probabilities are :

     $$
     \text{RED, RED} = \dfrac{3}{5} \times \dfrac{2}{4} = \dfrac{3}{10}
     $$

     $$
     \text{RED, BLUE} = \dfrac{3}{5} \times \dfrac{2}{4} = \dfrac{3}{10}
     $$

     $$
     \text{BLUE, RED} = \dfrac{2}{5} \times \dfrac{3}{4} = \dfrac{3}{10}
     $$

     $$
     \text{BLUE, BLUE} = \dfrac{2}{5} \times \dfrac{1}{4} = \dfrac{1}{10}
     $$
