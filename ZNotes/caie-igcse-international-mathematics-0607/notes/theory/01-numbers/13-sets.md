## Sets

* Collection of distinct items called elements

* Elements are written inside curly brackets {}

* Example: A={1,2,3,4….}

### **Types of sets**

* Null / Empty Set

  * A set with no elements

  * represented by {} or $\emptyset$

* Universal Set

  * A set that contains all the elements that are discussed

  * Represented by $U$

* Finite Set

  * A set with limited number of elements

  * Example: B={2,4,6,8}

* Infinite Set

  * A set with unlimited elements

  * Example: Set of $N$ ={1,2,3,4,5,…}

### **Set Notations**

* Number of elements in set

  * Represented by $n(X)$

  * $n(A) = 10$ means there are 10 elements in set A

* Element of a set:

  * represented by $\in$

  * $a\in A$ means $a$ belongs to Set $A$

* Not a element of :

  * Represented by $\notin$

  * $a\notin A $ means $a$ is not a element of $A$

* Subset :

  * Represented by $\subseteq$

  * $A\subseteq B$ means all elements of $A$ is also an element of $B$

  * Example: $A$ = {1,2} , $B$ = { 1,2,3,4 } therefore $A\subseteq B$

* Proper Subset  :

  * Represented by $\subset$

  * $A\subset B$ means $A$ is a subset of $B$ but $A\neq B$

  * $A$ has fewer elements than $B$

  * Example: A= {1,2} , B= {1,2,3} therefore $A\subset B$

* Union :

  * Represented by $\cup$

  * States that the set of elements are in $A$ **or** $B$ **or** Both

* Complement Set :

  * Represented by $N'$, where $N$ is any set

  * Example: $A’$ States that it has all elements except the elements of $A$

* Intersection :

  * Represented by $\cap$

  * $A\cap B$ means all elements in $A$ **and** $B$
