## Types of Functions

### Linear functions

* General Form: $f(x) = ax +b$

* Graph: Always  a straight line

* Domain: All real numbers

* Range: All real numbers

* Gradient-Intercept Form: $y= mx +c$

  * $m$ is the gradient

  * $c$ is the y-intercept

![](https://images.znotes.org/allimages/d499df6cd50b932bae7f63b2.webp =400x)

### **Quadratic functions**

* General Form: $f(x) = ax^2 +bx +c$
* Graph: A parabola curve
* Domain: All real numbers
* Range: Depends on the direction
  * If $a> 0 $ the curve open upwards

  * If $a< 0$ the curve open downwards
* Completed square Form : $f(x) = a(x + h)^2+k$, where vertex is (-h, k)

![](https://images.znotes.org/allimages/19656d8c1b8da98e603bc9a0.webp =400x)

### **Cubic functions**

* General Form : $f(x) = ax^3 + bx^2 + cx +d$

* Graph: An "S”- shaped curve that extend infinitely in both directions

* Domain: All real numbers

* Range: All real numbers

![](https://images.znotes.org/allimages/2861cc654c727d8e94a6375a.webp =400x)

### **Reciprocal functions**

* General Form: $f(x) = \dfrac{a}{x}$

* Graph: Hyperbola

* Vertical asymptote: A line that comes near $x = a$ but never touches it

* Horizontal asymptote: A line that comes near $y=b$ but never touches it

* Domain: All real numbers except $x = 0 $

* Range: All real numbers except $ f(x) = 0$

![](https://images.znotes.org/allimages/356606c4215dbb186e79dd4d.webp =400x)

### **Exponential functions**

* General Form: $a^x$ with $x>0$ where $a\neq 0 $

* When $a>0$ its an increasing curve

* When $0<a<1$ its a decreasing function

* Graph: Exponential curve

* Domain: All real numbers

* Range: $f(x)> 0$

![](https://images.znotes.org/allimages/6815453376c2eab5d8bd4fd5.webp =400x)

### **Absolute Functions**

* General Form : $f(x)=\|x\|$

* Graph : v shaped

* Domain : All real numbers

* Range : $f(x) \ge 0$

![](https://images.znotes.org/allimages/afeeb63829e2e5b8c89b2861.webp =400x)

### **Trigonometric Functions**

* **$f(x) = a sin (bx)$**

  * Amplitude: \| a \|

  * Period: $\frac {360}{b}$

    ![](https://images.znotes.org/allimages/029a1543cff6ae2cd44e07eb.webp =400x)

* **$f(x) = a cos (bx)$**

  * Amplitude: \| a \|

  * Period: $\frac {360}{b}$

    ![](https://images.znotes.org/allimages/1ff47ea99049d3b3ea39e365.webp =400x)

* **$f(x) = a tan (bx)$**

  * Amplitude: None

  * Period: $\frac{180}{b}$

    ![](https://images.znotes.org/allimages/83bf7094724ed3e9ff820de6.webp =400x)
