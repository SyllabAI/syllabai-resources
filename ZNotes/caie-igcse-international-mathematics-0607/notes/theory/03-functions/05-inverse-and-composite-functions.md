## Inverse and Composite Functions

### **Inverse Function**

* An inverse function essentially "reverses" the action of a function. If you have a function f(x) that maps an input x to an output y, the inverse function $f^{−1}(x)$ maps $y$ back to $x$
* **Steps :**
  1. Write $y = f(x)$

  2. Swap $x$ and $y$

  3. Solve for $y$

  4. Write $f^{-1}(x) = y$
* Example : Find the inverse of $f(x) = 2x + 3$
  * $y = 2x + 3$

  * Swap $x$ and $y$: $x = 2y + 3$

  * Solve for $y$: $y = \dfrac{x-3}{2}$

  * So, $f^{-1}(x) = \dfrac{x-3}{2}$

### Composite Function

* A composite function is a function formed when the output of one function is used as the input of another function,

  written as $gf(x)$ or $g(f(x))$

* Order matters in this case so $f(g(x)) \neq g(f(x))$

* **Steps to find a composite function:**

  1. Identify the inner function

  2. Substitute inner function into the outer function wherever $x$ occurs

  3. Simplify to get composite function

* Example: Find g(f(x)), where $f(x) = x^2$ and $g(x) = 2x + 1$

  $ f(g(x)) = (2x+1)^2$

  $ g(f(x)) = 2x^2 + 1$
