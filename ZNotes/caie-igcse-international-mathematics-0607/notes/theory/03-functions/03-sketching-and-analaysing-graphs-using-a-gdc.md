
## Sketching and Analaysing Graphs using a GDC

### Sketching a Graph Using a GDC

Steps:

1. Enter the function into the GDC (Y= or f(x)= mode)

2. Set a suitable **window** (choose x- and y-values that show the shape clearly)

3. Plot the graph

4. Sketch the graph seen on the screen onto paper

### **Producing a Table of Values Using a GDC**

### Steps:

1. Enter the function

2. Select **TABLE** mode

3. Choose a suitable starting x-value and step size

4. Read values of x and f(x) from the table

5. Copy these into a table

### **Plotting Points Using a GDC**

Steps:

1. Generate a table of values on the GDC

2. Plot the corresponding points on graph paper

3. Join points smoothly based on the GDC graph

### **Finding Zeros (x-intercepts) Using a GDC**

Zeros are where the graph crosses the x-axis.

Steps:

1. Plot the graph

2. Use the **zero / root / solve** function

3. Select the curve

4. Read the x-value(s)

### **Finding Local Maximum or Local Minimum Using a GDC**

Steps:

1. Plot the graph

2. Choose **maximum** or **minimum** from the GDC menu

3. Select the curve

4. Read the coordinates of the turning point

### **Finding Points of Intersection Using a GDC**

Points of intersection occur where two graphs meet.

### Steps:

1. Enter both functions

2. Plot both graphs on the same screen

3. Use **intersection** function

4. Select both curves

5. Read the coordinates

### **Finding the Vertex of a Quadratic Using a GDC**

The vertex is the turning point of a quadratic graph.

### Steps:

1. Enter the quadratic function

2. Plot the graph

3. Use:

   * **minimum** → if the parabola opens upwards

   * **maximum** → if the parabola opens downwards

4. Read the coordinates of the vertex

### **Tips for GDC Questions**

* Always state answers as **coordinates when required**

* Round values according to the question

* Sketch what you see on the GDC, not what you assume

* Check for multiple solutions (especially intersections and zeros)

* If the graph is not clear:

  * Increase or decrease x-range

  * Increase or decrease y-range

  * Re-plot until key features are visible
