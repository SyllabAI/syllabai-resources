## Transforming graphs of function

### **Horizontal Translation**

* If a function $f(x)$ is translated horizontally by h units

* $y=f(x−h)$

* Vector : $\begin{pmatrix} h \\ 0 \end{pmatrix}$

* If $h$>0, the graph shifts to the right

* If $h$ < 0, the graph shifts to the left

### **Vertical Translation**

* If a function f(x) is translated vertically by k units

* y=f(x)+k

* Vector: $\begin{pmatrix} 0 \\ k \end{pmatrix}$
