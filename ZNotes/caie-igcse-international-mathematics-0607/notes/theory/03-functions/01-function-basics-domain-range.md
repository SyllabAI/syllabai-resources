# Functions

## Function Basics: Domain & Range

* A function is a relation in which every input is mapped to exactly one output

* Notation of Function: $f(x)$ this represents the output when there is an input $x$

* Domain: the **set of all possible input values** for which the function is defined (the $x$ values)

* Range: the **set of all possible output values** produced by the function (the $y$ values)
