## Asymptotes

An asymptote is a line that a graph of a function approaches but never actually touches no matter how far we extend it

Usually present in reciprocal and tangent functions

### **Vertical asymptote**

* $x$ value of asymptotes

* Happens when the function is **not defined** at a certain value of $x$

* Usually caused by **division by zero**

* For $f(x)=\frac{1}{x-3}$

  * Vertical asymptote: $x=3$

  * The graph goes **up or down very steeply** near $x=3$

    ![](https://images.znotes.org/allimages/25978de8a11c5444dee04945.webp =400x)

### **Horizontal asymptote**

* $y$ value asymptotes

* If the numerator grows faster than the denominator, the graph does not have a horizontal asymptote

* $f(x)=\frac{1}{x}$ → Horizontal asymptote: $y=0$

  ![](https://images.znotes.org/allimages/356606c4215dbb186e79dd4d.webp =400x)

Note : $tan x$ has asymptotes at $90\degree$, $270\degree$, etc.
