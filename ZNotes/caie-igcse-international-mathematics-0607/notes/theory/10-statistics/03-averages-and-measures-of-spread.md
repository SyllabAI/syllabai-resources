## Averages and measures of spread

**Key Terms**

1. Mean : Average value

2. Median : Middle value when data is arranged in order

   * Odd number of values → middle number

   * Even number of values → mean of the two middle numbers

3. Mode: Value that occurs most often

4. Range : Highest value - Lowest value

   * Small range $\rightarrow$ data is consistent

   * Large range $\rightarrow$ data is spread out / inconsistent

5. Upper quartile : Value below which 75% of the data lies, when the data is arranged in ascending order

6. Lower quartile : Value below which 25% of the data lies, when the data is arranged in ascending order

7. Interquartile range : Spread of the middle 50% of the data
