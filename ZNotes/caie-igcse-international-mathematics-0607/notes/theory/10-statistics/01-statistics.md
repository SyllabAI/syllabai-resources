# Statistics

## Types of data

**Discrete data**

* Data that can take only specific, separate values (usually whole numbers)

* Obtained by counting

* No values in between

* **Examples:**

  * Number of students in a class

  * Number of cars in a parking lot

  * Number of goals scored

**Continuous data**

* Data that can take any value within a range

* Obtained by measuring

* Can include decimals

* **Examples:**

  * Height of students

  * Weight of a bag

  * Time taken to run a race
