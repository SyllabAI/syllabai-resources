## Simultaneous Linear equations

* Simultaneous linear equations are two linear equations with two unknowns that are solved at the same time to find values that satisfy both equations

* Methods for solving:

  1. Elimination

  2. Substitution

### **Elimination**

This method eliminates one variable by adding or subtracting the equations

1. Write the equations in a standard form, and align the variables

   $\qquad 2x + 3y = 21$

   $\qquad x - y = -2$

2. Multiply one or both equations to make the coefficients of one of the variables the same with opposite signs

   $\qquad 2x + 3y = 21$

   $\qquad(x - y = -2) \times 3$

   $\qquad3x - 3y = -6$

3. Cancel out one of the variables and solve for the other one

   $\qquad \quad \phantom{3}\ 2x + \cancel{3y} = 21$

   $\qquad +\quad 3x - \cancel{3y} = -6$

   $\qquad \rule{3.5cm}{0.4pt}$

   $\qquad \qquad 5x \phantom{+ \cancel{3y}}= 15$

   $\qquad x = 3$

4. Solve for the variable that we cancelled out earlier

   $\qquad x - y = -2$

   $\qquad y = x + 2$

   $\qquad y = (3) + 2 = 5$

### **Substitution**

This method substitutes one equation into the other

* Rearrange one equation to make one variable the subject

  1. $x+y=10$

  2. $4x-y=6$

* Substitute this expression into the second equation and solve the resulting equation

  1. $4x-(10-x)=6$

  2. $4x-10+x=6$

  3. $5x=16$

  4. $x=\dfrac{16}{5}$

* Substitute back the variable found to find the second variable

  1. $y=10-\dfrac{16}{5}$

  2. $y=\dfrac{50-16}{5}$

  3. $y=\dfrac{34}{5}$
