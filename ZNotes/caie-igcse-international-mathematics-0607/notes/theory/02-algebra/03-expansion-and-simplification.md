## Expansion and Simplification

### **Simplifying Expressions**

* We can simplify a expression by **combining like terms**

* Example : $4x+3x−7$ = $7x−7$

### **Expansion**

* Multiplying out algebraic expressions (removing brackets using the distributive property)

* Example :

![](https://images.znotes.org/allimages/2cfd486be7201410f750f649.webp =400x)

* $(3 + 5y)(2x - 4)$

  * Distribute each term:

    $= 3(2x - 4) + 5y(2x - 4)$

    $= 3(2x) + 3(-4) + 5y(2x) + 5y(-4)$

    $= 6x - 12 + 10xy - 20y$

  * Rearrange:

    $= 6x + 10xy - 20y - 12$

  * Final Answer:

    $6x + 10xy - 20y - 12$

**Important Expansions**

1. $(a+b)^2$ = $a^2 + 2ab + b^2$

   * Example: $(x+5)^2$ = $x^2 + 2(x)(5) +5^2$
     * $= x^2 + 10x + 25$

2. $(a-b)^2$ = $a^2 -2ab +b^2$

   * Example: $(x-2)^2$ = $x^2 + 2(x)(2) +2^2$
     * $= x^2 - 4x + 4$

3. $(a+b) \times (a-b)$ = $a^2 - b^2$

   * Example: $(x+2) \times (x-2)$ = $x^2 - 2^2$
     * $= x^2 - 4$

4. $a^2 x^2 - b^2y^2 = (ax - by)(ax+ by)$

   * Used when both terms are perfect squares and the symbol between the two terms is $"-”$

   * Example: $9x^2 - 16y^2$

     *  = (3x - 4y)(3x + 4y)$
