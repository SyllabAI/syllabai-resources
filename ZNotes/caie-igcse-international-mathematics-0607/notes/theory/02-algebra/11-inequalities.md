## Inequalities

* A mathematical statement indicating that one expression is not equal to another. It can show that one value is greater than, less than, or not equal to another value

* **Symbols:**

  * $>$ is greater than

  * $<$  is less than

  * $≥$  is greater than or equal to

  * $≤$ is less than or equal to

  * $≠$ is not equal to

* To write an inequality, determine the relationship between the expressions

  * For example, if $x$ is greater than 5, it is written as $x>5$

  * $1<x<5$ means $x$ is between 1 and 5

### **Representing Inequalities on a number line**

* Open circles represent strict inequalities ( $>,<$)

* Shaded circles are closed circles that represent inclusive inequalities ( $\le$, $\ge$ )

### **Solving Inequalities**

* Solve $2x−5<3$

  * $2x<8$

* Divide by $2 x< 4$

* Solve $x^2−4x−5<0$

  * $x^2−4x−5=0$

  * Factor the quadratic if possible

  * $(x−5)(x+1)=0$

  * Roots are $x=5$ and $x=−1$

* Important Rule : When you multiply or divide both sides by a negative number, reverse the inequality sign

  * Example : $2x < 6$

    * Divide both sides by $−2$

      $x>−3$

### **Graphical Representation of Inequalities**

* Broken/dashed/dotted line used to represent strict inequalities ($>$, $<$)

* Solid lines represent inclusive inequalities ( $\le$, $\ge$ )

### **Solve inequalities using GDC**

* Rewrite the inequality so that **one side is zero**

* Enter the expression into the GDC

* Plot the graph

* Find where the graph is **above or below the x-axis**

* State the solution using inequality notation

  * Pick a test point not on the line (commonly (0,0) if it's not on the line)

  * Substitute the test point into the inequality

  * If the inequality is true, shade the region containing the test point

  * If the inequality is false, shade the opposite region.
