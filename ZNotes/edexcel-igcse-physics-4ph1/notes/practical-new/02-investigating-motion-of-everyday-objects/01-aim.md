# Investigating Motion of Everyday Objects

## Experimental Setup

### Aim

To investigate the motion of everyday objects by measuring the **average speed** of a toy car or tennis ball moving over a measured distance.

For the ramp investigation, investigate how changing the **height of the ramp**, \\(h\\), affects the average speed.

### Apparatus

* toy car

* tennis ball

* wooden runway/ramp

* metre rule

* stop clock

* clamp/support

* marker

### Variables

* **Independent variable:** ramp height, $h$

* **Dependent variable:** average speed, $v$

* **Control variables:** fixed distance $s=AB$, same starting point $A$, same ramp, same release method, and the same object within each set of measurements.

Carry out a complete set of measurements with the **toy car**, then repeat the motion investigation using a **tennis ball**.
