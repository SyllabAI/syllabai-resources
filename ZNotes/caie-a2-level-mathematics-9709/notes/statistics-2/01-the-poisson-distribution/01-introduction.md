# The Poisson Distribution

## Introduction

* The **Poisson distribution** is used as a model for the
  number$,\ X,$ of events in a given interval of space or time. It
  has the probability formula

$$
P( X = x) = e^{- \lambda}\frac{\lambda^{x}}{x!} \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ x = 0,\ 1,\ 2,\ldots
$$

Where $\lambda$ is equal to the mean number of events in the given
interval

* A Poisson distribution with mean $\lambda$ can be noted as

$$
X\ \sim\ Po(\lambda)
$$
