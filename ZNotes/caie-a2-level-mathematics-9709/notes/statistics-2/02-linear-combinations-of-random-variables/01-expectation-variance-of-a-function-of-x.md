# Linear Combinations of Random Variables

## Expectation & Variance of a Function of $\mathbf{X}$

$$E\left( aX + b \right) = aE\left( X \right) + b$$

$$\text{Var}\left( aX + b \right) = a^{2}\text{Var}\left( X \right)$$

**<span class="underline">{IS Ex 6a} Question 12:</span>**

The random variable $T$ has mean 5 and variance 16. Find two pairs of
values for the constants $c$ and $d$ such that
$E\left( cT + d \right) = 100$ and
$\text{Var}\left( cT + d \right) = 144$

**<span class="underline">Solution:</span>**

*Expand expectation equation:*

$$E\left( cT + d \right) = cE\left( T \right) + d = 100$$

$$\therefore 5c + d = 100$$

*Expand variance equation:*

$$\text{Var}\left( cT + d \right) = c^{2}\text{Var}\left( T \right) = 144$$

$$16c^{2} = 144$$

$$c = \pm 3$$

*Use first equation to find two pairs:*

$$c = 3,\ \ d = 85c = - 3,\ \ d = 115$$
