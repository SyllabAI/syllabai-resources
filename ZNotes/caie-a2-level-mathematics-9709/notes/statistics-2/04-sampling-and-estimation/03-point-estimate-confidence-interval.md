## Point Estimate & Confidence Interval

* A **point estimate** is a numerical value calculated from a set of
  data (sample) which is used as an estimate of an unknown parameter
  in a population
* Examples of point estimates are:


|Sample mean $\overline{x}$|population mean $\mu$|
|:---|:---|
|Sample proportion $\frac{r}{n}$|population proportion $p$|
|Sample variance $s^{2}$|population variance $\sigma^{2}$|

* Point estimate close to population value but not exact
* We can determine a **confidence interval** where the population
  value is likely to lie in
  $(\overline{x} - \delta,\ \ \overline{x} + \delta)$
