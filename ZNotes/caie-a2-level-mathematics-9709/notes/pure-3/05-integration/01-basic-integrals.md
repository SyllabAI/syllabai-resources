# Integration

## Basic Integrals

$$
\text{ax}^{n}\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ a\frac{x^{n + 1}}{(n + 1)} + c
$$

$$
e^{ax + b}\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \frac{1}{a}e^{ax + b}
$$

$$
\frac{1}{ax + b}\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \frac{1}{a}\ln\left| ax + b \right|
$$

$$
\sin\left( ax + b \right) \ \ \ \ \ \ \ \ \ \ \ \ \ \ \  - \frac{1}{a}\cos{(ax + b)}
$$

$$
\cos\left( ax + b \right)\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \frac{1}{a}\sin\left( ax + b \right)
$$

$$
\sec^{2}\left( ax + b \right)\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \frac{1}{a}\tan\left( ax + b \right)
$$

$$
\left( ax + b \right)^{n}\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \frac{\left( ax + b \right)^{n + 1}}{a(n + 1)}
$$

$$
\frac{1}{x^{2} + a^{2}}\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \frac{1}{a}\tan^{- 1}\left( \frac{x}{a} \right)
$$

- Integration reverses a differentiation. It is the reverse of
    differentiation.
- Use trigonometrical relationships to facilitate complex
    trigonometric integrals.
- Integrate by decomposing into partial fraction.
