## Polynomials 

  - To find unknowns in a given identity, either
    
      - Substitute suitable values of $x$

      - Equalize given coefficients of like powers of $x$

<!-- end list -->

  - **Factor theorem:** If $\left( x - t \right)$ is a factor of the
    function $p\left( x \right)$ then $p\left( t \right) = 0$

  - **Remainder theorem:** If the function $f\left( x \right)$ is
    divided by $\left( x - t \right)$ then the remainder:
    $R = f\left( t \right)$

$$\text{Dividend} = \text{Divisor} \times \text{Quotient} + \text{Remainder}$$
