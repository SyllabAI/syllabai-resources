## Parallel, Skew or Intersects

**For the two lines:**

$\overrightarrow{\text{OA}} = \widetilde{\mathbf{a}} + s\widetilde{\mathbf{c}}$
$\overrightarrow{\text{OB}} = \widetilde{\mathbf{b}} + t\widetilde{\mathbf{d}}$

  - **Parallel:**
    
      - For the lines to be parallel $\widetilde{\mathbf{c}}$ must
        equal $\widetilde{\mathbf{d}}$ or be in some ratio to it e.g.
        $1:2$

  - **Intersects:**
    
      - Make $\overrightarrow{\text{OA}} = \overrightarrow{\text{OB}}$
    
      - If simultaneous works then intersects
    
      - If unknowns cancel then no intersection

  - **Skew:**
    
      - First check whether line parallel or not
    
      - If not, then make
        $\overrightarrow{\text{OA}} = \overrightarrow{\text{OB}}$
    
      - Carry out simultaneous
    
      - When a pair does not produce same answers as another, then lines
        are skew
