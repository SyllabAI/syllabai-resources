# Differentiation

## Basic Derivatives

$$
x^{n}\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ nx^{n - 1}
$$

$$
e^{u}\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ {\frac{\text{du}}{\text{dx}}e}^{u}
$$

$$
\ln u\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \frac{\frac{\text{du}}{\text{dx}}}{u}
$$

$$
\sin{(ax)}\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ a\cos{(ax)}
$$

$$
\cos{(ax)}\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \  - a\sin{(ax)}
$$

$$
\tan{(ax)} \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ a\sec^{2}{(ax)}
$$

$$
tan^{-1}(ax)\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \frac{a}{1 + {(ax)}^{2}}
$$
