## Square Roots

**<span class="underline">Example:</span>**

Find square roots of: $4 + 3i$

**<span class="underline">Solution:</span>**

*We can say that:*

$$
\sqrt{4 + 3i} = a + bi
$$

*Square both sides*

$$
a^{2} - b^{2} + 2abi = 4 + 3i
$$

*Equate real and imaginary parts*

$$
a^{2} - b^{2} = 4\ \ \ \ \ \ \ \ \ \ \ 2ab = 3
$$

*Solve simultaneous equation:*

$$
a = \frac{3\sqrt{2}}{2}\ \ \ \ \ \ \ \ \ \ b = \frac{\sqrt{2}}{2}
$$

$$
\therefore\sqrt{4 + 3i} = \frac{3\sqrt{2}}{2} + \frac{\sqrt{2}}{2}i\ \ \ \ \ \ \ \ \ \ or\ \ \ \ \ \ \ \  - \frac{3\sqrt{2}}{2} - \frac{\sqrt{2}}{2}i
$$
