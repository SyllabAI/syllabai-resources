# Quadratics

## Quadratic Formula

The quadratic formula helps us find the solutions to a quadratic equation, $ax^2 + bx + c = 0$.

It helps us find the values of $x$ for which the quadratic equation equals 0, which are also called the zeros of the quadratic equation for this reason.

<center>Quadratic formula (Given in MF19)</center>

$$

x = \frac{-(b) \pm \sqrt{(b)^2 - 4(a)(c)}}{2a}
$$

So each of the roots of the quadratic equation $ax^2 + bx + c = 0$ are

$$

x = \frac{-b + \sqrt{b^2 - 4ac}}{2a}
$$

<center>And</center>

$$

x = \frac{-b - \sqrt{b^2 - 4ac}}{2a}
$$


### Factorisation

Factorisation allows us to express a polynomial as the **product** of simpler terms.

For example:

$$

 x^2 - 2x - x + 2 = (x - 1)(x - 2)
$$

Factorisation of a quadratic can be done through two methods:

* splitting the middle term
  * Re-writing $ax^2 + bx + c = 0$ as $ax^2 + dx + ex + c = 0$ [Where $d \times e = a \times c$ and $dx + ex = bx$]
  * Then factoring out the common factors in the equation
* A calculator
  * Using the “mode” button and then selecting the type of equation. This will give us the solutions to a quadratic equation, which can then be used to factorise it.


---

**<center>Example 1</center>**

Solve the quadratic equation $6x^2 - 17x + 5 = 0$ using the quadratic formula.

**<center>Answer</center>**

Here $a = 6, b = -17, c = 5$. Using the quadratic formula

$$

x = \frac{-(-17) \pm \sqrt{(-17)^2 - 4(6)(5)}}{2(6)}
$$

So the 2 values of $x$ which satisfy the equation are

$$

x = \frac{5}{2} ~ \text{and} ~ x = \frac{1}{3}
$$

**<center>Example 2</center>**

Solve the quadratic equation $6x^2 - 17x + 5 = 0$ using factorisation.

**<center>Answer</center>**

This can be factorised as

$$

(2x - 5)(3x - 1) = 0
$$

* Logically, if we have $ab = 0$ then either $a = 0$ or $b = 0$.

$$

2x - 5 = 0 \implies x = \frac{5}{2}
$$

$$

3x - 1 = 0 \implies x = \frac{1}{3}
$$
