## Histograms

* A bar chart which represents continuous data
* Bars have no space between them
* Area of each bar is proportional to frequency

$$
Frequency = Frequency\ Density \times Class\ Width
$$

* For open ended class width, double the size of previous class width
  and use this
* If range ‘$0 - 9$’ then class width is ‘$- 0.5 \leq x \leq 9.5$’
