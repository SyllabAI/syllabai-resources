## Addition and Multiplication principle

## Addition Principle

* If an event can occur in $m$ ways and a second event, with **no common outcomes**, can occur in $n$ ways then the first **OR** second event can occur in $m + n$ ways.

 ![](../../../assets/94521cf07d44-66c468c7518059798226f57526d6052abf59ed1f15abb9ee.40)

* The union of these two sets gives us the addition principle
  * |$A ~ \bigcup ~ B$| = |$A$| + |$B$|  \[Where |$x$| denotes the number of elements in that set\]
* A general tip is to use the addition principle when a question uses the word “**or**”
  * To elaborate, it should be used in cases where you are finding the number of different cases which do not happen at the same time.

## Multiplication Principle

* If an event can occur in $m$ ways and a second event can occur in $n$ ways, **after** **the first event has occurred**, then the two events can occur in $m \times n$ ways.

 ![](../../../assets/3a0416a3c242-66c468c7518059798226f5752693ebcb2e61cafd99cbcf94.49)

* The intersection of these two sets gives us the multiplication principle
  * |$A \times B$| = |$A$||$B$|  \[Where |$x$| denotes the number of elements in that set\]
* A general tip is to use the multiplication principle when a question uses the word “**and**”
  * To elaborate, it should be used in cases where you are finding the number of different cases which happen at the same time, or after the first event has occurred.
