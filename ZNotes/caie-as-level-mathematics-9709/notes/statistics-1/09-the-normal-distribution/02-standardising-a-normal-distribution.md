## Standardising a Normal Distribution

- To convert any value in the normal distribution $X\sim N(\mu,\ \sigma^{2})$ to the standard normal distribution $N\left( 0,1 \right)$, we use the **standardization** formula
  - This is done as the $z$ values are already given a probability value for the standard normal distribution. 

The $x$ value in the normal distribution is the $z$ value in the standard normal distribution.
$$
z = \frac{x - \mu}{\sigma}
$$

- Note that you divide by the **standard deviation** and not the variance.

- It is also not required to standardise a normal distribution if the continuous random variable is already following a standard normal distribution $X \sim N(0, 1)$.
