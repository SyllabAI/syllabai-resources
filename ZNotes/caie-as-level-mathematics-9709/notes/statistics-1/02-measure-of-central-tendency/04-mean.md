## Mean

* Sum of all data values divided by number of values

$$
\overline{x} = \frac{\sum x_i}{n}
$$

$$
\overline{x} = \frac{\sum x_if_i}{\sum f_i}
$$

* Important as it uses all the data values
* Disadvantage: affected by extreme values
* If data is grouped – use the mid-point of group as $x$

### **Coded mean**

- Coded mean can be thought of as a transformation of all the data values in a data set. It is done to make computation easier.

$$
\textbf{Coded mean of ungrouped data}
$$

$$
\overline{x} = \frac{\sum{(x - b)}}{n} + b
$$

$$
\textbf{Coded mean of grouped data}
$$

$$
\overline{x} =  \frac{\sum{(x - b)f}}{\sum f} + b
$$

- Where $f$ is the corresponding frequency to a value $x$

### **Grouped Mean**

- The mean of 2 sets of data, or grouped mean, can be found by adding all the data values and the number of values.

Suppose a data set $x$ exists where the sum of the data is $\sum x$ and the number of values is $n_x$, and another data set $y$ exists where the sum of the data is $\sum y$ and the number of values is $n_y$.

The mean of this data set is:
$$
\text{Grouped mean} = \frac{\sum x + \sum y}{n_x + n_y}
$$

**Example 1**

A summary of 40 values of $x$ gives the follow information:
$$
\sum(x - k) = 520
$$
Where $k$ is a constant.

Given that the mean of these 40 values of $x$ is 34, find the value of $k$.

**Answer**

As we know the value of $\sum(x - k)$:
$$
\frac{\sum(x - k)}{40} + k = 34 \implies \frac{520}{40} + k = 34
$$
Now we can solve for $k$
$$
k = 34 - \frac{520}{40} = 21
$$

**Example 2**

For $n$ values of of the variable $x$, it is given that:
$$
\sum(x - 50) = 144 \ \ \text{and} \ \ \sum x = 944
$$

Find the value of $n$.

**Answer**

Using the properties of the summation, we can re-write this as
$$
\sum x - 50n = 144
$$
As we know the value of $\sum x$
$$
944 - 50n = 144 \implies 50n + 144 = 944
$$
So we can find the value of $n$ as
$$
50n = 800 \implies n = \frac{800}{50} = 16
$$
