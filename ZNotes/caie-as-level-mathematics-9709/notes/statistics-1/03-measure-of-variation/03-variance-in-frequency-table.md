## Variance in Frequency Table

$$
\frac{\sum{\left( x_i - \overline{x} \right)^{2}f_i}}{\sum f_i}
$$ 
<center>or</center>
$$
\frac{{\sum x_i}^{2}f_i}{\sum f_i} - {\overline{x}}^{2}
$$




**<span class="underline">{W04-P06} Question 4:</span>**

The ages, $x$ years, of 18 people attending an evening class are
summarised by the following totals:

$\sum x = 745$, $\sum x^{2} = 33\ 951$

i.  Calculate the mean and standard deviation of the ages of this group
of people.

ii.  One person leaves group and mean age of the remaining 17 people is
exactly 41 years. Find age of the person who left and standard
deviation of the ages of the remaining 17 people.

**<center>Solution:</center>**

**Part (i):**

$$
\sigma = \sqrt{\frac{\sum x^{2}}{n} - {\overline{x}}^{2}}\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \overline{x} = \frac{\sum x}{n}
$$

$$
\sigma = 13.2\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \overline{x} = 41.4
$$

**Part (ii):**

*The total age of the 18 people*

$$
\sum x = 745
$$

*Find the total age of the 17 people*

$$
\sum x = 41 \times 17 = 697
$$

*Subtract the two to get the age*

$745 - 697 = 48\ years$

*Calculating the new standard deviation*

*Find the* $\sum x^{2}$ *of the 17 people*

$$
\sum x^{2} = 33\ 951 - 48^{2} = 31\ 647
$$

*Find the standard deviation*

$$
\sigma = \sqrt{\frac{31\ 647}{17} - {(41)}^{2}} = 13.4
$$

**<span class="underline">{S13-P62} Question 2:</span>**

A summary of the speeds, $\text{x }$kilometres per hour, of 22 cars
passing a certain point gave the following information:

=$\sum\left( x - 50 \right) = 81.4\ \ \ \ \ \ \ \ $ and
$\ \ \ \ \ \ \ \ \sum\left( x - 50 \right)^{2} = 671.0$

Find variance of speeds and hence find the value of $\sum x^{2}$

**<center>Solution:</center>**

*Finding the variance using coded mean*

Variance $= \frac{671.0}{22} - \left( \frac{81.4}{22} \right)^{2} = 16.81$

*Find the actual sum*

$$
\sum x = 81.4 + \left( 22 \times 50 \right) = 1181.4
$$

*Put this back into variance formula*

$$
16.81 = \frac{\sum x^{2}}{n} - \left( \frac{1181.4}{22} \right)^{2}
$$

$$
\therefore\sum x^{2} = 2900.5 \times 22
$$

$$
\sum x^{2} = 63811
$$
