## **Cloud Computing**

* The sharing of data storage, servers, databases, and computational power over a LAN, WAN, or the internet.

* Resources are distributed across multiple servers in data centres.

* Resources are:

  * Available on demand

  * Accessible over the internet using TCP/IP

  * Device independent (laptops, tablets, smartphones, desktops)

* Requires minimal user setup (often only authenticated login).

* Uses pooled resources shared between users, but:

  * Each user’s data is logically separated and secure.

* Resources can be:

  * Scaled up or down automatically (elasticity).

* Usage can be:

  * Monitored and audited

  * Restricted

  * Billed based on use (pay-as-you-go model).

* Managed and maintained by third-party providers.

* Large clouds operate across multiple distributed data centres for reliability.

### Uses of Cloud Computing

* By individuals:

  * Cloud file storage (e.g., storing personal files online).

  * Accessing files from any device with internet access.

  * Video streaming services.

  * Online gaming platforms.

  * Cloud-based office applications (word processors, spreadsheets).

  * Email and social media services.

  * Automatic file synchronisation across devices.

* By Organisations:

  * Remote access to company resources.

  * Collaboration between employees in different locations.

  * Backup, archiving and disaster recovery.

  * Hosting applications using:

    * IaaS (Infrastructure as a Service) – virtual machines and servers.

    * PaaS (Platform as a Service) – development environments.

    * SaaS (Software as a Service) – cloud-based applications.

  * Reduced need to own hardware/software.

  * Reduced need for in-house IT staff.

  * Scalable computing power for data analysis and business growth.

  * Hybrid cloud setups (private \+ public cloud combination).
