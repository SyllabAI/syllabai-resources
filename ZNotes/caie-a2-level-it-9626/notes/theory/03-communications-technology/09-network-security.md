## Network Security

### Network Security Threats

1. **Brute Force Attacks**

   * When an attacker repeatedly tries different usernames, passwords or encryption keys until the correct one is found.

   * **Impact**

     * Unauthorised access to systems and files

     * Theft, modification or deletion of data

     * Identity theft

   * **Prevention**

     * Strong passwords

     * Account lockouts after failed attempts

     * Multi-factor authentication (MFA)

     * Biometrics

2. **Denial of Service (DoS)**

   * A DoS attack floods a server or network with large numbers of requests, making services unavailable to legitimate users.

   * **Impact**

     * Services become unavailable

     * Loss of productivity

     * Financial losses

     * Reputational damage

   * **Prevention**

     * Firewall filtering

     * Traffic monitoring

     * Detection of abnormal requests

     * Blacklisting attacking IP addresses

     * Network traffic analysis tools

3. **Botnets**

   * A collection of internet-connected devices infected with malware and controlled remotely by a bot herder (attacker).

   * **How they work**

     * Malware infects devices

     * Devices become "bots" or "zombies"

     * Commands are sent from a command-and-control (C&C) server

     * Bots perform actions without the owner's knowledge

   * **Uses**

     * DoS attacks

     * Sending spam emails

     * Collecting login credentials

     * Installing spyware

     * Stealing data

   * **Prevention**

     * Anti-malware software

     * Firewall protection

     * Security updates

     * User awareness

4. **Malware**

   * Software designed to damage systems or gain unauthorised access.

   * **Examples**

     * Viruses

     * Worms

     * Trojans

     * Spyware

     * Ransomware

   * **Impact**

     * Data destruction

     * Data modification

     * Data theft

     * Identity theft

     * System damage

   * **Prevention**

     * Anti-virus software

     * Anti-malware software

     * Anti-spyware software

     * Software updates

     * User training

5. **Malicious Actors (Perpetrators)**

   * Individuals or groups attempting unauthorised access to systems.

   * **Examples**

     * Hackers

     * Cybercriminals

     * Disgruntled Employees

     * Organised crime groups

   * **Possible Actions**

     * Steal data

     * Modify data

     * Delete data

     * Install malware

     * Commit identity theft

6. **Structured Query Language (SQL) Injection**

   * Occurs when malicious SQL code is entered into a database input field.

   * **Purpose**

     * Gain unauthorised database access

     * View confidential records

     * Modify records

     * Delete records

   * **Impact**

     * Data theft

     * Data modification

     * Data destruction

   * **Prevention**

     * Input validation

     * Parameterised queries

     * Access permissions

     * Database security controls

7. **Poor Network Policies**

   * Weak security policies increase vulnerability.

   * **Examples**

     * Weak Passwords

     * Shared Accounts

     * Unauthorised Software Installation

     * Lack of Staff Training

     * Failure to update Software

   * **Prevention**

     * Strong access control policies

     * Regular staff training

     * Software update policies

     * Standardised software use

     * User permissions

### Impact of Network Security Threats

* **Data Destruction**

  * Data is deleted or permanently removed.

  * **Examples**

    * Malware deleting files

    * Attackers removing database records

* **Data Modification / Manipulation**

  * Data is changed without authorisation.

  * **Examples**

    * Changing customer records

    * Altering financial information

    * Modifying database values

* **Data Theft**

  * Unauthorised copying or removal of data.

  * **Examples**

    * Downloading confidential files

    * Stealing customer information

* **Identity Theft**

  * Personal information is stolen and used fraudulently.

  * **Examples**

    * Stolen login credentials

    * Stolen banking details

    * Impersonation of legitimate users

5. **Firewalls and Access Control**

   * A firewall monitors and controls incoming and outgoing network traffic according to security rules.

   * How Firewalls Control Access

     * **Packet Filtering Checks:**

       * Source IP address

       * Destination IP address

       * Port numbers

       * Protocols

       Allows or blocks traffic according to rules.

     * **Port Filtering Checks**

       Allows only specific ports.

       Example:

       * Allow HTTPS (443)

       * Block unused ports

     * **IP Address Filtering Can**

       * Allow trusted IP addresses

       * Block known attackers

     * **Application Filtering**

       * Block peer-to-peer software

       * Block unauthorised applications

     * **Firewall Rules May:**

       * Allow specific traffic

       * Deny specific traffic

       * Restrict access to internal servers

       * Prevent unauthorised remote access
