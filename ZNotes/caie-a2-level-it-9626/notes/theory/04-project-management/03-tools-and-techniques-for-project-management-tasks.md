## **Tools and Techniques for Project Management Tasks**

### Gantt Charts

* A Gantt chart provides a visual timeline showing project tasks and their durations.

![](https://images.znotes.org/allimages/a1ae847ae75f606e028f3812.webp =500x)

* Components

  * Timeline: shows duration of the project and individual

  * Taskbars: show the length of activity relative to the time

  * Milestones: show the major checkpoints in the progression of a project

  * Dependencies: the limiting factors in a project, e.g., the start of task 2 is dependent on the completion of task 1; these are evident in the Gantt chart.

  * Progress bar: show percentage completion of entire project

  * Current date line: shows today’s position

* Interpreting Gantt charts

  * Allows a project manager to quickly determine

    * Which tasks are complete

    * Which tasks are overdue

    * Which tasks are in progress

    * Which milestones have been reached

  * Overdue tasks may be highlighted using

    * Red bars

    * Progress indicators

    * Colour changes

### PERT Charts

* PERT (Performance Evaluation and Review Technique) diagrams show relationships between project activities.

* Unlike Gantt charts, they focus on workflow rather than timelines.

* Components

  * Activities: Individual pieces of work that must be completed.

  * Dependencies: Tasks that rely on the completion of other tasks.

  * Milestones: Significant checkpoints.

  * Deliverables: Outputs produced by the project.

  * Float: Extra time available before a delay affects project completion.

  * Work Breakdown Structure (WBS): A hierarchical breakdown of all project work.

* Work Breakdown Structure (WBS)

![](https://images.znotes.org/allimages/738baac19098479b2b10ab46.webp =500x)

* Purpose of WBS

  * Shows project scope

  * Breaks work into manageable units

  * Helps allocate responsibility

  * Helps estimate costs and timings

* Characteristics of a good WBS

  * Must be understandable so everyone can interpret it

  * Measurable so that costs and times can be interpreted

  * Independent units must be used to allow tasks to be assigned separately

  * Must be flexible to accommodate changes

### Critical Path Method (CPM)

* The critical path is the longest sequence of dependent activities.

* Any delay to a critical path activity delays the entire project.

* Calculations

  * Forward Pass: to calculate earliest finish (EF) using earliest start (ES) and duration

    * EF = ES \+ Duration

  * Backward Pass: to calculate the latest start (LS) using the latest finish (LF) and duration

    * LS = LF - Duration

  * Float represents the spare time available.

    * Float = LS - ES  or  Float = LF - EF

    * Activities on the critical path always have: Float  = 0

* Uses of Critical Path Analysis

  * Scheduling to determine project duration

  * Resource allocation to prioritise resources

  * Workflow control to authorise work orders

  * Cost control to reduce delays and costs

  * Risk management to highlight critical tasks
