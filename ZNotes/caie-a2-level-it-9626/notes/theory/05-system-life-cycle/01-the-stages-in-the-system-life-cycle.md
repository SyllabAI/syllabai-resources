# System Life Cycle

## **The Stages in the System Life Cycle**

* A system is a collection of components working together to achieve a common goal.

* The various types of systems may include

  * Hardware systems that only contain physical devices such as a computer network

  * Software systems that only contain programs such as payroll systems

  * Combined systems that require hardware and software to work together such as ATMs, hospital management system, etc.

* A system is developed through multiple stages

$$
\begin{array}{c}

\text{Analysis} \\\

\downarrow \\\

\text{Design} \\\

\downarrow \\\

\text{Development and Testing} \\\

\downarrow \\\

\text{Implementation} \\\

\downarrow \\\

\text{Documentation} \\\

\downarrow \\\

\text{Evaluation} \\\

\downarrow \\\

\text{Maintenance}

\end{array}

$$

* Each stage of the life cycle

  * uses outputs from the previous stage

  * produces deliverables for the next stage

  * may require returning to an earlier stage if problems are found

  * contributes documentation used throughout the project

* This makes the life cycle **iterative**, even when following a structured model.
