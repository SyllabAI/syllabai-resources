## **Development and Testing‎**

* Testing ensures the system works correctly before release.

* Testing helps to

  * remove errors

  * verify requirements

  * validate outputs

  * improve reliability

  * increase user confidence

* Test plans contain

  * Test number to identify the plan

  * Test purpose to define what has to be tested

  * Test data, which has the input values for the test

  * Expected result, which gives the correct output

  * Actual result, which gives the actual output

  * Pass/Fail, which is the outcome of the testing

  * Comments have additional notes to identify the problems or highlight any issues

* Types of test data

  * Normal: valid input within the range of acceptable values

  * Extreme: boundary values that are on the edge of acceptability

  * Abnormal: Invalid data

  * Live: Real user data
