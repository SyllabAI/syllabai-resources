## Design‎

The design stage determines how the new system will work.

* Main outputs of this stage include

  * DFDs

  * System flowcharts

  * Database design

  * Input forms

  * Output reports

* ### Data Flow Diagrams

  * movement of data

  * processing

  * storage

  * external entities

These diagrams do not show any program logic, decisions, or looping.

### Data Storage

* **Databases** store related data in structured tables for efficient searching and updating, such as customer records, student database, hospital records

* **Files**

  * **Input** contain raw data that has not yet been processed.

    * Examples include:

      * Customer orders

      * Examination entries

      * Online booking forms

      * Employee timesheets

      * Survey responses

  * **Output** contain processed information generated by the system.

    * Examples include:

      * Receipts

      * Reports

      * Payslips

      * Timetables

      * Certificates

      * Financial statements

### Input Forms

* Good input forms should have the following features

  * be simple

  * use logical order

  * minimise typing

  * include validation

  * provide helpful error messages

  * use suitable controls

* Good screen designs

  * logical layout

  * clear labels

  * white space

  * consistent style

  * helpful instructions

  * immediate feedback

  * validation

  * navigation buttons

* Validation

  * checks data is sensible

  * automatic

  * prevents unreasonable input

* Verification

  * checks data is copied correctly

  * manual or automatic

  * prevents transcription errors

### Output Reports

* Should include

  * headings

  * company logo

  * totals

  * page numbers

  * date/time

  * clear layout

  * grouped information

* Outputs may be:

  * printed reports

  * dashboards

  * on-screen reports

  * emails
