### Stages of Different Software Development Methods

1. **Waterfall**

   * Requirements of the software are determined

   * Analysis

   * System Design

   * Development of Software

   * Testing

   * Implementation

   * Maintenance

2. **Agile**

   * Planning

   * Sprint planning

   * Design

   * Develop

   * Test

   * Customer feedback on the previously developed sprint

   * Next sprint

3. **Iterative**

   * Plan

   * Design

   * Develop

   * Test

   * Evaluate

   * Repeat the entire cycle until software has been completed

4. **Incremental**

   * Requirements

   * Divide the system into increments

   * Design increment 1

   * Develop and test

   * Release

   * Repeat for remaining increments

5. **Rapid** **Application Development (RAD)**

   * Requirements planning

   * User Design Workshop

   * Rapid prototype

   * User evaluation

   * Construction

   * Testing

   * Implementation
