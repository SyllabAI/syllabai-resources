## Rules

Here are the rules along with examples student should know to get maximum point.

1. ### অ+অ=আ
- নর + অধম = নরাধম
- হিম + অচল = হিমাচল
- প্রাণ + অধিক = প্রাণাধিক

2. ### অ+আ=আ
- হিম + আল = হিমালয়
- দেব + আলয় = দেবালয়
-  সিংহ + আসন = সিংহাসন
 
 
3. ### আ+অ=আ
- যথা + অর্থ = যথার্থ
- আশা + অতীত = আশাতীত
- মহা + অর্থ = মহার্থ
 
 
4. ### আ+আ=আ
- বিদ্যা + আলয় = বিদ্যালয়
- কারা + আগার = কারাগার
- হা + আশয় = মহাশয়


5. ### অ+ই=এ
- শুভ + ইচ্ছা = শুভেচ্ছা
- স্ব + ইচ্ছা = স্বেচ্ছা
- অধিক + ইচ্ছা = অধেচ্ছা
 
 
6. ### আ+ই=এ
- যথা + ইচ্ছা= যথেচ্ছা
- যা + ইচ্ছা = যেচ্ছা
- মা + ইশ্বর = মেশ্বর
 
7. ### অ+ঈ= এ
- পরম + ঈশ = পরমেশ
- গণ + ঈশ = গণেশ
- অধম + ঈশ্বর = অধমেশ্বর
- অগ্র + ঈশান = অগ্রেশান
 


8. ### আ+ঈ=এ
- মহা+ ঈশ = মহেশ
- প্রজা + ঈশ্বর = প্রজেশ্বর
 
 
9. ### অ+উ =ও
- সূর্য + উদয় = সূর্যোদয়
- নীল + উৎপল = নীলোৎপল

 
 
10. ### আ+উ =ও
- যথা + উচিত = যথোচিত
- মহা + উৎসব= মহোৎসব
- মহা + উদয় = মহোদয়
 
 
11.  ### অ+ঊ=ও
- গৃহ + ঊর্ধ্ব = গৃহোর্ধ্ব
- গঙ্গা + ঊর্মি = গঙ্গোর্মি
- চল+ ঊর্মি = চলোর্মি


12. ### অ/আ + ঋ = অর
- সপ্ত + ঋষি = সপ্তর্ষি
- মহা + ঋষি = মহর্ষি
- দেব + ঋষি = দেবর্ষি
- শীত+ ঋত = শীতার্ত
- বন্যা+ঋত =বন্যার্ত
- ভয়+ ঋত = ভয়ার্ত

13. ### অ + এ= ঐ
- জন + এক = জনৈক
- হিত + এশী = হিতৈশী
 
 
14. ### অ + ঐ= ঐ
- মত+ঐক্য =মতৈক্য



15. ### আ + ঐ= ঐ
- মহা + ঐশ্বর্য্য = মহৈশ্বর্য্য
- রাজা + ঐশ্বর্য্য = রাজৈশ্বর্য্য 

16. ### অ+ও= ঔ
- জল+অকা  =জলৌকা
- বন+ওষধি = বনৌষধি

17. ### আ+ও= ঔ
- মহা + ওষধি = মহৌষধি
- মহা + ঔষধ = মহৌষধ


18. ### ই+ই= ঈ
- অতি + ইত = অতীত
- অতি +ইব = অতীব
- রবি + ইন্দ্র = রবীন্দ্র
- প্রতি + ইতি = প্রতীতি
 
 
19. ### ই+ঈ= ঈ
- পরি+ ঈক্ষা = পরীক্ষা
- প্রতি + ঈক্ষা = প্রতীক্ষা
- অভি + ঈশ্বর = অভীশ্বর
 
 
20. ### ঈ+ই= ঈ
- সতী+ইন্দ্র = সতীন্দ্র
- মহী+ইন্দ্র = মহীন্দ্র
- শচী + ইন্দ্র = শচীন্দ্র
 

21. ### ঈ+ঈ= ঈ
- রজনী + ঈশ = রজনীশ
- দিল্লী + ঈশ্বর = দিল্লীশ্বর



22. ### ই+অ/আ/উ/এ= ্য
- অতি + অন্ত = অত্যন্ত
- প্রতি + অহ = প্রত্যহ
- অতি + অধিক = অত্যাধিক
- ইতি+ আদি = ইত্যাদি
- প্রতি + আশা = প্রত্যাশা
- অতি + উক্তি = অত্যুক্তি
- প্রতি + উপকার = প্রত্যুপকার
- প্রতি + ঊষ = প্রত্যুষ
- প্রতি + এক= প্রত্যেক


23. ### উ+উ= ঊ
- মরু + উদ্যান = মরূদ্যান
- সু + উক্ত= সূক্ত
- কটু + উক্তি = কটূক্তি


24. ### উ+ঊ= ঊ
- লঘু+ ঊর্মি =লঘূর্মি
- তনু+ ঊর্ধ্ব= তনূর্ধ্ব

25. ### ঊ+উ= ঊ
- বধূ + উচিত= বধূচিত
- বধূ + উক্তি  =বধূক্তি

 
26. ### ঊ+ঊ= ঊ
- বধূ+ঊর্মি = বধূর্মি

* অণু+এষণ- অণ্বেষণ
 
### ব্যঞ্জন সন্ধিঃ
- ক+দ = গ+দ (বাক+দান=বাগদান)
- ট+য=ড়+য (ষট+যন্ত্র= ষড়যন্ত্র)
- ত+ব=দ্ব (উৎ+ বন্ধন =উদ্বন্ধন)
- ত-ঘ = দ+ঘ (উৎ+ঘাটন= উদঘাটন)
- ত+য=দ+য (উৎ+যোগ= উদ্যোগ)
- ত+ব-দ+র( তৎ+রূপ= তদ্রূপ)
- ম+ক=ঙ্ক (শম+কা=শঙ্কা)
- ক+ন=গ+ন (দিক্‌ + নির্ণয়= দিগনির্ণয়)
- ম+ত=ন+ত (সম+তাপ = সন্তাপ)
- দ+ত =ত+ত (তদ+কাল = তৎকাল)

###  নিপাতনে সন্ধিঃ
- আ + চর্য = আশ্চর্য
- বন + পতি = বনস্পতি
- তৎ + কর = তক্কর
- মনস + ইষা = মনীষা
- দিব + লোক = দ্যুলোক
- গো + পদ = গোষ্পদ
- বৃহ+ পতি =বৃহস্পতি
- পর + পর = পরস্পর
- ষট + দশ = ষোড়শ
- এক + দশ = একাদশ 



### বিসর্গ সন্ধিঃ
- তিরঃ + ধান = তিরোধান
- মনঃ + রমা = মনোরমা
- মনঃ + যোগ = মনোযোগ
- মনঃ + হর =মনোহর
- তপঃ + বন = তপোবন
- অন্তঃ + ধান = অস্তর্ধান
- পুনঃ+ আয় =পুনরায়
- পুনঃ + উক্ত = পুনরুক্ত
- নিঃ+ রব = নীরব
- নিঃ+ রস = নিরস
- নিঃ+ চয় = নিশ্চয়
- শিঃ + ছেদ = শিরচ্ছেদ
- ধনুঃ+ টদ্কার = ধনুষ্টদ্কার
- নিঃ + ঠুর = নিষ্ঠুর
- দুঃ+ তর =দুস্তর
- দুঃ+ থ =দুস্থ
- প্রাতঃ + কাল = প্রাঃকাল
- মনঃ + কষ্ট = মনঃকষ্ট
- শির + পীড়া = শিরঃপীড়া
- নিঃ+ স্তব্ধ = নিঃস্তব্ধ/নিস্তব্ধ
- দুঃ+থ = দুঃস্থ/দুস্থ
- নিঃ+ স্পন্দ = নিঃস্পন্দ/নিশস্পন্দ
