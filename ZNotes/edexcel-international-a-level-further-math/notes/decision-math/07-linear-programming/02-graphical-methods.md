# Representing constraints into graphs

Formulating a linear problem can be represented into a graphical method using inequality as y=mx+c

Since it’s an inequality, shading regions can give us optimal regions.

## Locating Optimal point

Optimal points represents a single point in the feasible region which either maximizes or minimizes the objective function.

Method 1 : 

Objective line method/ Ruler Method-

After drawing the feasible region, sliding ruler method can be used to locate the optimal point of the problem, this can be done by sliding the ruler parallel to the objective function. If the objective function is to maximize the profit then optimal point will be the last point the ruler touches, if objective is to minimize the ruler’s first point on the feasible region is the optimal point.

Method 2: 

Vertex testing method: 

1. Find the coordinates of each vertex in the feasible region

2. Substitute the coordinates found in the objective function

3. Based on the objective (maximizing or minimizing), choose the coordinate that gives the optimal value.
