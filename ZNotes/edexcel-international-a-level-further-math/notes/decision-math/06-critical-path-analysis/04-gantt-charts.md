# How to draw Gantt Charts

Gantt charts represent a graphical way to represent the diagram into a graph

Key notes about Gantt Charts-

1. Horizontal axis represent time

2. Vertical Axis represent list of activities

3. Bars represent an activity’s duration

4. Critical activities are those that one after the other

5. Float activities are represented by duration and following a dotted line, the dotted line shows the value of float.
