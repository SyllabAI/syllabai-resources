# Numerical solutions of equations

## locating roots

* you can show that a root exists within a interval of a **continuous** (doesn’t jump from one value to another) function by showing that there is a change in sign within the interval
  * a interval of a continuous function can be represented by $[a,b]$
* there are various methods into determining a more accurate approximation to where the root within a interval is located

### example question

* show that $f(x) = x^3 -  5x^2 + 2x + 5$ has a interval between $[1,2]$
  * $f(1) = (1)^3 -  5(1)^2 + 2(1) + 5 = 3$

  * $f(2) = (2)^3 -  5(2)^2 + 2(2) + 5 = -3$

  * therefore since there is a change in sign inbetween in the interval, we can conclude that a root exists between the interval $[1,2]$
