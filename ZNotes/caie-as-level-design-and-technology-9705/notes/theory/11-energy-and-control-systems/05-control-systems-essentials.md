## Control Systems Essentials

* ### Input

  * Devices (such as sensors or switches) that receive external data or physical changes and convert them into electrical signals.

* **Process:** Components that evaluate or manipulate the signal according to a set of rules.

* ### **Amplification**

  * The process of increasing the strength or power of a weak electrical signal. In control loops, weak signals from sensors (like an LDR) are boosted using transistors or operational amplifiers (op-amps) so they possess enough power to switch heavy-duty output devices like relays or motors.

* ### Output

  * Devices (such as lamps, buzzers, or motors) that execute the final action.

* ### Feedback

  * Information about the output state returned to the input or processing stage to compare against the desired target.

* ### Manual Control

  * In a manual system, a human operator is an active part of the control loop.

  * They provide the input (the command), process the feedback (sensory information), and make adjustments to the output (the action).

  * An example is driving a car.

* ### Semi-Automatic Control

  * A semi-automatic system combines both human and machine control.

  * The human provides the initial goal or set of parameters, and the machine handles a specific part of the process using sensors for feedback.

  * For example, driving a car with cruise control.

* ### Automatic Control

  * In an automatic system, the entire control loop operates without any human intervention.

  * The desired state is pre-programmed, and the system uses sensors to continuously monitor the output.

  * A home thermostat is a good example.
