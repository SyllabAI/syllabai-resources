## Operation Strategy:

* **Lean production**: Producing goods and services with minimal wasted resources while maintaining high quality.

* **Computer-aided design (CAD)**: Using computer programs to create 2D or 3D graphical representations of physical objects.

* **Computer-aided manufacturing (CAM)**: Using computer software to control machine tools and equipment in manufacturing.

* **Operational flexibility**: The ability to adjust production levels and product range based on changes in customer demand.

* **Process innovation**: Using new or significantly improved production or service delivery methods.

* **Enterprise resource planning (ERP)**: Using a single computer application to manage the purchase and use of resources to improve operational efficiency.

* **Kaizen**: A Japanese term meaning continuous improvement.

* **Cell production**: Flow production organized into self-contained groups responsible for completing a unit of work.

* **Critical path analysis (CPA)**: A planning technique that identifies tasks, sequences them, and identifies the critical path.

* **Network diagram**: A diagram used in CPA to show the logical sequence and dependencies of activities.

* **Critical path**: The sequence of tasks that must be completed on time to ensure the entire project finishes by the agreed date.

* **Earliest start time**: The earliest time an activity can begin.

* **Latest finish time**: The latest time an activity can finish without delaying the project.

* **Total float**: The amount of time an activity can be delayed without delaying the overall project.

* **Free float**: The amount of time an activity can be delayed without affecting the start of the following activities.

* **Dummy activities**: Used in network diagrams to show logical dependencies between tasks, without consuming time or resources.
