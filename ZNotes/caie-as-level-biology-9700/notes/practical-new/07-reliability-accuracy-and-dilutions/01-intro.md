# Reliability, Accuracy and Improvements

* The results you obtain from an experiment must be precise. The quality and precision of an experiment can be assessed by considering its accuracy and reliability.

* **Accuracy:** How close a measured result is to the true or accepted value.

* **Reliability:** How consistent results are when an experiment is repeated under the same conditions.

## Improving accuracy

* Accuracy issues can be caused by:

  * Systematic errors - issues with the apparatus

    * Zero errors - the error where the machine reads a non-zero value when the actual value is 0

    * Incorrect calibration of equipment - apparatus is incorrectly set up

  * Random errors - errors cause by human fault

    * Incorrect measurement technique - method of data collection is incorrect (eg. zero error- starting your measurement from a non-zero value) 
    * Reaction time (eg- not being able to start a stopwatch at the exact moment) 

* You can avoid these issues by 

  * Recalibrating your equipment regularly through out the experiment 

  * Take multiple trials 

  * Using an average (without the anomolies)

## Improving Reliability 

* Reliability issues can be caused by:

  * Systematic errors - issues with the apparatus

    *  Glitches in the equipment / equipment failure

  * Random errors - errors cause by human fault

    * variation in measurements

    * unpredictable changes / accidental measurements

* You can avoid these issues by

  * Repeating measurements

  * Calculating a mean

  * Increasing sample size 

  * Identifying and removing anomalies
