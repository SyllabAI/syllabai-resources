## Scale bar

* **Scale bar:** A line that represents a known actual length and is used to determine the actual size of structures in an image.

* Example:

![](https://images.znotes.org/allimages/f71619c253e8e095e46aa445.webp =598x)

* You have been given this diagram, you are required to find the actual width of the cell.

* Here, AB is the scale diagram and XY is the line that indicates the actual length that needs to be found.

  1. First measure the length of the line AB on the diagram (in this case take it as 1 cm)

  2. Now you know that 1 cm= 40 micrometers

  3. Now measure line XY (in this case take it as 2 cm)

  4. Since 1 cm= 40 µm then 2cm= **80 µm**. (40 x 20) 

  5. In the case that the values are more confusing you can use the formula:

     Actual size = ( Measured size of structure / Measured length of scale bar ) ​× Actual length of scale bar

  6. For this example the substituted formula would be

     Actual size = ( length of XY / length of AB ) x actual size of line AB

     Actual size = ( 2 cm / 1 cm ) x 40 µm

     Actual size = ( 2 ) x 40 µm = **80 µm**
