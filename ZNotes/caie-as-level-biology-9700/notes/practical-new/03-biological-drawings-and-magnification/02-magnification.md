## Magnification

* Microscopes provide enlarged images of biological specimens, but each micrograph has 3 quantities to remember

  * **Magnification** (M) : How much larger an image is compared to the true size of the specimen

  * **Actual size** (A) : The true size of the specimen without any magnification

  * **Image size** (I): The size of the specimen in the micrograph with the magnification

* You can find 1 of the 3, provided you know the other two.

![](https://images.znotes.org/allimages/cc2f70023d19fb425713155a.webp =737x)

* **Remember: when performing any of these calculations, both actual size (A) and image size (I) must be in the same units**
