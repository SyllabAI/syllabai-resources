# Recording and presentation of data

## **Tables, graphs and data recording**

* During scientific investigations, data must be recorded clearly and systematically so that patterns can be identified and conclusions can be drawn.

* You can measure the data from your experiment using tables and graphs.

* First when conducting the experiment you must **collect data**:

  * The data you collect must be recorded clearly and concisely (avoid adding too many)
  * Collect both qualitative (descriptive words) and quantitative (numbers) data where possible.
  * Record raw data directly from the experiment before carrying out calculations.
  * Calculate and record processed data, such as means, rates or percentages, separately.
  * Repeat measurements where possible and calculate a mean to improve reliability.

* After collecting data, you must **record it** (usually in the form of a table):

  * Use a clear, descriptive title.

  * Put the independent variable in the first column

  * Put the dependent variable in the following column(s)

  * Include the unit in the column heading, not after every value

  * Use a consistent number of decimal places within each column

  * Record repeated results in separate columns before calculating a mean

* To spot a trend it would be easier to **plot a graph**:

  * Plot the independent variable on the x-axis

  * Plot the dependent variable on the y-axis

  * Label both axes clearly, including units where appropriate

  * Choose a sensible and even scale that uses most of the graph space

  * Plot points accurately using a small cross or clear point

  * Draw a line or curve of best fit when appropriate

  * If there are any, mark the anomaly by circling the point
