# Presenting Data & Observations

## Tabulating Results

  - Draw a table with neat, ruled pencil lines.

  - Give each column a suitable heading (Quantity/SI unit)

  - Arrange columns in order: independent, dependent & derived variable.

  - Round data to the same number of decimal places to maintain consistency.

  - The table should show results for at least 5 experiments with the independent variable changing if the question doesn't specify the number of experiments to carry out. 

  -  You can also confirm the number of results you need to perform (usually in the case of dilutions) by looking at the number of beakers provided.
