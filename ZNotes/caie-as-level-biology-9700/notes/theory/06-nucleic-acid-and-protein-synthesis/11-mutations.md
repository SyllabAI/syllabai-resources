**E.g. CAA -\>CAC**

* Both code for lysine

* Genetic code is **degenerate**

* No change in polypeptide chain

* That's called ***silent*** ***mutation***

* Sometimes it codes for a different amino acid

* That's called ***missense mutation***

* Sometimes it accidently becomes a stop codon so translation stops this is ***nonsense mutation***

|

1,2,3,4 to 1,2,3,4,5

***Frame*** ***shift***

* All subsequent amino acids are changed so all codons after mutation is affected
