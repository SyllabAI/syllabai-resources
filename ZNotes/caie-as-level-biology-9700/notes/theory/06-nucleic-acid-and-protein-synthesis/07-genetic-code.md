## Genetic Code

Gene: a sequence of nucleotides that forms part of a DNA  molecule.

Genetic code: different triplets of DNA bases either code for specific amino  acids or correspond to start and stop codons.

1. Universal: triplet codes for the same amino acids in all living organism.

2. Degenerate: more than one codon can code for the same amino acid.

3. Doesn't overlap: no base from one triplet will be part of the next triplet

Stop codons

* UAA

* UGA

* UAG
