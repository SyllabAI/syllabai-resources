## Making and Interpreting a Probability Distribution Table

* To make a probability distribution table, we need to know, or be able to find out, the probabilities of all the prizes.

* For example, there is a game in which you get the same number of pounds as the number you roll on a die.

* The probability distribution table for the game would be as follows:

* Where the sum of all the probabilities is 1
* This is expressed by:
  * $\Sigma P(x) = 1$

### How to Find the Expected Value/Prize of a game:

* To find the expected value or prize of a game, we multiply each prize by its probability.

* This is expressed by:

  * $E(X) = \Sigma [x.P(x)]$

* To find the expected prize of the game mentioned above:

  * $(1 \times \frac{1}{6}) + (2 \times \frac{1}{6}) + (3 \times \frac{1}{6}) + (4 \times \frac{1}{6}) + (5 \times \frac{1}{6}) +(6 \times \frac{1}{6})$
  * $= £3.5$

* Hence, $E(X) = \Sigma [x.P(x)] = £3.5$
