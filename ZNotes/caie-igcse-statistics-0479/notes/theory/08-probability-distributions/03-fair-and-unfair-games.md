## Fair and Unfair Games

* Games dependent on probability are classified as either “Fair” or “Unfair”.

* If the expected prize is equal for all parties involved, the game is considered fair.

* If the expected prize of a game is not equal for all the parties involved, the game is considered an unfair game.

* The game can be unfair for the players or the host

### Stake:

* The Stake is the price paid to enter a game.

### Determining whether a Game is Fair or Not

* If it is a single-player game, it is considered fair if the stake equals the player's expected prize.

* For example:

  * Alex plays a game where she flips a fair coin.

  * If she gets tails, she wins £5

  * If she gets heads, she wins £0

  * The Stake is £2

* To determine whether the game is fair or not, we shall first find $\Sigma [x.P(x)]$

  * $E(X) = (\frac{1}{2} \times 5) + (\frac{1}{2} \times 0)$

  * $E(X) = £2.5$

* The game is in favour of Alex as their

  * $E(X) > \text{Stake}$

* The game is unfair for the host as their

  * $E(X) < \text{Stake}$

* To make the game fair, the Expected Prize must equal the Stake

  * $E(X) = \text{Stake}$

  * $£2 = \text{Stake}$

    * OR

  * $E(X) = \text{Stake}$

  * $£2 = \text{Stake}$

* Therefore, the Stake must be changed to $£2.5$ OR the Expected Prize must be changed to $£2$
