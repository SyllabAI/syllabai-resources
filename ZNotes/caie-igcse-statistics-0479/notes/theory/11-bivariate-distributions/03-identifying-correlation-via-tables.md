## Identifying Correlation via Tables

* It is easy to spot the correlation between 2 variables using a graph; however, it is also possible to identify the correlation directly from a table of values.

* The key to this is to remember what type of trend each correlation defines

* Positive Correlation:

  * When $x$ increases, so does $y$
