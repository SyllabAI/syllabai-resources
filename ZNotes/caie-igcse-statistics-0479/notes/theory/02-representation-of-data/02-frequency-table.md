* A table that organizes raw data by recording the number of times a particular value occurs in a dataset.

* The frequency table shown above represents the number of bags with a particular number of marbles in them.

* To calculate the total number of marbles, multiply the number of marbles in each bag by the number of bags with that many marbles (frequency).

* ### Total Number of Marbles:

  * $5 \times 2 = 10$

  * $7 \times 6 = 42$

  * $4 \times 3 = 12$

  * $8 \times 2 = 16$

    * $10+42+12+16 = 80$

      * Hence, there are 80 marbles present in total.

* ### Advantages of Frequency Table:

  * Easy to comprehend

  * Large datasets can be condensed with the help of a frequency table

* ### Disadvantages of Frequency Table:

  * Loss of original data (when grouped into classes)

  * Data is estimated (when grouped into classes)
