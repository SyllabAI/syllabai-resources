# Representation of Data

## Terms to Know When Classifying Data

1. ### Raw Data:

   * Original facts and statistics before they are processed for use.

2. ### Ungrouped Data:

   * Data in which individual values can be seen as distinct from each other.

   * For example, the length of Road A is 5 km, and the length of Road B is 18km.

3. ### Grouped Data:

   * Data that is divided into intervals no longer retains its individual value

   * For example, the length of Roads A & B is 0-20 Km.

   * Although we have not incorrectly classified the data, the original values are lost.

4. ### Frequency:

   * The number of times that a particular value occurs in a dataset.

   * It is represented by the letter *f*.
