## Advantages and Disadvantages of each Measure of Dispersion

### Range:

* Advantages:

  * Easy to calculate

  * Can compare spread between similar datasets

* Disadvantages:

  * Strongly affected by extreme values

  * Is only based on Maximum and Minimum values

### Inter-Quartile Range (IQR):

* Advantages:

  * Not affected by extreme values

  * Not all of the data is required to calculate IQR

* Disadvantages:

  * Dependent on the median being an appropriate average

  * Only based on 2 values in a dataset

### Standard Deviation:

* Advantages:

  * Based on all values in a dataset

  * Can be used in further Calculations

* Disadvantages:

  * Dependent on the mean being an appropriate average

  * Greatly affected by extreme values and errors in data
