## Upper and Lower Quartiles

* Upper and Lower Quartiles are required to find the InterQuartile Range of a dataset.

### How to find the Lower Quartile:

* To find the lower quartile of an ungrouped data set, we use the formula:

  * $Q_1 = \frac{n + 1}{4}$

* For example, we are given the following set of data:

  * $2,4,5,6,6,7,8,9,10,10,11$

  * There are 11 values in the dataset; hence

    * $Q_1 = \frac{n + 1}{4}$

    * $Q_1 = \frac{11 + 1}{4}$

    * $Q_1 = 3$

  * So the 3rd value in the dataset would be our Lower Quartile

  * The Lower Quartile is 5

### How to find the Upper Quartile:

* To find the upper quartile of an ungrouped data set, we use the formula:

  * $Q_3 = \frac{3(n + 1)}{4}$

* For example, we are given the following set of data:

  * $2,4,5,6,6,7,8,9,10,10,11$

  * There are 11 values in the dataset; hence

    * $Q_3 = \frac{3(n + 1)}{4}$

    * $Q_3 = \frac{3(11 + 1)}{4}$

    * $Q_3 = 9$

  * So the 9th value in the dataset would be our Upper Quartile

  * The Upper Quartile is 10

### How to find the Interquartile Range (IQR):

* The IQR is the difference between the Upper and Lower Quartiles of a dataset

* To find the IQR of any data set, the following formula is used:

  * $Q_3 - Q_1$

* We can find the IQR of the data mentioned above using the formula

  * $Q_3 - Q_1$

  * $10 - 5$

  * $= 5$
