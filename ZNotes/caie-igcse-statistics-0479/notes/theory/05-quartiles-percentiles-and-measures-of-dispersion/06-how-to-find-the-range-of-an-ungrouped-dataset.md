## How to find the Range of an Ungrouped Dataset

* The Range is the difference between the maximum and minimum values in a dataset.

* The formula for the range is:

  * $\text {Maximum Value - Minimum Value} $

### Finding the Range:

$2,4,5,6,6,7,8,9,10,10,11$

* To find the range of the data given above, we will use the formula

  * $11- 2$

  * $= 9$

* Hence, the range of the dataset is 9.
