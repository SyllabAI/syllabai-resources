## Probability Tree Diagram

* A Probability Tree Diagram is used to visualise and easily interpret the probability of a series of events.

![](https://images.znotes.org/allimages/49ffd7f8a162490195fd4f5c.webp =649x)

* Above is a Probability Tree Diagram for 2 events: the weather and the exercise Sam does.

* There is a $\frac{1}{4}$ chance that it rains, and if it rains, the chance of Sam going for a Run is $\frac{1}{6}$

* So the probability that it rains and Sam goes on a Run is:

  * $\frac{1}{4} \times \frac{1}{6}$

  * $\frac{1}{24}$
