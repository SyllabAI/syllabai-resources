* To find the Median of grouped data, we must use “Linear Interpolation” or a “Cumulative Frequency Diagram”

Above, we are given some grouped data regarding the lifetime of 50 batteries.

### How to find the Median using Linear Interpolation:

* First, we must divide the cumulative frequency in half

  * $\frac{50}{2} = 25$

* Next, we must find the class within which the Median, 25, lies.

  * This is the “20-30” class, as the cumulative frequency the class accounts for is 17-30.

* Then, we will subtract the Median Value, 25, from the Cumulative frequency of the previous class

  * $25-17=8$

* We will then divide the value obtained from the previous step by the frequency of the class within which the Median lies.

* This is done because our Median Value is the 8th out of the 13 values in the class, and data is spread evenly within a class in grouped data.

  * $\frac{8}{13}$

* Then, we will find the class width of the Median class by subtracting the Lower Class Boundary from the Upper Class Boundary.

  * $30-20 = 10$

* Next, we will identify the Lower Class Boundary of the Median Class

  * 20

* We will put all this obtained information into a formula

  $$
  \text{Median} = L + \left\( \frac{\frac{N}{2} - CF}{f} \right\) \times w
  $$

  * L is the Lower Class Boundary

  * The fraction would be $\frac{8}{13}$, where we obtained the position of the Median Value in relation to the Median Class.

  * The $w$ refers to the class width of the median class

* Hence, through these steps, our median would be

  * $\text{Median} = 20 + \frac{8}{13} \times 10$

  * $\text{Median} = 26.15$

### How to find the Median using a Cumulative Frequency Diagram.

* To find the Median using a Cumulative Frequency diagram, we must first find the median value by dividing the cumulative frequency in half

  * $\frac{50}{2} = 25$

* Next, we will see which value corresponds to the Median value; in this case, the 25th value.

* With the help of a ruler, we can confirm that the Median Value for this data is around 26.
