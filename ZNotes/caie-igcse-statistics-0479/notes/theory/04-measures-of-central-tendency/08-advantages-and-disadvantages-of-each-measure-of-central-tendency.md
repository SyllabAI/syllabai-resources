## Advantages and Disadvantages of Each Measure of Central Tendency

### Mean:

* Advantages:

  * Easy to calculate

  * Easy to understand

  * Can be used for further calculations

  * Accounts for all values in a dataset

* Disadvantages

  * All values must be known.

  * Is strongly affected by extreme values.

* Best used when:

  * All of the data has to be accounted for

  * No extreme values present in the dataset

### Median:

* Advantages:

  * All values do not need to be known to be calculated.

  * Not affected by extreme values

* Disadvantages

  * Not used in any further calculations

  * Does not take all values into account

* Best used when:

  * Data contains extreme values.

### Mode:

* Advantages:

  * Only measure that can be used for qualitative values

  * Not affected by extreme values

* Disadvantages

  * Not used in further calculations

  * Does not take all values into account

* Best used when:

  * Finding out the most common/frequent value. Useful to manufacturers and businesses.

* **The Mode may have more than one value or no value at all**
