## How to Find the Mean for Grouped Data

* As the original data is displayed in grouped form, we can only find estimates of the measures of central tendency.

* Above, we are given some Grouped Data regarding the mass of sacks of potatoes.

* To find the estimated mean, we must first find the “Midvalues” of each class.

* To find the Midvalue, we add the lower and upper class boundaries and divide them by 2.

* For the following example:

  * $\frac{100+150}{2} = 125$

  * $\frac{150+200}{2} = 175$

  * $\frac{200+250}{2} = 225$

  * $\frac{250+320}{2} = 285$

* Now that we have found the “Midvalues” for all the classes, we will use the formula

  * $Mean = \frac{\sum\ f\ M}{\sum\ f}$

* Using this formula, we can find the estimated mean for the data

  * $Mean = \frac{(7 \times 125)+(4 \times 175)+(19 \times 225)+(8 \times 285)}{7+4+19+8}$
  * $Mean = 213.95$
