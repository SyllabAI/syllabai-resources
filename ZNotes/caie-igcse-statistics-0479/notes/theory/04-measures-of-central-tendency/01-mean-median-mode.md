# Measures of Central Tendency

## Mean, Median & Mode

* A measure of central tendency is a single value that describes a set of data by identifying the central position within the data.

* The three measures of central tendency used are:

  * Mean

  * Median

  * Mode

### Mean:

* Also called “Arithmetic Mean”

* The Measure of Central Tendency obtained by adding all the values in the dataset and dividing the total by the number of values present in the dataset.

### Median:

* The middle value in a dataset when the data is arranged in ascending order.

### Mode:

* The value with the highest frequency in a dataset.
