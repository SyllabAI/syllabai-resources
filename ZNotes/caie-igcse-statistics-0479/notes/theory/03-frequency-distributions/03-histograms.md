* Above, we are given a Grouped Frequency Distribution regarding sacks of potatoes.
* To make a histogram, we need to determine how we will organize our data.
* For this example, we will organize our data according to “Number of Sacks Per 50 kg”. This would be our “Standard Interval”
* This means that the height of each bar will show the number of sacks per 50 kg.
* For the 0-50 class, the bar will have a height of 6, as there are 6 sacks per 50 kg.
* For the 100-200 class, the bar will have a height of $\frac{23}{2} = 11.5$, as the data is spread out over 100 kg rather than 50 kg, and we have organized our data as “Number of Sacks Per 50 kg”.
* While using this process, we calculate the “Frequency Density” of each class.

### How to Calculate and Use Frequency Density:

* As our data states “Number of Sacks per 50 kg,” each 50 kg would be counted as 1 class interval. (Standard Interval)

* To find the Frequency Density, we will use the formula

  * $Frequency\ Density = \frac{\text{Class Frequency}}{\text{Class Interval}}$

* So, for the 0-50 class

  * $\frac{50}{50} = 1$

    * The Class Interval would be 1

  * $Frequency\ Density = \frac{6}{1}$

  * $Frequency\ Density = 6$

* Hence, the frequency density would be 6, and so would the height of the bar in the histogram.

* For the 200-270 class

  * $\frac{70}{50} = 1.4$

    * The Class Interval would be 1.4

  * $Frequency\ Density = \frac{13}{1.4}$

  * $Frequency\ Density = 9.3$

* Hence, the frequency density would be 9.3, and so would the height of the bar in the histogram.
