## Properties of Frequency Distributions

* While reading Frequency distributions, we look at 4 main things:

  * Class Limits

  * Class Boundaries

  * Midpoints

  * Class Widths

* For Discrete data, class limits are required alongside class boundaries.

* For Continuous data, class limits are not required alongside the class boundaries.

  * Class boundaries for continuous data also depend on the precision of the measurements.

### Class Limits:

* Class Limits are the smallest and largest possible values in a Class Interval.

* For example, in a Class Interval 1-20,

  * 1 is the Lower Class Limit

  * 20 is the Upper Class Limit

### Class Boundaries:

* Class Boundaries are the dividing points between continuous class intervals for discrete data.

* For example, if a given discrete data has Class Intervals 1-20 and 21-40,

  * The Class Boundaries can be found by subtracting 0.5 from the Lower Class Limits and adding 0.5 to the Upper Class Limits.

  * Hence, the Class Boundaries would be 0.5-20.5, 20.5-40.5

* Class Boundaries are the real class limits between continuous data.

* The Class Boundaries for continuous data depend on the limit of accuracy of the data.

* For example, if continuous data is given as 1.0-20.0 and 20.1-40.0, correct to the nearest 0.1 value.

  * We will first split the limit of accuracy in half, then add the answer to the upper limit and subtract it from the lower limit.

  * Hence, the Class Boundaries would be 0.95-20.05 and 20.05-40.05.

### Midpoints:

* Midpoints are the central values of a Class Interval

* They are found by adding the Lower and upper class limits and dividing the sum by 2

* For example, in a Class Interval 1-20,

  * $\frac{1+20}{2} = 10.5$

  * The Midpoint would be 10.5

### Class Widths:

* Class Widths are the size of the Class Intervals

* They are found by subtracting the Lower Class Boundary from the Upper Class Boundary, or by subtracting 2 continuous Lower Class Limits.

* For example, for Class Interval 1-20 and 21-40,

  * $20.5 - 0.5 = 20$

  * OR

  * $21 - 1 = 20$
