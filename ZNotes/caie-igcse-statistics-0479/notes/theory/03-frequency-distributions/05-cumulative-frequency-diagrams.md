## Cumulative Frequency Diagrams

* A method of displaying frequency distributions in which the frequencies are totalled/cumulated.

* To make a Cumulative Frequency Diagram, we must simply add each frequency to the previous total frequency (frequency always on the $ y$-axis) while plotting the $ x$-axis as usual.

* Instead of plotting at the Midpoints, we plot at the Upper Class Boundaries instead.

### Plotting a Cumulative Frequency Diagram:

* We will plot a Cumulative Frequency Diagram while using a Frequency Polygon plotted with a Standard Interval of 50 as a reference.

![](https://images.znotes.org/allimages/5f7f5dac4a5ee82156c72b8c.webp =501x)

* To plot a Cumulative Frequency Diagram, we must first obtain the Raw Values used to plot the Frequency Polygon.

  * The first plot is at 25, and plots in a Frequency Polygon are at the midpoint of the Class Interval so to find the Upper Class Boundary we will:

    * $\frac{0+x}{2} = 25$

    * $x = 50$

  * We have obtained the Upper Class Boundary, which is 50, and as we are given that the Standard Interval is 50, we can find the frequency for the 0-50 class using the Frequency Density formula

    * $6 = \frac{x}{1}$

    * $x = 6$

  * Hence, the Class Frequency would be 6

* We would repeat the steps for all the plots to obtain all the class boundaries and their respective frequencies

* To make drawing the Cumulative Frequency Diagram easier, we can make a cumulative frequency distribution with the cumulative frequencies instead of individual frequencies.

* To find the cumulative frequencies, we will simply add the previous frequencies as we go down the distribution.

* For example:

  * For Class Interval 100-200, the cumulative frequency would be the sum of the previous frequencies

    * $6+21+23 = 50$

* We may also use a cumulative frequency distribution to find the individual frequencies of each class to plot a frequency distribution.

* To do so, we will simply subtract each cumulative frequency from the previous to obtain the class frequency.

* For example:

  * For Class Interval 50-100, the cumulative frequency would be the difference between its cumulative frequency and class interval 0-50 ‘s cumulative frequency

  * $27-6 = 21$

* Then, we can draw our Cumulative Frequency Diagram with the help of a frequency distribution, making sure to make plots at the Upper Class Boundary of each Class Interval

![](https://images.znotes.org/allimages/b6de6b51a213f4b774b32af8.webp =762x)

We have successfully plotted a Cumulative Frequency **Polygon**

### Cumulative Frequency Curve:

* To make a Cumulative Frequency **Curve**, we will plot the points as done for the Cumulative Frequency Polygon; however, instead of joining them with straight lines, we will make a smooth curve.

![](https://images.znotes.org/allimages/74f4623316c0223c3369f3fa.webp =677x)

* The $ y$-axis always represents the frequency, and the $ x$-axis represents the variable, for example, the mass of sacks.

* Each plot represents the Upper Class Boundary of a class interval.

* The rise from a frequency of 6 to 27 between the 2 class boundaries 50 and 100 means that:

  * The Class 50-100 has a frequency of 21
