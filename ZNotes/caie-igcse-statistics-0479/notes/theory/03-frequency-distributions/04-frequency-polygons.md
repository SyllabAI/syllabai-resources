## Frequency Polygons

* Frequency Polygons are another common method of representing grouped data.

* Like in histograms, we will need to find the Frequency Density of each class to plot the Frequency Polygon.

* A major difference between a histogram and a frequency polygon is that the frequency polygon utilises midpoints of each class to plot points.

* The midpoints of each class have been calculated below

  * $\frac{0+50}{2} = 25$

  * $\frac{50+100}{2} = 75$

  * $\frac{100+200}{2} = 150$

  * $\frac{200+270}{2} = 235$

* We will plot a point using the frequency density as a reference for the $ x$-axis and using the midpoint as a reference for the $ y$-axis.

* After plotting the points, we will mark a point at 0,0 and 270,0 (or any other initial and ending point of the graph) to close the frequency **polygon**.

* Finally, we will join all the points with straight lines.

### Comparing Frequency Polygons:

* To compare 2 frequency distributions, we can draw them as a pair.

* Below is a pair of 2 frequency distributions for the exam results of 2 classes.

![](https://images.znotes.org/allimages/dac42a9a1190fc1d612225b8.webp =844x)

* We can observe that the green distribution has generally higher scores, as it is shifted towards the right.

* The highest average score for the green distribution is 50, whereas the blue distribution has a highest average score of 40.

* Both distributions have a maximum frequency of 12.

* They both have the same spread and follow the same trend.
