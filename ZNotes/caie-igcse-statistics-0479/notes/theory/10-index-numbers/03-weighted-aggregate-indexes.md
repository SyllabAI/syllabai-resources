## Weighted Aggregate Indexes

* A Weighted Aggregate Index is a weighted average of the Price Relatives of a given number of items.

* We can find suitable weights using the base year costs or quantities.

### Finding Weights:

* To find weights, we can either use the quantity or expenditure in the base year.

* For example, Tanya uses 680 Gallons of Water, 1300 Units of Electricity, and 17400 Minutes on the Telephone.

* Each Gallon of water Costs €1, Each Unit of Electricity costs €0.5, and each minute on the Telephone costs €0.05.

* To find the weights, we first need to find her expenditure in each category

* $680 \times 1 = €680$

* $1300 \times 0.5 = €650$

* $17400 \times 0.05 = €870$

* So the weights would be:

  * $680 : 650 : 870$

  * $68 : 65 : 87$

### Finding the Weighted Aggregate Index:

To find the Weighted Aggregate Index, we need to find the price relatives first.

* The cost of Water increased to €1.2 per gallon.

* The cost of Electricity increased to €0.6 per unit

* The cost of the Telephone increased to €0.07

* $\text{Water} = \frac{1.2}{1} \times 100 = 120$

* $\text{Electricity} = \frac{0.6}{0.5} \times 100 = 120$

* $\text{Telephone} = \frac{0.07}{0.05} \times 100 = 140$

So the Price Relatives are:

* $120 : 120 : 140$

The formula for Weighted Aggregate Index is:

* $\text{Weighted Aggregate Index} = \frac{\Sigma(Weight \times Price\ Relative)}{\Sigma(Weights)}$

* $= \frac{(68 \times 120) + (65 \times 120) + (87 \times 140)}{68 + 65 + 87}$

* $= \frac{28140}{220}$

* $= 127.91$
