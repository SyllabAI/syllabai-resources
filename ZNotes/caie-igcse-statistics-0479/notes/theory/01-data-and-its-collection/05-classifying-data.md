## Classifying Data

Collected data can be classified into 4 categories.

1. ### Quantitative:

   Data that is measured and expressed in numerical values. For example, the number of students in a class: 23.

2. ### Qualitative:

   Descriptive data that cannot be expressed in numerical values. For example, the colour of a car, red.

3. ### Discrete:

   Distinct data with no intermediates. It is expressed in whole numbers; for example, the number of marbles in a pouch, 7.

4. ### Continuous:

   Data that can take on any value within a range. For example, the weight of an elephant, 90.3 kilograms.
