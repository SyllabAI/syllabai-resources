## Forming Specific Conc. Solutions

**From a given parent solution**

e.g. 250cm<sup>3</sup> of 0.1 mol dm<sup>-3</sup> using a 2.0 mol
dm<sup>-3</sup> solution

  - Use $C_1V_1 = C_2V_2$

$$2.0\  \times \ x = 250\  \times \ 0.1$$

$$x = 12.5\ cm^3$$

  - Add 12.5cm<sup>3</sup> of parent solution to a volumetric flask
    (250cm<sup>3</sup>) using a burette

&nbsp;

**From a solid**

e.g. 250cm<sup>3</sup> of 0.5 mol dm<sup>-3</sup> solution of a crystal
Mr = 50g

  - Use $\text{Conc}\  = \frac{\text{Mols}}{\text{Vol}}$

$$Mols = 0.5\  \times \ 0.25 = 0.125$$

  - Use $\text{Mols} = \frac{\text{Mass}}{\text{Mr}}$

$$Mass = 0.125\  \times \ 50 = 6.25g$$

  - Add 6.25g of solid to 50cm<sup>3</sup> of water in a beaker

  - Stir well, add water gradually until fully dissolved

  - Transfer solution from the beaker to volume metric flask

  - Rinse the beaker with water and transfer back to the volumetric
    flask

  - Stopper the flask and shake properly

  - Top off volumetric flask with distilled water to mark.
