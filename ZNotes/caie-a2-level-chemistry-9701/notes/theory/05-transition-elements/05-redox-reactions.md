## Redox Reactions

* Transition elements have variable oxidation states

* Reactions involving reactants that change their oxidation states are redox reactions

* Note: Standard electrode potential values (E<sup>o</sup>) can be used to predict the feasibility of a reaction

  * The magnitude of the positive values provides a measure of a half-equation to proceed
    from left to right

  * The higher and more positive the E<sup>o</sup>, the greater the tendency of the reaction to proceed to the right

### Example 1. Iron ions and MnO<sub>4</sub><sup>-</sup> in acid solution

* Ions involved:

  * Fe<sup>2+</sup>, Fe<sup>3+</sup>, MnO<sub>4</sub><sup>-</sup>, Mn<sup>2+</sup>, and H<sup>+</sup> (from acid)

* Relevant half-equations:

  * Fe<sup>3+</sup>(aq) + e<sup>-</sup> $\rightarrow$ Fe<sup>2+</sup>(aq) :       E<sup>o</sup> = +0.77 V
  * MnO<sub>4</sub><sup>-</sup>(aq) + 8H<sup>+</sup>(aq) + 5e<sup>-</sup> $\rightarrow$ Mn<sup>2+</sup>(aq) + 4H<sub>2</sub>O(l) : E<sup>o</sup> = +1.52 V

* Analysis:

  * E<sup>o</sup> values show us that MnO<sub>4</sub><sup>-</sup>(aq) is more likely to accept electrons than Fe<sup>3+</sup>(aq)

  * Therefore, MnO<sub>4</sub><sup>-</sup>(aq) ions are capable of oxidising Fe<sup>2+</sup>(aq) into Fe<sup>3+</sup>(aq)

  * Hence, the Fe<sup>3+</sup>(aq) reaction will proceed in the reverse direction.

* Combining the half equations: (the first half-equation is multiplied by 5 to cancel out electrons)

  * 5Fe<sup>2+</sup>(aq) $\rightarrow$ 5e<sup>-</sup> + Fe<sup>3+</sup>(aq) :       E<sup>o</sup> = -0.77 V

  * MnO<sub>4</sub><sup>-</sup>(aq) + 8H<sup>+</sup>(aq) + 5e<sup>-</sup> $\rightarrow$ Mn<sup>2+</sup>(aq) + 4H<sub>2</sub>O(l) : E<sup>o</sup> = +1.52 V

  * Final equation:
    MnO<sub>4</sub><sup>-</sup>(aq) + 5Fe<sup>2+</sup>(aq) + 8H<sup>+</sup>(aq) $\rightarrow$ Mn<sup>2+</sup>(aq) + 5Fe<sup>3+</sup>(aq) + 4H<sub>2</sub>O(l)

  * Final E<sup>o</sup> = +0.75 V (= -0.77 V + 1.52 V)

### Example 2. Manganate (VII) ions and ethanedioate ions (from ethandioic acid)

* Ions involved:

  * C<sub>2</sub>O<sub>4</sub><sup>2-</sup>, MnO<sub>4</sub><sup>-</sup>, Mn<sup>2+</sup>, and H<sup>+</sup> (from acid)

* Relevant half-equations:

  * C<sub>2</sub>O<sub>4</sub><sup>2-</sup>(aq) $\rightarrow$ 2CO<sub>2</sub>(g) + 2e<sup>-</sup>
  * MnO<sub>4</sub><sup>-</sup>(aq) + 8H<sup>+</sup>(aq) + 5e<sup>-</sup> $\rightarrow$ Mn<sup>2+</sup>(aq) + 4H<sub>2</sub>O(l)

* Analysis:

  * The oxidation number of C goes from 3+ (in C<sub>2</sub>O<sub>4</sub><sup>2-</sup>) to 4+ (in CO<sub>2</sub>), while Mn is reduced from 7+ (in MnO<sub>4</sub><sup>-</sup>) to 2+

  * To balance this, we must multiply the first equation by 5, and the second by 2

* Combining the half equations:

  * 5C<sub>2</sub>O<sub>4</sub><sup>2-</sup>(aq) $\rightarrow$ 10CO<sub>2</sub>(g) + 10e<sup>-</sup>

  * 2MnO<sub>4</sub><sup>-</sup>(aq) + 16H<sup>+</sup>(aq) + 10e<sup>-</sup> $\rightarrow$ 2Mn<sup>2+</sup>(aq) + 8H<sub>2</sub>O(l)

  * Final equation:
    2MnO<sub>4</sub><sup>-</sup>(aq) + 5C<sub>2</sub>O<sub>4</sub><sup>2-</sup>(aq) + 16H<sup>+</sup>(aq) $\rightarrow$ 2Mn<sup>2+</sup>(aq) + 10CO<sub>2</sub>(g) + 8H<sub>2</sub>O(l)

  * Note: The MnO<sub>4</sub><sup>-</sup> ion reacts with the ethanedioate ion in the ratio 2 : 5

### Example 3. Copper (II) ions and iodide ions in aqueous solution and titration guide

* Relevant half-equations:

  * Cu<sup>2+</sup> + e<sup>-</sup> $\rightarrow$ Cu<sup>+</sup>

  * 2I<sup>-</sup> $\rightarrow$ I<sub>2</sub> + 2e<sup>-</sup>

* Combining the half equations: (first equation is multiplied by 2)

  * 2Cu<sup>2+</sup> + 2e<sup>-</sup> $\rightarrow$ 2Cu<sup>+</sup>

  * 2I<sup>-</sup> $\rightarrow$ I<sub>2</sub> + 2e<sup>-</sup>

  * Final equation:
    2Cu<sup>2+</sup> + 2I<sup>-</sup> $\rightarrow$ 2Cu<sup>+</sup> + I<sub>2</sub>

If iodide ions are in excess, then iodide would form in solution and copper (I) iodide ppt. would form:

* 2Cu<sup>2+</sup>(aq) + 4I<sup>-</sup>(aq) $\rightarrow$ 2CuI(s) + I<sub>2</sub>(aq) (equation 1)

* This reaction can be used to find the conc. of copper (II) ions in a solution

* Formation of I<sub>2</sub> means that starch solution can be used as an end-point indicator in titration

* Sodium thiosulfate (known conc.) can be added via a burette to react with I<sub>2</sub>:

  * I<sub>2</sub>(aq) + 2S<sub>2</sub>O<sub>3</sub><sup>2-</sup>(aq) $\rightarrow$ 2I<sup>-</sup>(aq) + S<sub>4</sub>O<sub>6</sub><sup>2-</sup>(aq) (equation 2)

* As the I<sub>2</sub>(aq) gets used up (in equation 2), the brown solution turns lighter; this is when the indicator is added (turns blue-black at end-point)

* Sodium thiosulfate is then added till blue-black colour disappears (i.e. when all the I<sub>2</sub> has reacted) to obtain final burette reading (and titre value)
