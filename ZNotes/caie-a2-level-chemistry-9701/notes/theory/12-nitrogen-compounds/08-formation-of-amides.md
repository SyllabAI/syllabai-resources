## Formation of Amides

**Formation of:**

* Primary Amides:

![](../../../assets/382f0c88d29a-image095.png)
Note: If NH<sub>3(aq)</sub> is used in excess, HCl may react with it

* Substituted (secondary) Amides:

![](../../../assets/0338e1b79b2e-image096.png)
Note: If there is an excess of amine, it will react with the HCl formed, making its salt

* Type of reaction:

  * nucleophilic substitution

* Reagent:

  * conc. NH<sub>3(aq)</sub>

* Condition:

  * r.t.p.

* Example of the formation of a substituted amide:

  ‎ ![](../../../assets/ab5278a8b2d1-cdb483b6102cf6d0e2350fd4.webp)

  ethanoyl chloride + methyl amine $\rightarrow$ N-methyl methanamide

  * Note: If there is an excess of methyl amine, it will react with the HCl formed, making CH<sub>3</sub>NH<sub>3</sub>$^{+}$Cl$^{-}$
