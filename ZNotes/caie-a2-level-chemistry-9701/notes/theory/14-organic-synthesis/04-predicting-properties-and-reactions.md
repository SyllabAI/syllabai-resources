## **Predicting Properties and Reactions**

When predicting how a multi-functional molecule will react, you must analyze each functional group independently, but also watch out for **selectivity**.

* *Example:* If a molecule contains both a ketone and a carboxylic acid group, adding $NaBH_4$ will **only** reduce the ketone to a secondary alcohol. The carboxylic acid will remain untouched because $NaBH_4$ is not a strong enough reducing agent for it (you would need $LiAlH_4$ to reduce both).

* *Example:* If a molecule has both an alcohol and a phenol group, adding a carboxylic acid (with an acid catalyst) will form an ester with the alcohol, but *not* with the phenol (phenols require highly reactive acyl chlorides to form esters).

## **Devising Multi-Step Synthetic Routes**

**Step 1: Check the Carbon Skeleton**

Count the carbons. Has the chain length changed?

* **Increasing chain length:** You need to form new $C-C$ bonds.

  * React a haloalkane with ethanolic $KCN$ (adds a $-CN$ group).

  * React an aldehyde/ketone with $HCN$ (adds a $-CN$ group).

  * Friedel-Crafts alkylation or acylation (adds carbon chains to benzene rings).

* **Decreasing chain length:** You need to break $C-C$ bonds.

  * Oxidative cleavage of alkenes using hot, concentrated acidified $KMnO_4$.

  * The Triiodomethane (Iodoform) reaction removes one carbon as a $CHI_3$ precipitate, leaving a carboxylate salt.

**Step 2: Functional Group Interconversions (FGI)**

If the carbon skeleton is the same, you only need to change the functional groups.

* *Note for students:* You must memorize your reaction maps! Know how to get from an alkane $\rightarrow$ haloalkane $\rightarrow$ alcohol $\rightarrow$ aldehyde $\rightarrow$ carboxylic acid $\rightarrow$ ester/acyl chloride.

**Step 3: Determine the Correct Order**

If you need to make two changes, the sequence matters immensely.

* *Example (Benzene substitution):* If you want to make 3-nitrobenzoic acid from toluene (methylbenzene), you must oxidize the methyl group to a carboxylic acid *first*, because the $-COOH$ group is 3-directing. If you nitrate it first, the methyl group is 2,4-directing, which would give you the wrong isomers.
