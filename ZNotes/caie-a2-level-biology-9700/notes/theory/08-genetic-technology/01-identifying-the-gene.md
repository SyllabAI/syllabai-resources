# Genetic technology

* **Genetic Engineering:** The modification of an organism’s characteristics by manipulating its genetic material

* **Recombinant DNA (rDNA):** DNA that has been modified to include genes from multiple other species

* **Genetically Modified Organism, GMO:** An organism in which the DNA has been modified artificially using genetic engineering

* **Transgenic organism:** An organism that contains DNA from another source

### Recombinant DNA Technology Basic Overview:

1. The target gene is identified and isolated from the organism

2. Multiple copies of the gene are made using PCR

3. The gene is inserted into a vector which takes it into the cells

4. The cells with the new gene are identified using marker genes

5. They are then cloned
