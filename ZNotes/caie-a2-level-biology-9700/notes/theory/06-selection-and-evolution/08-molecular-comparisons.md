## Molecular Comparisons

* Molecular comparisons help identify evolutionary relationships between species, by analyzing amino acid sequences and mitochondrial DNA

### Amino acid sequences

* Amino acid sequences are determined by DNA, so comparing sequences provides insight into genetic similarities

* The more similar the amino acid sequences, the more closely related the species

* Differences in the sequences are caused by mutations, which accumulate over time, so more differences = more distant common ancestor

### Mitochondrial DNA (mtDNA)

* The more similar the nucleotide sequences, the more closely related the species

* mtDNA is only inherited from the mother, so the female line can be tracked

* Mutations occur at a constant rate, so differences in mtDNA sequences help estimate how recently 2 individuals shared a common ancestor

* It mutates faster than nuclear DNA, so we can study recent evolutionary events
