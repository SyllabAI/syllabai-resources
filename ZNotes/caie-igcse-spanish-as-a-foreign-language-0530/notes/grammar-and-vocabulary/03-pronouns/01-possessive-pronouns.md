# Pronouns

## Possessive Pronouns

* Used to replace nouns to avoid repetition
* When using them, be careful so that they agree with the gender and number of the object
* Possessive pronouns you need to know are:
  * mío/a → mine
  * tuyo/a → yours
  * suyo/a → his/hers
  * nuestro/a → ours
  * suyo/a → theirs
