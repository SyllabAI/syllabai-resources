## P2 Verbs

* P2 verbs have a conjugation rule that only the *nosotros* form of the verb follows **regular conjugation** rules, rest are irregular
* Common P2 verbs you will need are:
  * Querer - to want
  * Poder - to be able to
  * Venir - to come
  * Decir - to say
  * Preferir - to prefer
  * Mostrar - to show
  * Volver - to return (person)
  * Devolver - to return (object)
  * Empezar - to start
* For instance, the conjugation of one of these verbs (eg: querer) would be as follows:

| **Subject Pronoun** | Querer conjugation |
|----|----|
| yo | quiero |
| tú | quieres |
| él/ella/usted | quiere |
| nosotros/nosotras | queremos |
| ellos/ellas/ustedes | quieren |

* Note that in this chart, it is the conjugation of the *nosotros* form that does follows the stem (quer-) of the verb. All of the other conjugations are stem-changing, and hence irregular
