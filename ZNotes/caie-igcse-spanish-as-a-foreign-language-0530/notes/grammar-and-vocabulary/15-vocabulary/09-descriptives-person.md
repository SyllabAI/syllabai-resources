## Descriptives (Person)

* Él/ella es… (he/she is…)
  * alto → tall
  * bajo → short
  * delgado → thin/slim
  * gordo → fat
  * hermoso/a → beautiful
  * feo/a → ugly
  * jóven → young
  * mayor → old
* Él/ella tiene pelo… (his/her hair is…)
  * negro → black
  * rubio → blond
  * corto → short
  * largo → long
  * liso → straight
  * rizado → curly
* Él/ella tiene ojos… (his/her eyes are…)
  * marrones → brown
  * verdes → green
  * azules → blue
  * grandes → big
  * pequeños → small
* Personalidad (personality)
  * amable → kind
  * empático/a → empathetic
  * inteligente → intelligent
  * optimista → optimist
  * responsable → responsile
  * sensible → sensible
  * bueno/a → good
  * gracioso/a → funny
  * tímido/a → shy
  * agradable → nice
  * trabajador/a → hard-working
  * malo/a → bad
  * interesante → interesting
  * orgulloso/a → proud
