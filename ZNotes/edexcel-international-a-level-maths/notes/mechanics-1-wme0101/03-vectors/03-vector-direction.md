## Vector Direction

* To get the angle between the vector and the horizontal axis ($i$) or the vertical axis ($j$):
  * Draw the horizontal and vertical axis.
  * Draw the vector.
  * Use trigonometry rules to calculate the required angle.
* To get the angle between two vectors:
  * Draw the horizontal and vertical axis.
  * Draw the first vector.
  * Use trigonometry rules to calculate the angle it makes with horizontal axis.
  * Draw the second vector.
  * Use trigonometry rules to calculate the angle it makes with horizontal axis.
  * Find the difference between both angles.
