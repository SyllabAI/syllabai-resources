# Measures of location and spread

## Types of Data

* **Qualitative Variables**: Non-numerical data descriptions.

  * *Examples: eye color, car brand, blood type.*

* **Quantitative Variables**: Numerical data values.

  * **Discrete**: Countable, distinct values

    * *Examples: number of children, shoe sizes (4,5,6)*

  * **Continuous**: Measurable values that can take any value within a given range.

    * *Examples: height, time, weight (1.36m, 32s, 55.6kg)*
