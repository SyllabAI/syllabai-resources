## Other Measures of Location

### Quartiles and percentiles

* Quartiles split ordered data into 3 quarters:

  * $Q_1 $(lower quartile)

  * $Q_2$ (median)

  * $Q_3$ (upper quartile).

* Percentile shows the percentage that falls below a specific value in a group

  * e.g. P90 is 90th percentile
    * getting 90th percentile for a test means you performed better than **90% of the group**

### Finding Quartiles for discrete variables

* Finding data position

  * $Q_1$= $\frac{n}{4}$

  * $Q_2$=$\frac{n}{2}$

  * $Q_3$= $\frac{3n}{4}$

* The rule:

  * If the position is a *whole number*, take the value above.

  * If the position has a *decimal*, round up.

**Example Model 1:**

$$\boxed{ [10, 12, 14, 15, 17, 18, 20, 22, 23, 25, 27]}$$

**Lower Quartile (\\(Q\_\{1\}\\))**

* Calculate: $\frac{n}{4} = \frac{11}{4} = 2.75$

  * It is not a whole number --\> round up to 3

* Pick the 3rd data point.

  * Answer: $Q_1 = 14$

**Example Model 2:**

$$\boxed{ [10, 12, 14, 15, 17, 18, 20, 22, 23, 25, 27, 30]}$$

**Lower Quartile (\\(Q\_\{1\}\\))**

* Calculate: $\frac{n}{4} = \frac{12}{4} = 3$

  * It is a whole number $\rightarrow$go **halfway** between the **3rd** and **4th** data points.

* Pick the midpoint of 3rd and 4th data point.

  * Answer: $\frac{14 + 15}{2} = 14.5$
