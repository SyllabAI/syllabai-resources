## **Using a calculator**

* On a calculator, the Normal C.D. function only gives you the probability that Z is *less than* a value (the area to the left on the graph)

* you input a very large negative number (e.g. −90000) as the lower bound if you want P(Z \< z) and your upper bound as the value you want

* There is no difference between P(Z \< z) and P(Z ≤ z) as Z is a continuous random variable, so the probability of it taking any one exact single value is zero: P(Z = z) = 0

  * For example in a question of heights in cm: P(Z\< 180) and P(Z ≤ 180) are the same because P(Z=180) is 0

    * The probability of a person being exactly 180.00000000 is almost zero

* Removing or including a single point does not change the area under the curve
