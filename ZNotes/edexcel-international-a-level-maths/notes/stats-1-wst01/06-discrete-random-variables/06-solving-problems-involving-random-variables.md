Given that $E(X) = 2.2$, find the values of a and b

**Answer:**

* (probabilities sum to 1):

  a \+ b \+ 0.3 \+ 0.1 = 1, so **a \+ b = 0.6**

* (expected value):

  1a \+ 2b \+ 3(0.3) \+ 4(0.1) = 2.2

  a \+ 2b \+ 1.3 = 2.2,

  **a \+ 2b = 0.9**

* Using simultaneous equation, a=0.3 and b=0.3

**Question 8:**

X is a discrete random variable. The random variable Y is defined by Y= 4X -6. Given that E(Y) = 2 and Var (Y)= 32. Find: (a) E(X) and (b) Var (X)

**Answer:**

* (a)

* Rearrange the X:

* X=$\frac{Y+6}{4}$ = $\frac{Y}{4} + \frac{3}{2}$

* E(X)=$\frac{1}{4}E(Y)+\frac{3}{2}$

* E(X)= $\frac{1}{4}(2)+\frac{3}{2}$ = 2

* (b)

* $X=\frac{Y+6}{4}$ = $\frac{Y}{4} + \frac{3}{2}$

* $Var(X)=(\frac{1}{4})^2E(Y)$

  * When calculating variance, the shift ($\frac{3}{2}$ in this case) doesn’t affect the variance so we just ignore it

* $Var(X)=2$
