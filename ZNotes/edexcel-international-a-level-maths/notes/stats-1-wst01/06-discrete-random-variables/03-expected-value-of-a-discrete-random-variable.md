## Expected value of a discrete random variable

* The **E**xpected Value (EV) of a discrete random variable is the long-run average outcome if you repeated an experiment indefinitely

* The expected value E(X) is the theoretical mean of X

* Formula: $E(X) = ΣxP(X = x)$

  * It is calculated by multiplying each possible outcome x by its corresponding probability

* Always make sure that the probabilities sum to 1 before calculating E(X)

* Example:

  Consider a fair six-sided die. The random variable X represents the number you roll. For 1 to 6, each probability has $\frac{1}{6}$

  $E(X)=\left\(1\cdot \frac{1}{6}\right\)+\left\(2\cdot \frac{1}{6}\right\)+\left\(3\cdot \frac{1}{6}\right\)+\left\(4\cdot \frac{1}{6}\right\)+\left\(5\cdot \frac{1}{6}\right\)+\left\(6\cdot \frac{1}{6}\right\)$

  $E(X)=\frac{1+2+3+4+5+6}{6}=\frac{21}{6}=3.5$

* **Key Insight:** The expected value of 3.5 is a theoretical average. You can never actually roll a (3.5) on a single die, but if you roll the die thousands of times, the average of your results will get closer and closer to 3.5.

**Question 4:**

Find $E(X)$ for $ (x = 1,2,3,4 $ with $ P(X=x)= 0.4, 0.3, 0.2, 0.1)$

**Answer:**

$E(X) = 1(0.4) + 2(0.3) + 3(0.2) + 4(0.1)$

$= 0.4 + 0.6 + 0.6 + 0.4$

$= 2$
