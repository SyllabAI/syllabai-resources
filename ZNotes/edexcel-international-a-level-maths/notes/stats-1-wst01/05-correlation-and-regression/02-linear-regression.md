## Linear regression

* Line of best fit: a straight line showing the trend on a scatter diagram

  * Least squares regression line = the best-fit line, minimising the sum of squared distances from each point to the line

  * More accurate than a fit line drawn by eye as it is calculated exactly from the data

**The order of the variables**

* y on x: predicts y from x, minimises vertical distances. Use when x is independent, y is dependent

  (y = mx \+ c)

* x on y: predicts x from y, minimises horizontal distances

  * The two lines are different\>\>\>always check which variable you're predicting

**Interpreting the gradient**

* Interpret in real-world context, not just the number on graph

  * Example: gradient b = 4, write: “For every additional hour spent revising, the exam mark increases by 4 marks.”

A **linear change of variable** 

* shifts and scales a dataset using a linear transformation which alters the line's gradient and intercept without changing the strength or validity of the correlation.

**Interpolation and extrapolation**

* A regression line is a valid model only when the data shows linear correlation

* Interpolation: using the regression line to predict a value **within** the range of the given data

* Extrapolation: using the regression line to predict a value **outside** the range of the given data

  * The questions may require you to mention extrapolation when it asks you the reliability of extrapolation

* It is important to only make predictions for the dependent variable. If you need to predict a value of x from a given value of y, you must use the regression line of x on y, not y on x
