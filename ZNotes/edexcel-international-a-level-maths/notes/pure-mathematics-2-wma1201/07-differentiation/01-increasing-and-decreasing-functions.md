# Differentiation

## Increasing and Decreasing Functions

* Differentiation can help determine if a given function increases or decreases within an interval.

### **Increasing Functions**

* In increasing functions, when the value of x rises, so does the value of y.
* It can be identified through differentiation when $\frac{dy}{dx} > 0$

 ![](../../../assets/685d7745f123-6553c3add6cf9a6a1a1e2fb236a3ae10447b5db1117c5a45.13)→ As seen above, when the value of x rises from $x_1$ to $x_2$, y also rises.

### **Decreasing Functions**

* In decreasing functions, as the value of x rises, the value of y lessens.
* It can be identified through differentiation when $\frac{dy}{dx} < 0$

 ![](../../../assets/57560ca0aa41-6553c3add6cf9a6a1a1e2fb250b65d278b7973423cb195ee.15)→ As seen above, when the value of x increases from $x_1$ to $x_2$, the value of y decreases.
