## Logarithms

* A logarithm is the inverse function of an exponential function.

→ The standard form of logarithms are written as: $\log_bx$ ; where b\>0; x\>0 ; b is not 1.

### Conversion from a logarithmic function to an exponential:

$$
y=\log_bx \ \text{converts to} \ x = b^y
$$

* Example: $y=\log_2x$  converts into $x=2^y$

### **Laws of Logarithms**

1. The multiplication rule: $\log(xy) = \log_ax + log_ay$
2. The division rule: $\log_a (\frac{x}{y}) = \log_ax - \log_ay$
3. The power rule: $\log_a(x^k) = k\log_ax$
4. $\log_a ( \frac{1}{x}) = -\log_ax$
5. $\log_aa = 1$

Example Question:

* Rewrite $4^4 =256$ as a logarithm

Solution:

* We can see that there is a power involved in this equation; therefore, we must apply the power rule.
* Take logs of both sides to get $\log4^4 = \log256$
* Use the power rule to get $4\log4 = \log256$
* Therefore: $4 = \frac{\log 256}{\log4}$

### Solving Equations in the form of $a^x=b$

* Example Question: Solve the following equations, giving your answers to 3 s.f where appropriate:

  a) $3^{x+1} = 2000$

* Solution:

1. Take logs of both sides to get $\log3^{x+1} = \log 2000$
2. Using the power rule get: $x+1(\log3) = \log2000$
3. Therefore: $x+1 = \frac{\log 2000}{\log3}$ → $x+1 = 6.92$
4. x= 5.92
