# Integration

## Introduction

* Integration is the reverse of differentiation
* $\int x^n = \frac{x^(n+1)}{n+1} +c$
* Make sure to include the c, as this is an indefinite integral
* Indefinite integrals are integrals without limits
* Use the coordinates of a point on the curve to find  when integrating a derivative to find the equation of the curve
