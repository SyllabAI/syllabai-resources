## Inequalities

* It can be solved like equations, as the solution of an inequality is the set of all real numbers x that make the inequality true.
* Linear inequalities can be solved as equations.
* Quadratic inequalities must be rearranged into $ax^2 + bx + c$ , so the solutions can be found using factorization or formula.
* Inequalities in the form $\frac{a}{x} > b$ :
  * Both sides must be multiplied by $x^2$ and then solved like a quadratic inequality; multiplying both sides by only x provides only one solution.
