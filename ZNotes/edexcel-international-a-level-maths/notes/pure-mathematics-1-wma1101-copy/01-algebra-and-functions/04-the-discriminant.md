## The Discriminant

* In a quadratic function, the discriminant ($b^2 - 4ac$). The discriminant can help find the number of solutions the function may have.
  * if $b^2- 4ac > 0$ the function has two distinct roots
  * if $b^2-4ac = 0$ the function has a repeating root
  * if $b^2-4ac < 0$ the function has no real roots
