## Useful Phrases

* Das ist/war alles (That is/was all)
  * When you’re done talking
* Noch einmal bitte (Once more please)
  * To prompt the examiner to repeat the question as it is
* Wie bitte? (Excuse me?)
  * To prompt the examiner to repeat the question as it is
* Langsamer bitte (Slower please)
* Lauter bitte (Louder please)
* Ich möchte noch etwas sagen bitte (I want to add something please)
  * If the examiner interrupted you when you still have something to say.
* Nicht verstanden/Ich kann die Frage nicht verstehen (I don’t understand the question)
  * This will cause the examiner to ask an alternative question if there is, if there are no alternative questions the examiner will continue to the next question.
* Ich persönlich ….. (I personally)
  * When you’re talking about your personal opinion ex. Ich persönlich hasse Mathe.
* Wie ich schon gesagt habe (like I already said before)
  * If you want to repeat an idea that you have said before in a question.
