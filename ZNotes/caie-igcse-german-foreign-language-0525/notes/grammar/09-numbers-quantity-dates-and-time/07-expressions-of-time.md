## Expressions of Time

Using expressions for time helps us know in which tense will our sentence be, whether past, present, or future.

| **Expression** | **Meaning** |
|----|----|
| **Morgen** | Morning |
| **Nachmittag** | Afternoon |
| **Abend** | Evening |
| **Nacht** | Night |
| **Mitternacht** | Midnight |
| **Heute Nacht** | Tonight |
| **letzte Nacht** | Last night |
| **Heute** | Today |
| **Morgen** | Tomorrow |
| **Gestern** | Yesterday |

Ex:

* Gestern habe ich viel Sport getrieben. *(Yesterday I exercised a lot.)*
* Am nächsten Morgen werde ich viel laufen. *(Next morning I will run a lot.)*
* Ich möchte heute mehr lesen. *(I want to read more today.)*
