## Important reminders about maps

### Describing an area:

* **General statement** (location on map, direction, place specific details: names etc)

* **Physical features** (Contour, relief, spot height etc)

* **Human features (**(e.g. land use, settlement etc)

### Extra Points 

* If contour lines are going in, then it is a valley

* Exotic forest are a human feature (introduced forest).
