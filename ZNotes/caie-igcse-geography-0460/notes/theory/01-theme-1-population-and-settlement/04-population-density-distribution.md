## Population Density & Distribution

* **Keywords:**
  * **Population density:** number of people per unit of area (typically per kilometre square)
  * **Sparsely populated:** an area with low population density
  * **Densely populated:** an area with high population density
* **Factors influencing:**

|    | Sparse Population | Dense Population |
|----|----|----|
| **Physical Factors** | Harsh areas; mountainous or uneven relief | Flat relief |
|    | Extreme/harsh climates and bad weather | Favourable climates and good weather |
|    | High risk of flooding | Availability of natural resources for industry and manufacturing. |
|    | Infertile soil | Fertile land for crops |
|    | Locations with frequent natural disasters | No or few natural disasters. |
|    | No water supplies. | Good water supply i.e. a river. |
|    |    |    |
| **Economic factors** | No economic opportunities | Many jobs opportunities |
|    | No infrastructure | Good infrastructures |
|    | No transport routes. | Many transport routes to travel easily. |
|    | Bad communication | Good communication |
| **Social factors** | High crime rates | Low crime rates |
|    | No Cultural and religious beliefs. | Cultural and religious beliefs of having big family. |
| **Political factors** | Government corruption | Reliable and stable government |
|    | Poor public services such as healthcare and education | Good public services |
|    | Civil war | No threats or wars. |
|    | Low birth rate and high death rate. | High birth rate and low death rate. |
|    |    |    |
