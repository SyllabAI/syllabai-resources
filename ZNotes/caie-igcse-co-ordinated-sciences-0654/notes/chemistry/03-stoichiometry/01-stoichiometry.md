# Stoichiometry

### Types of formulae:

**Molecular formula:** the number and type of atoms in one molecule.

E.g. H₂O, CH₄, C₆H₁₂O₆.

### **Deducing formulae from ion charges**

* Overall charge of the compound must be zero

* Cross-multiply charges to find the ratio, then simplify

**Example:** Ca²⁺ \+ Cl⁻ → CaCl₂ (need 2 Cl⁻ to balance 1 Ca²⁺)


Mg²⁺ \+ O²⁻ → MgO (1:1)

### **Word equations**

* Show reactants → products using names

* Example: methane \+ oxygen → carbon dioxide \+ water

### **Balancing symbol equations**

* Equation is balanced when the number of each atom is the same on both sides

* Only change the coefficient; never change the subscript

* Balance one element at a time; leave O and H last

Example: CH₄ \+ O₂ → CO₂ \+ H₂O


Balance H: CH₄ \+ O₂ → CO₂ \+ 2H₂O


Balance O: CH₄ \+ 2O₂ → CO₂ \+ 2H₂O ✓
