## Monohybrid inheritance

* **Dominant allele**: This will be expressed if it is present.
* **Recessive allele**: This will only be expressed if no dominant alleles exist.
* **~~Homozygou~~s**: An individual that contains two identical alleles.
* **Heterozygous**: An individual that contains two differing alleles.
* **Pure breeding**: This can only occur when two identical homozygous individuals breed together.
