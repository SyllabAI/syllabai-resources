## Algebraic Indices

* All the laws indices have been covered in the previous chapter. Here, we apply them to solve algebraic questions.

### Worked Examples

**Example 1**

$\text{Q. Solve } 32^{x} = 2$

**Step 1:** Express both sides with the same base

We know: $32 = 2^{5}$

$32^{x} = (2^{5} ) ^{x}$

**Step 2:** Apply the Power Rule

$(2^{5} )^{x} = 2^{5x}$

So, the equation becomes: $2^{5x} = 2^{1}$

**Step 3:** Use the One-to-One Property of Exponents

$5x = 1$

**Step 4:** Solve for $x$

$x= \frac{1}{5}$

**Final Answer:** $\boxed{x = \frac{1}{5}}$

**Example 2**

$\text{Q. Simplify } 3x^{-4} \times \frac{2}{3} x^{\frac{1}{2}}$

**Step 1:** Group Constants and Variables

$(3 \times \frac{2}{3} ) \times (x^{-4} \times x^{\frac{1}{2}} )$

**Step 2:** Simplify Constants

$3 \times \frac{2}{3} = 2$

**Step 3:** Apply the Product of Powers Rule

Use the law: $x^{a} \times x^{b} = x^{a+b}$

$x^{-4} \times x^{ \frac{1}{2} } = x^{-4 + \frac{1}{2} } = x^{ \frac{-7}{2} }$

**Step 4:** Combine Results

$2 \times x^{ \frac{-7}{2} } = 2x^{ \frac{-7}{2} }$

**Final Answer**: $\boxed{2x^{ \frac{-7}{2} }}$
