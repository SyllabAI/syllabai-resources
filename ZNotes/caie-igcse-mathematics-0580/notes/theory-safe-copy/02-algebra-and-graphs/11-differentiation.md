## Differentiation

### **Understanding Differentiation**

* Differentiation finds the **gradient (slope)** of a curve at any point

* It allows us to calculate the gradient of any $x$-coordinate on a curve.

### Power Rule

* For function

  $f(x) = x^{n}$

* The derivative is:

  $\frac{d}{dx} (x^{n}) = n \cdot x^{n-1}$

* Steps:

  1. Multiply by the exponent n

  2. Subtract 1 from the exponent

* **Worked Example**

  $\frac{d}{dx} (x^{5}) = 5x^{4}$

### Differentiating Constants

* The graph is a horizontal line, so the gradient = 0.

* $\frac{d}{dx} (a) = 0$

### Stationary Points

* A stationary point occurs where the gradient = 0

  $\frac{dy}{dx}$ = 0

* Steps to find stationary points:

  1. Differentiate the function

  2. Set $\frac{dy}{dx}$ = 0

  3. Solve for $x$

### Nature of Stationary Points

1. **Second Derivative Test**

* Differentiate again to get $\frac{d^{2} y}{d x^{2}}$

  * If $\frac{d^{2} y}{d x^{2}} > 0$ $\rightarrow$ **Minimum Point**

  * If $\frac{d^{2} y}{d x^{2}} < 0$ $\rightarrow$ **Maximum Point**

2. **Gradient Method**

* If the gradient changes $+ \rightarrow -$, the turning point is a **Maximum**

* If the gradient changes from $- \rightarrow +$, the turning point is a **Minimum**

3. **Graph Shape Method**

* Look at the curve around the turning point:

  * If the curve is like a **$\cup$**, it is a minimum.

  * If the curve is like a **$\cap$**, it is a maximum.
