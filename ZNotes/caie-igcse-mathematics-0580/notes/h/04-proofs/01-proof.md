## Quadratics

$ax^2 + bx +c$ = $a(x- \alpha)(a- \beta)$

$x^2 + \frac{b}{a}x + \frac{c}{a} = (x- \alpha)(x- \beta)$

$x^2 + \frac{b}{a}x + \frac{c}{a} = x^2 - \beta x -\alpha x + \alpha \beta$

$x^2 + \frac{b}{a}x + \frac{c}{a} = x^2 -(\alpha + \beta)x + (\alpha \beta)$

$\frac{b}{a} = -(\alpha + \beta) = \sum \alpha$

$\frac{c}{a} = \alpha \beta = \sum \alpha \beta$

### Cubic

$\sum \alpha = \alpha + \beta + \gamma = - \frac{b}{a}$
