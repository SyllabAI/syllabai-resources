## Exponential Graphs

### Standard Form

* $y = a(r^x) + b$

### Properties

1. Parameter $a$

* Represents the **vertical stretch** and determines the initial value when $x=0$.

2. Parameter $r$

* Represents the **base** of the exponential function.

* Determines whether the function is increasing or decreasing:

  * If $r > 1$, the curve **increases** as $x$ increases

  * If $0 < r < 1$, the curve **decreases** as $x$ increases

3. Parameter $b$

* Represents the **vertical shift** of the graph

* Shifts the curve **upwards** or **downward**

* Determines the **horizontal asymptote**: $y=b$

4. Asymptotes

* A curve approaches but never touches these lines

* For $y=a(r^{x})+b$, the asymptote is:

  $y=b$

* There is no vertical asymptote, unless the domain is restricted
