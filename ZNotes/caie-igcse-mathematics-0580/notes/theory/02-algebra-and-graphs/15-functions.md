## Functions

### Introduction to Functions

* Functions are like pre-set rules: you input a value, apply the rule, and get an output.

* Domain: The set of all possible input values (x-values) for a function.

* Range: The set of all possible output values (y-values) from the function.

* For an **inverse,** the domain and range are swapped

### Inverse Function

**Steps to find the Inverse Function $f^{-1} (x)$**

* **Step 1:** Replace $f(x)$ with $y$: $y = f(x)$

* **Step 2:** Swap $x$ and $y$

* **Step 3:** Solve for $y$ in terms of $x$

* **Step 4:** Replace $y$ with $f^{-1} (x)$

  **Example**

  * $f(x) = x^2 + 9$

  * $y = x^2 + 9$

  * $x = y^2 + 9$

  * $x-9 = y^2$

  * $y = \pm \sqrt{x-9}$

  * $f^{-1}(x) = \pm \sqrt{x-9}$

### Composite Function

* Notation: $gf(x) = g(f(x))$

**Steps to Form a Composite Function**

- **Step 1:** Find f(x)

- **Step 2:** Substitute f(x) into g(x)

- **Step 3:** Simplify

- **Worked Example**

  $\text{Find composite function  } \begin{cases} f(x) = 3x - 5 \\ g(x) = \frac{3 (x+4) }{5} \end{cases}$

  **Step 1:** Find $f(x)$

  $f(x) = 3x - 5$

  **Step 2:** Substitute into $g(x)$

  $g(f(x)) = \frac{3 ( (3x - 5) + 4 )}{5}$

  **Step 3:** Simplify

  $g(f(x)) = \frac{3(3x - 1)}{5} = \frac{9x - 3}{5}$

  **Final Answer:** $\boxed{ gf(x) = \frac{9x-3}{5} }$
