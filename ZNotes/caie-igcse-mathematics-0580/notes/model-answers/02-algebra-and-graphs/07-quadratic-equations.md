## Quadratic Equations

**<span class="underline">Question 24:</span>**

$y\  = \ x^{2} + \ 7x\ –\ 5\ $can be written in the form

$y = \left( x + a \right)^{2} + b$.

Find the value of *a* and the value of *b*. (3 marks)

**<center>Solution:</center>**

*If we expand* $\left( x + a \right)^{2}$ *and collect terms we get*

$$y = \left( x + a \right)^{2} + b$$

$$= x^{2} + 2ax + a^{2} + b$$

*If we now compare coefficients of the powers of x we have*

$$\text{CF}\text{ x}^{1}:\ \ 2a = 7$$

$\mathbf{\rightarrow a =}\frac{\mathbf{7}}{\mathbf{2}}$ <b>or 3.5</b>

$$\text{CF}x^{0}\ (units):\ \ a^{2} + b = - 5$$

$$\rightarrow \frac{49}{4} + b = - 5$$

$$\rightarrow b = - \frac{20}{4} - \frac{49}{4}$$

$\mathbf{b = -}\frac{\mathbf{69}}{\mathbf{4}}$ <b>or -17.25</b>
