## Functions

**<span class="underline">Question 31:</span>**

| $f\left( x \right) = 5x + 7$ | $g\left( x \right) = \frac{4}{x - 3}$ |
|----|----|

a)  Find

i.  fg(1) (2 Marks)

ii.  gf(1) (2 Marks)

iii.  g<sup>-1</sup>(x) (2 Marks)

iv.  ff<sup>-1</sup>(2) (2 Marks)




b)  f(x) = g(x)

i.  Show that $5x^{2} - 8x - 25 = 0$ (3 Marks)

ii.  Solve $5x^{2} - 8x - 25 = 0$. Show all your working and give
your answers correct to 2 decimal places. (4 Marks)

**<center>Solution:</center>**

**Part (a)(i):**

*We apply f(x) to g(x) like so*

$$\text{fg}\left( x \right) = 5g\left( x \right) + 7$$

$$= \frac{20}{x - 3} + 7$$

$$\text{fg}\left( 1 \right) = \frac{20}{1 - 3} + 7$$

$$= - 10 + 7$$

$$= \mathbf{- 3}$$

**Part (a)(ii):**

*We apply the function g to the output of function f giving:*

$$\text{gf}\left( x \right) = \frac{4}{f\left( x \right) - 3}$$

$$= \frac{4}{5x + 7 - 3}$$

$$= \frac{\mathbf{4}}{\mathbf{5}\mathbf{x + 4}}$$

**Part (a)(iii):**

*Let* $y = g(x)$*. If we rearrange for* $x = f(y)$ *then that
function of y will be* $g^{- 1}(y)$*.*

$$y = \frac{4}{x - 3}$$

*Multiply both sides by* $x - 3$

$$y\left( x - 3 \right) = 4$$

*Divide both sides by y*

$$x - 3 = \frac{4}{y}$$

*Add 3 to both sides*

$$x = \frac{4}{y} + 3 = g^{- 1}\left( y \right)$$

$$\rightarrow \mathbf{g}^{\mathbf{- 1}}\left( \mathbf{x} \right)\mathbf{=}\frac{\mathbf{4}}{\mathbf{x}}\mathbf{+ 3}$$

**Part (a)(iv):**

*Inverse function applied to the function reverses its effect, so*

$$\mathbf{f}^{\mathbf{- 1}}\mathbf{f}\left( \mathbf{2} \right)\mathbf{= 2}$$

**Part (b)(i):**

*We have*

$$5x + 7 = \frac{4}{x - 3}$$

*Multiply both sides by* $x - 3$

$$(5x + 7)\left( x - 3 \right) = 4$$

*Expand*

$$5x^{2} + 7x - 15x - 21 = 4$$

*Rearrange and simplify forming a quadratic equation that equals zero:*

$$\mathbf{5}\mathbf{x}^{\mathbf{2}}\mathbf{- 8}\mathbf{x - 25 = 0}$$

**Part (b)(ii):**

*We use the quadratic formula, given as*

$x = \frac{- b \pm \sqrt{b^{2} - 4ac}}{2a}$ *(where*
$ax^{2} + bx + c = 0$*)*

*Substitute for*

$a = 5,\ b = - 8,\ c = - 25$

*hence:*

$$x = \frac{8 \pm \sqrt{64 + 20 \times 25}}{10}$$

$$= \frac{8 \pm 2\sqrt{141}}{10}$$

$$\mathbf{x = 3.17}\left( \mathbf{2.d.p.} \right)\mathbf{\ or\ x = \  - 1.57\ (2.d.p.)}$$
