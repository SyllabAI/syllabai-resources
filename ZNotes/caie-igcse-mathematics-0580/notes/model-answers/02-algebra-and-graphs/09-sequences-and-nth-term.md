## Sequences and nth term

**<span class="underline">Question 26:</span>**

Find the nth term of each of these sequences.

a)  16, 19, 22, 25, 28, ... (2 marks)

b)  1, 3, 9, 27, 81, ... (2 marks)

**<center>Solution:</center>**

**Part (a):**

*The difference between the terms is 3. The sequence can then be written
as*

$$3n + a$$

*Where a is some real number and n is the term. The first term is then*

$$3 + a = 16$$

$$\rightarrow a = 13$$

*Hence*

$$\mathbf{nth\ term = 3}\mathbf{n + 13}$$

**Part (b):**

*Each term is a power of 3 so our sequence has the form*

$$3^{f\left( n \right)}$$

*If we substitute in some values, we can see that*

$$1 = 3^{f\left( 1 \right)}$$

$$\rightarrow f\left( 1 \right) = 0$$

$$3 = 3^{f\left( 2 \right)}$$

$$\rightarrow f\left( 2 \right) = 1$$

*Hence*

$$f\left( n \right) = n - 1$$

*Final answer*

$$\mathbf{nth\ term = \ \ }\mathbf{3}^{\mathbf{n - 1}}$$
