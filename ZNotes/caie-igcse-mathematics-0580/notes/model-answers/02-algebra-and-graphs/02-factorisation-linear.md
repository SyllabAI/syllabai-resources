## Factorisation (Linear)

**<span class="underline">Question 18:</span>**

Factorise completely.

a)  $2a + 4 + ap + 2p$ (2 marks)

b)  $162\ –\ 8t^{2}$ (2 marks)

**<center>Solution:</center>**

**Part (a):**

$$\left( \mathbf{a + 2} \right)\left( \mathbf{p + 2} \right)$$

*We can check this by expanding it back out:*

$$ap + 2p + 2a + 4$$

**Part (b):**

*We can start off by factorising out the common factor of 2*

$$2\left( 81 - 4t^{2} \right)$$

*Then we can see that this is the difference of two squares*

$$= 2\left( 9^{2} - \left( 2t \right)^{2} \right)$$

$$\mathbf{= 2}\left( \mathbf{9 + 2}\mathbf{t} \right)\left( \mathbf{9 - 2}\mathbf{t} \right)$$
