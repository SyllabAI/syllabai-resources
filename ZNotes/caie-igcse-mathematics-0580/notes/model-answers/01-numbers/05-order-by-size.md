## Order by Size

**<span class="underline">Question 5:</span>**

Write the following in order of size, smallest first: π, 3.14,
$\frac{22}{7}$, 3.142, 3 (2 marks)

**<center>Solution:</center>**

*The order of size can be found by writing all of these numbers out to
the same number of decimal places, and then comparing. In order to do
this, put each of the values into the same format (decimals) using the
‘S⇔D’ button (located above ‘DEL’) on your calculator.*

$${\pi = 3.14159\ (5.d.p)}$$
$${3.14 = 3.14000\ (5.d.p)}$$
$${\frac{22}{7} = 3.14286\ (5.d.p)}$$
$${3.142 = 3.14200\ (5.d.p)}$$
$${3 = 3.00000\ (5.d.p)}$$

*Therefore, the order we get (smallest to largest) is:*

**3 < 3.14 < π < 3.142 <** $\frac{\mathbf{22}}{\mathbf{7}}$
