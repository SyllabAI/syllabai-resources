# General Tips

* If range given e.g. $0$ to $20$, try to get a measurement from a
  large spread of the range.
* Record all measurements needed to obtain final value including
  intermediary steps
* For example, if a length $l$ *i*s derived from
  $l\  = \ l_{2}\  - \ l_{1}$ then $l_{1}$ and $l_{2}$ should
  appear in the table.
* Column labelled with the name of symbol and units
