## Coplanar forces in equilibrium

Coplanar forces are forces that lie on the same plane in 2D

* Usually demonstrated using vector triangles

![](https://images.znotes.org/allimages/5a454b7d7ba8fdb3a7fff968.webp =1036x)

### How to draw vector triangle 

1. **Choose a scale**, e.g. 1 cm=10 N

2. Draw the first force to scale in its correct direction.

3. Draw the second force **head-to-tail**.

4. Draw the third force from the last point back to the starting point.

5. If the triangle **closes**, the forces are in equilibrium.

6. Measure the unknown side and use the scale to find the unknown force.

**Important:** The vectors must be drawn **head-to-tail**, not all starting from the same point.
