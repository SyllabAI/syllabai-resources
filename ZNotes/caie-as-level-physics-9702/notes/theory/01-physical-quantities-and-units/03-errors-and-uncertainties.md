## Errors and uncertainties

* When performing experiments it can’t always be 100% accurate and errors tend to occur.

  ![ChatGPT Image Sep 22, 2026, 02 15 07 PM](https://images.znotes.org/allimages/adc0e609d7115c97976b36c8.webp =471x)

* The syllabus requires students to learn 2 types of errors that is systemic and random

### Systemic error

* So as mentioned in the image it changes readings by a constant amount

* Either too big or too small but only in one direction

* Affects accuracy and cant be reduced by repeating

* These errors are typically caused by faulty instruments or an error in technique when measuring values

* **Examples include**:

  * Zero error -  instrument not at 0 when not used (important for exam)

  * Incorrect calibration

  * Scale factor error

  * Instrument drift

  * Parallax error - reading instrument from an angle causing an incorrect measurement.

### Random error

* Random scatter or fluctuations about the true value

* Caused by environmental conditions or observers

* Can be corrected through continuous repetitions

* **Example include**:

  * Human reaction time

  * Changes in volume due to change in temperature

  * Observational estimation

  * Changing environment

### Precision & Accuracy

* Accuracy - how close the measured value is to the true value.
  * If systematic error is small, measurement is accurate
* Precision - how close are the measured values to each other.
  * When random error is small, measurement is precise

### Uncertainties

Uncertainties are estimates of margin of error, have the same unit as the quantity.

*For a quantity* $x=(5.0±0.2)mm$

* Absolute uncertainty - uncertainty is a fixed quantity.

  * Absolute uncertainty - $Δx=±0.2mm$

* Fractional uncertainty - ratio of uncertainty and the quantity (fraction of the quantity)

  * Fractional uncertainty = $\frac{\text{absolute uncertainty}}{\text{measured value}}$ $=\frac{\mathrm{\Delta}x}{x} = 0.04$

* Percentage uncertainty - uncertainty is shown as a percentage

  * Percentage uncertainty = $\frac{\text{absolute uncertainty}}{\text{measured value}} \times 100\\%$ $= \ \frac{\mathrm{\Delta}x}{x} \times 100% = 4%$

    $=$ $4$%
