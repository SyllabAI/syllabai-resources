## Projectile Motion

* Projectile motion involves constant motion in one direction while accelerating in the other perpendicularly

* motion on x axis and motion on y axis are independent of each other

* Conditions:

  * Air resistance is negligible

  * Acceleration is only influenced by gravity is 9.81 $\mathrm{ms^{-2}}$ and acts downward

  * Effect of earth rotation is negligible

* Key things to know to solve projectile problems

  * Time of flight

  * Horizontal distance travelled by object ( range )

  * Maximum height of the object where velocity is 0

### Resolving Velocity

* Velocity like any other vector can be resolved in horizontal and vertical direction

* If we assume initial velocity as $u$, then when we resolve we get:

* $u_x=u\cos\theta$ & $u_y=u\sin\theta$
