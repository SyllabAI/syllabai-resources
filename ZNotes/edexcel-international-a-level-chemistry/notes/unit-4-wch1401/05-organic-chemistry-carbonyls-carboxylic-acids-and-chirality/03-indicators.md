## Indicators

* $K_{2}Cr_{2}O_{7}$ is reduced and undergoes a color change from orange to green.
* The product is an aldehyde if a silver mirror is formed when Tollen’s Reagent is added.
* If Fehling’s solution/Benedict’s Reagent is warmed and turns blue to red, the product is an aldehyde.
* Lithium aluminum hydride ($LiAlH_{4}$) is a reducing agent in dry ether to reduce carboxylic acids and ketones back to alcohols. $LiAlH_{4}$ is reactive with water, so dry ether is used.
* Nucleophilic addition reactions occur with $CN^{-}$ ions and a carbonyl group, which is used to extend the carbon chain. The product is a hydroxynitrile. KCN is used as the reagent as HCN is a toxic gas and is hard to store.
* The iodoform test is for $CH_{3}CO^{-}$ groups. When iodine solution is added to a sample, then NaOH solution is added, a pale yellow precipitate will form, which is $CHI_{3}$ (triiodomethane)
* 2,4-DNPH (2,4-dinitrophenylhydrazone) can be used to make an orange precipitate with an aldehyde or ketone, which can then be melted to identify the aldehyde and ketone in the precipitate formed, which is done by comparing the melting point to a data booklet value
