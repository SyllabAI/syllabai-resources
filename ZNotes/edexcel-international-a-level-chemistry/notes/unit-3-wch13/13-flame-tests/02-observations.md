## Observations

The table below shows the flame colours for different metals:

| Metal Cation | Flame Colour Produced |
|----|----|
| Lithium | Red |
| Sodium | Yellow/Orange |
| Potassium | Lilac |
| Rubidium | Red/Purple |
| Caesium | Blue/Violet |
| Beryllium | (no colour produced) |
| Magnesium | (no colour produced) |
| Calcium | Brick red |
| Strontium | Crimson red |
| Barium | Pale/Apple green |
| Copper | Blue-green |
| Pb | Blue-white |

* Magnesium has no observable flame colour because it produces light outside the visible spectrum.
