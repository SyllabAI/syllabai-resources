# Chemical Tests

## Tests For Organic Compounds

The table gives the tests and positive results for some organic compounds:

| Compound | Test | Positive Result |
|----|----|----|
| **Alkenes** | 1. Bromine water | Brown to colourless |
|    | 2. Potassium Manganate and Sulfuric acid | Purple to colourless |
| **Alcohols (primary, secondary & tertiary)** | Adding Phosphorous (V) Chloride | Misty fumes (of HCl) are seen |
| **Alcohols (primary & secondary)** | Warmed with potassium dichromate(VI) and Sulfuric acid | Orange to green |
| **Aldehydes** | 1. Fehling’s solution | Blue to brick red (precipitate) |
|    | 2. Benedict’s solution | Blue to brick red |
|    | 3. Tollen’s reagent | Silver mirror |
| **Carboxylic acid** | Add $NaHCO_{3}$ | Bubbles/effervescence (of $CO_{2}$) |
