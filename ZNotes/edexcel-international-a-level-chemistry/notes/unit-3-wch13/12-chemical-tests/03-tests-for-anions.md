## Tests For Anions

Tests and positive results for some common anions:

* $NH_{4}^{-} \rightarrow \text{Add NaOH and warm} \rightarrow \text{The gas evolved will turn red litmus blue} (NH_{3})$

* $SO_{4}^{-} \rightarrow \text{1. Add } BaNO_{3} \text{ acidified with } HNO_{3} \rightarrow \text{White precipitate} \\\ \text{2. Add } BaCl_{2} \text{ acidified with HCl} \rightarrow \text{White precipitate}$

* $CO_{3}^{-} \rightarrow \text{Add HCl} \rightarrow \text{Effervescence}$

* $Cl^{-} \rightarrow \text{1. Silver nitrate solution acidified with dilute } HNO_{3} \rightarrow \text{White precipitate} \\\ \text{2. Dilute or concentrated } NH_{3} \rightarrow \text{ Soluble in both}$

* $Br^{-} \rightarrow \text{1. Silver nitrate solution acidified with dilute } HNO_{3} \rightarrow \text{ Cream precipitate} \\\ \text{2. Concentrated } NH_{3} \rightarrow \text{ Soluble}$

* $I^{-} \rightarrow \text{Silver nitrate solution acidified with dilute } HNO_{3} \rightarrow \text{ Yellow precipitate}$
