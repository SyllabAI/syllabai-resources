# Investigating the Rates of Hydrolysis of Halogenoalkanes

**Method**:

* Three test tubes with ethanol should be set up.

* Halogenoalkanes (iodo, bromo and chloro) should be added in each test tube with proper labels.

* Silver nitrate should then be added to each of the test tubes.

* All three test tubes should then be added to a water bath simultaneously.

* The time for the precipitates to occur should be calculated for each test tube.

* The rate of hydrolysis is inversely proportional to the time taken for the precipitate to occur.
