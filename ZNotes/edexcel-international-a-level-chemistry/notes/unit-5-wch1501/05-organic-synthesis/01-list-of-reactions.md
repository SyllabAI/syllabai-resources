# Organic Synthesis

## List of Reactions

| Homologous Series | Reactions | Identification |
|----|----|----|
| Alkanes | Combustion, free radical substitution (to form halogenoalkanes), electrophilic substitution, cracking (forms short-chain alkanes and alkenes) |    |
| Alkenes | Combustion, addition polymerization, oxidation with acidified MnO4^{-}, electrophilic addition | Decolorizes bromine water in the presence of C=C |
| Halogenoalkanes | nucleophilic substitution, elimination of hydrogen halide using ethanoic hydroxide ions (forms alkenes) | Forms a coloured precipitate - white, cream or yellow - when reacted with AgNO_{3}(aq), which can then be confirmed by adding dilute or concentrated NH_{3}(aq) |
| Alcohols | combustion, substitution, oxidation with acidified K_{2}Cr_{2}O_{7} , dehydration using an acid catalyst, esterification with carboxylic acids or acyl chlorides | Reacts with acidified K_{2}Cr_{2}O_{7} - colour change from orange to green - except with tertiary alcohols |
| Aldehydes | Oxidation with H^{+} , Cr_{2}O_{7} , reduction with LiAlH_{4} , nucleophilic addition with HCN | Reacts with acidified K_{2}Cr_{2}O_{7} - color change from orange to green \n Reacts with 2,4 - DNPH - forms an orange precipitate if there is C=O, that can be used to find the melting point \n Forms a silver mirror when reacted with Tollen’s Reagent \n Forms a red precipitate when reacted with Benedict’s Reagent (colour change from blue to red) |
| Ketones | Reduction using LiAlH_{4} \n nucleophilic addition with HCN | Reacts with 2,4 - DNPH - forms an orange precipitate if there is C=O, that can be used to find the melting point |
| Carboxylic acids | esterification with alcohols, reduction with LiAlH_{4} , Reaction with metals, carbonates and alkalis. \n Reaction with phosphorus(V) chloride | Forms CO_{2} when reacted with a carbonate - effervescence \n pH should be less than 7 |
| Esters | acid/alkali hydrolysis | They smell like fruits. |
| Amines | reaction with acids (forms a salt) |    |
| Nitriles | acid/alkali hydrolysis, reduction |    |
| Arenes | electrophilic substitution reactions |    |
| Phenols | electrophilic substitution and reactions with strong bases |    |
| Acyl Chlorides | hydrolysis, esterification, reaction with ammonia, reaction with primary amines |    |
| Amides | acid/alkali hydrolysis, reduction using LiAlH_{4} |    |
