## Extra Reactions

Chromium Reactions:

* 3$H_{2}O_{2}$ + 2$[Cr(OH)_{6}]^{3-}$ → 2$CrO_{4}^{2-}$ + $2OH^{-}$ + $8H_{2}O$ (green solution → yellow solution)
* $2CrO_{4}^{2-} +2H^{+} → Cr_{2}O_{7}^{2-} +H_2O$ (yellow solution → orange solution)
* $Cr_{2}O_{7}^{2-} + 14H^{+} + 3Zn → 2Cr^{3+} + 7H_{2}O + 3Zn^{2+}$ (orange solution → green solution)
* $2Cr^{3+} + Zn → 2Cr^{2+} + Zn^{2+}$ (green solution → blue solution as $[Cr(H_{2}O)_{6}]^{2+}$ is blue)
* $2Cr(OH)_{3} + 10OH^{-} → 2CrO_{4}^{2-} + 8H_{2}O + 6e^{-}$
* $3H_{2}O_{2} + 6e^{-} → 6OH^{-}$
* These two equations can be combined to form an equation that oxidizes $Cr^{3+} → Cr^{6+}$.Reaction is thermodynamically feasible as $E_{cell}$ for $Cr(OH)_{3}$ is more negative than $H_{2}O_{2}$
* A metal hydroxide that can act as an acid or a base is called an amphoteric hydroxide, e.g. $[Cr(H_{2}O)_{3}(OH)_{3}]$ can react with $H^{+}$ to form $[Cr(H_{2}O)_{6}]^{3+}$

Zinc Reactions:

* 2$H^{+}$ + $[Zn(H_{2}O)_{4}(OH)_{2}]$ → $[Zn(H_{2}O)_{6}]^{2+}$

Cobalt Reactions:

* $[Co(H_{2}O)_{6}]^{2+} + 4Cl^{-} → [CoCl_{4}]^{2-} + 6H_{2}O$

  pink solution → blue solution

 \n $[Fe(H_{2}O)_{6}]^{2+}$ and $[Fe(H_{2}O)_{6}]^{3+}$ are complexes with $Fe^{2+}$ and $Fe^{3+}$ respectively.

Hydrated Transition metal complexes can be deprotonated by adding a base.

* $[Cu(H_{2}O)_{6}]^{2+} + 4Cl^{-} → [CuCl_{4}]^{2-} + 6H_{2}O$
* The coordinate number changed from 6 to 4 - the oxidation number did not change. This reaction is reversible. The colour changes from blue to green to yellow.
* More negative $E_{cell}$ values → good reducing agent/gets oxidized
* More positive $E_{cell}$ values → good oxidizing agent/gets reduced
