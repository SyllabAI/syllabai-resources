# Expressions

* Expressions are commonly used in algebra
* A linear expression is an expression to the power of 1.
* A term is an expression containing at least a single mathematical expression.
* A variable is a letter used to represent an unknown number, while the coefficient is the recognisable number next to it.

E.g. 6*a* = 6 times the value of ‘a’.

* Expressions can contain one or more variables, and one or more coefficients.
* An expression does not contain an ‘=’ symbol.
* We can break down/simplify an expression to make it looks smaller and neater, by bringing the terms together.

E.g. 6*x* + 3*y* + 4*x*+ 7*y*

= 6*x* + 4*x* + 3*y* + 7*y*

= 10*x* + 10*y*,

which can be factored into 10(*x+y*) using the distributive law.
