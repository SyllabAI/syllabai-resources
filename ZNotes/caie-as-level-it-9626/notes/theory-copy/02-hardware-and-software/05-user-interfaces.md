## **User Interfaces**

* **User Interface:** A boundary between the user and the computer system.
* **Command Line Interface (CLI):** This interface allows the user to enter text commands to which the computer system responds.
* **Graphical User Interface (GUI):** The most common and easiest interface type. It has elements that are known as WIMP.
  * **Windows:** Area of the screen for a specific task.
  * **Icons:** Image used to represent a specific software or task.
  * **Menus:** Words on the screen representing a list of options.
  * **Pointers:** Representing movement on the screen.
* **Dialogue Interface:** It uses spoken words to communicate with the computer.
* **Gesture-Based Interface:** It uses the recognition of human motion.
