# Hardware and Software

## Mainframe Computers and Supercomputers

* **Mainframe Computers:**
  * Powerful computer serving several terminals
  * A dumb terminal (which has very little processing power) is connected to the mainframe with organisation.
  * Used for large-scale transaction processing, batch processing, and statistical analysis.
* **Supercomputers:**
  * Large computer with parallel processing to complete highly complex tasks quickly.
  * It runs very few computer programs but focuses on executing instructions as quickly as possible for one purpose.
  * They run at maximum capacity so that their full power is used to process data and solve a problem.
  * They are used in quantum mechanics, where billions of calculations must be made.
  * They are used in weather forecasting and climate research.
* **Measurement of performance:**
  * **MIPS (Millions of instructions per second):**
    * It is not considered as a very accurate measure.
  * **FLOPS (floating point operations per second) or MFLOPS (Mega FLOPS):**
    * Used to compare the speed of supercomputers.
    * Some processors can carry out a single floating point operation, but others may require several floating points for the same result.

| Advantages | Disadvantages |
|----|----|
| They are designed to be reliable, available and serviceable (RAS). | They are very expensive and can only be afforded by organisations. |
| They are scalable | A lot of space is required to install the system |
| They are designed to last for at least ten years. | Temperature must be regulated, so they are usually built in cold places. |
| They can store and process extremely large amounts of data. | Specialist staff are required for maintenance. |
| Hardware failures are notified immediately so that replacements can be made very quickly. | They need massive external storage devices. |
| More than one operating system can be used to improve the overall performance. | It isn't easy to understand as the interface is command-driven. |
