## Components of an Expert System

* **User interface:** It is the way in which a user interacts with the system
* **Knowledge base:** A database of related information about a particular subject.
  * Rules base: Part of the knowledge base that contains rules to be analysed by the expert system.
* **Knowledge base editor:** A component used to amend or update the knowledge base.
* **Inference engine:** A part of the expert system that makes judgments and reasoning.
  * Backward Chaining: A goal is broken down into sub-goals, allowing the system to work backwards from the goal.
  * Forward Chaining: A system that moves forward from rule to rule until it reaches possible outcomes.
* **Explanation system:** A component that explains an outcome.
* **Method of output:** The method through which the user can view the outcomes.
