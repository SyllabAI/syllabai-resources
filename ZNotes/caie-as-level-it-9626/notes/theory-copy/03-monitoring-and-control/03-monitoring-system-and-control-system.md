## Monitoring System and Control System

* **Monitoring System:** A system that observes and often records activities in process.
  * Example: Weather Stations
* **Control System:** A system that manages or regulates a process by physically changing aspects depending on the collected data.
* **Microprocessor:** Integrated circuit that is used in both monitoring and control systems.
  * Advantages and Disadvantages:

| Advantages | Disadvantages |
|----|----|
| Programmed to execute several different tasks. | A limit on the size of the data they can handle. |
| It is small so that it can be embedded into other technologies. | They are small and can overheat if too much demand is placed on them. |
| Fast at moving data between other memory locations. |    |

* **Actuator:** Type of motor used to move or operate another mechanism or device.
  * Advantages and Disadvantages:

| Advantages | Disadvantages |
|----|----|
| Hydraulic and electric actuators are fairly quiet. | Pneumatic actuators can be pretty noisy. |
| The cost of pneumatic actuators is relatively low. | Hydraulic and electric actuators are expensive. |
| Most actuators have moderate to high-speed abilities to perform an action. | Fluid leaks can be a problem in hydraulic actuators. |

* **Real-World Examples:**
  * Growing crops in a greenhouse.
  * Protection against intruders.
