## Encryption

* **Encryption:** The scrambling of data so it cannot be understood without a decryption key if intercepted.
* **Types of Encryption:**
  * **Caesar Cipher:** A special type of algorithm that defines a set of rules to follow to encrypt.
  * **Symmetric Encryption:** This encryption requires both the sender and recipient to possess a key known as a private key used for both encryption and decryption.
  * **Asymmetric Encryption:** This encryption has a public key for the sender to encrypt and a private key for the recipient to decrypt the data.

### Applications of Encryption

* **Hard Disk:** Every bit of stored data is encrypted and requires a key to decrypt it.
* **HTTPS:** It uses SSL ( Secure Socket Layer ) or TLS ( Transport Layer Security ) to encrypt web pages for security.
* **Email Encryption:** Email is encrypted using the asymmetric encryption method.
