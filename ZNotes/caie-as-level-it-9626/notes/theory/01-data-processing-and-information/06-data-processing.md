## Data Processing

* **Data processing:** Any activity that manipulates or carries out operations on data.
* **Batch processing:** Sets of data are processed all at once without user interaction.
  * **Master file:** A table in a database containing information about one set of things.
  * **Transaction file:** Data that is used to update a master file.
  * Advantages and Disadvantages of Batch Processing:

| Advantages | Disadvantages |
|----|----|
| A single, automated process that requires very little human interaction. | There is a delay in the process as the time has been scheduled. |
| It can be scheduled to occur at a fixed time. | Only data of the same type can be processed. |
| There will be no errors that human operators may produce. | Errors cannot be corrected until the end of processing. |
| There are fewer repetitive tasks for human operators. |    |

* **Online processing:** Data is input by the user, and the feedback is given in the form of outputs. Examples:
  * Electronic Electric Funds
  * Online Stores
  * Automatic stock control
  * Electronic data exchange
* **Real-time processing:** Data is processed as soon as it has been input so the outputs can be generated immediately. Examples:
  * Air Traffic Control
  * Computer games
  * Air conditioning system
  * Central heating system
