## System Software

* **System Software:** Any program designed to maintain or operate the computer system is known as system software.
* **Operating Systems:** The operating system manages the hardware within a computer system. It carries the tasks below:
  * Allocating memory to software
  * Sending data and instructions to output devices
  * Responding to input devices, such as when a key is pressed
  * Opening and closing files on storage devices
  * Giving each running task a fair share of processor time
  * Sending error messages or status messages to applications or users
  * Dealing with user log-on and security.
* **Device Drivers:** The device driver is used to enable communication between the computer system and specific hardware models.
* **Translators:** It translate a high-level language program into machine code that the computer can understand. There are two types of translators:
  * Compilers
  * Interpreters

| Compilers | Interpreters |
|----|----|
| Before executing, it simultaneously translates the source code into object code. | Translates source code into object code one line at a time. |
| The compiled object code will only work for the operating system it was compiled for. | The object code can be used for multiple operating systems. |
| Object code is ready to be executed quickly. | It takes extra time for execution as the object code needs to be generated. |
| It takes a long time to compile. | Only the required code needs to be interpreted. |
| Errors are reported only after compilation is done. | Errors are reported during the interpretation. |

* Linkers: A linker is used to combine the object files together to form one executable file.
