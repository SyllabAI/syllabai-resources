# eSecurity

## Personal Data

* **Personal Data:** Any data that relates to you or your identity.
  * Name
  * Address
  * Telephone number
* **Ways to keep your personal data safe:**
  * Have strong passwords
  * Encrypt any personal data
  * Have a firewall present
  * Have an antivirus package
  * Use a nickname when using the internet
* These are the ways personal data is collected:
  * **Phishing:** When a user receives a legitimate-looking email with a link so the personal data can be inputted.
  * **Smishing:** Smishing is the same as phishing, but an SMS is sent instead of email.
  * **Vishing:** Vishing is the same a phishing but using the voice of a human or automated system.
  * **Pharming:** Pharming is when an unauthorised user installs malicious code into a server that redirects the user to a legitimate-looking website.
