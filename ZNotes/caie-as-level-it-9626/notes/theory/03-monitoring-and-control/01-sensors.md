# Monitoring and Control

## Sensors

* **Sensor:** An input device that records data about the surrounding physical environment. The advantages of the sensors are as follows:
  * Data can be repeatedly collected.
  * Data can be collected from harmful and dangerous environments.
  * Data is likely to be more accurate.
* **Different types of sensors:**
  * Light sensor
  * Temperature sensor
  * Pressure sensor
  * Humidity sensor
  * Infrared sensor
