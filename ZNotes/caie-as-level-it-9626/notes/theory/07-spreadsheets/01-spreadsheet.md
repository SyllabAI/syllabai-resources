# Spreadsheets

* Spreadsheets are used to manipulate numbers, perform calculations,
  present summary data and make predictions.
* **Cell:** a rectangle within a spreadsheet where data can be
  positioned.
* **Range:** a set of one or more cells.
* **Worksheet:** a set of rows and columns.
* A workbook may contain a number of worksheets.
* **Formula:** a mathematical calculation using +, -, x or /
* **Orientation:** the direction of text, for example, horizontal or
  vertical.
* **Alignment:** positioning text so that it is in line, for example, on the left, right or centre.
* **Function:** a ready-made formula representing a complex
  calculation. Example =PRODUCT(D10:E10)
* **Validation:** the process of checking data matches acceptable
  rules.
* The four different types of test data include:
  * **Valid (standard/acceptable data):** Data that should pass the validation rule.
  * **Invalid (erroneous/unacceptable data):** Data that should
    generate an error message.
  * **Extreme valid:** Data that will only pass the validation rule because it is on the boundary of acceptable data.
  * **Extreme invalid:** Data that will only generate an error
    message because it is on the boundary of unacceptable data.
* A model is a computer representation of a real-world process. A model is created through mathematical analysis of the real-world process. Modelling software is used to create a model. Spreadsheets can be used to create computerised models, but custom-written solutions are also used to model specific processes.
* Modelling software usually features:
  * the ability to change variables within the software
  * asking what-if questions to see what the result of changing
    variables might be
  * formulae and functions to carry out the mathematical
    calculations that form the basis of the model.
  * Automatic recalculation of formulae and functions
  * Rules that define how the model behaves
  * Layers of abstraction so that different model parts can be viewed and analysed separately.
* **Simulation:** using a computer to predict how a real-life system might behave.
  * As with modelling, simulations can be used for training,
    forecasting and construction.
* Advantages include:
  * Removes the need for creating expensive prototypes
  * Changes to the model can be made rapidly, and the effects can be seen just as quickly
  * Alternative models and designs can be used simultaneously much
    easier to see how they react differently
  * Unusual situations can be tested without the need to wait for
    them in real life.
  * No loss, wear and tear or damage to equipment when tested or
    experimented with
  * Dangerous situations can be simulated safely without endangerment
  * Effects of extended periods can be tested by speeding up the simulation
* Disadvantages:
  * A simulation is only as good as the model it is based upon
  * Simulation software and equipment can be very expensive
  * Requires training to use simulation software and equipment
  * Complex models take a long time to develop, depending on how realistic the simulation is
  * It is near-impossible to simulate a perfect representation of a
    real-world process.
