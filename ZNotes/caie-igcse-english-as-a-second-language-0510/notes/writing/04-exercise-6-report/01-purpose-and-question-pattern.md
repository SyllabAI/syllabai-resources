# Report Writing

## Purpose and Question Pattern

* Mark distribution; content - 6, language - 9

* Word count - 120-160 words (can extend to 180 if it fits the page and if it is ABSOLUTELY necessary)

* For language part, refer the language module

### Purpose

* To inform reader of an event

* To give your opinions on that event

### Question pattern

*Your class recently went to a career day to get information about different types of jobs. Now, your teacher wants you to write a report about the careers day.*

*In your repot, **say what you found useful about careers day** and **how you think the event could be improved for next year**.*
