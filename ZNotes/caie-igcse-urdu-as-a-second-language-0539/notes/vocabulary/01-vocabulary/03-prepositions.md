## Prepositions (حروف جار)

### **For time:**

| In | **میں** |
|----|---:|
| On | **پر or کو** |
| Since, By | **سے** |
| During | **دوران** |
| With | **کےساتھ** |
| Within | **کے اندر** |
| Prior | **سے پہلے/ پہلےسے** |

### **For Place/Location:**

| In | **میں** |
|----|---:|
| On/At | **پر** |
| Above/Over | **اوپر/کے اوپر** |
| Under/Beneath | **کےنیچے/نیچے** |
| With | **کے ساتھ** |
| Between | **کےدرمیان** |
