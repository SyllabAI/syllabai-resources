## ASCII Code 

  - Uses 1 byte to store a character

  - 7 bits available to store data and 8<sup>th</sup> bit is a check
    digit

  - 2<sup>7</sup> = 128, therefore 128 different values

  - ASCII values can take many forms: numbers, letters (capitals and
    lower case are separate), punctuation, non-printing commands (enter,
    escape, F1)
