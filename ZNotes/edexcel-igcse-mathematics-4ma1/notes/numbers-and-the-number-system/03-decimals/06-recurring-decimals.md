## Recurring Decimals

*Recurring Decimals is part of higher tier mathematics course. You do not have to know this if you are taking the foundation tier mathematics course.*

* Recurring decimals are decimals in which the digits following the decimal point repeat infinitely.

  * $5.666666…$ is recurring because the $6$ after the decimal point repeats without end.

  * $27.89898989…$ is recurring because the digits $8$ and $9$ after the decimal point repeat without end.

* The repeating digits in a recurring decimal can be written with a single dot over the first and last digit in the recurring pattern.

  * $3.3333… \rightarrow 3.\dot{3}$

  * $98.9888.. \rightarrow 98.9\dot{8}$

  * $24.8787… \rightarrow 24.\dot{8}\dot{7}$

  * $45.6345345… \rightarrow 45.6\dot{3}4\dot{5}$

### Converting Recurring Decimals to Fractions

* To convert a recurring decimal to a fraction, let $x =$ the recurring decimal.

  $x = 3.333…$

* Subtract your value from $10x$ to get rid of the recurring part.

  $10x - x = 33.333… - 3.333…$

  $9x = 30$

* Solve for $x$ and simplify.

  $x = \frac{30}{9} = \frac{10}{3}$

  Therefore $3.\dot{3} = \frac{10}{3}$

### Converting Recurring Decimals with Multiple Recurring Digits

* First, let $x =$ the recurring number.

  $x = 36.4545….$

* We need to subtract the recurring digits, so multiply $x$ by $10$ until the fractional part is the same as $x$.

  $10x = 364.5454…$

  $100x = 3645.4545…$

* Subtract $x$ to get rid of the recurring part, then solve for $x$.

  $100x - x = 3645.\dot{4}\dot{5} - 36.\dot{4}\dot{5}$

  $99x = 3609$

  $x = \frac{3609}{99} = \frac{401}{11}$

  Therefore $36.\dot{4}\dot{5} = \frac{401}{11}$

### Converting Recurring Decimals with Non-recurring Digits

* If a number or numbers after the decimal point are not recurring, first let $x =$ the recurring number.

  $x = 3.69898…$

* Multiply $x$ by $10$ until the fractional part only contains the recurring digits.

  $10x = 36.9898…$

* Multiply the new $x$ until the fractional part only contains the recurring digits again.

  $100x = 369.8989…$

* The fractional part must be the same so we can get rid of it with subtraction.

  $1000x = 3698.9898…$

* Subtract the first calculated multiple of $x$ from this value.

  $1000x - 10x = 3698.\dot{9}\dot{8} - 36.\dot{9}\dot{8}$

  $990x = 3662$

* Solve for $x$.

  $x = \frac{3662}{990} = \frac{1831}{495}$

  Therefore $3.6\dot{9}\dot{8} = \frac{1831}{495}$
