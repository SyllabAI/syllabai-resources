## Place Value

* Place value tells us the value of a digit, based off its position within a number.

* Moving left increases the digit’s value by $10$.

* Moving right decreases the digit’s value by $10$.

For the number 3742.5:

* 3 represents 3 *thousands* $(3 \times 1000 = 3000)$
* 7 represents 7 *hundreds* $(7 \times 100 = 700)$
* 4 represents 4 *tens* $(4 \times 10 = 40)$
* 2 represents 2 *units* $(2 \times 1 = 2)$
* 5 represents 5 *tenths* $(5 \times 0.1 = 0.5)$
