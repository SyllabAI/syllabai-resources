## Order of Operations

When calculating with multiple operations, you must perform each operation in a specific order to attain the correct result.

The acronym BIDMAS can help you remember this order:

* **B** - brackets $() / []$ ; this is the highest priority.

  * solve the operations inside the brackets first.

* **I** - indices $x^2$, $\sqrt{x}$

  * solve exponents, powers and roots.

* **D** - division $\div$

* **M** - multiplication $\times$

  * both division and multiplication have the same level of priority, so solve these operations from left to right.

* **A** - addition $+$

* **S** - subtraction $-$

  * both addition and subtraction have the same level of priority, so solve these operations from left to right.

### Worked Examples

* $5 + (2 \times 3) = 5 + 6 = 11$

* $3 \times 4^2 = 3 \times 16 = 48$

* $5 \times 4 \div 2 = 20 \div 2 = 10$

  * you would get the same result if you performed division first.

* $13 + 25 \times 4 = 13 + 100 = 113$

* $45 - 15 \div 3 = 45 - 5 = 40$

* $24 + 12 - 6 = 36 - 6 = 30$

  * you would get the same result if you performed subtraction first.
