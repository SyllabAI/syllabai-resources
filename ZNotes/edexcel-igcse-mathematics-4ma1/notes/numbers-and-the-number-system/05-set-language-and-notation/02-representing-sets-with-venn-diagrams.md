## Representing Sets with Venn Diagrams

* The members shared between the sets go in the middle region.

* The members in the universal set that are not present in either set go outside.

* The remaining members go into their respective regions.

  $\xi = \{1, 2, 3, 4, 5, 6, 7, 11, 12, 13\}$

  $A = \{1, 2, 3, 4, 5\}$

  $B = \{4, 5, 6, 7\}$

  ![](https://images.znotes.org/allimages/7c4b1166c473cf935db3d51f.webp =600x400)

* $A \cap B$ is represented by the region shared between the two Venn Diagrams $A$ and $B$.

  *The region that contains **only** the members present in **both** set $A$ and set $B$.*

  ![](https://images.znotes.org/allimages/02cfef384f99efcc844069ba.webp =600x400)

* $A \cup B$ is represented by the whole region of the two sets on the Venn Diagram.

  *The region that contains **only** the members present in **both** set $A$ and set $B$.*

  ![](https://images.znotes.org/allimages/5427a60fad4d67299e9af8f0.webp =600x400)

* $A’$ is represented by the whole region apart from $A$.

  *The region that contains **no** members present in set $A$.*

  ![](https://images.znotes.org/allimages/68d86a0615236ef021208482.webp =600x400)

* $(A \cup B)’$ is represented by the whole region apart from $A$ and $B$.

  *The region that contains **no** members present in **both** set $A$ and set $B$.*

  ![](https://images.znotes.org/allimages/d04979ebc6e883155f4620e4.webp =600x400)
