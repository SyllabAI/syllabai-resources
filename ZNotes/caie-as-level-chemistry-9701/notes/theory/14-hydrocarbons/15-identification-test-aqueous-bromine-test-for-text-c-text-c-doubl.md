## Identification Test: Aqueous Bromine Test for $\text{C}=\text{C}$ Double Bonds

* **Test Description:** Aqueous bromine ($\text{Br}_2\text{(aq)}$) is added to the test compound at room temperature in the dark.

* **Observation & Conclusion:**

  * **With Alkenes (Unsaturated / $\text{C}=\text{C}$ present):** Rapidly undergoes electrophilic addition, causing the orange/brown bromine solution to **decolourize** (turn colourless).

  * **With Alkanes (Saturated / no $\text{C}=\text{C}$):** No rapid reaction occurs in the dark, so the orange/brown colour **remains unchanged**.
