# Grammar

## Basic Sentence Structure

* **Subject + Verb**
  * E.g. “我吃。” (I eat), “你去。” (You go)
* **Subject + Verb + Object**
  * E.g. “我去看电影。” (I go watch the movie), “他去公园。” (He goes to the park)
* **Subject + Time + Verb + Object**
  * E.g. “我今天买了食物” (I bought food today), “你昨天去哪里？” (Where did you
    go yesterday?)
* **Subject + (Time) + Verb + Object + ma?**
  * This makes the sentence a question.
  * E.g. “你要吃饭吗？” (Do you want to eat?), “你喜欢吗” (Do you like it?)
* **Subject + Time + Verb**
  * E.g. “我今天去” (I go today), “他昨天玩” (He played yesterday)
* **Subject + Time + Place + Verb**
  * E.g. “我今天要在学校踢足球” (Today, I want to play football at school)
