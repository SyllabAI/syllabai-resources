# Individual Report

## General Requirements

* The Individual Report must be from one of the topics listed in the [topics list](https://znotes.org/caie/igcse/global-perspective-0457/examination-summary/topics-list/)
* The title of the report is the student's research question
* The report must be **1500–2000 words** (does not include the bibliography)
* **Must consist of the following in the report:**
  * Introduction
  * Causes and consequences
  * Different perspectives
  * Courses of action
  * Source evaluation
  * Personal reflection
  * Bibliography
* Present each of these sections in different paragraphs/use sub-headings
