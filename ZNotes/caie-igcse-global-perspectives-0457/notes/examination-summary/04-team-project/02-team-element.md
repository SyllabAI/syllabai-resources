## Team Element

### **Explanation of Research and Planning**

* The report must be 300–400 words
* This can be presented in a table similar to this:

| **Topic** |    |
|----|----|
| **Issue** |    |
| **Roles** | Identify roles and responsibilities of team members |
| **Plan** | State how the action will be evidenced                                                                    -  Explain how its success will be measured |
| **Action** | Summary of the action the team will take to address the issue |
| **Changes** (after the project is completed) | Identify and explain any changes that had to be made |

### **Evidence of Action**

* To show what the team has done:
  * Can be posters, leaflets, web pages, videos (10 minutes maximum), presentations, photographs,…
* Should not include evidence of research or meetings to discuss the project
* To gain full marks:
  * The action must be **very likely to make a positive difference**
  * The action was **carried out very well**

### **Collaboration**

* Marks are awarded by the teacher based on observation throughout the project
