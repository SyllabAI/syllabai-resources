## Virtual Machines

* **Virtual machine:**
  * Process interacts with the software interface provided by the OS. This provides an exact copy of the hardware.
  * OS kernel handles interaction with actual host hardware

| **Pros** | **Cons** |
|----|----|
| Allows more than one OS to run on a system | Performance drop from native OS |
| Allows multiple copies of the same OS | The time and effort needed for implementation is high |

**Examples and Usage:**

* Used by companies wishing to use the legacy software on newer hardware and server consolidation companies
* Virtualising machines allows developers to test applications on many systems without making expensive hardware purchases.
