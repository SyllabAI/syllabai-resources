## Big O Notation

Big O Notation is used to help compare algorithms that achieve the same end result based on time complexity and space complexity.

**Time complexity:** The increase in time taken as the size of the array increases

**Space complexity:** The increase in memory used as the size of the array increases.


|Notation|Example|
|:---|:---|
|$O(1)$|A function that gets the first item from an array|
|$O(n)$|Linear search|
|$O(log\_2n)$|Binary Search|
|$O(n^2)$|Bubble/Insertion Sort|
