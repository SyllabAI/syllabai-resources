## Question 3

**(a)**

* Portable Document Format (PDF).

* The document is converted into an image format.

* Can be read by most computers, applications and apps.

* Hard to edit, therefore protects the file from change.

**(b)**

* Rich Text Format (RTF).

* Saves some of the formatting within the text.

* Readable by most text editors.

**(c)**

* Cascading Style Sheet (CSS).

* Attached to one or more web pages.

* Defines how web pages look (presentation layer).

* Written in HTML.
