## Question 2

**(a)**

(i) Spreadsheet

* A spreadsheet is a computer program used to organise, calculate, and analyse data.

* Data is arranged in rows and columns, forming cells that can contain numbers, text, or formulas.

* Spreadsheets are commonly used for calculations, budgeting, data analysis, and graphs.

(ii) Database

* A database is a computer program that stores a collection of structured and organised data.

* Data is stored in tables, made up of records (rows) and fields (columns).

* Databases allow data to be stored, searched, sorted, and updated efficiently.

(iii)Applet

* An applet is a small computer program that performs a specific task within a larger application.

* It is usually designed to carry out one simple function, such as displaying information or performing a calculation.

**(b)**

* Operating systems – manage hardware and software resources

* Device drivers – allow hardware to communicate with the computer

* Utilities – perform maintenance tasks (e.g. backup, antivirus)

* Compilers / Linkers – translate and prepare programs for execution
