## Question 13

**(a)**

* A function is a built-in command in spreadsheet software (e.g., SUM, AVERAGE). It performs a specific calculation automatically.

* A formula is created by the user using “=” and cell references (e.g., =A1\+B1). It tells the spreadsheet exactly what calculation to do.

**(b)**

 State an example of:

(i) A function: SUM(A1:A5) or AVERAGE(B1:B5)

(ii) A formula: =A1\+B1 or =(A1\*B1)/100

**(c)**

(i) Relative cell referencing.

* Means that when a formula is copied or filled into another cell, the cell references change automatically depending on their position.
  Example: copying =A1\+B1 down one row becomes =A2\+B2.

(ii)

* When formulas are copied, the cell references may shift incorrectly, leading to wrong calculations if not checked.
