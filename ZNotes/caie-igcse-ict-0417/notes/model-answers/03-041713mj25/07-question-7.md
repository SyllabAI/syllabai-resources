## Question 7

**(a)** 

 Private cloud.

* A service controlled by one organisation.

* Restricted access, only for authorised users.

* Usually free for users inside the organisation.

**(b)**

Stored:

* Users upload data to remote servers.

* Files are backed up automatically and updated.

Managed:

* Administrators control who can access or edit data.

* Files are synced so everyone sees the latest version.

* Changes are tracked for version control.
