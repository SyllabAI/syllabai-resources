## The Main Components of Computer Systems

### Central Processing Unit (CPU)

- The component of the computer that understands and executes hardware and software operations. Nowadays, it’s also known as a microprocessor. It is a single integrated circuit at the core of most PCs and is also present in many household gadgets and equipment where some control or monitoring is required.
- It consists of a control unit (CU) that manages the input and output devices, an arithmetic and logic unit (ALU) that performs computations and makes logical judgments, and tiny memory regions known as registers.
- It processes the input and produces the outcome of the processing in the form of output.

### Internal Memory

1. Random access memory (RAM): Temporary memory storage, lost after power is shut down, performs read and write functions, is used to store data that are currently in use, and can be increased in size to improve operational speed.
2. Read-only memory (ROM): Permanent memory storage, non-volatile, can only be read from, used to store computer’s configuration data, such as BIOS.

Note: The BIOS (basic input/output system) stores the date, time and system configuration on a non-volatile chip called a CMOS (complementary metal oxide semiconductor) – this is usually battery powered.

**Differentiating between Internal memories:**

1. RAM is a temporary memory device, whereas ROM is a permanent one.
2. RAM is volatile, ROM is non-volatile.
3. RAM can be written to and read from, but ROM can only be read from.
4. RAM is used to store data, files, programs, and parts of OS that are currently in use. However, ROM is used in storing start-up data,

### Input & Output Devices


|Input devices|Output devices|
|:---|:---|
|An input device is any hardware that enables data entry.|An output shows the result or solution of the input after it has been processed.|
|An input device can only send data.|An output device can only receive data.|
|Input devices are necessary for a computer to receive commands from the user for processing to be permitted.|Output devices are needed in order to display the outcome of the processing that took place to the user.|
|Input devices are complex as they must ensure proper communication between the computer and the user.|Output devices are simpler as they only need to display the final result.|

- Input devices are pieces of hardware that allow users to enter data into computers.
  - Keyboard: Uses a layout of individual keys sitting above electrical switches. When a key is pressed, it completes a circuit and sends a specific digital character code to the computer. It is ideal for entering text data but requires manual typing skills and can cause repetitive strain injury (RSI) over long periods.

  - Mouse: A hand-held pointing device that uses an optical sensor (an LED or laser) to track movement across a flat surface. It translates this physical movement into a 2D coordinate on the screen pointer. It features micro-switches for clicking and making selections, offering an intuitive way to navigate a GUI.
- An output device displays the computer's output in a human-readable format. For example, words on a printer or moving graphics on a monitor.
  - Monitor: A visual display screen (commonly LCD or LED) made up of a matrix of millions of tiny pixels. Each pixel glows with varying intensities of red, green, and blue to display sharp, real-time visual text, images, and video interfaces generated by the computer.

  - Inkjet Printer: An output device that creates physical documents by spraying tiny, precise droplets of liquid ink through miniature nozzles onto paper. They are slower but offer exceptional color blending, making them ideal for high-quality photos.

  - Laser Printer: An output device that uses a laser beam to draw an electrostatic image onto a drum. The drum attracts dry, powdered ink (toner), which is transferred to the paper and melted permanently into the fibers using a hot fuser unit. They are highly complex but extremely fast, making them ideal for high-volume text printing.

### Backing and Secondary Storage

- Required to store significant amounts of data permanently.

- Most commonly in the form of Hard disk drives and Solid-state drives.

  - Hard Disk Drive (HDD)**:**

    * Capacity: Extremely large, commonly ranging from 1TB to 10TB\+ at a very low cost per gigabyte.

    * Speed: Moderate read/write speeds. Because it relies on a physical actuator arm moving across spinning magnetic platters, it takes time to find data, and performance drops if files become fragmented.

    * Portability: Generally fixed internally due to its heavy weight and large size, though external versions exist inside protective casings.

    * Durability: Highly fragile; because it contains delicate moving parts, a physical drop or shock while operating can cause a "head crash," scratching the platter and permanently destroying data.

  * Solid-State Drive (SSD):

    * Capacity: Large capacities are widely available (typically 500GB to 4TB), though they remain more expensive per gigabyte than HDDs.

    * Speed: Exceptionally fast read/write speeds because it accesses data electronically with zero moving parts, resulting in fast boot times.

    * Portability: Highly portable; the flash memory chips are tiny, thin, and lightweight, making them perfect for compact laptops and pocket-sized external drives.

    * Durability: Highly robust and durable; because there are no moving parts, it can survive physical vibrations, bumps, and accidental drops without losing data.

**Differentiating between internal memory and backing storage:**

1. RAM contents are lost when power is lost, ROM is read-only, and backing storage is permanent even without power.
2. RAM and ROM are much smaller than backing storage.
3. RAM and ROM are significantly faster in accessing data than backing storage.
4. Backing storage is much cheaper than internal memory.
5. Internal memories are fixed, and backing storage can be fixed or portable.
6. Internal memories can be directly read by the CPU, while backing storage needs to be moved into the RAM before being read by the CPU.
