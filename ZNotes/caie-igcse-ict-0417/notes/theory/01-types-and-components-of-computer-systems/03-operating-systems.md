## Operating Systems

* Controls operation of input, output & backing storage
* Supervises loading, running & storage of application programs.
* Deals with errors in application programs.
* Maintains security of the whole computer system
* Maintains a computer log.

Operating systems offer various types of user interfaces, for example:

* **Command Line Interface (CLI):** Requires the user to type explicit text strings into a prompt to execute commands. It provides deep, unrestricted access to the computer's underlying configuration settings. However, it has very low user-friendliness; users must memorize complex syntax rules, and a single typo or spelling mistake will cause the command to fail, making it highly error-prone and time-consuming.

* **Graphical User Interface (GUI):** Built on the WIMP concept (Windows, Icons, Menus, Pointing device). It is highly user-friendly and intuitive because applications are represented visually by icons, removing the need to memorize commands. However, it requires a more complex operating system and uses up significantly more computer memory (RAM) and processing power just to render the graphical visuals. It also restricts the user to the specific options provided on the screen.

* **Dialogue-Based User Interface:** Uses speech recognition software to convert the human voice into computer commands. It is highly accessible and hands-free, which is useful for situations like driving or assisting users with physical disabilities. It can also act as a biometric security feature. However, it can be complex to set up, requires users to know specific verbal triggers, and remains unreliable because background noise, accents, or changes in vocal tone can cause commands to be misread.

* **Gesture-Based User Interface:** Relies on tracking human body movements (hands, fingers, head) using cameras or infrared sensors, completely replacing mechanical input devices. It is a completely natural interface requiring no physical contact or training. However, it is prone to errors as accidental or unintentional movements can be picked up as active commands. It also has a limited operational range, only working when the user is close to the camera/sensor (typically under 1.5 meters).
