## Data entry form

**Creating forms**

* When creating forms, it is important to ensure that all required fields are included and correctly label , with appropriate input space, font style/size, alignment and spacing.

* Use the correct controls for the type of data: radio buttons for one choice, check boxes for multiple choices, and drop-down menus for predefined options.

* Ensure the form is clear, well-spaced and functional, with appropriate white space, logical grouping, and controls that work correctly.

### Fields

* Include **all specified/required fields**.

* Use **clear, meaningful field labels**.

* Ensure labels correspond exactly to the required field names/information.

* Arrange fields in a **logical order**.

* Provide enough space for the expected data in each field.

* Make important/key fields easy to identify, such as by using bold headings and appropriate visual guide.

### Font style and size

* Use a clear, readable font. Keep the font style consistent throughout the form.

* Make field labels sufficiently large and readable.

* Use bold or other formatting to distinguish important headings/key fields where appropriate.

### Spacing between fields

* Use clear and consistent spacing between fields to avoid looking crowded.

* There should be enough space to distinguish one field from another.

* Related fields can be grouped together.

### Character spacing / input-field length

It is important to leave enough space for entering data in each field. For example:

* **First name:** relatively short input area.

* **Surname:** short/medium input area.

* **Telephone number:** enough space for the expected digits.

* **Address:** much larger area because it may contain many characters.

### White space

White space is intentional empty space used to make a form easier to read.

They are used to 

* avoid overcrowding the form.

* leave appropriate space around groups of fields.

* leave space between labels and input areas.

* separate different sections.

Excessive empty space should be avoided so that the form does not seem unnecessarily large.

### Radio buttons

Radio buttons are used when the user should select **ONE option from a group**.

* The options should be clearly labelled and aligned consistently.

* The radio buttons should be grouped together.

* Selecting one option normally deselects the other options in the same group.

* The selected value should be capable of being stored in the appropriate database field when required.

### Check boxes

Check boxes are used where the user can select zero, one or multiple options.

* Each option is independently selectable.

### Drop-down menus

Drop-down menus are useful when:

* The user needs to select an option from a predefined list of options.

* There are too many options to display conveniently as radio buttons.

### Layout and organisation

The form should have:

* A logical overall layout.

* Related fields grouped together.

* Consistent alignment throughout.

* Labels and their input controls clearly associated.

### Functionality

It is important to ensure the form functions without issues. This can be done by checking if 

* Controls work properly.

* Radio-button selections can be stored correctly.

* The appropriate database field/data type is used.

* The form should display the correct database record(s).

* Data entered through the form is saved appropriately.

**Steps to create a form**

Before creating a data form, open the required table/query from the appropriate database and identify the fields that need to appear on the data form. Ensure the fields are in the right order.

 1. **Open the database** containing the required tables.

 2. **Select the table/query** that contains the fields required for the form.

 3. Go to **Create → Form Wizard** and select the required fields to appear on the form. Click the **`>`** button to add individual fields, or **`>>`** to add all fields and click next.

 4. Choose an appropriate form layout and name.

 5. Open the form in **Layout View/Design View** to modify its appearance.

 6. **Arrange and resize fields** so that they are clearly positioned and fit the data.

 7. Switch to **Layout View** or **Design View** by going to the **Home tab**, clicking **View**, and selecting either view. Then add or modify **labels** for the fields.

 8. Adjust **font style, size and formatting**, and **spacing and alignment** between fields.

 9. Add appropriate **white space** so the form is not overcrowded.

10. Include suitable **controls**, such as:

* Radio buttons
