# Document Production

## Word Processing (MS Word)

### Format text

**Fonts:**

* Serif – with flicks, e.g. **Cambria, Times New Roman**

* Sans-serif – without flicks, e.g. **Calibri**

**Set line spacing:**

Go to Home tab and choose Line and Paragraph Spacing

* Spacing options: single, 1.5 times, double, multiple, spacing before and after paragraphs

**Setting tabulation:**

Go to Home tab and choose paragraph settings

* Left, right, centred

* Decimal tabs: use to align a column of numbers vertically by their decimal points

* Indented paragraphs: use to set a blank space at the beginning of a new paragraph/thought

* Hanging paragraphs: text block where the first line stays at the left margin, and the rest of the lines are indented → mainly use for citations

**Text enhancement:**

* Enhancement options: bold, underline, italic, superscript and subscript, changes in case

**Creating lists:**

* Bulleted

* Numbered

### Organise page layout

**Pagination:** divide the information into chunks to organise page layout

This can be done by set breaks:

* One part of the document is 1 column, and the rest is in two columns. a → section break.

* When you want to move text to the next column, a → column break.

* To force all further text onto the next page → page break

* A widow= single line that appears on the next page or column, separated from the rest of the paragraph

* An orphan = a single line that appears on the previous page or column, separated from the rest of the paragraph.

* To add page numbers in the header/footer → Place your cursor where you want to put the number → Go to insert tab → Quick parts → Select Numbering category→ Select Page in field names → Click Ok

**Page size:**

Go to Layout tab, choose Size

* Default: A4 (210 x 297)

**Page orientation:** Decide whether the page is displayed and printed horizontally or vertically

Go to Layout tab, choose Orientation

* Portrait: (default) vertical layout where the page is taller than it is wide

* Landscape: horizontal layout where the page is wider than it is tall

**Page margins:** The space between the page edges and the text

Go to Layout tab, choose Margins

* Frequently set to 2cm or 2.5cm unless instructed otherwise

* All four sides matter

* **Gutter margins:** extra space in the bound edge so no text is obscured (used primarily for printing)

Managing columns:

* Select specific paragraphs/subheading that need column formatting → Layout tab → click on Columns → select the number of columns, enter specific numbers for Width and Spacing

* Check Equal column width option if specified/needed.

**Manage fields:**

* Add the file size/name (including file path) → click on Quick Parts in the Insert tab → click on Field → select File Size or File name. For file path →, check the box to include file path. For file size →, choose whether Kilobytes or Megabytes.

* Include date → click on Date & Time in Insert tab → choose an appropriate format as specified. (If the date/month format is flipped →, change your region/ language settings on your computer to the United Kingdom.)

* Update fields if required (select auto-update while inserting fields.)
