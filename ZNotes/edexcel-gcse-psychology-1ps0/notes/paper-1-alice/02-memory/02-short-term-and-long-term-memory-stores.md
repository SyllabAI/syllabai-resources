## Short-term and long-term memory stores

### **Short-term memory (STM)**

* Input from the sensory register initially enters the STM store, a temporary repository lasting about 18 seconds.
* STM capacity is approximately seven items (Miller’s Magic Numbers: 7±2 items), encoding information acoustically through repetition (rehearsal)
* Rehearsed information can transition to the long-term memory (LTM)
  * *Learning link:* supports Willingham's learning theory

### **Long-term memory (LTM)**

* Encoding in the LTM is mainly semantic but may also be visual or acoustic
* LTM holds limitless information and can endure for minutes or even a lifetime

### **Forgetting mechanisms**

* In sensory register, forgetting can occur due to **displacement**, where not enough attention is given to incoming information
* In STM, forgetting can occur due to **displacement**, where new information replaces older information as the STM reaches capacity
* In LTM forgetting can occur due to:
  * memory **decay** may happen if the memory trace is unused for an extended period

  * overwritten by new information (**interference**)

  * missing cues or triggers (**retrieval failure**)
