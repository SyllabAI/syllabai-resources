# Memory

## Memory and information Processing

* **Input:** sensory information we receive from the environment
  * Sensory information is received from our 5 main senses:

    * Sight

    * Hearing

    * Touch

    * Taste

    * Smell
* **Encoding:** turning sensory information into a form (electrochemical) that can be stored in and used by the brain
  * Encoding can happen consciously or unconsciously

  * We have no control over the duration of encoded information

  * 3 ways of encoding information:

    * **Acoustic encoding:** storing sounds in memory

    * **Visual encoding:** storing seen information

    * **Semantic encoding:** storing meaningful information
* **Output:** recalling information (retrieval), or a behavioural response in general
