# PRO-07 — Transfer Patterns

## Executive Summary

Transfer is engineered, not hoped for. The board publishes a transferable-skills
interpretation for chemistry that names the skills students will need to cope
with degree-level demands, maps those skills to specification codes so each
transfer point is locatable in the taught course, and ships a maths-for-scientists
guide with dedicated percentages and standard-form booklets — the quantitative
layer that transfers across all sciences. The book generalises from the inside:
the calorimeter is defined so the pattern moves from copper can to polystyrene
cup across experiments, and the temperature-rate approximation is stated with
its own scope ("works for quite a lot of reactions"). At design level, the
specification commits to progression: it states what prior learning it builds on
and the World Class Qualification principles it is built to.
