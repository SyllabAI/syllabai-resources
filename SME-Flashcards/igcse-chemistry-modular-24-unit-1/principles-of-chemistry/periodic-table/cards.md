## Card 1 — keyword_definition (`fl_hTCSN6tKwVxR75kj`)

**FRONT**

What is a **period** in the Periodic Table?


**BACK**

A **period** is a horizontal row of the Periodic Table. The period number indicates how many **electron shells** an atom of that element has.

## Card 2 — keyword_definition (`fl_ttGHHYPXPrd34zfd`)

**FRONT**

What is a **group** in the Periodic Table?


**BACK**

A **group** is a vertical column of the Periodic Table. The group number indicates how many **outer electrons** an atom has in its outermost shell.


Spec links: `spcpt_4VfshKJkCVBsGFqZ`


## Card 3 — question_and_answer (`fl_MWWfkdDGqTTtdFhF`)

**FRONT**

How are elements arranged in the Periodic Table?


**BACK**

Elements are arranged in order of increasing **atomic number**. Each element has one more **proton** than the element before it.

## Card 14 — true_or_false (`fl_pc4n9ykjH9qz9Cm3`)

**FRONT**

**True or False?**

Elements in the same group of the Periodic Table have the same number of electron shells.


**BACK**

**False.**

Elements in the same group have the same number of **outer electrons**, not the same number of shells. Elements in the same **period** share the same number of electron shells.

**BACK**

A **metalloid** (also called a semi-metal) is an element that lies along the zig-zag line dividing metals and non-metals in the Periodic Table. Metalloids have characteristics of **both metals and non-metals**.

## Card 27 — question_and_answer (`fl_vhN8K2HCFFx6sZ5P`)

**FRONT**

Why do elements in the same group have similar chemical properties?


**BACK**

Elements in the same group all have the same number of **outer electrons**. Since outer electrons control how an element **reacts** and **bonds**, elements in the same group behave similarly.

**BACK**

**Noble gases** are the elements in Group 0 of the Periodic Table. They are non-metals that exist as single (**monatomic**) atoms and are colourless, non-flammable gases at room temperature.
