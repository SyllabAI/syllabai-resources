## Card 1 — keyword_definition (`fl_yDM4XjDkb3M9HyTn`)

**FRONT**

Define **function**.


**BACK**

A **function** is a mapping in which every input maps to exactly **one** output.

This means **one-one** and **many-one** mappings are functions, but a mapping that sends a single input to more than one output is not.

## Card 2 — question_and_answer (`fl_JGWYpmXzrwRM5Nqj`)

**FRONT**

What is the difference between a **one-one** mapping and a **many-one** mapping?


**BACK**

In a **one-one** mapping, every input has its own output, so no output value is ever repeated.

In a **many-one** mapping, two or more different inputs give the same output.

Both are functions, because in each case one input still gives only one output.

## Card 3 — question_and_answer (`fl_hCSCgYwykrcbfsm2`)

**FRONT**

A function is given by `\text{f} : x \mapsto 3x - 4`. What does this notation mean, and what is $\text{f} ( 5 )$?


**BACK**

This is **mapping notation**, and it means the same as $\text{f} ( x ) = 3 x - 4$.

To find $\text{f} ( 5 )$, replace every $x$ with 5:

$\text{f} ( 5 ) = 3 ( 5 ) - 4 = 11$

## Card 4 — question_and_answer (`fl_G6jGBrDkR8ZSBTVn`)

**FRONT**

For the function $\text{f} ( x ) = 2 x + 1$, the output is 15. How do you find the input?


**BACK**

Set the expression equal to the given output and solve the equation:

$2 x + 1 = 15 \Rightarrow x = 7$

Finding an output means **substituting**, but finding an input means **solving**.

## Card 5 — keyword_definition (`fl_2bXSCXW734XrkJnk`)

**FRONT**

Define the **domain** and the **range** of a function.


**BACK**

The **domain** is the set of values allowed as **inputs**, and the **range** is the set of all possible **outputs**.

On a graph, the domain values are the $x$-coordinates and the range values are the $y$-coordinates.


Spec links: `spcpt_pYXZH2ttg7ZPH73n`


## Card 6 — question_and_answer (`fl_ws9XhtwFsJ3CWvCY`)

**FRONT**

A function is written with no domain stated. What domain should you assume?


**BACK**

Assume the **largest set of values the function can accept**.

For example, $\text{f} ( x ) = \sqrt{x}$ has an assumed domain of $x \geq 0$, because the square root of a negative number is not a real number.

## Card 8 — question_and_answer (`fl_ChGzgtMGWjtbFtkB`)

**FRONT**

The domain of $\text{f} ( x ) = 2 x + 1$ changes from $x \geq 0$ to $x \geq 10$. What happens to the range?


**BACK**

The range changes from $\text{f} ( x ) \geq 1$ to $\text{f} ( x ) \geq 21$, because the smallest input is now 10 and $2 ( 10 ) + 1 = 21$.

Always work out the range from the domain you have been given, not from the expression alone.

## Card 9 — keyword_definition (`fl_yrkbQ7qw9Dk2DgSN`)

**FRONT**

Define the **modulus** of a number.


**BACK**

The **modulus** of a number is its size with any negative sign removed, so it is never negative.

It is written between vertical lines, so `\left|7\right| = 7` and `\left|-7\right| = 7`.

It is also called the **absolute value**.

## Card 10 — true_or_false (`fl_tMMwFtBrX7Y3pJXy`)

**FRONT**

**True or False?**

If $\text{f} ( x )$ is negative, then `\left|\text{f}(x)\right| = -\text{f}(x)`.


**BACK**

**True.**

Multiplying a negative value by $- 1$ makes it positive, which is exactly what the modulus has to do.

For example, if $\text{f} ( x ) = - 7$ then `-\text{f}(x) = 7 = \left|\text{f}(x)\right|`.

## Card 11 — keyword_definition (`fl_8K9GwSjD6NcpZ5tG`)

**FRONT**

Define an **inverse function**.


**BACK**

An **inverse function** $\text{f}^{-1}$ undoes whatever $\text{f}$ does, so applying $\text{f}$ and then $\text{f}^{-1}$ returns the original input.

It carries out the inverse operations in the **reverse order**: if $\text{f}$ doubles and then adds 1, $\text{f}^{-1}$ subtracts 1 and then halves.


Spec links: `spcpt_rqhzVMXZ3X4XpbYw`


## Card 12 — question_and_answer (`fl_x6kpWF54DDcNqdBk`)

**FRONT**

Why must a function be **one-one** for an inverse function to exist?


**BACK**

Because the inverse has to send each output back to a single input.

If the function is **many-one**, two different inputs share an output, so the inverse would have to send that one value back to two places, and that is not a function.


Spec links: `spcpt_rqhzVMXZ3X4XpbYw`


## Card 13 — question_and_answer (`fl_9JnNdFXXr5Y7wMKw`)

**FRONT**

Describe how to find $\text{f}^{-1} ( x )$ from $\text{f} ( x ) = 5 - 3 x$.


**BACK**

Write it as $y = 5 - 3 x$, swap the $x$ and the $y$ to get $x = 5 - 3 y$, then rearrange to make $y$ the subject:

$\text{f}^{-1} ( x ) = \frac{5-x}{3}$

Finish in inverse-function notation, with no $y$ left in the answer.


Spec links: `spcpt_rqhzVMXZ3X4XpbYw`


## Card 14 — question_and_answer (`fl_sHSzj9MyNK6jWFJV`)

**FRONT**

$\text{f} ( x ) = 2^{x}$. How can you solve $\text{f}^{-1} ( x ) = 5$ without first finding $\text{f}^{-1}$?


**BACK**

Apply $\text{f}$ to both sides and use the fact that $\text{ff}^{-1} ( x ) = x$:

$x = \text{f} ( 5 ) = 2^{5} = 32$

This works because a function and its inverse cancel each other out whenever they are applied together.

$\text{f} ( x ) = \sqrt{3x-2}$ for $x \geq \frac{2}{3}$. Write down the domain and range of $\text{f}^{-1} ( x )$.

The domain of $\text{f}^{-1}$ is $x \geq 0$, because that is the range of $\text{f}$.

## Card 17 — question_and_answer (`fl_h3RZz7XNXx8VTdB2`)

**FRONT**

How are the graphs of $y = \text{f} ( x )$ and $y = \text{f}^{-1} ( x )$ related?


**BACK**

Each is a **reflection** of the other in the line $y = x$.

Every key feature reflects with it, so axis intercepts, turning points and asymptotes all swap their $x$ and $y$ roles.


Spec links: `spcpt_VsPqmkcp657mcw6N`


## Card 18 — question_and_answer (`fl_d2dZgM2Wn4VMhpm5`)

**FRONT**

The graph of $y = \text{f} ( x )$ crosses the $x$-axis at $( 4 , 0 )$ and has the asymptote $x = - 2$. What happens to each on the graph of $y = \text{f}^{-1} ( x )$?


**BACK**

The intercept becomes $( 0 , 4 )$ and the asymptote becomes the line $y = - 2$.

Reflecting in $y = x$ swaps every $x$-coordinate with its $y$-coordinate, which turns a vertical asymptote into a horizontal one.

## Card 19 — true_or_false (`fl_FkJRyR8znV379xMX`)

**FRONT**

**True or False?**

You need the expression for $\text{f} ( x )$ before you can draw the graph of $y = \text{f}^{-1} ( x )$.


**BACK**

**False.**

If you are given the graph of $y = \text{f} ( x )$, reflecting it in the line $y = x$ produces the graph of the inverse.

The reflection is a geometric operation, so it works whatever the expression for $\text{f} ( x )$ happens to be.

## Card 20 — keyword_definition (`fl_FhRpZjbcgM4RqKsp`)

**FRONT**

Define a **composite function**.


**BACK**

A **composite function** applies one function to the output of another, so the output of the first becomes the input of the second.

$\text{fg} ( x )$ means $\text{f} ( \text{g} ( x ) )$, read as **f of g of x**.


Spec links: `spcpt_NbgkVjMb8tWmrx9b`


## Card 21 — question_and_answer (`fl_D2Nkcb3RVssczMPb`)

**FRONT**

In $\text{fg} ( x )$, which function is applied first?


**BACK**

$\text{g}$ is applied first, because it is the function **closest to the variable**.

Its output then becomes the input of $\text{f}$, which is why $\text{fg} ( x )$ means $\text{f} ( \text{g} ( x ) )$.

## Card 22 — question_and_answer (`fl_MRhB8PGtdSCqgTTy`)

**FRONT**

$\text{f} ( x ) = x^{2}$ and $\text{g} ( x ) = 2 x$. Find $\text{fg} ( x )$ and $\text{gf} ( x )$, and say what they show.


**BACK**

$\text{fg} ( x ) = \text{f} ( 2 x ) = ( 2 x )^{2} = 4 x^{2}$, while $\text{gf} ( x ) = \text{g} ( x^{2} ) = 2 x^{2}$.

They are different, which shows that the **order matters**: $\text{fg}$ is not usually the same as $\text{gf}$.

## Card 23 — true_or_false (`fl_B7Tf6nNyfpk5rFP6`)

**FRONT**

**True or False?**

For some pairs of functions, $\text{fg} ( x )$ and $\text{gf} ( x )$ are exactly the same.


**BACK**

**True.**

The order usually matters, but not always.

For example, if $\text{f} ( x ) = 3 x - 2$ and $\text{g} ( x ) = 6 x - 5$ then $\text{fg} ( x ) = \text{gf} ( x ) = 18 x - 17$.

## Card 24 — question_and_answer (`fl_PfXDhsnCwncMJJfQ`)

**FRONT**

What does $\text{f}^{2} ( x )$ mean, and why is this notation not used with trigonometric functions?


**BACK**

$\text{f}^{2} ( x )$ means $\text{ff} ( x )$, that is $\text{f} ( \text{f} ( x ) )$.

It is not used with trigonometric functions because there the superscript means a power: $\mathrm{sin}^{2} ( x )$ means $( \mathrm{sin} x )^{2}$, not $\mathrm{sin} ( \mathrm{sin} x )$.

## Card 26 — question_and_answer (`fl_rq3cxXXQgJQCT27t`)

**FRONT**

$\text{f} ( x ) = \frac{1}{x}$ for $0 < x < 1$, and $\text{g} ( x ) = x^{2}$ for $x > 1$. Explain why $\text{fg} ( x )$ does not exist.


**BACK**

The range of $\text{g}$ is $\text{g} ( x ) > 1$, but the domain of $\text{f}$ is $0 < x < 1$.

Nothing that $\text{g}$ produces is an acceptable input for $\text{f}$, so $\text{fg} ( x )$ cannot be formed.
