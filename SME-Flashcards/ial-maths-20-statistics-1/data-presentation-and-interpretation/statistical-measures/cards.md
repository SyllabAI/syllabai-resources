## Card 1 — keyword_definition (`fl_XSJJx8zjyY9RZ37n`)

**FRONT**

Define a **measure of location**.


**BACK**

A measure of location gives information about **where** data sits in the number system.

The mean, median and mode are measures of **central tendency**, a particular kind of location measure describing where the centre of the data is.

The quartiles and percentiles are measures of location too, but they describe other positions in the data rather than the centre.

## Card 2 — question_and_answer (`fl_vP7YhvQzwCVXb6qV`)

**FRONT**

Why must a data set be put in order of size before you can find its median, but not before you can find its mean?


**BACK**

Because the median is defined by its **position**: it is the middle value once the data is in order, so putting the data in order is what identifies it.

The mean is a **total** divided by how many values there are, and that total comes out the same whatever order the values are added in.

With an even number of values there is no single middle one, so the median is the **midpoint** of the two middle values.

## Card 3 — question_and_answer (`fl_DDYdwNKQV3RD8vVf`)

**FRONT**

In summary-statistic notation, what do $Σ x$ and $\overline{x}$ each stand for, and how is each read aloud?


**BACK**

$Σ x$ is the **sum** of all the data values, $x_{1} + x_{2} + \dots + x_{n}$, and is read as **sigma x**.

$\overline{x}$ is the **mean**, $\frac{Σx}{n}$, and is read as **x bar**.

## Card 4 — question_and_answer (`fl_BDxFqMqc72dvc5K6`)

**FRONT**

A data set contains one or two extreme values. Which average is affected most, and which average would you report instead?


**BACK**

The **mean** is affected most, because it is worked out from every value in the set, so one extreme value drags the whole total with it.

Report the **median** instead: it depends only on which value sits in the middle position, so an extreme value at one end shifts it by at most one place.

The mode is not affected either, but it can sit nowhere near the centre of the data, and a set can have several modes or none at all.

## Card 5 — question_and_answer (`fl_rzzBRCMvkbTFdd94`)

**FRONT**

The 70th **percentile** of a data set is 42. What does that tell you about the data?


**BACK**

**70% of the data lies below 42**, and the remaining 30% lies above it.

Percentiles divide the data into 100 parts, in the same way that the quartiles divide it into four: $Q_{1}$ is the 25th percentile, the median is the 50th and $Q_{3}$ is the 75th.

## Card 6 — question_and_answer (`fl_3vrVBMryGPNq3wKv`)

**FRONT**

For a list of $n$ raw data values written in order, $\frac{n}{4}$ is worked out in order to locate the lower quartile. Why does what you do next depend on whether $\frac{n}{4}$ is a whole number?


**BACK**

If $\frac{n}{4}$ is **not** a whole number, round it **up**, and $Q_{1}$ is the value in that position.

If $\frac{n}{4}$ **is** a whole number, the quarter-way point falls exactly between two data values, so $Q_{1}$ is the **midpoint** of that value and the one above it.

The upper quartile is found the same way, using $\frac{3n}{4}$.

## Card 8 — true_or_false (`fl_pSvzd6YWCsRy9sq6`)

**FRONT**

**True or False?**

The 25th to 75th interpercentile range is the same thing as the interquartile range.


**BACK**

**True.**

The 25th percentile is $Q_{1}$ and the 75th percentile is $Q_{3}$, so that particular interpercentile range is $Q_{3} - Q_{1}$, which is exactly the interquartile range.

Any other pair of percentiles gives something different, which is why you must always say **which** two you mean, as in the 10th to 90th interpercentile range.

## Card 9 — true_or_false (`fl_fz4NH2fSPGVWmDNW`)

**FRONT**

**True or False?**

Putting data into a frequency table loses the individual data values.


**BACK**

**False.**

An **ungrouped** frequency table keeps every value: it records how many times each individual value occurred, so exact averages, ranges and summary statistics can still be calculated from it.

It is **grouping** the data that loses the values. Once a table records only that eight items fell between 240 and 260, those eight values are gone, and every statistic calculated from it is an **estimate**.

## Card 10 — question_and_answer (`fl_QjV4s3d4Y2SRgFXH`)

**FRONT**

For **discrete data in an ungrouped frequency table**, which position gives the median, and how do you find the value there?


**BACK**

The median is the $\frac{n+1}{2}$ th value, where $n$ is the total frequency.

Add the frequencies up in order until the running total first reaches that position, and the median is the data value you are on when it does.

So, **for example**, with $n = 60$ the median is the 30.5th value, meaning halfway between the 30th and the 31st; **grouped** data uses a different position, because the individual values are no longer known.

## Card 11 — fill_in_the_blanks (`fl_ThBycjfhJrhtNtZV`)

**FRONT**

Complete the formula for the mean of data given in a frequency table, where $x$ is a data value and $f$ is its frequency:

`\bar{x} = \frac{\Sigma \_\_\_\_\_\_}{\Sigma \_\_\_\_\_\_}`


**BACK**

The completed formula is:

$\overline{x} = \frac{Σxf}{Σf}$

Multiply each value by its frequency and add the results, then divide by the total frequency.

$Σ x f$ is the sum of all the data values, exactly as $Σ x$ would be if they were listed out one by one, and $Σ f$ is how many values there are.

## Card 12 — question_and_answer (`fl_F987fKKqG2hYm7Kx`)

**FRONT**

A grouped frequency table for continuous data has the classes $10 \leq x \leq 19$ and $20 \leq x \leq 29$. What is wrong with them, and what do you do about it?


**BACK**

There is a **gap**: nothing between 19 and 20 has a class to go in, and a continuous quantity can take those values.

Close the gap before doing any calculation: for data that has been **rounded**, the boundaries become

$9 . 5 \leq x < 19 . 5  \text{and}  19 . 5 \leq x < 29 . 5$

For data that has been **truncated**, such as an age counted in whole years, they become $10 \leq x < 20$ and $20 \leq x < 30$ instead, since someone is 19 right up until their 20th birthday.

## Card 13 — question_and_answer (`fl_fTC7v2Nsy83GKNff`)

**FRONT**

For grouped data you give the modal **class** rather than the mode. Why can you not give a mode?


**BACK**

Grouping the data throws away the individual values, so there is no longer any way to tell which single value occurred most often.

What survives is which **class** the data is most concentrated in, so that is what you report.

The same limitation applies to the mean and the median from a grouped table: everything you can calculate is an estimate.


Spec links: `spcpt_Dnt3T3BYzbvRC4dh`


## Card 14 — question_and_answer (`fl_J8xR8H6m2NcFsrMK`)

**FRONT**

What do you use in place of the actual data values when estimating the mean from a grouped frequency table?


**BACK**

The **midpoint** of each class, which stands in for every value in that class; the midpoint is the mean of the class's lower and upper boundaries, so $150 \leq h < 155$ has midpoint 152.5.

This is why the answer is only an **estimate**: it assumes the values in each class average out at its midpoint, which they will not do exactly.

Watch for a class of a different width from the others, since its midpoint still has to be worked out from its own boundaries.

## Card 15 — fill_in_the_blanks (`fl_gGwSMp8vVsy8NcMr`)

**FRONT**

Complete the assumption that linear interpolation makes about grouped data:

The data values are assumed to be `\_\_\_\_\_\_` spread throughout each class.


**BACK**

The completed assumption is:

The data values are assumed to be **evenly** spread throughout each class.

That assumption is what makes the method work. If the values are evenly spread, then a position one third of the way through a class's frequency corresponds to a data value one third of the way through that class's range, so proportion can be used.

It is also why an interpolated median or quartile is an **estimate**: real data is rarely spread evenly.

## Card 16 — question_and_answer (`fl_PTw2x8sDXvqXWK3g`)

**FRONT**

$Q_{1}$ is the 6.25th value, and it lies in the class $155 \leq h < 160$, which runs from a cumulative frequency of 3 to a cumulative frequency of 8. How does linear interpolation give $Q_{1}$?


**BACK**

Set the fraction of the way through the **cumulative frequency** equal to the fraction of the way through the **class boundaries**:

$\frac{6.25-3}{8-3} = \frac{Q_{1}-155}{160-155}$

$\frac{3.25}{5} = \frac{Q_{1}-155}{5}$

so $Q_{1} = 155 + 3 . 25 = 158 . 25$.

The part that is easiest to forget is adding the **lower class boundary** back on at the end. The proportion gives you how far into the class the value sits, not the value itself.

## Card 17 — keyword_definition (`fl_2ZGS9XDGG3yV9V7W`)

**FRONT**

Define the **variance** of a set of data.


**BACK**

The variance measures how **spread out** a set of data is: it is the mean of the squared deviations from the mean.

Widely spread data has a large variance; data clustered close together has a small one.

The **standard deviation** is the square root of the variance and is written $σ$, which is why the variance itself is written $σ^{2}$.

## Card 18 — fill_in_the_blanks (`fl_ThRWrkRDqsSghzk6`)

**FRONT**

Complete the version of the variance formula that is usually quickest to use:

`\sigma^{2} = \frac{\Sigma \_\_\_\_\_\_}{n} - \left(\_\_\_\_\_\_\right)^{2}`


**BACK**

The completed formula is:

`\sigma^{2} = \frac{\Sigma x^{2}}{n} - \left(\bar{x}\right)^{2}`

In words, it is the mean of the squares minus the square of the mean.

It needs only $Σ x^{2}$, $Σ x$ and $n$, which is why it is quicker than working out every deviation $x - \overline{x}$ one at a time.

## Card 19 — question_and_answer (`fl_nK45NdfdJHjVGzMT`)

**FRONT**

The summary statistic `S_{x x} = \Sigma \left(x - \bar{x}\right)^{2}` is given in the formula booklet. How do you get the variance from it?


**BACK**

Divide it by $n$:

$σ^{2} = \frac{S_{xx}}{n}$

$S_{xx}$ is the **total** of the squared deviations, so dividing by how many values there are turns that total into their mean, which is what the variance is.

The formulae for the variance and the standard deviation are **not** in the booklet, so those two you have to know.

## Card 20 — true_or_false (`fl_BMPmk5qyJKhhtgTm`)

**FRONT**

**True or False?**

A set of data can have a variance of zero.


**BACK**

**True.**

The variance is zero exactly when every deviation $x - \overline{x}$ is zero, which happens when **every value in the set is the same**.

It can never be negative, because it is built out of squares, so zero is the smallest value a variance can take.

## Card 21 — question_and_answer (`fl_r85Z7hsYsdbKxWJY`)

**FRONT**

The times in a data set are measured in minutes. What are the units of the variance, and what are the units of the standard deviation?


**BACK**

The variance is in **minutes squared**, because it is built out of **squared** deviations from the mean.

The standard deviation is in **minutes**, the same units as the data itself, because taking the square root undoes that squaring.

That is what makes the standard deviation the more natural of the two to quote when describing a set of data.

## Card 22 — question_and_answer (`fl_bSJwRn64Mr5dgR4Y`)

**FRONT**

How does the variance formula change when the data is given in a **grouped** frequency table?


**BACK**

Every value is weighted by its frequency, and the class **midpoints** are used in place of the data values $x$:

`\sigma^{2} = \frac{\Sigma f x^{2}}{\Sigma f} - \left(\frac{\Sigma f x}{\Sigma f}\right)^{2}`

The total frequency $Σ f$ replaces $n$, because that is how many values there are.

Since the midpoints only stand in for the real values, the answer is an **estimate**.

## Card 23 — keyword_definition (`fl_GxGpPFcn2VPDyVvT`)

**FRONT**

Define **coding** a set of data.


**BACK**

Coding is applying the **same formula to every value** in a data set, to simplify the numbers you have to work with.

It is most useful when the data consists of very large or very small numbers, so coding such as $x = \frac{h-250}{20}$ turns awkward values into small, convenient ones.

The coding must be applied to **every** value, or the coded data no longer represents the original.

## Card 24 — question_and_answer (`fl_C7hqxHPQhSMcfdkY`)

**FRONT**

Data $x$ is coded using $y = a x + b$. What happens to the **mean**?


**BACK**

The mean is coded in exactly the same way as the data:

$\overline{y} = a \overline{x} + b$

The reason is that the mean is a measure of **location**.

Changing every value changes where the data sits, and the mean follows it: multiply everything by $a$ and the centre is multiplied by $a$; add $b$ to everything and the centre moves up by $b$.

## Card 25 — question_and_answer (`fl_HqQGSSQwRjMmFR7c`)

**FRONT**

Data $x$ is coded using $y = a x + b$. What happens to the **standard deviation**?


**BACK**

Only the multiplier affects it:

`\sigma_{y} = \left|a\right| \sigma_{x}`

Adding or subtracting $b$ makes **no difference at all**, because the standard deviation is a measure of **spread**: sliding every value along by the same amount leaves every gap between values exactly as it was.

Multiplying by $a$ does stretch those gaps, so it stretches the standard deviation with them.


Spec links: `spcpt_VdkHR5vRgMfZtKyd`

## Card 27 — question_and_answer (`fl_H2gb8hxWdjq3Qv4s`)

**FRONT**

In `\sigma_{y} = \left|a\right| \sigma_{x}`, why is the modulus of $a$ taken?


**BACK**

Because a standard deviation can **never be negative**: it measures how spread out data is, and a spread of less than nothing means nothing.

Coding with a negative multiplier, such as $y = - 3 x$, reflects the data as well as stretching it, but reflecting does not change how spread out it is.

So the standard deviation is multiplied by the **positive** value 3, not by $- 3$.

## Card 28 — question_and_answer (`fl_WRrYNG3hPMMGFXVK`)

**FRONT**

Heights $h$, in cm, are coded using $x = \frac{h-250}{20}$, and the coded data has standard deviation 1.3102. What is the standard deviation of the heights?


**BACK**

Only the **division by 20** has to be reversed:

$σ_{h} = 20 \times 1 . 3102 = 26 . 2 \text{cm}$

Subtracting 250 slid every height down the scale without changing how spread out they were, so it has no part in the calculation.

Note that the answer carries the units of the original data, cm, not of the coded values, which have no units at all.

## Card 29 — keyword_definition (`fl_yyy4S9RFC9rXcMtb`)

**FRONT**

Define a **statistical model**.


**BACK**

A statistical model uses mathematics to represent a **real-life situation**, such as the temperature in a city across a month or the sleeping times of a baby.

It is a deliberately simplified version of that situation rather than the situation itself, which is what makes it something you can calculate with.

## Card 30 — question_and_answer (`fl_s7SDgcrRfPzrTk4b`)

**FRONT**

Give two advantages of using a statistical model rather than working with the real-life situation directly.


**BACK**

It **simplifies** a complicated situation down to something that can be handled mathematically, and it can be built **quickly and easily** compared with observing the real situation.

Once it exists it can also be used to make **predictions**, which is usually the reason for building one in the first place.

**True or False?**

A good statistical model is one that includes as many features of the real situation as possible.


**BACK**

**False.**

## Card 32 — question_and_answer (`fl_pBVhxHQ3XSktvscs`)

**FRONT**

A model of a shop's daily sales was built using data collected in December. Why might it predict badly in June?


**BACK**

A statistical model is often only applicable to the **particular circumstances** it was built for, because it carries the pattern of the data it was built from.

December sales follow the run-up to Christmas, so a model fitted to them describes that period rather than a quiet summer month.

Using a model outside the situation it was designed for is one of the main reasons predictions stop being accurate.

## Card 33 — question_and_answer (`fl_bbmG27q7sh6FS62W`)

**FRONT**

Why must real-life data be collected **after** a statistical model has been used to make its predictions?


**BACK**

Because the model is judged by **comparing** the values it predicted with the values actually observed, and that comparison only means anything if the predictions came first.

Predictions made after seeing the data could simply be fitted to it, and would say nothing about whether the model works.

It is that comparison which decides whether the model is accepted or has to be improved.

## Card 34 — question_and_answer (`fl_WbHssH24W5JHNsnp`)

**FRONT**

The values a statistical model predicts turn out not to match the data that is then collected. What happens to the model?


**BACK**

It is **adjusted and improved**, then used again, rather than thrown away.

The way the data was selected and collected is examined as well, since a mismatch can say as much about the data as about the model.

That is what makes statistical modelling a **cycle**: predict, collect, compare, refine, and round again.
