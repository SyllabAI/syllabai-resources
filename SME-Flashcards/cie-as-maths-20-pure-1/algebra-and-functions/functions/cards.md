## Card 1 — keyword_definition (`fl_Qtm7mbC8qZ7NfwGm`)

**FRONT**

Define **function**.


**BACK**

A **function** is a mapping in which every 'input' maps to exactly one 'output'.

Functions are written as `\text{f}\left(x\right)`, or in the alternative form `\text{f} : x \mapsto x^{2} - 3 x + 2`.

## Card 2 — question_and_answer (`fl_b2wHTTtBfjThFZHQ`)

**FRONT**

Which types of mapping are functions?


**BACK**

**One-to-one** and **many-to-one** mappings.

One-to-many and many-to-many are not, because a single input would have more than one output.

## Card 3 — fill_in_the_blanks (`fl_nKWqdFR5zv8pm9rS`)

**FRONT**

The `\_\_\_\_\_\_` of a function is the set of allowed inputs, and the `\_\_\_\_\_\_` is the set of all possible outputs.


**BACK**

The **domain** of a function is the set of allowed inputs, and the **range** is the set of all possible outputs.

The range depends on the domain: change which inputs are allowed and the outputs change with them.

## Card 4 — question_and_answer (`fl_kVj63JZrYQTHxN4f`)

**FRONT**

Why is squaring a **many-to-one** mapping?


**BACK**

Because different inputs can give the same output: both $2$ and $- 2$ map to $4$.

It is still a function, since each individual input has only one output.

## Card 5 — true_or_false (`fl_KzR547552Z8Ms5ND`)

**FRONT**

**True or False?**

`\text{f}\left(x\right) = x^{2}` on its own is a fully defined function.


**BACK**

**False.**

A function is not fully defined until its **domain** has been stated.

Without it you cannot say what the range is, or whether the function is one-to-one.


Spec links: `spcpt_BPzK4hYjprckscTt`


## Card 6 — question_and_answer (`fl_qBjv5W7kfMvPDmsZ`)

**FRONT**

How can restricting the domain change a function?


**BACK**

It can turn a **many-to-one** function into a **one-to-one** one.

`\text{f}\left(x\right) = x^{2}` is many-to-one over all real $x$, but restricting it to $x \geq 0$ makes it one-to-one.

## Card 7 — question_and_answer (`fl_Hn2MXVNdYf57F8Zb`)

**FRONT**

How do you work out the range of a function?


**BACK**

Find the outputs that the stated domain actually produces, sketching the graph where that helps.

For `\text{f}\left(x\right) = x^{2}` with $x \in ℝ$ the range is `\text{f}\left(x\right) \geq 0`, because a square is never negative.

## Card 8 — keyword_definition (`fl_S8PfkVWJkqHBRH7M`)

**FRONT**

Define **composite function**.


**BACK**

A **composite function** is one function applied after another, with the output of the first becoming the input of the second.

It can be written `\text{fg}\left(x\right)`, `\text{f}\left(\text{g}\left(x\right)\right)` or `\left(\text{f} \circ \text{g}\right)\left(x\right)`, all meaning "$\text{f}$ of `\text{g}\left(x\right)`".


Spec links: `spcpt_M8pcsBkNN7dyg4b9`


## Card 9 — question_and_answer (`fl_pvvqFtqdv2wdFt5X`)

**FRONT**

In `\text{fg}\left(x\right)`, which function is applied first?


**BACK**

$\text{g}$, the one closest to the variable.

You work outwards: apply $\text{g}$ to $x$ first, then apply $\text{f}$ to whatever that produces.


Spec links: `spcpt_M8pcsBkNN7dyg4b9`


## Card 10 — true_or_false (`fl_PVr4BgwZd5qXrjDK`)

**FRONT**

**True or False?**

`\text{fg}\left(x\right)` and `\text{gf}\left(x\right)` always give the same result.


**BACK**

**False.**

The order in which the functions are applied changes the answer, so the two are usually different.

They can happen to agree for particular pairs of functions, but that cannot be assumed.

Applying a function to its own output, `\text{ff}\left(x\right)`, is written as `\text{f}^{2}\left(x\right)`.

## Card 12 — question_and_answer (`fl_pN7yPg4Mnd3hTgvh`)

**FRONT**

Why might `\text{fg} \left(x\right)` exist when `\text{gf} \left(x\right)` does not?


**BACK**

Because the output of the first function has to be an allowed input for the second.

The range of $\text{g}$ must lie inside the domain of $\text{f}$, and that can hold one way round without holding the other.

## Card 13 — question_and_answer (`fl_GNgtMvVc3dV3ywkP`)

**FRONT**

Given `\text{f} \left(x\right) = 2 x` and `\text{g} \left(x\right) = x + 3`, what is `\text{fg} \left(x\right)`?


**BACK**

`\text{fg}\left(x\right) = 2\left(x + 3\right) = 2 x + 6`.

Taking them the other way round gives `\text{gf}\left(x\right) = 2 x + 3`, which is a different function.

## Card 14 — keyword_definition (`fl_Qp2SGFjqcstzhHw6`)

**FRONT**

Define **inverse function**.


**BACK**

An **inverse function** reverses the original function, taking each output back to the input it came from.

It is written `\text{f}^{-1}\left(x\right)`, so whatever $\text{f}$ maps forwards, $\text{f}^{-1}$ maps back again.


Spec links: `spcpt_BDJMvyt2SwNGyFPd`


## Card 15 — question_and_answer (`fl_kQbN5Wsz77Q6rDMH`)

**FRONT**

Which functions have an inverse, and why?


**BACK**

Only **one-to-one** functions.

Reversing a many-to-one function would send a single input to more than one output, and that is not a function at all.


Spec links: `spcpt_BDJMvyt2SwNGyFPd`


## Card 16 — question_and_answer (`fl_m9QvbyqMgcY2SKFx`)

**FRONT**

Why does `\text{f}^{-1}\left(x\right)` not mean `\frac{1}{\text{f}\left(x\right)}`?


**BACK**

Because the $- 1$ is part of the **name** of the inverse function, not an index.

For `\text{f}\left(x\right) = x + 3` the inverse is `\text{f}^{-1}\left(x\right) = x - 3`, which is nothing like $\frac{1}{x+3}$.


Spec links: `spcpt_BDJMvyt2SwNGyFPd`


## Card 17 — true_or_false (`fl_qzjPfsrpvK5C87Fj`)

**FRONT**

**True or False?**

The graphs of `y = \text{f}\left(x\right)` and `y = \text{f}^{-1}\left(x\right)` are reflections of each other in the line $y = x$.


**BACK**

**True.**

Every point `\left(a, b\right)` on one graph has a matching point `\left(b, a\right)` on the other, and swapping the coordinates of a point is exactly what reflecting in $y = x$ does.

This is why the inverse can be sketched without finding a formula for it first.


Spec links: `spcpt_BDJMvyt2SwNGyFPd`


## Card 18 — fill_in_the_blanks (`fl_2cgXnM7gV4d486sx`)

**FRONT**

The domain of $\text{f}^{-1}$ is the `\_\_\_\_\_\_` of $\text{f}$, and the range of $\text{f}^{-1}$ is the `\_\_\_\_\_\_` of $\text{f}$.


**BACK**

The domain of $\text{f}^{-1}$ is the **range** of $\text{f}$, and the range of $\text{f}^{-1}$ is the **domain** of $\text{f}$.

The two swap over, because the inverse sends the outputs of $\text{f}$ back to the inputs they came from.

## Card 19 — question_and_answer (`fl_YnDmSYJK7JHzgdZq`)

**FRONT**

To find `\text{f}^{-1}\left(x\right)` algebraically, what do you do after writing `y = \text{f}\left(x\right)`?


**BACK**

Make $x$ the **subject** of the equation.

Then replace the $y$ with an $x$ to put the result in function notation, so $x = \sqrt{\frac{y-2}{3}}$ becomes `\text{f}^{-1}\left(x\right) = \sqrt{\frac{x - 2}{3}}`.

## Card 20 — question_and_answer (`fl_XfCvwcppQCx4T5Bc`)

**FRONT**

What do you get if you apply a function and then its inverse?


**BACK**

You get back the input you started with, so `\text{ff}^{-1}\left(x\right) = \text{f}^{-1}\text{f}\left(x\right) = x`.

The result is the same whichever of the two is applied first, which is unusual, since the order of a composite function normally matters.
