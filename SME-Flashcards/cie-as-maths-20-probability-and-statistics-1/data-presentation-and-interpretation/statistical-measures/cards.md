## Card 1 — keyword_definition (`fl_J6cRHCtjrYjmmZGX`)

**FRONT**

Define a **measure of central tendency**.


**BACK**

A **measure of central tendency** is a single value describing where the centre of a data set lies, which is what is usually meant by an **average**.

The three used in this course are the **mean**, the **median** and the **mode**.

## Card 2 — question_and_answer (`fl_zQMQTPGvvJcwcsPG`)

**FRONT**

What is the median of a data set, and how do you find it when there is an even number of values?


**BACK**

The **median** is the middle value once the data has been put in **order of size**.

With an even number of values there is no single middle one, so the median is the **midpoint of the two middle values**: for 14, 19, 19, 23, 27, 28 it is $\frac{19+23}{2} = 21$.

## Card 3 — fill_in_the_blanks (`fl_DZbS8vJV8qs2D8zM`)

**FRONT**

Complete the formula for the mean of $n$ data values:

`\bar{x} = \frac{\_\_\_\_\_\_}{\_\_\_\_\_\_}`


**BACK**

The completed formula is:

$\overline{x} = \frac{Σx}{n}$

$Σ x$ is the **total** of all the data values and $n$ is **how many** of them there are, so the mean shares that total out equally between them.

## Card 4 — question_and_answer (`fl_DjfzpYXMVSK7Zxmw`)

**FRONT**

Why can a single extreme value make the mean a poor description of a data set?


**BACK**

Because the mean is worked out from **every** value, so one unusually large or small value changes the total and drags the mean towards it.

The mean can then sit above almost all of the data, which is why the **median** is preferred for data sets containing extreme values.


Spec links: `spcpt_rjG6xK63YtGfwFYZ`


## Card 5 — true_or_false (`fl_c9n4hjHg7ZKFRTrK`)

**FRONT**

**True or False?**

Every data set has exactly one mode.


**BACK**

**False.**

A data set has **two** modes if two values tie for the highest frequency, and **no mode at all** if every value occurs the same number of times.

A data set with two modes is described as **bimodal**.

## Card 6 — question_and_answer (`fl_f3XzKHGSskjVKCdD`)

**FRONT**

What do the three quartiles divide an ordered data set into, and what does each one mark?


**BACK**

They divide it into **four equal sections**, each holding a quarter of the data.

The lower quartile $Q_{1}$ marks the point 25% of the way through, the median $Q_{2}$ the point 50% of the way through, and the upper quartile $Q_{3}$ the point 75% of the way through.


Spec links: `spcpt_pdFBjsBz9TnQ7GwH`


## Card 7 — question_and_answer (`fl_rMJRTSr47r4cW2H7`)

**FRONT**

In an ordered list of $n$ values, how do you find the position of the lower quartile?


**BACK**

Work out $\frac{n+1}{4}$, which gives the position of the lower quartile within the ordered list.

If that comes out as a whole number the lower quartile is the value in that position, and if it does not you take the **midpoint** of the two values on either side of it.

The upper quartile is found the same way from `\frac{3 \left(n + 1\right)}{4}`.


Spec links: `spcpt_pdFBjsBz9TnQ7GwH`


## Card 8 — question_and_answer (`fl_4KgjwhkjKmzXWxKs`)

**FRONT**

Why is the interquartile range often a better measure of spread than the range?


**BACK**

Because the range is worked out from only the largest and smallest values, which are the two most likely to be unusual, so a single odd value can change it completely.

The **interquartile range**, $Q_{3} - Q_{1}$, covers only the middle half of the data, so values at either extreme do not affect it at all.


Spec links: `spcpt_pdFBjsBz9TnQ7GwH`


## Card 9 — true_or_false (`fl_8WBVH2BGK5V5sbzg`)

**FRONT**

**True or False?**

The range and the interquartile range are measured in the same units as the data itself.


**BACK**

**True.**

Both are found by **subtracting one data value from another**, so the answer carries whatever unit the data was measured in: a range of 67 for data measured in metres is a range of **67 metres**.

## Card 10 — question_and_answer (`fl_Xmzkr8gG9H55qTBY`)

**FRONT**

Why is a mean found from a grouped frequency table only an estimate?


**BACK**

Because grouping records only **how many values fell in each class**, so the individual values are lost and cannot be added up.

An **ungrouped** table records how many times each individual value occurred, so nothing is thrown away and the mean it gives is the true one.


Spec links: `spcpt_vwSXjzQnpHNyGzdC` `spcpt_DwR2YXTQtqGz6ZNP`


## Card 11 — question_and_answer (`fl_YQhMpgG7Ms9XM7NK`)

**FRONT**

In a frequency table, why is each data value multiplied by its frequency before the total is divided?


**BACK**

Because a value listed once with a frequency of $f$ stands for $f$ separate data values, so $x f$ is their combined contribution.

Adding these products and dividing by the **total frequency** $Σ f$ therefore gives the mean:

$\overline{x} = \frac{Σxf}{Σf}$


Spec links: `spcpt_DwR2YXTQtqGz6ZNP`


## Card 12 — question_and_answer (`fl_625HKZcm4BbpXNq3`)

**FRONT**

In an ungrouped frequency table of $n$ values, how do you find which data value is the median?


**BACK**

Work out $\frac{n+1}{2}$ to get the median's **position** in the ordered data, then add the frequencies down the table until the running total first reaches that position.

The median is the value in the row where the running total arrives, because the table already lists the values in order and the running total says how far through them you have reached.


Spec links: `spcpt_DwR2YXTQtqGz6ZNP`


## Card 13 — true_or_false (`fl_fkx5TWT4yhgxmGNC`)

**FRONT**

**True or False?**

In a table with classes $155 \leq h < 160$ and $160 \leq h < 165$, a height of exactly 160 cm belongs to the first class.


**BACK**

**False.**

The first class stops **below** 160, because $h < 160$ excludes 160 itself, while the second class starts **at** 160, because $160 \leq h$ includes it.

So 160 cm goes into $160 \leq h < 165$, and it is the inequality signs rather than the numbers that settle every case like this.

## Card 14 — question_and_answer (`fl_ccHb9W5YBqHfHHH2`)

**FRONT**

Grouping a frequency table hides the individual data values. Why does that mean you can only give a modal **class**?


**BACK**

Because the table records only how many values fell in each class and never which values they were, so there is no way to tell which single value occurred most often.

The most that can be said is **which class** the data is concentrated in, and that class is called the **modal class**.


Spec links: `spcpt_vwSXjzQnpHNyGzdC`


## Card 15 — question_and_answer (`fl_RFYPwtBMPXXkKSkJ`)

**FRONT**

When estimating the mean from a grouped frequency table, what value do you use for each class, and what does that assume?


**BACK**

Use the **midpoint** of each class, which is the mean of its lower and upper boundaries, and then work exactly as you would for an ungrouped table.

This assumes that the values within each class average out at its **midpoint**, which they need not do.

A grouped table has classes $10 \leq x \leq 19$ and $20 \leq x \leq 29$, leaving a gap between them. Complete the boundaries once the gap has been closed:

`\_\_\_\_\_\_ \le x < 19.5 \text{ and } 19.5 \le x < \_\_\_\_\_\_`


**BACK**

The completed boundaries are:

$9 . 5 \leq x < 19 . 5 \text{and} 19 . 5 \leq x < 29 . 5$

The boundaries move to the **halfway points** because the data has been rounded, so a value recorded as 19 could really be anything up to 19.5.

Closing the gap matters because a value of 19.4 would otherwise belong to no class at all.

## Card 17 — keyword_definition (`fl_Wrvfc97HG4nx3qbT`)

**FRONT**

Define the **standard deviation** of a set of data.


**BACK**

The **standard deviation**, written $σ$, measures how **spread out** the values in a data set are about the mean.

A data set whose values cluster close together has a small standard deviation, and one whose values are widely scattered has a large one.


Spec links: `spcpt_qjZJ2vYM9CxGVG6V`


## Card 18 — fill_in_the_blanks (`fl_PqRHrkxY9n3CDJDc`)

**FRONT**

Complete the formula for the variance of $n$ data values with mean $\overline{x}$:

`\sigma^{2} = \frac{\_\_\_\_\_\_}{n} - \left(\bar{x}\right)^{2}`


**BACK**

The completed formula is:

`\sigma^{2} = \frac{\Sigma x^{2}}{n} - \left(\bar{x}\right)^{2}`

$Σ x^{2}$ is the sum of the **squares** of the data values, which is not the same thing as `\left(\Sigma x\right)^{2}`, the square of their sum.

This is the useful form because the two totals $Σ x$ and $Σ x^{2}$ are enough to find the standard deviation without knowing a single individual value.

## Card 19 — question_and_answer (`fl_Bw2MFBh8dxMvTXgf`)

**FRONT**

What are the units of the variance, and what are the units of the standard deviation?


**BACK**

The **standard deviation** is in the same units as the data itself, while the **variance** is in those units **squared**.

So a set of times measured in minutes has, for example, a variance of $10 . 4 \text{minutes}^{2}$ and a standard deviation of $3 . 23 \text{minutes}$.


Spec links: `spcpt_qjZJ2vYM9CxGVG6V`


## Card 20 — true_or_false (`fl_DXvvSYdSK2znzJws`)

**FRONT**

**True or False?**

A data set with a variance of 16 has a standard deviation of 16.


**BACK**

**False.**

The standard deviation is the **square root** of the variance, so a variance of 16 gives a standard deviation of $\sqrt{16} = 4$.

This is why the two are written $σ$ and $σ^{2}$: the symbols themselves record that one is the square of the other.

## Card 21 — question_and_answer (`fl_FzBn8W5gKZrCkP4F`)

**FRONT**

The variance can also be written as `\frac{\Sigma \left(x - \bar{x}\right)^{2}}{n}`. What does this form show about what the variance measures?


**BACK**

It shows that the variance is the **mean of the squared deviations** from the mean: each value's distance from the mean is squared, and those squares are then averaged.

Written this way it is slow to calculate, because it needs the mean first and then a separate subtraction for every value in the data set.

## Card 22 — question_and_answer (`fl_jPfZ6vsj5wN5hkYr`)

**FRONT**

The variance has more than one formula. What decides which one you can use?


**BACK**

**What the question supplies** decides it. If you are given the individual data values then either form will work.

If you are given only the totals and not the values themselves, the form built from those totals is the **only** one available.

## Card 23 — keyword_definition (`fl_S7pCwhh2Zmrbj2rZ`)

**FRONT**

Define an **assumed mean**.


**BACK**

An **assumed mean** is a convenient value that is subtracted from every value in a data set before the statistics are calculated.

It is usually chosen as an easy round number close to where the true mean is expected to lie, and the data is then said to have been **coded**.


Spec links: `spcpt_MQD5Vhs7yhyZGTMm`


## Card 24 — question_and_answer (`fl_Vt722fGtdhBRgChM`)

**FRONT**

What is the point of coding a data set before calculating with it?


**BACK**

Coding replaces awkward numbers with much smaller and simpler ones, which makes the arithmetic quicker and less error-prone.

It is most useful when the data consists of very large or very small numbers, such as volumes all close to 150 ml, where the coded values come out as small numbers instead.


Spec links: `spcpt_MQD5Vhs7yhyZGTMm`


## Card 25 — true_or_false (`fl_6Pq7f46jvg5Tt2b2`)

**FRONT**

**True or False?**

Subtracting the same number from every value in a data set leaves the standard deviation unchanged.


**BACK**

**True.**

Subtracting a constant slides every value along by the same amount, so the values sit exactly as far apart from one another as they did before, and a measure of spread cannot detect a shift.

## Card 26 — question_and_answer (`fl_fhchMXqBRtxXfK9t`)

**FRONT**

In a sample of 20 cups of coffee, `\Sigma \left(c - 150\right) = -16`, where $c$ ml is the volume of a cup. Find the mean volume.


**BACK**

The mean of the **coded** values is $\frac{-16}{20} = - 0 . 8$, so on average a cup holds 0.8 ml less than the assumed mean of 150 ml.

Adding the 150 back gives a mean volume of

$\overline{c} = 150 - 0 . 8 = 149 . 2 \text{ml}$

## Card 27 — question_and_answer (`fl_QSXbQyHQzsHvFtRV`)

**FRONT**

A data set is coded using $y = a x + b$. How is the standard deviation of the coded data related to the standard deviation of the original?


**BACK**

They are related by

`\sigma_{y} = \vert a \vert \sigma_{x}`

so the coded standard deviation is the original one multiplied by the size of the multiplier $a$.

The modulus is needed because a negative multiplier reverses the order of the data, but a measure of spread can never come out negative.


Spec links: `spcpt_MQD5Vhs7yhyZGTMm`


## Card 28 — question_and_answer (`fl_4D7kRqpRXc33QVGP`)

**FRONT**

The mean of some coded data $y = a x + b$ is $\overline{y}$. How do you get back to the mean $\overline{x}$ of the original data?


**BACK**

Reverse the coding, undoing the addition first and then the multiplication:

$\overline{x} = \frac{\overline{y}-b}{a}$

The mean is a measure of **location**, so whatever was done to every data value has been done to the mean as well, and can simply be undone.
