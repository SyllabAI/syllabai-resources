What is a **function**?


**BACK**

A **function **is a combination of **one or more mathematical operations** that takes a **set of numbers** and **changes** them into **another set of numbers**.



## Card 2 — keyword_definition (`fl_rcVyvY65nNnpWgz5`)

**BACK**

The notation  $\mathrm{f} ( x ) =...$  indicates a function $f$, where $x$ is the input and $\mathrm{f} ( x )$ is the output.

## Card 5 — question_and_answer (`fl_ywjmJczH63nV9Tj8`)

**FRONT**

How would you find the value of $\mathrm{f} ( 3 )$ for a function $\mathrm{f} ( x )$?


**BACK**

To find the value of $\mathrm{f} ( 3 )$ for a function $\mathrm{f} ( x )$, substitute $x=3$ into the equation of the function.

For example, if $f(x)=2x+1$, then $\mathrm{f} ( 3 ) = 2 ( 3 ) + 1 = 6 + 1 = 7$.



## Card 6 — question_and_answer (`fl_R5fyrVcwpPMkf3ks`)

**FRONT**

How would you find the value of $x$ if you knew that $\mathrm{f} ( x ) = 15$?


**BACK**

To find the value of $x$ if you know that $\mathrm{f} ( x ) = 15$:

- Set the equation for $\mathrm{f} ( x )$ equal to 15
- Then solve for $x$

For example, if $\mathrm{f} ( x ) = 2 x + 1$ and $\mathrm{f} ( x ) = 15$, then

$2x+1=15\Rightarrow2x=14\Rightarrowx=7$

## Card 10 — true_or_false (`fl_bF5GwzXqd6bn5bpp`)

**FRONT**

**True or false?**

The function $\mathrm{f} ( x ) = x^{2}$ with **domain** "all values of $x$" also has a** range** which is "all values of $x$".


**BACK**

**False.**

Whether $x$ is positive or negative, $\mathrm{f} ( x ) = x^{2}$ can **only ever be positive or zero**.

The domain is 'all values of $x$' and the range is $\mathrm{f} ( x ) \ge 0$.

## Card 12 — keyword_definition (`fl_XJXYF8P6HsT52x7C`)

**BACK**

A **composite function** is a function that 'combines' two functions.

The output of one function is used as the input for the other function.



## Card 13 — keyword_definition (`fl_GyCy5tCYC5ZqJj23`)

**FRONT**

What does the notation $fg ( x )$ mean?


**BACK**

$fg ( x )$ is the notation for a composite function made up of functions $f$ and $g$.

It means "$f$ is applied to the output of $\mathrm{g} ( x )$".

I.e., **first** put $x$ into the function $g$, and **next** put the output $\mathrm{g} ( x )$ into the function $f$.

Note that the function on the right ($g$) acts first, and the function on the left ($f$) acts second.

## Card 18 — question_and_answer (`fl_gPqqm39YvDWS7rmy`)

**FRONT**

What are the **steps** to find the **inverse function** $\mathrm{f}^{- 1} ( x )$ of $\mathrm{f} ( x )$?


**BACK**

To find $\mathrm{f}^{- 1} ( x )$:

1. Write $\mathrm{f} ( x )$ as $y = ( \text{formula} in x )$.
2. Swap $x$ and $y$ to get $x = ( \text{formula} in y )$.
3. Rearrange to make $y$ the subject.
4. Replace $y$ with $\mathrm{f}^{- 1} ( x )$to rewrite as $\mathrm{f}^{- 1} ( x ) =...$.



## Card 19 — question_and_answer (`fl_r92tdny8rG5fPwG4`)

**FRONT**

If you knew that $\mathrm{f} ( 3 ) = 10$, how would you find $\mathrm{f}^{- 1} ( 10 )$?


**BACK**

An inverse function 'undoes' the operations of the original function.

So if $f$ turns 3 into 10, then $f^{-1}$ turns 10 back into 3.

I.e., if $\mathrm{f} ( 3 ) = 10$, then $\mathrm{f}^{- 1} ( 10 ) = 3$.



## Card 20 — question_and_answer (`fl_mTDWrfv2VsqVsNQY`)

**FRONT**

What is $ff^{- 1} ( x )$ **equal **to?


**BACK**

$ff^{- 1} ( x )$ is a **composite function** of $f$ and its **inverse** $f^{-1}$.

An inverse function 'undoes' the operations of the original function (and vice versa).

So $ff^{- 1} ( x ) = x$.

(Note that $\mathrm{f}^{- 1} \mathrm{f} ( x ) = x$ as well.)
