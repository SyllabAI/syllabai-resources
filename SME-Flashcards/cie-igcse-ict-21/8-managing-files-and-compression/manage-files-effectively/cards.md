## Card 1 — keyword_definition (`fl_KrDPC8PywcNrthxb`)

**FRONT**

Define **file format**.


**BACK**

A file format is the **file type used to store the data in a file**. It defines the **structure and organisation** of the data and determines **which software can read** it.

**FRONT**

**BACK**

A **.txt** file stores **plain, human-readable text** with no formatting, while an **.rtf** file stores **formatted text** with different styles, fonts, colours and images. A .txt file takes up **less memory**.
