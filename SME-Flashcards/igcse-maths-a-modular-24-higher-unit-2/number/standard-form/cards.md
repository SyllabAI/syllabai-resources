## Card 1 — question_and_answer (`fl_s9yPTzr6SQgdVh32`)

**FRONT**

What does a number written in **standard form** look like?


**BACK**

A number in **standard form** looks like $a\times10^{n}$, e.g. $5.2\times10^{3}$.

It is a number between 1 and 10 multiplied by a power of ten.



## Card 2 — question_and_answer (`fl_Gv3BKfCzZfpTCG2P`)

**FRONT**

When a number is written in **standard form** $a\times10^{n}$, which **values** can $a$ be?


**BACK**

For $a\times10^{n}$, $a$ is **at least 1 and less than 10**, $1\leqa<10$.

This means there is one non-zero digit before the decimal point.



## Card 3 — true_or_false (`fl_GsD8YFVymGPFPMWG`)

**FRONT**

**True or False? **

When a number is written in **standard form** $a\times10^{n}$, $n$ can be a fraction.


**BACK**

**False.**

For a number written in standard form, $a\times10^{n}$, the value $n$ must be an **integer**.

It can be zero, positive or negative.



## Card 4 — question_and_answer (`fl_xy9z6h9hYbyJGSKg`)

**FRONT**

When a value **between 0 and 1**, is written in standard form $a\times10^{n}$, what **type of number** will $n$ be?


**BACK**

If a value is between 0 and 1 then when it is written in standard form, $n$ will be a **negative integer**.

E.g. 0.083 would be written as 8.3 x 10<sup>-2</sup>.
