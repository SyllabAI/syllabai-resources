## Card 2 — question_and_answer (`fl_w3zJdCRRfQtfjGPf`)

**FRONT**

How do you **construct** a **two-way table **from information given in words?


**BACK**

1. Identify the two characteristics, e.g. favourite colours, gender
2. Use rows for one characteristic and columns for the other
3. Add an extra row and column for marginal totals

|   | Red | Blue | Yellow | ***Total*** |
|---|---|---|---|---|
| Male |   |   |   |   |
| Female |   |   |   |   |
| ***Total*** |   |   |   |   |

## Card 6 — keyword_definition (`fl_MsdBktyTXktCRRvD`)

**FRONT**

Define a **set**.


**BACK**

A **set** is a collection of **elements**, which may be numbers, letters, coordinates or anything else.

Its elements are listed inside curly brackets, so the factors of 6 form the set `\left\{ 1 , 2 , 3 , 6 \right\}`.

## Card 10 — question_and_answer (`fl_mvkGs5xQcGNkVvZ2`)

**FRONT**

What does $A \cap B$ mean?


**BACK**

The **intersection** of $A$ and $B$, which is the set of elements that are in **both** sets.

On a Venn diagram it is the region where the two circles **overlap**.

## Card 11 — question_and_answer (`fl_kXsRcTPTpjZqv3by`)

**FRONT**

What does $A \cup B$ mean?


**BACK**

The **union** of $A$ and $B$, which is the set of elements in **at least one** of the sets.

This includes everything in the overlap, but each element is written only once.

## Card 19 — keyword_definition (`fl_3h6HfZj6B5KtJvSm`)

**FRONT**

Define a **probability tree diagram**.


**BACK**

A **probability tree diagram** shows the outcomes of two or more experiments in order, with a **probability written on each branch**.

Each complete path from left to right represents one combined outcome.


Spec links: `spcpt_bJdV9RcZkPsy79k8`


## Card 20 — question_and_answer (`fl_BMg3J4BDJ7XfvmDr`)

**FRONT**

How do you use a tree diagram to find the probability of a particular pair of outcomes?


**BACK**

**Multiply** the probabilities along the branches of that path, working from left to right.

If more than one path gives what you want, work each path out separately and then **add** the results together.

**FRONT**

**True or False?**

A tree diagram for two experiments, each with two outcomes, has four complete paths.


**BACK**

**True.**

Each of the two first-stage branches splits into two, giving $2 \times 2 = 4$ complete paths.

Every possible combined outcome is one of those four.

## Card 25 — question_and_answer (`fl_fbNfPzPkGWjP6jKx`)

**FRONT**

What does **AND** mean for combined probabilities?


**BACK**

**AND** means **multiply** ($\times$) and is used for **independent events** to find the **probability of both events **occurring.

E.g. the probability of events A **and** B occurring is $\mathrm{P} ( A ) \\times \mathrm{P} ( B )$.



## Card 26 — question_and_answer (`fl_zBZJ2Xqdgd8cVkjC`)

**FRONT**

What does **OR** mean for combined probabilities?


**BACK**

**OR** means **add** (+) and is used for **mutually exclusive** **events** to find the **probability of one event or the other event **occurring.

E.g. the probability of either event *A* and/or event *B* occurring is $\mathrm{P} ( A ) + \mathrm{P} ( B )$.

The **sum of all probabilities** is **1**.

## Card 28 — keyword_definition (`fl_QgdQS2gvBbGgT97Q`)

**FRONT**

State the** equation** for the probability of** two independent events**, $A$ and $B$, occurring together.


**BACK**

If $A$ and $B$ are **independent events**, then the probability of both events occurring is:

`P ( A and B ) = P ( A ) x P ( B )`.



## Card 29 — keyword_definition (`fl_ZMk2W4VkKp2BvfW7`)

**FRONT**

State the **equation** for the probability of one or the other of **two mutually exclusive events**, $A$ and $B$, occurring.


**BACK**

If $A$ and $B$ are **mutually exclusive events**, then the probability of one or the other of them occurring is:

$\mathrm{P} ( A \text{or} B ) = \mathrm{P} ( A ) + \mathrm{P} ( B )$.
