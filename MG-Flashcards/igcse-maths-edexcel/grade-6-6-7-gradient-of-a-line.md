## Card 1 — `basic`

**Front:** What does the gradient of a straight line measure?

**Back:** The steepness of the line (how much $y$ changes for each increase of 1 in $x$).

**Choices:**

- The steepness of the line (how much $y$ changes for each increase of 1 in $x$). ✔
  - _why:_ Gradient measures the rate at which $y$ changes as $x$ increases. A larger gradient magnitude means the straight line is steeper.
- The height of the line (the value of $y$ where the line crosses the $y$-axis).
  - _why:_ The value where a line crosses the $y$-axis is its $y$-intercept, not its gradient. Gradient measures steepness through the change in $y$ per unit change in $x$.
- The length of the line (the distance between the two endpoints of the line segment).
  - _why:_ Length measures the distance between two points and depends on both coordinate changes. Gradient instead measures steepness by comparing the vertical change with the horizontal change.
- The position of the line (how far the line is from the origin of the graph).
  - _why:_ A line’s position relative to the origin does not determine its gradient. Parallel lines can occupy different positions while sharing the same steepness and gradient.

## Card 2 — `basic`

**Front:** State the simple formula for gradient using vertical and horizontal change.

**Back:** $$$\text{gradient} = \frac{\text{rise}}{\text{run}}$$

**Choices:**

- $$$\text{gradient} = \frac{\text{rise}}{\text{run}}$$ ✔
  - _why:_ The rise is the vertical change and the run is the horizontal change. Dividing rise by run gives the change in $y$ for each unit change in $x$.
- $$$\text{gradient} = \frac{\text{run}}{\text{rise}}$$
  - _why:_ This reverses the numerator and denominator, producing the reciprocal of the gradient. The correct formula divides the vertical change, or rise, by the horizontal change, or run.
- $$$\text{gradient} = \text{rise} \times \text{run}$$
  - _why:_ Multiplying the coordinate changes does not measure the line’s rate of change. Gradient is a ratio, so the rise must be divided by the run.
- $$$\text{gradient} = \text{rise} + \text{run}$$
  - _why:_ Adding the changes does not compare vertical movement with horizontal movement. The gradient is calculated using the ratio $\frac{\text{rise}}{\text{run}}$.

## Card 3 — `basic`

**Front:** When finding the gradient from a graph, how should you choose your two points?

**Back:** Pick points where the line passes exactly through grid intersections.

**Choices:**

- Pick points where the line passes exactly through grid intersections. ✔
  - _why:_ Grid intersections give coordinates that can be read accurately. Using two such points on the line reduces estimation errors when calculating rise and run.
- Pick points that are close to the line at grid intersections.
  - _why:_ Nearby grid intersections cannot be used unless the line actually passes through them. The correct method is to choose two grid intersections lying exactly on the line.
- Pick points where the line is nearest to the coordinate axes.
  - _why:_ Distance from the coordinate axes does not make a point suitable. Choose points where the line passes exactly through grid intersections so their coordinates are precise.
- Pick points that lie halfway between two grid intersections.
  - _why:_ Halfway positions are harder to read accurately and can introduce estimation errors. Points where the line passes exactly through grid intersections should be chosen instead.

## Card 6 — `basic`

**Front:** How can you tell if a line has a positive gradient just by looking at a graph?

**Back:** The line slopes upwards from left to right.

**Choices:**

- The line slopes upwards from left to right. ✔
  - _why:_ As $x$ increases from left to right, $y$ also increases. Therefore the rise and run have the same sign, giving a positive gradient.
- The line slopes downwards from left to right.
  - _why:_ When a line slopes downwards from left to right, $y$ decreases as $x$ increases, so its gradient is negative. A positive-gradient line slopes upwards.
- The line stays horizontal from left to right.
  - _why:_ A horizontal line has no vertical change, so its rise and gradient are both zero. A positive-gradient line must slope upwards from left to right.
- The line slopes upwards from right to left.
  - _why:_ Sloping upwards from right to left means the line slopes downwards when viewed from left to right, giving a negative gradient rather than a positive one.

## Card 7 — `basic`

**Front:** How can you tell if a line has a negative gradient just by looking at a graph?

**Back:** The line slopes downwards from left to right.

**Choices:**

- The line slopes downwards from left to right. ✔
  - _why:_ As $x$ increases from left to right, $y$ decreases. A positive run combined with a negative rise gives a negative gradient.
- The line slopes upwards from left to right.
  - _why:_ When a line slopes upwards from left to right, $y$ increases as $x$ increases, giving a positive gradient. A negative-gradient line slopes downwards.
- The line stays horizontal from left to right.
  - _why:_ A horizontal line has a rise of zero, so its gradient is zero rather than negative. A negative-gradient line slopes downwards from left to right.
- The line slopes downwards from right to left.
  - _why:_ Sloping downwards from right to left means the line slopes upwards when viewed from left to right, so its gradient is positive rather than negative.

## Card 8 — `basic`

**Front:** What is the common mistake when calculating the rise of a line that slopes downwards?

**Back:** Counting the vertical change as positive instead of negative.

**Choices:**

- Counting the vertical change as positive instead of negative. ✔
  - _why:_ Moving from left to right along a downward-sloping line makes $y$ decrease, so the rise is negative. Treating it as positive incorrectly produces a positive gradient.
- Counting the vertical change as negative instead of positive.
  - _why:_ For a downward-sloping line measured from left to right, the vertical change should be negative. The common error is wrongly recording this fall as a positive rise.
- Counting the vertical change as zero instead of negative.
  - _why:_ A zero vertical change applies only to a horizontal line. The usual mistake for a downward-sloping line is treating the negative vertical change as positive.
- Counting the horizontal change as negative instead of positive.
  - _why:_ This concerns the run rather than the rise. When working from left to right, the run is positive, while the common rise error is ignoring its negative sign.

## Card 9 — `cloze`

**Back:** If a line goes up 1 square for every 3 squares it moves to the right, its gradient is $\boxed{\frac{1}{3}}$.

**Choices:**

- $$\frac{1}{3}$ ✔
  - _why:_ Gradient is rise divided by run. The line rises by 1 square while moving 3 squares right, so its gradient is $\frac{1}{3}$.
- $$-\frac{1}{3}$
  - _why:_ A negative gradient would mean the line falls as it moves from left to right. This line rises, so rise over run gives $\frac{1}{3}$.
- $$3$
  - _why:_ This reverses rise and run by calculating run divided by rise. Gradient is rise divided by run, giving $\frac{1}{3}$ rather than $3$.
- $$-3$
  - _why:_ This both reverses rise and run and assigns the wrong sign. The line rises to the right, so its gradient is positive and equals $\frac{1}{3}$.

## Card 10 — `basic`

**Front:** State the coordinate formula for gradient between $(x_1, y_1)$ and $(x_2, y_2)$.

**Back:** $$$\text{gradient} = \frac{y_2 - y_1}{x_2 - x_1}$$

**Choices:**

- $$$\text{gradient} = \frac{y_2 - y_1}{x_2 - x_1}$$ ✔
  - _why:_ Gradient is the change in the $y$-coordinates divided by the corresponding change in the $x$-coordinates, with the points subtracted in the same order.
- $$$\text{gradient} = \frac{x_2 - x_1}{y_2 - y_1}$$
  - _why:_ This reverses the fraction and calculates run divided by rise. Gradient must be change in $y$ divided by change in $x$: $\frac{y_2-y_1}{x_2-x_1}$.
- $$$\text{gradient} = \frac{y_2 + y_1}{x_2 + x_1}$$
  - _why:_ Adding coordinates does not measure the change between two points. Subtract corresponding coordinates in a consistent order to obtain $\frac{y_2-y_1}{x_2-x_1}$.
- $$$\text{gradient} = \frac{y_2 - y_1}{x_1 - x_2}$$
  - _why:_ The numerator and denominator use opposite subtraction orders here, incorrectly changing the sign. Both differences must follow the same point order: $\frac{y_2-y_1}{x_2-x_1}$.

## Card 11 — `basic`

**Front:** What is the consistency rule when using the coordinate formula $\frac{y_2 - y_1}{x_2 - x_1}$?

**Back:** The order of points must be the same for both the top and bottom (e.g. if you start with $y_2$, you must start with $x_2$).

**Choices:**

- The order of points must be the same for both the top and bottom (e.g. if you start with $y_2$, you must start with $x_2$). ✔
  - _why:_ Using the same point order preserves the correct sign because both coordinate differences describe movement in one consistent direction between the two points.
- The smaller coordinate must come first for both the top and bottom (e.g. if $y_1$ is smaller, you must start with $x_1$).
  - _why:_ Starting with the smaller coordinate is unnecessary and may produce inconsistent subtraction orders. The same point must come first in both the $y$-difference and the $x$-difference.
- The second point must always come first for both the top and bottom (e.g. you must start with $y_2$ and then start with $x_2$).
  - _why:_ The second point does not always have to come first; either point may be chosen first. What matters is using that same order in both coordinate differences.
- The order of points must be opposite for the top and bottom (e.g. if you start with $y_2$, you must start with $x_1$).
  - _why:_ Opposite subtraction orders introduce an incorrect negative sign. If the numerator starts with $y_2$, the denominator must start with $x_2$, not $x_1$.

## Card 12 — `basic`

**Front:** What is the gradient of any horizontal line?

**Back:** 0

**Choices:**

- 0 ✔
  - _why:_ A horizontal line has no vertical change, so its rise is zero. Dividing zero by any non-zero horizontal run gives a gradient of 0.
- 1
  - _why:_ A gradient of 1 means the line rises one unit for every unit moved right. A horizontal line has zero rise, so its gradient is 0.
- Undefined
  - _why:_ Undefined gradient applies to a vertical line because its horizontal change is zero. A horizontal line has zero vertical change, so its gradient is 0.
- -1
  - _why:_ A gradient of -1 describes a line falling one unit for every unit moved right. A horizontal line neither rises nor falls, giving a gradient of 0.

## Card 13 — `basic`

**Front:** Why is the gradient of a vertical line considered undefined/not allowed?

**Back:** The change in $x$ is 0, and you cannot divide by zero.

**Choices:**

- The change in $x$ is 0, and you cannot divide by zero. ✔
  - _why:_ Every pair of points on a vertical line has the same $x$-coordinate, making the run zero. The gradient calculation would therefore require division by zero.
- The change in $y$ is 0, and you cannot divide by zero.
  - _why:_ Zero change in $y$ describes a horizontal line, whose gradient is 0. A vertical line instead has zero change in $x$, causing division by zero.
- The changes in $x$ and $y$ are equal, and the gradient must be 1.
  - _why:_ Equal changes in $x$ and $y$ would produce a gradient of 1, not an undefined gradient. A vertical line has zero change in $x$.
- The line has no $y$-intercept, and every line must cross the $y$-axis.
  - _why:_ A line does not need a $y$-intercept for its gradient to exist. Vertical gradients are undefined specifically because the change in $x$ is zero.

## Card 16 — `basic`

**Front:** Calculate the gradient of the line passing through $(-2, -3)$ and $(0, 5)$.

**Back:** 4 (Rise is $5 - (-3) = 8$; Run is $0 - (-2) = 2$; $\frac{8}{2} = 4$)

**Choices:**

- 4 (Rise is $5 - (-3) = 8$; Run is $0 - (-2) = 2$; $\frac{8}{2} = 4$) ✔
  - _why:_ The rise is $5-(-3)=8$ and the run is $0-(-2)=2$. Dividing rise by run gives $\frac{8}{2}=4$.
- -4 (Rise is $-3 - 5 = -8$; Run is $0 - (-2) = 2$; $\frac{-8}{2} = -4$)
  - _why:_ This sign error comes from reversing only the $y$-subtraction while leaving the $x$-subtraction unchanged. Both differences need the same order, giving a positive gradient of 4.
- 2 (Rise is $5 - 3 = 2$; Run is $0 - (-2) = 2$; $\frac{2}{2} = 2$)
  - _why:_ This treats subtracting the negative coordinate as ordinary subtraction. Since $5-(-3)=5+3=8$, the rise is 8 and the gradient is 4.
- $$\frac{1}{4}$ (Rise is $5 - (-3) = 8$; Run is $0 - (-2) = 2$; $\frac{2}{8} = \frac{1}{4}$)
  - _why:_ This calculates run divided by rise, reversing the gradient formula. Gradient is rise divided by run, so the correct calculation is $\frac{8}{2}=4$.

## Card 20 — `basic`

**Front:** The line through $A(3, -2)$ and $B(7, k)$ has gradient 4. Outline the steps to find $k$.

**Back:** Set up the formula: $4 = \frac{k - (-2)}{7 - 3}$Simplify: $4 = \frac{k + 2}{4}$Solve: $16 = k + 2$, so $k = 14$

**Choices:**

- Set up the formula: $4 = \frac{k - (-2)}{7 - 3}$Simplify: $4 = \frac{k + 2}{4}$Solve: $16 = k + 2$, so $k = 14$ ✔
  - _why:_ Substituting both points into $m=\frac{y_2-y_1}{x_2-x_1}$ gives $4=\frac{k+2}{4}$. Multiplying by 4 and subtracting 2 gives $k=14$.
- Set up the formula: $4 = \frac{k - 2}{7 - 3}$Simplify: $4 = \frac{k - 2}{4}$Solve: $16 = k - 2$, so $k = 18$
  - _why:_ The numerator contains $k-(-2)$, not $k-2$; subtracting a negative gives $k+2$. Therefore $16=k+2$, so the correct value is $k=14$.
- Set up the formula: $4 = \frac{k - (-2)}{3 - 7}$Simplify: $4 = \frac{k + 2}{-4}$Solve: $-16 = k + 2$, so $k = -18$
  - _why:_ The $x$-coordinates were reversed while the $y$-coordinates were not, incorrectly changing the gradient’s sign. Using the same subtraction order gives $4=\frac{k+2}{4}$ and $k=14$.
- Set up the formula: $4 = \frac{k - (-2)}{7 + 3}$Simplify: $4 = \frac{k + 2}{10}$Solve: $40 = k + 2$, so $k = 38$
  - _why:_ The run is the difference $7-3=4$, not the sum $7+3=10$. Thus $4=\frac{k+2}{4}$, which leads to the correct value $k=14$.

## Card 21 — `basic`

**Front:** The line through $(-1, 6)$ and $(k, 18)$ has gradient 3. Outline the steps to find $k$.

**Back:** Set up the formula: $3 = \frac{18 - 6}{k - (-1)}$Simplify: $3 = \frac{12}{k + 1}$Solve: $3(k + 1) = 12 \rightarrow k + 1 = 4$, so $k = 3$

**Choices:**

- Set up the formula: $3 = \frac{18 - 6}{k - (-1)}$Simplify: $3 = \frac{12}{k + 1}$Solve: $3(k + 1) = 12 \rightarrow k + 1 = 4$, so $k = 3$ ✔
  - _why:_ The vertical change is $12$ and the horizontal change is $k+1$. Solving $3=\frac{12}{k+1}$ gives $k+1=4$, so $k=3$.
- Set up the formula: $3 = \frac{18 - 6}{k - 1}$Simplify: $3 = \frac{12}{k - 1}$Solve: $3(k - 1) = 12 \rightarrow k - 1 = 4$, so $k = 5$
  - _why:_ The horizontal change is $k-(-1)=k+1$, because subtracting a negative becomes addition. Solving $3=\frac{12}{k+1}$ gives the correct value $k=3$.
- Set up the formula: $3 = \frac{18 + 6}{k - (-1)}$Simplify: $3 = \frac{24}{k + 1}$Solve: $3(k + 1) = 24 \rightarrow k + 1 = 8$, so $k = 7$
  - _why:_ The rise is the difference between the $y$-coordinates, $18-6=12$, not their sum. Using $12$ gives $k+1=4$, so the correct value is $k=3$.
- Set up the formula: $3 = \frac{k - (-1)}{18 - 6}$Simplify: $3 = \frac{k + 1}{12}$Solve: $36 = k + 1 \rightarrow k + 1 = 36$, so $k = 35$
  - _why:_ This reverses the gradient formula by dividing the run by the rise. Gradient is rise over run, so $3=\frac{12}{k+1}$ and the correct value is $k=3$.
