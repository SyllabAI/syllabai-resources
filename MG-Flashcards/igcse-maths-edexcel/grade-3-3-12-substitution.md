## Card 1 — `basic`

**Front:** What does it mean to evaluate an expression?

**Back:** Find its numerical value by substituting given numbers.

**Choices:**

- Find its numerical value by substituting given numbers. ✔
  - _why:_ Evaluating means replacing the variables with the given numbers and carrying out the operations to obtain a numerical result.
- Find its simplest form by collecting like terms.
  - _why:_ Collecting like terms simplifies an expression but does not evaluate it. Evaluation requires substituting the given numbers and calculating the resulting numerical value.
- Find each unknown value by solving the expression.
  - _why:_ Solving is used to find an unknown in an equation, whereas evaluating an expression means substituting given numbers and calculating its numerical value.
- Expand all brackets without substituting any numbers.
  - _why:_ Expanding brackets may simplify an expression, but it does not evaluate it. Evaluation requires substituting the given numbers and completing the calculation.

## Card 4 — `basic`

**Front:** What is the hidden operation in the expression $4d$?

**Back:** Multiplication ($4 \times d$)

**Choices:**

- Multiplication ($4 \times d$) ✔
  - _why:_ When a number and a variable are written next to each other, multiplication is implied. Therefore, $4d$ means $4 \times d$.
- Addition ($4 + d$)
  - _why:_ Addition requires a visible plus sign, so $4+d$ would be written explicitly. Juxtaposition in $4d$ represents multiplication, meaning $4 \times d$.
- Exponentiation ($4^d$)
  - _why:_ An exponent must be shown as a raised power, as in $4^d$. Writing $4d$ places the factors side by side and means $4 \times d$.
- Division ($4 \div d$)
  - _why:_ Division requires a fraction bar or division symbol. With the number and variable adjacent, $4d$ instead represents multiplication: $4 \times d$.

## Card 6 — `basic`

**Front:** What is the value of $3f + 2g$ if $f = 6$ and $g = 4$?

**Back:** $3(6) + 2(4)$$18 + 8 = 26$

**Choices:**

- $3(6) + 2(4)$$18 + 8 = 26$ ✔
  - _why:_ Substituting $f=6$ and $g=4$ gives $3(6)+2(4)$. Multiplying before adding produces $18+8=26$.
- $3 + 6 + 2 + 4$$9 + 6 = 15$
  - _why:_ This treats each coefficient and variable value as separate addends instead of multiplying them. Correct substitution gives $3(6)+2(4)=18+8=26$.
- $3(6) + 2(4)$$18 + 6 = 24$
  - _why:_ The substitution is correct, but $2 \times 4$ has been miscalculated as $6$ rather than $8$. The correct total is $18+8=26$.
- $3(4) + 2(6)$$12 + 12 = 24$
  - _why:_ The assigned values have been swapped: $f$ is $6$ and $g$ is $4$. Correct substitution gives $3(6)+2(4)=26$.

## Card 8 — `basic`

**Front:** What is a common notation habit to prevent errors when substituting negative numbers?

**Back:** Put the negative number in brackets (e.g., $4(-3)$).

**Choices:**

- Put the negative number in brackets (e.g., $4(-3)$). ✔
  - _why:_ Brackets preserve the negative number as one substituted value and make any adjacent multiplication clear. For example, substituting $-3$ into $4x$ gives $4(-3)$.
- Write the negative number without brackets (e.g., $4-3$).
  - _why:_ Writing $4-3$ changes the intended multiplication into subtraction. The negative value should remain grouped in brackets, giving $4(-3)$.
- Put only the number in brackets (e.g., $4-(3)$).
  - _why:_ Writing $4-(3)$ represents subtracting positive $3$, rather than clearly substituting $-3$ as a factor. The reliable notation is $4(-3)$.
- Replace the negative number with its absolute value (e.g., $4(3)$).
  - _why:_ Using the absolute value removes the negative sign and changes the result’s sign. Keep the negative value intact inside brackets, as in $4(-3)$.

## Card 14 — `cloze`

**Front:** When substituting a negative value into $x^2$, the result is always [ ___ ] because $(-x) \times (-x) = x^2$.

**Back:** When substituting a negative value into $x^2$, the result is always positive because $(-x) \times (-x) = x^2$.

**Choices:**

- positive ✔
  - _why:_ Squaring means multiplying a number by itself. Two negative factors produce a positive product, so the square of any non-zero negative value is positive.
- negative
  - _why:_ This keeps only one negative sign instead of multiplying two of them. Squaring a negative value gives a positive product because a negative multiplied by a negative is positive.
- zero
  - _why:_ A negative value does not become zero when squared. Multiplying the negative number by itself produces a positive result; only substituting zero would give a square of zero.
- unchanged
  - _why:_ Squaring does not generally leave a negative value unchanged; it multiplies the value by itself. The two negative signs cancel, making the resulting square positive.

**Back:** When substituting a negative value into $x^2$, the result is always positive because $\boxed{(-x) \times (-x) = x^2}$.

**Choices:**

  - _why:_ A square means multiplying a value by itself. When that value is negative, both factors are negative, and their product is positive: $(-x)(-x)=x^2$.

  - _why:_ This incorrectly retains a negative sign after multiplying two negative factors. Their signs cancel, so the correct relationship is $(-x) \times (-x)=x^2$.

  - _why:_ This confuses squaring with adding a value to itself. A square is formed by multiplication, so the correct statement is $(-x) \times (-x)=x^2$.
- $$(-x) \times x = x^2$
  - _why:_ This uses one negative and one positive factor, whose product would be negative. Squaring the negative value requires two identical factors: $(-x) \times (-x)=x^2$.

**Back:** In a formula, the fraction line means divide by.

**Choices:**

## Card 20 — `basic`

**Front:** How do you evaluate a formula with a large fraction bar?

**Back:** Calculate the numerator and denominator separately before dividing.

**Choices:**

- Calculate the numerator and denominator separately before dividing. ✔
  - _why:_ The fraction bar groups everything above it and everything below it. Evaluating those two grouped expressions first ensures that the complete numerator is divided by the complete denominator.
- Calculate the numerator and denominator separately before subtracting.
  - _why:_ Subtracting the denominator from the numerator treats the fraction bar as a minus sign. Instead, calculate both grouped parts separately and divide the numerator by the denominator.
- Calculate the whole expression from left to right without grouping.
  - _why:_ Working strictly from left to right can ignore the grouping created by a large fraction bar. Calculate the whole numerator and denominator separately, then perform the division.
- Calculate the numerator and denominator separately before multiplying.
  - _why:_ Multiplying the two parts confuses a fraction bar with multiplication. After evaluating the complete numerator and denominator separately, the numerator must be divided by the denominator.

## Card 21 — `basic`

**Front:** Evaluate $s = \frac{v^2 - u^2}{2a}$ when $v = 8, u = 4, a = 2$.

**Back:** $\frac{8^2 - 4^2}{2(2)} = \frac{64 - 16}{4}$$\frac{48}{4} = 12$

**Choices:**

- $\frac{8^2 - 4^2}{2(2)} = \frac{64 - 16}{4}$$\frac{48}{4} = 12$ ✔
  - _why:_ Squaring gives $8^2=64$ and $4^2=16$, while the denominator is $2(2)=4$. Therefore $s=(64-16)/4=48/4=12$.
- $\frac{8^2 - 4^2}{2(2)} = \frac{64 - 8}{4}$$\frac{56}{4} = 14$
  - _why:_ Replacing $4^2$ with $8$ doubles $4$ instead of squaring it. Since $4^2=16$, the correct numerator is $48$ and $s=48/4=12$.
- $\frac{8^2 + 4^2}{2(2)} = \frac{64 + 16}{4}$$\frac{80}{4} = 20$
  - _why:_ Adding the squared values changes the subtraction in the numerator into addition. The formula requires $64-16=48$, so dividing by $4$ gives $s=12$.
- $\frac{8^2 - 4^2}{2(2)} = \frac{64 - 16}{2}$$\frac{48}{2} = 24$
  - _why:_ Evaluating $2(2)$ as $2$ ignores one factor of $2$ and halves the denominator. The denominator is $4$, so the correct result is $48/4=12$.

## Card 23 — `basic`

**Front:** Why should you write the substituted expression before calculating in an exam?

**Back:** To earn method marks even if the final arithmetic is wrong.

**Choices:**

- To earn method marks even if the final arithmetic is wrong. ✔
  - _why:_ Showing the substituted expression demonstrates that the correct formula and values were used. Examiners can therefore award method marks even if a later arithmetic error changes the answer.
- To earn presentation marks even if the final method is wrong.
  - _why:_ Method marks reward a valid mathematical process, not neat handwriting alone. Writing the substituted expression shows the intended method and can gain marks despite a later arithmetic error.
- To ensure all values are positive before the final calculation.
  - _why:_ Substitution can include negative values, which should be enclosed in brackets rather than changed to positive values. Its purpose is to show the method and secure method marks.
- To guarantee accurate arithmetic during the final calculation.
  - _why:_ Writing an extra expression does not guarantee that arithmetic will be correct. It records the method clearly, allowing method marks to be awarded even when the final calculation is wrong.
