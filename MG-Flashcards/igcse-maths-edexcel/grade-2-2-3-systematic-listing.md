## Card 1 — `cloze`

**Front:** Systematic listing puts outcomes in a clear order so none are [ ___ ] or [ ___ ].

**Back:** Systematic listing puts outcomes in a clear order so none are missing or repeated.

**Choices:**

- Systematic listing puts outcomes in a clear order so none are missing or repeated. ✔
  - _why:_ A clear, consistent order ensures every possible outcome appears exactly once, preventing outcomes from being accidentally omitted or counted more than once.
- Systematic listing puts outcomes in a clear order so none are missing or counted.
  - _why:_ Outcomes need to be counted, so counting them is not a problem to avoid. Systematic listing ensures that none are missing or repeated.
- Systematic listing puts outcomes in a clear order so none are listed or repeated.
  - _why:_ Listing outcomes is the purpose of the method, not an error. The ordered approach ensures that no outcomes are missing or repeated.
- Systematic listing puts outcomes in a clear order so none are included or checked.
  - _why:_ Outcomes should be included and checked as part of a complete list. The two errors systematic listing prevents are missing outcomes and repeated outcomes.

## Card 2 — `basic`

**Front:** What pattern should you use when listing outcomes from two groups?

**Back:** Fix the first choice, then pair it with every second choice.

**Choices:**

- Fix the first choice, then pair it with every second choice. ✔
  - _why:_ Keeping the first choice fixed while working through every second choice creates an organised list. Repeating this for each first choice includes every possible pairing once.
- Alternate between both choices, then remove any repeated pairs.
  - _why:_ Alternating choices can produce an unordered list in which combinations are missed or repeated. Fix the first choice, then pair it with every second choice.
- Fix the second choice, then pair it with one first choice.
  - _why:_ Pairing with only one first choice omits valid combinations. The intended pattern is to fix the first choice and pair it with every second choice.
- Choose the first pair, then reverse it for every new pair.
  - _why:_ Reversing pairs does not systematically combine all members of the two groups. Fix each first choice in turn and pair it with every second choice.

## Card 3 — `basic`

**Front:** How many meal combinations are there with 4 starters and 3 mains?

**Back:** 12 combinations.

**Choices:**

- 12 combinations. ✔
  - _why:_ Each of the 4 starters can be paired with each of the 3 mains, so the multiplication principle gives $4 \times 3 = 12$ combinations.
- 7 combinations.
  - _why:_ Adding $4+3$ counts the available dishes, not the possible pairings. Each starter pairs with three mains, giving $4 \times 3 = 12$ combinations.
- 16 combinations.
  - _why:_ This treats the meal as if there were 4 choices in both groups. There are only 3 mains, so the total is $4 \times 3 = 12$.
- 24 combinations.
  - _why:_ This double-counts each starter-and-main meal, usually by treating its order as variable. A starter followed by a main gives $4 \times 3 = 12$ combinations.

## Card 4 — `basic`

**Front:** Why are HHT and HTH different outcomes?

**Back:** The tails is on a different flip.

**Choices:**

- The tails is on a different flip. ✔
  - _why:_ In HHT, the tail occurs on the third flip, while in HTH it occurs on the second flip. Their ordered sequences are therefore different.
- The tails is on the same flip.
  - _why:_ The tail is third in HHT but second in HTH, so it is not on the same flip. Its different position makes the outcomes distinct.
- The number of tails is different.
  - _why:_ Both outcomes contain exactly one tail, so the number of tails does not distinguish them. They differ because the tail occurs on a different flip.
- The first flip is different in each outcome.
  - _why:_ Both HHT and HTH begin with heads, so their first flips are identical. They differ because the tail occurs on the third flip in HHT and the second in HTH.

## Card 5 — `cloze`

**Front:** For coin flips, each extra flip [ ___ ] the number of outcomes.

**Back:** For coin flips, each extra flip doubles the number of outcomes.

**Choices:**

- doubles ✔
  - _why:_ Each existing sequence can be extended with either heads or tails. This creates two new outcomes from every previous outcome, so the total doubles.
- triples
  - _why:_ Tripling would require three possible results on each extra flip. A coin has only two results, heads and tails, so each extra flip doubles the outcomes.
- halves
  - _why:_ An extra flip creates more possible sequences rather than reducing them. Each existing outcome gains a heads version and a tails version, so the total doubles.
- squares
  - _why:_ The total follows powers of 2 because every flip has two possible results. Adding one flip multiplies the previous number by 2 rather than squaring it.

## Card 6 — `basic`

**Front:** How many outcomes are there when a coin is flipped three times?

**Back:** 8 outcomes.

**Choices:**

- 8 outcomes. ✔
  - _why:_ Each of the three flips has 2 possible results, so the multiplication principle gives $2 \times 2 \times 2 = 2^3 = 8$ outcomes.
- 6 outcomes.
  - _why:_ Multiplying the 3 flips by 2 ignores that choices combine across every stage. The correct calculation is $2^3=8$ outcomes.
- 9 outcomes.
  - _why:_ The calculation $3^2$ reverses the number of flips and the choices per flip. There are 2 choices on each of 3 flips, giving $2^3=8$.
- 16 outcomes.
  - _why:_ Sixteen is $2^4$, which is the number of outcomes for four flips. Three flips have $2^3=8$ possible ordered outcomes.

## Card 7 — `cloze`

**Front:** The [ ___ ] is the complete list of all possible outcomes for an experiment.

**Back:** The sample space is the complete list of all possible outcomes for an experiment.

**Choices:**

- sample space ✔
  - _why:_ A sample space contains every possible outcome of an experiment. For example, the sample space for one coin flip is the complete list H and T.
- outcome
  - _why:_ An outcome is one possible result, not the complete collection of results. The list containing all possible outcomes is called the sample space.
- event
  - _why:_ An event is a selected outcome or group of outcomes of interest. The complete list of every possible outcome is the sample space.
- frequency table
  - _why:_ A frequency table records how often observed results occur, rather than defining every possible result. The complete list of possibilities is the sample space.

## Card 8 — `basic`

  - _why:_ A physical card is normally unavailable after it has been selected. It can be selected again only when the question explicitly permits replacement or reuse.

## Card 9 — `cloze`

**Front:** In a two-digit number, the first digit is the [ ___ ] digit and the second is the [ ___ ] digit.

**Back:** In a two-digit number, the first digit is the tens digit and the second is the units digit.

**Choices:**

- In a two-digit number, the first digit is the tens digit and the second is the units digit. ✔
  - _why:_ The first digit represents a multiple of ten, while the second represents the remaining individual units. For example, in 47, 4 is tens and 7 is units.
- In a two-digit number, the first digit is the hundreds digit and the second is the units digit.
  - _why:_ A hundreds digit occurs only in numbers with at least three digits. In a two-digit number, the first digit is the tens digit and the second is the units digit.
- In a two-digit number, the first digit is the tens digit and the second is the hundreds digit.
  - _why:_ Place values increase when moving left, not right. In a two-digit number, the first digit is the tens digit and the second is the units digit.
- In a two-digit number, the first digit is the units digit and the second is the tens digit.
  - _why:_ This reverses the place values. Reading from left to right, a two-digit number has its tens digit first and its units digit second.

## Card 11 — `basic`

**Front:** How many three-digit numbers can 3 different digit cards make if all are used?

**Back:** 6 numbers.

**Choices:**

- 6 numbers. ✔
  - _why:_ There are 3 choices for the first digit, then 2 choices for the second and 1 for the third, giving $3 \times 2 \times 1 = 6$.
- 3 numbers.
  - _why:_ This counts only one arrangement for each choice of first digit. The remaining two cards can be swapped, so there are $3 \times 2 = 6$ numbers.
- 8 numbers.
  - _why:_ This incorrectly treats each position as having two independent choices. Using all three different cards once gives $3! = 3 \times 2 \times 1 = 6$ numbers.
- 9 numbers.
  - _why:_ This comes from multiplying 3 choices by 3 choices without removing used cards. The choices reduce after each position, giving $3 \times 2 \times 1 = 6$.

## Card 12 — `basic`

**Front:** What is a systematic method for making three-digit numbers from three cards?

**Back:** Fix the hundreds digit.Arrange the other two digits both ways.

**Choices:**

- Fix the hundreds digit.Arrange the other two digits both ways. ✔
  - _why:_ Holding one card in the hundreds place and swapping the remaining cards produces both arrangements for that starting digit. Repeating this for each card lists all six numbers.
- Fix the hundreds digit.Keep the other two digits in one order.
  - _why:_ Keeping only one order misses the number formed by swapping the tens and units digits. The other two cards must be arranged both ways for each hundreds digit.
- Change the hundreds digit randomly.Arrange the other two digits one way.
  - _why:_ Random choices can cause repetitions and omissions, while using only one order misses further numbers. Fix each hundreds digit systematically and arrange the other two cards both ways.
- Fix the hundreds digit.Repeat one of the other two digits.
  - _why:_ Repeating a digit uses a card more than once and leaves another card unused. Instead, arrange the two remaining cards both ways without repetition.

## Card 13 — `basic`

**Front:** Why does swapping two identical digit cards not create a new number?

**Back:** The written number looks the same.

**Choices:**

- The written number looks the same. ✔
  - _why:_ Identical digits have the same value and appearance, so exchanging their physical cards does not alter any digit position in the written number or create a new outcome.
- The written number becomes one greater.
  - _why:_ Swapping identical digits does not change the number’s value at all. The written number remains the same, so the swap cannot be counted as a new arrangement.
- The digits change their values.
  - _why:_ Moving identical digit cards cannot change their values because both display the same digit. The written number looks unchanged, so no new number has been produced.
- The number gains an extra digit.
  - _why:_ A swap changes only the positions of existing cards and cannot add another digit. With identical cards, even the written arrangement looks exactly the same.

## Card 14 — `basic`

**Front:** How many different four-digit numbers can be made from 1, 4, 4 and 7?

**Back:** 12 different numbers.

**Choices:**

- 12 different numbers. ✔
  - _why:_ Four cards would give $4! = 24$ arrangements, but swapping the two identical 4s creates no new number. Dividing by $2!$ gives $24 \div 2 = 12$.
- 24 different numbers.
  - _why:_ This treats the two 4 cards as distinguishable and counts each written number twice. Dividing $4! = 24$ by $2!$ gives 12 different numbers.
- 6 different numbers.
  - _why:_ This divides by too large a factor, as though more than two cards were identical. Only the two 4s are interchangeable, so $24 \div 2 = 12$.
- 16 different numbers.
  - _why:_ This results from using an inappropriate power calculation rather than counting permutations. There are $4!$ arrangements divided by $2!$ for the repeated 4, giving 12.

## Card 15 — `cloze`

**Front:** For equally likely outcomes, probability = [ ___ ] / [ ___ ].

**Back:** For equally likely outcomes, probability = number of successful outcomes / total number of outcomes.

**Choices:**

- For equally likely outcomes, probability = number of successful outcomes / total number of outcomes. ✔
  - _why:_ Probability compares the number of outcomes satisfying the event with the total number of possible equally likely outcomes. This produces a value between 0 and 1.
- For equally likely outcomes, probability = total number of outcomes / number of successful outcomes.
  - _why:_ This reverses the fraction and can produce a value greater than 1. Probability is successful outcomes divided by the total number of equally likely outcomes.
- For equally likely outcomes, probability = number of unsuccessful outcomes / total number of outcomes.
  - _why:_ This calculates the probability of the event not happening, which is the complementary probability. The required probability uses the number of successful outcomes as the numerator.
- For equally likely outcomes, probability = total number of outcomes / number of unsuccessful outcomes.
  - _why:_ This both reverses the required ratio and counts unsuccessful rather than successful outcomes. Probability is the number of successful outcomes divided by the total number of outcomes.

## Card 16 — `basic`

  - _why:_ Each die has 6 possible results, and every result on the first die can pair with every result on the second. Therefore, $6 \times 6 = 36$ outcomes.
- 12 outcomes.
  - _why:_ This adds the two sets of 6 results instead of pairing them. Since each first-die result combines with 6 second-die results, there are $6 \times 6 = 36$ outcomes.

  - _why:_ There are 11 possible totals from 2 to 12, but these totals are not equally likely. Counting ordered pairs of die results gives 36 equally likely outcomes.
- 6 outcomes.
  - _why:_ This counts the possible results of only one die. With two dice, each of the 6 first-die results pairs with 6 second-die results, giving 36 outcomes.

## Card 18 — `basic`

**Front:** What is the probability that two fair dice have a total greater than 7?

**Back:** $\frac{5}{12}$.

**Choices:**

- $\frac{5}{12}$. ✔
  - _why:_ Totals greater than 7 are 8, 9, 10, 11 and 12, giving 5 + 4 + 3 + 2 + 1 = 15 outcomes out of 36, which simplifies to $\frac{5}{12}$.
- $\frac{7}{12}$.
  - _why:_ This counts totals greater than or equal to 7, including the six outcomes making 7. Excluding 7 leaves 15 favourable outcomes out of 36, giving the correct probability $\frac{5}{12}$.
- $\frac{1}{2}$.
  - _why:_ The totals are not equally likely, so simply dividing the possible totals above 7 incorrectly gives one half. Listing ordered outcomes gives 15 favourable outcomes out of 36, or $\frac{5}{12}$.
- $\frac{11}{36}$.
  - _why:_ This is one outcome too few: totals 8 to 12 have 5, 4, 3, 2 and 1 outcomes, respectively, totalling 15. The probability is therefore $\frac{15}{36}=\frac{5}{12}$.

## Card 20 — `basic`

**Front:** Box A has 1, 4, 7 and Box B has 3, 6, 9. What is the probability of an odd product?

**Back:** $\frac{4}{9}$.

**Choices:**

- $\frac{4}{9}$. ✔
  - _why:_ An odd product requires two odd factors. Box A has 2 odd numbers and Box B has 2, so there are $2\times2=4$ favourable pairs out of $3\times3=9$.
- $\frac{5}{9}$.
  - _why:_ This overcounts the favourable pairs, probably by treating the even number in one box as contributing an additional odd-product case. Only odd-odd pairs work, giving $2\times2=4$ out of 9, or $\frac{4}{9}$.
- $\frac{2}{9}$.
  - _why:_ This counts only one set of odd choices and forgets that either odd number in Box A can pair with either odd number in Box B. There are 4 favourable pairs, so the probability is $\frac{4}{9}$.
- $\frac{1}{3}$.
  - _why:_ This treats the three possible numbers in one box as equally relevant without counting ordered pairs. Systematic listing gives 4 odd-odd pairs among 9 total pairs, so the correct probability is $\frac{4}{9}$.

## Card 22 — `basic`

**Front:** For finishing positions, does order matter?

**Back:** Yes - each different order is a different outcome.

**Choices:**

- Yes - each different order is a different outcome. ✔
  - _why:_ Finishing positions are ordered: first, second and third are distinct positions. Therefore, changing which competitor finishes in each position creates a different outcome.
- No - all orders represent the same outcome.
  - _why:_ This confuses finishing positions with an unordered selection. In a race or ranking, positions have different meanings, so each different order is a different outcome.
- Yes - only the competitors matter, not their positions.
  - _why:_ The competitors alone are not enough to describe finishing results. Their positions determine the order, so each different order is a different outcome.
- No - order matters only when competitors tie.
  - _why:_ Order matters whenever competitors are assigned distinct finishing positions, not only when there is a tie. A change in first, second or later positions creates a different outcome.
