## Card 1 — `basic`

**Front:** On a cumulative frequency graph, which specific value from a class interval is plotted on the horizontal axis?

**Back:** The upper bound.

**Choices:**

- The upper bound. ✔
  - _why:_ Each point shows how many observations lie below a class’s upper boundary, so the upper bound is paired with the cumulative frequency for that class.
- The lower bound.
  - _why:_ The lower bound is used only for the initial zero-frequency point. Each subsequent cumulative frequency is plotted against the corresponding class’s upper bound.
- The class midpoint.
  - _why:_ Class midpoints are commonly used for frequency polygons, not cumulative frequency graphs. A cumulative frequency point is plotted at each class interval’s upper bound.
- The class width.
  - _why:_ Class width measures the size of an interval and is not a horizontal coordinate here. Cumulative frequencies are plotted against the class intervals’ upper bounds.

## Card 2 — `cloze`

**Front:** Cumulative frequency represents a [ ___ ] of the frequencies as you move down a table.

**Back:** Cumulative frequency represents a running total of the frequencies as you move down a table.

**Choices:**

- running total ✔
  - _why:_ Each entry adds the current class frequency to all preceding frequencies, producing a running total that increases or remains unchanged down the table.
- running average
  - _why:_ A running average would involve dividing totals by the number of values or groups considered. Cumulative frequency simply forms a running total of frequencies.
- class frequency
  - _why:_ A class frequency counts observations in one interval only. Cumulative frequency adds that count to all earlier class frequencies, forming a running total.
- frequency density
  - _why:_ Frequency density is frequency divided by class width and is used for histograms. Cumulative frequency instead represents a running total of the frequencies.

## Card 3 — `basic`

**Front:** How can you verify that the last entry in a cumulative frequency table is correct?

**Back:** It must equal the total frequency ($n$) of the data set.

**Choices:**

- It must equal the total frequency ($n$) of the data set. ✔
  - _why:_ The final cumulative entry includes every class frequency, so it must count every observation and therefore equal the data set’s total frequency, $n$.
- It must equal the highest class frequency ($n$) of the data set.
  - _why:_ The largest individual class frequency includes only one interval and need not include every observation. The final cumulative entry must equal the total frequency, $n$.
- It must equal the number of class intervals ($n$) of the data set.
  - _why:_ Counting intervals gives the number of groups, not the number of observations. The final cumulative frequency must equal the total frequency, $n$, of the data set.
- It must equal the largest data value ($n$) of the data set.
  - _why:_ The largest data value measures magnitude rather than how many observations there are. The final cumulative entry must equal the total frequency, $n$.

## Card 4 — `basic`

**Front:** Why must a cumulative frequency curve never slope downwards?

**Back:** Cumulative frequency is a running total; since frequencies cannot be negative, the total only increases or stays flat.

**Choices:**

- Cumulative frequency is a running total; since frequencies cannot be negative, the total only increases or stays flat. ✔
  - _why:_ Adding each non-negative class frequency to the previous total can only increase it or leave it unchanged, so a cumulative frequency curve cannot slope downwards.
- Cumulative frequency is a moving average; since averages cannot be negative, the graph only increases or stays flat.
  - _why:_ Averages can rise or fall even when all values are non-negative. The graph cannot slope down because cumulative frequency is a running total of non-negative frequencies.
- Cumulative frequency records each class frequency; since every class has more values than the previous one, the graph only increases or stays flat.
  - _why:_ Successive classes do not necessarily contain increasing numbers of values. The curve is non-decreasing because it displays a running total, not separate class frequencies.
- Cumulative frequency is a running total; if a class has zero frequency, the total must decrease before increasing.
  - _why:_ A zero class frequency adds nothing, so the cumulative total stays flat rather than decreasing. Non-negative frequencies mean the curve can only rise or remain level.

**Back:** When starting a cumulative frequency graph, you should plot a point at the lowest boundary with a cumulative frequency of 0.

**Choices:**

- class midpoint
  - _why:_ A midpoint lies inside a class and is used in representations such as frequency polygons. The cumulative frequency curve starts at the lowest boundary.
- highest boundary
  - _why:_ The highest boundary is paired with the final cumulative frequency, which equals the total number of observations. The graph starts at zero at the lowest boundary.

## Card 7 — `basic`

**Front:** At which cumulative frequency do you find the median if the total frequency is $n$?

**Back:** $$\frac{n}{2}$

**Choices:**

- $$\frac{n}{2}$ ✔
  - _why:_ The median divides the ordered data into two equal halves, so it is located by reading from cumulative frequency $\frac{n}{2}$ across to the curve.
- $$\frac{n}{4}$
  - _why:_ This position identifies the lower quartile, not the median. The median is halfway through the ordered data and is found at cumulative frequency $\frac{n}{2}$.
- $$\frac{3n}{4}$
  - _why:_ This position identifies the upper quartile, not the median. The median divides the data into two equal halves and is found at cumulative frequency $\frac{n}{2}$.
- $$n$
  - _why:_ This is the final cumulative frequency and corresponds to the end of the data set. The median is halfway through, at cumulative frequency $\frac{n}{2}$.

## Card 9 — `basic`

**Front:** How do you estimate the number of data values greater than a specific value $x$ from a graph?

**Back:** Subtract the cumulative frequency at $x$ from the total frequency.

**Choices:**

- Subtract the cumulative frequency at $x$ from the total frequency. ✔
  - _why:_ The cumulative frequency at $x$ counts values up to $x$. Subtracting it from the total frequency therefore estimates how many values are greater than $x$.
- Add the cumulative frequency at $x$ to the total frequency.
  - _why:_ Adding the two frequencies double-counts values up to $x$. The required estimate is found by subtracting the cumulative frequency at $x$ from the total frequency.
- Subtract the total frequency from the cumulative frequency at $x$.
  - _why:_ Reversing the subtraction would usually produce a negative result because cumulative frequency cannot exceed total frequency. Subtract the cumulative frequency at $x$ from the total.
- Divide the cumulative frequency at $x$ by the total frequency.
  - _why:_ Dividing gives a proportion rather than the number of values above $x$. Subtract the cumulative frequency at $x$ from the total frequency to obtain the estimate.

## Card 10 — `cloze`

**Front:** The formula for the interquartile range (IQR) is $IQR = \text{[...]}$.

**Back:** The formula for the interquartile range (IQR) is $IQR = \boxed{Q_3 - Q_1}$.

**Choices:**

- $$Q_3 - Q_1$ ✔
  - _why:_ The interquartile range is the distance between the upper and lower quartiles, so it is calculated by subtracting $Q_1$ from $Q_3$.
- $$Q_3 + Q_1$
  - _why:_ Adding the quartiles does not measure the width of the middle half of the data. The interquartile range is the difference $Q_3 - Q_1$.
- $$Q_1 - Q_3$
  - _why:_ This reverses the subtraction and would make the IQR negative whenever $Q_3>Q_1$. The correct order is upper quartile minus lower quartile: $Q_3-Q_1$.
- $$Q_3 \div Q_1$
  - _why:_ Dividing the quartiles calculates a ratio, not the spread between them. The interquartile range is found using the difference $Q_3 - Q_1$.

## Card 11 — `basic`

**Front:** Why is the interquartile range (IQR) often used instead of the range to describe spread?

**Back:** It measures the middle 50% of data and is less affected by extreme values (outliers).

**Choices:**

- It measures the middle 50% of data and is less affected by extreme values (outliers). ✔
  - _why:_ The IQR ignores the lowest and highest quarters of the ordered data. It therefore describes the central half and is more resistant to unusually extreme observations.
- It measures the entire 100% of data and is more affected by extreme values (outliers).
  - _why:_ The range, not the IQR, uses all data values and is strongly affected by outliers. The IQR measures the middle 50%, making it less sensitive to extremes.
- It measures the outer 50% of data and is more affected by extreme values (outliers).
  - _why:_ The IQR does not focus on the outer quarters, which are precisely where extreme values occur. It measures the middle 50% and is less affected by outliers.
- It measures the middle 50% of data and is unaffected by all data values (observations).
  - _why:_ The IQR is resistant to outliers rather than being unaffected by every data value. Changes within the middle 50% can alter $Q_1$, $Q_3$, and hence the IQR.

## Card 13 — `cloze`

## Card 14 — `basic`

**Front:** When comparing two box plots, what does a higher median value indicate?

**Back:** The average or typical value of that data set is higher.

**Choices:**

- The average or typical value of that data set is higher. ✔
  - _why:_ The median is the central value when the data are ordered. A higher median therefore indicates a higher typical or average value for that distribution.
- The spread or variability of that data set is greater.
  - _why:_ A higher median concerns the centre, not the spread. The IQR or range must be compared to decide whether the values are more widely dispersed.
- The maximum or largest value of that data set is higher.
  - _why:_ The median does not determine the largest observation, so a distribution can have a higher median but a lower maximum. It indicates that the typical value is higher.
- The frequency or number of values in that data set is greater.
  - _why:_ A higher median does not reveal the sample size because frequency and central value are independent. It indicates that the distribution’s typical value is higher.

## Card 15 — `basic`

**Front:** What does a smaller interquartile range (IQR) indicate when comparing two data distributions?

**Back:** The middle 50% of the data is more consistent (less spread out).

**Choices:**

- The middle 50% of the data is more consistent (less spread out). ✔
  - _why:_ The IQR measures the spread of the central half of the ordered data. A smaller IQR means those middle observations occupy a narrower interval and are more consistent.
- The middle 50% of the data is less consistent (more spread out).
  - _why:_ This reverses the interpretation of IQR: a smaller difference between $Q_1$ and $Q_3$ means less spread, so the middle 50% is more consistent.
- The middle 50% of the data is higher overall (greater in value).
  - _why:_ IQR measures spread rather than the level of the data, so it cannot show whether central values are higher. A smaller IQR means the middle 50% is more consistent.
- The outer 50% of the data is more consistent (less extreme overall).
  - _why:_ The IQR describes only the middle half and gives no direct information about how extreme the minimum or maximum is. A smaller IQR indicates greater central consistency.

**Back:** The y-axis (the cumulative frequency axis).

**Choices:**

- The y-axis (the cumulative frequency axis). ✔
  - _why:_ Cumulative frequency is read vertically on the y-axis. Start at the required quartile frequency on that axis, move horizontally to the curve, then move down to the x-axis to read the value.

  - _why:_ Starting on the x-axis reverses the graph-reading process. Begin with the quartile's cumulative frequency on the y-axis, then use the curve to find the corresponding data value.

  - _why:_ A graph's centre has no fixed statistical meaning and will not generally represent a quartile. Use the relevant cumulative frequency on the y-axis to locate the quartile.

**Front:** Why are values read from a cumulative frequency graph considered "estimates"?

**Back:** The curve is a smooth approximation drawn between known data points.

**Choices:**

- The curve is a smooth approximation drawn between known data points. ✔
  - _why:_ Cumulative frequency graphs use a smooth curve to estimate values between the plotted class boundaries. Because the original grouped data is not known exactly within each class, readings are estimates.
- The curve is an exact record of every individual data value.
  - _why:_ Grouped data does not show every individual value, so the curve cannot record them exactly. It is a smooth approximation between known points, making readings estimates.
- The curve is a straight-line calculation joining the class midpoints.
  - _why:_ Cumulative frequency curves are drawn through class boundaries and are usually smooth, not based on joining class midpoints with straight lines. Therefore the readings are smooth-curve estimates.
- The curve is a bar-chart representation of the original frequencies.
  - _why:_ A cumulative frequency graph is not a bar chart of the original class frequencies. Its smooth curve approximates cumulative totals between known points, so values read from it are estimates.
