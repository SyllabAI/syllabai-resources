## Card 1 — `basic`

**Front:** In proportionality equations, what does the letter $k$ represent?

**Back:** The constant of proportionality.

**Choices:**

- The constant of proportionality. ✔
  - _why:_ The value $k$ is the fixed multiplier that connects the two proportional quantities. It remains constant for every corresponding pair of values in the relationship.
- The variable of proportionality.
  - _why:_ The quantities represented by variables may change, but $k$ does not. The correct term is the constant of proportionality because it is the fixed multiplier relating them.
- The gradient of proportionality.
  - _why:_ Although $k$ is also the gradient of a direct proportion graph, its general name in proportionality equations is the constant of proportionality.
- The coefficient of variation.
  - _why:_ A coefficient of variation is a statistical measure and is unrelated to these equations. Here, $k$ is the constant of proportionality linking the proportional quantities.

## Card 2 — `basic`

**Front:** State the standard equation for $y$ being directly proportional to $x$.

**Back:** $$$y = kx$$

**Choices:**

- $$$y = kx$$ ✔
  - _why:_ Direct proportion means that $y$ is obtained by multiplying $x$ by a fixed constant $k$. Therefore, the standard equation is $y=kx$.
- $$$y = \frac{k}{x}$$
  - _why:_ Dividing a constant by $x$ describes inverse proportion, where $y$ decreases as $x$ increases. Direct proportion uses multiplication, so the correct equation is $y=kx$.
- $$$y = x + k$$
  - _why:_ Adding a constant creates a linear relationship with a non-zero intercept, not direct proportion. A direct proportion graph passes through the origin and has equation $y=kx$.
- $$$y = \frac{x}{k}$$
  - _why:_ This incorrectly treats $k$ as a divisor rather than the stated proportionality multiplier. In standard form, direct proportion is written $y=kx$, where $k$ multiplies $x$.

## Card 3 — `basic`

**Front:** List the three general steps for solving any proportionality question.

**Back:** Write the equation using $k$Substitute given values to find $k$Substitute the new value to solve for the missing variable

**Choices:**

- Write the equation using $k$Substitute given values to find $k$Substitute the new value to solve for the missing variable ✔
  - _why:_ A proportionality problem is solved by forming the appropriate equation, using a known pair of values to calculate $k$, then using that constant to find the missing value.
- Write the equation without $k$Substitute given values to find $x$Substitute the new value to solve for the missing variable
  - _why:_ Omitting $k$ loses the fixed relationship between the quantities, and the known values should first determine $k$, not necessarily $x$. The final substitution then finds the missing variable.
- Write the equation using $k$Substitute new values to find $k$Substitute the given value to solve for the missing variable
  - _why:_ The new value cannot determine $k$ when its corresponding variable is unknown. Use the complete given pair to find $k$, then substitute the new value to solve.
- Write the equation using $x$Substitute given values to find $y$Substitute the new value to solve for the constant
  - _why:_ The equation must include $k$, and the known pair is used to find this constant first. Once $k$ is known, the new value determines the missing variable.
