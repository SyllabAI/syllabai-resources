## Card 1 — `basic`

**Front:** What is the structural difference between an expression and an equation?

**Back:** Expression: A mathematical phrase with no equals sign.Equation: Contains an equals sign and can be solved.

**Choices:**

- Expression: A mathematical phrase with no equals sign.Equation: Contains an equals sign and can be solved. ✔
  - _why:_ An expression represents a mathematical quantity and can be simplified, whereas an equation states that two quantities are equal and can be solved for unknown values.
- Expression: Contains an equals sign and can be solved.Equation: A mathematical phrase with no equals sign.
  - _why:_ This reverses the definitions. An expression has no equals sign and is simplified, while an equation contains an equals sign and can be solved.
- Expression: Contains an equals sign but has no variables.Equation: Contains variables but has no equals sign.
  - _why:_ Variables do not determine whether something is an expression or equation. The structural distinction is that an equation has an equals sign, whereas an expression does not.
- Expression: A mathematical statement that can be solved.Equation: A mathematical phrase that can only be simplified.
  - _why:_ This confuses solving with simplifying. Expressions have no equals sign and can be simplified; equations contain an equals sign and can be solved.

## Card 2 — `basic`

**Front:** What is the common mistake when forming an expression for the perimeter of a rectangle?

**Back:** Only adding the length and width once (forgetting there are two of each).

**Choices:**

- Only adding the length and width once (forgetting there are two of each). ✔
  - _why:_ A rectangle has two equal lengths and two equal widths. Adding each dimension only once gives half the perimeter; the required calculation is $2L + 2W$.
- Adding the length and width twice (correctly including the two pairs of equal sides).
  - _why:_ Adding the length and width twice is the correct perimeter method, not the mistake. The mistake is adding each only once and forgetting the second pair of sides.
- Adding all four side lengths once (including both lengths and both widths).
  - _why:_ Adding all four side lengths correctly calculates the perimeter, so this is not an error. The usual mistake is using only $L + W$ and omitting two sides.
- Doubling the length and width separately (then adding the two results).
  - _why:_ Doubling each dimension separately gives $2L + 2W$, which is the correct perimeter. The mistake is counting only one length and one width.

## Card 3 — `basic`

**Front:** What is the simplified formula for the perimeter ($P$) of a rectangle with length $L$ and width $W$?

**Back:** $$P = 2(L + W)$ or $P = 2L + 2W$

**Choices:**

- $$P = 2(L + W)$ or $P = 2L + 2W$ ✔
  - _why:_ A rectangle has two sides of length $L$ and two of width $W$, so its perimeter is $2L + 2W$, equivalent to $2(L + W)$.
- $$P = L + W$ or $P = 1L + 1W$
  - _why:_ This counts only one length and one width, giving half the perimeter. Both dimensions must be counted twice, so $P = 2(L + W)$.
- $$P = 2(LW)$ or $P = 2LW$
  - _why:_ Multiplying length by width uses the area calculation rather than adding boundary lengths. Perimeter counts the four sides, giving $P = 2L + 2W$.
- $$P = 4(L + W)$ or $P = 4L + 4W$
  - _why:_ This doubles both dimensions twice, making the result twice the true perimeter. Each length and width occurs only twice, so $P = 2(L + W)$.
