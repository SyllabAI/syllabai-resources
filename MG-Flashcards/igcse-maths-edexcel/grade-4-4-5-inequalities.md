## Card 1 — `basic`

**Front:** In $x<3$, is 3 included?

**Back:** No - $<$ is strict.

**Choices:**

- No - $<$ is strict. ✔
  - _why:_ A strict inequality excludes its boundary value. Since $x<3$ requires values smaller than 3, the endpoint 3 is not included.
- Yes - $<$ is inclusive.
  - _why:_ This confuses strict and inclusive inequality symbols. The symbol $<$ is strict, so $x<3$ excludes 3; only $cle$ would include the endpoint.
- Yes - $<$ includes the endpoint.
  - _why:_ A common mistake is to treat the boundary as part of every inequality. The symbol $<$ excludes the endpoint, so 3 is not included in $x<3$.
- Yes - 3 is the upper bound.
  - _why:_ Being an upper boundary does not automatically make 3 a permitted value. Because the inequality is strict, $x$ must be less than 3, not equal to it.

## Card 2 — `basic`

**Front:** In $x\le 3$, is 3 included?

**Back:** Yes - $\le$ is inclusive.

**Choices:**

- Yes - $\le$ is inclusive. ✔
  - _why:_ The symbol $\le$ means less than or equal to. Therefore, $x\le 3$ includes 3 as well as every value smaller than 3.
- No - $\le$ is strict.
  - _why:_ This confuses $\le$ with the strict symbol $<$. The equality line means the endpoint is allowed, so 3 is included in $x\le 3$.
- No - $\le$ excludes the endpoint.
  - _why:_ The equality line beneath $<$ specifically includes the endpoint. Therefore, $x\le 3$ allows $x=3$, so 3 is included.
- No - 3 is only an upper bound.
  - _why:_ Although 3 is an upper bound, the equality part of $\le$ makes it an attainable bound. Thus 3 itself is included in the solution set.

## Card 18 — `basic`

**Back:** When multiplying or dividing by a negative number.

**Choices:**

- When multiplying or dividing by a negative number. ✔
  - _why:_ Multiplication or division by a negative number reverses the order of values, so the inequality sign must be reversed to preserve a true statement.
- When adding or subtracting a negative number.
  - _why:_ Adding or subtracting the same negative number preserves the order of both sides. The sign reverses only when multiplying or dividing by a negative number.
- When multiplying or dividing by a positive number.
  - _why:_ A positive multiplier or divisor does not change the order of the values. The inequality sign reverses only for multiplication or division by a negative number.
- When moving a term across an inequality sign.
  - _why:_ Moving a term is shorthand for applying an inverse operation to both sides, so it does not automatically reverse the sign. Reversal occurs when dividing or multiplying by a negative number.
