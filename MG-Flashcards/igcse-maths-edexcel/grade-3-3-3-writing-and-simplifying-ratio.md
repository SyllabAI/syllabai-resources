# Writing and Simplifying Ratio Flashcards

_Lane: `igcse-maths-edexcel` · grade 3 · 20 cards (source: MathsGenie flashcards)_

## Card 1 — `basic`

**Front:** In the ratio $A:B$, why does the order of the numbers matter?

**Back:** It must match the order of words in the question (e.g. "apples to oranges").

**Choices:**

- It must match the order of words in the question (e.g. "apples to oranges"). ✔
  - _why:_ Each number represents the quantity named in the corresponding position. For “apples to oranges”, the number of apples must come first and the number of oranges second.
- It must place the larger number first, regardless of the wording in the question.
  - _why:_ Ratios are not arranged by numerical size. The numbers must follow the order of the words, so “apples to oranges” means apples first and oranges second.
- It must match the order of calculation used to find the two quantities.
  - _why:_ The order in which quantities are calculated does not determine their ratio positions. The correct order comes from the named quantities in the question.
- It must list the smaller number first so the ratio is simplified.
  - _why:_ Putting the smaller number first does not simplify a ratio and may reverse its meaning. The order must match the order of the quantities named.

## Card 2 — `basic`

**Front:** How is a ratio simplified?

**Back:** Divide all parts by the same common factor.

**Choices:**

- Divide all parts by the same common factor. ✔
  - _why:_ Dividing every part by the same common factor creates an equivalent ratio. Using the highest common factor reduces the ratio fully to its simplest form.
- Multiply all parts by the same common factor.
  - _why:_ Multiplication produces an equivalent ratio with larger values rather than simplifying it. Divide every part by the same common factor, ideally the highest common factor.
- Divide one part by the largest common factor.
  - _why:_ Changing only one part alters the relationship between the quantities. Every part must be divided by the same common factor to preserve the ratio.
- Subtract the same common factor from all parts.
  - _why:_ Subtracting equal amounts does not preserve the multiplicative relationship represented by a ratio. Simplification requires dividing all parts by the same common factor.

## Card 3 — `cloze`

**Front:** A ratio is in simplest form when no whole number bigger than [ ___ ] divides exactly into every part.

**Back:** A ratio is in simplest form when no whole number bigger than 1 divides exactly into every part.

**Choices:**

- 1 ✔
  - _why:_ Every whole number is divisible by 1, so this does not allow further simplification. A ratio is simplest when no larger whole number divides every part exactly.
- 0
  - _why:_ Division by 0 is undefined, while every whole number is divisible by 1. The threshold must therefore be 1 when defining whether a ratio is fully simplified.
- 2
  - _why:_ This would wrongly classify ratios whose parts share a factor of 2 as simplest. The correct number is 1 because any common factor greater than 1 permits simplification.
- 10
  - _why:_ This overlooks common factors from 2 to 10, so many reducible ratios would be called simplest. The correct number is 1 because no larger common factor may remain.

## Card 4 — `basic`

**Front:** Simplify the length ratio 420 cm to 30 cm.

**Back:** $$14 : 1$

**Choices:**

- $$14 : 1$ ✔
  - _why:_ Both lengths use centimetres, so divide 420 and 30 by their highest common factor, 30. This gives $420 \div 30 : 30 \div 30 = 14 : 1$.
- $$42 : 3$
  - _why:_ Dividing both values by 10 gives an equivalent ratio, but it is not fully simplified because 42 and 3 share a factor of 3. The simplest ratio is $14 : 1$.
- $$14 : 10$
  - _why:_ This comes from removing a zero from 420 but not applying the same division correctly to 30. Dividing both original parts by 30 gives $14 : 1$.
- $$140 : 1$
  - _why:_ This divides the two parts by different amounts, changing the ratio’s value. Both 420 and 30 must be divided by 30, producing $14 : 1$.

## Card 5 — `basic`

**Front:** When writing a ratio of values (like coins), what must you do first?

**Back:** Multiply the number of items by the value per item to find the total value for each group.

**Choices:**

- Multiply the number of items by the value per item to find the total value for each group. ✔
  - _why:_ A value ratio compares the groups’ total monetary values, not merely their item counts. Multiplying each group’s number of items by its value per item finds those totals.
- Compare the number of items with the value per item without finding the total value of each group.
  - _why:_ This mixes two different quantities: an item count and a monetary value. Calculate each group’s total value by multiplying its number of items by the value per item.
- Add the number of items to the value per item to find the total value for each group.
  - _why:_ Adding a count to a monetary value does not calculate a group’s total worth. The number of items must be multiplied by the value per item.
- Divide the number of items by the value per item to find the total value for each group.
  - _why:_ Division does not give the total value of identical items. Multiply the quantity of items by the value of each item before forming and simplifying the ratio.

## Card 6 — `basic`

**Front:** Calculate the ratio of the value of four 20p coins to three 50p coins.

**Back:** $$8 : 15$

**Choices:**

- $$8 : 15$ ✔
  - _why:_ Four 20p coins are worth 80p, while three 50p coins are worth 150p. The ratio $80 : 150$ simplifies by dividing both parts by 10.
- $$4 : 3$
  - _why:_ This compares the numbers of coins rather than their values. The totals are 80p and 150p, giving $80 : 150 = 8 : 15$.
- $$2 : 5$
  - _why:_ This compares the denominations 20p and 50p but ignores how many coins there are. Using the total values gives $80 : 150 = 8 : 15$.
- $$8 : 5$
  - _why:_ The first total is correctly treated as 80p, but the second part uses one 50p coin rather than three. The correct simplified ratio is $80 : 150 = 8 : 15$.

## Card 7 — `basic`

**Front:** If $\frac{2}{9}$ of a group are left-handed, what is the ratio of left-handed to right-handed students?

**Back:** $$2 : 7$

**Choices:**

- $$2 : 7$ ✔
  - _why:_ The whole group has 9 equal parts, with 2 left-handed parts. The remaining $9 - 2 = 7$ parts are right-handed, giving $2 : 7$.
- $$2 : 9$
  - _why:_ This is the ratio of left-handed students to the whole group, not to right-handed students. Right-handed students make up $9 - 2 = 7$ parts, so the ratio is $2 : 7$.
- $$7 : 2$
  - _why:_ The quantities have been placed in reverse order. There are 2 left-handed parts and 7 right-handed parts, so left-handed to right-handed is $2 : 7$.
- $$2 : 11$
  - _why:_ Adding the numerator and denominator treats the 9 parts as if they exclude the left-handed students. Since 9 represents the whole, the right-handed share is $9 - 2 = 7$.

## Card 8 — `cloze`

**Front:** To write a ratio in the form $n:1$, you must divide both parts by the [ ___ ] part.

**Back:** To write a ratio in the form $n:1$, you must divide both parts by the second part.

**Choices:**

- second ✔
  - _why:_ Dividing both parts by the second part makes that part equal to 1. The first part becomes its value relative to the second, producing the form $n:1$.
- first
  - _why:_ Dividing by the first part makes the first entry equal to 1, producing a ratio in the form $1:n$. For $n:1$, divide by the second part.
- larger
  - _why:_ Dividing by the larger part only gives $n:1$ when the larger value happens to be second. The reliable rule is always to divide by the second part.
- smaller
  - _why:_ Dividing by the smaller part does not necessarily make the second entry equal to 1. To obtain $n:1$, both entries must be divided by the second part.

## Card 9 — `cloze`

**Front:** To write a ratio in the form $1:n$, you must divide both parts by the [ ___ ] part.

**Back:** To write a ratio in the form $1:n$, you must divide both parts by the first part.

**Choices:**

- first ✔
  - _why:_ Dividing both parts by the first part makes the first term equal to 1, leaving the equivalent ratio in the required form $1:n$.
- second
  - _why:_ Dividing by the second part would make the second term equal to 1, producing a ratio in the form $n:1$. The first part is needed for $1:n$.
- larger
  - _why:_ The part chosen does not depend on which term is larger. To make the first term equal to 1, divide both parts by the first part.
- smaller
  - _why:_ Choosing the smaller part is not the rule and may not produce a first term of 1. Divide both parts by the first part instead.

## Card 10 — `basic`

**Front:** Convert the ratio $14 : 35$ into the form $1:n$.

**Back:** $$1 : 2.5$

**Choices:**

- $$1 : 2.5$ ✔
  - _why:_ Divide both terms by 14: $14 \div 14 = 1$ and $35 \div 14 = 2.5$, giving the equivalent ratio $1 : 2.5$.
- $$1 : 2$
  - _why:_ This comes from treating 35 as approximately twice 14 and losing the remaining half. Dividing accurately by 14 gives $1 : 2.5$.
- $$1 : 3.5$
  - _why:_ The second term has been divided by 10 instead of using the first term as the common divisor. Dividing both terms by 14 gives $1 : 2.5$.
- $$2.5 : 1$
  - _why:_ This reverses the ratio, making the second original term correspond to 1. Dividing by the first term keeps the order and gives $1 : 2.5$.

## Card 11 — `basic`

**Front:** Convert the ratio $10.5 : 3.5$ into the form $n:1$.

**Back:** $$3 : 1$

**Choices:**

- $$3 : 1$ ✔
  - _why:_ Divide both terms by 3.5, the second term: $10.5 \div 3.5 = 3$ and $3.5 \div 3.5 = 1$. Therefore the ratio is $3 : 1$.
- $$1 : 3$
  - _why:_ The terms have been reversed after simplifying. Dividing both original terms by 3.5 gives 3 for the first term and 1 for the second, so the answer is $3 : 1$.
- $$3.5 : 1$
  - _why:_ Only the second term has effectively been divided, while the first term has not been simplified. Both terms must be divided by 3.5, giving $3 : 1$.
- $$2 : 1$
  - _why:_ This may result from rounding 10.5 or using an incorrect common divisor. Since $10.5 \div 3.5 = 3$, the simplified ratio is $3 : 1$.

## Card 12 — `basic`

**Front:** In a three-part ratio, there are 3 times as many green pens as black, and 2 times as many red as green. What is the ratio green : black : red?

**Back:** $$3 : 1 : 6$

**Choices:**

- $$3 : 1 : 6$ ✔
  - _why:_ Taking black as 1 part gives green as 3 parts. Red is twice green, so it is 6 parts, producing $3 : 1 : 6$.
- $$3 : 1 : 5$
  - _why:_ The red quantity has been found by adding 2 to green instead of multiplying green by 2. Twice 3 is 6, so the ratio is $3 : 1 : 6$.
- $$1 : 3 : 6$
  - _why:_ The first two parts are reversed, making black appear three times green. The information says green is three times black, so the correct ratio is $3 : 1 : 6$.
- $$3 : 1 : 9$
  - _why:_ The red quantity has been made three times green rather than twice green. With green equal to 3 parts, red must be 6 parts, giving $3 : 1 : 6$.

## Card 13 — `basic`

**Front:** How do you convert a ratio like $1 : 3 : 1.5$ into whole numbers?

**Back:** Multiply every part by 2.

**Choices:**

- Multiply every part by 2. ✔
  - _why:_ Multiplying by 2 changes the decimal part 1.5 into the whole number 3, while preserving the ratio's proportions and making every term an integer.
- Divide every part by 2.
  - _why:_ Dividing by 2 creates smaller values and leaves 0.75 as a decimal. Multiplying by 2 changes 1.5 into 3 and makes all parts whole numbers.
- Add 2 to every part.
  - _why:_ Adding the same number changes the ratios between the parts, so it is not an equivalent ratio. Multiplying every part by 2 preserves the proportions.
- Multiply every part by 1.5.
  - _why:_ This still gives a non-whole value for the first part, 1.5, and changes the useful scaling factor. Multiplying every part by 2 removes the decimal.

## Card 14 — `basic`

**Front:** If 48 people are Year 11, 16 are Year 10, and the total is 96, how many are "the rest" (Year 9)?

**Back:** 32

**Choices:**

- 32 ✔
  - _why:_ The known groups contain $48 + 16 = 64$ people. Subtracting this from the total gives $96 - 64 = 32$ people in Year 9.
- 48
  - _why:_ This subtracts only the Year 10 group from the total and ignores the 48 Year 11 pupils. Subtracting both known groups gives $96 - 48 - 16 = 32$.
- 64
  - _why:_ This is the number of people already assigned to Years 11 and 10, not the remainder. The rest is $96 - (48 + 16) = 32$.
- 80
  - _why:_ This results from subtracting only 16 from 96, leaving out the Year 11 group. Both known groups must be removed, giving $96 - 64 = 32$.

## Card 15 — `cloze`

**Front:** A percentage is calculated by finding a fraction of the total and multiplying by [ ___ ].

**Back:** A percentage is calculated by finding a fraction of the total and multiplying by 100.

**Choices:**

- 100 ✔
  - _why:_ A percentage expresses a fraction out of 100, so multiplying the fraction by 100 converts it into a percentage value.
- 10
  - _why:_ Multiplying by 10 changes a decimal into a value based on tenths, not hundredths. Percentages require multiplication by 100 because percent means per hundred.
- 1,000
  - _why:_ Multiplying by 1,000 would express the fraction per thousand rather than per hundred. The conversion to a percentage uses a factor of 100.
- 1
  - _why:_ Multiplying by 1 leaves the fraction unchanged, so it does not convert it into a percentage. A percentage is found by multiplying the fraction by 100.

## Card 16 — `basic`

**Front:** If a ratio is $6 : 2 : 1$ (green:orange:purple), what fraction of the total is orange?

**Back:** $$\frac{2}{9}$

**Choices:**

- $$\frac{2}{9}$ ✔
  - _why:_ The total number of ratio parts is $6 + 2 + 1 = 9$. Orange accounts for 2 of those parts, so its fraction of the total is $\frac{2}{9}$.
- $$\frac{1}{3}$
  - _why:_ This treats the three colours as equal groups, but their ratio parts are 6, 2 and 1. Orange therefore represents 2 out of 9 parts, or $\frac{2}{9}$.
- $$\frac{2}{7}$
  - _why:_ The purple part has been omitted when finding the total, giving $6 + 1 = 7$. Including all three colours gives 9 parts, so orange is $\frac{2}{9}$.
- $$\frac{1}{9}$
  - _why:_ This uses the single purple part as the numerator instead of the two orange parts. Orange contributes 2 of the 9 total parts, giving $\frac{2}{9}$.

## Card 17 — `cloze`

**Front:** When turning a fraction into a ratio, the [ ___ ] represents the total number of parts.

**Back:** When turning a fraction into a ratio, the denominator represents the total number of parts.

**Choices:**

- denominator ✔
  - _why:_ The denominator states how many equal parts make up the whole, so it becomes the total number of parts when the fraction is expressed as a ratio.
- numerator
  - _why:_ The numerator counts the selected parts, not the total number of parts. The denominator gives the total because it shows how many equal parts form the whole.
- quotient
  - _why:_ A quotient is the result of division, so it does not identify the number of equal parts in the whole. That information is given by the denominator.
- remainder
  - _why:_ A remainder is an amount left over after division, not the total number of equal parts. In a fraction, the denominator represents the total number of parts.

## Card 18 — `basic`

**Front:** Simplify the ratio $84 : 36$ to its simplest form.

**Back:** $$7 : 3$

**Choices:**

- $$7 : 3$ ✔
  - _why:_ The highest common factor of 84 and 36 is 12. Dividing both terms by 12 gives $84 \div 12 : 36 \div 12 = 7 : 3$.
- $$14 : 6$
  - _why:_ Dividing both terms by 6 gives $14 : 6$, but both terms still have a common factor of 2. Dividing again gives the simplest form, $7 : 3$.
- $$21 : 9$
  - _why:_ Dividing both terms by 4 gives $21 : 9$, but both terms remain divisible by 3. The ratio simplifies fully to $7 : 3$.
- $$3 : 7$
  - _why:_ This reverses the order of the ratio after simplifying. Since 84 corresponds to the first term and 36 to the second, the simplest form is $7 : 3$.

## Card 19 — `basic`

**Front:** What is the common mistake when simplifying a ratio like $84 : 36$?

**Back:** Dividing only one side of the ratio.

**Choices:**

- Dividing only one side of the ratio. ✔
  - _why:_ Equivalent ratios are produced by applying the same operation to both terms. Dividing only one side changes the relationship between the quantities rather than simplifying it.
- Dividing both sides equally in the ratio.
  - _why:_ Dividing both terms by the same common factor is the correct method, not the common mistake. The mistake is dividing only one side, which changes the ratio’s value.
- Finding the highest common factor first.
  - _why:_ Finding the highest common factor is an efficient correct strategy because it simplifies the ratio in one step. The common mistake is dividing only one side of the ratio.
- Checking the final ratio cannot simplify.
  - _why:_ Checking that no common factor remains is good practice, not an error. The common mistake is dividing only one side instead of dividing both terms equally.

## Card 20 — `basic`

**Front:** What must you check before writing a ratio between two physical quantities like lengths?

**Back:** Ensure both quantities are in the same units.

**Choices:**

- Ensure both quantities are in the same units. ✔
  - _why:_ A ratio compares quantities directly, so their units must match before the numbers are compared. Converting to the same units produces a valid ratio that can then be simplified.
- Ensure both quantities have the same value.
  - _why:_ Quantities in a ratio do not need equal values; the ratio describes how their values compare. They must instead be converted into the same units before forming the ratio.
- Ensure both quantities use the same scale.
  - _why:_ A shared drawing scale may matter in a diagram, but it is not the essential check for physical quantities. Both measurements must first be expressed in the same units.
- Ensure both quantities have the same precision.
  - _why:_ Matching decimal places or significant figures is not required for writing a ratio. The essential requirement is that both physical quantities are expressed using the same units.
