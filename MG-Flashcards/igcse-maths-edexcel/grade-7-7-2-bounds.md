# Bounds Flashcards

_Lane: `igcse-maths-edexcel` · grade 7 · 3 cards (source: MathsGenie flashcards)_

## Card 1 — `basic`

**Front:** What is the lower bound of a rounded measurement?

**Back:** The smallest possible value the original number could have been before rounding.

**Choices:**

- The smallest possible value the original number could have been before rounding. ✔
  - _why:_ The lower bound is the least value that would round to the stated measurement. It is found by subtracting half the rounding unit from the rounded value.
- The largest possible value the original number could have been before rounding.
  - _why:_ This describes the upper bound rather than the lower bound. The lower bound is the smallest possible original value and is found by subtracting half the rounding unit.
- The smallest rounded value that can be obtained from the original number.
  - _why:_ This reverses the relationship by treating the original number as known. The lower bound is the smallest possible original value that could have produced the given rounded measurement.
- The exact value the original number had before rounding.
  - _why:_ Rounding does not reveal one exact original value; it gives a range of possibilities. The lower bound is the smallest possible value within that range.

## Card 2 — `basic`

**Front:** How is the interval for a rounded value $x$ written using the lower bound ($L$) and upper bound ($U$)?

**Back:** $$L \le x < U$

**Choices:**

- $$L \le x < U$ ✔
  - _why:_ The lower bound is included because it rounds to the stated value, while the upper bound is excluded because it rounds to the next value.
- $$L < x \le U$
  - _why:_ This reverses which endpoint is included. The lower bound is possible but the upper bound is not, so the correct interval is $L \le x < U$.
- $$L \le x \le U$
  - _why:_ Including both endpoints wrongly treats the upper bound as a possible value. The upper bound rounds to the next value, so the correct interval is $L \le x < U$.
- $$L < x < U$
  - _why:_ Excluding both endpoints wrongly removes the lower bound, even though it rounds to the stated measurement. The correct interval is $L \le x < U$.

## Card 3 — `basic`

**Front:** What is the general rule for finding the half-unit to calculate bounds?

**Back:** Halve the size of the unit used for rounding.

**Choices:**

- Halve the size of the unit used for rounding. ✔
  - _why:_ The rounding boundaries lie halfway between consecutive rounded values. Therefore, half the rounding unit is subtracted for the lower bound and added for the upper bound.
- Double the size of the unit used for rounding.
  - _why:_ Doubling the rounding unit makes the interval far too wide. The boundaries are halfway between consecutive rounded values, so the unit used for rounding must be halved.
- Square the size of the unit used for rounding.
  - _why:_ Squaring the rounding unit is unrelated to the midpoint between rounded values and may also change the units. The correct rule is to halve the rounding unit.
- Subtract the size of the unit used for rounding.
  - _why:_ Subtracting a whole rounding unit does not find the distance to both boundaries. First halve the rounding unit, then subtract it for the lower bound and add it for the upper bound.
