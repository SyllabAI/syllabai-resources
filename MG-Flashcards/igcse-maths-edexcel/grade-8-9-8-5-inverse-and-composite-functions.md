## Card 1 — `basic`

**Front:** What is the difference between the domain and the range of a function?

**Back:** Domain: set of allowed input valuesRange: set of possible output values

**Choices:**

- Domain: set of allowed input valuesRange: set of possible output values ✔
  - _why:_ The domain contains every permitted input to the function, while the range contains every output that the function can produce from those inputs.
- Domain: set of possible output valuesRange: set of allowed input values
  - _why:_ This reverses the two definitions. The domain is the set of allowed input values, while the range is the set of possible output values.
- Domain: set of excluded input valuesRange: set of impossible output values
  - _why:_ Domain and range describe values that are allowed or possible, not values that are excluded or impossible. They refer to permitted inputs and resulting outputs respectively.
- Domain: set of possible input valuesRange: set of possible input values
  - _why:_ This treats both sets as inputs. The domain contains allowed input values, but the range contains the possible output values produced by the function.

## Card 2 — `cloze`

**Front:** To find excluded values for a fraction, set the denominator to $\text{[...]}$.

**Back:** To find excluded values for a fraction, set the denominator to $\boxed{\neq 0}$.

**Choices:**

- $$\neq 0$ ✔
  - _why:_ A fraction is defined only when its denominator is non-zero. Values making the denominator zero are therefore excluded from the function’s domain.
- $$=0$
  - _why:_ Setting the denominator equal to zero identifies the values that must be excluded, but the required condition for an allowed denominator is $\neq 0$.
- $$>0$
  - _why:_ A denominator may be positive or negative; it only cannot equal zero. The correct condition for permitted values is therefore $\neq 0$.
- $$\neq 1$
  - _why:_ There is no general restriction preventing a denominator from equalling one. Division fails only when the denominator is zero, so the condition is $\neq 0$.

## Card 3 — `basic`

**Front:** What mathematical condition must be met for values to be included in the domain of $f(x) = \sqrt{x}$?

**Back:** The expression inside the square root must be non-negative ($x \ge 0$).

**Choices:**

- The expression inside the square root must be non-negative ($x \ge 0$). ✔
  - _why:_ For a real-valued square root, the expression under the root cannot be negative. Therefore $\sqrt{x}$ is defined for real $x$ only when $x \ge 0$.
- The expression inside the square root must be positive ($x > 0$).
  - _why:_ This unnecessarily excludes zero. Since $\sqrt{0}=0$ is defined, the expression may equal zero, so the correct condition is $x \ge 0$.
- The expression inside the square root must be non-positive ($x \le 0$).
  - _why:_ This reverses the inequality and includes negative values, whose square roots are not real. The expression must instead be non-negative, giving $x \ge 0$.
- The expression inside the square root must be negative ($x < 0$).
  - _why:_ Negative inputs do not have real square roots, so this condition describes values outside the real domain. The required condition is $x \ge 0$.

## Card 4 — `basic`

**Front:** What value must be excluded from the domain of $p(x) = \frac{6}{x-3}$?

**Back:** $$x = 3$ (because the denominator cannot be zero).

**Choices:**

- $$x = 3$ (because the denominator cannot be zero). ✔
  - _why:_ Substituting $x=3$ makes the denominator $x-3$ equal to zero. Division by zero is undefined, so this value must be excluded.
- $$x = -3$ (because the denominator cannot be zero).
  - _why:_ This sign error comes from solving $x-3=0$ incorrectly. Adding 3 to both sides gives $x=3$, which is the excluded value.
- $$x = 0$ (because the denominator cannot be zero).
  - _why:_ Substituting zero gives a denominator of $-3$, so the fraction remains defined. The denominator becomes zero when $x=3$, which must be excluded.
- $$x = 6$ (because the denominator cannot be zero).
  - _why:_ The numerator does not determine the excluded input. At $x=6$ the denominator is 3; it becomes zero only at $x=3$.

## Card 5 — `cloze`

**Front:** The graph of an inverse function is a reflection of the original function in the line $\text{[...]}$.

**Back:** The graph of an inverse function is a reflection of the original function in the line $\boxed{y=x}$.

**Choices:**

- $$y=x$ ✔
  - _why:_ Finding an inverse swaps every point’s coordinates from $(x,y)$ to $(y,x)$. Geometrically, this is precisely a reflection in the line $y=x$.
- $$y=-x$
  - _why:_ Reflection in $y=-x$ does not simply swap the input and output coordinates. An inverse graph is obtained by reflection in $y=x$.
- $$x=0$
  - _why:_ Reflection in $x=0$, the $y$-axis, changes the sign of each input rather than swapping inputs and outputs. Inverse graphs reflect in $y=x$.
- $$y=0$
  - _why:_ Reflection in $y=0$, the $x$-axis, changes the sign of each output rather than interchanging coordinates. The correct mirror line is $y=x$.

## Card 6 — `basic`

**Front:** How do the domain and range of $f$ relate to the domain and range of $f^{-1}$?

**Back:** The domain of $f$ becomes the range of $f^{-1}$.The range of $f$ becomes the domain of $f^{-1}$.

**Choices:**

- The domain of $f$ becomes the range of $f^{-1}$.The range of $f$ becomes the domain of $f^{-1}$. ✔
  - _why:_ An inverse function reverses the original mapping, so the original inputs become inverse outputs and the original outputs become inverse inputs.
- The domain of $f$ becomes the domain of $f^{-1}$.The range of $f$ becomes the range of $f^{-1}$.
  - _why:_ This incorrectly leaves the sets unchanged. Because an inverse swaps inputs and outputs, the domain and range of the original function exchange roles.
- The domain of $f$ becomes the domain of $f^{-1}$.The range of $f$ becomes the domain of $f^{-1}$.
  - _why:_ This assigns both original sets to the inverse domain. Instead, the range of $f$ becomes the inverse domain, while the domain of $f$ becomes the inverse range.
- The domain of $f$ becomes the range of $f^{-1}$.The range of $f$ becomes the range of $f^{-1}$.
  - _why:_ This assigns both original sets to the inverse range. Only the domain of $f$ becomes the inverse range; the range of $f$ becomes the inverse domain.

## Card 7 — `basic`

**Front:** What is the common mistake regarding the notation $f^{-1}(x)$?

**Back:** Assuming $f^{-1}(x) = \frac{1}{f(x)}$; it is the inverse function, not the reciprocal.

**Choices:**

- Assuming $f^{-1}(x) = \frac{1}{f(x)}$; it is the inverse function, not the reciprocal. ✔
  - _why:_ The superscript $-1$ in function notation means the function that reverses $f$. A reciprocal is written $\frac{1}{f(x)}$ and is generally different.
- Assuming $f^{-1}(x) = -f(x)$; it is the inverse function, not the negative.
  - _why:_ Although the superscript may be mistaken for a negative operation, the classic error is interpreting it as a reciprocal. It denotes the inverse function, not $\frac{1}{f(x)}$.
- Assuming $f^{-1}(x) = f(-x)$; it is the inverse function, not the reflection.
  - _why:_ Replacing $x$ by $-x$ reflects a graph in the $y$-axis and does not find its inverse. The common misconception is treating $f^{-1}(x)$ as $\frac{1}{f(x)}$.
- Assuming $f^{-1}(x) = f(x-1)$; it is the inverse function, not the translation.
  - _why:_ Subtracting one from the input translates the graph and is unrelated to inverse notation. The common mistake is confusing $f^{-1}(x)$ with the reciprocal $\frac{1}{f(x)}$.

## Card 8 — `basic`

**Front:** What are the algebraic steps to find an inverse function?

**Back:** Set $y = f(x)$Swap $x$ and $y$Rearrange to make $y$ the subjectReplace $y$ with $f^{-1}(x)$

**Choices:**

- Set $y = f(x)$Swap $x$ and $y$Rearrange to make $y$ the subjectReplace $y$ with $f^{-1}(x)$ ✔
  - _why:_ An inverse reverses inputs and outputs, so $x$ and $y$ are swapped. Solving for the new output and renaming it gives the inverse function.
- Set $y = f(x)$Swap $x$ and $y$Rearrange to make $x$ the subjectReplace $x$ with $f^{-1}(x)$
  - _why:_ After swapping the variables, the new output is $y$, so $y$ must be isolated. It is then replaced with $f^{-1}(x)$, not $x$.
- Set $y = f(x)$Replace $y$ with $\frac{1}{y}$Rearrange to make $y$ the subjectReplace $y$ with $f^{-1}(x)$
  - _why:_ Taking a reciprocal does not reverse a function’s input-output mapping. The correct process swaps $x$ and $y$, then rearranges to make $y$ the subject.
- Set $y = f(x)$Swap $x$ and $y$Rearrange to make $x$ the subjectReplace $y$ with $f^{-1}(x)$
  - _why:_ This isolates the wrong variable after the swap. To express the inverse as a function of $x$, rearrange for $y$ and then write $f^{-1}(x)$.

## Card 9 — `basic`

**Front:** Define a one-to-one function.

**Back:** A function where each output comes from exactly one input.

**Choices:**

- A function where each output comes from exactly one input. ✔
  - _why:_ This is one-to-one because no two different inputs produce the same output. Consequently, each output in the range can be traced back to exactly one input.
- A function where each input maps to exactly one output.
  - _why:_ This states the general definition of a function, since every function assigns one output to each input. One-to-one additionally requires each output to come from exactly one input.
- A function where every possible output has at least one input.
  - _why:_ This describes an onto function, where every value in the codomain is reached. A one-to-one function instead requires each output in its range to come from exactly one input.
- A function where each output can come from several different inputs.
  - _why:_ This describes a many-to-one function, which is the opposite of one-to-one. In a one-to-one function, different inputs must always produce different outputs.

## Card 10 — `cloze`

**Front:** A function must be [ ___ ] on its domain for its inverse to be a function.

**Back:** A function must be one-to-one on its domain for its inverse to be a function.

**Choices:**

- one-to-one ✔
  - _why:_ A one-to-one function gives different outputs for different inputs, so reversing the mapping assigns exactly one output to every input of the inverse.
- many-to-one
  - _why:_ A many-to-one function sends different inputs to the same output, so its inverse would send one input to several outputs. The original function must be one-to-one.
- onto
  - _why:_ Being onto concerns whether every codomain value is reached, not whether outputs are repeated. The condition needed for the inverse to be a function is one-to-one.
- continuous
  - _why:_ Continuity does not prevent two different inputs from having the same output. An inverse is a function only when the original function is one-to-one on its domain.

## Card 11 — `basic`

**Front:** Why do quadratic functions usually need a restricted domain to have an inverse?

**Back:** Without restriction, they are many-to-one (different inputs can give the same output).

**Choices:**

- Without restriction, they are many-to-one (different inputs can give the same output). ✔
  - _why:_ A full quadratic graph is symmetric about its turning point, so pairs of different inputs can produce the same output. Restricting the domain removes one branch and makes it one-to-one.
- Without restriction, they are one-to-many (one input can give several different outputs).
  - _why:_ A quadratic is still a function, so each input gives only one output; it is not one-to-many. The problem is that different inputs can share an output, making it many-to-one.
- Without restriction, they are undefined at the turning point (the minimum or maximum has no output).
  - _why:_ A quadratic is defined at its turning point, which gives its minimum or maximum value. Restriction is needed because symmetry makes the unrestricted quadratic many-to-one.
- Without restriction, they are always decreasing (larger inputs always give smaller outputs).
  - _why:_ A quadratic generally decreases on one side of its turning point and increases on the other. This creates repeated outputs, so a restricted domain is needed to make it one-to-one.

## Card 12 — `cloze`

**Front:** To find the inverse of a quadratic function, you should first [ ___ ].

**Back:** To find the inverse of a quadratic function, you should first complete the square.

**Choices:**

- complete the square ✔
  - _why:_ Completing the square rewrites the quadratic in turning-point form. This makes it straightforward to swap variables, isolate the squared expression and select the correct square-root branch.
- differentiate the function
  - _why:_ Differentiation can locate the turning point, but it does not rearrange the function into a form suitable for inversion. You should first complete the square.
- factorise the expression
  - _why:_ Factorising is useful for finding roots but usually does not make the inverse easy to isolate. Completing the square exposes the squared term and turning point directly.
- expand the brackets
  - _why:_ Expanding produces standard quadratic form, which hides the structure needed when taking square roots. Completing the square is the useful first step for finding the inverse.

## Card 13 — `basic`

**Front:** If $g(x) = x^2 + 10x + 7$ with domain $x \ge -5$, what is the range of $g^{-1}(x)$?

**Back:** The range is $x \ge -5$ (identical to the domain of the original function).

**Choices:**

- The range is $x \ge -5$ (identical to the domain of the original function). ✔
  - _why:_ The inverse swaps input and output roles, so its range equals the original function’s domain. Since $g$ is restricted to $x \ge -5$, so is the range of $g^{-1}$.
- The range is $x \ge -18$ (identical to the range of the original function).
  - _why:_ Completing the square gives $g(x)=(x+5)^2-18$, so $x \ge -18$ is the domain of the inverse, not its range. Its range is $x \ge -5$.
- The range is $x \le -5$ (the opposite inequality to the original domain).
  - _why:_ This chooses the branch opposite to the stated restriction. The inverse’s range must reproduce the original domain exactly, so the correct inequality is $x \ge -5$.
- The range is $x \ge 5$ (using the positive value of the turning-point input).
  - _why:_ This loses the negative sign in the turning-point input, which is $-5$, not $5$. The inverse’s range equals the original domain, giving $x \ge -5$.

## Card 14 — `basic`

**Front:** How do you decide between the positive or negative square root branch when finding a quadratic inverse?

**Back:** Check the restricted domain of the original function.

**Choices:**

- Check the restricted domain of the original function. ✔
  - _why:_ The restricted domain identifies which side of the quadratic’s turning point is retained. That determines whether the inverse uses the positive or negative square-root branch.
- Always choose the positive square root for the inverse function.
  - _why:_ The positive branch is not automatic; it is used only when it reproduces values in the original restricted domain. The domain determines which square-root sign is valid.
- Check the sign of the quadratic coefficient in the original function.
  - _why:_ The quadratic coefficient determines whether the graph opens upwards or downwards, but not which side is retained. The positive or negative branch is chosen from the restricted domain.
- Check the sign of the constant term in the original function.
  - _why:_ The constant term affects the graph’s vertical position but does not identify the permitted inverse branch. The branch must match the original function’s restricted domain.

## Card 15 — `basic`

**Front:** What does the composite function $fg(x)$ represent?

**Back:** $$f(g(x))$; applying $g$ first, then applying $f$ to the result.

**Choices:**

- $$f(g(x))$; applying $g$ first, then applying $f$ to the result. ✔
  - _why:_ Composition is evaluated from the inside out. The input first enters $g$, and the output produced by $g$ then becomes the input of $f$.
- $$g(f(x))$; applying $f$ first, then applying $g$ to the result.
  - _why:_ This reverses the order and represents $gf(x)$ rather than $fg(x)$. For $fg(x)$, apply $g$ first and then apply $f$ to its output.
- $$f(x)g(x)$; multiplying the outputs of $f$ and $g$ for the same input.
  - _why:_ This is the product of two function values, not a composite function. In $fg(x)$, the output of $g$ is substituted into $f$, giving $f(g(x))$.
- $$f(x)+g(x)$; adding the outputs of $f$ and $g$ for the same input.
  - _why:_ This is the sum of two function values rather than composition. The notation $fg(x)$ here means substitute $g(x)$ into $f$, producing $f(g(x))$.

## Card 16 — `cloze`

**Front:** When calculating a composite function value like $fg(2)$, you work from [ ___ ].

**Back:** When calculating a composite function value like $fg(2)$, you work from right to left.

**Choices:**

- right to left ✔
  - _why:_ In $fg(2)=f(g(2))$, the right-hand function $g$ acts on $2$ first. Its result is then used as the input to the left-hand function $f$.
- left to right
  - _why:_ This reverses the order of composition and would apply $f$ before $g$. For $fg(2)=f(g(2))$, evaluate $g(2)$ first, so work from right to left.
- outside to inside
  - _why:_ Starting with the outer function is impossible until its input has been found. Composite functions are evaluated inside first, which means working from right to left.
- the left-hand function first
  - _why:_ The left-hand function receives the result of the right-hand function, so it cannot be evaluated first. For $fg(2)$, calculate $g(2)$ before applying $f$.

**Back:** $g(1) = 6$$f(6) = \frac{3}{6-2} = \mathbf{\frac{3}{4}}$

**Choices:**

- $g(1) = 6$$f(6) = \frac{3}{6-2} = \mathbf{\frac{3}{4}}$ ✔
  - _why:_ Composition applies $g$ first, giving $g(1)=6$. Substituting this output into $f$ gives $f(6)=3/(6-2)=3/4$.
- $f(1) = -3$$g(-3) = -3+5 = \mathbf{2}$
  - _why:_ This reverses the order and calculates $gf(1)$ instead of $fg(1)$. Applying $g$ first gives 6, then $f(6)=3/4$.
- $g(1) = 6$$f(6) = \frac{3}{6+2} = \mathbf{\frac{3}{8}}$
  - _why:_ This changes the denominator from $x-2$ to $x+2$. Since $g(1)=6$, the correct substitution is $f(6)=3/(6-2)=3/4$.
- $g(1) = 6$$f(6) = \frac{3}{6}-2 = \mathbf{-\frac{3}{2}}$
  - _why:_ This treats the denominator brackets incorrectly, reading $3/(x-2)$ as $3/x-2$. The entire expression $6-2$ is the denominator, giving $3/4$.

## Card 18 — `basic`

**Front:** Is $fg(x)$ always equal to $gf(x)$?

**Back:** No, the order usually changes the result.

**Choices:**

- No, the order usually changes the result. ✔
  - _why:_ Function composition is not generally commutative: $fg(x)$ means $f(g(x))$, whereas $gf(x)$ means $g(f(x))$. Applying the functions in a different order usually changes the result.
- Yes, the order never changes the result.
  - _why:_ Function composition is not generally commutative. Since $fg(x)=f(g(x))$ and $gf(x)=g(f(x))$, changing the order usually changes the result.
- Yes, the same input guarantees the same result.
  - _why:_ Using the same starting input does not guarantee the same final output because the intermediate values can differ. The order of composition usually changes the result.
- Yes, the notation shows the functions are interchangeable.
  - _why:_ The notation indicates which function is applied first; it does not make the functions interchangeable. In general, $f(g(x))$ and $g(f(x))$ produce different results.

## Card 20 — `cloze`

**Front:** In $fg(8)$, the input 8 goes into the function $g$ first, then the output goes into $\text{[...]}$.

**Back:** In $fg(8)$, the input 8 goes into the function $g$ first, then the output goes into $\boxed{f}$.

**Choices:**

- $$f$ ✔
  - _why:_ The notation $fg(8)$ means $f(g(8))$. After 8 is substituted into $g$, the resulting output becomes the input of $f$.
- $$g$
  - _why:_ Applying $g$ again would calculate $g(g(8))$, not $fg(8)$. After $g$ acts on 8, its output must be substituted into $f$.
- $$f^{-1}$
  - _why:_ An inverse is not implied by function composition. In $fg(8)=f(g(8))$, the output from $g$ goes directly into $f$, not into $f^{-1}$.
- $$g^{-1}$
  - _why:_ This would attempt to undo the first function rather than complete the stated composition. After applying $g$, its output must be substituted into $f$.

## Card 21 — `basic`

**Front:** What is the inverse of $f(x) = \frac{4x-7}{3}$?

**Back:** $$f^{-1}(x) = \frac{3x+7}{4}$

**Choices:**

- $$f^{-1}(x) = \frac{3x+7}{4}$ ✔
  - _why:_ Writing $y=(4x-7)/3$ and rearranging gives $3y=4x-7$, then $x=(3y+7)/4$. Swapping variables produces the stated inverse.
- $$f^{-1}(x) = \frac{3x-7}{4}$
  - _why:_ The sign is not changed correctly when rearranging: adding 7 to both sides gives $4x=3y+7$, not $3y-7$. Therefore the inverse is $(3x+7)/4$.
- $$f^{-1}(x) = \frac{4x+7}{3}$
  - _why:_ Changing only the sign of the constant does not reverse the function’s operations. Rearranging $y=(4x-7)/3$ correctly gives the inverse $(3x+7)/4$.
- $$f^{-1}(x) = \frac{3x+7}{3}$
  - _why:_ This divides by the original outer denominator instead of the coefficient of the original input. Rearrangement gives $4x=3y+7$, so the inverse is $(3x+7)/4$.
