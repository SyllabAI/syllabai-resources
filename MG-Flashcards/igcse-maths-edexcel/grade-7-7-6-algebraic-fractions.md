## Card 1 — `basic`

**Front:** What is an excluded value in an algebraic fraction?

**Back:** A value of $x$ that makes the denominator zero.

**Choices:**

- A value of $x$ that makes the denominator zero. ✔
  - _why:_ Division by zero is undefined, so any value of $x$ that makes an algebraic fraction’s denominator zero must be excluded from its domain.
- A value of $x$ that makes the numerator zero.
  - _why:_ Making the numerator zero usually makes the whole fraction zero, provided the denominator is non-zero. An excluded value instead makes the denominator zero.
- A value of $x$ that makes the fraction equal zero.
  - _why:_ A fraction can equal zero when its numerator is zero, and that value may be permitted. An excluded value specifically makes the denominator zero.
- A value of $x$ that makes the denominator equal one.
  - _why:_ A denominator of one is valid and simply leaves the numerator unchanged. Values are excluded only when they make the denominator zero, causing undefined division.

## Card 2 — `basic`

**Front:** How do you find the excluded values of $\frac{x+3}{x^2-4}$?

**Back:** Set the denominator to zero ($x^2-4=0$)Factorise and solve for $x$

**Choices:**

- Set the denominator to zero ($x^2-4=0$)Factorise and solve for $x$ ✔
  - _why:_ Excluded values make the denominator zero. Factorising gives $(x-2)(x+2)=0$, so solving the two factors identifies $x=2$ and $x=-2$.
- Set the numerator to zero ($x+3=0$)Solve the equation for $x$
  - _why:_ Setting the numerator to zero finds where the fraction equals zero, not where it is undefined. Set $x^2-4=0$ instead, giving excluded values $x=2$ and $x=-2$.
- Set the denominator to zero ($x^2-4=0$)Take the square root to get $x=2$
  - _why:_ This misses the negative square root, a common error when solving $x^2=4$. Both $x=2$ and $x=-2$ make the denominator zero and are excluded.
- Set the denominator to one ($x^2-4=1$)Rearrange and solve for $x$
  - _why:_ A denominator equal to one is valid, so those solutions are not excluded. Set the denominator equal to zero and solve $x^2-4=0$, obtaining $x=2$ and $x=-2$.
