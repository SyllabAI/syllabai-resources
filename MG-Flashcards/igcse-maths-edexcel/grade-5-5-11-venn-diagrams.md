## Card 1 — `basic`

**Front:** What does the symbol $\mathcal{E}$ represent in a Venn diagram?

**Back:** The universal set (all items being considered).

**Choices:**

- The universal set (all items being considered). ✔
  - _why:_ The universal set contains every item being considered in the problem, including items inside and outside the other sets shown in the Venn diagram.
- The empty set (items in no sets).
  - _why:_ The empty set contains no items, whereas $\mathcal{E}$ represents the universal set: all items being considered, whether or not they belong to a particular set.
- The intersection (items in both sets).
  - _why:_ The intersection is shown using $\cap$ and contains items common to sets. The symbol $\mathcal{E}$ instead represents the universal set containing every item under consideration.
- The complement (items outside a set).
  - _why:_ A complement contains everything not in a specified set and is written using a prime, such as $A'$. The symbol $\mathcal{E}$ denotes the whole universal set.

## Card 2 — `cloze`

**Front:** The [ ___ ] of set $A$ is written as $A'$ and means everything not in $A$.

**Back:** The complement of set $A$ is written as $A'$ and means everything not in $A$.

**Choices:**

- complement ✔
  - _why:_ The complement of $A$, written $A'$, contains every item in the universal set that is not in $A$.
- intersection
  - _why:_ The intersection describes items belonging to both sets and is written $A \cap B$. The correct term is complement, meaning everything not in $A$.
- union
  - _why:_ The union combines all items in either set and is written $A \cup B$. The correct term is complement, meaning everything not in $A$.
- universal set
  - _why:_ The universal set is the complete collection of items being considered, not the items outside $A$. The correct term is complement, written $A'$.

## Card 3 — `basic`

**Front:** How do you calculate $P(A')$ if $P(A) = 0.64$?

**Back:** $$$1 - 0.64 = 0.36$$

**Choices:**

- $$$1 - 0.64 = 0.36$$ ✔
  - _why:_ An event and its complement have probabilities adding to 1, so $P(A') = 1 - P(A) = 1 - 0.64 = 0.36$.
- $$$1 + 0.64 = 1.64$$
  - _why:_ Adding $P(A)$ to 1 gives a value above 1, which cannot be a probability. The complement is found by subtraction: $1 - 0.64 = 0.36$.
- $$$0.64 - 1 = -0.36$$
  - _why:_ Reversing the subtraction produces a negative probability, which is impossible. Use $P(A') = 1 - P(A)$, giving $1 - 0.64 = 0.36$.
- $$$0.64 \times 1 = 0.64$$
  - _why:_ Multiplying by 1 leaves the original probability unchanged, so it does not find the complement. Subtract $0.64$ from 1 to obtain $P(A') = 0.36$.

## Card 4 — `basic`

**Front:** Describe the difference between the symbols $\cap$ and $\cup$.

**Back:** $\cap$ is the intersection ("and" / overlap).$\cup$ is the union ("or" / everything inside the circles).

**Choices:**

- $\cap$ is the intersection ("and" / overlap).$\cup$ is the union ("or" / everything inside the circles). ✔
  - _why:_ The intersection, $A \cap B$, contains items in both sets, while the union, $A \cup B$, contains items in at least one set, including the overlap.
- $\cap$ is the union ("or" / everything inside the circles).$\cup$ is the intersection ("and" / overlap).
  - _why:_ These meanings have been reversed: $\cap$ means intersection, or overlap, and $\cup$ means union, or everything in either circle. The symbols are easy to confuse.
- $\cap$ is the complement (everything outside a set).$\cup$ is the intersection ("and" / overlap).
  - _why:_ The complement is written with a prime, such as $A'$, not $\cap$. Also, $\cup$ means union; $\cap$ is the intersection containing the overlap.
- $\cap$ is the intersection ("or" / everything inside the circles).$\cup$ is the union ("and" / overlap).
  - _why:_ The symbols have been assigned the wrong logical words: intersection means "and" and union means "or". Thus $\cap$ is the overlap, while $\cup$ covers both circles.

**Back:** $A$ only$B$ onlyThe overlap ($A \cap B$)

**Choices:**

- $A$ only$B$ onlyThe overlap ($A \cap B$) ✔
  - _why:_ The union $A \cup B$ includes every region inside either circle, so it contains the part only in $A$, the part only in $B$, and their overlap.
- $A$ only$B$ only
  - _why:_ Leaving out the overlap omits elements belonging to both sets. The union includes $A$ only, $B$ only, and the overlap $A \cap B$.

- $A$ onlyThe overlap ($A \cap B$)Outside both circles
  - _why:_ The union includes the two circles and their overlap, but not the region outside both sets. The correct regions are $A$ only, $B$ only, and the overlap.

## Card 6 — `basic`

**Front:** In set notation, what does $n(A)$ represent?

**Back:** The number of members (elements) in set $A$.

**Choices:**

- The number of members (elements) in set $A$. ✔
  - _why:_ The notation $n(A)$ gives the cardinality of set $A$, meaning how many distinct members or elements the set contains.
- The name of the members (elements) in set $A$.
  - _why:_ Set notation can list or describe the names of elements, but $n(A)$ counts how many distinct elements there are. It represents the number of members in $A$.
- The number of sets containing set $A$.
  - _why:_ The notation $n(A)$ does not count other sets or relationships between sets. It gives the number of members, or elements, contained in set $A$.
- The number of members outside set $A$.
  - _why:_ Members outside $A$ belong to its complement and are counted using notation such as $n(A')$. The expression $n(A)$ counts the elements inside set $A$.

## Card 7 — `cloze`

**Front:** The formula for the number of elements in the union of two sets is $$\text{[...]}$$.

**Back:** The formula for the number of elements in the union of two sets is $$\boxed{n(A \cup B) = n(A) + n(B) - n(A \cap B)}$$.

**Choices:**

- $$$n(A \cup B) = n(A) + n(B) - n(A \cap B)$$ ✔
  - _why:_ Adding $n(A)$ and $n(B)$ counts the overlap twice, so $n(A \cap B)$ is subtracted once to leave every element counted exactly once.
- $$$n(A \cup B) = n(A) + n(B) + n(A \cap B)$$
  - _why:_ Adding the intersection counts the overlap three times in total: once within each set and once again separately. Subtract $n(A \cap B)$ instead.
- $$$n(A \cup B) = n(A) - n(B) - n(A \cap B)$$
  - _why:_ Subtracting both $n(B)$ and the overlap removes elements that should be included in the union. Add both set totals, then subtract the overlap once.
- $$$n(A \cup B) = n(A) + n(B) - n(A \cup B)$$
  - _why:_ Subtracting the union itself does not correct the double-counted region and makes the formula circular. The repeated region is the intersection, $n(A \cap B)$.

## Card 8 — `basic`

**Front:** Why is $n(A \cap B)$ subtracted in the formula for $n(A \cup B)$?

**Back:** Because the overlap is counted twice when adding $n(A)$ and $n(B)$.

**Choices:**

- Because the overlap is counted twice when adding $n(A)$ and $n(B)$. ✔
  - _why:_ Every element in the overlap belongs to both $A$ and $B$, so adding their sizes counts it twice. Subtracting $n(A \cap B)$ once corrects this.
- Because the overlap is not counted when adding $n(A)$ and $n(B)$.
  - _why:_ The overlap is included in both $n(A)$ and $n(B)$, so it is counted twice rather than missed. Subtracting it once prevents double-counting in the union.
- Because the overlap is counted once when adding $n(A)$ and $n(B)$.
  - _why:_ The shared elements appear in both set totals, meaning they are counted twice. Removing one copy by subtracting $n(A \cap B)$ leaves one valid count.
- Because the overlap is outside both sets when adding $n(A)$ and $n(B)$.
  - _why:_ The overlap is inside both sets, not outside them. It is subtracted because adding $n(A)$ and $n(B)$ counts those shared elements twice.

## Card 9 — `basic`

**Front:** When completing a Venn diagram from scratch, which region should you fill in first?

**Back:** The overlap (intersection).

**Choices:**

- The overlap (intersection). ✔
  - _why:_ Members in the intersection are included in the totals for both sets. Entering the overlap first allows it to be subtracted correctly when calculating the remaining regions.
- The single-only regions (non-overlapping parts).
  - _why:_ Starting with single-only regions can cause double-counting because their totals usually include members of the intersection. Fill the overlap first, then subtract it from each set total.
- The outside region (neither set).
  - _why:_ The outside region is not generally calculated before the circles because it depends on the completed set totals. Begin with the overlap to prevent double-counting.
- The universal set total.
  - _why:_ The universal-set total helps calculate the final outside region, but it does not determine the entries within the circles. Fill the overlap first and work outwards.

## Card 10 — `basic`

**Front:** If 21 people visit Italy and 7 visit both Italy and Germany, how many visited Italy only?

**Back:** $$$21 - 7 = 14$$

**Choices:**

- $$$21 - 7 = 14$$ ✔
  - _why:_ The 21 Italy visitors include the seven who also visited Germany. Subtracting those seven leaves 14 people who visited Italy but not Germany.
- $$$21 \div 7 = 3$$
  - _why:_ Dividing finds how many groups of seven fit into 21, not the number who visited Italy only. Subtract the seven who visited both, giving $14$.
- $$$21 + 7 = 28$$
  - _why:_ Adding counts the seven people in both countries on top of all 21 Italy visitors. They must instead be removed from Italy’s total, giving $14$.
- $$$21 - 0 = 21$$
  - _why:_ Keeping 21 fails to remove the visitors who also went to Germany. Italy only is found by calculating $21-7$, which equals $14$.

## Card 11 — `basic`

**Front:** Which region is represented by $A \cap B'$?

**Back:** $A$ only (inside $A$ but outside $B$).

**Choices:**

- $A$ only (inside $A$ but outside $B$). ✔
  - _why:_ The intersection requires membership of $A$ and of $B'$. Since $B'$ means outside $B$, this selects the part of $A$ that does not overlap $B$.
- Both $A$ and $B$ (inside the overlap).
  - _why:_ The overlap is $A \cap B$, where members belong to both sets. The complement on $B$ instead requires members in $A$ but outside $B$, so it means $A$ only.
- $B$ only (inside $B$ but outside $A$).
  - _why:_ The $B$-only region is $A' \cap B$, because it lies outside $A$ and inside $B$. Here the complements are reversed, so the correct region is $A$ only.
- Neither $A$ nor $B$ (the area outside both circles).
  - _why:_ The region outside both sets is $A' \cap B'$. Since the given expression requires membership of $A$, it represents $A$ only rather than neither set.

## Card 12 — `basic`

**Front:** Which region is represented by $A' \cap B'$?

**Back:** Neither $A$ nor $B$ (the area outside both circles).

**Choices:**

- Neither $A$ nor $B$ (the area outside both circles). ✔
  - _why:_ Both sets are complemented, so members must be outside $A$ and outside $B$ simultaneously. Their intersection is therefore the region outside both circles.
- Both $A$ and $B$ (the area inside both circles).
  - _why:_ The overlap is $A \cap B$, with no complements, because its members are inside both sets. Two complemented sets instead select the region outside both circles.
- $A$ only (inside $A$ but outside $B$).
  - _why:_ The $A$-only region is $A \cap B'$, because its members are inside $A$ but outside $B$. Complementing $A$ as well means neither set.
- $B$ only (inside $B$ but outside $A$).
  - _why:_ The $B$-only region is $A' \cap B$, requiring membership of $B$. In $A' \cap B'$, membership of both sets is excluded, so the region is neither.

## Card 13 — `cloze`

**Front:** The notation for the region where members are in all three sets $A$, $B$, and $C$ is $\text{[...]}$.

**Back:** The notation for the region where members are in all three sets $A$, $B$, and $C$ is $\boxed{A \cap B \cap C}$.

**Choices:**

- $$A \cap B \cap C$ ✔
  - _why:_ Intersection means that all stated conditions hold simultaneously. Intersecting $A$, $B$, and $C$ therefore selects the central region shared by all three sets.
- $$A \cup B \cup C$
  - _why:_ Union means membership of at least one of the three sets, so this expression covers all three circles. Membership of every set requires intersections: $A \cap B \cap C$.
- $$(A \cap B) \cup C$
  - _why:_ The union with $C$ includes every member of $C$, even those outside $A$ and $B$. The shared three-set region is $A \cap B \cap C$.
- $$A' \cap B' \cap C'$
  - _why:_ The complements select members outside all three sets, which describes the region belonging to none of them. The central triple overlap is $A \cap B \cap C$.

## Card 14 — `basic`

**Front:** What is the general strategy for filling in a three-set Venn diagram?

**Back:** Work from the centre outwards (triple overlap $\rightarrow$ pair-only overlaps $\rightarrow$ single-only regions).

**Choices:**

- Work from the centre outwards (triple overlap $\rightarrow$ pair-only overlaps $\rightarrow$ single-only regions). ✔
  - _why:_ The triple overlap is contained in every pairwise total, so it must be entered first. Subtract it when finding pair-only overlaps, then use those to find single-only regions.
- Work from the outside inwards (neither region $\rightarrow$ single-only regions $\rightarrow$ overlaps).
  - _why:_ Working outside inwards leaves overlapping memberships unresolved and can produce double-counting. Begin with the triple overlap, then calculate pair-only overlaps and finally single-only regions.
- Work one circle at a time (first set $\rightarrow$ second set $\rightarrow$ third set).
  - _why:_ Completing one whole circle at a time counts shared members repeatedly because its overlaps are not yet known. Instead, work from the central triple overlap outwards.
- Work from the edges inwards (single-only regions $\rightarrow$ pair-only overlaps $\rightarrow$ triple overlap).
  - _why:_ Set totals normally include members in the pairwise and triple overlaps, so single-only regions cannot reliably be entered first. Start at the centre and work outwards.

## Card 15 — `basic`

**Front:** If 15 students like Art and Basketball, and 4 like all three subjects (including Choir), how many like Art and Basketball only?

**Back:** $$$15 - 4 = 11$$

**Choices:**

- $$$15 - 4 = 11$$ ✔
  - _why:_ The 15 students who like Art and Basketball include the four who also like Choir. Removing those four leaves 11 in the Art-Basketball overlap only.
- $$$15 + 4 = 19$$
  - _why:_ Adding the four triple-overlap students counts them twice because they are already among the 15 who like Art and Basketball. Subtracting them gives 11.
- $$$15 - 0 = 15$$
  - _why:_ Keeping all 15 includes the four students who also like Choir, so it does not represent the pair-only region. Subtracting four gives 11.
- $$$15 - 8 = 7$$
  - _why:_ Subtracting eight removes the four triple-overlap students twice. They appear within the total of 15 only once, so one subtraction gives 11.

## Card 16 — `basic`

**Front:** When calculating probability from a Venn diagram, what is typically used as the denominator?

**Back:** The total number of outcomes in the universal set ($\mathcal{E}$).

**Choices:**

- The total number of outcomes in the universal set ($\mathcal{E}$). ✔
  - _why:_ Probability is the number of favourable outcomes divided by the total possible outcomes. On a Venn diagram, that total is the number in the universal set.
- The number of outcomes in the required region only.
  - _why:_ The number in the required region forms the numerator, not usually the denominator. The denominator is the total number of outcomes in the universal set.
- The total number of outcomes in set $A$ only.
  - _why:_ Using only set $A$ as the denominator would calculate a conditional proportion within $A$, not an ordinary probability. The full universal-set total is normally required.
- The total number of outcomes outside both sets.
  - _why:_ The area outside both circles contains only outcomes in neither set, so it is not the complete sample space. The denominator uses every outcome in the universal set.

**Back:** Everything outside circle $A$ plus everything inside circle $B$ (only the "A only" section remains unshaded).

**Choices:**

- Everything outside circle $A$ plus everything inside circle $B$ (only the "A only" section remains unshaded). ✔

  - _why:_ This describes $A' \cup B'$, which excludes only the intersection rather than both complete circles. $A' \cup B$ leaves just the "A only" section unshaded.
- Everything inside circle $A$ plus everything inside circle $B$ (only the outside section remains unshaded).
  - _why:_ This describes $A \cup B$, the union of the two original sets. The complement on $A$ means $A' \cup B$ includes the outside region and leaves only "A only" unshaded.

## Card 18 — `cloze`

**Front:** If probabilities are given as percentages, you find the complement by subtracting from [ ___ ]; if given as decimals, you subtract from 1.

**Back:** If probabilities are given as percentages, you find the complement by subtracting from 100%; if given as decimals, you subtract from 1.

**Choices:**

- 100% ✔
  - _why:_ The probabilities of an event and its complement total 100%. Therefore, when probabilities are percentages, the complement is found by subtracting the given probability from 100%.
- 1%
  - _why:_ This confuses the percentage total with the decimal total of 1. Percentages across the whole sample total 100%, so a percentage complement must be subtracted from 100%.
- 10%
  - _why:_ This treats 10% as the complete probability scale, perhaps by confusing percentages with tenths. A certain event has probability 100%, so complements are subtracted from 100%.
- 99%
  - _why:_ This off-by-one error incorrectly removes one percentage point from the complete probability scale. All possible outcomes total 100%, so the complement is found by subtracting from 100%.

## Card 20 — `basic`

**Front:** If a survey of 50 people shows 6 are in neither set, how many people are in at least one set?

**Back:** $$$50 - 6 = 44$$

**Choices:**

- $$$50 - 6 = 44$$ ✔
  - _why:_ Everyone is either in at least one set or in neither set. Subtracting the 6 in neither from the total of 50 gives 44 people in at least one set.
- $$$50 + 6 = 56$$
  - _why:_ Adding the 6 counts those in neither on top of the full survey total. They must be removed from 50, giving $50 - 6 = 44$ people in at least one set.
- $$$50 - 6 = 46$$
  - _why:_ The method is correct, but the subtraction contains an arithmetic slip. Subtracting 6 from 50 gives 44, so 44 people are in at least one set.
- $$$50 - 44 = 6$$
  - _why:_ This calculation identifies the number in neither set, which is already given, rather than the requested number in at least one set. The required calculation is $50 - 6 = 44$.

## Card 21 — `basic`

**Front:** What is a common mistake when finding probabilities from a Venn diagram containing listed numerical elements?

**Back:** Adding the values of the elements instead of counting how many elements there are.

**Choices:**

- Adding the values of the elements instead of counting how many elements there are. ✔
  - _why:_ Listed numbers are labels for individual elements, not frequencies. Probability depends on the number of favourable elements and the total number of elements, so the entries must be counted.
- Counting the values of the elements instead of adding how large the values are.
  - _why:_ Counting is the correct method when the numbers shown are elements rather than frequencies. Their numerical sizes are irrelevant, so adding their values would produce an incorrect probability.
- Including the elements in the overlap instead of excluding all overlapping elements.
  - _why:_ Elements in the overlap still belong to both sets and must be included when relevant, though counted only once in a union. The key mistake is adding listed values instead of counting elements.
- Dividing the number of favourable elements instead of multiplying it by the total.
  - _why:_ Probability is correctly calculated by dividing the number of favourable outcomes by the total number of outcomes. With listed numerical elements, the common error is adding their values instead of counting them.
