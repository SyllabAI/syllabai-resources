## Card 1 — `basic`

**Front:** If a value has frequency 5, what does the 5 tell you?

**Back:** It occurs 5 times.

**Choices:**

- It occurs 5 times. ✔
  - _why:_ Frequency records the number of occurrences. A frequency of 5 means that this particular value appears five times in the data set.
- It occurs once.
  - _why:_ This treats each table row as a single occurrence and overlooks the frequency entry. A frequency of 5 means the value occurs 5 times.
- It has a value of 5.
  - _why:_ This confuses the frequency with the data value itself. The 5 counts how often the value occurs; it does not give the value.
- It is the fifth value.
  - _why:_ This interprets frequency as a position or rank. Frequency counts repetitions, so 5 tells you that the value occurs 5 times.

## Card 2 — `cloze`

**Front:** In a frequency table, frequency means [ ___ ].

**Back:** In a frequency table, frequency means how many times a value, score, result or group occurs.

**Choices:**

- how many times a value, score, result or group occurs ✔
  - _why:_ Frequency is a count of occurrences. It shows how many observations have a particular value, score, result or belong to a particular group.
- the value obtained when all results are added
  - _why:_ This describes a total rather than a frequency. Frequency counts how many times a value, score, result or group occurs in the data.
- how far a value is from the mean
  - _why:_ This confuses frequency with deviation from the mean. Frequency simply states how many times a value, score, result or group occurs.
- the number of different values listed
  - _why:_ This counts distinct categories rather than their occurrences. Frequency is how many times a particular value, score, result or group occurs.

## Card 3 — `basic`

**Front:** When finding the mean from an exact frequency table, what do you multiply each value by?

**Back:** Its frequency.

**Choices:**

- Its frequency. ✔
  - _why:_ Multiplying each value by its frequency gives the total contribution made by all occurrences of that value before the contributions are added.
- Its position.
  - _why:_ A value’s position does not show how often it occurs. Each value must be multiplied by its frequency to find its total contribution.
- The total frequency.
  - _why:_ Using the total frequency for every value overcounts each row. Multiply each value by its own frequency, then add the resulting products.
- The number of rows.
  - _why:_ The number of rows only counts the distinct entries in the table. Each value must instead be multiplied by its corresponding frequency.

## Card 4 — `basic`

**Front:** For a mean from a frequency table, what do you divide the total of value × frequency by?

**Back:** The total frequency.

**Choices:**

- The total frequency. ✔
  - _why:_ The total frequency is the total number of observations. Dividing the sum of value × frequency by this total gives the mean.
- The number of rows.
  - _why:_ Rows represent distinct values or groups, not necessarily individual observations. Divide by the total frequency because it counts all the data items.
- The highest frequency.
  - _why:_ The highest frequency helps identify the mode, not calculate the mean. The weighted total must be divided by the total frequency.
- The total of the values.
  - _why:_ Adding the listed values ignores how many times each occurs. Divide the total of value × frequency by the total frequency.

## Card 5 — `cloze`

**Front:** For an exact frequency table, $$\text{mean}=\frac{\sum(\text{value}\times\text{frequency})}{\sum\text{frequencies}}$$ so you must divide by [ ___ ], not [ ___ ].

**Back:** For an exact frequency table, $$\text{mean}=\frac{\sum(\text{value}\times\text{frequency})}{\sum\text{frequencies}}$$ so you must divide by total frequency, not the number of rows.

**Choices:**

- For an exact frequency table, $$\text{mean}=\frac{\sum(\text{value}\times\text{frequency})}{\sum\text{frequencies}}$$ so you must divide by total frequency, not the number of rows. ✔
  - _why:_ The denominator must count every observation, which is the total frequency. The number of rows counts only the distinct values listed in the table.
- For an exact frequency table, $$\text{mean}=\frac{\sum(\text{value}\times\text{frequency})}{\sum\text{frequencies}}$$ so you must divide by the number of rows, not total frequency.
  - _why:_ This reverses the correct quantities and treats every listed value as occurring once. The weighted total must be divided by the total frequency.
- For an exact frequency table, $$\text{mean}=\frac{\sum(\text{value}\times\text{frequency})}{\sum\text{frequencies}}$$ so you must divide by highest frequency, not the number of rows.
  - _why:_ The highest frequency identifies the modal value but does not count all observations. The mean requires division by the total frequency.
- For an exact frequency table, $$\text{mean}=\frac{\sum(\text{value}\times\text{frequency})}{\sum\text{frequencies}}$$ so you must divide by total frequency, not the sum of frequencies.
  - _why:_ The total frequency and the sum of frequencies are the same quantity, so they cannot be contrasted. This quantity is the correct denominator.

## Card 6 — `basic`

**Front:** Why is averaging only the first column of a frequency table wrong?

**Back:** It ignores frequencies.

**Choices:**

- It ignores frequencies. ✔
  - _why:_ Values occurring more often must have more influence on the mean. Averaging only the first column treats every listed value as if it occurred once.
- It counts every value twice.
  - _why:_ The problem is not automatic double counting. Averaging the first column ignores the frequencies and wrongly gives each distinct listed value equal weight.
- It uses the wrong units.
  - _why:_ The measurement units are unchanged by this calculation. The error is ignoring frequency, so repeated values do not receive their proper weighting.
- It finds the median instead.
  - _why:_ Simply averaging the first column does not generally produce the median. It is wrong because it ignores how frequently each listed value occurs.

## Card 7 — `basic`

**Front:** In a frequency table, how do you identify the mode?

**Back:** Choose the value with the highest frequency.

**Choices:**

- Choose the value with the highest frequency. ✔
  - _why:_ The mode is the value that occurs most often. Therefore, its row has the greatest frequency in the frequency table.
- Choose the value with the lowest frequency.
  - _why:_ This selects the least common value rather than the most common one. The mode is the value with the highest frequency.
- Choose the value with the greatest size.
  - _why:_ The mode depends on how often a value occurs, not on its numerical size. Choose the value whose frequency is highest.
- Choose the value at the middle position.
  - _why:_ The middle position is used to identify the median, not the mode. The mode is found by choosing the value with the highest frequency.

## Card 8 — `basic`

**Front:** What is cumulative frequency used for when finding a median from a frequency table?

**Back:** To locate the middle value.

**Choices:**

- To locate the middle value. ✔
  - _why:_ Cumulative frequency gives a running total, showing where the middle observation lies when the data are placed in numerical order.
- To locate the most frequent value.
  - _why:_ The most frequent value is the mode and can be found from ordinary frequencies. Cumulative frequency is used to locate the middle value.
- To locate the total of all values.
  - _why:_ Cumulative frequency totals the number of observations, not their values. Its running count helps identify the position of the middle value.
- To locate the range of values.
  - _why:_ The range comes from subtracting the smallest value from the largest. Cumulative frequency instead helps locate the middle observation for the median.

## Card 9 — `cloze`

**Front:** Cumulative frequency is the [ ___ ] of the frequencies as you move down a table.

**Back:** Cumulative frequency is the running total of the frequencies as you move down a table.

**Choices:**

- running total ✔
  - _why:_ Cumulative frequency is found by adding each frequency to the total already accumulated, so it gives the running total as you move down the table.
- largest frequency
  - _why:_ The largest frequency is only the row with the greatest individual count. The correct term is “running total”, because cumulative frequency adds frequencies progressively.
- frequency difference
  - _why:_ Subtracting frequencies gives a difference, not a cumulative value. The correct term is “running total”, formed by adding each frequency to the previous total.
- average frequency
  - _why:_ An average frequency would involve dividing by the number of groups, which is not how cumulative frequency is calculated. The correct term is “running total”.

## Card 10 — `basic`

**Front:** For 38 values, which positions are used to find the median?

**Back:** The 19th and 20th values.

**Choices:**

- The 19th and 20th values. ✔
  - _why:_ With 38 values, the data set has an even number of values, so the median lies halfway between the two central positions: the 19th and 20th values.
- The 18th and 19th values.
  - _why:_ These positions are one place too early. For 38 values, the two central positions are found using $\frac{38}{2}=19$ and the next position, giving the 19th and 20th values.
- The 20th and 21st values.
  - _why:_ These positions are one place too late. An even data set of 38 values has central positions 19 and 20, so the median uses the 19th and 20th values.
- The 19th value only.
  - _why:_ A single middle value is used only when the number of data values is odd. Since 38 is even, the median is based on the 19th and 20th values.

## Card 12 — `basic`

**Front:** If total goals are 54, known contribution is 28, and the 2-goal frequency is $x$, what equation is formed?

**Back:** $$2x+28=54$

**Choices:**

- $$2x+28=54$ ✔
  - _why:_ The 2-goal group contributes $2x$ goals, and the known contribution is 28. Their total must equal 54, so the equation combines these contributions as required.
- $$x+28=54$
  - _why:_ This forgets that each of the $x$ people scored 2 goals, so their contribution is $2x$. The correct equation is $2x+28=54$.
- $$2x+54=28$
  - _why:_ The total contribution should equal 54, while 28 is the known part, not the overall total. Therefore the correct equation is $2x+28=54$.
- $$2(x+28)=54$
  - _why:_ The factor 2 applies only to the 2-goal frequency, not to the known contribution of 28. The correct equation is $2x+28=54$.

## Card 13 — `basic`

**Front:** Solve $2x+28=54$.

**Back:** $$x=13$

**Choices:**

- $$x=13$ ✔
  - _why:_ Subtracting 28 from both sides gives $2x=26$, and dividing by 2 gives $x=13$.
- $$x=26$
  - _why:_ This stops after subtracting 28 and forgets to divide by the coefficient 2. Since $2x=26$, the correct solution is $x=13$.
- $$x=14$
  - _why:_ Adding rather than subtracting, or making an arithmetic slip, can produce 14. Solving gives $2x=54-28=26$, so $x=13$.
- $$x=41$
  - _why:_ This comes from combining 28 and 13 rather than isolating the unknown. Subtract 28 from 54 and then divide by 2, giving $x=13$.

## Card 14 — `basic`

**Front:** Why can’t an exact mean be found if an open-ended class has non-zero frequency?

**Back:** The exact values are unknown.

**Choices:**

- The exact values are unknown. ✔
  - _why:_ An open-ended class does not specify the individual values above or below its boundary. Without those exact values, their contribution to the total cannot be calculated exactly.
- The class midpoint is unknown.
  - _why:_ An open-ended class has no finite pair of boundaries, so a midpoint cannot be used reliably. The key reason an exact mean is impossible is that the individual values are unknown.
- The frequency is unknown.
  - _why:_ The frequency can be given even when a class is open-ended. The difficulty is that the exact individual values within that class are unknown, preventing an exact total.
- The total frequency is unknown.
  - _why:_ The total frequency may be calculated from the table. An exact mean still cannot be found because the actual values in the open-ended class are unknown.

## Card 15 — `cloze`

**Front:** Grouped data is shown in [ ___ ] rather than exact individual values.

**Back:** Grouped data is shown in intervals rather than exact individual values.

**Choices:**

- intervals ✔
  - _why:_ Grouped data combines values into ranges, or intervals, rather than listing every individual observation separately.
- midpoints
  - _why:_ A midpoint is a representative value used to estimate calculations for a class. Grouped data itself is displayed in intervals, not midpoints.
- frequencies
  - _why:_ Frequencies show how many values lie in each group, but they do not describe the ranges used to display grouped data. The correct term is intervals.
- averages
  - _why:_ An average summarises data with a single value, whereas grouped data is organised into ranges. These ranges are called intervals.

## Card 16 — `basic`

**Front:** For grouped data, what value represents each class when estimating the mean?

**Back:** The class midpoint.

**Choices:**

- The class midpoint. ✔
  - _why:_ The midpoint is halfway between the lower and upper boundaries of a class. It represents the class when estimating the mean of grouped data.
- The class frequency.
  - _why:_ Frequency tells how many values are in the class, not which value represents it. The class midpoint is used as the representative value for estimating the mean.
- The class width.
  - _why:_ Class width measures the size of the interval, so it is not a data value representing the class. The correct representative value is the class midpoint.
- The class upper boundary.
  - _why:_ Using the upper boundary would treat every value as if it were at the top of the interval. The midpoint gives a more suitable representative estimate.

## Card 18 — `cloze`

**Back:** For grouped data, $$\text{estimated mean}=\frac{\sum(\text{midpoint}\times\text{frequency})}{\sum\text{frequencies}}$$ because values in each class are treated as if they are at the midpoint.

**Choices:**

- midpoint ✔
  - _why:_ The exact values are unknown, so every value in a class is represented by the class midpoint when estimating the mean.
- lower boundary
  - _why:_ Using the lower boundary would systematically underestimate the values. Grouped-mean calculations represent every value in a class by its midpoint.
- upper boundary
  - _why:_ Using the upper boundary would systematically overestimate the values. Each class is instead represented by the value halfway between its boundaries, the midpoint.
- class width
  - _why:_ The class width measures the size of an interval, not the assumed data value. Grouped values are treated as if they occur at the midpoint.

**Back:** Exact values within each interval are unknown.

**Choices:**

- Exact values within each interval are unknown. ✔
  - _why:_ A grouped table gives only the interval containing each value. Replacing unknown individual values with class midpoints makes the calculated mean an estimate.
- Exact frequencies within each interval are unknown.
  - _why:_ The frequency column states how many values belong to each interval, so those frequencies are known. The mean is estimated because the individual values are unknown.
