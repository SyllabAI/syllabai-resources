# Function Machines Flashcards

_Lane: `igcse-maths-edexcel` · grade 2 · 2 cards (source: MathsGenie flashcards)_

## Card 1 — `basic`

**Front:** In a function machine, what is the input?

**Back:** The number that goes into the machine.

**Choices:**

- The number that goes into the machine. ✔
  - _why:_ The input is the starting number entered into the function machine before the machine’s mathematical rule is applied to it.
- The number that comes out of the machine.
  - _why:_ This confuses the input with the output. The input is the number that goes into the machine, while the output is produced after applying the rule.
- The calculation performed inside the machine.
  - _why:_ This describes the function or rule, not the input. The input is the number entered into the machine before that calculation is performed.
- The answer found by reversing the machine.
  - _why:_ Reversing a function machine can be used to recover an input, but it does not define one. The input is the number that goes into the machine.

## Card 2 — `basic`

**Front:** In a function machine, what is the output?

**Back:** The number that comes out of the machine.

**Choices:**

- The number that comes out of the machine. ✔
  - _why:_ The output is the resulting number that comes out after the function machine has applied its mathematical rule to the input.
- The number that goes into the machine.
  - _why:_ This confuses the output with the input. The output is the number that comes out of the machine after its rule has been applied.
- The calculation performed inside the machine.
  - _why:_ This describes the function or rule rather than the output. The output is the resulting number produced when that rule is applied to the input.
- The value used to reverse the machine.
  - _why:_ Reversing the machine involves inverse operations and may be used to find an input. The output is the number produced by applying the original rule.
