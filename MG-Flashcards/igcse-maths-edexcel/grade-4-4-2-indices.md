## Card 1 — `basic`

**Front:** In the algebraic term $a^n$, what are the names for $a$ and $n$?

**Back:** $a$ is the base$n$ is the index

**Choices:**

- $a$ is the base$n$ is the index ✔
  - _why:_ The base is the quantity being repeatedly multiplied, while the index states how many factors of that base appear in the expanded power.
- $a$ is the index$n$ is the base
  - _why:_ This reverses the two names. In $a^n$, $a$ is the base being raised to a power, while $n$ is the index.
- $a$ is the coefficient$n$ is the variable
  - _why:_ A coefficient multiplies an algebraic term, so it is not the correct label here. In $a^n$, $a$ is the base and $n$ is the index.
- $a$ is the power$n$ is the coefficient
  - _why:_ The power refers to the complete expression rather than the letter $a$, and $n$ is not a coefficient. The correct names are base and index respectively.

## Card 2 — `basic`

**Front:** In the term $a^n$, what does the index $n$ represent?

**Back:** How many times the base is multiplied by itself.

**Choices:**

- How many times the base is multiplied by itself. ✔
  - _why:_ The index counts the number of factors of the base. For example, $a^3$ means $a \times a \times a$, giving three factors of $a$.
- How many times the base is added to itself.
  - _why:_ This confuses powers with repeated addition, which describes multiplication. An index instead shows how many times the base occurs as a factor in repeated multiplication.
- How many times the index is multiplied by itself.
  - _why:_ The index is not the quantity being repeatedly multiplied. It counts how many times the base is multiplied by itself, so $a^n$ contains $n$ factors of $a$.
- How many times the base is divided by itself.
  - _why:_ Indices describe repeated multiplication rather than repeated division. The index $n$ tells you that the expanded power contains $n$ factors of the base.

## Card 3 — `cloze`

**Front:** When multiplying powers with the same base, $a^m \times a^n = \text{[...]}.

**Back:** When multiplying powers with the same base, $a^m \times a^n = \boxed{a^{m+n}}.

**Choices:**

- $$a^{m+n}$ ✔
  - _why:_ Multiplying powers with the same base combines all their factors, so the indices are added. Therefore, $a^m \times a^n$ simplifies to $a^{m+n}$.
- $$a^{mn}$
  - _why:_ Multiplying the indices is the rule for raising a power to another power, not multiplying powers. With the same base, add the indices to obtain $a^{m+n}$.
- $$a^{m-n}$
  - _why:_ Subtracting indices applies when dividing powers with the same non-zero base. Multiplication combines the factors, so the indices must be added to give $a^{m+n}$.
- $$a^{m+n+1}$
  - _why:_ No additional factor of $a$ is introduced during multiplication, so adding an extra $1$ is an off-by-one error. The correct result is $a^{m+n}$.

## Card 4 — `cloze`

**Front:** When dividing powers with the same non-zero base, $\frac{a^m}{a^n} = \text{[...]}.

**Back:** When dividing powers with the same non-zero base, $\frac{a^m}{a^n} = \boxed{a^{m-n}}.

**Choices:**

- $$a^{m-n}$ ✔
  - _why:_ Dividing cancels $n$ factors of $a$ from the $m$ factors in the numerator. This leaves an index of $m-n$, giving $a^{m-n}$.
- $$a^{m+n}$
  - _why:_ Adding the indices is the rule for multiplying powers with the same base. Division cancels factors, so subtract the denominator’s index from the numerator’s to get $a^{m-n}$.
- $$a^{n-m}$
  - _why:_ This subtracts the indices in the wrong order. The denominator’s index is subtracted from the numerator’s index, so the result is $a^{m-n}$.
- $$a^{\frac{m}{n}}$
  - _why:_ Dividing powers does not mean dividing their indices. Cancelling common factors subtracts the denominator’s index from the numerator’s, producing $a^{m-n}$.

## Card 5 — `cloze`

**Front:** When a power is raised to another power, $(a^m)^n = \text{[...]}.

**Back:** When a power is raised to another power, $(a^m)^n = \boxed{a^{mn}}.

**Choices:**

- $$a^{mn}$ ✔
  - _why:_ Raising $a^m$ to the power $n$ creates $n$ copies of $a^m$. Adding those repeated indices gives $m+m+\cdots+m=mn$.
- $$a^{m+n}$
  - _why:_ Adding indices applies when multiplying separate powers with the same base. A power raised to another power requires the indices to be multiplied, giving $a^{mn}$.
- $$a^{m^n}$
  - _why:_ The outer index does not become a power of the inner index. It counts repeated copies of $a^m$, so the indices multiply and the result is $a^{mn}$.
- $$a^{m-n}$
  - _why:_ Subtracting indices is used when dividing powers with the same non-zero base. Here the power is repeated $n$ times, so the indices multiply to give $a^{mn}$.

## Card 6 — `cloze`

**Front:** An algebraic letter on its own (e.g. $x$) has a hidden index of [ ___ ].

**Back:** An algebraic letter on its own (e.g. $x$) has a hidden index of 1.

**Choices:**

- 1 ✔
  - _why:_ An algebraic letter written without a visible index represents one factor of itself. Therefore, $x$ means exactly the same as $x^1$.
- 0
  - _why:_ An index of zero would make a non-zero base equal to $1$, so $x^0$ is not $x$. A letter on its own has index $1$.
- 2
  - _why:_ An index of $2$ would mean the letter is multiplied by itself, producing $x^2$. A single $x$ contains one factor, so its hidden index is $1$.
- -1
  - _why:_ A negative index indicates a reciprocal, so $x^{-1}=\frac{1}{x}$. A letter written on its own is simply $x^1$, giving a hidden index of $1$.

## Card 7 — `cloze`

**Front:** For any non-zero base, $a^0 = \text{[...]}.

**Back:** For any non-zero base, $a^0 = \boxed{1}.

**Choices:**

- $$1$ ✔
  - _why:_ For any non-zero $a$, dividing $a^n$ by itself gives both $a^{n-n}=a^0$ and $1$. Therefore, $a^0=1$.
- $$0$
  - _why:_ This confuses a zero index with multiplying the base by zero. Since $a^n \div a^n=a^0$ and also equals $1$, the correct value is $1$.
- $$a$
  - _why:_ The expression $a$ has an index of $1$, not $0$. Reducing the index to zero gives $a^0=1$ for every non-zero base.
- $$-1$
  - _why:_ A zero index does not make a value negative. Using $a^n \div a^n=a^{n-n}=a^0$ shows that the result must be $1$.

## Card 8 — `cloze`

**Front:** A negative index indicates a reciprocal: $a^{-n} = \text{[...]}.

**Back:** A negative index indicates a reciprocal: $a^{-n} = \boxed{\frac{1}{a^n}}.

**Choices:**

- $$\frac{1}{a^n}$ ✔
  - _why:_ A negative index means take the reciprocal of the corresponding positive power. Moving $a^{-n}$ across the fraction bar changes the index to $n$, giving $\frac{1}{a^n}$.
- $$-a^n$
  - _why:_ A negative index does not make the value itself negative; it indicates a reciprocal. The correct conversion is $a^{-n}=\frac{1}{a^n}$.
- $$\frac{-1}{a^n}$
  - _why:_ The negative sign belongs to the index and does not create a negative numerator. It instructs you to take the reciprocal, giving $\frac{1}{a^n}$.
- $$\frac{1}{a^{-n}}$
  - _why:_ Placing $a^{-n}$ in the denominator reverses the reciprocal again, making the expression equal to $a^n$. The correct reciprocal form is $\frac{1}{a^n}$.

## Card 9 — `basic`

**Front:** Why is the division law $\frac{a^m}{a^n} = a^{m-n}$ restricted to non-zero bases?

**Back:** Because division by zero is not allowed.

**Choices:**

- Because division by zero is not allowed. ✔
  - _why:_ The expression contains division by $a^n$. If $a=0$, then $a^n=0$ for positive $n$, making the denominator zero and the division undefined.
- Because subtraction of indices is not allowed.
  - _why:_ Subtracting indices is exactly the correct operation when dividing powers with the same non-zero base. The restriction exists because a zero base could produce division by zero.
- Because negative indices are not allowed.
  - _why:_ Negative indices are valid and represent reciprocals, such as $a^{-2}=\frac{1}{a^2}$. The base must be non-zero because the division law may otherwise involve division by zero.
- Because zero indices are not allowed.
  - _why:_ A zero index is valid for any non-zero base, with $a^0=1$. The non-zero restriction is needed because dividing powers of zero can require division by zero.

## Card 10 — `basic`

**Front:** Simplify $(4x)^2$ and explain the common mistake.

**Back:** The answer is $16x^2$. The coefficient 4 must be squared as well as the $x$.

**Choices:**

- The answer is $16x^2$. The coefficient 4 must be squared as well as the $x$. ✔
  - _why:_ The exponent applies to everything inside the brackets, so $(4x)^2=4^2x^2=16x^2$. Both the numerical coefficient and the variable must be squared.
- The answer is $4x^2$. The coefficient 4 must be left unchanged while squaring the $x$.
  - _why:_ This applies the exponent only to $x$, a common bracket error. The exponent applies to the entire product, so $4$ must also be squared, giving $16x^2$.
- The answer is $8x^2$. The coefficient 4 must be multiplied by 2 as well as squaring the $x$.
  - _why:_ An exponent of 2 means multiplying a quantity by itself, not multiplying it by 2. Therefore $4^2=16$, so the simplified expression is $16x^2$.
- The answer is $16x$. The coefficient 4 must be squared while leaving the $x$ unchanged.
  - _why:_ This correctly squares the coefficient but fails to square the variable. Since the exponent applies to both factors inside the brackets, the answer is $16x^2$.

## Card 11 — `basic`

**Front:** Simplify the expression $(3m^2n)^3$.

**Back:** $$27m^6n^3$

**Choices:**

- $$27m^6n^3$ ✔
  - _why:_ Cube each factor inside the brackets: $3^3=27$, $(m^2)^3=m^6$, and $n^3=n^3$. Therefore the fully simplified product is $27m^6n^3$.
- $$9m^6n^3$
  - _why:_ The variable indices have been multiplied correctly, but the coefficient has only been squared. Cubing $3$ gives $3^3=27$, so the answer is $27m^6n^3$.
- $$27m^5n^3$
  - _why:_ This adds the indices $2+3$ instead of multiplying them. The power-of-a-power law gives $(m^2)^3=m^{2\times3}=m^6$, so the answer is $27m^6n^3$.
- $$27m^6n$
  - _why:_ The outer exponent applies to every factor inside the brackets, including $n$. Thus $n$ becomes $n^3$, and the complete simplified expression is $27m^6n^3$.

## Card 12 — `basic`

**Front:** State the two-step process for multiplying algebraic terms like $4p^2 \times 5p^3$.

**Back:** Multiply the coefficients ($4 \times 5$)Add the indices for matching bases ($p^{2+3}$)

**Choices:**

- Multiply the coefficients ($4 \times 5$)Add the indices for matching bases ($p^{2+3}$) ✔
  - _why:_ Numerical coefficients are multiplied normally, while powers with the same base are combined by adding their indices. Hence $4p^2\times5p^3=20p^5$.
- Multiply the coefficients ($4 \times 5$)Multiply the indices for matching bases ($p^{2\times3}$)
  - _why:_ Multiplying indices is used for a power raised to another power, not for multiplying separate powers. Here the indices are added, so $4p^2\times5p^3=20p^5$.
- Add the coefficients ($4 + 5$)Add the indices for matching bases ($p^{2+3}$)
  - _why:_ The indices are correctly added, but coefficients must be multiplied when algebraic terms are multiplied. Therefore the coefficient is $4\times5=20$, giving $20p^5$.
- Multiply the coefficients ($4 \times 5$)Subtract the indices for matching bases ($p^{3-2}$)
  - _why:_ Subtracting indices applies when dividing powers with the same base. For multiplication, add the indices, so the correct process gives $20p^{2+3}=20p^5$.

## Card 13 — `basic`

**Front:** Simplify $\frac{18a^6b^4}{6a^2b}$.

**Back:** $$3a^4b^3$

**Choices:**

- $$3a^4b^3$ ✔
  - _why:_ Divide the coefficients to get $18\div6=3$, then subtract indices for matching bases: $a^{6-2}=a^4$ and $b^{4-1}=b^3$.
- $$3a^3b^4$
  - _why:_ This mishandles both variable divisions. Subtracting the denominator indices gives $a^{6-2}=a^4$ and $b^{4-1}=b^3$, so the answer is $3a^4b^3$.
- $$12a^4b^3$
  - _why:_ The variable indices are correct, but the coefficients have been subtracted rather than divided. Since $18\div6=3$, the correct simplified expression is $3a^4b^3$.
- $$3a^8b^5$
  - _why:_ Adding the indices is the rule for multiplication, not division. Division requires subtraction, giving $a^{6-2}=a^4$ and $b^{4-1}=b^3$, so the answer is $3a^4b^3$.

## Card 14 — `basic`

**Front:** Explain why $x^0 = 1$ using the division law (where $x \neq 0$).

**Back:** $\frac{x^n}{x^n} = 1$ because any non-zero value divided by itself is 1By index laws, $\frac{x^n}{x^n} = x^{n-n} = x^0$

**Choices:**

- $\frac{x^n}{x^n} = 1$ because any non-zero value divided by itself is 1By index laws, $\frac{x^n}{x^n} = x^{n-n} = x^0$ ✔
  - _why:_ The same quotient equals both $1$ by ordinary division and $x^0$ by subtracting equal indices. Therefore $x^0=1$ for every non-zero value of $x$.
- $\frac{x^n}{x^n} = 0$ because any value subtracted from itself is 0By index laws, $\frac{x^n}{x^n} = x^{n-n} = x^0$
  - _why:_ This confuses division with subtraction. A non-zero value divided by itself equals $1$, while only the indices are subtracted, so the comparison shows that $x^0=1$.
- $\frac{x^n}{x^n} = 1$ because any non-zero value divided by itself is 1By index laws, $\frac{x^n}{x^n} = x^{n+n} = x^{2n}$
  - _why:_ Adding indices is the multiplication law, whereas division requires subtracting them. Thus $\frac{x^n}{x^n}=x^{n-n}=x^0$, and since the quotient is $1$, $x^0=1$.
- $\frac{x^n}{x^n} = x$ because equal powers cancel to leave their baseBy index laws, $\frac{x^n}{x^n} = x^{n-n} = x^0$
  - _why:_ Equal numerator and denominator factors cancel completely, leaving $1$, not the base. Since the index law also gives $x^{n-n}=x^0$, it follows that $x^0=1$.

## Card 15 — `basic`

**Front:** Evaluate $3^{-2}$.

**Back:** $$\frac{1}{9}$

**Choices:**

- $$\frac{1}{9}$ ✔
  - _why:_ A negative index means take the reciprocal: $3^{-2}=\frac{1}{3^2}$. Since $3^2=9$, the value is $\frac{1}{9}$.
- $$-9$
  - _why:_ A negative index does not make the result negative; it indicates a reciprocal. Therefore $3^{-2}=\frac{1}{3^2}=\frac{1}{9}$, which is positive.
- $$\frac{1}{6}$
  - _why:_ This treats the exponent as multiplication by $2$. The exponent means square the base, so $3^{-2}=\frac{1}{3^2}=\frac{1}{9}$.
- $$9$
  - _why:_ This ignores the negative sign on the index. While $3^2=9$, a negative index requires the reciprocal, so $3^{-2}=\frac{1}{9}$.

## Card 16 — `basic`

**Front:** Simplify $7x^5 \times 2x^{-3}$.

**Back:** $$14x^2$

**Choices:**

- $$14x^2$ ✔
  - _why:_ Multiply the coefficients to get $7\times2=14$, then add the indices of the matching base: $5+(-3)=2$. Therefore the result is $14x^2$.
- $$14x^8$
  - _why:_ This subtracts the negative index as though applying the division law. For multiplication, indices are added: $5+(-3)=2$, so the correct result is $14x^2$.
- $$9x^2$
  - _why:_ The indices have been combined correctly, but the coefficients have been added rather than multiplied. Since $7\times2=14$, the correct simplified expression is $14x^2$.
- $$14x^{-15}$
  - _why:_ Multiplying the indices is a power-of-a-power error. When multiplying powers with the same base, add the indices: $5+(-3)=2$, giving $14x^2$.

## Card 17 — `basic`

**Front:** Rewrite $1000^3$ as a power of 10.

**Back:** $$10^9$

**Choices:**

- $$10^9$ ✔
  - _why:_ Since $1000 = 10^3$, the power-of-a-power law gives $(10^3)^3 = 10^{3 \times 3} = 10^9$.
- $$10^6$
  - _why:_ Adding the two indices gives 6, but the power-of-a-power law requires multiplication. Since $1000 = 10^3$, $(10^3)^3 = 10^{3 \times 3} = 10^9$.
- $$10^3$
  - _why:_ This rewrites 1000 correctly but ignores the outer cube. Cubing $10^3$ multiplies its index by 3, giving $(10^3)^3 = 10^9$.
- $$10^{27}$
  - _why:_ Cubing the index itself gives 27, but indices are multiplied when raising a power to another power. Therefore $(10^3)^3 = 10^{3 \times 3} = 10^9$.

## Card 18 — `basic`

**Front:** Solve $z^4 \times z^k = z^{11}$ for $k$.

**Back:** $$k = 7$

**Choices:**

- $$k = 7$ ✔
  - _why:_ Multiplying powers with the same base adds their indices, so $4 + k = 11$. Subtracting 4 from both sides gives $k = 7$.
- $$k = 15$
  - _why:_ Adding 4 to 11 reverses the required solving step. The index law gives $4 + k = 11$, so subtracting 4 gives $k = 7$.
- $$k = 44$
  - _why:_ Multiplying the indices is a common error; indices are added when powers with the same base are multiplied. Thus $4 + k = 11$, giving $k = 7$.
- $$k = 8$
  - _why:_ This is an off-by-one subtraction error. Since $z^4 \times z^k = z^{4+k}$, the equation is $4 + k = 11$, so $k = 7$.

## Card 19 — `basic`

**Front:** Solve $\frac{x^5}{x^a} = x^8$ for $a$.

**Back:** $$a = -3$

**Choices:**

- $$a = -3$ ✔
  - _why:_ Dividing powers with the same base subtracts the denominator’s index, so $5-a=8$. Hence $-a=3$, which gives $a=-3$.
- $$a = 3$
  - _why:_ This loses the negative sign when solving $5-a=8$. Subtracting 5 gives $-a=3$, so multiplying by $-1$ gives the correct answer $a=-3$.
- $$a = 13$
  - _why:_ This comes from reversing the order of the exponent subtraction. The quotient is $x^{5-a}$, not $x^{a-5}$, so $5-a=8$ and $a=-3$.
- $$a = \frac{5}{8}$
  - _why:_ Indices are subtracted, not divided, when powers with the same base are divided. Therefore the equation is $5-a=8$, which solves to $a=-3$.

## Card 20 — `basic`

**Front:** Work out the value of $\frac{2^7 \times 2^{-2}}{2^3}$ using index laws.

**Back:** 4

**Choices:**

- 4 ✔
  - _why:_ Combining the indices gives $2^{7+(-2)-3}=2^2$. Since $2^2=4$, the value of the expression is 4.
- 2
  - _why:_ This gives the resulting index rather than evaluating the power. The expression simplifies to $2^{7-2-3}=2^2$, and $2^2=4$.
- 16
  - _why:_ This results from ignoring the factor $2^{-2}$. All three powers must be combined: $2^{7+(-2)-3}=2^2$, so the value is 4.
- 64
  - _why:_ This treats the index $-2$ as positive 2, producing $2^6$. The negative index must remain negative, so $7+(-2)-3=2$ and the value is 4.
