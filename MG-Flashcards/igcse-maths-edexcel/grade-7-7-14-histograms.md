## Card 1 — `cloze`

**Front:** A histogram is used for grouped [ ___ ] data.

**Back:** A histogram is used for grouped continuous data.

**Choices:**

- continuous ✔
  - _why:_ Histograms represent grouped continuous data because measurements can take any value within each class interval, and the bars cover adjoining numerical ranges.
- discrete
  - _why:_ Discrete data consists of separate, countable values and is usually represented using a bar chart. The correct term is continuous because histogram classes cover uninterrupted ranges.
- categorical
  - _why:_ Categorical data is divided into named groups rather than numerical intervals and is normally shown on a bar chart. Histograms are used for grouped continuous data.
- ungrouped
  - _why:_ Ungrouped data lists individual observations rather than organising them into class intervals. A histogram is specifically used to represent grouped continuous data.

## Card 2 — `cloze`

**Front:** In a bar chart, [ ___ ] shows frequency; in a histogram, [ ___ ] shows frequency.

**Back:** In a bar chart, height shows frequency; in a histogram, area shows frequency.

**Choices:**

- In a bar chart, height shows frequency; in a histogram, area shows frequency. ✔
  - _why:_ Bar-chart frequencies are read directly from bar heights. In a histogram, frequency is proportional to bar area because class intervals can have different widths.
- In a bar chart, area shows frequency; in a histogram, height shows frequency.
  - _why:_ This reverses the two conventions. Height represents frequency in a bar chart, whereas area represents frequency in a histogram because histogram class widths may vary.
- In a bar chart, width shows frequency; in a histogram, area shows frequency.
  - _why:_ Bar width does not encode frequency in a bar chart; the height does. Histogram frequency is represented by area, calculated from class width and frequency density.
- In a bar chart, height shows frequency; in a histogram, width shows frequency.
  - _why:_ Histogram width represents the class width, not the frequency. Frequency is represented by the bar’s area, while bar-chart frequency is represented by height.

## Card 3 — `cloze`

**Front:** In a histogram, bar width is [ ___ ] and bar height is [ ___ ].

**Back:** In a histogram, bar width is class width and bar height is frequency density.

**Choices:**

- In a histogram, bar width is class width and bar height is frequency density. ✔
  - _why:_ Each bar spans its class interval, so its width is the class width. Its height is frequency density, ensuring that the bar’s area represents frequency.
- In a histogram, bar width is class width and bar height is frequency.
  - _why:_ The width is correctly identified, but histogram height is frequency density, not frequency. Multiplying frequency density by class width gives the frequency represented by the area.
- In a histogram, bar width is frequency density and bar height is class width.
  - _why:_ This swaps the two quantities. Bar width represents class width along the horizontal axis, while bar height represents frequency density on the vertical axis.
- In a histogram, bar width is class midpoint and bar height is cumulative frequency.
  - _why:_ A class midpoint is a single central value, not a bar width, and cumulative frequency belongs to cumulative frequency graphs. The required quantities are class width and frequency density.

## Card 4 — `cloze`

**Front:** The interval $0 \le t < 5$ includes 0 but not [ ___ ].

**Back:** The interval $0 \le t < 5$ includes 0 but not 5.

**Choices:**

- 5 ✔
  - _why:_ The strict inequality $t < 5$ excludes the upper endpoint 5, while the inequality $0 \le t$ includes the lower endpoint 0.
- 0
  - _why:_ The symbol $\le$ means 0 is included in the interval. The excluded endpoint is 5 because the strict inequality $t < 5$ does not include equality.
- 4
  - _why:_ Values below 5, including 4, are contained in the interval. The upper endpoint 5 is excluded because the inequality uses $<$ rather than $\le$.
- 6
  - _why:_ Although 6 is outside the interval, it is not the endpoint being tested. The notation specifically includes 0 but excludes the upper boundary 5.

## Card 5 — `cloze`

**Front:** Class width = [ ___ ].

**Back:** Class width = upper boundary - lower boundary.

**Choices:**

- upper boundary - lower boundary ✔
  - _why:_ Class width measures the distance from the lower boundary to the upper boundary, so it is calculated by subtracting the lower boundary from the upper boundary.
- lower boundary - upper boundary
  - _why:_ Reversing the subtraction produces a negative value for an ordinary class interval. Class width is found using upper boundary - lower boundary.
- upper boundary + lower boundary
  - _why:_ Adding the boundaries does not measure the size of the interval and may instead relate to finding twice its midpoint. Class width uses upper boundary - lower boundary.
- upper boundary - class midpoint
  - _why:_ Subtracting the midpoint from the upper boundary gives only half the class width for a standard interval. The full width is upper boundary - lower boundary.

## Card 6 — `cloze`

**Back:** A histogram’s vertical axis shows frequency density and its horizontal axis shows class intervals.

**Choices:**

- A histogram’s vertical axis shows frequency density and its horizontal axis shows class intervals. ✔
  - _why:_ Frequency density determines each bar’s height and is plotted vertically. The horizontal axis contains the continuous class intervals whose widths form the bases of the bars.
- A histogram’s vertical axis shows frequency and its horizontal axis shows class intervals.
  - _why:_ Frequency is represented by bar area, not generally by the vertical axis. The vertical axis shows frequency density, while the horizontal axis shows class intervals.
- A histogram’s vertical axis shows frequency density and its horizontal axis shows frequency.
  - _why:_ The horizontal axis represents the measured variable divided into class intervals, not frequency. Frequency density is vertical, and each bar’s area gives its frequency.
- A histogram’s vertical axis shows class intervals and its horizontal axis shows frequency density.
  - _why:_ This reverses the axes. Class intervals run along the horizontal axis, while frequency density is plotted on the vertical axis to determine bar height.

## Card 9 — `basic`

**Front:** What formula gives frequency from class width and frequency density?

**Back:** $\text{frequency}=\text{class width}\times\text{frequency density}$

**Choices:**

- $\text{frequency}=\text{class width}\times\text{frequency density}$ ✔
  - _why:_ A histogram bar’s frequency is represented by its area. Multiplying the class width by the frequency density gives this area and therefore the class frequency.
- $\text{frequency}=\dfrac{\text{frequency density}}{\text{class width}}$
  - _why:_ Dividing frequency density by class width does not calculate the bar’s area. Frequency is found by multiplying class width by frequency density.
- $\text{frequency}=\dfrac{\text{class width}}{\text{frequency density}}$
  - _why:_ This incorrectly divides the class width by the bar height. Histogram frequency is the bar’s area, so class width must be multiplied by frequency density.
- $\text{frequency}=\text{class width}+\text{frequency density}$
  - _why:_ Adding the width and density confuses the dimensions of the histogram bar. Its frequency is represented by area, calculated as class width multiplied by frequency density.

## Card 11 — `basic`

**Front:** Why is height alone not the frequency when class widths are unequal?

**Back:** Frequency is area: width $\times$ height.

**Choices:**

- Frequency is area: width $\times$ height. ✔
  - _why:_ In a histogram, frequency is represented by each bar’s area. Therefore both class width and frequency density, shown by height, determine the frequency.
- Frequency is height: the frequency density alone.
  - _why:_ Height represents frequency density, not frequency. When class widths differ, equal heights can produce different areas, so frequency must be calculated as width multiplied by height.
- Frequency is width: upper boundary $-$ lower boundary.
  - _why:_ The difference between the class boundaries gives only the class width. Frequency is represented by the whole bar area, calculated as width multiplied by height.
- Frequency is perimeter: $2\times($width $+$ height$)$.
  - _why:_ A bar’s perimeter has no statistical meaning in a histogram. Frequency is represented by area, so it is found by multiplying the class width by the height.

## Card 12 — `basic`

**Front:** What formula gives frequency density from frequency and class width?

**Back:** $\text{frequency density}=\dfrac{\text{frequency}}{\text{class width}}$

**Choices:**

- $\text{frequency density}=\dfrac{\text{frequency}}{\text{class width}}$ ✔
  - _why:_ Frequency equals class width multiplied by frequency density. Rearranging this relationship gives frequency density as frequency divided by class width.
- $\text{frequency density}=\dfrac{\text{class width}}{\text{frequency}}$
  - _why:_ This reverses the required division. Since frequency equals class width multiplied by frequency density, divide frequency by class width to obtain frequency density.
- $\text{frequency density}=\text{frequency}\times\text{class width}$
  - _why:_ Multiplication is used to recover frequency from density and width, not to find density. Frequency density is frequency divided by class width.
- $\text{frequency density}=\text{frequency}-\text{class width}$
  - _why:_ Subtracting class width from frequency does not represent the histogram relationship. Frequency density is calculated by dividing the frequency by the class width.

## Card 16 — `basic`

**Front:** Two bars have the same height. One class is twice as wide. How do the frequencies compare?

**Back:** The wider class has twice the frequency.

**Choices:**

- The wider class has twice the frequency. ✔
  - _why:_ Equal heights mean equal frequency densities. Since frequency is width multiplied by height, doubling the width while keeping the height fixed doubles the frequency.
- The wider class has the same frequency.
  - _why:_ Equal bar heights mean equal frequency densities, not equal frequencies. The wider bar has twice the area, so its class has twice the frequency.
- The wider class has half the frequency.
  - _why:_ This reverses the effect of increasing class width. With equal heights, doubling the width doubles the bar’s area and therefore doubles the frequency.
- The wider class has four times the frequency.
  - _why:_ This incorrectly treats frequency as if both dimensions had doubled. Only the width doubles while height stays fixed, so the area and frequency merely double.

## Card 20 — `basic`

**Front:** What assumption is made when estimating frequency within part of a class interval?

**Back:** The data is evenly spread within the class.

**Choices:**

- The data is evenly spread within the class. ✔
  - _why:_ A histogram does not show how values are distributed inside each class. Estimating a proportion of a class therefore assumes uniform distribution within that interval.
- The data is concentrated at the midpoint within the class.
  - _why:_ Equal concentration at the midpoint would not justify using widths to estimate proportions. The required assumption is that the data is evenly spread throughout the class.
- The data is increasing steadily within the class.
  - _why:_ A steadily increasing distribution would place more observations near the upper boundary and make area proportions invalid. The estimate assumes the data is evenly spread within the class.
- The data is decreasing steadily within the class.
  - _why:_ A steadily decreasing distribution would place more observations near the lower boundary. Proportional estimation instead relies on assuming that the data is evenly spread within the class.
