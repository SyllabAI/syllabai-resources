## Card 1 — `cloze`

**Front:** The equals sign in an equation means both sides have the [ ___ ], not write the answer next.

**Back:** The equals sign in an equation means both sides have the same value, not write the answer next.

**Choices:**

- same value ✔
  - _why:_ An equation states that the expressions on its left and right represent the same value, even when they are written in different forms.
- same number of terms
  - _why:_ The two sides do not need the same number of terms. They must have the same value, such as $2+3$ and $5$.
- different values
  - _why:_ Different values would make the equation false. The equals sign states that the expression on each side has the same value.
- answer written next
  - _why:_ An equals sign does not simply introduce an answer, as it may connect two expressions. It means that both sides have the same value.

## Card 2 — `cloze`

**Front:** The balance rule: doing the [ ___ ] to [ ___ ] keeps an equation true.

**Back:** The balance rule: doing the same operation to both sides keeps an equation true.

**Choices:**

- The balance rule: doing the same operation to both sides keeps an equation true. ✔
  - _why:_ Applying the same operation to both sides preserves equality because both sides are changed equally, maintaining the balance represented by the equation.
- The balance rule: doing the same operation to one side keeps an equation true.
  - _why:_ Changing only one side usually destroys the equality. The balance rule requires the same operation to be applied to both sides.
- The balance rule: doing the different operations to both sides keeps an equation true.
  - _why:_ Applying different operations changes the sides by unequal amounts or factors. An equation remains balanced when the same operation is performed on both sides.
- The balance rule: doing the inverse operations to opposite sides keeps an equation true.
  - _why:_ Using inverse operations on opposite sides does not preserve equality because the sides change differently. Instead, perform the same operation on both sides.

## Card 3 — `cloze`

**Front:** Adding is undone by [ ___ ]; multiplying is undone by [ ___ ].

**Back:** Adding is undone by subtracting; multiplying is undone by dividing.

**Choices:**

- Adding is undone by subtracting; multiplying is undone by dividing. ✔
  - _why:_ Subtraction reverses addition, while division reverses multiplication. These inverse operations allow terms and coefficients to be removed when solving equations.
- Adding is undone by subtracting; multiplying is undone by subtracting.
  - _why:_ Subtraction correctly reverses addition, but it does not reverse multiplication. Multiplication must be undone by dividing by the same non-zero number.
- Adding is undone by dividing; multiplying is undone by dividing.
  - _why:_ Division correctly reverses multiplication, but it does not reverse addition. Addition must be undone by subtracting the same amount.
- Adding is undone by multiplying; multiplying is undone by adding.
  - _why:_ Multiplying does not reverse addition, and adding does not reverse multiplication. The required inverse operations are subtracting and dividing respectively.

## Card 4 — `basic`

**Front:** Find the missing number: $9+\Box=16$.

**Back:** $7$.

**Choices:**

- $7$. ✔
  - _why:_ Subtracting $9$ from both sides gives the missing number: $16-9=7$. Checking confirms that $9+7=16$.
- $25$.
  - _why:_ Adding $9$ and $16$ instead of finding their difference produces $25$. The missing number is $16-9=7$.
- $-7$.
  - _why:_ Reversing the subtraction as $9-16$ creates an unnecessary negative answer. The required calculation is $16-9=7$.
- $6$.
  - _why:_ This is an off-by-one subtraction error. Taking $9$ from $16$ gives $7$, and $9+7$ checks correctly as $16$.

## Card 5 — `basic`

**Front:** Solve $x+5=18$.

**Back:** $x=13$.

**Choices:**

- $x=13$. ✔
  - _why:_ Subtracting $5$ from both sides isolates $x$, giving $x=18-5=13$. Substitution confirms that $13+5=18$.
- $x=23$.
  - _why:_ Adding $5$ to $18$ applies the inverse operation in the wrong direction. Subtracting $5$ from both sides gives $x=13$.
- $x=90$.
  - _why:_ Multiplying $18$ by $5$ confuses an additive equation with a multiplicative one. Since $5$ is added, subtract it to obtain $x=13$.
- $x=3.6$.
  - _why:_ Dividing $18$ by $5$ does not undo adding $5$. The correct inverse operation is subtraction, so $x=18-5=13$.

## Card 7 — `cloze`

**Front:** A letter next to a number means [ ___ ]; a fraction bar means [ ___ ].

**Back:** A letter next to a number means multiplication; a fraction bar means division.

**Choices:**

- A letter next to a number means multiplication; a fraction bar means division. ✔
  - _why:_ In algebra, adjacency indicates multiplication, so $3x$ means $3\times x$. A fraction bar indicates that the numerator is divided by the denominator.
- A letter next to a number means addition; a fraction bar means division.
  - _why:_ A number written beside a letter is multiplied by it, not added to it. The fraction bar does correctly represent division.
- A letter next to a number means multiplication; a fraction bar means multiplication.
  - _why:_ Adjacency correctly represents multiplication, but a fraction bar represents division rather than multiplication. For example, $\frac{x}{2}$ means $x\div2$.
- A letter next to a number means division; a fraction bar means multiplication.
  - _why:_ These operations have been reversed. A number beside a letter indicates multiplication, while a fraction bar indicates division.

## Card 10 — `basic`

**Front:** How can you check a proposed solution to an equation?

**Back:** Substitute it into the original equation; both sides must match.

**Choices:**

- Substitute it into the original equation; both sides must match. ✔
  - _why:_ Replacing the variable with the proposed value tests the complete original equation. The value is a solution only when both sides evaluate to the same result.
- Round it before putting it into the original equation; both sides must be close.
  - _why:_ Rounding can conceal an incorrect value, and being close is not sufficient for an exact equation. Substitute the proposed value unchanged; both sides must match exactly.
- Substitute it into one side of the original equation; that side must simplify.
  - _why:_ Checking only one side gives no comparison and cannot establish equality. Substitute the value throughout the original equation and verify that both sides have equal values.
- Rearrange the original equation until the proposed solution appears on one side.
  - _why:_ Rearranging may reproduce an algebraic error and does not directly verify the proposed value. Substitute it into the original equation and check that both sides match.

## Card 11 — `cloze`

**Front:** In a two-step equation, usually undo [ ___ ] before [ ___ ].

**Back:** In a two-step equation, usually undo addition or subtraction before multiplication or division.

**Choices:**

- In a two-step equation, usually undo addition or subtraction before multiplication or division. ✔
  - _why:_ Inverse operations are normally applied in reverse order. Since multiplication or division acts on the variable before addition or subtraction, the added or subtracted term is undone first.
- In a two-step equation, usually undo multiplication or division before addition or subtraction.
  - _why:_ This follows the original order rather than reversing it. Usually remove addition or subtraction first, then undo multiplication or division to isolate the variable.
- In a two-step equation, usually undo the operation nearest the variable before the operation furthest from the variable.
  - _why:_ Starting nearest the variable reverses the required solving order. Undo the outer operation first - usually addition or subtraction - before undoing multiplication or division.
- In a two-step equation, usually undo operations on the right-hand side before operations on the left-hand side.
  - _why:_ Equations are solved by applying inverse operations to both sides, not by clearing one side first. Usually undo addition or subtraction before multiplication or division.

## Card 14 — `basic`

**Front:** Expand $4(x-3)$ correctly.

**Back:** $4x-12$.

**Choices:**

- $4x-12$. ✔
  - _why:_ The multiplier $4$ applies to both terms inside the brackets: $4\times x=4x$ and $4\times(-3)=-12$, giving $4x-12$.
- $4x-3$.
  - _why:_ Only the $x$ term has been multiplied by $4$. The multiplier must distribute to both terms, so $4(x-3)=4x-12$.
- $4x-7$.
  - _why:_ Subtracting $4$ from $3$ does not distribute the multiplier. Multiply both $x$ and $-3$ by $4$ to obtain $4x-12$.
- $x-12$.
  - _why:_ The constant has been multiplied by $4$, but the $x$ term has not. Distribution applies to every term, so the correct expansion is $4x-12$.

## Card 19 — `cloze`

**Front:** Like terms have the [ ___ ]; variable terms should be collected on [ ___ ].

**Back:** Like terms have the same variable part; variable terms should be collected on one side.

**Choices:**

- Like terms have the same variable part; variable terms should be collected on one side. ✔
  - _why:_ Like terms contain identical variables raised to identical powers, so they share the same variable part. Collecting variable terms on one side allows the equation to be simplified and solved.
- Like terms have the same coefficient; variable terms should be collected on one side.
  - _why:_ Coefficients do not need to match for terms to be like terms; for example, $3x$ and $7x$ are like terms. They must have the same variable part.
- Like terms have the same variable part; variable terms should be collected on both sides.
  - _why:_ Leaving variable terms on both sides does not complete the collection step. They should be moved to one side, while their identical variable parts determine whether they are like terms.
- Like terms have the same coefficient; variable terms should be collected on both sides.
  - _why:_ This confuses coefficients with variable parts and leaves variables uncollected. Like terms share the same variable part, and variable terms should be gathered on one side of the equation.
