# The Product Rule for Counting Flashcards

_Lane: `gcse-maths-edexcel` · grade 6 · 20 cards (source: MathsGenie flashcards)_

## Card 1 — `basic`

**Front:** A task has $a$ options at stage one and $b$ options at stage two. How is the total number of outcomes calculated?

**Back:** Multiply the options: $a \times b$.

**Choices:**

- Multiply the options: $a \times b$. ✔
  - _why:_ For two independent stages, each of the $a$ first choices can be paired with each of the $b$ second choices, so the total is found by multiplication.
- Add the options: $a + b$.
  - _why:_ Adding counts the total number of individual choices available, not the number of two-stage outcomes. The product rule uses $a \times b$ because every first choice can pair with every second choice.
- Subtract the options: $a - b$.
  - _why:_ Subtraction would compare the two numbers of choices rather than count all possible pairings. For a two-stage task, the total number of outcomes is $a \times b$.
- Divide the options: $a \div b$.
  - _why:_ Division shares one number of choices by the other, which does not count combinations. The correct product rule is $a \times b$, one pairing for each first-stage and second-stage choice.

## Card 2 — `cloze`

**Front:** When choosing one item from each of several separate groups, you must [ ___ ] the number of choices in each group.

**Back:** When choosing one item from each of several separate groups, you must multiply the number of choices in each group.

**Choices:**

- multiply ✔
  - _why:_ Separate groups of choices form combinations by pairing each choice from one group with each choice from the others, so the numbers of choices must be multiplied.
- add
  - _why:_ Adding is tempting because it finds the total number of items, but it does not count combinations. Choosing one item from each separate group requires multiplying the group sizes.
- subtract
  - _why:_ Subtraction compares two quantities instead of counting all possible selections. For one choice from each group, use multiplication so every possible pairing is included.
- divide
  - _why:_ Division would split or share choices, not count the combinations formed across groups. The product rule says to multiply the number of choices in each group.

## Card 3 — `basic`

**Front:** A lunch offer has 2 wraps and 3 drinks. How many possible lunch combinations are there?

**Back:** $$2 \times 3 = 6$.

**Choices:**

- $$2 \times 3 = 6$. ✔
  - _why:_ Each of the 2 wraps can be matched with each of the 3 drinks, giving $2 \times 3 = 6$ possible lunch combinations.
- $$2 + 3 = 5$.
  - _why:_ Adding counts the number of menu items, not the number of wrap-and-drink pairings. The product rule gives $2 \times 3 = 6$ combinations.
- $$3 - 2 = 1$.
  - _why:_ Subtracting only compares the numbers of wraps and drinks, so it cannot count possible lunches. Each wrap pairs with each drink, giving $2 \times 3 = 6$.
- $$2^3 = 8$.
  - _why:_ Using a power treats the choice as if there were 3 repeated stages with 2 options each. There are just 2 wraps and 3 drinks, so $2 \times 3 = 6$.

## Card 4 — `basic`

**Front:** Why is addition ($11 + 13$) incorrect for finding the number of boy-and-girl pairs from 11 boys and 13 girls?

**Back:** Addition gives the total number of students, not the number of possible combinations.

**Choices:**

- Addition gives the total number of students, not the number of possible combinations. ✔
  - _why:_ The sum $11 + 13$ counts students separately. A boy-and-girl pair needs one choice from each group, so the number of possible pairs comes from multiplying.
- Addition gives the number of boys only, not the number of possible combinations.
  - _why:_ The sum $11 + 13$ does not give the number of boys only; it gives the total number of students. The real issue is that pairs require multiplication, not addition.
- Addition gives the number of girls only, not the number of possible combinations.
  - _why:_ The sum $11 + 13$ does not give the number of girls only; it gives all students together. To count boy-and-girl pairs, multiply the two group sizes.
- Addition gives the number in one pair, not the number of possible combinations.
  - _why:_ One pair contains 2 students, not $11 + 13$ students. Adding gives the total number of students, while multiplying counts every possible boy-and-girl pairing.

## Card 5 — `cloze`

**Front:** In counting problems, a calculated number of choices ($x$) must always be a [ ___ ].

**Back:** In counting problems, a calculated number of choices ($x$) must always be a whole number.

**Choices:**

- whole number ✔
  - _why:_ A number of choices counts actual possible options, so it cannot be a part of an option or a negative amount. It must be a whole number.
- proper fraction
  - _why:_ A proper fraction would mean less than one complete choice, which is impossible when counting outcomes. A calculated number of choices must be a whole number.
- negative number
  - _why:_ A negative value would mean fewer than no choices, which cannot represent a count of outcomes. Counts in these problems must be whole numbers.
- prime number
  - _why:_ Some numbers of choices are prime, but many valid counts are not, such as 6 or 12. The necessary condition is being a whole number.

## Card 6 — `basic`

**Front:** A restaurant offers 4 starters, 6 mains, and 3 desserts. How many different three-course meals are possible?

**Back:** $$4 \times 6 \times 3 = 72$.

**Choices:**

- $$4 \times 6 \times 3 = 72$. ✔
  - _why:_ A three-course meal is formed by choosing one starter, one main, and one dessert. The product rule gives $4 \times 6 \times 3 = 72$ meals.
- $$4 + 6 + 3 = 13$.
  - _why:_ Adding counts the total number of dishes on the menu, not the number of meals. Each starter can combine with each main and dessert, so $4 \times 6 \times 3 = 72$.
- $$4 \times 6 + 3 = 27$.
  - _why:_ This multiplies starters and mains but then only adds desserts, missing that each dessert can go with every starter-main pair. The correct calculation is $4 \times 6 \times 3 = 72$.
- $$4 \times 3 \times 6 = 72$.
  - _why:_ Although this gives the same value, it does not match the stated order of starters, mains, and desserts. The intended product-rule calculation is $4 \times 6 \times 3 = 72$.

## Card 7 — `basic`

**Front:** What condition must be met to use the product rule directly for multiple stages?

**Back:** Every option at one stage must be allowed to go with every option at the next stage.

**Choices:**

- Every option at one stage must be allowed to go with every option at the next stage. ✔
  - _why:_ The product rule works directly only when there are no restrictions between stages. Then each choice at one stage can be paired with every choice at the next.
- Every option at one stage must be different to go with every option at the next stage.
  - _why:_ Options being different is not the key condition; restrictions are. The product rule applies directly when every option at one stage is allowed with every option at the next.
- Every option at one stage must be equally likely to go with every option at the next stage.
  - _why:_ Equally likely choices matter in probability, not in simply counting outcomes. For the product rule, the requirement is that every cross-stage combination is allowed.
- Every option at one stage must be chosen to go with every option at the next stage.
  - _why:_ You do not choose every option; you choose one option at each stage. Direct multiplication is valid when each possible first choice is allowed with each possible next choice.

## Card 8 — `basic`

**Front:** A shop has 8 sandwiches and $x$ drinks. Sam claims there are 90 meal deal outcomes. Why is Sam wrong?

**Back:** $90 \div 8 = 11.25$The number of drinks must be a whole number.

**Choices:**

- $90 \div 8 = 11.25$The number of drinks must be a whole number. ✔
  - _why:_ If there are 8 sandwiches and $x$ drinks, the outcomes are $8x$. Solving $8x = 90$ gives $x = 11.25$, which cannot be a count of drinks.
- $90 \times 8 = 720$The number of drinks must be a whole number.
  - _why:_ Multiplying by 8 is the reverse of the required step. Since $8x = 90$, divide by 8 to get $x = 11.25$, not a whole number.
- $90 \div 8 = 11.25$The number of drinks can be a decimal.
  - _why:_ The division is right, but the conclusion is not. A shop cannot have 11.25 drink choices, so the number of drinks must be a whole number.
- $90 \div 8 = 12$The number of drinks must be a whole number.
  - _why:_ This rounds the division instead of calculating it exactly. $90 \div 8 = 11.25$, and that non-whole result is why Sam’s claim cannot be correct.

## Card 9 — `cloze`

**Front:** Choosing "without replacement" means the number of options for the next stage [ ___ ].

**Back:** Choosing "without replacement" means the number of options for the next stage decreases by 1.

**Choices:**

- decreases by 1 ✔
  - _why:_ Once an item has been selected without replacement, it is unavailable at the next stage. Therefore, the number of available options falls by exactly one.
- stays the same
  - _why:_ The number stays the same only when selection is with replacement. Without replacement, the chosen item is unavailable, so the number of options decreases by 1.
- increases by 1
  - _why:_ This reverses the effect of removing an item from the available choices. Without replacement, one option is used up, so the number decreases by 1.
- decreases by 2
  - _why:_ This assumes two options are removed after one choice. Only the selected item becomes unavailable, so the number of options decreases by 1.

## Card 10 — `basic`

**Front:** Two cards are dealt from a 52-card deck to two named people. How many outcomes are possible?

**Back:** $$52 \times 51 = 2652$.

**Choices:**

- $$52 \times 51 = 2652$. ✔
  - _why:_ The first named person can receive any of 52 cards, while the second can receive any of the remaining 51. The product rule gives $52 \times 51 = 2652$.
- $$52 \times 52 = 2704$.
  - _why:_ Using $52$ choices at both stages incorrectly allows the same card to be dealt twice. Without replacement, the correct calculation is $52 \times 51 = 2652$.
- $$\frac{52 \times 51}{2} = 1326$.
  - _why:_ Dividing by 2 treats the recipients as interchangeable. Because the two people are named, swapping their cards creates a different outcome, giving $52 \times 51 = 2652$.
- $$51 \times 51 = 2601$.
  - _why:_ Using $51$ choices for both stages omits one possible first card. There are 52 initial choices and then 51 remaining choices, giving $2652$.

## Card 11 — `basic`

**Front:** Why is the second stage $51$ instead of $52$ when dealing two cards from a deck?

**Back:** One card has already been removed and cannot be chosen again.

**Choices:**

- One card has already been removed and cannot be chosen again. ✔
  - _why:_ Dealing is without replacement, so the first card is no longer available for the second person. This leaves exactly 51 possible cards at the second stage.
- One card has already been removed but can be chosen again.
  - _why:_ A removed card cannot immediately be selected again when dealing without replacement. Consequently, the second stage has 51 available cards rather than 52.
- One person has already been named and cannot be chosen again.
  - _why:_ The number falls because one physical card has been removed, not because the recipients are named. After the first deal, only 51 cards remain available.
- One ordering has already been counted and cannot be counted again.
  - _why:_ Dividing for reversed arrangements applies to unordered pairs, not to the number of second-stage choices. The second stage is 51 because one card has been removed.

## Card 12 — `basic`

**Front:** When calculating unordered pairs from $n$ items, what is the formula?

**Back:** $$$\frac{n(n-1)}{2}$$

**Choices:**

- $$$\frac{n(n-1)}{2}$$ ✔
  - _why:_ There are $n(n-1)$ ordered selections of two distinct items. Each unordered pair appears in both possible orders, so dividing by 2 gives $\frac{n(n-1)}{2}$.
- $$$n(n-1)$$
  - _why:_ This counts every unordered pair twice because it retains both possible orders. Dividing by 2 is required, so the correct formula is $\frac{n(n-1)}{2}$.
- $$$\frac{n(n+1)}{2}$$
  - _why:_ The second factor must be $n-1$ because the first selected item cannot be selected again. Unordered pairs are therefore counted by $\frac{n(n-1)}{2}$.
- $$$\frac{(n-1)(n-2)}{2}$$
  - _why:_ This incorrectly removes two choices before either item has been selected. There are $n$ first choices and $n-1$ second choices, then division by 2.

## Card 13 — `cloze`

**Front:** For handshakes or matches, we [ ___ ] because each pair is counted twice (e.g., A-B and B-A).

**Back:** For handshakes or matches, we divide by 2 because each pair is counted twice (e.g., A-B and B-A).

**Choices:**

- divide by 2 ✔
  - _why:_ The product $n(n-1)$ counts A-B and B-A separately. Since these represent the same handshake or match, dividing by 2 counts each pair once.
- multiply by 2
  - _why:_ Multiplying by 2 would count each pair four times after both orders are already included. The duplicate orderings must instead be removed by dividing by 2.
- subtract 2
  - _why:_ Subtracting 2 removes only two outcomes, rather than one duplicate for every pair. Because every pair is counted twice, the total must be divided by 2.
- divide by 4
  - _why:_ Dividing by 4 removes too many outcomes because each pair appears only twice, not four times. The correct adjustment is therefore to divide by 2.

## Card 14 — `basic`

**Front:** 28 students are in a class. Two are chosen for the same prize. How many possible pairs are there?

**Back:** $$$\frac{28 \times 27}{2} = 378$$

**Choices:**

- $$$\frac{28 \times 27}{2} = 378$$ ✔
  - _why:_ There are $28 \times 27$ ordered selections of two different students. Because the prize is the same, each pair is counted in both orders, giving $378$ after division by 2.
- $$$28 \times 27 = 756$$
  - _why:_ This counts each pair twice, once in each selection order. Since both students receive the same prize, order is irrelevant and division by 2 gives $378$.
- $$$28 \times 28 = 784$$
  - _why:_ Squaring 28 incorrectly allows the same student to occupy both selections and also treats order as significant. Distinct unordered pairs give $\frac{28 \times 27}{2}=378$.
- $$$\frac{27 \times 26}{2} = 351$$
  - _why:_ This starts with 27 rather than all 28 possible first students, creating an off-by-one error. The correct calculation is $\frac{28 \times 27}{2}=378$.

## Card 15 — `basic`

**Front:** 9 teams play each other once in a league. How many games are played?

**Back:** $$$\frac{9 \times 8}{2} = 36$$

**Choices:**

- $$$\frac{9 \times 8}{2} = 36$$ ✔
  - _why:_ Each of the 9 teams can face 8 others, producing 72 ordered listings. Every game appears from both teams’ perspectives, so division by 2 gives 36.
- $$$9 \times 8 = 72$$
  - _why:_ This counts every game twice, once from each team’s perspective. Since a game between A and B is the same as B against A, the answer is 36.
- $$$9 \times 9 = 81$$
  - _why:_ Using $9^2$ incorrectly includes each team playing itself and counts games between different teams twice. The correct calculation is $\frac{9 \times 8}{2}=36$.
- $$$\frac{8 \times 7}{2} = 28$$
  - _why:_ This calculation uses only 8 teams, omitting one team and all its fixtures. With 9 teams, the correct total is $\frac{9 \times 8}{2}=36$.

## Card 16 — `cloze`

**Front:** If two people are chosen for different roles, you [ ___ ] divide by 2.

**Back:** If two people are chosen for different roles, you do not divide by 2.

**Choices:**

- do not ✔
  - _why:_ Different roles make order significant: choosing A then B assigns them differently from choosing B then A. Both assignments must remain, so division by 2 is inappropriate.
- always
  - _why:_ Dividing by 2 would wrongly merge two distinct role assignments. When the roles differ, swapping the chosen people changes the outcome, so you do not divide by 2.
- must
  - _why:_ Division by 2 is required for identical roles or unordered pairs, not different roles. Different assignments remain separate outcomes, so you do not divide by 2.
- should
  - _why:_ This confuses different roles with an unordered selection. Since reversing the two people changes who holds each role, both orders count and you do not divide by 2.

**Choices:**

- Option: A choice at a single stage.Outcome: A complete result after all stages. ✔

  - _why:_ This confuses individual choices and results with lists and methods. An option is a choice at one stage, while an outcome is a complete result after all stages.

## Card 18 — `cloze`

**Front:** In product rule questions, the word [ ___ ] usually indicates that you should multiply the choices.

**Back:** In product rule questions, the word "and" usually indicates that you should multiply the choices.

**Choices:**

- "and" ✔
  - _why:_ The word "and" links successive stages that must all occur. The product rule therefore multiplies the number of choices available at each stage.
- "or"
  - _why:_ The word "or" usually indicates alternative cases whose numbers of outcomes should be added. The word "and" links successive stages, so their choices are multiplied.
- "not"
  - _why:_ The word "not" indicates an exclusion or restriction, rather than the product rule. The word "and" usually signals that choices from successive stages should be multiplied.
- "only"
  - _why:_ The word "only" places a restriction on the permitted outcomes and does not itself signal multiplication. The usual product-rule indicator is the word "and".

## Card 19 — `basic`

**Front:** When should you divide by 2 in a counting problem?

**Back:** When making pairs, matches, or handshakes where the order does not matter.

**Choices:**

- When making pairs, matches, or handshakes where the order does not matter. ✔
  - _why:_ Choosing A with B and choosing B with A describe the same unordered pair. Basic multiplication counts each pair twice, so dividing by 2 corrects the duplication.
- When making lists, codes, or passwords where the order does matter.
  - _why:_ Ordered lists, codes, and passwords treat different arrangements as different outcomes, so dividing by 2 would wrongly remove valid results. Division by 2 applies to unordered pairs counted twice.
- When making pairs, matches, or handshakes where the order does matter.
  - _why:_ If order matters, AB and BA are distinct outcomes and should both remain counted. Divide by 2 only for pairs, matches, or handshakes where order does not matter.
- When making choices, selections, or decisions where the stages are independent.
  - _why:_ Independent successive stages normally require multiplying their numbers of options, not dividing by 2. Division is needed for unordered pairs when multiplication has counted each pair twice.
