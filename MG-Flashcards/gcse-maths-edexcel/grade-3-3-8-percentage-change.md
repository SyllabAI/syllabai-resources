## Card 1 — `basic`

**Front:** What does the term percentage literally mean?

**Back:** Out of 100.

**Choices:**

- Out of 100. ✔
  - _why:_ Percentage means “per hundred”, so a percentage expresses an amount as a number of parts out of 100.
- Out of 10.
  - _why:_ This confuses percentages with tenths. The word percentage means “per hundred”, so it describes an amount out of 100.
- Out of 1000.
  - _why:_ An amount out of 1000 is expressed in thousandths, not as a percentage. Percentage literally means an amount out of 100.
- Out of 1.
  - _why:_ An amount out of 1 is a decimal proportion. A percentage rescales that proportion so that it is expressed out of 100.

## Card 2 — `cloze`

**Front:** The formula for percentage change is: $$\text{percentage change} = \frac{\text{[...]}}{\text{original value}} \times 100$$

**Back:** The formula for percentage change is: $$\text{percentage change} = \frac{\boxed{\text{change}}}{\text{original value}} \times 100$$

**Choices:**

- $$\text{change}$ ✔
  - _why:_ Percentage change compares the amount of change with the original value, so the change must be placed in the numerator.
- $$\text{new value}$
  - _why:_ Using the new value gives its size relative to the original, not the percentage change. The numerator must be the change between the two values.
- $$\text{original value}$
  - _why:_ Putting the original value in both numerator and denominator would always produce 100%. The numerator must instead be the change.
- $$\text{sum of values}$
  - _why:_ Adding the original and new values does not measure how much the value changed. The numerator must be the difference, called the change.

## Card 3 — `cloze`

**Front:** The formula for percentage change is: $$\text{percentage change} = \frac{\text{change}}{\text{[...]}} \times 100$$

**Back:** The formula for percentage change is: $$\text{percentage change} = \frac{\text{change}}{\boxed{\text{original value}}} \times 100$$

**Choices:**

- $$\text{original value}$ ✔
  - _why:_ The original value is the comparison base, so percentage change is calculated by dividing the change by the original value and multiplying by 100.
- $$\text{new value}$
  - _why:_ Using the new value as the denominator compares the change with the final amount. Percentage change must use the original value as its base.
- $$\text{change}$
  - _why:_ Dividing the change by itself would give 1 and therefore 100%, regardless of the values. The denominator must be the original value.
- $$\text{average value}$
  - _why:_ Using the average of the original and new values calculates a different type of relative difference. Standard percentage change uses the original value.

## Card 4 — `basic`

**Back:** The original value.

**Choices:**

- The original value. ✔
  - _why:_ Percentage change measures the change relative to the starting amount, so the original value is always used as the denominator.
- The new value.
  - _why:_ The new value is the final amount, not the comparison base. Percentage change divides by the original value from before the change occurred.
- The difference value.
  - _why:_ The difference is the change and belongs in the numerator. The denominator is the original value because it provides the comparison base.
- The average value.
  - _why:_ Averaging the original and new values gives a different relative-change measure. GCSE percentage change uses the original value as the denominator.

## Card 5 — `basic`

**Front:** How do you calculate the change in a percentage change problem?

**Back:** The difference between the original and new values.

**Choices:**

- The difference between the original and new values. ✔
  - _why:_ The change is the amount separating the original and new values, found by subtracting one from the other and taking the appropriate increase or decrease.
- The sum of the original and new values.
  - _why:_ Adding the values finds their combined total, not how much one changed into the other. The change is their difference.
- The ratio between the original and new values.
  - _why:_ A ratio compares the relative sizes of the values but does not directly give the amount of change. The change is their difference.
- The average of the original and new values.
  - _why:_ The average gives a midpoint between the two values, not the distance between them. The change is found from their difference.

## Card 6 — `basic`

**Front:** How can you determine if a change is a percentage increase or decrease?

**Back:** Increase: new value is bigger than original.Decrease: new value is smaller than original.

**Choices:**

- Increase: new value is bigger than original.Decrease: new value is smaller than original. ✔
  - _why:_ An increase moves from a smaller original value to a larger new value, while a decrease moves from a larger original value to a smaller new value.
- Increase: new value is smaller than original.Decrease: new value is bigger than original.
  - _why:_ This reverses the two directions. A larger new value means an increase, while a smaller new value means a decrease.
- Increase: new value is equal to original.Decrease: new value is smaller than original.
  - _why:_ Equal original and new values represent no change, not an increase. An increase requires the new value to be bigger than the original.
- Increase: new value is bigger than original.Decrease: new value is equal to original.
  - _why:_ Equal values represent no change, not a decrease. A decrease occurs only when the new value is smaller than the original.

## Card 7 — `basic`

**Front:** What is the common mistake made when selecting the denominator for percentage change?

**Back:** Dividing by the new value instead of the original.

**Choices:**

- Dividing by the new value instead of the original. ✔
  - _why:_ Students often use the final value as the comparison base. Percentage change must instead compare the change with the original value.
- Dividing by the original value instead of the new.
  - _why:_ This incorrectly labels the correct method as a mistake. The original value is the required denominator, while using the new value is the common error.
- Dividing by the change value instead of the original.
  - _why:_ The change belongs in the numerator, so using it as the denominator is structurally wrong. The commonly tested denominator error is using the new value.
- Dividing by the larger value instead of the original.
  - _why:_ The denominator is not chosen according to which value is larger. The specific common mistake is automatically using the new value rather than the original.

## Card 8 — `cloze`

**Front:** In profit and loss questions, the original value is always the [ ___ ].

**Back:** In profit and loss questions, the original value is always the cost price.

**Choices:**

- cost price ✔
  - _why:_ Profit or loss is measured relative to what the item originally cost, so the cost price is the original value used as the denominator.
- selling price
  - _why:_ The selling price is the new value received after the transaction. The original value is the cost price paid for the item.
- profit amount
  - _why:_ Profit is the positive difference between selling price and cost price, not the original value. The original value is the cost price.
- loss amount
  - _why:_ Loss is the difference when the selling price is below the cost price, not the starting value. The original value is the cost price.

## Card 9 — `basic`

**Front:** In business terms, what is the difference between cost price and selling price?

**Back:** Cost price: amount paid to buy/make an item.Selling price: amount received when selling the item.

**Choices:**

- Cost price: amount paid to buy/make an item.Selling price: amount received when selling the item. ✔
  - _why:_ Cost price records what the item costs the business, while selling price records the amount paid by the customer when the business sells it.
- Cost price: amount received when selling an item.Selling price: amount paid to buy/make the item.
  - _why:_ This reverses the two definitions. Cost price is the amount paid to obtain or make the item, while selling price is the amount received from its sale.
- Cost price: amount of profit made on an item.Selling price: amount lost when selling the item.
  - _why:_ Profit and loss are differences between prices, not definitions of the prices themselves. Cost price is paid to obtain the item, and selling price is received from selling it.
- Cost price: amount shown on an item’s price label.Selling price: amount spent advertising the item.
  - _why:_ A price label usually shows the intended selling price, while advertising is a separate expense. Cost price is paid to obtain the item, and selling price is received from selling it.

## Card 10 — `basic`

**Front:** What determines if a transaction has resulted in a profit or a loss?

**Back:** Profit: Selling price is bigger than cost price.Loss: Selling price is smaller than cost price.

**Choices:**

- Profit: Selling price is bigger than cost price.Loss: Selling price is smaller than cost price. ✔
  - _why:_ A business gains money when it sells for more than the item cost, creating a profit. Selling for less than the cost creates a loss.
- Profit: Selling price is smaller than cost price.Loss: Selling price is bigger than cost price.
  - _why:_ The relationships have been reversed. Profit occurs when selling price is bigger than cost price, while a smaller selling price means the business has made a loss.
- Profit: Selling price is equal to cost price.Loss: Selling price is bigger than cost price.
  - _why:_ Equal prices produce neither profit nor loss, and selling above cost produces profit. A loss occurs only when selling price is smaller than cost price.
- Profit: Selling price is smaller than cost price.Loss: Selling price is equal to cost price.
  - _why:_ Selling below cost creates a loss, not a profit, while equal prices break even. Profit requires the selling price to be bigger than the cost price.

## Card 13 — `basic`

**Front:** If a question involves costs in pounds and sales in pence, what must you do first?

**Back:** Convert the units to be the same (e.g., all into pounds).

**Choices:**

- Convert the units to be the same (e.g., all into pounds). ✔
  - _why:_ Amounts must use a common unit before they can be compared or used together reliably. For example, convert all pence amounts into pounds before calculating profit or loss.
- Round both amounts to the nearest whole unit first.
  - _why:_ Rounding does not resolve the mismatch between pounds and pence and may reduce accuracy. First convert both amounts into the same unit, such as pounds.
- Add the pounds and pence values together immediately.
  - _why:_ Adding the numerical values directly treats pounds and pence as equivalent units, producing an invalid result. Convert both amounts into the same unit before calculating.
- Compare the numbers without changing either unit first.
  - _why:_ The numerical sizes are not directly comparable because one pound equals 100 pence. Convert both amounts into the same unit before making the comparison.

## Card 14 — `basic`

**Front:** A coat reduced from £80 to £60 has a £20 reduction. What is the calculation for the percentage reduction?

**Back:** $$$\frac{20}{80} \times 100$$

**Choices:**

- $$$\frac{20}{80} \times 100$$ ✔
  - _why:_ Percentage reduction compares the £20 decrease with the original £80 price. Dividing the reduction by the original amount and multiplying by 100 gives 25%.
- $$$\frac{20}{60} \times 100$$
  - _why:_ This uses the reduced price as the denominator, a common percentage-change error. The reduction must be compared with the original £80 price, giving $\frac{20}{80}\times 100$.
- $$$\frac{60}{80} \times 100$$
  - _why:_ This calculates the reduced price as a percentage of the original price, giving 75%, rather than the percentage reduction. Use $\frac{20}{80}\times 100$ for the 25% decrease.
- $$$\frac{80}{20} \times 100$$
  - _why:_ This reverses the fraction by dividing the original price by the reduction. Percentage reduction requires reduction divided by original price, so use $\frac{20}{80}\times 100$.

**Back:** It can make the final answer inaccurate.

**Choices:**

- It can make the final answer inaccurate. ✔
  - _why:_ Rounding removes precision, and the resulting small error can be carried through later steps and enlarged. Keep full calculator values until the final answer, then round as required.
- It can make the final answer more accurate.
  - _why:_ Rounding early removes useful digits rather than improving accuracy, so errors can accumulate through later steps. Keep the unrounded values until the final stage of the calculation.
- It can make the final answer exact.
  - _why:_ A rounded value is an approximation, not an exact value. Using that approximation in further calculations can make the final answer inaccurate, so round only at the end.
- It cannot affect the final answer at all.
  - _why:_ Intermediate rounding errors can carry through and alter the final result, especially over several steps. Retaining full calculator values until the end keeps the answer more accurate.

## Card 16 — `cloze`

**Front:** A decimal place refers to the number of digits [ ___ ] the decimal point.

**Back:** A decimal place refers to the number of digits after the decimal point.

**Choices:**

- after ✔
  - _why:_ Decimal places count digits to the right of the decimal point. For example, $3.142$ has three decimal places because three digits appear after the point.
- before
  - _why:_ Digits before the decimal point form the whole-number part and are not decimal places. Decimal places are counted using the digits after the decimal point.
- around
  - _why:_ Decimal places are not counted on both sides or generally around the point. Only digits after the decimal point determine the number of decimal places.
- including
  - _why:_ The decimal point is a separator rather than a digit, so it is not included in the count. Decimal places count only the digits after the point.

## Card 17 — `cloze`

**Front:** Significant figures start counting from the [ ___ ] digit.

**Back:** Significant figures start counting from the first non-zero digit.

**Choices:**

- first non-zero ✔
  - _why:_ Leading zeros only show place value and are not significant, so counting begins at the first digit that is not zero.
- first zero
  - _why:_ Starting at the first zero would count placeholder zeros, which are not significant. The correct rule is to begin with the first non-zero digit.
- last non-zero
  - _why:_ Starting from the end can omit earlier significant digits. Significant figures are counted from the first non-zero digit, moving from left to right.
- first decimal
  - _why:_ The decimal point does not determine where significant figures begin. Counting starts at the first non-zero digit, whether it appears before or after the decimal point.

## Card 19 — `basic`

**Front:** Aisha buys a flat for £185,000 and sells for £199,800. What is the first step to find the percentage profit?

**Back:** Subtract £185,000 from £199,800 to find the actual profit (£14,800).

**Choices:**

- Subtract £185,000 from £199,800 to find the actual profit (£14,800). ✔
  - _why:_ Actual profit is the selling price minus the buying price. Subtracting £185,000 from £199,800 gives £14,800 before it is expressed as a percentage of the original price.
- Subtract £199,800 from £185,000 to find the actual loss (-£14,800).
  - _why:_ Reversing the subtraction produces a negative value and wrongly describes the sale as a loss. The selling price exceeds the buying price, so the actual profit is £14,800.
- Add £185,000 to £199,800 to find the total value (£384,800).
  - _why:_ Adding the buying and selling prices does not measure the change. The first step is to subtract £185,000 from £199,800, giving an actual profit of £14,800.
- Subtract £14,800 from £185,000 to find the sale price (£170,200).
  - _why:_ This subtracts the profit from the buying price and therefore moves in the wrong direction. First find the profit by calculating £199,800 - £185,000 = £14,800.

## Card 21 — `basic`

**Front:** A car was £12,500 and sold for £9,800. What is the calculation for the percentage loss?

**Back:** $$$\frac{12500 - 9800}{12500} \times 100$$

**Choices:**

- $$$\frac{12500 - 9800}{12500} \times 100$$ ✔
  - _why:_ The loss is the original price minus the selling price, and percentage loss is measured against the original price. Therefore the £2,700 loss is divided by £12,500.
- $$$\frac{12500 - 9800}{9800} \times 100$$
  - _why:_ This uses the selling price as the denominator, a common percentage-change error. Percentage loss must be based on the original price, so the denominator should be 12,500.
- $$$\frac{12500 + 9800}{12500} \times 100$$
  - _why:_ Adding the two prices finds their combined value rather than the loss. The loss is found by subtraction, so the numerator should be $12500 - 9800$.
- $$$\frac{9800 - 12500}{12500} \times 100$$
  - _why:_ Reversing the subtraction makes the result negative. For percentage loss, calculate the positive amount lost using $12500 - 9800$, then divide by the original price.
