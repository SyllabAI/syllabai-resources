## Card 1 — `basic`

**Front:** What are simultaneous equations?

**Back:** Two or more equations that must be true at the same time.

**Choices:**

- Two or more equations that must be true at the same time. ✔
  - _why:_ Simultaneous equations form a set whose equations must all hold for the same values of the variables, so they must be true at the same time.
- Two or more equations that must be solved separately from each other.
  - _why:_ Solving each equation with unrelated values misses the defining requirement. Simultaneous equations are two or more equations that must be true at the same time.
- Two or more equations that must have exactly the same coefficients.
  - _why:_ Equations do not need identical coefficients to be simultaneous. They are simultaneous when the same variable values must make all the equations true at the same time.
- Two or more equations that must use completely different variables.
  - _why:_ Having different variables does not define simultaneous equations. The equations usually share variables and must all be satisfied by the same values at the same time.

## Card 2 — `basic`

**Front:** What does the solution to a pair of simultaneous equations represent on a graph?

**Back:** The coordinates of the point where the two lines intersect.

**Choices:**

- The coordinates of the point where the two lines intersect. ✔
  - _why:_ A solution satisfies both equations, so its coordinates lie on both lines. Graphically, this is precisely the point at which the two lines intersect.
- The gradients of the two lines where they have the same steepness.
  - _why:_ The gradient describes a line’s steepness, not the shared solution. The solution is given by the coordinates of the point where the two lines intersect.
- The intercepts of the points where the two lines cross the axes.
  - _why:_ The intercepts show where individual lines cross an axis, which is not generally their shared solution. The solution is the coordinates of the lines’ intersection point.
- The coordinates of the point lying exactly between both lines.
  - _why:_ The midpoint between two lines need not lie on either line and does not satisfy both equations. The solution is the coordinates of their intersection point.

## Card 3 — `basic`

**Front:** How do you verify if a pair of values (e.g., $x=4, y=1$) is the correct solution?

**Back:** Substitute the values into both original equations to see if they work.

**Choices:**

- Substitute the values into both original equations to see if they work. ✔
  - _why:_ A simultaneous solution must satisfy every original equation. Substituting both values into both equations confirms whether each resulting numerical statement is true.
- Substitute the values into one original equation to see if they work.
  - _why:_ Checking only one equation can accept values that fail the other equation. Substitute the values into both original equations and verify that both statements are true.
- Add the values together in both original equations to see if they work.
  - _why:_ Adding the values together does not test whether they satisfy either equation. Each value must be substituted for its variable in both original equations.
- Swap the values before using both original equations to see if they work.
  - _why:_ Swapping the values tests the ordered pair $(y,x)$ rather than the proposed pair $(x,y)$. Substitute each value for its correct variable in both equations.

## Card 4 — `cloze`

**Front:** Elimination means adding or subtracting equations so that [ ___ ].

**Back:** Elimination means adding or subtracting equations so that one variable disappears.

**Choices:**

- one variable disappears ✔
  - _why:_ Adding or subtracting suitably arranged equations cancels matching variable terms. This makes one variable disappear, leaving an equation in the remaining variable.
- both variables remain
  - _why:_ Elimination aims to remove a variable, not preserve both of them. The equations are added or subtracted so that one variable disappears.
- each variable is isolated
  - _why:_ Adding or subtracting equations does not generally isolate each variable immediately. Elimination first makes one variable disappear so the remaining variable can be found.
- one coefficient doubles
  - _why:_ A coefficient can double when like-signed terms are added, but that is not the aim of elimination. The operation should make one variable disappear.

## Card 5 — `basic`

**Front:** What is a coefficient in algebra?

**Back:** The number multiplying a variable (e.g., in $4x$, the coefficient is $4$).

**Choices:**

- The number multiplying a variable (e.g., in $4x$, the coefficient is $4$). ✔
  - _why:_ A coefficient is the numerical factor attached to a variable. For example, $4x$ means $4\times x$, so its coefficient is $4$.
- The letter representing a number (e.g., in $4x$, the coefficient is $x$).
  - _why:_ The variable is the letter representing an unknown quantity, not the coefficient. In $4x$, the number $4$ multiplies $x$ and is therefore the coefficient.
- The power applied to a variable (e.g., in $4x$, the coefficient is $1$).
  - _why:_ An exponent indicates repeated multiplication and is written as a power, whereas a coefficient multiplies a variable. In $4x$, the coefficient is $4$.
- The constant without a variable (e.g., in $4x$, the coefficient is $x$).
  - _why:_ A constant term has no variable attached, whereas a coefficient is the number multiplying a variable. In $4x$, that multiplying number is $4$.

## Card 6 — `basic`

**Front:** In the elimination method, when should you add the two equations?

**Back:** When the coefficients of a variable are the same size but have opposite signs (e.g., $+2y$ and $-2y$).

**Choices:**

- When the coefficients of a variable are the same size but have opposite signs (e.g., $+2y$ and $-2y$). ✔
  - _why:_ Equal-sized coefficients with opposite signs cancel when added, since terms such as $+2y$ and $-2y$ sum to zero. This eliminates that variable.
- When the coefficients of a variable are the same size and have the same sign (e.g., $+2y$ and $+2y$).
  - _why:_ Equal-sized coefficients with the same sign double when added rather than cancelling. In this case, subtract the equations to eliminate the variable.
- When the coefficients of a variable are different sizes but have opposite signs (e.g., $+2y$ and $-3y$).
  - _why:_ Opposite signs alone do not guarantee cancellation when the coefficient sizes differ. First scale an equation so the coefficients have the same size, then add.
- When the coefficients of a variable are different sizes and have the same sign (e.g., $+2y$ and $+3y$).
  - _why:_ Different-sized coefficients with the same sign do not cancel through addition. The equations must first be scaled to create equal-sized coefficients suitable for elimination.

## Card 7 — `basic`

**Front:** In the elimination method, when should you subtract the two equations?

**Back:** When the coefficients of a variable are the same size and have the same sign (e.g., $+3y$ and $+3y$).

**Choices:**

- When the coefficients of a variable are the same size and have the same sign (e.g., $+3y$ and $+3y$). ✔
  - _why:_ Equal-sized coefficients with the same sign cancel when one equation is subtracted from the other, since terms such as $+3y-(+3y)$ equal zero.
- When the coefficients of a variable are the same size but have opposite signs (e.g., $+3y$ and $-3y$).
  - _why:_ Subtracting equal-sized terms with opposite signs makes their size double rather than cancelling them. Add the equations when the coefficients have opposite signs.
- When the coefficients of a variable are different sizes and have the same sign (e.g., $+3y$ and $+2y$).
  - _why:_ Same signs alone are insufficient when the coefficient sizes differ, because subtraction leaves a non-zero variable term. First scale an equation to make the sizes equal.
- When the coefficients of a variable are different sizes and have opposite signs (e.g., $+3y$ and $-2y$).
  - _why:_ Different-sized coefficients with opposite signs do not cancel through subtraction. Scale the equations to equalise their sizes, then add terms with opposite signs.

## Card 8 — `cloze`

**Front:** If the coefficients of a variable have the [ ___ ], you subtract the equations; if they have opposite signs, you add them.

**Back:** If the coefficients of a variable have the same sign, you subtract the equations; if they have opposite signs, you add them.

**Choices:**

- same sign ✔
  - _why:_ Coefficients with the same sign cancel through subtraction because one is removed from the other. Coefficients with opposite signs instead cancel through addition.
- same size
  - _why:_ Coefficient size alone does not determine the operation because signs also matter. Subtract equal coefficients with the same sign, but add equal-sized coefficients with opposite signs.
- opposite sign
  - _why:_ Coefficients with opposite signs should be added, not subtracted, so that they cancel. Subtraction is used when equal-sized coefficients have the same sign.
- same variable
  - _why:_ Both equations normally contain the same variable regardless of which operation is needed. Subtract when its equal-sized coefficients have the same sign, and add when they have opposite signs.

## Card 9 — `cloze`

**Front:** If the coefficients of a variable have the same sign, you subtract the equations; if they have [ ___ ], you add them.

**Back:** If the coefficients of a variable have the same sign, you subtract the equations; if they have opposite signs, you add them.

**Choices:**

- opposite signs ✔
  - _why:_ Opposite signs cancel when the equations are added because one coefficient is positive and the other is negative.
- the same signs
  - _why:_ Coefficients with the same signs reinforce rather than cancel when added. The correct fill is opposite signs, because a positive and negative coefficient cancel through addition.
- positive signs
  - _why:_ Two positive coefficients become larger when added, so the variable is not eliminated. The correct fill is opposite signs, which cancel when the equations are added.
- negative signs
  - _why:_ Two negative coefficients combine rather than cancel when added. The correct fill is opposite signs, because equal positive and negative coefficients sum to zero.

## Card 10 — `basic`

**Front:** What is the common mistake when subtracting one equation from another?

**Back:** Forgetting to subtract every term on both the left and right sides of the equals sign.

**Choices:**

- Forgetting to subtract every term on both the left and right sides of the equals sign. ✔
  - _why:_ Subtracting equations means subtracting the entire second equation, so every term on both sides must have the subtraction applied to it.
- Forgetting to divide every term on both the left and right sides of the equals sign.
  - _why:_ Division is not the required operation when one equation is being subtracted. The common mistake is failing to subtract every term on both sides of the equals sign.
- Forgetting to multiply every term on both the left and right sides of the equals sign.
  - _why:_ Multiplication is used earlier only when coefficients need matching. During subtraction, the key mistake is forgetting to subtract every term on both sides of the equations.
- Forgetting to substitute every term on both the left and right sides of the equals sign.
  - _why:_ Substitution is a different solving method and is not applied term by term here. When subtracting equations, every term on both sides must be subtracted.

## Card 11 — `basic`

**Front:** What must be done if neither $x$ nor $y$ have matching coefficients in a pair of equations?

**Back:** Multiply one or both whole equations by a number to make the coefficients match.

**Choices:**

- Multiply one or both whole equations by a number to make the coefficients match. ✔
  - _why:_ Multiplying a whole equation preserves its equality while producing matching coefficients, allowing one variable to be eliminated by adding or subtracting the equations.
- Add a number to one or both equations to make the coefficients match.
  - _why:_ Adding a number does not scale the coefficients and may alter only selected terms. Instead, multiply one or both whole equations to create matching coefficients.
- Multiply only the variable terms by a number to make the coefficients match.
  - _why:_ Multiplying only variable terms changes the equation and destroys the equality. Every term in one or both whole equations must be multiplied by the chosen number.
- Swap the variables in one or both equations to make the coefficients match.
  - _why:_ Swapping variables changes what the equations represent and does not produce an equivalent system. Multiply one or both whole equations to make corresponding coefficients match.

## Card 12 — `cloze`

**Front:** When multiplying an equation to match coefficients, [ ___ ] in the equation must be multiplied by that number.

**Back:** When multiplying an equation to match coefficients, every term in the equation must be multiplied by that number.

**Choices:**

- every term ✔
  - _why:_ An equation remains balanced only if the multiplier is applied to every term on both sides, including variables, constants and any negative terms.
- only the variable term
  - _why:_ Multiplying only the variable term changes the equation rather than forming an equivalent one. The correct fill is every term, including constants on both sides.
- only the coefficient
  - _why:_ Changing only one coefficient does not preserve the equality of the original equation. The correct fill is every term, all multiplied by the same number.
- the term being eliminated
  - _why:_ Scaling only the term intended for elimination produces a non-equivalent equation. The correct fill is every term, because the whole equation must be multiplied consistently.

## Card 13 — `basic`

**Front:** What is the standard form for arranging simultaneous equations before solving?

**Back:** $$ax + by = c$ (variables on the left, number on the right).

**Choices:**

- $$ax + by = c$ (variables on the left, number on the right). ✔
  - _why:_ Standard form places both variable terms together on the left-hand side and the constant alone on the right-hand side.
- $$c = ax + by$ (number on the left, variables on the right).
  - _why:_ Although algebraically equivalent, this reverses the required standard arrangement. Standard form is $ax + by = c$, with variables left and the constant right.
- $$ax = c - by$ ($x$ on the left, $y$ and number on the right).
  - _why:_ This leaves the variable terms on opposite sides of the equation. Standard form collects both variables on the left as $ax + by = c$.
- $$by = c - ax$ ($y$ on the left, $x$ and number on the right).
  - _why:_ This isolates one variable term instead of collecting both on the same side. Standard form is $ax + by = c$, with the constant on the right.

## Card 14 — `basic`

**Front:** How should the equation $3x = 12 + y$ be rearranged into standard form?

**Back:** $$3x - y = 12$

**Choices:**

- $$3x - y = 12$ ✔
  - _why:_ Subtracting $y$ from both sides moves it to the left with a negative sign, leaving the constant $12$ on the right.
- $$3x + y = 12$
  - _why:_ This keeps $y$ positive after moving it across the equals sign. Subtracting $y$ from both sides gives the correct form $3x - y = 12$.
- $$3x - y = -12$
  - _why:_ The sign of $12$ should not change because it has not crossed the equals sign. Only $y$ moves, giving $3x - y = 12$.
- $$3x + y = -12$
  - _why:_ This incorrectly changes the signs of both $y$ and $12$. Subtract only $y$ from both sides to obtain $3x - y = 12$.

## Card 16 — `basic`

**Front:** After finding the value of one variable (e.g., $x=4$), how do you find the value of the second variable?

**Back:** Substitute the known value into one of the original equations and solve.

**Choices:**

- Substitute the known value into one of the original equations and solve. ✔
  - _why:_ Replacing the known variable in either original equation leaves an equation containing only the second variable, which can then be solved directly.
- Substitute the known value into the final one-variable equation and solve.
  - _why:_ The final one-variable equation only confirms the value already found and contains no second variable. Substitute into one original equation to calculate the other value.
- Add the known value to both of the original equations and solve.
  - _why:_ Adding the value changes the equations and does not replace the known variable. Substitute it into one original equation, leaving only the second variable unknown.
- Divide both original equations by the known value and solve.
  - _why:_ Dividing the equations does not use the fact that one variable has a known value. Substitute that value into one original equation and solve for the other variable.

## Card 17 — `basic`

**Front:** Two sandwiches ($s$) and three drinks ($d$) cost £14.70. One sandwich and two drinks cost £8.70. What are the two equations?

**Back:** $2s + 3d = 14.70$$s + 2d = 8.70$

**Choices:**

- $2s + 3d = 14.70$$s + 2d = 8.70$ ✔
  - _why:_ The coefficients represent the numbers of sandwiches and drinks in each purchase, while £14.70 and £8.70 are the corresponding totals.
- $2s + 3d = 8.70$$s + 2d = 14.70$
  - _why:_ This swaps the two purchase totals. The order information gives $2s + 3d = 14.70$ for the first purchase and $s + 2d = 8.70$ for the second.
- $3s + 2d = 14.70$$2s + d = 8.70$
  - _why:_ This reverses the numbers of sandwiches and drinks in both purchases. The correct coefficients are two and three in the first equation, then one and two in the second.
- $2s + 3d = 14.70$$2s + d = 8.70$
  - _why:_ The second purchase has one sandwich and two drinks, not two sandwiches and one drink. Its equation must therefore be $s + 2d = 8.70$.

## Card 18 — `cloze`

**Front:** In word problems, it is vital not to [ ___ ] of your variables halfway through the calculation.

**Back:** In word problems, it is vital not to swap the meanings of your variables halfway through the calculation.

**Choices:**

- swap the meanings ✔
  - _why:_ Each variable must represent the same quantity throughout the calculation. Swapping their meanings would make later equations and substitutions inconsistent with the original definitions.
- swap the coefficients
  - _why:_ Coefficients may legitimately change when equations are multiplied during elimination. The essential rule is not to swap the meanings assigned to the variables themselves.
- reverse the signs
  - _why:_ Signs can legitimately reverse when multiplying an entire equation by a negative number. The key consistency requirement is not to swap the meanings of the variables.
- simplify the coefficients
  - _why:_ Simplifying coefficients can be a valid algebraic step when applied correctly. The mistake warned against is swapping the meanings of the variables during the calculation.

**Front:** A pair of values is only a solution if it works in [ ___ ] equations.

**Back:** A pair of values is only a solution if it works in both equations.

**Choices:**

- both ✔
  - _why:_ Simultaneous equations require one pair of values that satisfies the two equations at the same time. Therefore, the pair must work in both equations.
- only one of the
  - _why:_ Satisfying just one equation does not establish a simultaneous solution because many other pairs may also satisfy it. The values must work in both equations.
- at least one of the
  - _why:_ Working in at least one equation is insufficient for a simultaneous solution. The defining requirement is that the same pair of values satisfies both equations.
- neither of the
  - _why:_ A pair that satisfies neither equation cannot be a solution to the system. A valid simultaneous solution must make both original equations true.
