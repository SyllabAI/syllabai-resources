## Card 1 — `basic`

**Front:** In GCSE mathematics, what is an integer?

**Back:** A whole number (including zero and negative whole numbers).

**Choices:**

- A whole number (including zero and negative whole numbers). ✔
  - _why:_ Integers are whole numbers with no fractional or decimal part. They include positive whole numbers, zero and negative whole numbers.
- A positive whole number (excluding zero and negative numbers).
  - _why:_ Restricting integers to positive numbers confuses them with counting numbers. Integers also include zero and negative whole numbers, such as $0$ and $-5$.
- A number with a decimal part (including positive and negative decimals).
  - _why:_ Numbers with non-zero decimal parts are not integers. An integer is a whole number, including zero and negative whole numbers.
- A counting number (starting at one and increasing in whole steps).
  - _why:_ Counting numbers usually begin at $1$, so this definition leaves out zero and negative values. Integers include all positive and negative whole numbers and zero.

**Back:** $$\le$ includes the end value.

**Choices:**

- $$\le$ includes the end value. ✔
  - _why:_ A strict inequality does not allow equality, so $<$ excludes the endpoint. The line beneath $\le$ represents equality, meaning the endpoint is included.
- $$\le$ excludes the end value.
  - _why:_ This reverses the meanings of the two symbols. The symbol $<$ excludes equality, whereas $\le$ means less than or equal to and therefore includes the endpoint.
- $$\le$ excludes the end value.
  - _why:_ The line beneath $\le$ represents equality, so its endpoint is included rather than excluded. Only the strict inequality $<$ excludes the endpoint.
- $$\le$ includes the end value.
  - _why:_ The symbol $<$ means strictly less than, so equality is not permitted and the endpoint is excluded. The symbol $\le$ includes the endpoint.

## Card 3 — `cloze`

**Front:** On a number line, an [ ___ ] means the value is not included ($$), while a solid circle means the value is included ($\le$ or $\ge$).

**Back:** On a number line, an open circle means the value is not included ($$), while a solid circle means the value is included ($\le$ or $\ge$).

**Choices:**

- open circle ✔
  - _why:_ An open circle marks an excluded boundary value because a strict inequality, $$, does not permit equality at that endpoint.
- solid circle
  - _why:_ A solid circle indicates that the boundary value is included, corresponding to $\le$ or $\ge$. An open circle is used when the value is excluded.
- arrowhead
  - _why:_ An arrowhead shows that the solution continues indefinitely in one direction. An open circle, not an arrowhead, marks a boundary value that is excluded.
- thick line
  - _why:_ A thick line represents the set of allowed values across part of the number line. An open circle specifically shows that an endpoint is not included.

## Card 5 — `basic`

**Front:** List the integers that satisfy $-4 < n \le 2$.

**Back:** $$-3, -2, -1, 0, 1, 2$

**Choices:**

- $$-3, -2, -1, 0, 1, 2$ ✔
  - _why:_ The strict lower bound excludes $-4$, while the inclusive upper bound allows $2$. Every integer between those endpoints is therefore listed.
- $$-4, -3, -2, -1, 0, 1, 2$
  - _why:_ Including $-4$ treats the strict inequality $-4<n$ as though it were $-4\le n$. The correct list begins at $-3$ and ends at $2$.
- $$-3, -2, -1, 0, 1$
  - _why:_ Leaving out $2$ treats $n\le2$ as a strict inequality. Since equality is allowed at the upper bound, the correct list includes $2$.
- $$-4, -3, -2, -1, 0, 1$
  - _why:_ This reverses both endpoint rules by including the excluded lower endpoint and omitting the included upper endpoint. The correct list runs from $-3$ through $2$.

## Card 6 — `basic`

**Back:** Values less than the circle's value.

**Choices:**

- Values less than the circle's value. ✔
  - _why:_ Numbers decrease as you move left along a number line. Therefore, an arrow pointing left represents values less than the boundary marked by the circle.
- Values greater than the circle's value.
  - _why:_ Greater values lie to the right on a number line, not the left. A left-pointing arrow represents values less than the circle's value.

  - _why:_ An arrow shows that the solution continues through infinitely many values rather than selecting one value. Pointing left means all represented values are less than the boundary.

## Card 7 — `basic`

**Front:** What does a thick line between two circles on a number line represent?

**Back:** All values between the two endpoints are allowed.

**Choices:**

- All values between the two endpoints are allowed. ✔
  - _why:_ A thick line marks the complete interval of solutions, so every value along it is allowed. The circles determine separately whether each endpoint is included.
- Only the endpoints of the interval are allowed.
  - _why:_ The circles mark the endpoints, but the thick line marks every permitted value between them. It does not restrict the solution to the two endpoints.
- All values outside the two endpoints are allowed.
  - _why:_ Values outside the endpoints would be shown by lines or arrows extending away from the circles. A thick connecting line represents all values between them.
- Only integer values between the two endpoints are allowed.
  - _why:_ A continuous thick line includes every real value in the interval, including decimals and fractions. Integer-only solutions would normally be shown using separate marked points.

## Card 8 — `basic`

**Front:** Describe the circles and line needed to show $-2 \le x < 3$ on a number line.

**Back:** Solid circle at -2.Open circle at 3.Thick line connecting them.

**Choices:**

- Solid circle at -2.Open circle at 3.Thick line connecting them. ✔
  - _why:_ The symbol $\le$ includes $-2$, so that endpoint is solid. The symbol $<$ excludes $3$, so it is open, and the interval between them is shaded.
- Open circle at -2.Solid circle at 3.Thick line connecting them.
  - _why:_ This reverses both endpoint markers. The inequality includes $-2$, requiring a solid circle, but excludes $3$, requiring an open circle.
- Solid circle at -2.Solid circle at 3.Thick line connecting them.
  - _why:_ The solid circle at $3$ incorrectly includes that endpoint. Since $x<3$ is strict, $3$ needs an open circle, while $-2$ remains solid.
- Solid circle at -2.Open circle at 3.Thin line connecting them.
  - _why:_ The endpoint circles are correct, but the solution interval must be shown with a thick line. This indicates that all values from $-2$ up to $3$ are allowed.

## Card 9 — `basic`

**Front:** Write the inequality for $x$ shown by an open circle at 1 and an arrow pointing left.

**Back:** $$x < 1$

**Choices:**

- $$x < 1$ ✔
  - _why:_ An open circle excludes 1, while the arrow pointing left represents values smaller than 1. Therefore, the inequality is strictly less than 1.
- $$x \le 1$
  - _why:_ Using $\le$ would include 1, which requires a filled circle. The circle is open, so 1 is excluded and the correct inequality is $x < 1$.
- $$x > 1$
  - _why:_ The open circle correctly excludes 1, but $>$ represents values to the right. The arrow points left, so the correct inequality is $x < 1$.
- $$x \ge 1$
  - _why:_ This combines both common diagram-reading errors: $\ge$ includes 1 and represents values to the right. The open circle and left arrow give $x < 1$.

## Card 10 — `basic`

**Front:** When solving an inequality, what must you do if you multiply or divide both sides by a negative number?

**Back:** Reverse the inequality sign (e.g., change $>$ to $<$).

**Choices:**

- Reverse the inequality sign (e.g., change $>$ to $<$). ✔
  - _why:_ Multiplication or division by a negative number reverses the order of the values. The inequality sign must therefore be reversed to keep the statement equivalent.
- Keep the inequality sign unchanged (e.g., leave $>$ as $>$).
  - _why:_ Keeping the sign unchanged ignores how multiplication or division by a negative reverses numerical order. The correct rule is to reverse the inequality sign.
- Replace the inequality sign with equals (e.g., change $>$ to $=$).
  - _why:_ An inequality does not become an equation when both sides are multiplied or divided. If the number is negative, the correct action is to reverse the inequality sign.
- Reverse the signs of all terms (e.g., change $+$ to $-$).
  - _why:_ Changing operation signs is not the required inequality rule. Multiplying or dividing both sides by a negative number requires the inequality sign itself to be reversed.

## Card 11 — `cloze`

**Front:** The inequality sign [ ___ ] when you add or subtract numbers from both sides.

**Back:** The inequality sign does NOT change when you add or subtract numbers from both sides.

**Choices:**

- does NOT change ✔
  - _why:_ Adding or subtracting the same number from both sides preserves their order, so the inequality sign remains unchanged. Reversal is only required when multiplying or dividing by a negative number.
- always reverses
  - _why:_ Reversing the sign here confuses addition and subtraction with multiplication or division by a negative number. The inequality sign does NOT change when equal amounts are added or subtracted.
- changes to an equals sign
  - _why:_ Performing the same addition or subtraction on both sides preserves the inequality rather than creating equality. The inequality sign does NOT change during these operations.
- changes only when subtracting
  - _why:_ Subtraction does not reverse an inequality when the same value is subtracted from both sides. For both addition and subtraction, the inequality sign does NOT change.

## Card 12 — `basic`

**Front:** Solve the inequality: $3t + 5 \le 17$

**Back:** $$t \le 4$

**Choices:**

- $$t \le 4$ ✔
  - _why:_ Subtracting 5 gives $3t \le 12$, and dividing both sides by positive 3 gives $t \le 4$. The sign remains unchanged because the divisor is positive.
- $$t \ge 4$
  - _why:_ This unnecessarily reverses the inequality sign when dividing by positive 3. Only division by a negative reverses it, so the correct solution is $t \le 4$.
- $$t \le 12$
  - _why:_ Subtracting 5 gives $3t \le 12$, but the coefficient of $t$ must still be removed. Dividing by 3 gives the complete solution $t \le 4$.
- $$t \le \frac{22}{3}$
  - _why:_ This comes from adding 5 instead of subtracting it when isolating $3t$. The correct intermediate result is $3t \le 12$, giving $t \le 4$.

## Card 13 — `basic`

**Front:** What is the recommended first step when solving an inequality with letters on both sides?

**Back:** Subtract the smaller variable part from both sides to keep the variable positive.

**Choices:**

- Subtract the smaller variable part from both sides to keep the variable positive. ✔
  - _why:_ Subtracting the smaller variable part collects the letters on one side while usually leaving a positive coefficient. This reduces the chance of needing to reverse the inequality later.
- Subtract the larger variable part from both sides to make the variable negative.
  - _why:_ Although equivalent algebra may still be possible, this creates a negative variable coefficient and introduces an avoidable sign reversal. The recommended step is to subtract the smaller variable part.
- Divide by the variable on both sides to remove the letters completely.
  - _why:_ Dividing by an unknown variable is unsafe because its sign and whether it equals zero may be unknown. Instead, subtract the smaller variable part from both sides.
- Reverse the inequality sign before collecting the variable terms together.
  - _why:_ The inequality sign is reversed only after multiplying or dividing by a negative number, not before collecting terms. First subtract the smaller variable part from both sides.

## Card 14 — `basic`

**Front:** Solve the inequality: $5x + 1 \le 2x + 13$

**Back:** $$x \le 4$

**Choices:**

- $$x \le 4$ ✔
  - _why:_ Subtracting $2x$ gives $3x+1 \le 13$, then subtracting 1 gives $3x \le 12$. Dividing by positive 3 produces $x \le 4$.
- $$x \ge 4$
  - _why:_ This reverses the inequality despite dividing by positive 3. The sign changes only when dividing by a negative number, so the correct solution is $x \le 4$.
- $$x \le 6$
  - _why:_ This results from incorrectly treating $5x-2x$ as $2x$. The variable terms combine to $3x$, so $3x \le 12$ and therefore $x \le 4$.
- $$x \le \frac{14}{3}$
  - _why:_ This comes from adding 1 to 13 rather than subtracting 1 after collecting the variable terms. The correct step is $3x \le 12$, giving $x \le 4$.

## Card 15 — `cloze`

**Front:** If you divide both sides of $-12 > -3x$ by $-3$, the resulting inequality is $\text{[...]}$.

**Back:** If you divide both sides of $-12 > -3x$ by $-3$, the resulting inequality is $\boxed{4 < x}$.

**Choices:**

- $$4 < x$ ✔
  - _why:_ Dividing both sides by $-3$ gives 4 on the left and $x$ on the right. Because the divisor is negative, $>$ reverses to $<$.
- $$4 > x$
  - _why:_ This keeps the original inequality sign and misses the negative-division rule. Dividing by $-3$ reverses $>$ to $<$, so the correct result is $4 < x$.
- $$-4 < x$
  - _why:_ The inequality is reversed correctly, but $-12 \div -3$ equals positive 4, not negative 4. Therefore, the resulting inequality is $4 < x$.
- $$4 < -x$
  - _why:_ Dividing $-3x$ by $-3$ gives positive $x$ because the negative signs cancel. Reversing the inequality then gives the correct result $4 < x$.

## Card 16 — `basic`

**Front:** What is the first step to solve $3(n + 2) < 21$?

**Back:** Expand the brackets ($3n + 6 < 21$).

**Choices:**

- Expand the brackets ($3n + 6 < 21$). ✔
  - _why:_ Multiplying both terms inside the brackets by 3 gives $3n+6$. The equivalent inequality after expansion is therefore $3n + 6 < 21$.
- Expand the brackets ($3n + 2 < 21$).
  - _why:_ This distributes 3 to $n$ but not to 2, a common expansion error. Both terms must be multiplied by 3, giving $3n + 6 < 21$.
- Divide the left side ($n + 2 < 21$).
  - _why:_ Dividing only one side changes the inequality and produces a non-equivalent statement. The recommended first step is to expand correctly, giving $3n + 6 < 21$.
- Multiply the brackets ($9n + 6 < 21$).
  - _why:_ This incorrectly multiplies $3n$ by 3 again. Distributing the single outside factor gives $3 \times n + 3 \times 2$, so the result is $3n + 6 < 21$.

## Card 17 — `cloze`

**Front:** A [ ___ ] has two inequality signs and shows that a variable must fit between two values.

**Back:** A compound inequality has two inequality signs and shows that a variable must fit between two values.

**Choices:**

- compound inequality ✔
  - _why:_ A compound inequality combines two inequality comparisons in one statement, placing the variable between a lower boundary and an upper boundary.
- simple inequality
  - _why:_ A simple inequality normally contains one inequality sign and gives only one boundary. The correct term is compound inequality because two linked comparisons restrict the variable.
- linear inequality
  - _why:_ A linear inequality is defined by the variable having a highest power of one, not by having two signs. The required term is compound inequality.
- simultaneous equation
  - _why:_ A simultaneous equation involves multiple equations solved together rather than two linked inequality signs. A statement bounding one variable between two values is a compound inequality.

## Card 18 — `basic`

**Front:** Solve the compound inequality: $3 \le 2y - 1 < 11$

**Back:** $$2 \le y < 6$

**Choices:**

- $$2 \le y < 6$ ✔
  - _why:_ Adding $1$ to all three parts gives $4 \le 2y < 12$. Dividing every part by $2$ then gives $2 \le y < 6$.
- $$1.5 \le y < 5.5$
  - _why:_ This ignores the $-1$ beside $2y$ and divides only the original bounds by $2$. Adding $1$ first and then dividing gives $2 \le y < 6$.
- $$4 \le y < 12$
  - _why:_ Adding $1$ produces these intermediate bounds, but the coefficient of $y$ has not been removed. Dividing all three parts by $2$ gives $2 \le y < 6$.
- $$2 < y < 6$
  - _why:_ The lower sign must remain inclusive because dividing by positive $2$ does not change it. Solving correctly gives $2 \le y < 6$, including $y=2$.

## Card 19 — `basic`

**Back:** $$2, 3, 4, 5$

**Choices:**

- $$2, 3, 4, 5$ ✔
  - _why:_ The inclusive sign $\le$ allows $2$, while the strict sign $<$ excludes $6$. Therefore the integer values from the lower bound to the upper bound are $2, 3, 4, 5$.
- $$3, 4, 5, 6$
  - _why:_ This reverses which endpoints are included: $2$ is permitted by $\le$, whereas $6$ is excluded by $<$. The correct list is $2, 3, 4, 5$.

  - _why:_ Including $6$ treats the strict upper inequality $y<6$ as though it were $y\le6$. The correct integer values are $2, 3, 4, 5$.

  - _why:_ Omitting $2$ treats the inclusive lower inequality $2\le y$ as though it were strict. Since $2$ is allowed, the correct list is $2, 3, 4, 5$.

## Card 20 — `basic`

**Front:** Why is $4$ not included in the list of integers for $n < 4$?

**Back:** Because the symbol $<$ means "strictly less than" and excludes the limit.

**Choices:**

- Because the symbol $<$ means "strictly less than" and excludes the limit. ✔
  - _why:_ A strict inequality allows only values below the boundary, so a value equal to $4$ does not satisfy $n<4$. Equality requires the symbol $\le$.
- Because the symbol $<$ means "less than or equal to", but integer limits are always excluded.
  - _why:_ Integer boundaries are governed by the inequality symbol in exactly the same way as other numbers. The symbol $<$ means strictly less than, so it excludes $4$.
- Because $4$ is the first integer greater than the stated limit.
  - _why:_ The number $4$ equals the stated limit rather than being greater than it. It is excluded because $<$ permits only values strictly below the limit.
- Because boundary values are excluded from every inequality, whichever symbol is used.
  - _why:_ Some inequalities include their boundaries: $\le$ and $\ge$ both allow equality. Here, $4$ is excluded specifically because $<$ means strictly less than.

## Card 21 — `cloze`

**Front:** To solve a compound inequality, you must perform the same operation to [ ___ ] of the inequality.

**Back:** To solve a compound inequality, you must perform the same operation to all three parts of the inequality.

**Choices:**

- all three parts ✔
  - _why:_ A compound inequality links a lower bound, a variable expression and an upper bound. Applying the operation to all three preserves both comparisons and keeps the statement equivalent.
- the left and middle parts
  - _why:_ Changing only the left and middle parts breaks the comparison with the unchanged upper bound. The same operation must be applied to all three parts of the compound inequality.
- the middle and right parts
  - _why:_ Changing only the middle and right parts breaks the comparison with the unchanged lower bound. An equivalent compound inequality requires the operation to be applied to all three parts.
- the variable term only
  - _why:_ Operating only on the variable expression leaves both boundaries on the original scale, so the resulting comparisons are not equivalent. The operation must affect all three parts.
