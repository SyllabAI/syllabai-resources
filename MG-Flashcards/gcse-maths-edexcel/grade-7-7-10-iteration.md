## Card 1 — `cloze`

**Front:** Iteration means [ ___ ].

**Back:** Iteration means repeatedly applying the same rule.

**Choices:**

- repeatedly applying the same rule ✔
  - _why:_ Iteration generates successive values by applying the same rule repeatedly, with each result normally becoming the input for the next application.
- applying several different rules once
  - _why:_ Using different rules once is not iteration. Iteration means repeatedly applying the same rule, usually feeding each calculated value back into that rule.
- reversing the same rule repeatedly
  - _why:_ Iteration does not require a rule to be reversed. It means repeatedly applying the same rule to generate a sequence of successive values.
- repeatedly choosing a different rule
  - _why:_ Changing the rule at every step contradicts the definition of iteration. The right description is repeatedly applying the same rule.

## Card 2 — `basic`

**Front:** In \(x_3\), what does the subscript 3 tell you?

**Back:** The term with subscript 3.

**Choices:**

- The term with subscript 3. ✔
  - _why:_ A subscript identifies a term’s position or label in a sequence, so \(x_3\) denotes the term with subscript 3.
- The term raised to power 3.
  - _why:_ This confuses a subscript with an exponent. The 3 labels the term with subscript 3; a power would be written \(x^3\).
- The term multiplied by 3.
  - _why:_ A subscript does not indicate multiplication. In \(x_3\), the 3 identifies the term with subscript 3, rather than meaning \(3x\).
- The term divided by 3.
  - _why:_ A subscript labels a term and does not mean division. The notation \(x_3\) identifies the term with subscript 3.

## Card 3 — `cloze`

**Front:** In \(x_3\), the 3 is a [ ___ ], not a [ ___ ].

**Back:** In \(x_3\), the 3 is a subscript, not a power.

**Choices:**

- In \(x_3\), the 3 is a subscript, not a power. ✔
  - _why:_ The 3 is written below the variable, so it is a subscript labelling a term. An exponent or power would be written above the variable.
- In \(x_3\), the 3 is a power, not a subscript.
  - _why:_ This reverses the meanings of the two positions. In \(x_3\), the 3 is a subscript; a power of 3 would be written \(x^3\).
- In \(x_3\), the 3 is a coefficient, not a power.
  - _why:_ A coefficient is placed before a variable, as in \(3x\). Here the 3 is below the variable, making it a subscript rather than a power.
- In \(x_3\), the 3 is a subscript, not a coefficient.
  - _why:_ Although 3 is a subscript, the intended contrast is with a power, a common notation error. In \(x_3\), it is a subscript, not a power.

## Card 4 — `cloze`

**Front:** A starting value, such as \(x_0\), is used [ ___ ] the recurrence formula.

**Back:** A starting value, such as \(x_0\), is used before the recurrence formula.

**Choices:**

- before ✔
  - _why:_ The starting value must be known before the recurrence formula can first be used, because it provides the input needed to calculate the next term.
- after
  - _why:_ Placing the starting value after the recurrence formula reverses the process. The starting value is used before the formula to calculate the first new term.
- instead of
  - _why:_ The starting value does not replace the recurrence formula. It is used before the formula as the initial input from which later terms are generated.
- independently of
  - _why:_ The starting value and recurrence formula are not independent. The starting value is used before the formula and supplies its first input.

## Card 5 — `basic`

**Front:** When using \(x_{n+1}=f(x_n)\), which value is substituted to find the next term?

**Back:** The current term \(x_n\).

**Choices:**

- The current term \(x_n\). ✔
  - _why:_ The recurrence formula applies \(f\) to the current term \(x_n\), producing the next term \(x_{n+1}\).
- The starting term \(x_0\).
  - _why:_ The starting term is used only to begin the iteration. At each later step, the current term \(x_n\) is substituted to obtain \(x_{n+1}\).
- The next term \(x_{n+1}\).
  - _why:_ Substituting the next term would use the unknown value being calculated. The current term \(x_n\) is substituted into \(f\) to find \(x_{n+1}\).
- The term number \(n\).
  - _why:_ The index \(n\) labels the term but is not the value substituted here. The recurrence uses the current term \(x_n\) to calculate the next one.

## Card 6 — `cloze`

**Front:** In \(x_{n+1}=2+\frac{6}{x_n^2}\), \(x_n\) is the [ ___ ] value and \(x_{n+1}\) is the [ ___ ] value.

**Back:** In \(x_{n+1}=2+\frac{6}{x_n^2}\), \(x_n\) is the current value and \(x_{n+1}\) is the next value.

**Choices:**

- In \(x_{n+1}=2+\frac{6}{x_n^2}\), \(x_n\) is the current value and \(x_{n+1}\) is the next value. ✔
  - _why:_ The formula uses the current value \(x_n\) as its input and produces the next value \(x_{n+1}\), advancing the sequence by one term.
- In \(x_{n+1}=2+\frac{6}{x_n^2}\), \(x_n\) is the previous value and \(x_{n+1}\) is the current value.
  - _why:_ This labels the terms from the following step rather than the calculation shown. Here \(x_n\) is the current value and \(x_{n+1}\) is the next value.
- In \(x_{n+1}=2+\frac{6}{x_n^2}\), \(x_n\) is the next value and \(x_{n+1}\) is the current value.
  - _why:_ This reverses the order of the sequence. The input \(x_n\) is the current value, while the output \(x_{n+1}\) is the next value.
- In \(x_{n+1}=2+\frac{6}{x_n^2}\), \(x_n\) is the starting value and \(x_{n+1}\) is the final value.
  - _why:_ The indices do not necessarily represent the beginning and end of the iteration. They identify consecutive terms: \(x_n\) is current and \(x_{n+1}\) is next.

## Card 7 — `cloze`

**Front:** Starting from \(x_0\), after one use you get [ ___ ]; after three uses you get [ ___ ].

**Back:** Starting from \(x_0\), after one use you get \(x_1\); after three uses you get \(x_3\).

**Choices:**

- Starting from \(x_0\), after one use you get \(x_1\); after three uses you get \(x_3\). ✔
  - _why:_ Each use of the recurrence increases the subscript by one. Starting at \(x_0\), one use reaches \(x_1\) and three uses reach \(x_3\).
- Starting from \(x_0\), after one use you get \(x_0\); after three uses you get \(x_2\).
  - _why:_ This fails to count the first application as a step. Each use increases the subscript, so one use gives \(x_1\) and three uses give \(x_3\).
- Starting from \(x_0\), after one use you get \(x_1\); after three uses you get \(x_4\).
  - _why:_ The first result is counted correctly, but the third is one step too far. Three applications from \(x_0\) produce \(x_1\), \(x_2\), then \(x_3\).
- Starting from \(x_0\), after one use you get \(x_2\); after three uses you get \(x_3\).
  - _why:_ This skips \(x_1\) on the first application. A recurrence advances one subscript at a time, so one use gives \(x_1\), while three uses give \(x_3\).

## Card 8 — `basic`

**Front:** For \(P_{t+1}=1.10(P_t-12)\), which value is used to calculate \(P_2\)?

**Back:** \(P_1\), not \(P_0\).

**Choices:**

- \(P_1\), not \(P_0\). ✔
  - _why:_ To calculate \(P_2\), set \(t=1\), giving \(P_2=1.10(P_1-12)\). The recurrence therefore uses the immediately preceding value \(P_1\).
- \(P_0\), not \(P_1\).
  - _why:_ Using \(P_0\) would calculate \(P_1\), not \(P_2\). To find \(P_2\), the current value must be \(P_1\).
- \(P_2\), not \(P_1\).
  - _why:_ The recurrence cannot use the unknown value \(P_2\) to calculate itself. It uses the preceding value \(P_1\) to produce \(P_2\).
- \(P_3\), not \(P_2\).
  - _why:_ This uses a later term rather than the preceding one. Calculating \(P_2\) requires setting \(t=1\), so the substituted value is \(P_1\).

## Card 14 — `cloze`

**Front:** If the terms get closer and closer to one value, the sequence [ ___ ].

**Back:** If the terms get closer and closer to one value, the sequence converges.

**Choices:**

- converges ✔
  - _why:_ A sequence converges when its terms approach one fixed value more and more closely, even if the limiting value is never reached exactly.
- diverges
  - _why:_ Divergence means the terms do not approach one limiting value. The described behaviour is convergence, so the sequence converges.
- terminates
  - _why:_ A terminating sequence stops after a finite number of terms, whereas getting closer to one value describes convergence. The correct term is converges.
- cycles
  - _why:_ A cycling sequence repeatedly returns to a pattern of values rather than approaching one value. Terms getting closer to one value means the sequence converges.

## Card 15 — `cloze`

**Front:** At a fixed point, applying the iteration rule leaves the value [ ___ ]; the current and next values are [ ___ ].

**Back:** At a fixed point, applying the iteration rule leaves the value unchanged; the current and next values are equal.

**Choices:**

- At a fixed point, applying the iteration rule leaves the value unchanged; the current and next values are equal. ✔
  - _why:_ At a fixed point, the iteration rule maps the value to itself. Therefore the value remains unchanged, and the current and next terms are equal.
- At a fixed point, applying the iteration rule leaves the value changed; the current and next values are equal.
  - _why:_ A fixed point is not changed by applying the rule, although the current and next values are equal. The correct description is unchanged and equal.
- At a fixed point, applying the iteration rule leaves the value unchanged; the current and next values are different.
  - _why:_ If the value is unchanged by the rule, the next value must be the same as the current value. Thus the correct pair is unchanged and equal.
- At a fixed point, applying the iteration rule leaves the value changed; the current and next values are different.
  - _why:_ Both terms describe movement away from the defining property of a fixed point. A fixed point remains unchanged, so the current and next values are equal.

## Card 18 — `basic`

**Front:** What substitution links a convergent iteration to its equation?

**Back:** Set \(x_{n+1}=x_n=a\).

**Choices:**

- Set \(x_{n+1}=x_n=a\). ✔
  - _why:_ At convergence, consecutive iterates approach the same limiting value. Calling that value \(a\) means setting both \(x_{n+1}\) and \(x_n\) equal to \(a\).
- Set \(x_{n+1}=x_n+1=a\).
  - _why:_ Adding 1 incorrectly describes a sequence increasing by a fixed amount, not a convergent sequence. Convergence requires consecutive iterates to become equal: \(x_{n+1}=x_n=a\).
- Set \(x_{n+1}=x_n=0\).
  - _why:_ Zero is not automatically the limiting value; it must satisfy the iteration equation. The general fixed-point substitution is \(x_{n+1}=x_n=a\), with \(a\) then determined algebraically.
- Set \(x_{n+1}=\frac{1}{x_n}=a\).
  - _why:_ Taking a reciprocal imposes an unrelated condition and does not express convergence. A convergent iteration has equal consecutive values, so the substitution is \(x_{n+1}=x_n=a\).

## Card 19 — `basic`

**Front:** From \(a=\frac{2}{a^2+4}\), what equation follows after rearranging?

**Back:** \(a^3+4a-2=0\)

**Choices:**

- \(a^3+4a-2=0\) ✔
  - _why:_ Multiplying by \(a^2+4\) gives \(a(a^2+4)=2\). Expanding and moving all terms to one side produces \(a^3+4a-2=0\).
- \(a^3+4a+2=0\)
  - _why:_ The constant term changes sign incorrectly when 2 is moved to the left. Rearranging gives \(a^3+4a-2=0\), because the original right-hand side is positive 2.
- \(a^2+4a-2=0\)
  - _why:_ This misses the factor of \(a\) multiplying the denominator. Multiplying through gives \(a(a^2+4)=a^3+4a\), leading to \(a^3+4a-2=0\).
- \(a^3+2a-4=0\)
  - _why:_ The coefficients have been rearranged incorrectly. Expanding \(a(a^2+4)\) gives \(a^3+4a\), and subtracting 2 yields \(a^3+4a-2=0\).

**Choices:**

- A sign change means one output is negative and the other is positive. ✔
  - _why:_ A sign change occurs when two function outputs have opposite signs: one is negative and the other is positive. This supports the existence of a root between them for a continuous function.
- A sign change means one output is positive and the other is positive.
  - _why:_ Two positive outputs have the same sign, so no sign change has occurred. A sign change requires one negative output and one positive output.
- A sign change means one output is negative and the other is negative.

- A sign change means one output is zero and the other is positive.
  - _why:_ An output of zero means a root has already been found, rather than showing a sign change across an interval. A sign change requires opposite non-zero signs: negative and positive.

## Card 21 — `basic`

**Front:** Show that \(x^3+5x-2=0\) has a solution between \(0\) and \(1\).

**Back:** \(f(0)=-2\)\(f(1)=4\)Opposite signs and continuous, so a root lies between.

**Choices:**

- \(f(0)=-2\)\(f(1)=4\)Opposite signs and continuous, so a root lies between. ✔
  - _why:_ Evaluating gives \(f(0)=-2\) and \(f(1)=4\), which have opposite signs. Since the polynomial is continuous, the Intermediate Value Theorem guarantees a root between 0 and 1.
- \(f(0)=2\)\(f(1)=4\)Same signs and continuous, so a root lies between.
  - _why:_ The constant term is \(-2\), so \(f(0)=-2\), not 2. The correct endpoint values are \(-2\) and 4, giving opposite signs and therefore a root between them.
- \(f(0)=-2\)\(f(1)=2\)Opposite signs and continuous, so a root lies between.
  - _why:_ At 1, the value is \(1^3+5(1)-2=4\), not 2. Although the sign conclusion is right, the endpoint calculation must be \(f(1)=4\).
- \(f(0)=-2\)\(f(1)=4\)Opposite signs but not continuous, so no conclusion follows.
  - _why:_ A polynomial is continuous everywhere, so the opposite endpoint signs do guarantee a root in the interval. The mistake is wrongly denying continuity.
