# Vectors Proof Questions Flashcards

_Lane: `gcse-maths-edexcel` · grade 8 · 2 cards (source: MathsGenie flashcards)_

## Card 1 — `basic`

**Front:** How is the vector $\vec{AB}$ expressed using the position vectors $\vec{OA}$ and $\vec{OB}$?

**Back:** $$\vec{AB} = \vec{OB} - \vec{OA}$

**Choices:**

- $$\vec{AB} = \vec{OB} - \vec{OA}$ ✔
  - _why:_ Subtracting the position vector of the starting point A from that of the endpoint B gives the displacement from A to B.
- $$\vec{AB} = \vec{OA} - \vec{OB}$
  - _why:_ Reversing the subtraction gives the vector from B to A, which points in the opposite direction. The correct relationship is $\vec{AB} = \vec{OB} - \vec{OA}$.
- $$\vec{AB} = \vec{OA} + \vec{OB}$
  - _why:_ Adding both position vectors does not represent the displacement between A and B. The starting position must be subtracted, giving $\vec{AB} = \vec{OB} - \vec{OA}$.
- $$\vec{AB} = \vec{OB} + \vec{OA}$
  - _why:_ The sum of the two position vectors does not account for A being the starting point. Subtracting A’s position from B’s gives $\vec{AB} = \vec{OB} - \vec{OA}$.

## Card 2 — `basic`

**Front:** What defines a position vector?

**Back:** A vector that starts from the origin (point O).

**Choices:**

- A vector that starts from the origin (point O). ✔
  - _why:_ A position vector describes the location of a point relative to the origin, so its initial point is always the origin O.
- A vector that ends at the origin (point O).
  - _why:_ This reverses the defining direction of a position vector. A position vector starts at the origin O and ends at the point whose position it represents.
- A vector that starts from any fixed point (point A).
  - _why:_ Using any fixed starting point describes a general displacement vector, not necessarily a position vector. A position vector must start from the origin O.
- A vector that joins any two points (points A and B).
  - _why:_ A vector between arbitrary points represents displacement from one point to another. A position vector specifically begins at the origin O and locates another point.
