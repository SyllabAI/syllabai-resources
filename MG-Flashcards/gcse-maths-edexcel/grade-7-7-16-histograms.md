## Card 1 — `basic`

**Front:** In a histogram, what does the area of a bar represent?

**Back:** Frequency.

**Choices:**

- Frequency. ✔
  - _why:_ A bar’s area represents frequency because area equals class width multiplied by frequency density. This ensures that larger bar areas correspond to more observations.
- Frequency density.
  - _why:_ Frequency density determines the bar’s height, not its area. The area represents frequency because multiplying frequency density by class width gives the frequency.
- Class width.
  - _why:_ Class width is represented by the bar’s horizontal width, not its area. The area of the bar represents the frequency in that class interval.
- Class boundary.
  - _why:_ Class boundaries mark the endpoints of each interval and do not correspond to bar area. The area of a histogram bar represents the class frequency.

## Card 2 — `cloze`

**Front:** A histogram is used for grouped [ ___ ].

**Back:** A histogram is used for grouped continuous data.

**Choices:**

- continuous data ✔
  - _why:_ Histograms display grouped continuous data because values can occur anywhere within each class interval, and the bars therefore touch to show this continuity.
- discrete data
  - _why:_ Discrete data consists of separate countable values and is usually shown using a bar chart. A histogram is used for grouped continuous data.
- categorical data
  - _why:_ Categorical data is divided into named groups and is normally displayed with a bar chart. Histograms are designed for grouped continuous data.
- nominal data
  - _why:_ Nominal data consists of unordered categories rather than numerical intervals, so a bar chart is appropriate. A histogram is used for grouped continuous data.

## Card 3 — `basic`

**Front:** In the class interval $0 \le t < 5$, where does a value of exactly 5 go?

**Back:** The next class.

**Choices:**

- The next class. ✔
  - _why:_ The inequality $t < 5$ excludes 5 from this interval. Therefore, exactly 5 belongs in the next class, whose lower boundary is 5.
- The previous class.
  - _why:_ Treating the upper boundary as included ignores the strict inequality $t < 5$. Exactly 5 is excluded and must be placed in the next class.
- The current class.
  - _why:_ The current class contains values from 0 up to, but not including, 5. Therefore, exactly 5 must be placed in the next class.
- The nearest class.
  - _why:_ Class placement is determined by the inequalities, not by which interval seems nearest. Since $t < 5$ excludes 5, it belongs in the next class.

## Card 4 — `basic`

**Front:** Find the class width of $7 \le t < 15$.

**Back:** 8.

**Choices:**

- 8. ✔
  - _why:_ Class width is found by subtracting the lower boundary from the upper boundary. Here, $15 - 7 = 8$, so the class width is 8.
- 7.
  - _why:_ Subtracting an extra 1 incorrectly treats class width as a count of selected integer positions. Using the boundaries gives $15 - 7 = 8$.
- 9.
  - _why:_ Counting both endpoints produces an off-by-one error and ignores that 15 is excluded. Class width is the boundary difference, $15 - 7 = 8$.
- 22.
  - _why:_ Adding the two boundaries does not calculate the size of the interval. Class width is found by subtraction, giving $15 - 7 = 8$.

## Card 5 — `cloze`

**Front:** Class width = [ ___ ] - [ ___ ].

**Back:** Class width = upper boundary - lower boundary.

**Choices:**

- Class width = upper boundary - lower boundary. ✔
  - _why:_ Class width measures the distance between the interval’s boundaries, so it is calculated by subtracting the lower boundary from the upper boundary.
- Class width = lower boundary - upper boundary.
  - _why:_ Reversing the subtraction usually gives a negative result, although class width must be positive. Subtract the lower boundary from the upper boundary instead.
- Class width = class midpoint - lower boundary.
  - _why:_ The distance from the lower boundary to the midpoint is only half the class width. The full width is upper boundary minus lower boundary.
- Class width = upper boundary - class midpoint.
  - _why:_ The distance from the midpoint to the upper boundary is only half the interval. Class width is calculated as upper boundary minus lower boundary.

## Card 7 — `basic`

**Front:** What is the height of a histogram bar called?

**Back:** Frequency density.

**Choices:**

- Frequency density. ✔
  - _why:_ The vertical height of each histogram bar is frequency density. Multiplying this height by the class width gives the frequency represented by the bar’s area.
- Frequency.
  - _why:_ Frequency is represented by the bar’s area, not necessarily its height, because histogram classes may have unequal widths. The height is called frequency density.
- Class width.
  - _why:_ Class width is shown horizontally along the axis and determines the bar’s width. The vertical height of a histogram bar is called frequency density.
- Class boundary.
  - _why:_ Class boundaries are the endpoints marked along the horizontal axis, not vertical measurements. The height of a histogram bar is called frequency density.

## Card 9 — `basic`

**Front:** How do you calculate frequency density from frequency and class width?

**Back:** Frequency density $= \frac{\text{frequency}}{\text{class width}}$.

**Choices:**

- Frequency density $= \frac{\text{frequency}}{\text{class width}}$. ✔
  - _why:_ Dividing the frequency by the class width accounts for unequal class intervals. The resulting frequency density determines the height of the corresponding histogram bar.
- Frequency density $= \frac{\text{class width}}{\text{frequency}}$.
  - _why:_ This reverses the required division. Frequency density is calculated by dividing frequency by class width, not class width by frequency.
- Frequency density $= \text{frequency} \times \text{class width}$.
  - _why:_ Multiplication is used to recover frequency from frequency density and class width. To find frequency density, divide the frequency by the class width.
- Frequency density $= \frac{\text{frequency}}{\text{class midpoint}}$.
  - _why:_ The class midpoint identifies the centre of an interval but is not used to calculate bar height. Frequency density is frequency divided by class width.

## Card 13 — `basic`

**Front:** How do you calculate frequency from class width and frequency density?

**Back:** Frequency $= \text{class width} \times \text{frequency density}$.

**Choices:**

- Frequency $= \text{class width} \times \text{frequency density}$. ✔
  - _why:_ A histogram bar’s area represents frequency. Since its width is the class width and its height is the frequency density, multiplying them gives the frequency.
- Frequency $= \frac{\text{class width}}{\text{frequency density}}$.
  - _why:_ Dividing class width by frequency density does not give bar area. Frequency is found by multiplying class width by frequency density.

  - _why:_ This divides the bar height by its width rather than calculating its area. Frequency equals class width multiplied by frequency density.
- Frequency $= \text{class width} + \text{frequency density}$.
  - _why:_ Adding width and height does not calculate a histogram bar’s area. Frequency is found by multiplying class width by frequency density.

## Card 19 — `basic`

**Front:** When drawing a histogram, should the bars touch?

**Back:** Yes - bars touch for continuous grouped data.

**Choices:**

- Yes - bars touch for continuous grouped data. ✔
  - _why:_ A histogram represents continuous grouped data, so adjacent class intervals meet without gaps. Therefore, the corresponding bars touch unless an interval has zero frequency.
- No - bars have gaps for continuous grouped data.
  - _why:_ Gaps are normally used in bar charts for separate categories or discrete values. Histograms represent continuous grouped intervals, so adjacent bars should touch.
- No - bars touch only for discrete ungrouped data.
  - _why:_ This reverses the usual distinction between chart types. Histogram bars touch because the grouped intervals form a continuous scale, while discrete bar charts normally have gaps.
- No - bars must be separated when class widths differ.
  - _why:_ Unequal class widths change the widths and frequency densities of the bars, not whether they touch. Adjacent continuous class intervals are still drawn without gaps.

**Back:** It has a larger class width.

**Choices:**

- It has a larger class width. ✔
  - _why:_ Histogram bar widths represent class widths on the horizontal axis. The interval from 15 to 25 has width 10, while the interval from 4 to 9 has width 5.

  - _why:_ A larger upper boundary alone does not determine bar width; the lower boundary must also be considered. The class widths are 10 and 5, respectively.
