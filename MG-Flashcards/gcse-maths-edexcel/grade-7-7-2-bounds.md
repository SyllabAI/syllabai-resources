## Card 1 — `cloze`

**Front:** The lower bound is the [ ___ ] possible value before rounding, while the upper bound is the largest boundary value.

**Back:** The lower bound is the smallest possible value before rounding, while the upper bound is the largest boundary value.

**Choices:**

- smallest ✔
  - _why:_ The lower bound marks the smallest possible original value within the interval of values that round to the stated measurement.
- largest
  - _why:_ This reverses the definitions of the two bounds. The lower bound is the smallest possible original value that could have produced the stated rounded value.
- average
  - _why:_ A bound is an endpoint, not a mean of the possible values. The lower bound is the smallest possible value before rounding.
- nearest
  - _why:_ This confuses a boundary with the rounded value itself. The lower bound is the smallest possible value in the rounding interval.

**Back:** The lower bound is the smallest possible value before rounding, while the upper bound is the largest boundary value.

**Choices:**

- largest ✔

- smallest
  - _why:_ This describes the lower boundary rather than the upper boundary. The upper bound is the largest boundary value in the rounding interval.
- nearest
  - _why:_ The rounded value may be nearest to the original value, but the upper bound is specifically the largest boundary value permitted.
- central
  - _why:_ The centre of the interval is the rounded value, not its upper boundary. The upper bound is the largest boundary value.

## Card 3 — `basic`

**Front:** What is the half-gap for a measurement rounded to the nearest $5\text{ m}$?

**Back:** $$2.5\text{ m}$

**Choices:**

- $$2.5\text{ m}$ ✔
  - _why:_ Values rounded to the nearest $5\text{ m}$ have a rounding gap of $5\text{ m}$, so the half-gap is $5 \div 2 = 2.5\text{ m}$.
- $$1.25\text{ m}$
  - _why:_ This uses one quarter of the rounding interval rather than one half. Half of the $5\text{ m}$ gap is $2.5\text{ m}$.
- $$5\text{ m}$
  - _why:_ This uses the full rounding gap instead of halving it. The half-gap for rounding to the nearest $5\text{ m}$ is $2.5\text{ m}$.
- $$10\text{ m}$
  - _why:_ This incorrectly doubles the rounding gap. The gap is $5\text{ m}$ and its half-gap is therefore $2.5\text{ m}$.

## Card 4 — `basic`

**Front:** What is the half-gap for a measurement rounded correct to $2$ decimal places?

**Back:** $$0.005$

**Choices:**

- $$0.005$ ✔
  - _why:_ Two decimal places correspond to a rounding increment of $0.01$. The half-gap is therefore $0.01 \div 2 = 0.005$.
- $$0.01$
  - _why:_ This is the full gap between consecutive values to two decimal places. Halving $0.01$ gives the required half-gap of $0.005$.
- $$0.05$
  - _why:_ This is the half-gap for rounding to one decimal place. For two decimal places, the gap is $0.01$, giving a half-gap of $0.005$.
- $$0.0005$
  - _why:_ This introduces an extra decimal place when halving. Half of the two-decimal-place increment $0.01$ is $0.005$, not $0.0005$.

## Card 5 — `basic`

**Front:** If a measurement in $\text{cm}$ is rounded to the nearest $\text{mm}$, what half-gap value is used?

**Back:** $$0.05\text{ cm}$

**Choices:**

- $$0.05\text{ cm}$ ✔
  - _why:_ One millimetre equals $0.1\text{ cm}$, so rounding to the nearest millimetre gives a half-gap of $0.1 \div 2 = 0.05\text{ cm}$.
- $$0.1\text{ cm}$
  - _why:_ This uses the full $1\text{ mm}$ rounding gap, converted to centimetres, without halving it. The required half-gap is $0.05\text{ cm}$.
- $$0.5\text{ cm}$
  - _why:_ This incorrectly treats half a millimetre as half a centimetre. Since $0.5\text{ mm}=0.05\text{ cm}$, the half-gap is $0.05\text{ cm}$.
- $$0.005\text{ cm}$
  - _why:_ This divides by ten once too many during the unit conversion. Half a millimetre is $0.05\text{ cm}$, not $0.005\text{ cm}$.

## Card 6 — `cloze`

**Front:** A rounded value $l$ is expressed as an interval using the symbols: $\text{[...]} l < <$.

**Back:** A rounded value $l$ is expressed as an interval using the symbols: $\boxed{\le} l < <$.

**Choices:**

- $$\le$ ✔
  - _why:_ The lower boundary is included in a bounds interval, so the lower bound is less than or equal to the value: $\text{lower bound} \le l$.
- $$<$
  - _why:_ Using a strict inequality would exclude the lower boundary. Bounds intervals include the lower bound, so the left-hand comparison must use $\le$.
- $$\ge$
  - _why:_ This reverses the direction of the comparison. The interval is written from the lower bound to $l$, so the required symbol is $\le$.
- $$>$
  - _why:_ This both reverses the comparison and excludes the lower boundary. The correct relationship is $\text{lower bound} \le l$.

## Card 7 — `cloze`

**Front:** A rounded value $l$ is expressed as an interval using the symbols: $\le l < \text{[...]}$.

**Back:** A rounded value $l$ is expressed as an interval using the symbols: $\le l < \boxed{<}$.

**Choices:**

- $$<$ ✔
  - _why:_ The upper boundary is excluded from the interval, so the value must be strictly less than the upper bound. This requires the symbol $<$.
- $$\le$
  - _why:_ The upper boundary is not included because values exactly at it round to the next value. The right-hand comparison must therefore use $<$.
- $$>$
  - _why:_ This reverses the comparison, suggesting that $l$ exceeds the upper bound. Instead, $l$ must be strictly less than the upper bound, using $<$.
- $$\ge$
  - _why:_ This reverses the comparison and incorrectly includes the upper boundary. The value must be strictly less than the upper bound, so the correct symbol is $<$.

## Card 8 — `basic`

**Front:** How do you calculate the upper bound for the area of a rectangle?

**Back:** $$\text{upper length} \times \text{upper width}$

**Choices:**

- $$\text{upper length} \times \text{upper width}$ ✔
  - _why:_ For positive rectangle dimensions, the area increases as either dimension increases. Its upper bound is therefore found by multiplying both upper bounds.
- $$\text{lower length} \times \text{lower width}$
  - _why:_ Using both lower dimensions gives the lower bound for the area, not the upper bound. The maximum area uses the upper length and upper width.
- $$\text{upper length} \times \text{lower width}$
  - _why:_ Using the lower width prevents the area from being as large as possible. The upper bound requires both the upper length and upper width.
- $$\text{lower length} \times \text{upper width}$
  - _why:_ Using the lower length prevents the area from being maximised. Both dimensions must take their upper bounds to find the upper bound for area.

## Card 9 — `basic`

**Front:** How do you calculate the lower bound for the perimeter of a rectangle?

**Back:** $$2 \times (\text{lower length} + \text{lower width})$

**Choices:**

- $$2 \times (\text{lower length} + \text{lower width})$ ✔
  - _why:_ The perimeter increases as either dimension increases, so using both lower bounds gives the smallest possible perimeter: twice the sum of the lower length and lower width.
- $$2 \times (\text{upper length} + \text{upper width})$
  - _why:_ Using both upper bounds gives the upper bound, not the lower bound, of the perimeter. The lower bound is $2 \times (\text{lower length} + \text{lower width})$.
- $$2 \times (\text{lower length} + \text{upper width})$
  - _why:_ Mixing a lower length with an upper width does not produce the smallest possible perimeter. Both dimensions must use their lower bounds in the perimeter formula.
- $$2 \times (\text{upper length} + \text{lower width})$
  - _why:_ Using the upper length makes the calculated perimeter larger than its minimum possible value. The lower bounds of both the length and width are required.

## Card 10 — `basic`

**Front:** To find the lower bound for a circle's circumference ($C=2\pi r$), which bound of the radius is required?

**Back:** The lower bound of the radius.

**Choices:**

- The lower bound of the radius. ✔
  - _why:_ Circumference is directly proportional to radius because $C=2\pi r$. Therefore, the smallest possible radius produces the lower bound of the circumference.
- The upper bound of the radius.
  - _why:_ Using the upper radius produces the upper bound of the circumference because circumference increases with radius. The lower bound of the radius is required for the lower circumference bound.
- The rounded value of the radius.
  - _why:_ The rounded radius is not the smallest possible radius and therefore cannot guarantee the lower circumference bound. Use the lower bound of the radius in $C=2\pi r$.
- The midpoint value of the radius.
  - _why:_ The midpoint lies between the radius bounds, so it gives neither an upper nor a lower circumference bound. The lower radius bound gives the lower circumference bound.

## Card 11 — `basic`

**Front:** How do you calculate the upper bound of a product $v = x \times y$?

**Back:** $$\text{upper } x \times \text{upper } y$

**Choices:**

- $$\text{upper } x \times \text{upper } y$ ✔
  - _why:_ For positive quantities, a product is greatest when both factors take their greatest possible values. Therefore, multiply the upper bound of $x$ by the upper bound of $y$.
- $$\text{lower } x \times \text{lower } y$
  - _why:_ Using both lower bounds gives the lower bound of the product for positive quantities. The upper product bound requires $\text{upper } x \times \text{upper } y$.
- $$\text{upper } x \times \text{lower } y$
  - _why:_ Mixing an upper bound with a lower bound does not maximise both positive factors. The largest possible product is found by multiplying both upper bounds.
- $$\text{lower } x \times \text{upper } y$
  - _why:_ Using the lower bound of $x$ prevents the product from reaching its greatest possible value. For the upper bound, multiply the upper bounds of both variables.

## Card 12 — `cloze`

**Front:** To find the upper bound of a fraction, use the [ ___ ] numerator and the lower denominator.

**Back:** To find the upper bound of a fraction, use the upper numerator and the lower denominator.

**Choices:**

- upper ✔
  - _why:_ A fraction becomes larger when its positive numerator increases. Therefore, its upper bound uses the upper numerator together with the lower denominator.
- lower
  - _why:_ Using the lower numerator tends to minimise rather than maximise a positive fraction. Its upper bound requires the upper numerator and the lower denominator.
- central
  - _why:_ A central numerator value does not represent an extreme and therefore cannot guarantee an upper bound. Use the upper numerator and lower denominator to maximise the fraction.
- rounded
  - _why:_ The rounded numerator is only an estimate and need not be the greatest possible value. The upper numerator must be used to obtain the fraction’s upper bound.

## Card 13 — `cloze`

**Front:** To find the upper bound of a fraction, use the upper numerator and the [ ___ ] denominator.

**Back:** To find the upper bound of a fraction, use the upper numerator and the lower denominator.

**Choices:**

- lower ✔
  - _why:_ For a positive fraction, decreasing the denominator increases the quotient. Therefore, the upper bound uses the lower denominator together with the upper numerator.
- upper
  - _why:_ Using the upper denominator makes a positive quotient smaller, so it contributes to a lower bound. The upper fraction bound requires the lower denominator.
- central
  - _why:_ A central denominator is not an extreme value and cannot guarantee the greatest possible quotient. The lower denominator must be paired with the upper numerator.
- rounded
  - _why:_ The rounded denominator is an estimate rather than the smallest possible value. To maximise the fraction, use the denominator’s lower bound.

## Card 14 — `basic`

**Front:** In the formula $v = \frac{s}{t}$, why is the lower bound of $t$ used to find the upper bound of $v$?

**Back:** A smaller denominator results in a larger overall quotient.

**Choices:**

- A smaller denominator results in a larger overall quotient. ✔
  - _why:_ With a fixed positive numerator, division by a smaller positive number gives a larger result. Thus, the lower bound of $t$ helps produce the upper bound of $v$.
- A larger denominator results in a larger overall quotient.
  - _why:_ This reverses the effect of the denominator: increasing a positive denominator decreases the quotient. The upper bound of $v$ therefore uses the lower bound of $t$.
- A smaller denominator results in a smaller overall quotient.
  - _why:_ This confuses division with direct proportion. For a fixed positive numerator, a smaller denominator gives a larger quotient, so the lower bound of $t$ is used.
- A larger denominator results in an unchanged overall quotient.
  - _why:_ Changing the denominator changes the quotient when the numerator is fixed. A smaller positive denominator creates a larger quotient, which is why the lower bound of $t$ is required.

**Front:** To find the lower bound of a fraction, which bounds for the numerator and denominator are used?

**Back:** Lower bound of the numeratorUpper bound of the denominator

**Choices:**

- Lower bound of the numeratorUpper bound of the denominator ✔

## Card 16 — `basic`

**Front:** To find the lower bound of the hypotenuse $c$ in $c^2 = a^2 + b^2$, which bounds of $a$ and $b$ are used?

**Back:** The lower bounds of both $a$ and $b$.

**Choices:**

- The lower bounds of both $a$ and $b$. ✔
  - _why:_ For positive lengths, increasing either shorter side increases $a^2+b^2$ and hence $c$. The lower hypotenuse bound therefore uses the lower bounds of both $a$ and $b$.
- The upper bounds of both $a$ and $b$.
  - _why:_ Using both upper bounds makes $a^2+b^2$ as large as possible, producing the upper bound of $c$. The lower bound requires both lower bounds.
- The lower bound of $a$ and upper bound of $b$.
  - _why:_ Using the upper bound of $b$ does not minimise $a^2+b^2$, so the result is not the lower hypotenuse bound. Both $a$ and $b$ require lower bounds.
- The upper bound of $a$ and lower bound of $b$.
  - _why:_ Using the upper bound of $a$ prevents $a^2+b^2$ from taking its smallest possible value. The lower bounds of both sides are needed.

## Card 17 — `basic`

**Front:** To find the lower bound of side $b = \sqrt{c^2 - a^2}$, which bound of the hypotenuse $c$ is used?

**Back:** The lower bound of $c$.

**Choices:**

- The lower bound of $c$. ✔
  - _why:_ A smaller hypotenuse gives a smaller value of $c^2$, so it minimises $c^2-a^2$ and therefore produces the lower bound of $b$.
- The upper bound of $c$.
  - _why:_ Using the upper bound of $c$ increases $c^2$ and therefore increases $b$. The lower bound of $c$ is needed to minimise the result.
- The rounded value of $c$.
  - _why:_ The stated rounded value is not an extreme of the possible interval. The lower bound of $c$ must be used because it produces the smallest possible $c^2$.
- The midpoint value of $c$.
  - _why:_ The midpoint does not give the smallest possible result and is usually just the stated rounded value. The lower bound of $c$ is required to minimise $b$.

## Card 18 — `basic`

**Front:** To find the lower bound of side $b = \sqrt{c^2 - a^2}$, which bound of side $a$ is used?

**Back:** The upper bound of $a$ (subtracting a larger value minimizes the result).

**Choices:**

- The upper bound of $a$ (subtracting a larger value minimizes the result). ✔
  - _why:_ Because $a^2$ is subtracted, its largest possible value makes $c^2-a^2$ as small as possible. This gives the lower bound of $b$.
- The lower bound of $a$ (subtracting a smaller value minimizes the result).
  - _why:_ Subtracting a smaller value actually leaves a larger result, so this would help maximise $b$. The upper bound of $a$ is used to find the lower bound.
- The rounded value of $a$ (subtracting the stated value minimizes the result).
  - _why:_ The rounded value is not the largest possible value of $a$, so it cannot guarantee the minimum. The upper bound of $a$ must be subtracted.
- The midpoint value of $a$ (subtracting the central value minimizes the result).
  - _why:_ Using the midpoint ignores the extreme values allowed by the bounds. Since $a^2$ is subtracted, its upper bound gives the smallest possible result.

## Card 19 — `basic`

**Front:** Define a suitable degree of accuracy in the context of bounds.

**Back:** The rounding level where the lower bound and upper bound round to the same value.

**Choices:**

- The rounding level where the lower bound and upper bound round to the same value. ✔
  - _why:_ If both endpoints round to the same value at a particular accuracy, every possible value between them also rounds to that value, making the accuracy justified.
- The rounding level where the lower bound and upper bound round to different values.
  - _why:_ Different rounded endpoint values mean the interval does not determine one answer at that accuracy. A suitable accuracy is one where both bounds round to the same value.
- The rounding level where the lower bound and upper bound have the same digits.
  - _why:_ Bounds may share several digits without rounding to the same final value. Suitability depends specifically on both bounds rounding to exactly the same value.
- The rounding level where the lower bound and upper bound differ by the rounding unit.
  - _why:_ Comparing the interval width with the rounding unit is not sufficient, especially near a rounding boundary. Both bounds must round to the same value.

## Card 20 — `basic`

**Front:** If $LB = 5.359$ and $UB = 5.371$, why is "2 decimal places" NOT a suitable degree of accuracy?

**Back:** They round to different values ($5.36$ and $5.37$).

**Choices:**

- They round to different values ($5.36$ and $5.37$). ✔
  - _why:_ At two decimal places, $5.359$ rounds to $5.36$, while $5.371$ rounds to $5.37$. Therefore the interval does not guarantee one rounded answer.
- They round to the same value ($5.36$ and $5.36$).
  - _why:_ This incorrectly rounds $5.371$ down; its third decimal digit is $1$, so it rounds to $5.37$. The bounds therefore give different two-decimal-place values.
- They round to different values ($5.35$ and $5.38$).
  - _why:_ These results come from moving each endpoint outward rather than applying standard rounding. Correctly rounding gives $5.36$ and $5.37$, which are still different.
- They round to the same value ($5.37$ and $5.37$).
  - _why:_ This incorrectly rounds $5.359$ up to $5.37$; its hundredths rounding is determined by the third decimal digit, giving $5.36$. The endpoints round differently.

## Card 21 — `basic`

**Front:** What are the bounds for $58.0\text{ cm}$ correct to the nearest millimetre?

**Back:** $$57.95 \le l < 58.05$

**Choices:**

- $$57.95 \le l < 58.05$ ✔
  - _why:_ One millimetre is $0.1$ cm, so the rounding interval extends half of this, $0.05$ cm, on either side of $58.0$ cm.
- $$57.5 \le l < 58.5$
  - _why:_ These are the bounds for a measurement rounded to the nearest centimetre, not millimetre. Nearest millimetre means half of $0.1$ cm, giving $57.95 \le l < 58.05$.
- $$57.9 \le l < 58.1$
  - _why:_ This subtracts and adds a whole millimetre rather than half a millimetre. Rounding bounds use half the rounding unit, so the correct endpoints are $57.95$ and $58.05$.
- $$57.99 \le l < 58.01$
  - _why:_ This interval uses $0.01$ cm on either side, equivalent to only $0.1$ mm. Half of the $1$ mm rounding unit is $0.5$ mm, or $0.05$ cm.

## Card 22 — `cloze`

**Front:** When solving bounds problems, you should calculate the bounds for each value [ ___ ] substituting them into a formula.

**Back:** When solving bounds problems, you should calculate the bounds for each value before substituting them into a formula.

**Choices:**

- before ✔
  - _why:_ Each measured quantity has its own interval of possible values. Finding those bounds before substitution ensures the correct extreme values are selected for the required result.
- after
  - _why:_ Substituting the rounded measurements first loses the extreme values needed for a bounds calculation. The lower and upper bounds of every value must be found before substitution.
- while
  - _why:_ Working out bounds during substitution encourages values to be bounded inconsistently or overlooked. Determine each quantity’s lower and upper bounds before applying the formula.
- without
  - _why:_ Bounds must eventually be substituted into the formula to calculate the result’s limits. They should be calculated before substitution, not used as a replacement for substitution.
