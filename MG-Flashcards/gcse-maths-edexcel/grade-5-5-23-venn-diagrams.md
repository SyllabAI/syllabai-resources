## Card 1 — `basic`

**Front:** In frequency notation, what does $n(A)$ represent?

**Back:** The number of elements in set $A$.

**Choices:**

- The number of elements in set $A$. ✔
  - _why:_ The notation $n(A)$ gives the cardinality of $A$, meaning the total number of distinct elements contained in that set.
- The number of elements outside set $A$.
  - _why:_ This confuses a set with its complement. Elements outside $A$ are counted by $n(A')$, while $n(A)$ counts the elements inside $A$.
- The number of subsets formed from set $A$.
  - _why:_ The number of subsets of a set with $n(A)$ elements is $2^{n(A)}$. The notation $n(A)$ itself counts the elements in $A$.
- The probability of selecting set $A$.
  - _why:_ Probability is written as $P(A)$, not $n(A)$. The notation $n(A)$ represents the number of elements contained in set $A$.

## Card 2 — `basic`

**Front:** What symbol is used for the universal set and how is it represented on a diagram?

**Back:** Symbol: $\mathcal{E}$Representation: The rectangle

**Choices:**

- Symbol: $\mathcal{E}$Representation: The rectangle ✔
  - _why:_ The universal set is denoted by $\mathcal{E}$ in this notation and is drawn as the rectangle containing every set and all relevant elements.
- Symbol: $A$Representation: A circle
  - _why:_ A labelled circle represents an individual set such as $A$, not the universal set. The universal set is $\mathcal{E}$ and is represented by the rectangle.
- Symbol: $\varnothing$Representation: An empty circle
  - _why:_ The symbol $\varnothing$ denotes the empty set, which has no elements. The universal set is denoted by $\mathcal{E}$ and shown as the surrounding rectangle.
- Symbol: $A \cap B$Representation: The overlap
  - _why:_ The notation $A \cap B$ and the overlap represent the intersection of two sets. The universal set is $\mathcal{E}$ and is drawn as the rectangle.

## Card 3 — `cloze`

**Front:** The complement $A'$ represents all elements in the universal set that are [ ___ ].

**Back:** The complement $A'$ represents all elements in the universal set that are not in A.

**Choices:**

- not in A ✔
  - _why:_ The complement of $A$ contains every element belonging to the universal set that does not belong to $A$.
- in A
  - _why:_ This describes $A$ itself rather than its complement. The complement $A'$ consists of elements in the universal set that are not in $A$.
- in every set
  - _why:_ A complement is not defined by membership of every set. The set $A'$ contains precisely the universal-set elements that are not in $A$.
- outside the universal set
  - _why:_ A complement only includes elements within the universal set. Specifically, $A'$ contains those universal-set elements that are not in $A$.

## Card 4 — `basic`

**Front:** Define the intersection symbol $\cap$.

**Back:** Items that are in both set A and set B (the overlap).

**Choices:**

- Items that are in both set A and set B (the overlap). ✔
  - _why:_ The intersection $A \cap B$ consists of elements shared by A and B, so it is represented by the overlapping region of their circles.
- Items that are in either set A or set B (the union).
  - _why:_ This describes the union $A \cup B$, which includes elements in either set. The intersection $A \cap B$ contains only elements in both sets.
- Items that are in only set A and not set B (A-only).
  - _why:_ The A-only region excludes the overlap and is written $A \cap B'$. The intersection $A \cap B$ is the region belonging to both sets.
- Items that are in neither set A nor set B (the outside).
  - _why:_ The region outside both sets is the complement of their union, $(A \cup B)'$. The intersection $A \cap B$ is their shared overlap.

## Card 5 — `basic`

**Front:** Define the union symbol $\cup$.

**Back:** Items in A or B or both.

**Choices:**

- Items in A or B or both. ✔
  - _why:_ The union $A \cup B$ contains every element belonging to A, to B, or to both sets, so both circles are included.
- Items in A and B at once.
  - _why:_ This describes the intersection $A \cap B$, which includes only the overlap. The union $A \cup B$ includes items in A, B, or both.
- Items in A but not B at all.
  - _why:_ This is the A-only region, written $A \cap B'$. The union $A \cup B$ includes all of A and B, including their overlap.
- Items outside A and B entirely.
  - _why:_ This describes elements in neither set, written $(A \cup B)'$. The union $A \cup B$ contains elements in A, B, or both.

## Card 6 — `cloze`

**Front:** $$$P(A') = \text{[...]}$$

**Back:** $$$P(A') = \boxed{1 - P(A)}$$

**Choices:**

- $$$1 - P(A)$$ ✔
  - _why:_ An event and its complement cover all possible outcomes, so their probabilities total 1. Therefore, $P(A')=1-P(A)$.
- $$$1 + P(A)$$
  - _why:_ Adding produces a value greater than 1 whenever $P(A)>0$, which cannot be a probability. The complement rule is $P(A')=1-P(A)$.
- $$$P(A)$$
  - _why:_ An event and its complement do not generally have equal probabilities; that occurs only when each is 0.5. In general, $P(A')=1-P(A)$.
- $$$\frac{1}{P(A)}$$
  - _why:_ Taking a reciprocal is not the complement rule and often gives a value above 1. Complementary probabilities sum to 1, so $P(A')=1-P(A)$.

## Card 7 — `basic`

**Front:** If $P(A) = 0.64$, what is $P(A')$?

**Back:** $$$1 - 0.64 = 0.36$$

**Choices:**

- $$$1 - 0.64 = 0.36$$ ✔
  - _why:_ Complementary probabilities add to 1, so subtracting $0.64$ from 1 gives $P(A')=0.36$.
- $$$1 - 0.64 = 0.64$$
  - _why:_ This leaves the original probability unchanged instead of carrying out the subtraction. The complement is $1-0.64=0.36$.
- $$$1 - 0.64 = 0.46$$
  - _why:_ This reverses the digits in the correct difference. Subtracting carefully gives $1.00-0.64=0.36$, so $P(A')=0.36$.
- $$$1 + 0.64 = 1.64$$
  - _why:_ This adds the probability instead of subtracting it, producing an impossible probability above 1. The complement is $1-0.64=0.36$.

## Card 8 — `basic`

**Front:** Which region corresponds to the notation $A \cap B'$?

**Back:** The A-only region (in A but not in B).

**Choices:**

- The A-only region (in A but not in B). ✔
  - _why:_ The intersection with $B'$ selects elements that satisfy both conditions: they belong to A and do not belong to B.
- The B-only region (in B but not in A).
  - _why:_ The B-only region is $A' \cap B$, with the complement applied to A. The notation $A \cap B'$ instead describes the A-only region.
- The overlap region (in both A and B).
  - _why:_ The overlap is $A \cap B$. The prime in $B'$ excludes elements in B, so $A \cap B'$ is the A-only region.
- The outside region (in neither A nor B).
  - _why:_ The region in neither set is $A' \cap B'$, or $(A \cup B)'$. The notation $A \cap B'$ requires membership of A.

## Card 9 — `cloze`

**Front:** The region for "neither A nor B" is represented by $A' \cap B'$, which is located [ ___ ].

**Back:** The region for "neither A nor B" is represented by $A' \cap B'$, which is located outside both circles.

**Choices:**

- outside both circles ✔
  - _why:_ By De Morgan’s law, $A' \cap B'$ contains elements not in A and not in B, so the required region lies outside both circles.
- inside both circles
  - _why:_ Inside both circles represents $A \cap B$, where elements belong to both sets. Neither set instead means $A' \cap B'$, which is outside both circles.
- inside circle A only
  - _why:_ The A-only region contains elements in A but not B, represented by $A \cap B'$. Neither A nor B lies outside both circles.
- inside at least one circle
  - _why:_ Inside at least one circle represents the union $A \cup B$. Neither A nor B is the complement of this union, located outside both circles.

## Card 10 — `basic`

**Front:** What is the rule for completing a frequency Venn diagram when the overlap is known?

**Back:** Fill the overlap first, then subtract it from the circle totals to find the "only" regions.

**Choices:**

- Fill the overlap first, then subtract it from the circle totals to find the "only" regions. ✔
  - _why:_ The overlap contributes to both circle totals. Entering it first allows it to be subtracted from each total, leaving the correct counts for the two "only" regions.
- Fill the circle totals first, then add the overlap to find the "only" regions.
  - _why:_ Adding the overlap double-counts elements belonging to both sets. The overlap must be filled first and subtracted from each circle total to obtain the "only" regions.
- Fill the only regions first, then subtract them from the overlap to find the circle totals.
  - _why:_ The "only" regions cannot be determined directly while the known overlap is unused. Fill the overlap first, then subtract it from each circle total.
- Fill the outside region first, then subtract it from the circle totals to find the "only" regions.
  - _why:_ The outside count is not included in either circle total, so subtracting it is inappropriate. Fill the known overlap first and subtract that from the circle totals.

## Card 11 — `basic`

**Front:** How do you find the count of the overlap if given circle totals and the union total?

**Back:** Add the two circle totals together and subtract the total count of the union.

**Choices:**

- Add the two circle totals together and subtract the total count of the union. ✔
  - _why:_ Adding the circle totals counts the overlap twice, while the union counts it once. Subtracting the union total therefore leaves one copy of the overlap.
- Add the two circle totals together and add the total count of the union.
  - _why:_ Adding the union creates extensive double-counting rather than isolating the overlap. Add the circle totals, then subtract the union total to leave the overlap count.
- Subtract the two circle totals from each other and add the total count of the union.
  - _why:_ The difference between circle totals does not isolate shared elements. Inclusion-exclusion gives the overlap by adding both circle totals and subtracting the union total.
- Subtract the total count of the union and subtract the two circle totals together.
  - _why:_ Subtracting all the given counts cannot recover the shared portion and may produce a negative result. Add the circle totals, then subtract the union total.

## Card 12 — `basic`

**Front:** State the order for filling a three-circle Venn diagram from a survey.

**Back:** Centre (all three sets)Pair-only overlapsSingle-only regionsOutside region

**Choices:**

- Centre (all three sets)Pair-only overlapsSingle-only regionsOutside region ✔
  - _why:_ The centre affects every pair and circle total, so it is entered first. Successive subtraction then determines pair-only, single-only, and finally outside regions.
- Single-only regionsPair-only overlapsCentre (all three sets)Outside region
  - _why:_ Starting with single-only regions ignores values that must first be removed from circle totals. Begin with the centre, then pair-only overlaps, single-only regions, and outside.
- Outside regionSingle-only regionsPair-only overlapsCentre (all three sets)
  - _why:_ Working from outside inward prevents the necessary subtractions from known intersections. Fill the centre first, followed by pair-only overlaps, single-only regions, and the outside region.
- Pair-only overlapsCentre (all three sets)Outside regionSingle-only regions
  - _why:_ Pair totals normally include the centre, so entering pair-only values before the centre risks overcounting. The correct progression is centre, pair-only, single-only, then outside.

## Card 13 — `cloze`

**Front:** In a three-circle diagram, a statement like "18 like rugby and football" usually includes those who [ ___ ].

**Back:** In a three-circle diagram, a statement like "18 like rugby and football" usually includes those who also like the third sport.

**Choices:**

- also like the third sport ✔
  - _why:_ An intersection of rugby and football includes everyone who likes both, including people who also like the third sport, unless the wording says "only".
- do not like the third sport
  - _why:_ This incorrectly restricts the count to the rugby-and-football-only region. Without the word "only", the count also includes people who like the third sport.
- like exactly two sports
  - _why:_ "Exactly two" would exclude the central three-way intersection. A statement that people like rugby and football normally includes those who also like the third sport.
- like neither of those sports
  - _why:_ People who like neither rugby nor football cannot belong to their intersection. The statement describes everyone who likes both, including those who also like the third sport.

## Card 14 — `basic`

**Front:** How do you calculate the probability of a region if elements are equally likely?

**Back:** $$$\frac{\text{Number of elements in the region}}{\text{Total elements in the universal set}}$$

**Choices:**

- $$$\frac{\text{Number of elements in the region}}{\text{Total elements in the universal set}}$$ ✔
  - _why:_ For equally likely elements, probability is favourable outcomes divided by all possible outcomes. The region supplies the favourable count and the universal set supplies the total.
- $$$\frac{\text{Total elements in the universal set}}{\text{Number of elements in the region}}$$
  - _why:_ This reverses the probability fraction and can produce a value greater than 1. Divide the number in the region by the total in the universal set.
- $$$\frac{\text{Number of elements outside the region}}{\text{Total elements in the universal set}}$$
  - _why:_ Using the count outside the region calculates the complementary probability. The requested probability uses the number inside the region over the universal-set total.
- $$$\frac{\text{Number of elements in the region}}{\text{Total elements outside the region}}$$
  - _why:_ The denominator must count every equally likely outcome, not merely those outside the region. Use the total number of elements in the universal set.

## Card 15 — `cloze`

**Front:** When shading the union $A \cup B$, you must include the A-only region, the B-only region, and the [ ___ ].

**Back:** When shading the union $A \cup B$, you must include the A-only region, the B-only region, and the overlap.

**Choices:**

- overlap ✔
  - _why:_ A union contains every element in A or B or both. Therefore, its shading includes both single-set regions and the overlap between the circles.
- outside region
  - _why:_ The outside region contains elements in neither set, so it is excluded from $A \cup B$. The union includes the A-only, B-only, and overlap regions.
- A-only region
  - _why:_ The A-only region has already been listed and does not replace the shared section. The remaining part needed to complete the union is the overlap.
- B-only region
  - _why:_ The B-only region has already been included, so naming it again omits elements belonging to both sets. The union must also contain the overlap.

## Card 16 — `basic`

**Front:** Describe the region represented by $A' \cup B$.

**Back:** Everything except the A-only region.

**Choices:**

- Everything except the A-only region. ✔
  - _why:_ $$A'$ includes everything outside A, while B restores the overlap because it belongs to B. Only the part in A but not B remains excluded.
- Everything except the B-only region.
  - _why:_ The B-only region belongs to both $A'$ and B, so it must be included. The only excluded area is the A-only region.
- Everything except the overlap region.
  - _why:_ Although the overlap is not in $A'$, it is in B and therefore belongs to the union. Only the A-only region is excluded.
- Everything except both circle regions.
  - _why:_ This describes the area outside both sets and wrongly excludes most of B. $A' \cup B$ includes all regions except the A-only region.

## Card 17 — `cloze`

**Front:** When placing listed elements into a diagram, every element from the universal set must be placed in [ ___ ] region.

**Back:** When placing listed elements into a diagram, every element from the universal set must be placed in exactly one region.

**Choices:**

- exactly one ✔
  - _why:_ The regions of a Venn diagram are mutually exclusive areas, so each element in the universal set belongs in exactly one region, including any region outside the circles.
- one or more
  - _why:_ Allowing one or more regions would permit the same element to be recorded repeatedly. Each element must be placed in exactly one mutually exclusive region.
- exactly two
  - _why:_ Placing every element in two regions would double-count it and misrepresent its set membership. Each element belongs in exactly one region of the diagram.
- every
  - _why:_ An element should not appear throughout the diagram, because each region represents a particular combination of set memberships. It must be placed in exactly one region.

## Card 18 — `cloze`

**Front:** To find the count for the "neither" region, [ ___ ] the total number of elements inside all circles from the universal set total.

**Back:** To find the count for the "neither" region, subtract the total number of elements inside all circles from the universal set total.

**Choices:**

- subtract ✔
  - _why:_ Everything inside the circles is removed from the universal set total, leaving the number outside all circles. That remaining count represents neither set.
- estimate
  - _why:_ Estimating is unnecessary when the relevant totals are known and may produce an inaccurate count. Subtract the number inside all circles from the universal set total.
- separate
  - _why:_ Separating the two totals does not calculate the number in neither set. Subtract the complete count inside the circles from the universal set total.
- infer
  - _why:_ The neither count cannot be inferred without performing the required arithmetic. Subtract the number inside all circles from the universal set total to find it.

## Card 19 — `basic`

**Front:** What is the common mistake when shading the union $A \cup B$?

**Back:** Shading only the overlap instead of both circles entirely.

**Choices:**

- Shading only the overlap instead of both circles entirely. ✔
  - _why:_ The union contains everything in A, in B, or in both sets. Shading only their overlap confuses the union with the intersection.
- Shading both circles entirely instead of only the overlap.
  - _why:_ Shading both circles entirely is the correct representation of the union, not the mistake. Shading only the overlap is the usual confusion with the intersection.
- Shading everything outside both circles instead of both circles entirely.
  - _why:_ The area outside both circles represents elements in neither set, not the union. The usual union error is shading only the overlap rather than both circles.
- Shading only circle A instead of both circles entirely.
  - _why:_ Shading only circle A omits elements that belong exclusively to B, but it is not the stated intersection confusion. The common error is shading only the overlap.

## Card 20 — `basic`

**Front:** What must you do to every region to check if a Venn diagram is completed correctly?

**Back:** Sum every region (including the outside); it must equal the total number of items in the survey.

**Choices:**

- Sum every region (including the outside); it must equal the total number of items in the survey. ✔
  - _why:_ Every mutually exclusive region, including the area outside the circles, accounts for part of the universal set. Their sum must therefore equal the survey total.
- Sum every region (excluding the outside); it must equal the total number of items in the survey.
  - _why:_ Excluding the outside region omits respondents who belong to neither set. Sum every region, including the outside, and compare the result with the survey total.
- Multiply every region (including the outside); it must equal the total number of items in the survey.
  - _why:_ Region frequencies represent separate groups that must be added, not multiplied. The sum of all regions, including the outside, must equal the survey total.
- Sum only the circles (excluding the outside); it must equal the total number of items in the survey.
  - _why:_ Counting only the circles ignores items belonging to neither set, so it cannot verify the universal total. Every region, including the outside, must be summed.
