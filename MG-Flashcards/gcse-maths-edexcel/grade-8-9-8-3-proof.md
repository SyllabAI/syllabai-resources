# Proof Flashcards

_Lane: `gcse-maths-edexcel` · grade 8 · 1 cards (source: MathsGenie flashcards)_

## Card 1 — `basic`

**Front:** What does a single letter (like $n$) represent in an algebraic proof?

**Back:** A general number (representing every possible case).

**Choices:**

- A general number (representing every possible case). ✔
  - _why:_ The letter $n$ is treated as arbitrary, so reasoning that works for $n$ applies to every number covered by the proof rather than one selected example.
- A fixed unknown number (representing only one hidden value).
  - _why:_ Treating $n$ as one fixed unknown confuses algebraic proof with solving an equation. The letter represents a general number so the argument covers every possible case.
- A chosen example number (representing one possible case).
  - _why:_ Checking one chosen example can illustrate a claim but cannot prove it generally. In an algebraic proof, $n$ represents a general number covering every possible case.
- A positive whole number (representing only counting-number cases).
  - _why:_ A letter is not automatically restricted to positive whole numbers unless the proof states that restriction. Here, $n$ represents a general number and every possible case.
