## Card 1 — `cloze`

**Front:** A function machine changes a [ ___ ] into an [ ___ ].

**Back:** A function machine changes a starting number into an answer.

**Choices:**

- A function machine changes a starting number into an answer. ✔
  - _why:_ The starting number is the value put into the machine, and the answer is the value that comes out after the operations have been applied in order.
- A function machine changes a answer into an starting number.
  - _why:_ This reverses the direction of the machine. A function machine starts with a starting number and uses its operations to produce an answer.
- A function machine changes a calculation into an answer.
  - _why:_ The calculation is the process inside the machine, not the value being changed. The machine changes a starting number into an answer.
- A function machine changes a starting number into an operation.
  - _why:_ An operation is an instruction such as add or multiply, not the result. The starting number is changed into an answer.

## Card 2 — `cloze`

**Front:** The number you put in is the [ ___ ]; the number that comes out is the [ ___ ].

**Back:** The number you put in is the input; the number that comes out is the output.

**Choices:**

- The number you put in is the input; the number that comes out is the output. ✔
  - _why:_ In a function machine, the input is the number entered first, and the output is the number produced after all the operations have been followed.
- The number you put in is the output; the number that comes out is the input.
  - _why:_ This swaps the two terms round. The number put into the machine is the input, and the number that comes out is the output.
- The number you put in is the rule; the number that comes out is the answer.
  - _why:_ The rule is the operation or set of operations, not the number being entered. The entered number is the input, and the result is the output.
- The number you put in is the multiplier; the number that comes out is the product.
  - _why:_ Multiplier and product only describe a multiplication situation, not every function machine. The general terms are input for the number entered and output for the number produced.

## Card 3 — `basic`

**Front:** Why must you follow the arrows in a function machine?

**Back:** A different order can give a different answer.

**Choices:**

- A different order can give a different answer. ✔
  - _why:_ Function machines apply operations in a set order. Changing that order can change the result, so the arrows show the sequence you must follow.
- A different order always gives the same answer.
  - _why:_ This confuses special cases with the general rule. Some operations happen to give the same result, but function-machine steps must be followed because order can change the answer.
- The order of boxes is not important.
  - _why:_ The order is important because each operation acts on the result of the previous one. The arrows must be followed since a different order can give a different answer.
- You should work from the largest number.
  - _why:_ Choosing the largest number is not how function machines are read. You follow the arrows because the sequence of operations affects the answer.

## Card 4 — `basic`

**Front:** Machine: $6$ &rarr; $\times 4$ &rarr; $-2$. What is the output?

**Back:** $22$ ($6 \times 4 = 24$, then $24 - 2 = 22$).

**Choices:**

- $22$ ($6 \times 4 = 24$, then $24 - 2 = 22$). ✔
  - _why:_ The machine first multiplies the input by $4$, giving $24$, and then subtracts $2$. That gives an output of $22$.
- $16$ ($6 - 2 = 4$, then $4 \times 4 = 16$).
  - _why:_ This works through the boxes in the wrong order. The arrows say to multiply first, then subtract, so the correct output is $22$.
- $26$ ($6 \times 4 = 24$, then $24 + 2 = 26$).
  - _why:_ This keeps the first step but uses add instead of subtract for the second box. The machine says $-2$, so the correct output is $22$.
- $8$ ($6 + 4 = 10$, then $10 - 2 = 8$).
  - _why:_ This misreads the multiplication box as addition. The first step is $6 \times 4 = 24$, and then $2$ is subtracted to give $22$.

## Card 5 — `basic`

**Front:** Machine: $5$ &rarr; $+10$ &rarr; missing box &rarr; $4$. What is the missing box?

**Back:** subtract $11$ ($5 + 10 = 15$, and $15 - 11 = 4$).

**Choices:**

- subtract $11$ ($5 + 10 = 15$, and $15 - 11 = 4$). ✔
  - _why:_ After the first box, the number is $15$. To get from $15$ down to $4$, the missing operation must be subtract $11$.
- add $11$ ($5 + 10 = 15$, and $15 + 11 = 26$).
  - _why:_ This finds the size of the difference but uses the wrong operation. Since the value must go from $15$ to $4$, the missing box is subtract $11$.
- subtract $1$ ($5 - 1 = 4$, ignoring the $+10$ box).
  - _why:_ This ignores the first operation in the machine. You must do $5 + 10 = 15$ first, then subtract $11$ to reach $4$.
- subtract $10$ ($5 + 10 = 15$, and $15 - 10 = 5$).
  - _why:_ This undoes the $+10$ box rather than finding the operation from $15$ to $4$. The correct missing operation is subtract $11$.

## Card 6 — `cloze`

**Front:** An inverse operation undoes another operation: [ ___ ] and subtract undo each other; [ ___ ] and divide undo each other.

**Back:** An inverse operation undoes another operation: add and subtract undo each other; multiply and divide undo each other.

**Choices:**

- An inverse operation undoes another operation: add and subtract undo each other; multiply and divide undo each other. ✔
  - _why:_ Addition is undone by subtraction, and multiplication is undone by division. These pairs are inverse operations because one reverses the effect of the other.
- An inverse operation undoes another operation: multiply and subtract undo each other; add and divide undo each other.
  - _why:_ This mixes up the inverse pairs. Subtract undoes add, and divide undoes multiply, so the correct missing terms are add and multiply.
- An inverse operation undoes another operation: add and subtract undo each other; add and divide undo each other.
  - _why:_ The first pair is right, but division does not undo addition. Division undoes multiplication, so the second missing term should be multiply.
- An inverse operation undoes another operation: divide and subtract undo each other; multiply and divide undo each other.
  - _why:_ The second pair is right, but subtraction does not undo division. Subtraction undoes addition, so the first missing term should be add.

## Card 7 — `basic`

**Front:** When working backwards through a function machine, which box is undone first?

**Back:** The last box.

**Choices:**

- The last box. ✔
  - _why:_ Working backwards means applying inverse operations in reverse order. Therefore, the operation applied last to the input is the first one that must be undone.
- The first box.
  - _why:_ Starting with the first box ignores the order in which the output was produced. Work backwards from the output by undoing the last box first.
- The largest-number box.
  - _why:_ The size of the numbers does not determine the order of inverse operations. The last box must be undone first because it produced the final output.
- Any box.
  - _why:_ Operations cannot be undone in an arbitrary order because changing their order usually changes the result. Begin by undoing the last box, then continue backwards.

## Card 8 — `basic`

**Front:** Machine: input &rarr; $\times 6$ &rarr; $+4$ &rarr; $46$. What was the input?

**Back:** $7$ ($46 - 4 = 42$, then $42 \div 6 = 7$).

**Choices:**

- $7$ ($46 - 4 = 42$, then $42 \div 6 = 7$). ✔
  - _why:_ Reverse the operations in reverse order: subtracting $4$ from $46$ gives $42$, and dividing $42$ by $6$ gives the original input, $7$.
- $42$ ($46 - 4 = 42$, but the $\times 6$ step is not undone).
  - _why:_ This stops after undoing only the addition step. The multiplication by $6$ must also be reversed, so $42 \div 6 = 7$ gives the input.
- $252$ ($46 - 4 = 42$, then $42 \times 6 = 252$).
  - _why:_ Multiplying by $6$ repeats the forward operation instead of reversing it. After obtaining $42$, divide by $6$ to find the correct input of $7$.
- $300$ ($46 + 4 = 50$, then $50 \times 6 = 300$).
  - _why:_ Both operations have been continued rather than reversed. Working backwards requires subtracting $4$ and then dividing by $6$, which produces the correct input of $7$.

## Card 9 — `basic`

**Front:** What is the backwards operation for a forwards box $\div 5$?

**Back:** multiply by $5$.

**Choices:**

- multiply by $5$. ✔
  - _why:_ Multiplication by 5 reverses division by 5 because multiplying the divided value by the same number restores the original value.
- divide by $5$.
  - _why:_ Dividing by 5 repeats the forwards operation rather than reversing it. The inverse of dividing by 5 is to multiply by 5.
- add $5$.
  - _why:_ Adding 5 does not undo division because addition and division are not inverse operations. The correct backwards operation is to multiply by 5.
- multiply by $rac{1}{5}$.
  - _why:_ Multiplying by one fifth is equivalent to dividing by 5, so it repeats the forwards operation. To reverse the box, multiply by 5.

## Card 10 — `basic`

**Front:** Machine: $40$ &rarr; $\div 5$ &rarr; $+3$. What is the output?

**Back:** $11$ ($40 \div 5 = 8$, then $8 + 3 = 11$).

**Choices:**

- $11$ ($40 \div 5 = 8$, then $8 + 3 = 11$). ✔
  - _why:_ Apply the boxes from left to right: dividing 40 by 5 gives 8, and adding 3 then gives an output of 11.
- $8.6$ ($40 + 3 = 43$, then $43 \div 5 = 8.6$).
  - _why:_ This results from adding 3 before dividing, which reverses the required order. The boxes act left to right: 40 divided by 5 is 8, then 3 gives 11.
- $5$ ($40 \div 5 = 8$, then $8 - 3 = 5$).
  - _why:_ This subtracts 3 after dividing instead of adding it. The intermediate value is 8, and the stated $+3$ box makes the correct output 11.
- $1.6$ ($40 \div 5 = 8$, then $8 \div 5 = 1.6$).
  - _why:_ This divides by 5 twice, treating the second box as another division. After obtaining 8, the machine requires adding 3, producing 11.

## Card 11 — `basic`

**Back:** $45$ ($12 - 3 = 9$, then $9 \times 5 = 45$).

**Choices:**

- $45$ ($12 - 3 = 9$, then $9 \times 5 = 45$). ✔
  - _why:_ Work backwards using inverse operations in reverse order. Subtracting 3 from 12 gives 9, and multiplying 9 by 5 recovers the input 45.
- $1.8$ ($12 - 3 = 9$, then $9 \div 5 = 1.8$).
  - _why:_ This uses division by 5 while working backwards, repeating the forwards operation. After subtracting 3, the inverse of dividing by 5 is multiplication, giving 45.
- $75$ ($12 + 3 = 15$, then $15 \times 5 = 75$).
  - _why:_ This adds 3 rather than subtracting it when reversing the final box. The correct first backwards step gives 9, which is then multiplied by 5 to give 45.
- $57$ ($12 \times 5 = 60$, then $60 - 3 = 57$).
  - _why:_ This applies the inverse operations in the wrong order. Backwards steps must reverse both the operations and their order: subtract 3 first, then multiply by 5 to obtain 45.

## Card 12 — `cloze`

**Front:** A negative number is [ ___ ] and is written with a [ ___ ].

**Back:** A negative number is less than zero and is written with a minus sign.

**Choices:**

- A negative number is less than zero and is written with a minus sign. ✔
  - _why:_ Negative numbers lie below zero on the number line and use a minus sign before their magnitude, such as $-4$.
- A negative number is greater than zero and is written with a minus sign.
  - _why:_ Numbers greater than zero are positive, even if a minus sign is mentioned. A negative number is less than zero and is written with a minus sign.
- A negative number is less than zero and is written with a plus sign.
  - _why:_ A plus sign denotes a positive value, not a negative one. Negative numbers are less than zero and are written using a minus sign.
- A negative number is equal to zero and is written with a zero sign.
  - _why:_ Zero is neither positive nor negative, and there is no special zero sign for negative values. Negative numbers are less than zero and use a minus sign.

## Card 13 — `basic`

**Front:** Machine: $-2$ &rarr; $\times 4$ &rarr; $+7$. What is the output?

**Back:** $-1$ ($-2 \times 4 = -8$, then $-8 + 7 = -1$).

**Choices:**

- $-1$ ($-2 \times 4 = -8$, then $-8 + 7 = -1$). ✔
  - _why:_ Multiplying $-2$ by 4 gives $-8$ because a negative times a positive is negative. Adding 7 then moves the value to $-1$.
- $15$ ($-2 \times 4 = 8$, then $8 + 7 = 15$).
  - _why:_ This loses the negative sign during multiplication. A negative multiplied by a positive remains negative, so the intermediate value is $-8$ and the final output is $-1$.
- $-15$ ($-2 \times 4 = -8$, then $-8 - 7 = -15$).
  - _why:_ This subtracts 7 rather than following the $+7$ box. Starting from $-8$, adding positive 7 gives $-1$, not $-15$.
- $20$ ($-2 + 7 = 5$, then $5 \times 4 = 20$).
  - _why:_ This adds 7 before multiplying, changing the order of the machine. The boxes must be applied left to right: multiply first, then add, giving $-1$.

## Card 14 — `cloze`

**Front:** Adding a positive number to a negative number moves you [ ___ ].

**Back:** Adding a positive number to a negative number moves you towards zero.

**Choices:**

- towards zero ✔
  - _why:_ Adding a positive value increases a negative number, moving it rightwards on the number line and closer to zero, provided it remains negative.
- away from zero
  - _why:_ Moving away from zero would make a negative number more negative, which happens when a positive number is subtracted. Adding a positive number moves it towards zero.
- to the left
  - _why:_ Adding a positive number increases the value, so it moves right rather than left on the number line. For a negative starting value, this means moving towards zero.
- nowhere at all
  - _why:_ The value cannot remain unchanged when a non-zero positive number is added. It increases and therefore moves towards zero from its negative starting position.

## Card 15 — `basic`

**Front:** Machine: input &rarr; $\times 4$ &rarr; $-9$. Give one input where output equals input.

**Back:** $3$, since $3 \times 4 - 9 = 3$.

**Choices:**

- $3$, since $3 \times 4 - 9 = 3$. ✔
  - _why:_ For the output to equal the input, the number must satisfy $4x-9=x$. Solving $3x=9$ gives $x=3$, which checks correctly.
- $0$, since $0 \times 4 - 9 = -9$.
  - _why:_ Substituting zero gives an output of $-9$, so the input and output are not equal. Solving $4x-9=x$ instead gives the fixed input $3$.
- $-3$, since $-3 \times 4 - 9 = -21$.
  - _why:_ The calculation gives $-21$, which does not equal the input $-3$. Equating input and output gives $4x-9=x$, whose solution is $3$.
- $9$, since $9 \times 4 - 9 = 27$.
  - _why:_ The output 27 is three times the proposed input, so it is not fixed by the machine. Solving $4x-9=x$ shows that the required input is $3$.

## Card 16 — `basic`

**Front:** Temperature rule: Celsius &rarr; $\times 1.8$ &rarr; $+32$. What is $10$°C in °F?

**Back:** 50°F ($10 \times 1.8 = 18$, then $18 + 32 = 50$).

**Choices:**

- 50°F ($10 \times 1.8 = 18$, then $18 + 32 = 50$). ✔
  - _why:_ The rule requires multiplication before addition. Multiplying 10 by 1.8 gives 18, and adding 32 produces a Fahrenheit temperature of 50°F.
- 18°F ($10 \times 1.8 = 18$, then $18 + 0 = 18$).
  - _why:_ This omits the final addition of 32, leaving only the result of the first box. Adding 32 to 18 gives the correct temperature of 50°F.
- 75.6°F ($10 + 32 = 42$, then $42 \times 1.8 = 75.6$).
  - _why:_ This adds 32 before multiplying, so the operations are performed in the wrong order. The machine multiplies 10 by 1.8 first, then adds 32 to give 50°F.
- 52°F ($10 \times 2 = 20$, then $20 + 32 = 52$).
  - _why:_ This uses 2 instead of the specified scale factor 1.8. The correct multiplication gives 18, and adding 32 results in 50°F.

## Card 17 — `basic`

**Front:** Temperature rule: Celsius &rarr; $\times 1.8$ &rarr; $+32$. What is $77$°F in °C?

**Back:** 25°C ($77 - 32 = 45$, then $45 \div 1.8 = 25$).

**Choices:**

- 25°C ($77 - 32 = 45$, then $45 \div 1.8 = 25$). ✔
  - _why:_ To reverse the Fahrenheit function machine, subtract 32 first and then divide by 1.8. This converts 77°F to 25°C.
- 45°C ($77 - 32 = 45$, with no further calculation).
  - _why:_ Subtracting 32 completes only the first inverse operation. The result must also be divided by 1.8, giving the correct temperature of 25°C.
- 81°C ($77 - 32 = 45$, then $45 \times 1.8 = 81$).
  - _why:_ Multiplying by 1.8 repeats the forward conversion instead of reversing it. After subtracting 32, divide by 1.8 to obtain 25°C.
- 10.8°C ($77 \div 1.8 \approx 42.8$, then $42.8 - 32 \approx 10.8$).
  - _why:_ Reversing a function machine requires undoing the operations in reverse order. Subtract 32 before dividing by 1.8, which gives 25°C.

## Card 18 — `cloze`

**Front:** A [ ___ ] is paid before distance is added; [ ___ ] means for each mile travelled.

**Back:** A fixed charge is paid before distance is added; per mile means for each mile travelled.

**Choices:**

- A fixed charge is paid before distance is added; per mile means for each mile travelled. ✔
  - _why:_ A fixed charge does not depend on the journey’s distance and is paid first. A per-mile charge is then applied once for every mile travelled.
- A variable charge is paid before distance is added; per mile means for each mile travelled.
  - _why:_ A variable charge changes with the distance, so it is not the initial amount paid regardless of distance. The correct first term is fixed charge.
- A fixed charge is paid before distance is added; per journey means for each mile travelled.
  - _why:_ Per journey describes one charge for the whole trip, not a charge for each mile. The correct expression for each mile travelled is per mile.
- A mileage charge is paid before distance is added; flat rate means for each mile travelled.
  - _why:_ A mileage charge depends on distance rather than being paid beforehand, while a flat rate is not applied to every mile. The correct terms are fixed charge and per mile.

**Choices:**

- £17 ($7 \times 2 = 14$, then add £3). ✔
  - _why:_ Seven miles at £2 per mile costs £14. Adding the fixed £3 charge gives a total fare of £17.

  - _why:_ Multiplying the distance by the per-mile rate gives only the mileage charge. The fixed £3 must also be added, making the total £17.
- £20 ($7 + 3 = 10$, then $10 \times 2 = 20$).
  - _why:_ The fixed charge must not be included in the distance before multiplication. Calculate 7 times £2 first, then add £3 to obtain £17.
- £23 ($7 \times 3 = 21$, then add £2).
  - _why:_ This swaps the fixed charge and the per-mile rate. The seven miles cost £14 at £2 each, and adding £3 gives £17.

## Card 20 — `basic`

**Front:** A taxi costs £3 plus £2 per mile. If the fare is £19, what was the distance?

**Back:** 8 miles (subtract £3, then $16 \div 2 = 8$).

**Choices:**

- 8 miles (subtract £3, then $16 \div 2 = 8$). ✔
  - _why:_ Remove the fixed £3 charge from £19, leaving £16 for distance. At £2 per mile, dividing £16 by £2 gives 8 miles.
- 16 miles (subtract £3, but do not divide by £2 per mile).
  - _why:_ The £16 remaining after subtracting the fixed charge is a cost, not a distance. Divide it by £2 per mile to get 8 miles.
- 9.5 miles (divide £19 by £2, but do not subtract £3).
  - _why:_ Dividing the entire fare by the per-mile rate ignores the fixed £3 charge. Subtract that charge first, then divide £16 by £2 to get 8 miles.
- 14 miles (subtract £3, then subtract £2 instead of dividing).
  - _why:_ After removing the fixed charge, division is needed because £2 is charged for each mile. Subtracting £2 instead confuses a rate with a fixed amount; the answer is 8 miles.
