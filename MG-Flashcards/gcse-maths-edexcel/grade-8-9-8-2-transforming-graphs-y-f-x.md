# Transforming Graphs y=f(x) Flashcards

_Lane: `gcse-maths-edexcel` · grade 8 · 1 cards (source: MathsGenie flashcards)_

## Card 1 — `basic`

**Front:** If the function notation $f(-2)=5$ is given, what are the coordinates of the point on the original graph?

**Back:** $$(-2, 5)$

**Choices:**

- $$(-2, 5)$ ✔
  - _why:_ The notation $f(-2)=5$ means that when the input is $x=-2$, the output is $y=5$. Therefore, the point is $(-2, 5)$.
- $$(5, -2)$
  - _why:_ This reverses the input and output coordinates. In $f(-2)=5$, the input gives $x=-2$ and the output gives $y=5$, so the point is $(-2, 5)$.
- $$(2, 5)$
  - _why:_ This incorrectly changes the sign of the input. The input is exactly $-2$ and the output is $5$, so the point on the graph is $(-2, 5)$.
- $$(-2, -5)$
  - _why:_ This incorrectly changes the sign of the output. Since $f(-2)=5$, the graph has output $y=5$ when $x=-2$, giving the point $(-2, 5)$.
