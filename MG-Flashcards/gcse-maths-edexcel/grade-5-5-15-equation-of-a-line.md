# Equation of a Line Flashcards

_Lane: `gcse-maths-edexcel` · grade 5 · 3 cards (source: MathsGenie flashcards)_

## Card 1 — `basic`

**Front:** What does the first value in a coordinate pair $(x, y)$ represent?

**Back:** Horizontal position (the x-coordinate).

**Choices:**

- Horizontal position (the x-coordinate). ✔
  - _why:_ Coordinates are written in the order $(x, y)$, so the first value gives the horizontal position measured along the x-axis.
- Vertical position (the y-coordinate).
  - _why:_ The vertical position is given by the second value, called the y-coordinate. The first value is the horizontal position, or x-coordinate.
- Distance from the origin (the radial coordinate).
  - _why:_ Distance from the origin must be calculated using both coordinates. The first value alone represents horizontal position and is called the x-coordinate.
- Quadrant position (the region coordinate).
  - _why:_ The quadrant depends on the signs of both coordinates, not just the first value. The first value represents horizontal position and is the x-coordinate.

## Card 2 — `basic`

**Front:** At what $x$-value does a line cross the y-axis?

**Back:** $$x = 0$

**Choices:**

- $$x = 0$ ✔
  - _why:_ Every point on the y-axis has an x-coordinate of zero, regardless of its y-coordinate. Therefore, a line crosses the y-axis where $x = 0$.
- $$y = 0$
  - _why:_ The condition $y = 0$ describes the x-axis, so it locates an x-intercept rather than a y-intercept. On the y-axis, $x = 0$.
- $$x = 1$
  - _why:_ Using 1 confuses the y-axis with a vertical line shifted one unit to the right. The y-axis itself consists of points where $x = 0$.
- $$x = -1$
  - _why:_ Using -1 describes a vertical line one unit to the left of the y-axis. A point lies on the y-axis only when $x = 0$.

## Card 3 — `basic`

**Front:** What is the formula for calculating gradient ($m$)?

**Back:** $$m = \frac{\text{change in } y}{\text{change in } x}$

**Choices:**

- $$m = \frac{\text{change in } y}{\text{change in } x}$ ✔
  - _why:_ Gradient measures vertical change per unit of horizontal change, often called rise over run. Therefore, change in $y$ is divided by change in $x$.
- $$m = \frac{\text{change in } x}{\text{change in } y}$
  - _why:_ This reverses rise over run and calculates the reciprocal of the gradient. Gradient is change in $y$ divided by change in $x$.
- $$m = \frac{\text{change in } x + \text{change in } y}{2}$
  - _why:_ Averaging the horizontal and vertical changes does not measure a line’s steepness. Gradient is the ratio of change in $y$ to change in $x$.
- $$m = \frac{\text{change in } y}{\text{change in } x} + c$
  - _why:_ Adding $c$ confuses the gradient formula with the line equation $y = mx + c$. Gradient alone is change in $y$ divided by change in $x$.
