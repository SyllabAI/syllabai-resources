## Card 1 — `cloze`

**Front:** A function is a rule that takes an input and gives exactly [ ___ ] output.

**Back:** A function is a rule that takes an input and gives exactly one output.

**Choices:**

- one ✔
  - _why:_ A function assigns exactly one output to each permitted input. Different inputs may share an output, but a single input cannot have multiple outputs.
- the same
  - _why:_ A function does not have to give the same output for every input. It must give exactly one output for each individual input.
- a random
  - _why:_ Functions are deterministic rules rather than random processes. Each permitted input must be assigned exactly one specific output, so the correct term is one.
- an unpredictable
  - _why:_ An output cannot be left unpredictable while still defining a function. The rule must associate every permitted input with exactly one determined output.

## Card 2 — `basic`

**Front:** How do you evaluate $h(4)$ for the function $h(x) = 2x^2 - 6$?

**Back:** Substitute 4 for $x$ in the formula: $2(4)^2 - 6$.

**Choices:**

- Substitute 4 for $x$ in the formula: $2(4)^2 - 6$. ✔
  - _why:_ Evaluating $h(4)$ means replacing every $x$ in $h(x)=2x^2-6$ with 4, giving $2(4)^2-6$ before calculating the result.
- Substitute $-4$ for $x$ in the formula: $2(-4)^2 - 6$.
  - _why:_ This substitutes $-4$, so it evaluates $h(-4)$ rather than $h(4)$. The required substitution is $2(4)^2-6$.
- Substitute 4 for $x$ in the formula: $(2 \times 4)^2 - 6$.
  - _why:_ This incorrectly squares the product $2\times4$ instead of squaring only the input. The coefficient remains outside the square, giving $2(4)^2-6$.
- Substitute 2 for $x$ in the formula: $2(2)^2 - 6$.
  - _why:_ This substitutes the coefficient 2 instead of the requested input 4. To evaluate $h(4)$, replace $x$ with 4 to obtain $2(4)^2-6$.

## Card 3 — `cloze`

**Front:** When substituting negative numbers into a function, always use [ ___ ] to avoid calculation errors.

**Back:** When substituting negative numbers into a function, always use brackets to avoid calculation errors.

**Choices:**

- brackets ✔
  - _why:_ Brackets keep the negative sign attached to the substituted value. For example, $(-3)^2=9$, whereas writing $-3^2$ is interpreted as $-(3^2)=-9$.
- a calculator
  - _why:_ A calculator does not prevent an incorrectly entered negative substitution. Brackets are needed to keep the negative sign attached to the complete substituted value.
- fractions
  - _why:_ Converting a negative number to a fraction does not resolve sign or order-of-operations errors. Brackets correctly show that the entire negative value is being substituted.
- decimals
  - _why:_ Decimal notation does not keep a negative sign attached during powers or multiplication. Brackets must surround the substituted negative number to preserve the intended calculation.

## Card 4 — `basic`

**Front:** What does the instruction "solve $f(x) = 10$" mean?

**Back:** Find the input values that result in an output of 10.

**Choices:**

- Find the input values that result in an output of 10. ✔
  - _why:_ Solving $f(x)=10$ means identifying every input $x$ that the function maps to 10. Depending on the function, there may be one, several, or no such inputs.
- Find the output values that result from an input of 10.
  - _why:_ This reverses the roles of input and output. The output is already specified as 10, so the task is to find the corresponding input values.
- Find the output value that results from an input of 10.
  - _why:_ Setting the input to 10 would evaluate $f(10)$, not solve $f(x)=10$. Solving requires finding inputs whose output is equal to 10.
- Find the input values that result in an output greater than 10.
  - _why:_ The equation asks for inputs producing exactly 10, not outputs greater than 10. The required values satisfy the equality $f(x)=10$.

## Card 5 — `basic`

**Front:** If $x^2 = 9$, why are there two possible solutions for $x$?

**Back:** Both positive and negative values give a positive result when squared ($3^2 = 9$ and $(-3)^2 = 9$).

**Choices:**

- Both positive and negative values give a positive result when squared ($3^2 = 9$ and $(-3)^2 = 9$). ✔
  - _why:_ Squaring removes the distinction between opposite signs because the product of two negative numbers is positive. Therefore both $3$ and $-3$ satisfy $x^2=9$.
- Only the positive value gives a positive result when squared ($3^2 = 9$, so $x = 3$ is the only solution).
  - _why:_ This keeps only the principal square root and overlooks the second solution. Since $(-3)^2$ also equals 9, both $x=3$ and $x=-3$ work.
- The positive value gives 9 and the negative value gives $-9$ when squared ($3^2 = 9$ and $(-3)^2 = -9$).
  - _why:_ Squaring a negative number produces a positive result because two negative factors multiply to give a positive product. Thus $(-3)^2=9$, not $-9$.
- The positive and negative values cancel when squared, so the only possible solution is $x = 0$.
  - _why:_ Opposite values do not cancel when each is squared separately. Both $3^2$ and $(-3)^2$ equal 9, giving the two solutions $x=3$ and $x=-3$.

## Card 6 — `basic`

**Front:** What is the relationship between the outputs of $f(x)$ and $f^{-1}(x)$?

**Back:** The inverse function $f^{-1}$ undoes the function $f$ (if $f(a) = b$, then $f^{-1}(b) = a$).

**Choices:**

- The inverse function $f^{-1}$ undoes the function $f$ (if $f(a) = b$, then $f^{-1}(b) = a$). ✔
  - _why:_ An inverse reverses the original mapping: if $f$ sends $a$ to $b$, then $f^{-1}$ sends $b$ back to $a$. Their inputs and outputs exchange roles.
- The inverse function $f^{-1}$ reciprocates the function $f$ (if $f(a) = b$, then $f^{-1}(a) = \frac{1}{b}$).
  - _why:_ The superscript $-1$ denotes an inverse function, not a reciprocal. If $f(a)=b$, the inverse maps $b$ back to $a$ rather than calculating $1/b$.
- The inverse function $f^{-1}$ repeats the function $f$ (if $f(a) = b$, then $f^{-1}(a) = b$).
  - _why:_ Repeating the same mapping describes applying $f$ again, not applying its inverse. The inverse must reverse the mapping, so $f^{-1}(b)=a$.
- The inverse function $f^{-1}$ negates the function $f$ (if $f(a) = b$, then $f^{-1}(a) = -b$).
  - _why:_ An inverse does not generally change an output’s sign. It reverses the input-output mapping, meaning that $f(a)=b$ leads to $f^{-1}(b)=a$.

## Card 7 — `basic`

**Front:** Outline the three steps to find an inverse function $f^{-1}(x)$.

**Back:** Set $y = f(x)$Swap $x$ and $y$Rearrange the equation to make $y$ the subject

**Choices:**

- Set $y = f(x)$Swap $x$ and $y$Rearrange the equation to make $y$ the subject ✔
  - _why:_ Writing the function as $y$, exchanging input and output variables, and then solving for $y$ reverses the original mapping and produces the inverse function.
- Set $y = f(x)$Keep $x$ and $y$ unchangedRearrange the equation to make $y$ the subject
  - _why:_ Leaving $x$ and $y$ unchanged does not reverse the input-output relationship, so it merely rearranges the original function. They must be swapped before solving for $y$.
- Set $y = f(x)$Swap $x$ and $y$Rearrange the equation to make $x$ the subject
  - _why:_ After swapping $x$ and $y$, solving for $x$ moves back towards the original function. To express the inverse in function form, rearrange to make $y$ the subject.
- Set $y = f(x)$Negate $x$ and $y$Rearrange the equation to make $y$ the subject
  - _why:_ Negating both variables reflects signs rather than reversing the input-output mapping. The correct process swaps $x$ and $y$, then rearranges to make $y$ the subject.

## Card 8 — `cloze`

**Front:** The notation $f^{-1}(x)$ refers to the [ ___ ], not the reciprocal ($\frac{1}{f(x)}$).

**Back:** The notation $f^{-1}(x)$ refers to the inverse function, not the reciprocal ($\frac{1}{f(x)}$).

**Choices:**

- inverse function ✔
  - _why:_ The superscript $-1$ indicates the function that reverses the mapping performed by $f$. It does not mean taking the reciprocal of the function’s output.
- reciprocal function
  - _why:_ Treating the exponent as an ordinary negative power causes this misconception. The reciprocal is written $\frac{1}{f(x)}$, while $f^{-1}(x)$ denotes the inverse function.
- negative function
  - _why:_ A negative function would be written $-f(x)$ and changes the signs of outputs. The notation $f^{-1}(x)$ instead represents the inverse function.
- derivative function
  - _why:_ A derivative represents the rate of change and is usually written $f'(x)$. The notation $f^{-1}(x)$ refers specifically to the inverse function.

**Back:** The notation $f^{-1}(x)$ refers to the inverse function, not the reciprocal ($\frac{1}{f(x)}$).

## Card 10 — `basic`

**Front:** What is the inverse of $r(x) = 4x - 3$?

**Back:** $$r^{-1}(x) = \frac{x+3}{4}$

**Choices:**

- $$r^{-1}(x) = \frac{x+3}{4}$ ✔
  - _why:_ Writing $y=4x-3$, swapping $x$ and $y$, and rearranging gives $x=4y-3$, so $y=\frac{x+3}{4}$.
- $$r^{-1}(x) = \frac{x-3}{4}$
  - _why:_ This keeps the subtraction rather than reversing it. After swapping variables, adding $3$ to both sides gives $x+3=4y$, so the numerator is $x+3$.
- $$r^{-1}(x) = 4x+3$
  - _why:_ This reverses the subtraction but not the multiplication. Both operations must be undone in reverse order, giving $r^{-1}(x)=\frac{x+3}{4}$.
- $$r^{-1}(x) = \frac{x+4}{3}$
  - _why:_ This mistakenly swaps the constants rather than reversing the operations. Add $3$ and then divide by $4$, giving $r^{-1}(x)=\frac{x+3}{4}$.

## Card 11 — `basic`

**Front:** In the composite function $gf(x)$, which function is applied to $x$ first?

**Back:** Function $f$ (the function nearest to $x$).

**Choices:**

- Function $f$ (the function nearest to $x$). ✔
  - _why:_ The notation $gf(x)$ means $g(f(x))$, so $x$ is first input into $f$. The resulting output is then used as the input to $g$.
- Function $g$ (the function furthest from $x$).
  - _why:_ Reading the letters from left to right causes this mistake. Since $gf(x)=g(f(x))$, function $f$, which is nearest to $x$, is applied first.
- Function $g$ (the function nearest to $x$).
  - _why:_ Although $g$ appears first when reading normally, it is not nearest to the input. The notation expands to $g(f(x))$, so $f$ acts first.
- Function $f$ (the function furthest from $x$).
  - _why:_ This identifies the correct letter but gives the wrong positional rule. In $gf(x)$, $f$ is nearest to $x$, which is why it is applied first.

## Card 12 — `cloze`

**Front:** Composite functions like $gf(x)$ are read from [ ___ ].

**Back:** Composite functions like $gf(x)$ are read from right to left.

**Choices:**

- right to left ✔
  - _why:_ The notation $gf(x)$ represents $g(f(x))$. Therefore, the right-hand function $f$ is applied first, followed by the left-hand function $g$.
- left to right
  - _why:_ Ordinary reading order is tempting, but it reverses the composition. Since $gf(x)=g(f(x))$, the right-hand function $f$ must be applied before $g$.
- outside to inside
  - _why:_ Applying the outside function first reverses the required order. In $g(f(x))$, the inside function $f$ acts on $x$ before the outside function $g$.
- either way round
  - _why:_ Function composition is generally order-dependent, so the direction cannot be chosen freely. The notation $gf(x)$ must be read from right to left as $g(f(x))$.

## Card 13 — `basic`

**Front:** Why is $fg(x)$ not the same as $f(x) \times g(x)$?

**Back:** Composite notation indicates a chain of operations, not multiplication of the two formulas.

**Choices:**

- Composite notation indicates a chain of operations, not multiplication of the two formulas. ✔
  - _why:_ The notation $fg(x)$ means $f(g(x))$: the output of $g$ becomes the input of $f$. It does not mean the product $f(x)g(x)$.
- Composite notation indicates a sum of operations, not multiplication of the two formulas.
  - _why:_ Composition does not add the functions; that would be written $f(x)+g(x)$. Instead, $fg(x)$ means substituting $g(x)$ into $f$, forming a chain of operations.
- Composite notation indicates a difference of operations, not multiplication of the two formulas.
  - _why:_ Composition is not subtraction, which would be written $f(x)-g(x)$. The notation $fg(x)$ means $f(g(x))$, where one function acts on the other’s output.
- Composite notation indicates a division of operations, not multiplication of the two formulas.
  - _why:_ Composition does not divide the function formulas; a quotient would require a fraction. Instead, $fg(x)=f(g(x))$, so the functions are applied one after the other.

## Card 14 — `basic`

**Front:** Given $f(x) = 2x + 1$ and $g(x) = x^2$, calculate $fg(x)$.

**Back:** $$2x^2 + 1$

**Choices:**

- $$2x^2 + 1$ ✔
  - _why:_ The composition $fg(x)$ means $f(g(x))$. Substituting $g(x)=x^2$ into $f(x)=2x+1$ gives $f(x^2)=2x^2+1$.
- $$(2x + 1)^2$
  - _why:_ This calculates $g(f(x))$, so the functions have been applied in the reverse order. For $fg(x)=f(g(x))$, the result is $2x^2+1$.
- $$4x^2 + 1$
  - _why:_ This incorrectly squares the coefficient $2$ when substituting $x^2$ into $f$. Only $x$ is replaced, so $2(x^2)+1=2x^2+1$.
- $$2x^2 + 2$
  - _why:_ This mistakenly changes the constant term when substituting into the function. The $+1$ remains unchanged, so $f(x^2)=2x^2+1$.

## Card 15 — `basic`

**Front:** Given $f(x) = 2x + 1$ and $g(x) = x^2$, calculate $gf(x)$.

**Back:** $$(2x + 1)^2$

**Choices:**

- $$(2x + 1)^2$ ✔
  - _why:_ The composition $gf(x)$ means $g(f(x))$. Since $g$ squares its input, substituting $f(x)=2x+1$ gives $g(2x+1)=(2x+1)^2$.
- $$2x^2 + 1$
  - _why:_ This calculates $f(g(x))$, applying the functions in the reverse order. For $gf(x)=g(f(x))$, the whole expression $2x+1$ must be squared.
- $$4x^2 + 1$
  - _why:_ This squares the two terms separately and omits the middle term. The unexpanded answer is $(2x+1)^2$, which expands to $4x^2+4x+1$.
- $$4x^2 + 2x + 1$
  - _why:_ This underestimates the cross term when expanding the square. Since $2(2x)(1)=4x$, $(2x+1)^2$ expands to $4x^2+4x+1$.

## Card 16 — `cloze`

**Front:** When finding $f(x-3)$, you must substitute the [ ___ ] $(x-3)$ wherever $x$ appears in the original function.

**Back:** When finding $f(x-3)$, you must substitute the entire expression $(x-3)$ wherever $x$ appears in the original function.

**Choices:**

- entire expression ✔
  - _why:_ The input to the function is now $x-3$, so every occurrence of the original input $x$ must be replaced by the bracketed expression $(x-3)$.
- variable only
  - _why:_ Substituting only the variable can lose the subtraction or apply it to just one occurrence. The whole input $(x-3)$ must replace every $x$ in the function.
- constant term
  - _why:_ The constant term in the original formula is not the new input. To find $f(x-3)$, replace each occurrence of $x$ with the entire expression $(x-3)$.
- final term
  - _why:_ Changing only the final term confuses substitution with altering part of the formula. The entire expression $(x-3)$ must replace every occurrence of the original variable $x$.

## Card 17 — `basic`

**Front:** How do you solve $(x - 3)^2 = 9$ without expanding the brackets?

**Back:** Square root both sides to get $x - 3 = 3$ and $x - 3 = -3$, then solve for $x$.

**Choices:**

- Square root both sides to get $x - 3 = 3$ and $x - 3 = -3$, then solve for $x$. ✔
  - _why:_ A square equal to $9$ can have a base of either $3$ or $-3$. Solving both resulting equations gives the two solutions $x = 6$ and $x = 0$.
- Square root both sides to get $x - 3 = 3$ only, then solve for $x$.
  - _why:_ Taking only the positive square root misses one solution. Since both $3^2$ and $(-3)^2$ equal $9$, you must solve $x - 3 = 3$ and $x - 3 = -3$.
- Square root both sides to get $x - 3 = 9$ and $x - 3 = -9$, then solve for $x$.
  - _why:_ This treats the square root of $9$ as $9$. The square root is $3$, so the required equations are $x - 3 = 3$ and $x - 3 = -3$.
- Square root both sides to get $x + 3 = 3$ and $x + 3 = -3$, then solve for $x$.
  - _why:_ Taking square roots does not change $x - 3$ into $x + 3$. The bracketed expression remains $x - 3$, which must equal either $3$ or $-3$.

## Card 19 — `cloze`

**Front:** In the absence of a restricted domain, the inverse of a quadratic like $f(x) = x^2 - 9$ is often given as the [ ___ ] square root.

**Back:** In the absence of a restricted domain, the inverse of a quadratic like $f(x) = x^2 - 9$ is often given as the non-negative square root.

**Choices:**

- non-negative ✔
  - _why:_ The principal square root is defined to produce values greater than or equal to zero. Therefore, the inverse branch of the quadratic is taken as the non-negative square root.
- positive
  - _why:_ The principal square root can equal zero, so describing it as positive is too restrictive. The inverse uses the non-negative square root, allowing outputs greater than or equal to zero.
- negative
  - _why:_ The negative square-root branch would produce values less than or equal to zero. By convention, the inverse is usually given using the principal, non-negative square root.
- non-positive
  - _why:_ Non-positive includes zero and negative values, which describes the lower square-root branch. The usual principal square root is non-negative, giving values greater than or equal to zero.

## Card 20 — `basic`

**Front:** What does the statement $f(x) = g(x)$ require you to do algebraically?

**Back:** Set the formula for function $f$ equal to the formula for function $g$ and solve for $x$.

**Choices:**

- Set the formula for function $f$ equal to the formula for function $g$ and solve for $x$. ✔
  - _why:_ The equation states that both functions have the same output for particular input values. Equating their algebraic formulas and solving identifies every value of $x$ where their graphs intersect.
- Substitute the formula for function $g$ into the formula for function $f$ and solve for $x$.
  - _why:_ Substituting one function into another forms the composite function $f(g(x))$ rather than solving $f(x)=g(x)$. The two original formulas must instead be set equal.
- Set the formula for function $f$ equal to the negative formula for function $g$ and solve for $x$.
  - _why:_ Introducing a negative sign changes the equation to $f(x)=-g(x)$, which represents different output values. For $f(x)=g(x)$, equate the two formulas directly and solve for $x$.
- Set the inverse formula for function $f$ equal to the formula for function $g$ and solve for $x$.
  - _why:_ Using the inverse of $f$ changes the equation and is not required here. Replace $f(x)$ and $g(x)$ with their original formulas, set them equal, and solve for $x$.

## Card 21 — `basic`

**Front:** If $f(x) = x^2 + 2$, what is the expression for $f(x-3)$?

**Back:** $$(x-3)^2 + 2$

**Choices:**

- $$(x-3)^2 + 2$ ✔
  - _why:_ Replacing the input $x$ with $x-3$ means substituting $x-3$ everywhere $x$ appears in the function. Therefore, the squared term becomes $(x-3)^2$ while the constant remains $2$.
- $$x^2 - 3 + 2$
  - _why:_ This subtracts $3$ after squaring rather than replacing the function’s input. Substituting $x-3$ for $x$ makes the entire input squared, giving $(x-3)^2+2$.
- $$(x+3)^2 + 2$
  - _why:_ This reverses the sign of the substituted input. The expression requested is $f(x-3)$, so $x$ must be replaced by $x-3$, giving $(x-3)^2+2$.
- $$(x-3)^2 - 2$
  - _why:_ Substituting $x-3$ changes only occurrences of the input variable, not the separate constant term. The $+2$ remains unchanged, so the expression is $(x-3)^2+2$.
