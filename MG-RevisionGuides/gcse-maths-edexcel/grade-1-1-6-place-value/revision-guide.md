# Place Value

Learn how digit positions change values, compare decimals, and build numbers carefully from cards or written clues.

In the number 10 we have one lot of ten and zero ones.

![placevalue1](../assets/001-placevalue1.jpg)

In the number 23 we have 2 lots of ten and 3 ones. 20 + 3 = 23

![placevalue2](../assets/002-placevalue2.jpg)

In the number 59 we have 5 lots of ten and 9 ones. 50 + 9 = 59

![placevalue3](../assets/003-placevalue3.jpg)

In the number 136 we have 1 lot of 100, 3 tens and 6 ones. 100 + 30 + 6 = 136

![placevalue4](../assets/004-placevalue4.jpg)

For bigger numbers we use more and more columns. Each column is ten times bigger than the column to its right.

**Example 1: Write down the value of the 4 in the number 9487.**

9487 = 9000 + 400 + 80 + 7  
The 4 is worth 400.


**Example 2: Write down the value of the 8 in the number 180950.**

180950 = 100000 + 80000 + 900 + 50  
The 8 is worth 80000.


**Practice questions**

1. Which number is $4.7$ million written in figures?

   - $4{,}700{,}000$ ✔

   - $47{,}000{,}000$

   - $4{,}070{,}000$

   - $470{,}000$

   _Explanation:_ $4.7$ million means $4$ million plus $0.7$ million, so it is $4{,}000{,}000+700{,}000=4{,}700{,}000$.

2. In the number $5086$, what is the value of the digit $8$?

   - $8$

   - $800$

   - $80$ ✔

   - $8000$

   _Explanation:_ The $8$ is in the tens column, so its value is $8\times 10=80$.

3. Which is the correct expanded form of $306040$?

   - $300000+600+40$

   - $300000+6000+40$ ✔

   - $30000+6000+40$

   - $300000+6000+4$

   _Explanation:_ The $3$ represents $300000$, the $6$ represents $6000$, and the $4$ represents $40$, giving $300000+6000+40$.
