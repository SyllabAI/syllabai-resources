# Inverse and Composite Functions

Learn how functions work forwards, backwards, and in chains so you can evaluate, rearrange, and solve confidently.

**Practice questions**

1. Let $h(x)=3x^2-5$. What is $h(-2)$?

   - $7$ ✔

   - $-17$

   - $17$

   - $-7$

   _Explanation:_ Substitute using brackets: $h(-2)=3(-2)^2-5=3(4)-5=7$. Squaring $-2$ gives $4$, not $-4$.

2. Let $p(x)=2x^2+1$. Solve $p(x)=19$.

   - $x=3$

   - $x=-3$

   - $x=\pm3$ ✔

   - $x=\pm9$

   _Explanation:_ Solve $2x^2+1=19$, giving $2x^2=18$ and $x^2=9$. Therefore $x=3$ or $x=-3$, so $x=\pm3$.

3. Let $f(x)=x-4$ and $g(x)=3x$. What is $gf(5)$?

   - $11$

   - $3$ ✔

   - $15$

   - $1$

   _Explanation:_ The notation $gf(5)$ means $g(f(5))$. First, $f(5)=5-4=1$; then $g(1)=3(1)=3$.

4. Let $f(x)=5x+2$. What is $f^{-1}(x)$?

   - $5x-2$

   - $\frac{1}{5x+2}$

   - $\frac{x+2}{5}$

   - $\frac{x-2}{5}$ ✔

   _Explanation:_ Starting with $y=5x+2$, subtract $2$ and divide by $5$ to reverse the function. Hence $f^{-1}(x)=\frac{x-2}{5}$; an inverse function is not the reciprocal.

5. Let $a(x)=2x-5$ and $b(x)=kx+1$. Given that $ab(3)=15$, what is $k$?

   - $3$ ✔

   - $14$

   - $\frac{10}{3}$

   - $\frac{14}{3}$

   _Explanation:_ Do $b$ first: $b(3)=3k+1$. Then $a(b(3))=2(3k+1)-5=6k-3$. Solving $6k-3=15$ gives $6k=18$, so $k=3$.
