# Inequalities on Graphs

**Practice questions**

1. A graph has a solid vertical boundary line at $x=3$, with the region to the right shaded. Which inequality does it represent?

   - $x<3$

   - $x\leq 3$

   - $x\geq 3$ ✔

   - $x>3$

   _Explanation:_ Points to the right have $x$-coordinates greater than $3$. The solid line means points where $x=3$ are included, so the inequality is $x\geq 3$.

2. A graph has a dashed horizontal boundary line at $y=-2$, with the region below the line shaded. Which inequality does it represent?

   - $y<-2$ ✔

   - $y\leq -2$

   - $y>-2$

   - $y\geq -2$

   _Explanation:_ Points below the line have $y$-coordinates less than $-2$. The dashed line means the boundary is not included, so $y<-2$.

3. Which point lies in the region represented by $y>2x+1$?

   - $(0,1)$

   - $(-1,-2)$

   - $(2,5)$

   - $(1,4)$ ✔

   _Explanation:_ For $(1,4)$, substituting gives $4>2(1)+1$, so $4>3$, which is true. The points $(0,1)$ and $(2,5)$ lie on the boundary and are not included because the inequality is strict.

4. The solid line $y=3x-2$ is drawn, and the side containing the origin is shaded. Which inequality represents the shaded region?

   - $y<3x-2$

   - $y\geq 3x-2$ ✔

   - $y>3x-2$

   - $y\leq 3x-2$

   _Explanation:_ Test the origin $(0,0)$: $0\geq 3(0)-2$ gives $0\geq -2$, which is true. The line is solid, so equality is included and the inequality is $y\geq 3x-2$.

5. Which point satisfies both $x+y\leq 6$ and $y>x$?

   - $(3,3)$

   - $(4,3)$

   - $(2,3)$ ✔

   - $(1,6)$

   _Explanation:_ For $(2,3)$, $2+3=5\leq 6$ and $3>2$, so both inequalities are satisfied. Each other point fails at least one of the inequalities.
