# Proof

Learn how to turn patterns into algebra that proves a result is true for every possible case.

**Practice questions**

1. For integer $n$, simplify $(3n+2)^2-(3n-2)^2$. Which result proves that the expression is divisible by $12$?

   - $18n^2+8$

   - $12n$

   - $24n$ ✔

   - $9n^2+4$

   _Explanation:_ Expanding gives $(9n^2+12n+4)-(9n^2-12n+4)=24n$. Since $24n=12(2n)$ and $2n$ is an integer, the expression is divisible by $12$.

2. Which list represents three consecutive odd integers for every integer $n$?

   - $2n+1,\ 2n+3,\ 2n+5$ ✔

   - $n,\ n+2,\ n+4$

   - $2n,\ 2n+2,\ 2n+4$

   - $2n+1,\ 2n+2,\ 2n+3$

   _Explanation:_ Every number of the form $2n+1$ is odd. Consecutive odd integers differ by $2$, giving $2n+1$, $2n+3$ and $2n+5$.

3. For integer $n$, which factorised form proves that the sum of three consecutive even integers, $2n+(2n+2)+(2n+4)$, is divisible by $6$?

   - $2(3n+1)$

   - $6(n+2)$

   - $6n+4$

   - $6(n+1)$ ✔

   _Explanation:_ The sum is $6n+6=6(n+1)$. Since $n+1$ is an integer, this is always a multiple of $6$.

4. Which form proves that $(n+7)(n+6)+(n+7)$ is a square number for every integer $n$?

   - $(n+6)^2$

   - $(n+7)^2$ ✔

   - $(n+13)^2$

   - $(n+7)(n+6)$

   _Explanation:_ Factor out $n+7$: $(n+7)((n+6)+1)=(n+7)(n+7)=(n+7)^2$, which is a square number.

5. The expression $(2n+3)^2+(2n+5)^2$ simplifies to $8n^2+32n+34$. Which rewrite proves that it is always $2$ more than a multiple of $8$?

   - $8(n^2+4n)+2$

   - $8(n^2+4n+4)+4$

   - $8(n^2+4n+4)+2$ ✔

   - $8(n^2+2n+4)+2$

   _Explanation:_ Write $34$ as $32+2$: $8n^2+32n+34=8(n^2+4n+4)+2$. The bracket is an integer, so the expression is $2$ more than a multiple of $8$.
