# Algebraic Fractions

Learn how to simplify, divide, and solve fractions where the top or bottom contains algebra.

**Practice questions**

1. Simplify fully $\frac{x^2+5x}{x^2+7x+10}$.

   - $\frac{x}{x+2}$ ✔

   - $\frac{x}{x+7}$

   - $\frac{x+5}{x+2}$

   - $\frac{x}{x+5}$

   _Explanation:_ Factorising gives $\frac{x(x+5)}{(x+5)(x+2)}$. Cancelling the common factor $x+5$ leaves $\frac{x}{x+2}$.

2. Simplify $\frac{2}{x}+\frac{3}{x+1}$.

   - $\frac{5}{2x+1}$

   - $\frac{5x+1}{x(x+1)}$

   - $\frac{5x+2}{x(x+1)}$ ✔

   - $\frac{5x+2}{2x+1}$

   _Explanation:_ The common denominator is $x(x+1)$. The numerator becomes $2(x+1)+3x=5x+2$, giving $\frac{5x+2}{x(x+1)}$.

3. Simplify fully $\frac{x^2-4}{x+5}\div\frac{x-2}{2x+10}$.

   - $x+2$

   - $2(x-2)$

   - $\frac{x+2}{2}$

   - $2(x+2)$ ✔

   _Explanation:_ Rewrite the division as multiplication by the reciprocal. Using $x^2-4=(x-2)(x+2)$ and $2x+10=2(x+5)$ allows the common factors to cancel, leaving $2(x+2)$.

4. Solve $\frac{3}{x}=\frac{2}{x+1}$.

   - $x=3$

   - $x=-3$ ✔

   - $x=-1$

   - $x=1$

   _Explanation:_ Cross-multiplying gives $3(x+1)=2x$. Therefore $3x+3=2x$, so $x=-3$, which does not make either denominator zero.

5. Given $x+1:x+3=x+5:2x+6$, what are the possible values of $x$?

   - $x=3$ only ✔

   - $x=-3$ only

   - $x=3$ and $x=-3$

   - $x=0$ only

   _Explanation:_ Writing the ratio as fractions and cross-multiplying gives $x^2-9=0$, so initially $x=3$ or $x=-3$. However, $x=-3$ makes the denominators zero, so only $x=3$ is valid.
