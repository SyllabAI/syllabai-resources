# Drawing Other Graphs: Cubic/Reciprocal

**Practice questions**

1. For the cubic graph $y=x^3$, what is the value of $y$ when $x=-2$?

   - $8$

   - $-6$

   - $-8$ ✔

   - $4$

   _Explanation:_ Substitute $x=-2$: $y=(-2)^3=(-2)\times(-2)\times(-2)=-8$.

2. Which point lies on the reciprocal graph $y=\frac{12}{x}$?

   - $(3,4)$ ✔

   - $(4,2)$

   - $(6,3)$

   - $(12,12)$

   _Explanation:_ For $y=\frac{12}{x}$, the coordinates must satisfy $xy=12$. For $(3,4)$, $3\times4=12$.

3. Which statement about the graph $y=\frac{1}{x}$ is correct?

   - It crosses both coordinate axes.

   - It crosses the $x$-axis but not the $y$-axis.

   - It crosses the $y$-axis but not the $x$-axis.

   - It approaches both coordinate axes but never touches them. ✔

   _Explanation:_ The axes are asymptotes. The graph approaches $x=0$ and $y=0$, but $x$ cannot equal $0$ and $\frac{1}{x}$ can never equal $0$.

4. What is the $y$-coordinate of the point on $y=x^3-2$ when $x=2$?

   - $4$

   - $6$ ✔

   - $8$

   - $10$

   _Explanation:_ Substitute $x=2$: $y=2^3-2=8-2=6$.

5. A point on the reciprocal graph $y=\frac{6}{x}$ has $y$-coordinate $-3$. What is its $x$-coordinate?

   - $-18$

   - $-3$

   - $-2$ ✔

   - $2$

   _Explanation:_ Solve $-3=\frac{6}{x}$. Multiplying by $x$ gives $-3x=6$, so $x=-2$.
