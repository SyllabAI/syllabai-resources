# Exchange Rates

Learn when to multiply or divide so you can change money between currencies confidently.

## Exchange Rates

Different countries use different currencies:  
The UK uses pounds (£)  
The USA uses US Dollars ($)  
Many counties in Europe use the Euro (€)

To convert between different currencies we use an exchange rate.

We need to be able to convert between different currencies using a given exchange rate.

If we are told the exchange rate is £1 = €1.15 it means that every 1 pound is worth 1.15 Euros.

If we wanted to change £250 into Euros we would need to calculate 250 × 1.15 to work out how many Euros we would get.

250 × 1.15 = 287.5

£250 = €287.50  
We would get €287.50 in exchange for £250

**Practice questions**

1. You change £72 into euros. The exchange rate is £1 = €1.25. How many euros do you get?

   - €57.60

   - €90.00 ✔

   - €73.25

   - €86.40

   _Explanation:_ Multiply by the exchange rate when converting pounds to euros: $72 \times 1.25 = 90$, so you get €90.00.

2. A meal costs €38. The exchange rate is €1 = £0.86. What is the cost in pounds?

   - £32.68 ✔

   - £44.19

   - £38.86

   - £37.14

   _Explanation:_ The rate gives the value of each euro in pounds, so calculate $38 \times 0.86 = 32.68$. The meal costs £32.68.


If we want to convert €500 into pounds (and the exchange rate is still £1 = €1.15) we will have to calculate 500 ÷ 1.15

500 ÷ 1.15 = £434.78 (we always round money to 2 decimal places because we cannot have half a penny)

£434.78 = €500  
We would get £434.78 in exchange for €500

**Practice questions**

1. You have €95 left after a trip. The exchange rate is £1 = €1.18. How much is this in pounds to the nearest penny?

   - £112.10

   - £80.50

   - £93.82

   - £80.51 ✔

   _Explanation:_ Divide by $1.18$ to convert euros back into pounds: $95 \div 1.18 = 80.508\ldots$, which rounds to £80.51.

2. A traveller changes £630 into dong at an exchange rate of £1 = 25 000 dong. They want as many 200 000 dong notes as possible. What is the greatest number of complete notes they can have?

   - 79

   - 78.75

   - 80

   - 78 ✔

   _Explanation:_ They receive $630 \times 25\,000 = 15\,750\,000$ dong. This is $15\,750\,000 \div 200\,000 = 78.75$ notes, so the greatest possible number of complete notes is 78.

3. A pair of headphones costs 4500 rupees abroad and £60 in the UK. The exchange rate is £1 = 90 rupees. Which price is cheaper, and by how much?

   - UK, by £10

   - Abroad, by £50

   - Abroad, by £10 ✔

   - UK, by £50

   _Explanation:_ Convert the overseas price into pounds: $4500 \div 90 = 50$. The headphones cost £50 abroad, so they are £10 cheaper than the £60 UK price.
