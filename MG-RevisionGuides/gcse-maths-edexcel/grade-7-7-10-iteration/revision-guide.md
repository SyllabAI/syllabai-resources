# Iteration

Turn repeated formula rules into reliable estimates for sequences, populations and equation solutions.

**Practice questions**

1. Given $x_0=2$ and $x_{n+1}=3x_n-1$, what is $x_1$?

   - $6$

   - $5$ ✔

   - $4$

   - $2$

   _Explanation:_ Substitute $x_0=2$ into the iteration: $x_1=3(2)-1=5$.

2. Starting with $x_0=1$, use $x_{n+1}=\frac{4}{x_n+1}$ three times. What is $x_3$ to 3 d.p.?

   - $1.333$

   - $2.000$

   - $1.500$

   - $1.714$ ✔

   _Explanation:_ The values are $x_1=2$, $x_2=\frac{4}{3}$ and $x_3=\frac{4}{\frac{4}{3}+1}=\frac{12}{7}\approx1.714$.

3. An iteration is $x_{n+1}=\frac{7-x_n^2}{3}$. If it converges to a fixed point, which equation does the fixed point solve?

   - $x^2+3x-7=0$ ✔

   - $x^2-3x+7=0$

   - $x^2+3x+7=0$

   - $x^2-3x-7=0$

   _Explanation:_ At a fixed point, set $x_{n+1}=x_n=x$. Then $x=\frac{7-x^2}{3}$, so $3x=7-x^2$ and therefore $x^2+3x-7=0$.

4. Let $f(x)=x^3+x-3$. Which calculation shows that there is a root between $1.2$ and $1.3$?

   - $f(1.2)=0.072$ and $f(1.3)=0.497$

   - $f(1.2)=-0.072$ and $f(1.3)=-0.497$

   - $f(1.2)=-0.072$ and $f(1.3)=0.497$ ✔

   - $f(1.2)=0.072$ and $f(1.3)=-0.497$

   _Explanation:_ $f(1.2)=1.2^3+1.2-3=-0.072$ and $f(1.3)=1.3^3+1.3-3=0.497$. The change of sign shows that the graph crosses the $x$-axis between these values.

5. Two consecutive values from an iteration are $x_5=1.52136$ and $x_6=1.52138$. What estimate should be given to 3 decimal places?

   - $1.520$

   - $1.522$

   - $1.5214$

   - $1.521$ ✔

   _Explanation:_ Both consecutive values round to $1.521$ to 3 decimal places, so this is a suitable estimate for the solution.
