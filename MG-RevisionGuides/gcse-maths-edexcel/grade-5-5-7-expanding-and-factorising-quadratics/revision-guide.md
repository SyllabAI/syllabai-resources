# Expanding and Factorising Quadratics

Learn how brackets create quadratics and how to reverse the process by spotting pairs of numbers.

**Practice questions**

1. Expand and simplify $(x + 4)(x - 7)$.

   - $x^2 - 11x - 28$

   - $x^2 - 3x - 28$ ✔

   - $x^2 + 3x - 28$

   - $x^2 - 28$

   _Explanation:_ Multiplying each pair gives $x^2 - 7x + 4x - 28$. The middle terms combine to $-3x$, so the result is $x^2 - 3x - 28$.

2. Expand and simplify $(3x - 2)(2x + 5)$.

   - $6x^2 + 19x - 10$

   - $5x^2 + 11x - 10$

   - $6x^2 - 11x - 10$

   - $6x^2 + 11x - 10$ ✔

   _Explanation:_ Expanding gives $6x^2 + 15x - 4x - 10$. Collecting the middle terms gives $6x^2 + 11x - 10$.

3. Expand and simplify $(y - 5)^2$.

   - $y^2 - 10y + 25$ ✔

   - $y^2 - 25$

   - $y^2 + 10y + 25$

   - $y^2 + 25$

   _Explanation:_ The square means $(y - 5)(y - 5)$. This expands to $y^2 - 5y - 5y + 25 = y^2 - 10y + 25$.

4. Factorise $x^2 + 2x - 35$.

   - $(x - 7)(x + 5)$

   - $(x + 7)(x + 5)$

   - $(x + 7)(x - 5)$ ✔

   - $(x - 7)(x - 5)$

   _Explanation:_ The two numbers must multiply to $-35$ and add to $2$. These numbers are $7$ and $-5$, so the factorisation is $(x + 7)(x - 5)$.

5. Factorise fully $9x^2 - 16$.

   - $(9x - 4)(x + 4)$

   - $(3x - 4)(3x + 4)$ ✔

   - $(3x - 4)^2$

   - $(9x - 16)(x + 1)$

   _Explanation:_ This is a difference of two squares: $9x^2 - 16 = (3x)^2 - 4^2$. Therefore it factorises as $(3x - 4)(3x + 4)$.
