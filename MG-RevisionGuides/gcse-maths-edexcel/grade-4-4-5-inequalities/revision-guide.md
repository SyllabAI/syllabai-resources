# Inequalities

Learn how inequality signs, number lines, and integer solutions work before solving simple linear inequalities.

**Practice questions**

1. A number line has an open circle at 5 and is shaded to the left. Which inequality does it represent?

   - $x \le 5$

   - $x > 5$

   - $x \ge 5$

   - $x < 5$ ✔

   _Explanation:_ Shading to the left means values less than 5. The open circle means 5 is not included, so the inequality is $x < 5$.

2. Solve $4t - 3 > 9$.

   - $t > 3$ ✔

   - $t < 3$

   - $t > \frac{3}{2}$

   - $t \ge 3$

   _Explanation:_ Add 3 to both sides to get $4t > 12$, then divide by 4. This gives $t > 3$; dividing by a positive number does not reverse the inequality sign.

3. Solve $7 > 19 - 3x$.

   - $x < 4$

   - $x \ge 4$

   - $x > 4$ ✔

   - $x > -4$

   _Explanation:_ Subtract 19 to get $-12 > -3x$. Dividing by $-3$ reverses the inequality sign, giving $4 < x$, which is the same as $x > 4$.

4. Solve $3(x + 2) \le 2x + 11$.

   - $x \ge 5$

   - $x \le 5$ ✔

   - $x < 5$

   - $x \le 9$

   _Explanation:_ Expand to get $3x + 6 \le 2x + 11$. Subtract $2x$ and then subtract 6, giving $x \le 5$.

5. Let $n$ be an integer. Which list gives all possible values of $n$ if $-3 < n \le 2$?

   - $-3, -2, -1, 0, 1, 2$

   - $-2, -1, 0, 1$

   - $-3, -2, -1, 0, 1$

   - $-2, -1, 0, 1, 2$ ✔

   _Explanation:_ The integers must be greater than $-3$, so $-3$ is excluded, and at most 2, so 2 is included. The values are $-2, -1, 0, 1, 2$.
