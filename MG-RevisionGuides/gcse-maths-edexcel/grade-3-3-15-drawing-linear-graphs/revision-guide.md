# Drawing Linear Graphs

Build a straight-line graph by calculating points, plotting them carefully, and reading values from the grid.

When we have an equation with two **different** unknowns, like y = 2x + 1, we cannot solve the equation.

We can instead find pairs of x and y values that make the left side equal the right side

We can use a table of values to show the number pairs:

| x | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| y |  |  |  |  |

To complete this table of values, for y = 2x + 1, we need to find out the value of y when x = 0, when x = 1, when x = 2 and when x = 3

We do this using substitution

When x = 0  
y = 2(0) + 1  
y = 1

When x = 1  
y = 2(1) + 1  
y = 3

When x = 2  
y = 2(2) + 1  
y = 5

When x = 3  
y = 2(3) + 1  
y = 7

We can use these values to complete the table

| x | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| y | 1 | 3 | 5 | 7 |

**Example 1: Complete the table of values for x + y = 6**

**Practice questions**

1. For the equation $x+y=9$, what is the value of $y$ when $x=-3$?

   - $-12$

   - $12$ ✔

   - $6$

   - $-6$

   _Explanation:_ Substitute $x=-3$: $-3+y=9$, so adding 3 to both sides gives $y=12$.

2. For $y=4x-1$, which value of $y$ corresponds to $x=-2$?

   - $-7$

   - $7$

   - $-9$ ✔

   - $9$

   _Explanation:_ Substitute $x=-2$: $y=4(-2)-1=-8-1=-9$.

**Example 2: Complete the table of values for y = 3x - 5**

| x | -3 | -2 | -1 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|---|---|---|
| y |  |  |  |  |  |  |  |

In this example we have negative x values in the table. It is often easier to start with the positive x values:

When x = 3  
y = 3(3) - 5  
y = 4

When x = 2  
y = 3(2) - 5  
y = 1

When x = 1  
y = 3(1) - 5  
y = -2

When x = 0  
y = 3(0) - 5  
y = -5

| x | -3 | -2 | -1 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|---|---|---|
| y |  |  |  | -5 | -2 | 1 | 4 |

We can notice a pattern in these y values, they are going up by 3 each time (from left to right or down by 3 each time from right to left).

We can expect that for x = -1, y = -8  
When x = -2, y = -11  
and when x = -3, y = -14

Substituting gives:

When x = -1  
y = 3(-1) - 5  
y = -8

When x = -2  
y = 3(-2) - 5  
y = -11

When x = -3  
y = 3(-3) - 5  
y = -14

If we make a mistake in our calculations we will be able to notice as our values would not fit the pattern.


**Practice questions**

1. For $y=-2x+3$, what is the value of $y$ when $x=-4$?

   - $11$ ✔

   - $-5$

   - $5$

   - $-11$

   _Explanation:_ Substitute $x=-4$: $y=-2(-4)+3=8+3=11$. Multiplying two negative numbers gives a positive result.

2. Which point lies on the line $y=3x-5$?

   - $(-1,-2)$

   - $(1,-8)$

   - $(-1,-8)$ ✔

   - $(3,5)$

   _Explanation:_ Check $(-1,-8)$: $3(-1)-5=-3-5=-8$, so it satisfies the equation.

## Example: Draw the graph for y = 3x + 1

![linear graphs 4](../assets/004-linear-graphs-4.jpg)

Here we have not been given a table of values.

We can create a table of values. We can see that the x values on the graph are -2, -1, 0, 1 and 2. We can use these for our table of values:

| x | -2 | -1 | 0 | 1 | 2 |
|---|---|---|---|---|---|
| y |  |  |  |  |  |

We can now complete our table bu substituting our x values into the equation:

When x = 2  
y = 3(2) + 1  
y = 7

When x = 1  
y = 3(1) + 1  
y = 4

When x = 0  
y = 3(0) + 1  
y = 1

When x = -1  
y = 3(-1) + 1  
y = -2

When x = -2  
y = 3(-2) + 1  
y = -5

We can use these values to complete the table

| x | -2 | -1 | 0 | 1 | 2 |
|---|---|---|---|---|---|
| y | -5 | -2 | 1 | 4 | 7 |

The next step is to plot the coordinates:  
(-2,-5), (-1,-2), (0,1), (1,4) and (2,7)

**Practice questions**

1. When drawing $y=2x-3$, which coordinate should be plotted when $x=2$?

   - $(1,2)$

   - $(2,-1)$

   - $(2,1)$ ✔

   - $(-2,1)$

   _Explanation:_ Substitute $x=2$: $y=2(2)-3=4-3=1$, giving the coordinate $(2,1)$.

2. A table for a straight line shows that when $x$ increases by 1, $y$ increases by 2. What does this tell you about the line?

   - It crosses the $y$-axis at 2.

   - It has gradient $2$. ✔

   - It has gradient $\frac{1}{2}$.

   - It decreases from left to right.

   _Explanation:_ The gradient is the change in $y$ divided by the change in $x$. Here it is $\frac{2}{1}=2$, so the line rises from left to right.
