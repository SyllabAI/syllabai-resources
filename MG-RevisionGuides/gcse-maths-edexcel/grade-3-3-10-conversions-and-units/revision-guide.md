# Conversions and Units

Learn how to read conversion graphs and change between length, area, volume and speed units confidently.

Here is a conversion graph that can be used to change between Euros and Pounds.

![conversion graphs1](../assets/001-conversion-graphs1.jpg)

We can use the conversion graph to convert Euros into Pounds or Pounds into Euros.

## Example: Use the conversion graph to convert €10 into Pounds.

We need to draw a straight line up (vertical) from €10 to the line on the conversion graph.

![conversion graphs1a](../assets/002-conversion-graphs1a.jpg)

We then draw a horizontal line (across) from this point to the Pounds axis.

![conversion graphs1b](../assets/003-conversion-graphs1b.jpg)

We now read off the scale. Half way between £8 and £9 is £8.50

€10 = £8.50

## Example: Use the conversion graph to convert £18 into Euros.

We need to draw a straight line across (horizontal) from £18 to the line on the conversion graph.

![conversion graphs1c](../assets/004-conversion-graphs1c.jpg)

From this point we draw a vertical line down to the Euros axis

![conversion graphs1d](../assets/005-conversion-graphs1d.jpg)

We can now read off the Euros axis.  
£18 = €21

**Practice questions**

1. A conversion graph shows that €10 is equal to £8.50. Using the same graph, approximately how many pounds is €30?

   - £18.50

   - £25.50 ✔

   - £28.50

   - £30.00

   _Explanation:_ €30 is $3$ times €10, so multiply £8.50 by $3$: $3 \times 8.50 = 25.50$. Therefore, €30 is approximately £25.50.

2. A conversion graph shows that £18 is equal to €21. Approximately how many euros is £12?

   - €9

   - €10.50

   - €15

   - €14 ✔

   _Explanation:_ £12 is $\frac{2}{3}$ of £18, so find $\frac{2}{3}$ of €21: $21 \div 3 \times 2 = 14$. Therefore, £12 is approximately €14.

3. A conversion graph has Euros on the horizontal axis and Pounds on the vertical axis. How should you use it to convert a value in Pounds into Euros?

   - Move horizontally from the Pounds axis to the conversion line, then vertically down to the Euros axis. ✔

   - Move vertically from the Pounds axis to the conversion line, then horizontally to the Euros axis.

   - Multiply the number of Pounds by the largest value on the Euros axis.

   - Move horizontally from the Euros axis, then vertically up to the Pounds axis.

   _Explanation:_ Start on the axis containing the given unit. From the Pounds axis, move horizontally to the conversion line and then vertically down to read the Euros value.


We can also be asked to use a conversion graph to convert numbers that are off the chart

## Example: Use the conversion graph to convert €80 into Pounds.

The first step would be to use the conversion graph to convert something in Euros into Pounds

If we convert €20 into pounds we could multiply the answer by 4 to get €80

![conversion graphs1e](../assets/006-conversion-graphs1e.jpg)

€20 is just over £17  
In an exam question there will be a range of answers, anything between £17 and £17.25 should be acceptable.  
I will say €20 = £17.10

We can now multiply by 4  
4 × €20 = 4 × £17.10  
€80 = £68.40

**Practice questions**

1. The conversion graph gives €20 as approximately £17.10. Using this conversion, approximately how many pounds is €100?

   - £342.00

   - £68.40

   - £85.50 ✔

   - £117.10

   _Explanation:_ €100 is $5$ times €20, so multiply £17.10 by $5$: $17.10 \times 5 = 85.50$. Therefore, €100 is approximately £85.50.

2. A conversion graph shows that 20 litres is approximately 35 pints. Using this relationship, approximately how many litres is 70 pints?

   - 35 litres

   - 40 litres ✔

   - 122.5 litres

   - 90 litres

   _Explanation:_ 70 pints is twice 35 pints, so the corresponding volume is twice 20 litres: $2 \times 20 = 40$ litres.
