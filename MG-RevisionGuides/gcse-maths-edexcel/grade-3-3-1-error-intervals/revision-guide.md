# Error Intervals

See how one displayed value can cover many true measurements.

When we use error intervals we are looking at a number that has been rounded. An error interval tells us the range of numbers that we could have had before the number was rounded.

**Example 1: A number *x* has been rounded to one decimal place  
The result is 4.8  
Write down the error interval for *x***

The number has been rounded to 4.8 to one decimal place.  
The number below is 4.7 and the number above is 4.9 (to one decimal place)

![error intervals 1](../assets/001-error-intervals-1.jpg)

We need to look half way between 4.7 and 4.8 for the lower bound and half way between 4.8 and 4.9 for the upper bound.

![error intervals 2](../assets/002-error-intervals-2.jpg)

The number must have been between 4.75 and 4.85 to round to 4.8 to one decimal place.

This can be written as an inequality.  
4.75 would round to 4.8, so we use an or equal symbol  
4.85 would not round to 4.8 we just use the less than symbol.

**4.75 ≤ *x* < 4.85**

**Practice questions**

1. A number $x$ is rounded to 2 decimal places and the result is $6.37$. What is the error interval for $x$?

   - $6.365 \le x < 6.375$ ✔

   - $6.37 \le x < 6.38$

   - $6.36 \le x < 6.38$

   - $6.365 < x \le 6.375$

   _Explanation:_ Rounding to 2 decimal places means the half-step is $0.005$. Therefore the lower bound is $6.37-0.005=6.365$ and the upper bound is $6.37+0.005=6.375$, which is not included because it would round to $6.38$.

2. A mass $m$ is given as $580$ g, correct to the nearest $10$ g. Which is the error interval for $m$?

   - $570 \le m < 590$

   - $579.5 \le m < 580.5$

   - $575 \le m < 585$ ✔

   - $580 \le m < 590$

   _Explanation:_ The rounding unit is $10$ g, so the half-step is $5$ g. The mass is at least $580-5=575$ g and less than $580+5=585$ g.


**Example 2: A number *y* has been rounded to one significant figure  
The result is 7000  
Write down the error interval for *y***

The number below is 6000 and the number above is 8000 (to one significant figure)

![error intervals 3](../assets/003-error-intervals-3.jpg)

We need to look half way between 6000 and 7000 for the lower bound and half way between 7000 and 8000 for the upper bound.

![error intervals 4](../assets/004-error-intervals-4.jpg)

The number must have been between 6500 and 7500 to round to 7000 to one significant figure.

We write this as an inequality. The number could have been equal to 6500, but not equal to 7500.

**6500 ≤ *y* < 7500**

**Practice questions**

1. A number $x$ is rounded to 2 significant figures and the result is $0.047$. What is the error interval for $x$?

   - $0.046 \le x < 0.048$

   - $0.0465 \le x < 0.0475$ ✔

   - $0.047 \le x < 0.048$

   - $0.04695 \le x < 0.04705$

   _Explanation:_ In $0.047$, the second significant figure is in the thousandths place, so the half-step is $0.0005$. Thus the interval is $0.0465 \le x < 0.0475$.

2. A number $x$ rounds to $3.2$ to 1 decimal place. Which value could $x$ be?

   - $3.14$

   - $3.25$

   - $3.27$

   - $3.15$ ✔

   _Explanation:_ The error interval is $3.15 \le x < 3.25$. The value $3.15$ is included because it rounds up to $3.2$, while $3.25$ would round to $3.3$.

## Truncating numbers

When a number has been truncated it has been cut off. If we truncate a number to one decimal place we delete all digits after one decimal place. If we truncate a number to two decimal places we delete all digits after two decimal places.

**Example 3: Truncate 4.5891 to one decimal place**

We delete all the digits after one decimal place:  
4.5891  
4.5891 truncated to one decimal place is 4.5


**Example 4: Truncate 19.68572 to two decimal places**

We remove all the digits after two decimal places:  
19.68572  
19.68572 truncated to two decimal place sis 19.68


**Example 5: A number *x* has been truncated to one decimal place  
The result is 1.4  
Write an error interval for *x***

The number must have began with 1.4 in order for it to be truncated to 1.4

![error intervals 5](../assets/005-error-intervals-5.jpg)

All of the numbers between 1.4 and 1.5 begin with 1.4

The number could have been equal to 1.4 but not equal to 1.5 (It could have been anything up to 1.5, but not 1.5)

**1.4 ≤ *x* < 1.5**

**Practice questions**

1. A positive number $x$ is truncated to 2 decimal places and gives $7.40$. What is the error interval for $x$?

   - $7.395 \le x < 7.405$

   - $7.40 \le x < 7.41$ ✔

   - $7.40 \le x \le 7.41$

   - $7.4 \le x < 7.5$

   _Explanation:_ Truncation keeps the digits up to 2 decimal places and discards the rest. So $x$ can start at $7.40$ but must be less than the next hundredth, $7.41$.

2. A positive number is truncated to 2 decimal places to give $5.90$. Which value could the original number be?

   - $5.899$

   - $5.895$

   - $5.907$ ✔

   - $5.91$

   _Explanation:_ For truncation to give $5.90$, the original number must satisfy $5.90 \le x < 5.91$. Therefore $5.907$ works; $5.91$ is too large and the first two values are below $5.90$.
