# Histograms

Learn how histogram bar area, class width and frequency density connect so you can complete tables and draw accurate bars.

**Practice questions**

1. A histogram uses the class interval $7 \le t < 15$. What is the class width?

   - $7$

   - $8$ ✔

   - $15$

   - $22$

   _Explanation:_ Class width is the upper boundary minus the lower boundary: $15-7=8$.

2. For the class $2 \le t < 10$, the frequency is $24$. What is the frequency density?

   - $3$ ✔

   - $8$

   - $12$

   - $24$

   _Explanation:_ Frequency density is $\dfrac{\text{frequency}}{\text{class width}}$. The width is $10-2=8$, so the density is $24\div8=3$.

3. A histogram bar covers $5 \le x < 13$ and has frequency density $1.5$. What frequency does the bar represent?

   - $7.5$

   - $9.5$

   - $12$ ✔

   - $19.5$

   _Explanation:_ Frequency is the area of the bar: $\text{class width}\times\text{frequency density}$. Therefore, $(13-5)\times1.5=8\times1.5=12$.

4. The class $0 \le t < 4$ has frequency $18$, while the class $4 \le t < 10$ has frequency density $2$. What are the frequency density of the first class and the frequency of the second class?

   - $18$ and $2$

   - $72$ and $12$

   - $4.5$ and $6$

   - $4.5$ and $12$ ✔

   _Explanation:_ For the first class, the density is $18\div4=4.5$. For the second class, the width is $10-4=6$, so the frequency is $6\times2=12$.

5. A histogram bar covers $20 \le m < 35$ and represents a frequency of $45$. Assuming values are evenly distributed within the class, estimate the frequency for $24 \le m < 30$.

   - $15$

   - $18$ ✔

   - $24$

   - $30$

   _Explanation:_ The whole class has width $35-20=15$, so its density is $45\div15=3$. The interval from $24$ to $30$ has width $6$, giving an estimated frequency of $6\times3=18$.
