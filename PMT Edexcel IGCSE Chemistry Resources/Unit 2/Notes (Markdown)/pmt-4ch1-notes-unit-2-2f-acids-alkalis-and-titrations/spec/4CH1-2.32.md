# 4CH1-2.32 — know that alkalis can neutralise acids

- A neutralisation reaction is one between an acid and a base 

- the ionic equation **** for any alkali-acid neutralisation reaction is: H<sup>+</sup> (aq)<sup></sup>  + OH<sup>-</sup> (aq)<sup></sup>  -> H2O(l)
