# 4CH1-2.11 — describe the combustion of elements in oxygen,including magnesium,hydrogen and sulfur

- Combustion is an example of oxidation 

   - In an oxidation reaction, a substance gains oxygen 

   - Metals and non-metals can take part in these reactions 

- E.g. magnesium + oxygen -> magnesium oxide 

   - 2Mg + O2  -> 2MgO 

- E.g. sulfur + oxygen -> sulfur dioxide 

   - S + O2 -> SO2 

- E.g. hydrogen + oxygen -> water o 2H2  + O2 -> 2H2O
