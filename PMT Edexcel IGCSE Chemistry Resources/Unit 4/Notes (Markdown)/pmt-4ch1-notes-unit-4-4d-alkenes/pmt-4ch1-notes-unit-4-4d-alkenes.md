# _<mark>4.27</mark>_   _<mark>describe</mark>_   _<mark>the</mark>_   _<mark>reactions</mark>_   _<mark>of</mark>_   _<mark>alkenes</mark>_   _<mark>with</mark>_   _<mark>bromine</mark>_   _<mark>to</mark>_   _<mark>produce dibromoalkanes</mark>_ {#pmt-4ch1-notes-unit-4-4d-alkenes-s1}
- alkene + bromine → dibromoalkane 

   - E.g. Ethene + bromine -> 1,2-dibromoethane 

- Addition reaction 

- Involves the removal of C=C double bond 

- remember bromine exists as Br2 

# _<mark>4.28</mark>_   _<mark>describe</mark>_   _<mark>how</mark>_   _<mark>bromine</mark>_   _<mark>water</mark>_   _<mark>can</mark>_   _<mark>be</mark>_   _<mark>used</mark>_   _<mark>to</mark>_   _<mark>distinguish</mark>_   _<mark>between</mark>_   _<mark>an alkane</mark>_   _<mark>and</mark>_   _<mark>an</mark>_   _<mark>alkene</mark>_ {#pmt-4ch1-notes-unit-4-4d-alkenes-s2}
- alkenes react with bromine water, turning it from orange to colourless – alkanes DO NOT react with bromine water- it remains orange
