# Calculating Entropy Changes

## Entropy Change Calculations

> **Spec point** — `spcpt_8Y5M4NmNmFkWjxnG`

## Entropy Change Calculations

- The standard entropy change (Δ*S*<sub>*system*</sub><sup>θ</sup>) for a given reaction can be calculated using the standard entropies (*S*<sup>θ</sup>) of the reactants and products
- The equation to calculate the standard entropy change of a system is:

**Δ*****S***<sub>***system***</sub><sup>**θ **</sup>**= ∑*****S***<sub>***products***</sub><sup>**θ**</sup>** - ∑*****S***<sub>***reactants***</sub><sup>**θ**</sup>

(where ∑ = sum of)

- For example, the standard entropy change for the formation of ammonia (NH<sub>3</sub>) from nitrogen (N<sub>2</sub>) and hydrogen (H<sub>2</sub>) can be calculated using this equation

**            N**<sub>**2 **</sub>**(g) + 3H**<sub>**2 **</sub>**(g) ⇋ 2NH**<sub>**3 **</sub>**(g)**

**Δ*****S***<sub>***system***</sub><sup>**θ**</sup>** = (2 x Δ*****S***<sup>**θ**</sup>**(NH**<sub>**3**</sub>**)) - (Δ*****S***<sup>**θ**</sup>**(N**<sub>**2**</sub>**) + 3 x Δ*****S***<sup>**θ**</sup>**(H**<sub>**2**</sub>**))**

> **Worked Example**
> Calculate the entropy change of the system for the following reaction:
> 
> **2Mg (s) + O**<sub>**2**</sub>** (g) → 2MgO (s)**
> 
> - S<sup>θ</sup><sup>** **</sup>[Mg (s)] = 32.60 J K<sup>–1</sup> mol<sup>–1</sup>
> - S<sup>θ</sup><sup>** **</sup>[O<sub>2</sub> (g)] = 205.0 J K<sup>–1</sup> mol<sup>–1</sup>
> - S<sup>θ</sup><sup>** **</sup>[MgO (s)] = 38.20 J K<sup>–1</sup> mol<sup>–1</sup>
> 
> **Answer:**
> 
> - Δ*S*<sub>*system*</sub><sup>θ </sup>= ΣΔ*S*<sub>*products*</sub><sup>θ</sup> - ΣΔ*S*<sub>*reactants*</sub><sup>θ</sup>
> - Δ*S*<sub>*system*</sub><sup>θ </sup>= (2 x 38.20) - (2 x 32.60 + 205.0)
> - Δ*S*<sub>*system*</sub><sup>θ </sup>= –193.8 J K<sup>-1</sup> mol<sup>-1</sup>

> **Exam Hint**
> Use the **stoichiometry**  of the equation and the correct state of the compounds when calculating the entropy change of a reaction
