## Storage devices

| Device | Principal operations | Additional information |
|---|---|---|
| **Magnetic hard disk** | - Multiple metal platters coated with magnetic material store data as magnetised iron particles (0s and 1s)<br>- Platters spin at high speed (typically 5400–7200 RPM)<br>- Data read/written using electromagnets | - **Platters **divided into concentric tracks and wedge-shaped sectors, forming track sectors<br>- **Read/write arm**, controlled by an actuator, positions the head over the correct track sector<br>- Reliable but mechanical – can be slower and more prone to damage than SSDs |
|   |   |   |
|   |   |   |

| **Solid state (flash) memory** | - Stores data in **cells **using transistors that act as switches<br>- Uses **NAND **or **NOR **gates to control flow of electrons<br>- Writing: high voltage **pushes electrons** onto floating gate<br>- Faster and more durable than magnetic drives | - Common examples: SSDs, USB flash drives<br>- Each cell contains a **control gate** (controls current) and a **floating gate** (stores charge)<br>- Erasing: reverse high voltage pulls electrons off floating gate<br>- No moving parts – better shock resistance |

> **Worked Example**
> A magnetic hard disk is used to store data on the computer. Describe the principal operations of a magnetic hard disk **[5]**
> 
> **Final answer:** **Answer**
> 
> - The hard disk has (one or more) platter/plate/disk **[1 mark]**
> - Each surface of the platter/disk is capable of being magnetised  **[1 mark]**
> - The surface of the platter/disk is divided into concentric tracks / circles  **[1 mark]**
> - The disks are rotated (at high-speed)  **[1 mark]**
> - (Each surface of the disk) has a read/write head mounted on an arm (positioned just above the surface)  **[1 mark]**
