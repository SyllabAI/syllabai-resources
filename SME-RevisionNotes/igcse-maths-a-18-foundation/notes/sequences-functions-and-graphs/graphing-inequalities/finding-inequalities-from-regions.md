# Finding Inequalities from Regions

## Interpreting Graphical Inequalities

> **Spec point** — `spcpt_Ck9bpVKKwGGyBVb6`

## Interpreting graphical inequalities

### How do I know which inequalities are shown on a graph of shaded regions?

- To **identify the inequalities **represented by the shaded regions on a graph:

  - Find the **equation** of each line on the graph
  
    - You may have to calculate the **gradient** and find the ***y*****-intercept** to use $y=mx+c$
    - **Vertical **lines have the form $x=k$
    - **Horizontal** lines have the form $y=k$
  - **Replace **the = sign with the relevant inequality
  
    - ≤ if region is **below** line
    - ≥ if region is **above** line
    - (Use a point to test if not sure)
  - For **vertical lines**:
  
    - ≤ if region is to the **left** of the line
    - ≥ if region is to the **right** of the line
    - (Use a point to test if not sure)

> **Exam Hint**
> Always read the question carefully to see if the diagram shades the wanted region or the unwanted region. You normally still get full marks if you write < instead of ≤ or > instead of ≥.

> **Worked Example**
> Write down the three inequalities which define the shaded region shown on the axes below.
> 
> ![A graph showing a shaded region and three inequalities.](assets/3aeadf986450-55366-finding-inequalities-from-regions-1-igcse-.png)
> 
> **Answer:**
> 
> > *Find the equations of the three lines shown (ignoring inequality signs for now)*
> 
> > *You may be able to see the lines *$x=1$* and *$y=x$
> *The other line has the form *$y=mx+c$* with y-intercept 7 and gradient -1*
> 
> ![A graph showing a shaded region with three inequalities and a highlighted point within the shaded region.](assets/a6d8ad1c5df0-6850-finding-inequalities-from-regions-2-igcse-v.png)
> 
> > *Now decide which inequality signs to use*
> 
> > *For *$y=x$*, the shaded region is above the line, so the inequality is*
> 
> $y\geqx$
> 
> > *If unsure, check by substituting in coordinates from the shaded region*
> *For example, using (2, 4) as marked on the graph above*
> 
> *"*$4>2$*" is true, so the inequality *$y\geqx$* is correct*
> 
> > *For *$y=-x+7$*, the shaded region is below the line, so the inequality is *
> 
> $y\leq-x+7$
> 
> > *Again, check by substituting (2, 4) into the inequality*
> 
> *"*$4\leq-2+7$*" is true, so the inequality *$y\leq-x+7$* is correct*
> 
> > *For *$x=1$*, the shaded region is to the right of the line so the inequality is*
> 
> $x\geq1$
> 
> > *Write all three inequalities together as your final answer*
> 
> **Final answer:** $y\geqx$**, **$y\leq-x+7$** and **$x\geq1$
