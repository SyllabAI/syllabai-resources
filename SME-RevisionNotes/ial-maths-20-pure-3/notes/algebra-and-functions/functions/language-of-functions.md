## Language of functions

### What language is used with functions?

- The language of functions has many keywords associated with it that need to be understood

![Language of Functions Notes Diagram 1, A Level & AS Level Pure Maths Revision Notes](../../../assets/37d441053a3d-2-8-1-language-of-functions-notes-diagram-1.png)

### What are mappings?

- A **mapping** takes an ‘**input’** from one **set** of values to an ‘**output’** in another

![Language of Functions Notes Diagram 2, A Level & AS Level Pure Maths Revision Notes](../../../assets/9aae11cc3a56-2-8-1-language-of-functions-notes-diagram-2.png)

- Mappings can be

  - ‘**many**-to-**one’** (**many** ‘input’ values go to **one** ‘output’ value)
  - ‘**one**-to-**many’**
  - ‘**many**-to-**many’**
  - ‘**one**-to-**one’**

![Language of Functions Notes Diagram 3, A Level & AS Level Pure Maths Revision Notes](../../../assets/894cc04e6163-2-8-1-language-of-functions-notes-diagram-3.png)

### What is the difference between a mapping and a function?

- A **function** is a mapping where every ‘input’ value maps to a **single** ‘output’
- **Many**-to-**one** and **one**-to-**one** mappings are functions
- **Mappings **which have** many possible outputs **are** not functions**

![Language of Functions Notes Diagram 4, A Level & AS Level Pure Maths Revision Notes](../../../assets/26ef82e1a3f2-2-8-1-language-of-functions-notes-diagram-4.png)

### What is function notation?

- Functions are denoted by the notation** f(x)**, **g(x)**, etc

  - eg. f(x) = x<sup>2</sup> - 3x + 2
- Or the alternative notation

  - eg. f : x ↦ x<sup>2</sup> – 3x + 2

### What sets of numbers do I need to know?

- Functions often involve domains and ranges for specific sets of numbers
- All numbers can be organised into different sets ℕ, ℤ, ℚ, ℝ

![Language of Functions Notes Diagram 5, A Level & AS Level Pure Maths Revision Notes](../../../assets/0ed91f399495-2-8-1-language-of-functions-notes-diagram-5.png)

- So ℕ is a **subset** of ℤ etc
- ℤ<sup>-</sup> would be the set of negative integers only

### What is the domain of a function?

- The **domain** of a function is the set of values that are allowed to be the ‘input’

![Language of Functions Notes Diagram 6, A Level & AS Level Pure Maths Revision Notes](../../../assets/b32b439c21f8-2-8-1-language-of-functions-notes-diagram-6.png)

- A function is only fully defined once its domain has been stated
- **Restrictions** on a domain can turn **many**-to-**one** functions into **one**-to-**one** functions

![EXTRA No1, A Level & AS Level Pure Maths Revision Notes](../../../assets/c7f1c39b93cd-2-8-1-extra-no1.png)

### What is the range of a function?

- The **range** of a function is the set of values of all possible ‘outputs’ ![Language of Functions Notes Diagram 7, A Level & AS Level Pure Maths Revision Notes](assets/e3dd6226f7b5-2-8-1-language-of-functions-notes-diagram-7.png)
- The type of values in the range depend on the domain
