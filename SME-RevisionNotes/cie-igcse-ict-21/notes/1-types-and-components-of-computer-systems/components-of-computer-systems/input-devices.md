## Input Devices

### What is an Input Device?

- Input devices are **hardware components** that** allow users to interact **with a computer system
- They enable the user to** input data or commands into the system**, which the computer then processes to produce an output

#### Types of input devices

| **Input device** | **Advantages** | **Disadvantages** |
|---|---|---|
| **Keyboard**<br><br>(Entering data into a computer) | - Easy method of entering data<br>- Very common | - Repetitive strain injury<br>- Slow to enter data compared to direct data entry |
| Numeric **Keypad**<br><br>(**ATMs **, chip and PIN devices) | - Fast<br>- Easy to use | - Size of buttons can impede some users<br>- Button layouts not always the same |
| Pointing Devices<br><br>(**Mouse**) | - Intuitive and precise control<br>- Fast to make on-screen choices | - RSI (strain on wrist)<br>- Requires flat surface<br>- People with disabilities can find them difficult to use |
| **Remote Control**<br><br>(TV, hi-fi remotes) | - Easy to use<br>- Can control from a distance | - May require line-of-sight<br>- Easily lost<br>- Needs regular battery replacements |
| Pointing Devices<br><br>(**Joystick/Driving Wheel**) | - Enhances gameplay/simulation experience<br>- Improve realism<br>- Accurate | - Expensive<br>- Limited use outside of gaming and simulators |
| **Touchscreen**<br><br>(Smart phones & tablets) | - Intuitive<br>- No need for a separate pointing device<br>- Easy to keep clean | - Screens can get dirty<br>- Easily scratched<br>- Less precise than a mouse |
| **Scanner**<br><br>(Convert paper documents to electronic) | - Accurate reproduction<br>- Easy to share and store<br>- Combined with barcodes becomes a DDE | - Quality depends on resolution<br>- High quality means can be slow |
| **Digital camera**<br><br>(Taking photos/videos) | - Vast amounts can be captured<br>- No developing<br>- Easy to share | - Storage compression can lead to a loss in quality<br>- Need to be tech-savvy to use effectively |
| **Microphone**<br><br>(Input speech, sensor to pick up sounds) | - Hands-free input<br>- Can be used for voice recognition<br>- Fast | - Variable quality<br>- Verbal inputs can be inaccurate<br>- Need to remember key words/phrases |
| Analogue **sensors**<br><br>(Measure environmental data e.g. temperature, light, sound, humidity etc.) | - Generally accurate<br>- Provides real-time information<br>- Automatic<br>- Can collect data from places where they may be threat to human life | - May require calibration<br>- Data must be converted to digital data (ADC)<br>- Data may need to be checked for accuracy |
| **Light pen**<br><br>(Select/write on screen) | - Accuracy for fine detail<br>- Small & lightweight<br>- Easy to use | - Lag<br>- Only work on certain types of screen<br>- Dated technology |

## Direct Data Entry

### What is a direct data entry device?

- A direct data entry device is a device capable of inputting data into a computer with little/no human interaction
- Data collection and transfer is completed automatically

#### Types of direct data entry devices

| **Direct data entry device** | **Advantages** | **Disadvantages** |
|---|---|---|
| **Magnetic stripe reader**<br><br>(Debit/credit cards) | - Fast<br>- Simple to use<br>- Secure (unreadable) | - Magnetic stripes can get damaged and become unreadable<br>- Reader must be in close contact |
| **Chip and PIN reader** | - Secure<br>- Reduced fraud risk | - Requires PIN input<br>- Potential for skimming<br>- High payment limits an issue for stolen cards |
| **RFID **reader (read only)<br><br>(Contactless payment) | - Fast transaction (no pin)<br>- Data wirelessly transferred securely<br>- Retailers don't have to access customer credit/debit information | - Transaction limit is smaller<br>- RFID signals can be read/intercepted |
| **RFID** reader<br><br>(Security tags on clothes, location tracking ) | - Very fast<br>- Data can be sent both ways<br>- Bulk detection | - Radio waves can be blocked/jammed<br>- Tag collisions<br>- Possible to hack |
| Optical Mark Recognition (**OMR**, read marks on exam paper in pen/pencil) | - Fast processing<br>- Reduced human error | - Limited to specific forms<br>- Cannot read handwriting<br>- Form must be completed accurately |
| Optical Character Recognition<br><br>(**OCR**, text to digital data) | - Fast data entry<br>- Accurate and less error prone | - Can struggle with complex layouts<br>- Font dependent<br>- Not always 100% accurate<br>- Expensive |
| **Barcode **reader<br><br>(reads barcode labels) | - Fast and accurate<br>- Low cost<br>- Allows for automatic stock control<br>- Tried & trusted | - Requires line-of-sight<br>- Barcodes are easily damaged<br>- Barcodes can be swapped/altered by consumers |
| **QR **scanner<br><br>(QR codes) | - Can store more data than barcodes<br>- Versatile uses<br>- Easy to read<br>- Can be encrypted | - QR codes can store malicious code<br>- Different QR code formats |

> **Worked Example**
