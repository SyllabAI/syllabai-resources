> **Spec point** — `spcpt_Nfvbnw5Zjj6KVjcd`

## Output Devices

### What is an output device?

- Output devices are hardware components that **receive information from a computer system** and** present it to the user **in a comprehensible form
- They enable the computer to **communicate the results** of processed data or commands

#### Types of output devices

| Output device | **Advantages** | **Disadvantages** |
|---|---|---|
| Monitor<br><br>(**CRT**) | - Large viewing angles<br>- Can be used with light pens | - Run hot<br>- Heavy<br>- Consume more power (than other monitor types) |
| Monitor<br><br>(**LCD**) | - Low power<br>- Lightweight<br>- No flickering<br>- No image burn-in | - Motion blur/ghosting<br>- Colour & contrast variable from different viewing angles |
| Monitor<br><br>(**LED**) | - No motion blur/ghosting<br>- Low power<br>- Long life | - More expensive (than LCD)<br>- Contrast can be poor |
| **Touch screen **<br><br>(Output) | - Intuitive<br>- Space-saving | - Susceptible to smudge<br>- Potential calibration issues |
| **Multimedia projector**<br><br>(Output computer usually to much larger display) | - Large display<br>- Good for presentations<br>- Space saving | - Requires darkened room<br>- Expensive bulbs<br>- Need separate audio<br>- Quality is variable |
| **Laser printer**<br><br>(Dry ink) | - Fast<br>- High-quality prints<br>- Lower cost per page | - Expensive initial cost<br>- Limited to flat surfaces |
| **Inkjet printer**<br><br>(Four/five wet inks) | - Lower initial cost<br>- High-quality prints<br>- Ink can be refilled | - Slower<br>- Higher cost per page<br>- Ink may smudge |
| **Dot matrix printer**<br><br>(Inked ribbon) | - Low cost<br>- Can print multi-part forms<br>- Very good for long print runs | - Noisy<br>- Low print quality<br>- Slow |
| **Plotters**<br><br>(Drawing & blueprints) | - High accuracy<br>- Can print on various materials<br>- Inexpensive to run | - Slow<br>- Expensive to buy<br>- Large size |
| **3D printer** | - Customisable designs<br>- Rapid prototyping<br>- Medical benefits | - Limited materials<br>- Slow process<br>- Counterfeit items easier to produce<br>- Very expensive |
| **Speakers** | - Range of sizes and power outputs<br>- Immersive audio<br>- Helps people with disabilities | - Expensive for higher quality output<br>- Varying  sound quality |
| **Actuators**<br><br>(Control motors, pumps, switches etc.) | - Precise movement<br>- Programmable<br>- Allow automatic control of many devices | - Requires power<br>- Potential mechanical wear<br>- Requires DAC interface |
