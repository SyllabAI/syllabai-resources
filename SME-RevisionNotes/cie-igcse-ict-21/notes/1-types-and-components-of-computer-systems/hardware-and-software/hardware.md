## Hardware

### What is hardware?

- Hardware is the **physical components of a computer** system
- Hardware can be divided into three categories:

  - **Internal components**
  - **Internal memory**
  - **Hardware components**

#### Internal components

- Internal components include:

  - [Central Processing Unit (CPU)](https://www.savemyexams.com/igcse/ict/cie/21/revision-notes/1-types-and-components-of-computer-systems/components-of-computer-systems/central-processing-unit-cpu/) - brain of the computer
  - **Processors **- electronic circuits that process information
  - **Motherboard **- connects all important components together allowing them to communicate

#### Internal memory

- Internal memory includes:

  - **Random Access Memory** (RAM) - fast, working memory
  - **Read-Only Memory** (ROM) - holds start-up instruction for the computer
- For full explanations, and comparisons, see the ‘[Internal Memory](https://www.savemyexams.com/igcse/ict/cie/21/revision-notes/1-types-and-components-of-computer-systems/components-of-computer-systems/internal-memory/)’ page

#### Hardware components

- Hardware components include:

  - **Graphics card **(GPU) - processes images and video
  - **Sound card** - processes audio
  - **Network Interface Card** (NIC) - provides wired connection to a network
  - **Camera **- captures images or video
  - [Internal/external storage devices](https://www.savemyexams.com/igcse/ict/cie/21/revision-notes/1-types-and-components-of-computer-systems/components-of-computer-systems/storage/) - stores data permanently e.g. hard drive, USB memory stick
  - [Input devices](https://www.savemyexams.com/igcse/ict/cie/21/revision-notes/1-types-and-components-of-computer-systems/components-of-computer-systems/input-devices/)** **- allow user input e.g. mouse & keyboard
  - [Output devices](https://www.savemyexams.com/igcse/ict/cie/21/revision-notes/1-types-and-components-of-computer-systems/components-of-computer-systems/output-devices/)** **- output results of processing e.g. monitor
