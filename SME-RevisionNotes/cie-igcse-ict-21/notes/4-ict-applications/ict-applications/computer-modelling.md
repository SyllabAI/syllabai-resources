## Computer Modelling

### What is computer modelling?

- Computer modelling is** using a computer to simulate a real-life system** in order to be able to **study the behaviour **in different scenarios
- The simulation **uses a model **to help** predict how the system will work** in unusual circumstances
- Examples of modelling application include:

  - **Personal finance**
  - **Bridge and building design**
  - **Flood water management**
  - **Traffic management**
  - **Weather forecasting**

#### Advantages and disadvantages of computer modelling

| Advantages | Disadvantages |
|---|---|
| - Cheaper than having to build the real thing<br>- Easier to try out a range of different scenarios<br>- Safer, can simulate hazardous environments e.g. power station<br>- Faster, can speed up variables that would impact on results e.g. climate change<br>- Testing can be done before real-life construction begins | - A computer model will never be 100% accurate<br>- Results are only as good as the model designed and data entered<br>- Possibility of human error in the design could skew results |

#### Modelling applications

| Application | Description |
|---|---|
| Personal finance | - Use of a spreadsheet to test 'what if' scenarios<br>- Using spreadsheet functionality to change values and see what impact is made e.g. the financial impact on a family if household income was to go down |
| Bridge and building design | - Architects will use 3D computer models of bridges and buildings so that a number of scenarios can be tested<br>- In bridge design:<br><br>  - How much traffic can the bridge take<br>  - The effects of natural vibrations<br>  - The effects of different weather conditions<br>  - What impact on structural integrity would an accident cause<br>- In building design:<br><br>  - The effects of different weather conditions<br>  - Simulating fire evacuation protocols<br>  - What impact on structural integrity would a fire cause |
| Flood water management | - Computer models allow risk assessments to be made of high risk flooding areas<br>- Using models and changing variables allows for the design of automated flood defence systems<br>- Variables would include:<br><br>  - different rivers and sea inlets<br>  - time of the day<br>  - previous flood behaviours<br>  - possible obstructions etc.<br>- An automated system allows for:<br><br>  - Real-time monitoring<br>  - Data collection<br>  - Faster response to changing conditions e.g. advance warning to people |
| Traffic management | - Computer models allow users to see the effect of traffic and accidents on major road networks<br>- The data collected can be used to optimise the traffic light times at different junctions<br>- Data collected could include:<br><br>  - Time of day<br>  - Number of vehicles passing the junction from all directions<br>  - Factors that effect the flow of traffic e.g. pedestrians crossing, accidents etc.<br>- After successful modelling has been completed, optimised systems can be built and installed |
| Weather forecasting | - Sensors are used collect data and sent to a central computer<br>- Data collected could include:<br><br>  - Air pressure<br>  - Wind speed<br>  - Air temperature<br>  - Humidity<br>- The computer model can then be used to predict weather patterns for the next few days<br>- Actual weather is compared to the modelled data to check for accuracy and identify any areas in the model to modify |
