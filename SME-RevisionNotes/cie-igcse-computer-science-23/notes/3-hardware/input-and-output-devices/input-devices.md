## Input Devices

### What is an Input Device?

- Input devices are **hardware components** that** allow users to interact **with a computer system
- They enable the user to** input data or commands into the system**, which the computer then processes to produce an output

#### Types of input devices

| **Device** | **What It Does** | **Where It Is Used** | **Why It Is Used** |
|---|---|---|---|
| **Barcode Scanner** | - Reads barcodes to capture product information | - Supermarkets<br>- Warehouses<br>- Libraries | - Quickly and accurately retrieves product details for stock and checkout |
| **Digital Camera** | - Captures photographs or videos as digital images | - Photography<br>- Smartphones<br>- Webcams | - High-quality visual content |
| **Keyboard** | - Inputs text and commands by pressing keys | - Computers<br>- Tablets<br>- Laptops | - Type documents<br>- Enter data<br>- Control software |
| **Microphone** | - Captures analogue sound and converts it into digital signals | - Recording studios<br>- Smartphones<br>- Computers | - Audio recording<br>- Voice communication |
| **Optical Mouse** | - Moves the cursor on the screen based on hand movements over a surface | - Computers<br>- Laptops | - Precise control and navigation on a computer screen |
| **QR Code Scanner** | - Reads QR codes to access stored information | - Retail shops<br>- Mobile apps | - Quickly retrieves data from QR codes<br>- Website links or product information |
| **Touch Screen (Resistive)** | - Detects touch by pressing a flexible screen layer | - ATMs<br>- Older smartphones and tablets | - Direct interaction with the device |
| **Touch Screen (Infra-red)** | - Detects touch by interrupting infrared light beams across the screen | - Kiosks<br>- Large touch displays | - Accurate touch detection<br>- Works well in various lighting conditions |
| **Touch Screen (Capacitive)** | - Detects touch through changes in electrical charge on the screen surface | - Modern smartphones<br>- Tablets<br>- Touch monitors | - Smooth, responsive touch experience with multi-touch capabilities |
| **Two-Dimensional (2D) Scanner** | - Captures flat, 2D images of documents or photos | - Offices<br>- Libraries<br>- Schools | - Digitises documents and photos for storage, editing, or sharing |
| **Three-Dimensional (3D) Scanner** | - Captures detailed 3D shapes and dimensions of objects | - Manufacturing<br>- Design<br>- Medical imaging | - Creates digital models of objects for design, analysis, or reproduction |
