# Gaming Sites

> **Spec point** — `spcpt_FYQTpKTsWJFDqKnc`

## Gaming sites

### What are gaming sites?

- A gaming site is an **online application that hosts a game on a remote server **for users to play
- Sometimes these games are **multiplayer**
- Gaming sites offer features that:

  - **Enhance the gameplay**
  - **Build a community**

| Enhance the gameplay | **Matchmaking **- connect users with other users of a similar skill level<br><br>**Leader boards** - allow users to track progress and compare with others<br><br>**Cloud saves** - save game progress online, ensures no issues if a user changes devices<br><br>**Microtransactions **- small, in game purchases allow users to personalise characters (cosmetics)<br><br>**DLC **- downloadable content that offers game expansion |
|---|---|
| Build a community | **Friends lists/chat** - allow users to connect online<br><br>**Voice chat** - allows users to communicate directly with other users whilst in the game<br><br>**Livestreaming** - allow users to stream gameplay so that other users can watch and interact<br><br>**Esports** - host tournaments where users compete for prizes |
