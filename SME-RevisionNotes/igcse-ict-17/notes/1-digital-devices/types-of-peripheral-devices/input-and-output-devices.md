# Input & Output Devices

## Input devices

> **Spec point** — `spcpt_QRyRhfJTHYkcmnP4`

## Input devices

### What is an input device?

- Input devices are **hardware components** that** allow users to interact **with a computer system
- They enable the user to** input data or commands into the system**, which the computer then processes to produce an output

#### Types of input devices

| **Input device** | Use | **Advantages** | **Disadvantages** |
|---|---|---|---|
| **Keyboard** | **Entering **data into a computer | - Easy method of entering data<br>- Very common | - Repetitive strain injury<br>- Slow to enter data compared to direct data entry |
| **Mouse** | To **select **on screen objects | - Intuitive and precise control<br>- Fast to make on-screen choices | - RSI (strain on wrist)<br>- Requires flat surface<br>- People with disabilities can find them difficult to use |
| **Joystick** | **Moves **sprites/characters around a game | - Enhances gameplay/simulation experience<br>- Improve realism<br>- Accurate | - Expensive<br>- Limited use outside of gaming and simulators |
| **Graphics tablet** | Use a **stylus **to draw or write | - Precise<br>- Natural feel<br>- Ergonomic | - Cost<br>- Learning curve<br>- Battery life |
| **Scanner** | **Convert **paper documents to electronic | - Accurate reproduction<br>- Easy to share and store<br>- Combined with barcodes becomes a DDE | - Quality depends on resolution<br>- High quality means can be slow |
| **Digital camera** | **Taking **photos/videos | - Vast amounts can be captured<br>- No developing<br>- Easy to share | - Storage compression can lead to a loss in quality<br>- Need to be tech-savvy to use effectively |
| **Webcam** | **Streaming **images/video | - Real-time communication<br>- Cheap<br>- Multipurpose | - Image quality<br>- Privacy concerns |
| **Microphone** | Input **speech**, sensor to pick up sounds | - Hands-free input<br>- Can be used for voice recognition<br>- Fast | - Variable quality<br>- Verbal inputs can be inaccurate<br>- Need to remember key words and/or phrases |
| **Resistive touchscreen** | Pressure causes **layers to 'touch'**<br><br>**Durable** | - Intuitive<br>- No need for a separate pointing device<br>- Easy to keep clean | - Screens can get dirty<br>- Easily scratched<br>- Less precise than a mouse |
| **Capacitive touchscreen** | **Conduct **electricity<br><br>Finger causes a **change in electrical charge **and can be **measured precisely** |   |   |
| **OMR**<br><br>Optical Mark Recognition | **Read marks **on exam paper in pen/pencil | - Fast processing<br>- Reduced human error | - Limited to specific forms<br>- Cannot read handwriting<br>- Form must be completed accurately |
| **OCR**<br><br>Optical Character Recognition | **Text **to **digital **data | - Fast data entry<br>- Accurate and less error prone | - Can struggle with complex layouts<br>- Font dependent<br>- Not always 100% accurate<br>- Expensive |
| **Barcode scanner** | Reads **barcode** labels | - Fast and accurate<br>- Low cost<br>- Allows for automatic stock control<br>- Tried & trusted | - Requires line-of-sight<br>- Barcodes are easily damaged<br>- Barcodes can be swapped/altered by consumers |
| **Biometric scanner** | Fingerprint/facial/voice/iris **recognition** | - Easier than passwords<br>- More secure<br>- Speed | - Privacy concerns<br>- Expensive |
| **Magnetic stripe reader** | **Debit**/**credit **cards | - Fast<br>- Simple to use<br>- Secure (unreadable) | - Magnetic stripes can get damaged and become unreadable<br>- Reader must be in close contact |
| **Chip and PIN reader** | Retail **card payments** | - Secure<br>- Reduced fraud risk | - Requires PIN input<br>- Potential for skimming<br>- High payment limits an issue for stolen cards |
| **RFID reader** | **Contactless **payments | - Fast transaction (no pin)<br>- Data wirelessly transferred securely<br>- Retailers don't have to access customer credit/debit information | - Transaction limit is smaller<br>- RFID signals can be read/intercepted |
| Analogue **sensors** | Measure **environmental data **e.g. temperature, light, sound, humidity etc. | - Generally accurate<br>- Provides real-time information<br>- Automatic<br>- Can collect data from places where they may be threat to human life | - May require calibration<br>- Data must be converted to digital data (ADC)<br>- Data may need to be checked for accuracy |

## Output devices

### What is an output device?

- Output devices are hardware components that **receive information from a computer system** and** present it to the user **in a comprehensible form
- They enable the computer to **communicate the results** of processed data or commands

#### Types of output devices

| **Output device** | Use/features | **Advantages** | **Disadvantages** |
|---|---|---|---|
| **CRT monitor** | Display output from a computer<br><br>**Screen size** is measured diagonally in inches<br><br>**Resolution **is the number of *pixels *measured horizontally across the screen | - Large viewing angles<br>- Can be used with light pens | - Run hot<br>- Heavy<br>- Consume more power (than other monitor types) |
| **LCD monitor** | - Low power<br>- Lightweight<br>- No flickering<br>- No image burn-in | - Motion blur/ghosting<br>- Colour & contrast variable from different viewing angles |   |
| **LED monitor** | - No motion blur/ghosting<br>- Low power<br>- Long life | - More expensive (than LCD)<br>- Contrast can be poor |   |
| **Laser printer** | **High volume** printing<br><br>Electronically charged **toner**<br><br>**Dry ink** | - Fast<br>- High-quality prints<br>- Lower cost per page | - Expensive initial cost<br>- Limited to flat surfaces |
| **Inkjet printer** | **Home printing** & photographs<br><br>Uses **wet ink** separated into black, cyan, magenta & yellow<br><br>Tiny dots **sprayed **onto paper | - Lower initial cost<br>- High-quality prints<br>- Ink can be refilled | - Slower<br>- Higher cost per page<br>- Ink may smudge |
| **Dot matrix printer** | Useful when printing** multiple copies**<br><br>Paper is **impacted **through a **ribbon **of ink | - Low cost<br>- Can print multi-part forms<br>- Very good for long print runs | - Noisy<br>- Low print quality<br>- Slow |
| **3D printer** | Create real-life versions of digital models | - Customisable designs<br>- Rapid prototyping<br>- Medical benefits | - Limited materials<br>- Slow process<br>- Counterfeit items easier to produce<br>- Very expensive |
| **Plotters** | Create drawings & blueprints | - High accuracy<br>- Can print on various materials<br>- Inexpensive to run | - Slow<br>- Expensive to buy<br>- Large size |
| **Multimedia projector** | Output computer usually to much larger display | - Large display<br>- Good for presentations<br>- Space saving | - Requires darkened room<br>- Expensive bulbs<br>- Need separate audio<br>- Quality is variable |
| **Speakers** | Output audio | - Range of sizes and power outputs<br>- Immersive audio<br>- Helps people with disabilities | - Expensive for higher quality output<br>- Varying  sound quality |
| **Actuators** | Control motors, pumps, switches etc. | - Precise movement<br>- Programmable<br>- Allow automatic control of many devices | - Requires power<br>- Potential mechanical wear<br>- Requires DAC interface |
