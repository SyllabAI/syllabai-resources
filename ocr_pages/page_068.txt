CHEMICAL FORMULAE, EQUATIONS AND CALCULATIONS: PART 1

We might be tempted to say that 0.2 mol Mg produces 0.2 mol H,(g) and the
mass of H2 = 0.2 x 2 = 0.4g. Unfortunately this is not the correct answer!

We can understand why it is not correct by looking at the chemical equation.
1 mol Mg reacts with 2mol HCI and therefore 0.2 mol Mg would react with
2 x 0.2 = 0.4mol HCl.

But we only used 0.2mol HCI and so we did not have enough to react with all
the Mg. Because all the Mg did not react we cannot use the number of moles
of Mg to work out how much hydrogen is produced.

If we try starting with the number of moles of HCI, we can deduce from the
chemical equation that 2mol HCl reacts with 1 mol Mg, therefore 0.2 mol
HCI reacts with 0.1 mol Mg. We added 0.2mol Mg and so there is more than
enough to react with all the HCI - the Mg is in excess.

Because we know that all the HCI reacts we can use the number of moles of
HCI to work out how much H, is produced.

2mol HCl produce 1 mol H,: the number of moles of H, is half the number of
moles of HCI.

Therefore 0.2 mol HCI produce 0.1 mol Hp.

The mass of Hz = 0.1 x 2 = 0.2g.

This is the correct answer!
