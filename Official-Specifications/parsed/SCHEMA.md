# Parsed Official Specifications — Schema v1.0

Deterministic, PDF-direct parse of all 20 Pearson Edexcel qualification
specifications in `Official-Specifications/`. Zero-LLM: every statement is
extracted from the PDF text layer with span-geometry provenance. Generated by
`scripts/spec_parser.py` (parser `spec-parser-1.0`), validated by
`scripts/validate_parsed.py`, reported by `scripts/finalize_reports.py`.

## Layout

```
parsed/
├── SCHEMA.md                        <- this file
├── _summary.json                    <- one row per parsed PDF
├── _sme_crossref.json               <- SME triangulation details
├── chemistry-rediff.json / .md      <- fresh 4CH1 parse vs OCR-based graph
└── <qual-slug>/                     <- 20 dirs, mirror Official-Specifications/
    ├── <pdf-stem>.parsed.json       <- the parsed product (1 per PDF)
    └── parse_report.json            <- gates + counts + SME crossref
```

## `spec_parsed.json` structure

```json
{
  "schema": "syllabai.parsed-specification/1.0",
  "id": "<qual-slug>",
  "family": "code_column | triplet_table | lettered_table | bare_int | heading_bullets",
  "source": { "pdf", "pdf_sha1", "pages", "parser", "parsed_utc" },
  "topics":      [ { "number", "title", "page", "oy" } ],
  "subsections": [ { "letter"|"code", "title", "page", "oy" } ],
  "spec_points": [ {
      "id": "IGCSE_CHEMISTRY:1.1",        // stable node id (see below)
      "official_code": "1.1",             // as printed in the PDF (null for
                                          // heading_bullets families)
      "scope": "Biology" | "M1" | null,   // per-science / per-unit context
      "text": "verbatim statement text",  // whitespace-normalised only
      "page": 17, "oy": 347.2,            // provenance: page + baseline y
      "topic": {...}, "subsection": {...},
      "sub_items": ["• bullet text", "i roman item", ...],
      "practical": false,
      "flags": ["possible-superscript-loss", ...]
  } ],
  "counts": { "spec_points", "practicals", "topics", "subsections", "flagged" }
}
```

### ID scheme (`<QUAL>:` prefix, maps to core `KnowledgeNode.code`)

| family | id shape | example |
|---|---|---|
| code_column (no scope) | `<QUAL>:<N.M><suffix>` | `IGCSE_CHEMISTRY:2.27C` |
| code_column + scope | `<QUAL>:<scope>-<N.M>` | `IGCSE_SCIENCE_DOUBLE_AWARD:Biology-1.1`, `IAL_MATHS:M1-5.1` |
| bare_int (IAL physics) | `<QUAL>:<int>` | `IAL_PHYSICS:92` |
| triplet/lettered | `<QUAL>:<N.M.K>[<letter>]` | `IGCSE_ECONOMICS:1.2.5a` |
| heading_bullets | `<QUAL>:S<sec>.<nnn>` (synthesised, doc order) | `IGCSE_MATHS_A:S2.041` |

## Family strategies

| family | quals | statement signal |
|---|---|---|
| `code_column` | IGCSE sciences (linear+modular), SDA, IAL bio/chem, IAL maths | left-column code `N.M[BCH]`, scope from `Biology/Chemistry/Physics content` or `M1.3 Unit content` headers |
| `bare_int` | IAL physics | bold sequential integer at left margin inside *Candidates will be assessed* sections |
| `triplet_table` | Business, ICT | three-column table: `N.M` topic rows + `N.M.K` statement rows (x>150) |
| `lettered_table` | Economics | `N.M.K` rows + lettered statements `a)` in content column |
| `heading_bullets` | Maths A (+modular), Geography, Accounting, English Lit, Further Maths | bold `N.M` headings; bullet statements get synthesised IDs (no official codes exist) |

## Validation

- **Chemistry ground truth**: 182/182 code-set equality with
  `graph/specification_points.yaml` (operator-ratified OCR-based graph);
  70.9% of statement texts byte-identical after whitespace/quote normalisation
  — every remaining diff is an OCR-md artifact (LaTeX-ified symbols like
  `$\rightleftharpoons$` vs the true `⇌`, OCR-invented linear text for drawn
  functional-group graphics) or image content absent from the text layer.
- **SME triangulation** (`_sme_crossref.json`): SME `definition` fields matched
  verbatim (notation-aware normalisation) against parsed statements + bullets.
  Biology 91.8% / physics 79.3% / SDA 77.0% / chemistry 72.7% — at or above the
  raw-PDF-text ceiling; remaining misses are SME-side merged/paraphrased
  definitions, resolved at the spec-point mapping stage with provenance tiers
  (verbatim / fuzzy / ai-adjudicated), never silently.
- **Gates per qual** (`parse_report.json`): G1 schema present, G2 ids unique,
  G3 provenance complete (page+oy), G4 id prefix valid — ALL_PASS × 20.

## Known limitations (flagged, never silently guessed)

1. Drawn functional-group graphics (e.g. ester linkage) are images — no text
   layer content. The OCR-md graph invented linear text for these; this parse
   leaves the statement short (see `chemistry-rediff.md`).
2. `heading_bullets` statements carry synthesised IDs (Pearson prints no
   statement codes for maths/geography/accounting/English lit/further maths).
3. Display equations are stored verbatim with satellite glyphs inline
   (`Q = m c Δ T`); LaTeX-style reconstruction happens at the mapping/consumption
   layer via the science Equations appendices (validation oracle).
4. SME granularity differs per subject (SME bullets-vs-rows aggregation) —
   count parity is reported, not gated.

## Regenerate

```bash

python3 scripts/validate_parsed.py        # SME crossref -> _sme_crossref.json

python3 scripts/finalize_reports.py       # per-qual parse_report.json
```
