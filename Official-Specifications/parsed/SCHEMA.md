# Parsed Official Specifications — Schema v1.0

Deterministic, PDF-direct parse of all 23 Pearson Edexcel qualification
specifications in `Official-Specifications/` (20 original T-SPEC-PARSE-1
quals + 3 T-SME-11 additions: english-language-a 4EA1, maths-b 4MB1,
science-double-award-modular 4XSD1 — same schema, same bundle, same gates). Zero-LLM: every statement is
extracted from the PDF text layer with span-geometry provenance. Generated by
`scripts/spec_parser.py` (parser `spec-parser-1.0`), validated by
`scripts/validate_parsed.py`, reported by `scripts/finalize_reports.py`.

## Layout

```
parsed/
├── SCHEMA.md                        <- this file
├── _summary.json                    <- one row per parsed PDF
├── _sme_crossref.json               <- SME triangulation details
├── chemistry-rediff.json / .md      <- fresh 4CH1 parse vs OCR-based graph
└── <qual-slug>/                     <- 23 dirs, mirror Official-Specifications/
    ├── <pdf-stem>.parsed.json       <- the parsed product (1 per PDF)
    └── parse_report.json            <- gates + counts + SME crossref
```

## `spec_parsed.json` structure

```json
{
  "schema": "syllabai.parsed-specification/1.0",
  "id": "<qual-slug>",
  "family": "code_column | triplet_table | lettered_table | bare_int | heading_bullets",
  "source": { "pdf", "pdf_sha1", "pages", "parser", "parsed_utc" },
  "topics":      [ { "number", "title", "page", "oy" } ],
  "subsections": [ { "letter"|"code", "title", "page", "oy" } ],
  "spec_points": [ {
      "id": "IGCSE_CHEMISTRY:1.1",        // stable node id (see below)
      "official_code": "1.1",             // as printed in the PDF (null for
                                          // heading_bullets families)
      "scope": "Biology" | "M1" | null,   // per-science / per-unit context
      "text": "verbatim statement text",  // whitespace-normalised only
      "page": 17, "oy": 347.2,            // provenance: page + baseline y
      "topic": {...}, "subsection": {...},
      "sub_items": ["• bullet text", "i roman item", ...],
      "practical": false,
      "flags": ["possible-superscript-loss", ...]
  } ],
  "counts": { "spec_points", "practicals", "topics", "subsections", "flagged" }
}
```

### ID scheme (`<QUAL>:` prefix, maps to core `KnowledgeNode.code`)

| family | id shape | example |
|---|---|---|
| code_column (no scope) | `<QUAL>:<N.M><suffix>` | `IGCSE_CHEMISTRY:2.27C` |
| code_column + scope | `<QUAL>:<scope>-<N.M>` | `IGCSE_SCIENCE_DOUBLE_AWARD:Biology-1.1`, `IAL_MATHS:M1-5.1` |
| bare_int (IAL physics) | `<QUAL>:<int>` | `IAL_PHYSICS:92` |
| triplet/lettered | `<QUAL>:<N.M.K>[<letter>]` | `IGCSE_ECONOMICS:1.2.5a` |
| heading_bullets | `<QUAL>:S<sec>.<nnn>` (content sections, doc order) | `IGCSE_MATHS_A:S2.041` |
| heading_bullets (assessment/front-matter rows) | `<QUAL>:SX.<nnn>` | `IGCSE_GEOGRAPHY:SX.020` |
| heading_bullets (component-anchored, ELA + English Lit) | `<QUAL>:C<comp><T|S>A<nn>` / `C<comp>T<nn>` | `IGCSE_ENGLISH_LANGUAGE_A:C1T01` |
| lettered headings (further maths, maths B) | `<QUAL>:<N><letter>` | `IGCSE_MATHS_B:4C` |

## Family strategies

| family | quals | statement signal |
|---|---|---|
| `code_column` | IGCSE sciences (linear+modular), SDA, IAL bio/chem, IAL maths | left-column code `N.M[BCH]`, scope from `Biology/Chemistry/Physics content` or `M1.3 Unit content` headers |
| `bare_int` | IAL physics | bold sequential integer at left margin inside *Candidates will be assessed* sections |
| `triplet_table` | Business, ICT | three-column table: `N.M` topic rows + `N.M.K` statement rows (x>150) |
| `lettered_table` | Economics | `N.M.K` rows + lettered statements `a)` in content column |
| `heading_bullets` | Maths A (+modular), Geography, Accounting, English Lit, Further Maths | bold `N.M` headings; bullet statements get synthesised IDs (no official codes exist) |

## Validation

- **Chemistry ground truth**: 182/182 code-set equality with
  `graph/specification_points.yaml` (operator-ratified OCR-based graph);
  70.9% of statement texts byte-identical after whitespace/quote normalisation
  — every remaining diff is an OCR-md artifact (LaTeX-ified symbols like
  `$\rightleftharpoons$` vs the true `⇌`, OCR-invented linear text for drawn
  functional-group graphics) or image content absent from the text layer.
- **SME triangulation** (`_sme_crossref.json`): SME `definition` fields matched
  verbatim (notation-aware normalisation) against parsed statements + bullets.
  Biology 91.8% / physics 79.3% / SDA 77.0% / chemistry 72.7% — at or above the
  raw-PDF-text ceiling; remaining misses are SME-side merged/paraphrased
  definitions, resolved at the spec-point mapping stage with provenance tiers
  (verbatim / fuzzy / ai-adjudicated), never silently.
- **Gates per qual** (`parse_report.json`): G1 schema present, G2 ids unique,
  G3 provenance complete (page+oy), G4 id prefix valid — ALL_PASS × 23.

## Known limitations (flagged, never silently guessed)

1. Drawn functional-group graphics (e.g. ester linkage) are images — no text
   layer content. The OCR-md graph invented linear text for these; this parse
   leaves the statement short (see `chemistry-rediff.md`).
2. `heading_bullets` statements carry synthesised IDs (Pearson prints no
   statement codes for maths/geography/accounting/English lit/further maths).
3. Display equations are stored verbatim with satellite glyphs inline
   (`Q = m c Δ T`); LaTeX-style reconstruction happens at the mapping/consumption
   layer via the science Equations appendices (validation oracle).
4. SME granularity differs per subject (SME bullets-vs-rows aggregation) —
   count parity is reported, not gated.

## Normalization invariants (KG-consumer contract, audited 2026-09-20)

Cross-qual audit of all 23 canonical bundles guarantees:

- **One point schema**: every one of the 4,189 spec points across all quals
  carries exactly the same 13 fields (id, official_code, scope, text, topic,
  subsection, sub_items, practical, applicability, leading_verb, ordering,
  provenance, flags). Schema string `syllabai.spec-points/1.0` everywhere.
- **Bundle top-level key sets** are identical across quals for spec_points /
  topics / practicals / assessment_objectives / command_words.
  `equations.json` has two content-driven shapes: quals WITH equations carry
  `method`+`source`; quals whose source PDF has no equations/formulae appendix
  carry `note` ("no equations/formulae appendix in source specification") and
  counts.sections == 0. Consumers should branch on counts.sections.
- **Provenance**: every point carries per-point provenance {pdf, pdf_sha1,
  page, oy, extraction_method}; all 23 pdf_sha1 values match the committed
  source PDFs byte-for-byte (sha1 re-verified 2026-09-20).
- **v1 vs canonical**: `<pdf-stem>.parsed.json` is the RAW parse record and may
  retain junk fragments the canonical builder drops (e.g. ial-biology v1 171
  vs canonical 170); `spec_points.json` is the clean product. Counts may
  differ by those junk rows by design.
- **Sub-item convention (triplet/lettered tables)**: '•' bullets -> sub_items;
  'o' sub-bullets -> flattened into text with the 'o ' glyph kept.
- **ial-maths two-column tables**: rows whose Content/Guidance columns wrap
  misaligned baselines were assembled line-interleaved by the parser; 146 such
  rows carry the `two-column-line-interleave` flag (wording approximate, treat
  as caution-quoted), 45 prose rows were rebuilt column-sequential
  (token-multiset verified) in T-SPEC-NORM-1, and the at-a-glance duplicate
  `IAL_MATHS:6.5` was removed (its unit-content row is `IAL_MATHS:P4-6.5`).
- **_summary.json**: one row per parsed PDF across the 23 quals (run log of
  spec_parser; regenerated from the committed parse set — the T-PARSE-FIX-2
  single-qual re-parse had truncated it to 1 row).
- **T-KG-13 repairs (2026-09-24, PDF-verified)**: (a) igcse-accounting — the
  44 flattened-duplicate rows (S1.035-050, S2.051-068, S4.069-072,
  S5.073-078: promoted bullets + lettered-lead merges) were removed; every
  statement/bullet in them exists verbatim in the clean capture (S1.119+)
  or the source PDF — canonical total 4,277 -> 4,233; (b) igcse-accounting
  subsection titles completed from the PDF left column ('Types of' ->
  'Types of business organisation', 24 entries); (c) igcse-geography — 69
  wrapped-bullet rows recovered their PDF continuation lines (skills lists,
  topic overviews, SX aims) and 20 two-column-table interleaved rows were
  rebuilt column-sequential (text + sub_items, flag
  `two-column-line-interleave`); (d) 64 edge-whitespace text violations
  trimmed (SCHEMA whitespace-normalised invariant).

# Canonical bundle (v2.0, `canonical-builder-2.0`)

`scripts/build_canonical.py` splits each v1.0 parse into the canonical 7-file
bundle; `scripts/emit_graph.py` derives loader-contract Layer-A YAMLs.

## Layout (per `<qual>/`)

| file | contents |
|---|---|
| `spec_points.json` | canonical points: id, official_code, verbatim text, topic/subsection refs, sub_items, practical flag, **applicability** (papers + double-award sharing, rule-derived), leading_verb, provenance `{pdf, sha1, page, oy}` |
| `topics.json` | topic rows + subsection rows (cover-code IDs, page provenance) |
| `practicals.json` | practical-flagged statements as `PR-xx` records |
| `equations.json` | appendix equations via span-geometry composite assembly (fractions `(n)/(d)`, sup `^`, sub `_`, twin fractions, subject `=` rows); sections per appendix; empty where the spec has none |
| `assessment_objectives.json` | AO statements (dedup, junk-guarded) + per-unit weighting tables (incl. IAL IAS/IA2, AO2a/AO2b splits) |
| `command_words.json` | command-word taxonomy tables (header rows excluded) |
| `parse_report.json` | extended with `canonical_bundle` counts + flags |

`parsed/_derived/graph/<qual>/` — `specification_points.yaml`, `topics.yaml`,
`relationships.yaml`, `practicals.yaml` in the core loader field contract
(`RULE_DERIVED`, per-point PDF provenance). For 4CH1 the emitter reproduces the
ratified store's section codes (`4CH1-S1`), and
`_derived/graph/igcse-chemistry/DIFF_VS_RATIFIED.json` diffs the candidate
against `graph/specification_points.yaml`.

## Oracle results (v2.0 re-validation)

- **Chemistry**: 182/182 code-set parity; command words 25/25 exact parity with
  the ratified store; AO1–3 + per-paper weightings extracted (en-dash loss in
  source text layer flagged, never silently fixed).
- **Physics**: all 18 numbered relationships of the `Physics formulae for
  relationships` appendix reconstruct exactly, incl. stacked fractions
  (`density = (mass)/(volume)`), `kinetic energy = (1)/(2) × mass × speed^2`,
  and the twin-fraction transformer row; modular + SDA variants pass.
- **Flags policy**: dense multi-column formulae sheets (IAL physics, further
  maths, maths A) and AO-descriptors-absent (IAL sciences) are flagged
  informationally; nothing is silently guessed.
