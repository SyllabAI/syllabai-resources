### Q1 — hard — 4 marks

**Q1** [4 marks]

A travel website shows one photograph of each hotel.

Each photograph is stored on the web server as an uncompressed bitmap image with an image resolution of 3000 pixels wide by 2000 pixels high.

Every photograph is displayed on the web page inside an area that is 600 pixels wide by 400 pixels high.

The website owner decides to store each photograph at an image resolution of 600 pixels wide by 400 pixels high instead.

Explain why this decision is suitable for the website, **and** give **one** situation in which the original photographs would still be needed.
