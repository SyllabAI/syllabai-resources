### Q1

- Write a balanced equation for the thermal decomposition of calcium nitrate and identify gas **Y**:

2Ca(NO<sub>3</sub>)<sub>2</sub> (s) → 2CaO (s) + 4NO<sub>2</sub> (g) + O<sub>2</sub> (g)

- Gas **Y** is nitrogen dioxide, NO<sub>2</sub>.
- Calculate the molar mass of the reactant and of gas **Y**:

*M*<sub>r</sub>[Ca(NO<sub>3</sub>)<sub>2</sub>] = 40.1 + 2[14.0 + 3 x 16.0] = 164.1 g mol<sup>-1</sup>

*M*<sub>r</sub>[NO<sub>2</sub>] = 14.0 + 2 x 16.0 = 46.0 g mol<sup>-1</sup>

- Calculate the number of moles of calcium nitrate:

*n*(Ca(NO<sub>3</sub>)<sub>2</sub>) = $\frac{\mathrm{mass}}{M_{r}}$

*n*(Ca(NO<sub>3</sub>)<sub>2</sub>) = $\frac{8.2}{164.1}$

*n*(Ca(NO<sub>3</sub>)<sub>2</sub>) = 0.050 mol

- Use the stoichiometric ratio to find the moles of NO<sub>2</sub> produced:

2 mol Ca(NO<sub>3</sub>)<sub>2</sub> produces 4 mol NO<sub>2</sub>, so the molar ratio is 1 : 2

*n*(NO<sub>2</sub>) = 2 x 0.050 = 0.10 mol

- Calculate the mass of gas **Y**:

mass = *n* x *M*<sub>r</sub>

mass = 0.10 x 46.0

mass = 4.6 g

**A** is incorrect as this uses a 1:1 molar ratio between Ca(NO<sub>3</sub>)<sub>2</sub> and NO<sub>2</sub> instead of the correct 1:2 ratio: 0.050 x 1 x 46.0 = 2.3 g.

**B** is incorrect as this uses the molar mass of N<sub>2</sub> (28.0 g mol<sup>-1</sup>) instead of NO<sub>2</sub> (46.0 g mol<sup>-1</sup>) for gas **Y**: 0.10 x 28.0 = 2.8 g.

### Q2
**Final answer:** **The correct answer is A**

- **A**, 3.00 g of ammonia:
- Calculate the number of *M*<sub>r</sub>:

14.0 + (3 x 1.0) = 17.0

- Calculate the number of moles:

moles = $\frac{\mathrm{mass}}{M_{r}}$

moles = $\frac{3.00}{17.0}$

moles = 0.18 mol

- Calculate the number of moles of atoms:

0.18 x 4 = 0.72 mol of atoms

- **B**, 3.00 g of chloromethane:

*M*<sub>r</sub> = 12.0 + (3 x 1.0) + 35.5 = 50.5

moles = $\frac{3.00}{50.5}$ = 0.059 mol

0.059 x 5 = 0.30 mol of atoms

- **C**, 4.00 g of hydrogen sulfide:

*M*<sub>r</sub> = (2 x 1.0) + 32.1 = 34.1

moles= $\frac{4.00}{34.1}$ = 0.12 mol

0.12 x 3 = 0.36 mol of atoms

- **D**, 4.00 g of hydrogen chloride:

*M*<sub>r</sub> = 1.0 + 35.5 = 36.5

moles= $\frac{4.00}{36.5}$ = 0.11 mol

0.11 x 2 = 0.22 mol of atoms

- Option **A** contains the greatest number of moles of atoms and, therefore, the greatest number of atoms.

**B**, **C** & **D** are incorrect as they do not contain the greatest number of moles of atoms.

> **[exam-tip]**
> There is no need to use the Avogadro constant to answer this question. The option with the greatest number of moles of atoms has the greatest number of atoms, so comparing moles directly is sufficient.
