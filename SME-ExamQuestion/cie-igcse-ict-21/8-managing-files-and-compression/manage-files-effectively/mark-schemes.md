## Exam Questions (3 questions)


### Q1
> **[mark-scheme]**
> Any 4 from:
> 
> - jpg is a lossy format
> - Smaller file size
> - Joint Photographic Experts Group
> - Loses quality when compressed
> - png is a lossless format
> - Does not lose quality when compressed
> - Portable Network Graphics
> 
> **[4 marks]**
> 
> "Explain" requires candidates to provide developed points that show understanding of the differences between the two file types, not just name them

> **[exam-tip]**
> Make sure you clearly distinguish which points relate to jpg and which relate to png. A good approach is to make a comparison, e.g. "jpg is lossy whereas png is lossless." This way, each statement clearly shows a difference. Many students lose marks by only describing one file type without contrasting it with the other. Remember that the question asks for differences, so try to pair your points where possible.
