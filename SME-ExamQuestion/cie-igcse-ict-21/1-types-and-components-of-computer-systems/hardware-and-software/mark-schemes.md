### Q6
Examples of the benefits and drawbacks of using a dialogue based user interface include:

To gain full marks there must be correct benefits **and **drawbacks:

**Benefits **

- Allows for hands free control **[1 mark]**
- Safer than using a standard interface **[1 mark]**
- More useful for physically disabled users **[1 mark]**

**Drawbacks **

- Limited access due to the number of commands stored **[1 mark]**
- More expensive to develop **[1 mark]**
- May not operate reliably due to background noise/speech impediment/accents **[1 mark]**
- Need to be ‘trained’ by the user **[1 mark]**
- Can be distracting if the commands are not understood **[1 mark]**

> **[mark-scheme]**
> "Safer" as a benefit must come from its own distinct, separately developed point to be awarded a mark.
