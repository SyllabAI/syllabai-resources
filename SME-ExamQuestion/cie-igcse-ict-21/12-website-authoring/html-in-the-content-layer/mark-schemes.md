### Q2
The similarities and differences between anchors and hyperlinks include:

Any **four **of the following:

**Similarities **

- Both are links (in a web page) **[1 mark]**
- Both can be attached to icons/text/graphics **[1 mark]**
- Both are html tags used on web pages **[1 mark]**
- Both are used for navigation **[1 mark]**
- Both are coded as html tags starting with **[1 mark]**

**Differences **

- An anchor allows the user to move from one part of a web page to another part **[1 mark]**
- An anchor is a label that identifies a specific position in a document **OR **An anchor is within a hyperlink **[1 mark]**
- An anchor needs a point set in the document and a link **OR **A hyperlink only needs the link and a web address **[1 mark]**
- The code within an anchor will either be "name.." or "id.." **[1 mark]**
- An anchor determines a fixed point on a web page that is used as a bookmark **[1 mark]**
- An anchor can be placed at any point on a web page **[1 mark]**
- A hyperlink allows the user to move from one web page to another web page/website The code within a hyperlink can be "href..", "rel..”, “target..” **[1 mark]**
- A hyperlink can be attached to a block of text or image **[1 mark]**
- A hyperlink can be clicked on to cause another web page or part of the same web page to be displayed **[1 mark]**
- A hyperlink can redirect a user to an anchor by including its name **[1 mark]**
- A hyperlink is clickable **[1 mark]**

> **[mark-scheme]**
> To gain full marks your response must have correct answers for **both** similarities and differences.
