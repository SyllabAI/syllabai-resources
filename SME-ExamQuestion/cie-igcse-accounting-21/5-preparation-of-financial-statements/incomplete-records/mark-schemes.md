### Q10
**Final answer:** **The correct answer is B**

- Remember working capital is current assets minus current liabilities

  - Therefore capital = non-current assets + working capital - non-current liabilities
  - You do not need to include current assets separately
- The opening capital is \$29 000

  - Non-current assets (30 000) + working capital (5 000) - non-current liabilities (6 000)
  - Note that the working capital is the current assets minus the current liabilities so you do not need to include the value of the current assets
- The closing capital is \$44 000

  - Non-current assets (50 000) + working capital (4 000) - non-current liabilities (10 000)
  - Note that the working capital is the current assets minus the current liabilities so you do not need to include the value of the current assets

- The formula for the profit is

  - profit = closing capital - opening capital + drawings
  - profit = \$44 000 - \$29 000 + \$2 000 = \$17 000
