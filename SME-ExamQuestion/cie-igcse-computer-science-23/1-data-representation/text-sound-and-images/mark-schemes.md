### Q1
Sample rate and sample resolution are defined as:

- The **sample resolution** is the number of bits per sample **[1 mark]**

### Q2
**Resolution**

Higher-resolution images have more pixels, which means they contain more detail and have higher quality. However, this also means they have larger file sizes, taking up more storage space and possibly causing slower loading times on websites. On the other hand, lower-resolution images have fewer pixels, which reduces the file size and makes them load faster, but this comes at the cost of image quality, potentially making them look blurry or pixelated when viewed up close or on larger screens.

**Colour depth**

Higher colour depth allows an image to display more colours, leading to better image quality. However, this increases the file size because more bits are needed for each pixel. Lower colour depth reduces the number of colours available, which can make images appear less vibrant but helps in reducing the file size. This is beneficial for faster loading times and less storage usage.

**Examples**

A professional photograph used for printing requires high resolution and high colour depth to ensure excellent quality, but it results in a large file size. In contrast, a thumbnail image on a website typically has low resolution and low colour depth to ensure faster loading times while sacrificing some quality.

> - Applies knowledge directly and consistently with explicit evidence/examples **[1 mark]**
> - Weighs up both sides of the discussion with suitable examples **[1 mark]**
> 
> This is a "Discuss" question worth 8 marks. Marks are awarded using a levels-based approach across three assessment strands:
> 
> - Knowledge and understanding (up to 3 marks): accurate, detailed material covering both resolution and colour depth
> - Application (up to 3 marks): explicit use of examples to support points made
> - Analysis/evaluation (up to 2 marks): weighing up both sides (benefits and drawbacks) of higher/lower resolution and colour depth
> 
> To achieve full marks, candidates must address resolution, colour depth and provide relevant examples. Each property must be discussed in terms of both benefits and drawbacks relating to image quality and file size.
> 
> **[8 marks]**

> **[exam-tip]**
> Make sure you structure your answer clearly using paragraphs — ideally one for resolution, one for colour depth and one for examples. This helps the examiner see that you have addressed all three required areas.
> 
> For each property (resolution and colour depth), always consider both sides: what happens when it is high and what happens when it is low. A common mistake is to only discuss one direction (e.g. only talking about high resolution) without mentioning the trade-off.
> 
> Your examples should be specific and realistic. Rather than saying "a big image has a big file size", explain the context, e.g. "a professional photograph for printing" versus "a thumbnail on a website". This demonstrates application of knowledge and will help you access the higher mark bands.
> 
> Avoid vague statements such as "it makes it better" — always specify what improves (e.g. image quality, detail, colour accuracy) and what worsens (e.g. file size, loading time, storage requirements).

### Q7
Unicode takes up more storage space as:

- Each character is encoded/stored using more bits **[1 mark]**

> **[exam-tip]**
> Saying Unicode has more characters available is not the reason for greater storage and will not gain the mark
