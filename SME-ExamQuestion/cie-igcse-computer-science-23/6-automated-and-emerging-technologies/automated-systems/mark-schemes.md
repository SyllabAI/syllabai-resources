### Q8
The system uses sensors and the microprocessor by:

Any **six **from the following:

- Suitable sensor used e.g. motion sensor/pressure sensor **[1 mark]**
- Analogue data is converted to digital, using an analogue-to-digital converter (ADC) **[1 mark] **
- The sensor sends data to the microprocessor **[1 mark]**
- Data is compared to stored data … **[1 mark]**
- … if a value outside range/within range water is sprayed **[1 mark]**
- … the signal is sent to the actuator to spray water **[1 mark] **
- … if the value is within range/outside range no action is taken **[1 mark] **
- Continuous loop **[1 mark]**

> **[exam-tip]**
> - An example of a six-mark response could be:
> 
> *The system in the theme park game uses sensors, such as motion or pressure sensors, to detect when a player is running past. These sensors send data to the microprocessor, where the data is converted from analogue to digital using an analogue-to-digital converter (ADC). The microprocessor compares this data to the pre-set conditions. If the data indicates that the player has passed the sensor, the microprocessor sends a signal to an actuator, which triggers the spraying of water. If the data doesn't match the conditions for spraying, no action is taken. This process continues in a loop, ensuring the system responds to each player in real-time.*

### Q9
The system uses the temperature sensor and the microprocessor to maintain the temperature in the greenhouse by:

Any **eight **of the following:

- Sensor sends data/readings/signal to microprocessor **[1 mark]**
- Data is converted from analogue to digital using analogue to digital converter (ADC) **[1 mark]**
- Microprocessor compares/checks data to stored values/range of values... **[1 mark]**
- … If data is greater than 30 / above the range microprocessor sends a **signal** to open the window and to turn heater off **[1 mark]**
- **… **If data is below 25 the microprocessor sends a **signal **to turn on the heater and to close the window **[1 mark]**
- … If data is between 25 and 30 / within the range no action is taken **[1 mark]**
- Actuator is used to operate heater/window **[1 mark]**
- **Whole **process is continuous **[1 mark]**

> **[exam-tip]**
> - An example of a eight mark response could be:
> 
> *The system operates by using a temperature sensor to constantly monitor the conditions inside the greenhouse. The sensor collects temperature data and sends it to the microprocessor, where the data is converted from analogue to digital using an analogue-to-digital converter (ADC). The microprocessor then compares this data to the pre-set temperature range of 25°C to 30°C. If the temperature goes above 30°C, the microprocessor sends a signal to open the window and turn off the heater to cool the greenhouse. Conversely, if the temperature falls below 25°C, the microprocessor will send a signal to close the window and turn the heater on. If the temperature is within the desired range, no action is taken. Actuators are used to physically operate both the heater and the window, and this process runs continuously to maintain the optimal growing conditions for Jamelia's plants.*
