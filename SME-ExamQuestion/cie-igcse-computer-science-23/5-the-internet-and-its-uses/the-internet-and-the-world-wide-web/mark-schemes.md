### Q7
HTML structure and presentation is:

**Structure **

- Layout of the web page **[1 mark]**
- Any valid example, e.g. Where text is placed **[1 mark]**

**Presentation **

- Formatting of the web page (accept: formatting/format of the elements) **[1 mark]**
- Any valid example, e.g. the colour of the font (accept: colour fonts) **[1 mark]**

> **[exam-tip]**
> Don't confuse the two — structure is the layout/organisation of the page, presentation is its formatting; never define structure as 'the code'
> 
> Give a specific, clearly labelled example for each, and keep presentation examples about formatting features rather than content like images or links
