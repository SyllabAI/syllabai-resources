### Q2
Encryption protects data transmitted over wireless networks by:

- scrambling data into ciphertext **[1 mark]** *accept encrypting/encrypted the data/message as equivalent to scrambling into ciphertext*
- … making it unreadable to anyone intercepting the data **[1 mark]**

The **role **of the master key is to:

- protect the data from unauthorised access **[1 mark]** *accept the master key is used to encrypt/decrypt the data*

The **importance **of not transmitting the master key is:

- without the master key, any intercepted data is meaningless and cannot be decrypted **[1 mark]** *accept if the key is intercepted/leaked, the same key can be used to decrypt the data*

> **[exam-tip]**
> When asked about the importance of keeping the key secret, always explain what an interceptor cannot do without it, not just that it stays hidden
> 
> Use precise technical vocabulary such as ciphertext rather than vague terms like codes or the message
