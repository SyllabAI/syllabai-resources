### Q4
The file is transmitted using packet switching by:

Any **five **from:

- Data is broken/split/divided into packets **[1 mark]**
- Each packet (could) take a different route **[1 mark]**
- A router controls the route/path a packet takes **[1 mark]**
- … selecting the shortest/fastest available route/path **[1 mark]**
- Packets may arrive out of order **[1 mark]**
- Once the last packet has arrived, packets are reordered**[1 mark]**
- If a packet is missing/corrupted, it is requested again **[1 mark]**

> **[exam-tip]**
> - An example of a 5 mark response could be:
> 
> *Packet switching is a method used to send data, like a sound file, over a network by breaking the file into smaller pieces called packets. Each packet can take a different route through the network, with routers deciding the quickest path for each one. Since the packets travel independently, they might arrive at the destination in a different order. Once all the packets arrive, the receiving computer reorders them using the information in the packets. If any packet is missing or corrupted, the system will request it again, ensuring that the entire file is received correctly.*

> **[exam-tip]**
> - An example of a 4 mark answer could be:
> 
> *A data packet has a specific structure made up of three parts: the header, the payload, and the trailer. The header contains important information such as the destination address, the originator’s address, and the packet number. The payload is the actual data being transmitted, like part of a website. The trailer marks the end of the packet and ensures that the data has been received correctly*
