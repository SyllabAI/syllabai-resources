`Count ← 0`
`REPEAT`
`    INPUT Number`
`    IF Number > 0 THEN`
`        Count ← Count + 1`
`    ENDIF`
`UNTIL Number < 0`
`OUTPUT "Total positive numbers entered:", Count`

- correctly initialising the count to 0 **[1 mark]**
- setting up a loop that continues while the user input is positive **[1 mark]**
