### Q3
A program might need to store data as:

Any **three **of the following:

- Data is not lost when the computer is switched off **OR** data is stored permanently **[1 mark]**
- Data can be used by more than one program or reused when a program is run again **[1 mark]**
- Data can be backed up or archived **[1 mark]**
- Data can be transported from one place / system to another **[1 mark]**

> **[exam-tip]**
> Give three distinct reasons and make each precise, e.g. reuse on a rerun rather than a vague 'for future use'
> 
> Stick to reasons for storing data permanently, not points about editing, deleting or manipulating files
