## Q7 — medium — 8 marks · exam-questions

### 3() — 8 marks
> **[mark-scheme]**
> (i)
> 
> To provide internet access/service
> 
> (ii)
> 
> Any two from:
> 
> - Router
> - Gateway
> - (Network) cable
> - Modem
> - Network interface (card) / NIC
> 
> Do not accept ‘wire’ for cable.
> 
> Do not accept types of cable that are not network cables (e.g. ‘power cable’
> 
> (iii)
> 
> A description to include any two linked points from:
> 
> To check / interpret a URL (1), send a request for an IP (1) to a domain name server (1) then fetch the resource (from the web server at that IP address) (1) interprets HTML (1) then displays the contents to the user (1)
> 
> (iv)
> 
> Any one from:
> 
> - Identifying/locating/track a device/person
> - Ensuring data can be / is sent (to the correct device)
> 
> (v)
> 
> An explanation such as:
> 
> - More reliable method of identifying a device (1) because MAC addresses are hard coded / uniquely identify a device (1)
> - Harder to identify a device to attack (1) because MAC addresses are not contained in data packets (1)
> - A MAC address is unique (1) because the last three hex pairs reference the individual device’s network interface card (1)
> - The manufacturer can be identified (1) because the first three hex pairs reference the manufacturer code (1)
> 
> Accept: “MAC cannot be changed” for “hard-coded”. 
> Do not accept: “more secure” for “harder to identify a device to attack”
