The ethene reaction is one instance of a method that works for
*any* alkene, and the method is worth learning as a drawing
routine. Always draw the alkene with the C=C vertical in the
middle. Cut the double bond into two single bonds, one on each
side. Attach a continuation bond to each freed end, wrap the
whole unit in square brackets with the subscript n, and you
have the polymerisation equation. Nothing else in the molecule
moves: whatever atoms or groups hang off the double-bond
carbons keep their positions, they just ride along on the
outside of the [[repeat-unit]].

**Propene** is the first rehearsal. Its formula is normally
written CH₃CH=CH₂ — three carbon atoms, think of it as a
modified ethene molecule with a CH₃ group attached in place of
one hydrogen atom. Run the routine: the double bond opens, the
CH₃ group stays attached to its carbon, and the product is
[[polypropene]], which used to be called polypropylene:

```
   CH₃  H               CH₃  H
   |    |               |    |
n  C == C     →       [  C - C  ]n
   |    |               |    |
   H    H               H    H
   (propene)        (poly(propene) repeat unit)
```

Poly(propene) is somewhat stronger than poly(ethene), which is
why it turns up where a bit of muscle is needed — ropes and
crates among many other things. Packaging carrying a recycling
mark with the letters PP in it or near it is made of
poly(propene).

**Chloroethene** is the second rehearsal: one of ethene's
hydrogen atoms is replaced by a chlorine, giving CH₂=CHCl. It
was once called vinyl chloride, and polymerising it gives
[[polychloroethene]] — better known by its old name,
polyvinylchloride, or PVC:

```
   Cl   H               Cl   H
   |    |               |    |
n  C == C     →       [  C - C  ]n
   |    |               |    |
   H    H               H    H
(chloroethene)   (poly(chloroethene) repeat unit)
```

Whether you draw the chlorine on the left-hand carbon or the
right-hand one makes no difference — the repeat unit is the
same either way, so pick one and stay consistent.

PVC has a lot of uses because it starts out quite strong and
rigid: water pipes and replacement windows are its natural
territory. It can also be made flexible by adding
[[plasticiser]]s — additives that slip between the chains and
let them slide — which opens up a second life for the polymer
in sheet floor coverings, and even clothing. One more property
lands it a third job: these polymers do not conduct
electricity, therefore PVC is used for electrical insulation,
the coating on the wires behind your walls.

:::exam-hint
Statement 4.45 names the four polymers whose repeat units you
must be able to draw: poly(ethene), poly(propene),
poly(chloroethene) and poly(tetrafluoroethene). Practise the
four as a set — they are the same routine run four times, with
H, CH₃, Cl and F riding on the repeat unit respectively. The
styrene case in the question bank (u4:c29:s09) is the same
routine with a whole benzene ring riding along, which is why
examiners like it: it tests the routine, not the memory.
:::

:::misconception
"The chlorine atom must be drawn on a particular side of the
repeat unit, otherwise the polymer is wrong." Addition
polymerisation leaves the substituent where the monomer had it,
and the monomer can approach the growing chain from either
end — so left and right placements describe the same polymer.
What *would* be wrong is moving the chlorine onto a hydrogen
position, dropping it entirely, or bonding it into the chain:
the substituent hangs off the carbon, never in the backbone.
:::

:::quick-check
Can you run the four-step routine (draw the alkene with C=C in
the middle, open the bond, add continuation bonds, bracket with
n) for propene and chloroethene without looking? Can you name
the polymer and one use for each? Can you explain what
[[plasticiser]]s change about PVC and why that matters for
floor coverings? If yes, the only named polymer left is the
fluorine one — next section.
:::
