An **[[element]]** is a substance that cannot be split into anything simpler
by chemical means. Every element contains only one kind of atom — heat it,
react it, electrocute it, and you will never chemically prize an element
apart into different substances. In models and diagrams, elements are drawn
as atoms of a single colour or size. The book's examples are a pure metal
such as magnesium, oxygen gas, and diamond (a form of carbon) — three very
different materials, but each contains just one type of atom (Figure 2.3).

One subtlety, which the book flags in its margin: it is not *completely*
true to say an element contains only one type of atom. Most elements are
natural mixtures of **[[isotope]]s** — atoms with the same atomic number but
different mass numbers, because they carry different numbers of neutrons.
The precise statement is that all the atoms in an element have the same
**[[atomic-number]]**. Diagrams and models usually ignore the
difference between isotopes; they get their full treatment in Chapter 3.

:::key-point
The safe definition: all the atoms in an element have the **same atomic
number**. "Only one type of atom" is almost right, but isotopes mean most
elements contain atoms of slightly different masses — same protons,
different neutrons (Chapter 3).
:::

:::misconception
"Oxygen gas can't be an element — its particles contain two atoms joined
together." No — an element is defined by having **one type of atom**, not
one atom per particle. Oxygen gas contains only oxygen atoms, so it is an
element; the same is true of nitrogen, hydrogen and chlorine gases.
:::

:::exam-hint
"State what is meant by an *element*" (1 mark): mark schemes accept
"a substance that cannot be broken down into anything simpler by chemical
means" or "contains only one type of atom / atoms with the same atomic
number". Avoid circular answers like "an element is a substance made of
elements".
:::
