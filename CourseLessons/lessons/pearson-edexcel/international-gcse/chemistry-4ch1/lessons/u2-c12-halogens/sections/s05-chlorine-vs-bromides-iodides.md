Put a more reactive halogen into a solution of a less reactive halogen's
salt and the newcomer takes over: it pushes the original halogen out of
solution and takes its place. These are **[[displacement-reaction]]**s,
and they are the experimental engine of this chapter — a way of *ranking*
the halogens by reactivity using nothing more than colour changes.

**Demo 1: chlorine water + potassium bromide solution.** Add orange-free
— colourless — potassium bromide solution to chlorine water and the
mixture turns **orange**: bromine has been formed.

Cl₂(aq) + 2KBr(aq) → 2KCl(aq) + Br₂(aq)

Chlorine is more reactive than bromine, and it has **displaced** the
bromine from solution. The way to think about it: a more reactive element
has a greater tendency to react and form a compound; a less reactive
element is more likely to fall back to being the free, unreacted element.
Chlorine wins the compound-forming contest, so bromine is pushed back out
as the element.

**Demo 2: chlorine water + potassium iodide solution.** The same
experiment with potassium iodide solution gives a **brown** solution
(orange if very dilute) — iodine has been displaced:

Cl₂(aq) + 2KI(aq) → 2KCl(aq) + I₂(aq)

And the ladder keeps its order one rung down: bromine water added to
potassium iodide solution also gives brown iodine,

Br₂(aq) + 2KI(aq) → 2KBr(aq) + I₂(aq)

because bromine, though weaker than chlorine, is still stronger than
iodine. Reactivity falls down the group, and every one of these
colour changes is a measurement of that fall.

Colour is your observation data in these experiments, so the shades need
to be exact. Pure liquid bromine is red-brown — but **bromine in solution
is orange**, and a very dilute solution can look yellow. Iodine in
solution is brown (yellow-brown when dilute). Learn the in-solution
colours, not the neat-element colours, because exams show you solutions.

:::key-point
Colour discipline for displacement work: pure liquid bromine is
**red-brown**, bromine **in solution** is **orange** (dilute: yellow);
iodine in solution is **brown** (dilute: yellow-brown). Observations
should name the solution colour, and the displaced halogen, every time.
:::

:::exam-hint
Precision of wording is marked directly: write **"chlorine displaces
bromine"**, never "chlorine displaces bromide". Bromine is the displaced
*element* (Br₂); bromide is the *ion* (Br⁻) that sat in the salt before
the reaction. The same grammar fixes every variant: "bromine displaces
iodine", "chlorine displaces iodine". An answer that swaps element and
ion names reads as if the chemistry itself is muddled — and the mark
scheme treats it that way.
:::

:::misconception
"The solution turned orange because potassium bromide solution is orange."
Potassium bromide solution is **colourless** — the orange appears only
*because* bromine is produced by the reaction. In every displacement
observation, the colour you see belongs to the **displaced halogen**
formed as a product, never to the salt that was already there. Read the
colour, name the displaced halogen: orange → bromine; brown → iodine.
:::
