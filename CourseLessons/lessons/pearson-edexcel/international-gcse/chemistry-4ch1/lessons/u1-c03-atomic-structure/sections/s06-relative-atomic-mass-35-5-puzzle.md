Look up chlorine on the [[periodic-table]] and you meet a paradox. The number
printed against chlorine appears to be a **mass number of 35.5**. Try the
§s04 formula on it:

> number of neutrons = 35.5 − 17 = 18.5

It is not possible to have **half a neutron** — so something must be wrong
with this. And something is: 35.5 is not a mass number at all. It is the
**[[relative-atomic-mass]] (Aᵣ)** of chlorine. Chlorine consists of two
isotopes, ³⁵Cl and ³⁷Cl, and a naturally occurring sample contains a
**mixture of these** — so the 35.5 is an average across the whole sample,
not the mass of any single atom.

A plain average would not do, because the isotopes are not present in
equal amounts. The tool for this is the same one you use in maths when
some values count for more than others: the
**[[weighted-average]]** (or **weighted mean**). The relative atomic mass
is a weighted average of the isotope masses, weighted by how much of each
isotope is present in a naturally occurring sample. That single sentence
is the definition behind spec 1.16's last term — and §s07 and §s08 turn it
into a calculation you can perform.

:::

:::cross-curricular
**Maths:** the weighted mean is a taught GCSE maths skill — values scaled
by weights before averaging. Aᵣ is that exact calculation applied to
isotope masses and abundances; the maths department's "weighted average"
and chemistry's "relative atomic mass" are one and the same operation.
:::key-point
35.5 for chlorine is a **relative atomic mass (Aᵣ)**, not a mass number —
no atom has half a neutron. Aᵣ is a weighted average of the isotope masses
across a naturally occurring sample; chlorine's sample is a mixture of
³⁵Cl and ³⁷Cl.
:::

:::misconception
"Chlorine's mass number is 35.5, so a chlorine atom has 18.5 neutrons."
Twice wrong — no chlorine atom has 18.5 neutrons (impossible), and 35.5 is
not any atom's mass number. Real chlorine atoms are ³⁵Cl (18 neutrons) or
³⁷Cl (20 neutrons); the 35.5 is the sample's weighted average.
:::

:::exam-hint
If an exam gives a non-integer "mass number" (35.5, 63.5), it is telling
you the quantity is a **relative atomic mass** — say so explicitly.
Naming the quantity correctly ("Aᵣ, not mass number") is usually a mark
in itself on questions of this type.
:::
