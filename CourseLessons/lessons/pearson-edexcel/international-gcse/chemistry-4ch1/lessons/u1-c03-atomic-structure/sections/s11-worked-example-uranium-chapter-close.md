This worked example runs the §s10 recipe on a heavy atom. The symbol for
uranium is given in a Periodic Table as **²³⁸U (uranium, atomic number
92)**. Calculate the number of protons, neutrons and electrons in an atom
of uranium.

- The atomic number is the **smaller** number, so uranium's atomic number
  is 92 → a uranium atom contains **92 protons**.
- Protons = electrons → **92 electrons**.
- Neutrons = mass number − atomic number = 238 − 92 = **146**.

Same three lines as always — the atom just gets heavier. (For this you
will need the Periodic Table printed in your exam paper.)

The chapter-closing skill list is worth self-checking: particle locations
and charges; counting the particles in a fluorine atom; reading
nuclide-style symbols like ⁵⁶Fe and ⁹³₄₁Nb; chlorine's two isotopes; and a
run of relative-atomic-mass calculations — lithium, magnesium with three
isotopes, and lead with four. This lesson's practice is wired to the
question bank below.

One last fact for the road: considering only the most
common isotope of each element, there is **only one element that has more
protons than neutrons**. Work it out with the recipe — the answer is
hydrogen, whose most common atom (¹H) has 1 proton and **0** neutrons;
every other element's most common isotope carries at least as many
neutrons as protons.

:::worked-example
Uranium ²³⁸U, atomic number 92: atomic number = smaller number = 92 →
92 protons; electrons = protons → 92 electrons; neutrons = 238 − 92 =
146. Mark lines: (1) identify the atomic number as the smaller number;
(2) protons from atomic number; (3) electrons = protons; (4) subtract for
neutrons.
:::

:::key-point
The counting recipe is atom-independent: ²³⁸U → 92 protons, 92 electrons,
146 neutrons. And a chapter-closing curiosity — hydrogen-1
is the only most-common-isotope atom with more protons than neutrons
(1 proton, 0 neutrons).
:::

:::misconception
"Heavy atoms like uranium have far more electrons than protons." No —
charge balance holds for every atom: 92 protons, 92 electrons. What grows
faster in heavy atoms is the **neutron** count (146 here), which is
exactly why neutrons = mass number − atomic number is the line you keep
computing.
:::

:::exam-hint
For "state the numbers of protons, neutrons and electrons" answers,
present all three counts in order (protons, electrons, neutrons) with the
substitution shown for neutrons (238 − 92 = 146). The substitution line is
the method mark; the three numbers are the answer marks.
:::

:::summary
- An **[[atom]]** is the smallest piece of an element still recognisable
  as that element; a **[[molecule]]** is two or more atoms chemically
  bonded (H₂, H₂O). Only nuclear processes split atoms — chemistry never
  does.
- Atoms contain **protons** (mass 1, charge +1) and **neutrons** (mass 1,
  charge 0) in the nucleus, with **electrons** (mass 1/1836, charge −1)
  outside; virtually all the mass is nuclear.
- **Atomic number** = protons (defines the element); **mass number** =
  protons + neutrons; **neutrons** = mass number − atomic number;
  electrons = protons (neutral atoms).
- **Isotopes**: same atomic number, different mass numbers — chemically
  identical, because chemistry belongs to the electrons.
- **Aᵣ** is the weighted average of isotope masses across a natural
  sample (chlorine 35.5: mostly ³⁵Cl; boron 10.8 from 20%/80%).
- Periodic Table: ordered by increasing atomic number; smaller number =
  atomic number; run the three-line recipe for any atom.
:::
