Organic names look complicated until you see that they are **codes**.
[[iupac-nomenclature]] — the naming rules of the International Union
of Pure and Applied Chemistry — builds every name from parts, and each
part tells you something specific: one part gives the number of carbon
atoms in the longest chain, another says whether carbon-carbon double
bonds are present, another identifies branches and functional groups.
Read the parts and the molecule assembles itself; this section
installs the first code book, the chain-length code.

| Code letters | Carbons in chain |
|--------------|------------------|
| meth         | 1                |
| eth          | 2                |
| prop         | 3                |
| but          | 4                |
| pent         | 5                |
| hex          | 6                |

The first four codes have to be learned outright — there is no
pattern connecting one to five to carbon counts. A mnemonic helps:
**M**onkeys **E**at **P**ink **B**ananas lines meth, eth, prop, but
up in order, and the specification's own limit (compounds containing
up to six carbon atoms) means this six-row table is the complete code
book. From five onward the Greek roots take over, which is why *pent*
means five (as in pentagon) and *hex* means six (as in hexagon) —
those two you can reconstruct instead of memorise. Worked examples:
butane carries a chain of four carbon atoms; propane carries a chain
of three.

A second code segment appears inside longer names: the letters *an*
signal that the carbons are joined by **single bonds**. Decode
propan-1-ol as a demonstration: *prop* says three carbon atoms,
*an* says they are joined by carbon-carbon single bonds, and the
ending *-ol* (a code you meet properly in the alcohols section) adds
information of its own. Every extra fragment in a name is a extra
fact about the structure — nothing in an IUPAC name is decoration.

One caution before moving on: the name describes the molecule's
connectivity, not its drawing's orientation. Take but-1-ene drawn
with the double bond at the left, then drawn flipped so it sits on
the right — the same molecule, turned over, with what was left now on
the right and vice versa. Nobody renames a molecule because it moved;
both drawings are but-1-ene. So when two drawings seem to disagree,
check whether a rotation explains the difference before you suspect
two different compounds — and keep the chain-length code (the table
above) as your first decoding stop in every name you meet.

:::exam-hint
Decode-first is the examinable direction. Decoding a name into a
structure is worth far more marks than constructing a name from a
structure, and if you cannot decode what an examiner or a question is
talking about, the whole item is lost — so drill the code table until
meth-through-hex are reflexes. The six-carbon limit is itself a gift:
it caps the vocabulary you must learn and tells you no question will
hide a heptane at you.
:::

:::misconception
"Flipping the drawing changes the name." A molecule in space has no
left or right — the name encodes structure, not page position. But-1-ene
stays but-1-ene whichever end you draw it from, because flipping is
rotation, not reconstruction. The names that genuinely differ (but-1-ene
versus but-2-ene, say) differ in *code content* — where the double
bond starts — never in how the paper is oriented.
:::

:::quick-check
Can you recite the six chain-length codes and their carbon counts,
and say which four need pure memorisation? Can you decode propan-1-ol
fragment by fragment — chain length, bond type, and what the ending
contributes? Can you explain why a molecule drawn upside-down keeps
its name? With the code book installed, the next section adds the
bond-type endings and builds the two simplest families.
:::
