Carbon chains grow side branches as well as length, and the naming
code handles branches with exactly the same economy. Hydrocarbon
chains can carry small side chains — at International GCSE you are
likely to meet only two:

| Side chain | Coded |
|------------|-------|
| CH₃−       | methyl |
| CH₃CH₂−    | ethyl  |

The count of carbons in a side chain is coded exactly like a main
chain — *meth* for a one-carbon side chain, *eth* for two — and the
ending **yl** signals that the group is attached to something else
rather than standing alone. A methyl branch is a CH₃ group hanging
off the main chain; an ethyl branch adds one more carbon.

Reading the full [[iupac-nomenclature]] code is a skill worth over-practising, because it is
much more important to be able to **decode** names into structures
than the reverse — if you cannot decode what a question or an examiner
is talking about, you are completely lost. Three rules run the decode.
First, the name of a molecule is always based on the **longest chain**
you can find in it. Second, the position of each branch is numbered
from the end that produces the smaller numbers — exactly as with
double-bond positions in alkenes. Third, when there is more than one
branch, you describe the position of each.

Watch the rules produce two names. The longest chain in the first
molecule has four carbon atoms (*but*) with no double bonds (*ane*),
so the name is based on butane; a methyl group branches from carbon
number 2, counting from the end that gives the smaller number — the
compound is **2-methylbutane**. The second molecule's longest chain
has three carbons and no double bonds, so the base is propane; there
are **two** methyl groups attached to the second carbon — the compound
is **2,2-dimethylpropane**. The prefix *di* shows two identical
branches, and the 2,2 says both sit on the second carbon atom.

Decoding runs in reverse too, and it is specification 4.5's skill:
draw the structure from the name.

:::worked-example
Decode 2,3-dimethylbut-2-ene into a [[structural-formula]] (4.4 + 4.5).

1. Scan for the longest-chain code: *but* — a four-carbon main chain.
2. Scan for the bond ending: *ene* with position −2− — a carbon-carbon
   double bond starting on the second carbon atom.
3. Scan for branches: *dimethyl* — two methyl (CH₃) groups, at
   positions 2 and 3.
4. Draw the skeleton first: four carbons in a line, the double bond
   between C2 and C3, a CH₃ branch pointing off C2 and another off
   C3 (up or down does not matter).
5. Add hydrogens last, enough that every carbon makes exactly four
   bonds. Figure-free, formula-first: the name is now a structure —
   and the four-bond audit (u1:c08 bookkeeping) is the check that
   catches every mistake.
:::

:::key-point
Side-chain carbons are counted with the same code as main chains:
*meth* = one carbon, *eth* = two. The ending **yl** is the marker that
the group is attached to something else — methyl is CH₃− *as a
branch*, never methane loose in the mixture.
:::

:::exam-hint
Structure-from-name is where decoding pays its marks: scan the name in
order — longest chain, bond ending and position, branches and their
positions — and build the skeleton before adding any hydrogens. For
the reverse direction, always name from the *longest* chain you can
trace, and remember the branch positions must come out as small
numbers. Draw your isomers with the longest chain horizontal (or
redraw without the hydrogens first) so you never mistake a rotated
chain for a new structure.
:::

:::misconception
"2,2-dimethylpropane must have a five-carbon main chain — I can see
five carbons." Five carbons exist in the molecule, but the **longest
chain** through it holds three: the central carbon connects to four
methyl groups, and any path through the molecule passes three of them.
The name is built on propane with two methyl branches, not on a
five-chain that does not exist. Longest-chain-first is the rule that
makes the code unambiguous — it is why two chemists looking at the
same molecule write the same name.
:::

:::quick-check
Can you decode 2-methylbutane and 2,2-dimethylpropane into structures,
saying which end you numbered from and why? Can you explain what the
*yl* ending adds, and what *di* contributes in a name like
2,2-dimethylpropane? Can you state the three decode rules and run
them on 2,3-dimethylbut-2-ene without looking? That last skill — the
worked example — is the examinable centrepiece of this section.
:::
