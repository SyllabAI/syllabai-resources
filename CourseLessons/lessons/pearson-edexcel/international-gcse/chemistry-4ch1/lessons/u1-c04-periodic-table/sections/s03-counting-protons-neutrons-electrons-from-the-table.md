Lesson u1:c03 built the counting recipe from the definitions of atomic
number and mass number; this section connects it to the chart itself,
because **most Periodic Tables have two numbers against each symbol**.
The book gives you the reading rule: **the atomic number will always be
the smaller number**. The other number will either be the **mass number
of the most common isotope** of the element or the **relative atomic
mass** of the element — and the table you are using tells you which.

From there the recipe is the one you already know, restated by the book
in its table-reading form:

- the number of **protons** in an atom is equal to the **atomic number**;
- the number of **electrons** in an atom is equal to the number of
  protons;
- the number of **neutrons** in an atom = **mass number − atomic number**.

So the Periodic Table is not just a directory of elements — it is the
input device for the particle-counting recipe. Read the smaller number,
you have the protons (and therefore the electrons, for a neutral atom);
take the larger number, subtract, you have the neutrons. That is the
whole method, and it works for every atom on the chart.

:::key-point
Two numbers per symbol: **smaller = atomic number = protons** (=
electrons in a neutral atom); **larger = mass number of the most common
isotope, or the relative atomic mass** — the table tells you which.
Neutrons = larger − smaller. The recipe from u1:c03, now wired to the
chart you will use in every exam.
:::

:::misconception
"The bigger number on the Periodic Table is always the mass number." Not
always — for many elements that second number is the **relative atomic
mass**, which need not be a whole number (chlorine's is 35.5, as you saw
in u1:c03). The reading rule survives either way: atomic number is the
*smaller* number, and for neutron counting you use the mass number of the
most common isotope when the table supplies Aᵣ instead.
:::

:::exam-hint
If a Periodic Table offers you two numbers, never guess which is which:
**the atomic number is always the smaller one**. The book makes the same
point when it walks through chlorine in §s04 — pick the wrong number and
every count that follows (protons, electrons, neutrons) is wrong.
:::
